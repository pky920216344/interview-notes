876. 链表的中间结点

快慢指针：fast 一次两步、slow 一次一步，fast 到尾时 slow 正好在中间。

思路

  • fast 每轮走两步、slow 走一步；循环条件 fast != null && fast.next != null。
  • 奇数长度：fast 停在最后一个结点，slow 在正中间；偶数长度：fast 先出界，slow 停在两个中点里靠后的那个（题目要求返回第二个）。
  • 不用先数长度再走一遍，一遍扫描就定位。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public ListNode middleNode(ListNode head) {3        ListNode slow = head, fast = head;4        // fast 一次走两步、slow 一次一步：fast 走到尾（或出界）时，slow 正好在中间5        while (fast != null && fast.next != null) {6            slow = slow.next;7            fast = fast.next.next;8        }9        return slow;10    }11}
题目

给你单链表的头结点 head ，请你找出并返回链表的中间结点。

如果有两个中间结点，则返回第二个中间结点。

示例 1：

输入：head = [1,2,3,4,5]
输出：[3,4,5]
解释：链表只有一个中间结点，值为 3 。

示例 2：

输入：head = [1,2,3,4,5,6]
输出：[4,5,6]
解释：该链表有两个中间结点，值分别为 3 和 4 ，返回第二个结点。

提示：

  • 链表的结点数范围是 [1, 100]
  • 1 <= Node.val <= 100
