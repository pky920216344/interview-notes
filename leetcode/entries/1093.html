分桶直接累加出 min/max/mean/mode；中位数不用展开样本，按「累计计数够到第 k 名」在桶上定位。

思路

  • 一遍扫 256 个桶：首个非零桶是 min，末个非零桶是 max，sum += k × count[k]、cnt += count[k]，计数最大的桶是 mode。
  • cnt 和 sum 都要 long：1e9 个样本的加权总和能到 2.5e11。
  • 中位数：奇数取第 (cnt+1)/2 名，偶数取第 cnt/2 和 cnt/2+1 名的平均；第 k 名用累计计数扫桶定位，不展开样本。
  • 输出统一保留到 1e-5 精度，避开浮点尾数比较问题。

图解

最优解

时间复杂度 O(256)，空间复杂度 O(1)
1class Solution {2    public double[] sampleStats(int[] count) {3        long cnt = 0, sum = 0;      // 总数和加权总和都可能超 int，用 long4        int min = 0, max = 0, mode = 0;5        long bestCnt = 0;6        boolean seen = false;7        for (int k = 0; k < 256; k++) {8            if (count[k] == 0) continue;9            if (!seen) { min = k; seen = true; }10            max = k;11            cnt += count[k];12            sum += (long) count[k] * k;13            if (count[k] > bestCnt) { bestCnt = count[k]; mode = k; }14        }15        // 中位数：奇数个取第 (cnt+1)/2 名；偶数个取第 cnt/2、cnt/2+1 名的平均16        int v1 = kth(count, (cnt + 1) / 2);17        int v2 = kth(count, cnt / 2 + 1);18        double median = (v1 + v2) / 2.0;19        double mean = (double) sum / cnt;20        return new double[]{fix(min), fix(max), fix(mean), fix(median), fix(mode)};21    }22 23    // 第 k 名（1 起始）的样本值：按累计计数找桶24    private int kth(int[] count, long k) {25        long acc = 0;26        for (int i = 0; i < 256; i++) {27            acc += count[i];28            if (acc >= k) return i;29        }30        return 255;31    }32 33    // 统一到 1e-5 精度，避免浮点尾数差异34    private double fix(double x) {35        return Math.round(x * 100000.0) / 100000.0;36    }37}
题目

我们对 0 到 255 之间的整数进行采样，并将结果存储在数组 count 中：count[k] 就是整数 k 在样本中出现的次数。

计算以下统计数据:

  • minimum ：样本中的最小元素。
  • maximum ：样品中的最大元素。
  • mean ：样本的平均值，计算为所有元素的总和除以元素总数。
  • median ：
    • 如果样本的元素个数是奇数，那么一旦样本排序后，中位数 median 就是中间的元素。
    • 如果样本中有偶数个元素，那么中位数median 就是样本排序后中间两个元素的平均值。
  • mode ：样本中出现次数最多的数字。保众数是 唯一 的。

以浮点数数组的形式返回样本的统计信息 [minimum, maximum, mean, median, mode] 。与真实答案误差在 10-5 内的答案都可以通过。
