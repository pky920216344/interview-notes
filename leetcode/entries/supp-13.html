补充题13. 中文数字转阿拉伯数字

  • 中等
  • 频度 9
  • 模拟
  • 未经力扣验证

先找 亿/万 把串切成三节，每节按「攒数字、遇单位相乘」累加，零跳过；光杆十/百/千当作 1。

思路

  • 先找 亿：前面一段是亿节（×1e8）；亿之后再找 万，分成万节（×1e4）和个节；没有 亿 就只按 万 分。
  • 节内读到数字先攒着，读到 十/百/千 就乘上去累加；零 没有值直接跳过（它只负责垫开位次）。
  • 光杆的 十/百/千（前面没数字）按 1 算：十 = 10、三千六百四十六 按位乘加。
  • 节尾没挂单位的个位直接加上（return v + num）。

最优解

时间复杂度 O(串长)，空间复杂度 O(1)
1class Solution {2    // 中文数字 → 阿拉伯数字：先找 亿/万 把串分成三节，每节按「数字 × 单位」累加3    public long parse(String cn) {4        int yi = cn.indexOf('亿');5        if (yi >= 0) {6            int wan = cn.indexOf('万', yi + 1);   // 亿后面的万，是万节的尾巴7            long ans = sec(cn, 0, yi) * 100000000L;8            if (wan >= 0) return ans + sec(cn, yi + 1, wan) * 10000L + sec(cn, wan + 1, cn.length());9            return ans + sec(cn, yi + 1, cn.length());10        }11        int wan = cn.indexOf('万');12        if (wan >= 0) return sec(cn, 0, wan) * 10000L + sec(cn, wan + 1, cn.length());13        return sec(cn, 0, cn.length());14    }15 16    // 节 [from, to) 的值：读到数字先攒着，读到单位乘上去；零没有值直接跳过17    private long sec(String s, int from, int to) {18        long v = 0, num = 0;19        for (int i = from; i < to; i++) {20            char c = s.charAt(i);21            if (c == '零') { num = 0; continue; }22            int d = c == '两' ? 2 : "零一二三四五六七八九".indexOf(c);23            if (d >= 1) { num = d; continue; }   // 攒数字，等后面的单位24            long u = 0;25            if (c == '十') u = 10;26            else if (c == '百') u = 100;27            else if (c == '千') u = 1000;28            if (u > 0) { v += (num == 0 ? 1 : num) * u; num = 0; }   // 光杆十/百/千当作 129        }30        return v + num;   // 节尾没挂单位的个位直接加上31    }32}
