466. 统计重复个数

  • 困难
  • 频度 1
  • 模拟
  • 哈希表
  • 双指针
  • 字符串
  • 动态规划
  • 待提交

用「s2 配到哪个下标 j」当状态逐块扫 s1；同一状态再现说明出现循环，按「每 cb 块凑 cc 个 s2」整段跳跃。

思路

  • 一眼看穿状态：扫第 k 个 s1 块之前，只需要知道 j（s2 下一个要配的下标）——j 只有 s2.length 种取值。
  • 每个块开工前把 (j → 块号, 已凑 s2 数) 记下来；j 再次出现即找到循环节：cb 个块凑 cc 个 s2。
  • 剩余块数整除 cb 的部分一次跳完，余数继续逐块扫；n1 高达 10⁶ 也只需扫 O(s2) 个块。
  • 陷阱：s2 里有 s1 配不上的字符时 cc=0，照样能跳（答案 0）；最终答案是 cnt / n2 向下取整。

最优解

时间复杂度 O((s1 + s2) × s2)，空间复杂度 O(s2)
1import java.util.*;2 3class Solution {4    public int getMaxRepetitions(String s1, int n1, String s2, int n2) {5        int m = s2.length();6        // 状态 = 下一个要匹配的 s2 下标 j；seen 记这个状态上次出现在第几个 s1 块、那时已凑几个 s27        int[] seenBlock = new int[m], seenCnt = new int[m];8        Arrays.fill(seenBlock, -1);9        int j = 0, cnt = 0, block = 0;10        while (block < n1) {11            if (seenBlock[j] >= 0) {12                // 同一状态再次出现：每 cb 个块凑 cc 个 s2，整段循环一次跳过去13                int cb = block - seenBlock[j], cc = cnt - seenCnt[j];14                int jump = (n1 - block) / cb;15                cnt += cc * jump;16                block += cb * jump;17            } else {18                seenBlock[j] = block;19                seenCnt[j] = cnt;20            }21            if (block >= n1) break;22            // 逐字符扫一个 s1 块：配得上就把 j 前移，凑满一个 s2 就 cnt++、j 归零23            for (int i = 0; i < s1.length(); i++) {24                if (s1.charAt(i) == s2.charAt(j)) {25                    j++;26                    if (j == s2.length()) { j = 0; cnt++; }27                }28            }29            block++;30        }31        return cnt / n2;32    }33}
题目

定义 str = [s, n] 表示 str 由 n 个字符串 s 连接构成。

  • 例如，str == ["abc", 3] =="abcabcabc" 。

如果可以从 s2 中删除某些字符使其变为 s1，则称字符串 s1 可以从字符串 s2 获得。

  • 例如，根据定义，s1 = "abc" 可以从 s2 = "abdbec" 获得，仅需要删除加粗且用斜体标识的字符。

现在给你两个字符串 s1 和 s2 和两个整数 n1 和 n2 。由此构造得到两个字符串，其中 str1 = [s1, n1]、str2 = [s2, n2] 。

请你找出一个最大整数 m ，以满足 str = [str2, m] 可以从 str1 获得。

示例 1：

输入：s1 = "acb", n1 = 4, s2 = "ab", n2 = 2
输出：2

示例 2：

输入：s1 = "acb", n1 = 1, s2 = "acb", n2 = 1
输出：1

提示：

  • 1 <= s1.length, s2.length <= 100
  • s1 和 s2 由小写英文字母组成
  • 1 <= n1, n2 <= 106
