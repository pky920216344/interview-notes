360. 有序转化数组

  • 中等
  • 频度 1
  • 双指针
  • 数组
  • 数学
  • 双指针
  • 排序
  • 未经力扣验证

f(x)=ax²+bx+c 在 a≥0（开口向上）时最大值必在有序数组两端：双指针从两端挑大的放结果末尾；a<0 对称地挑小的放开头。

思路

  • 输入有序，抛物线是单峰的：a≥0 时值最大的一定在 nums[0] 或 nums[n−1] 之一。
  • 两端比 f 值，大的一方写进结果末尾并收缩该侧指针，一轮填完即为升序。
  • a<0 开口向下：两端是最小值，改成从结果开头放小的即可；a=0 退化为线性，同样适用 a≥0 分支。

时间复杂度 O(n)，空间复杂度 O(1)（不计输出）
1class Solution {2    public int[] sortTransformedArray(int[] nums, int a, int b, int c) {3        int n = nums.length;4        int[] res = new int[n];5        // f(x)=ax²+bx+c：a≥0 开口向上，最大值必在两端 → 两端挑大的，从结果末尾往前放6        if (a >= 0) {7            int i = 0, j = n - 1, k = n - 1;8            while (i <= j) {9                long L = f(nums[i], a, b, c), R = f(nums[j], a, b, c);10                if (L >= R) { res[k--] = (int) L; i++; }11                else { res[k--] = (int) R; j--; }12            }13        } else {14            // a<0 开口向下，最小值必在两端 → 两端挑小的，从结果开头往后放15            int i = 0, j = n - 1, k = 0;16            while (i <= j) {17                long L = f(nums[i], a, b, c), R = f(nums[j], a, b, c);18                if (L <= R) { res[k++] = (int) L; i++; }19                else { res[k++] = (int) R; j--; }20            }21        }22        return res;23    }24 25    private long f(int x, int a, int b, int c) { return (long) a * x * x + (long) b * x + c; }26}
