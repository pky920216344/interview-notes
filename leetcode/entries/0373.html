373. 查找和最小的 K 对数字

  • 中等
  • 频度 8
  • 堆
  • 数组
  • 堆（优先队列）
  • 待提交

小顶堆装「行 × 列」下标对：每行先放 (i,0)，弹出谁就把谁那一行的下一列推进来，弹 k 次即答案。

思路

  • 把所有对想成 nums1.length 行的矩阵，每行按列递增：第 k 小只需在堆里维护「每行的候选」。
  • 初始把 (i, 0)（i < min(len1, k)）入堆；弹出的 (i, j) 就是当前最小的对，答案收下它。
  • 弹出后把同一行的下一个 (i, j+1) 推回堆——每行内部有序，堆顶永远是全局最小。
  • 和用 long 比较：两个 10^9 相加会溢出 int；只入前 k 行是因为更靠后的行不可能挤进前 k。

时间复杂度 O(k log k)，空间复杂度 O(k)
1import java.util.*;2 3class Solution {4    public List<List<Integer>> kSmallestPairs(int[] nums1, int[] nums2, int k) {5        // 堆里放下标对 {i, j}：按和排序（和可能超 int，用 long 比；和相同按 i、j 定序保证稳定）6        PriorityQueue<int[]> heap = new PriorityQueue<>((x, y) -> {7            long sx = (long) nums1[x[0]] + nums2[x[1]], sy = (long) nums1[y[0]] + nums2[y[1]];8            if (sx != sy) return Long.compare(sx, sy);9            if (x[0] != y[0]) return x[0] - y[0];10            return x[1] - y[1];11        });12        // 只需前 k 行：第 k 小之前的对每行至少占一个，后面的行轮不到13        for (int i = 0; i < Math.min(nums1.length, k); i++) heap.offer(new int[]{i, 0});14        List<List<Integer>> out = new ArrayList<>();15        while (out.size() < k && !heap.isEmpty()) {16            int[] top = heap.poll();17            out.add(Arrays.asList(nums1[top[0]], nums2[top[1]]));18            if (top[1] + 1 < nums2.length) heap.offer(new int[]{top[0], top[1] + 1});19        }20        return out;21    }22}
题目

给定两个以 非递减顺序排列 的整数数组 nums1 和nums2, 以及一个整数 k。

定义一对值 (u,v)，其中第一个元素来自 nums1，第二个元素来自 nums2。

请找到和最小的 k 个数对 (u1,v1),  (u2,v2)  ...  (uk,vk) 。

示例 1:

输入: nums1 = [1,7,11], nums2 = [2,4,6], k = 3
输出: [[1,2],[1,4],[1,6]]
解释: 返回序列中的前 3 对数：
     [1,2],[1,4],[1,6],[7,2],[7,4],[11,2],[7,6],[11,4],[11,6]

示例 2:

输入: nums1 = [1,1,2], nums2 = [1,2,3], k = 2
输出: [[1,1],[1,1]]
解释: 返回序列中的前 2 对数：
     [1,1],[1,1],[1,2],[2,1],[1,2],[2,2],[1,3],[1,3],[2,3]

提示:

  • 1 <= nums1.length, nums2.length <= 105
  • -109 <= nums1[i], nums2[i] <= 109
  • nums1 和 nums2 均为 升序排列
  • 1 <= k <= 104
  • k <= nums1.length * nums2.length
