456. 132 模式

从右往左扫 + 单调栈：third 维护目前最好（最大）的「2」，栈里存被弹掉的更小值；有数比 third 小就是 132。

思路

  • 倒着扫，栈从底到顶递增；third 记录「目前为止当过 2 的最大值」。
  • 遇到 nums[i]：先判 nums[i] < third（它就是 1，且右边有更大的 3 压着 2）→ 直接 true。
  • 否则把栈里所有 < nums[i] 的弹出，最后一个弹出的就是新的 third（它比其他弹出值大，是最优的 2）；然后 nums[i] 入栈当候选 3。
  • 关键：third 只增不减——弹出次序保证最后弹出的最大，不用额外比较。

1import java.util.*;2 3class Solution {4    public boolean find132pattern(int[] nums) {5        // 从右往左扫：third 是目前最好（最大）的「2」，栈里是被弹掉的更小值6        Deque<Integer> stack = new ArrayDeque<>();7        int third = Integer.MIN_VALUE;8        for (int i = nums.length - 1; i >= 0; i--) {9            // nums[i] 比 third 还小：它当「1」，右边已有「3」>「2」> 它，成立10            if (nums[i] < third) return true;11            // nums[i] 当候选「3」：把栈里比它小的都弹掉，最后一个弹出的就是新的「2」12            while (!stack.isEmpty() && stack.peek() < nums[i]) {13                third = stack.pop();14            }15            stack.push(nums[i]);16        }17        return false;18    }19}
题目

给你一个整数数组 nums ，数组中共有 n 个整数。132 模式的子序列 由三个整数 nums[i]、nums[j] 和 nums[k] 组成，并同时满足：i < j < k 和 nums[i] < nums[k] < nums[j] 。

如果 nums 中存在 132 模式的子序列 ，返回 true ；否则，返回 false 。

示例 1：

输入：nums = [1,2,3,4]
输出：false
解释：序列中不存在 132 模式的子序列。

示例 2：

输入：nums = [3,1,4,2]
输出：true
解释：序列中有 1 个 132 模式的子序列： [1, 4, 2] 。

示例 3：

输入：nums = [-1,3,2,0]
输出：true
解释：序列中有 3 个 132 模式的的子序列：[-1, 3, 2]、[-1, 3, 0] 和 [-1, 2, 0] 。

提示：

  • n == nums.length
  • 1 <= n <= 2 * 105
  • -109 <= nums[i] <= 109
