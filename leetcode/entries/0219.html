219. 存在重复元素 II

  • 简单

  • 哈希表
  • 滑动窗口
  • 待提交

哈希表记每个值最近一次出现的下标；再遇到同值时只跟上一次比距离，超过 k 就把表更新成当前位置。

思路

  • 扫一遍，last[v] 记值 v 上次出现的下标。
  • 再遇到 v：若 i - last[v] <= k 直接返回 true；否则更新 last[v] = i。
  • 只和上一次比就够：更早的同值下标距离只会更大（本题 k ≥ 0，距离为 i - j，无绝对值坑）。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public boolean containsNearbyDuplicate(int[] nums, int k) {5        // last[v]：值 v 上次出现的下标；只需和上一次比距离6        Map<Integer, Integer> last = new HashMap<>();7        for (int i = 0; i < nums.length; i++) {8            Integer j = last.get(nums[i]);9            // 更早的同值下标离得更远，不必再看10            if (j != null && i - j <= k) return true;11            last.put(nums[i], i);12        }13        return false;14    }15}
题目

给你一个整数数组 nums 和一个整数 k ，判断数组中是否存在两个 不同的索引 i 和 j ，满足 nums[i] == nums[j] 且 abs(i - j) <= k 。如果存在，返回 true ；否则，返回 false 。

示例 1：

输入：nums = [1,2,3,1], k = 3
输出：true

示例 2：

输入：nums = [1,0,1,1], k = 1
输出：true

示例 3：

输入：nums = [1,2,3,1,2,3], k = 2
输出：false

提示：

  • 1 <= nums.length <= 105
  • -109 <= nums[i] <= 109
  • 0 <= k <= 105
