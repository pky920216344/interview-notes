1151. 最少交换次数来组合所有的 1

  • 中等
  • 频度 4
  • 滑动窗口
  • 数组
  • 滑动窗口
  • 未经力扣验证

1 的总数 k 就是最终窗口长度；找长度 k 的窗口让里面的 0 最少，0 的个数就是交换次数。

思路

  • 全部 1 必须连成一段，段长固定 = 1 的总数 k。
  • 每次交换把窗口外的一个 1 换进窗口里的一个 0 → 交换次数 = 窗口内 0 的个数。
  • 滑动窗口枚举所有长度 k 的段，维护其中 0 的最少个数。
  • 窗口右移一格：进一个出一个，zeros O(1) 更新。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int minSwaps(int[] data) {3        int k = 0;4        for (int x : data) k += x;   // 1 的总数 = 最终连续段的长度5        // 滑动窗口：长度 k 的窗口里 0 越少，交换次数越少6        int zeros = 0, best = Integer.MAX_VALUE;7        for (int i = 0; i < data.length; i++) {8            if (data[i] == 0) zeros++;9            if (i >= k && data[i - k] == 0) zeros--;   // 窗口左端移出10            if (i >= k - 1) best = Math.min(best, zeros);11        }12        return best;13    }14}
