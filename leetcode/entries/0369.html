369. 给单链表加一

  • 中等
  • 频度 5
  • 链表
  • 链表
  • 数学
  • 未经力扣验证

找最后一个非 9 的结点：它加 1、后面全是 9 归零；若全是 9，就整体归零并在前面补一个 1。

思路

  • 加一只影响尾部一串 9：进位停在最后一个非 9 的结点上，先一趟扫描找到它。
  • 找到 last：last.val++，last 后面的 9 全部改成 0，返回原头结点。
  • 全是 9（last == null）：所有结点归零，new ListNode(1, head) 接在前面当新头，返回新头。
  • 不用反转链表、不用递归，两趟扫描、原地完成。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public ListNode plusOne(ListNode head) {3        // 加一只会停在最后一个非 9 的结点上：先扫一遍找到它4        ListNode last = null;5        for (ListNode p = head; p != null; p = p.next) {6            if (p.val != 9) last = p;7        }8        if (last == null) {                      // 全是 9：位数变多，前面补一个 19            for (ListNode p = head; p != null; p = p.next) p.val = 0;10            return new ListNode(1, head);11        }12        last.val++;                              // 它加 1，进位到此为止13        for (ListNode p = last.next; p != null; p = p.next) p.val = 0;   // 它后面全是 9，全部归零14        return head;15    }16}
