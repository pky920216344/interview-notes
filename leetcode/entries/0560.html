560. 和为 K 的子数组

  • 中等
  • 频度 84
  • 前缀和/差分
  • 哈希表
  • 数组
  • 哈希表
  • 前缀和
  • 力扣已通过

前缀和 + 哈希计数：查有多少旧前缀等于 prefix - k，就有多少段和为 k。

思路

  • 子数组和 = 两个前缀和之差：nums[j..i] 之和 = prefix(i) - prefix(j-1)，要等于 k 就是问 prefix(i) - k 这个前缀出现过几次。
  • 表 cnt 存每个前缀和的出现次数，先放 0:1（从头开始的子数组）。
  • 扫到每个位置：ans += cnt[prefix - k]，再把当前 prefix 计数 +1；先查后存，k = 0 时才不会把自己也算进去。
  • 有负数也不怕：前缀和不再单调，但哈希查数照样 O(1)。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int subarraySum(int[] nums, int k) {5        // cnt：前缀和 → 出现次数；空前缀 0 先记 1 次6        Map<Integer, Integer> cnt = new HashMap<>();7        cnt.put(0, 1);8        int prefix = 0, ans = 0;9        for (int cur : nums) {10            prefix += cur;11            // 有多少个旧前缀等于 prefix-k，就有多少段和为 k12            ans += cnt.getOrDefault(prefix - k, 0);13            // 当前前缀存进去，给后面的位置查14            cnt.merge(prefix, 1, Integer::sum);15        }16        return ans;17    }18}
题目

给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k的子数组的个数 。

子数组是数组中元素的连续非空序列。

示例 1：

输入：nums = [1,1,1], k = 2
输出：2

示例 2：

输入：nums = [1,2,3], k = 3
输出：2

提示：

  • 1 <= nums.length <= 2 * 104
  • -1000 <= nums[i] <= 1000
  • -107 <= k <= 107
