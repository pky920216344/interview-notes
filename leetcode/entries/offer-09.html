双栈摊还：in 只管入队；out 空了才把 in 整个倒过去，out 的栈顶永远是队首。

思路

  • appendTail 直接压进 in；deleteHead 先保证 out 里有货，再从 out 弹栈顶。
  • out 空了才倒：把 in 逐个弹出压进 out，先进的元素正好翻到 out 栈顶。
  • out 非空时绝不能倒，否则新元素会跑到老元素前面，队首顺序就乱了。
  • 两个栈都空返回 -1；每个元素最多入栈、出栈、倒手各一次，均摊 O(1)。

题目

读者来到图书馆排队借还书，图书管理员使用两个书车来完成整理借还书的任务。书车中的书从下往上叠加存放，图书管理员每次只能拿取书车顶部的书。排队的读者会有两种操作：

  • push(bookID)：把借阅的书籍还到图书馆。
  • pop()：从图书馆中借出书籍。

为了保持图书的顺序，图书管理员每次取出供读者借阅的书籍是 最早 归还到图书馆的书籍。你需要返回 每次读者借出书的值 。

如果没有归还的书可以取出，返回 -1 。

示例 1：

输入：
["BookQueue", "push", "push", "pop"]
[[], [1], [2], []]
输出：[null,null,null,1]
解释：
MyQueue myQueue = new MyQueue();
myQueue.push(1); // queue is: [1]
myQueue.push(2); // queue is: [1, 2] (leftmost is front of the queue)
myQueue.pop(); // return 1, queue is [2]

提示：

  • 1 <= bookID <= 10000
  • 最多会对 push、pop 进行 10000 次调用
