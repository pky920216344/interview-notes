字典序排序后扫一遍：以「上一个保留项 + /」开头的是子文件夹，删；否则保留并成为新的上一个。

思路

  • 排序后父文件夹一定排在所有子文件夹前面；从左往右扫，只维护「上一个保留项」。
  • 当前路径以 上一个保留项 + "/" 开头 ⟹ 是它的子文件夹，删；否则保留并顶替上一个。
  • 关键坑：判断必须带上 /——/ab 不以 /a/ 开头，它不是 /a 的孩子。

1import java.util.*;2 3class Solution {4    public List<String> removeSubfolders(String[] folder) {5        Arrays.sort(folder);                       // 字典序：父文件夹一定排在它的子文件夹前面6        List<String> ans = new ArrayList<>();7        for (String f : folder) {8            // 以「上一个保留项 + /」开头才是它的子文件夹；带上 / 挡住 /ab 冒充 /a 的孩子9            if (ans.isEmpty() || !f.startsWith(ans.get(ans.size() - 1) + "/")) {10                ans.add(f);11            }12        }13        return ans;14    }15}
题目

你是一位系统管理员，手里有一份文件夹列表 folder，你的任务是要删除该列表中的所有 子文件夹，并以 任意顺序 返回剩下的文件夹。

如果文件夹 folder[i] 位于另一个文件夹 folder[j] 下，那么 folder[i] 就是 folder[j] 的 子文件夹 。folder[j] 的子文件夹必须以 folder[j] 开头，后跟一个 "/"。例如，"/a/b" 是 "/a" 的一个子文件夹，但 "/b" 不是 "/a/b/c" 的一个子文件夹。

文件夹的「路径」是由一个或多个按以下格式串联形成的字符串：'/' 后跟一个或者多个小写英文字母。

  • 例如，"/leetcode" 和 "/leetcode/problems" 都是有效的路径，而空字符串和 "/" 不是。

示例 1：

输入：folder = ["/a","/a/b","/c/d","/c/d/e","/c/f"]
输出：["/a","/c/d","/c/f"]
解释："/a/b" 是 "/a" 的子文件夹，而 "/c/d/e" 是 "/c/d" 的子文件夹。

示例 2：

输入：folder = ["/a","/a/b/c","/a/b/d"]
输出：["/a"]
解释：文件夹 "/a/b/c" 和 "/a/b/d" 都会被删除，因为它们都是 "/a" 的子文件夹。

示例 3：

输入: folder = ["/a/b/c","/a/b/ca","/a/b/d"]
输出: ["/a/b/c","/a/b/ca","/a/b/d"]

提示：

  • 1 <= folder.length <= 4 * 104
  • 2 <= folder[i].length <= 100
  • folder[i] 只包含小写字母和 '/'
  • folder[i] 总是以字符 '/' 起始
  • folder 每个元素都是 唯一 的
