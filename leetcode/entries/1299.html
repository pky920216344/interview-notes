1299. 将每个元素替换为右侧最大元素

  • 简单
  • 频度 2
  • 模拟
  • 数组
  • 待提交

从右往左一遍扫：suffix 记右边已见的最大值，先写后更新；末位写 -1。

思路

  • 倒着扫：arr[i] = suffix（右边已见最大），末位时 suffix 还是 -1，正好符合题面。
  • 写完再拿当前值更新 suffix：当前值从此进入「右侧」，它可能成为新的后缀最大。
  • 顺序不能反：先写后更新，才能保证「右侧」不含自己。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] replaceElements(int[] arr) {3        // 从右往左扫：suffix 记「右边已见过的最大值」4        int suffix = -1;5        for (int i = arr.length - 1; i >= 0; i--) {6            int cur = arr[i];7            arr[i] = suffix;                  // 末位 suffix 是 -1，正好是题面要求8            if (cur > suffix) suffix = cur;   // 当前值进入「右侧」，顺手更新后缀最大9        }10        return arr;11    }12}
题目

给你一个数组 arr ，请你将每个元素用它右边最大的元素替换，如果是最后一个元素，用 -1 替换。

完成所有替换操作后，请你返回这个数组。

示例 1：

输入：arr = [17,18,5,4,6,1]
输出：[18,6,6,6,1,-1]
解释：
- 下标 0 的元素 --> 右侧最大元素是下标 1 的元素 (18)
- 下标 1 的元素 --> 右侧最大元素是下标 4 的元素 (6)
- 下标 2 的元素 --> 右侧最大元素是下标 4 的元素 (6)
- 下标 3 的元素 --> 右侧最大元素是下标 4 的元素 (6)
- 下标 4 的元素 --> 右侧最大元素是下标 5 的元素 (1)
- 下标 5 的元素 --> 右侧没有其他元素，替换为 -1

示例 2：

输入：arr = [400]
输出：[-1]
解释：下标0 的元素右侧没有其他元素。

提示：

  • 1 <= arr.length <= 104
  • 1 <= arr[i] <= 105
