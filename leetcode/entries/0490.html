BFS，但结点不是格子而是「停点」：球沿一个方向一口气滚到撞墙才停，停点才入队，问终点是否是可达停点。

思路

  • 普通格子 BFS 不行：球不能停在任意格，只能停在撞墙处。
  • 从停点向四个方向「一口气滚」：while 下一格在界内且为空就继续，停下才是新停点。
  • 停点去重后入队；弹出时等于终点就 true。
  • 终点若只会被路过、从不停靠（或根本到不了），队列耗尽返回 false。

1import java.util.*;2 3class Solution {4    public boolean hasPath(int[][] maze, int[] start, int[] destination) {5        int m = maze.length, n = maze[0].length;6        boolean[][] seen = new boolean[m][n];7        seen[start[0]][start[1]] = true;8        ArrayDeque<int[]> queue = new ArrayDeque<>();9        queue.add(start);10        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};11        while (!queue.isEmpty()) {12            int[] p = queue.poll();13            // 球只在撞墙处停，队列里全是停点；走到终点停点就成了14            if (p[0] == destination[0] && p[1] == destination[1]) return true;15            for (int[] d : dirs) {16                int r = p[0], c = p[1];17                while (open(maze, r + d[0], c + d[1])) {18                    r += d[0];19                    c += d[1];20                }21                if (!seen[r][c]) {22                    seen[r][c] = true;23                    queue.add(new int[]{r, c});24                }25            }26        }27        return false;28    }29 30    // (r, c) 在界内且是空格，球就能滚过去31    private boolean open(int[][] maze, int r, int c) {32        return r >= 0 && r < maze.length && c >= 0 && c < maze[0].length && maze[r][c] == 0;33    }34}
