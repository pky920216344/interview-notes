159. 至多包含两个不同字符的最长子串

  • 未经力扣验证

滑动窗口：右端进字符、计数；种类一超过 2，左端就连吐字符直到回到 2 种，窗口合法时更新答案。

思路

  • 窗口 [left, right] 永远保持「至多 2 种字符」，right 每步右移一格。
  • count[c] 记窗口内字符个数：进窗口时 0→1 说明多了新种类；出窗口时 1→0 说明少了一种。
  • 种类超过 2 就收缩：左端字符计数减一，减到 0 时 distinct--，直到回到 2 种。
  • 每步用 right - left + 1 更新最长长度；窗口长度只会不减，答案不会漏。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int lengthOfLongestSubstringTwoDistinct(String s) {3        // count[c]：窗口里字符 c 的个数；种类超过 2 就从左端收缩4        int[] count = new int[128];5        int distinct = 0, ans = 0, left = 0;6        for (int right = 0; right < s.length(); right++) {7            if (count[s.charAt(right)]++ == 0) distinct++;   // 新字符进窗口8            while (distinct > 2) {                           // 超了：吐出左端字符9                if (--count[s.charAt(left)] == 0) distinct--;10                left++;11            }12            ans = Math.max(ans, right - left + 1);13        }14        return ans;15    }16}
