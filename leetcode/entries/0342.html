342. 4的幂

三连判断：n > 0、n & (n-1) == 0（是 2 的幂）、n & 0x55555555 == n（唯一的 1 位在偶数位）。

思路

  • n & (n - 1) == 0 且 n > 0：只有一个 1 位，说明 n 是 2 的幂。
  • 4 的幂比 2 的幂多一条：那个 1 位必须落在偶数位（2⁰、2²、2⁴…），掩码 0x55555555（二进制 0101…01）正好只保留偶数位。
  • 所以 n & 0x55555555 == n 说明 1 位没被掩码抹掉，即落在偶数位；三条件与起来就是答案。

题目

给定一个整数，写一个函数来判断它是否是 4 的幂次方。如果是，返回 true ；否则，返回 false 。

整数 n 是 4 的幂次方需满足：存在整数 x 使得 n == 4x

示例 1：

输入：n = 16
输出：true

示例 2：

输入：n = 5
输出：false

示例 3：

输入：n = 1
输出：true

提示：

  • -231 <= n <= 231 - 1
