剑指 Offer 11. 库存管理 I

  • 简单
  • 频度 18
  • 二分查找
  • 数组
  • 二分查找
  • 力扣已通过

二分和 hi 比大小：mid > stock[hi] 断点在右半段，< 则在左半段收 hi，相等分不清就 hi--，O(log n)。

思路

  • 旋转数组 = 两段非降序拼成，最小值是右段的头。拿 mid 和 stock[hi] 比（和 hi 比，而不是 lo，因为断点信息在右端）：
  • stock[mid] > stock[hi]：mid 处还在左段，最小值在 (mid, hi] → lo = mid + 1。
  • stock[mid] < stock[hi]：[mid, hi] 整段有序，最小值在 [lo, mid] → hi = mid（mid 本身可能是答案，不能跳过）。
  • stock[mid] == stock[hi]：比如 [3,3,1,3]，分不清断点在左还是右 → hi--：末尾值有 mid 兜底，丢掉不影响答案。这一步最坏把算法拖成 O(n)，其余情况 O(log n)。

最优解

时间复杂度 O(log n)，全相等退化 O(n)，空间复杂度 O(1)
1class Solution {2    public int inventoryManagement(int[] stock) {3        int lo = 0, hi = stock.length - 1;4        while (lo < hi) {5            int mid = lo + (hi - lo) / 2;   // 偏左取中：hi-- 时区间也一定在缩6            if (stock[mid] > stock[hi]) {7                lo = mid + 1;               // mid 比末尾大：断点在 mid 右边，最小值也在那边8            } else if (stock[mid] < stock[hi]) {9                hi = mid;                   // mid 到 hi 是有序段，最小值在 mid 及其左边10            } else {11                hi--;                        // 分不清断点在哪边：末尾这个重复值丢掉也不影响答案12            }13        }14        return stock[lo];15    }16}
题目

仓库管理员以数组 stock 形式记录商品库存表。stock[i] 表示商品 id，可能存在重复。原库存表按商品 id 升序排列。现因突发情况需要进行商品紧急调拨，管理员将这批商品 id 提前依次整理至库存表最后。请你找到并返回库存表中编号的 最小的元素 以便及时记录本次调拨。

示例 1：

输入：stock =[4,5,8,3,4]
输出：3

示例 2：

输入：stock = [5,7,9,1,2]
输出：1

提示：

  • 1 <= stock.length <= 5000
  • -5000 <= stock[i] <= 5000
