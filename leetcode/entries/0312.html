312. 戳气球

  • 频度 13
  • 动态规划
  • 数组
  • 动态规划
  • 待提交

区间 DP + 倒着想：设 k 是区间里最后戳的气球，戳它时邻居是固定的 a[l]、a[r]，两半互不影响可拆开算。

思路

  • 先补两端 1：把边界当值为 1 的气球，dp[l][r] 表示戳空开区间 (l, r) 的最大收益。
  • 关键转换：正着戳邻居会变，没法分治；倒着想——设 k 是 (l,r) 里最后戳的，戳它时左右邻居恰是 a[l] 和 a[r]，且左右两半此前已各自戳空、互不相干。
  • 转移：dp[l][r] = max(dp[l][k] + a[l]*a[k]*a[r] + dp[k][r])，区间按长度从短到长算。
  • 答案是 dp[0][n+1]。

最优解

时间复杂度 O(n^3)，空间复杂度 O(n^2)
1class Solution {2    public int maxCoins(int[] nums) {3        int n = nums.length;4        // 两端补 1：边界气球戳破时按 1 算，区间 DP 就不用判边界了5        int[] a = new int[n + 2];6        a[0] = a[n + 1] = 1;7        for (int i = 0; i < n; i++) a[i + 1] = nums[i];8        // dp[l][r]：把开区间 (l, r) 里的气球全戳空的最大收益（l、r 一直活着）9        int[][] dp = new int[n + 2][n + 2];10        // 区间从短到长算；倒着想：设 k 是 (l,r) 里最后戳的，11        // 戳它时邻居恰是 a[l] 和 a[r]，且两半此前已各自戳空12        for (int len = 2; len <= n + 1; len++) {13            for (int l = 0; l + len <= n + 1; l++) {14                int r = l + len;15                for (int k = l + 1; k < r; k++) {16                    int gain = a[l] * a[k] * a[r] + dp[l][k] + dp[k][r];17                    dp[l][r] = Math.max(dp[l][r], gain);18                }19            }20        }21        return dp[0][n + 1];22    }23}
题目

有 n 个气球，编号为0 到 n - 1，每个气球上都标有一个数字，这些数字存在数组 nums 中。

现在要求你戳破所有的气球。戳破第 i 个气球，你可以获得 nums[i - 1] * nums[i] * nums[i + 1] 枚硬币。 这里的 i - 1 和 i + 1 代表和 i 相邻的两个气球的序号。如果 i - 1或 i + 1 超出了数组的边界，那么就当它是一个数字为 1 的气球。

求所能获得硬币的最大数量。

示例 1： 
输入：nums = [3,1,5,8]
输出：167
解释：
nums = [3,1,5,8] --> [3,5,8] --> [3,8] --> [8] --> []
coins =  3*1*5    +   3*5*8   +  1*3*8  + 1*8*1 = 167

示例 2：

输入：nums = [1,5]
输出：10

提示：

  • n == nums.length
  • 1 <= n <= 300
  • 0 <= nums[i] <= 100
