53. 最大子数组和

Kadane：cur 是以当前数结尾的最大和，前面的和为负就丢掉重来；ans 记下 cur 的最大值。

思路

  • cur 表示「以 nums[i] 结尾的最大子数组和」，ans 记下扫描过程中 cur 出现过的最大值。
  • 转移 cur = max(x, cur + x)：前面的 cur 是负数，接上去只会更小，就丢掉，从 x 重新开始；否则接在后面。
  • cur、ans 都从 nums[0] 起步，循环从下标 1 开始；ans 不能初始化成 0，数组全是负数时答案是负的。
  • 一遍扫完就行，不用记子数组的位置。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxSubArray(int[] nums) {3        // cur：以 nums[i] 结尾的最大子数组和4        int cur = nums[0], ans = nums[0];5        for (int i = 1; i < nums.length; i++) {6            // 前面的和是负的就丢掉，从自己重新开始7            cur = Math.max(nums[i], cur + nums[i]);8            ans = Math.max(ans, cur);9        }10        return ans;11    }12}
题目

给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组 是数组中的一个连续部分。

示例 1：

输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。

示例 2：

输入：nums = [1]
输出：1

示例 3：

输入：nums = [5,4,-1,7,8]
输出：23

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104

进阶：如果你已经实现复杂度为 O(n) 的解法，尝试使用更为精妙的 分治法 求解。
