双指针拉开定距：fast 先走 cnt 步，再与 slow 同速前进，fast 到 null 时 slow 正停在倒数第 cnt 个。

思路

  • fast 先走 cnt 步，从此比 slow 恒领先 cnt 个结点。
  • 然后两个指针同速前进，间距保持不变。
  • fast 走到 null 时，链表尾部还剩 cnt 个结点，slow 就停在倒数第 cnt 个。
  • 只扫一遍，不用先数一遍长度。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public ListNode trainingPlan(ListNode head, int cnt) {3        // fast 先走 cnt 步，和 slow 恒差 cnt 个结点4        ListNode fast = head, slow = head;5        for (int i = 0; i < cnt; i++) fast = fast.next;6        // 再同速前进：fast 到 null 时 slow 就是答案7        while (fast != null) {8            fast = fast.next;9            slow = slow.next;10        }11        return slow;12    }13}
题目

给定一个头节点为 head 的链表用于记录一系列核心肌群训练项目编号，请查找并返回倒数第 cnt 个训练项目编号对应的节点。

示例 1：

输入：head = [2,4,7,8], cnt = 1
输出：8

提示：

  • 1 <= head.length <= 100
  • 0 <= head[i] <= 100
  • 1 <= cnt <= head.length
