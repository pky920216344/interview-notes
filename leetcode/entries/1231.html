1231. 分享巧克力

二分答案「我这块的甜度 x」：贪心从左到右切，攒够 x 就切段，能切出 ≥ k+1 段即可行。

思路

  • 切成 k+1 段（k 个朋友 + 我），我拿最小那段；「最小段 ≥ x」等价于每段都 ≥ x。
  • check(x)：从左往右累加，sum ≥ x 立刻切段（切得越早剩余越多，段数最多）。
  • 段数 ≥ k+1 则 x 可行，二分取最大可行 x；上界 sum/(k+1)（k+1 段每段 ≥ x 需要总和够分）。

最优解

时间复杂度 O(n log sum)，空间复杂度 O(1)
1class Solution {2    public int maximizeSweetness(int[] sweetness, int k) {3        // 二分「我这块的甜度 x」：能切成 ≥ k+1 段、每段 ≥ x 就可行4        int lo = 1, hi = 0;5        for (int s : sweetness) hi += s;6        hi /= (k + 1);7        while (lo < hi) {8            int mid = (lo + hi + 1) / 2;   // 偏右取中，找最大可行 x9            if (count(sweetness, mid) >= k + 1) lo = mid;10            else hi = mid - 1;11        }12        return lo;13    }14 15    /** 贪心：sum 攒够 x 就立刻切段，切得越早，能切出的段数越多。 */16    private int count(int[] a, int x) {17        int cnt = 0, sum = 0;18        for (int s : a) {19            sum += s;20            if (sum >= x) { cnt++; sum = 0; }21        }22        return cnt;23    }24}
