387. 字符串中的第一个唯一字符

两遍扫描：第一遍把每个字母出现几次数进 26 格数组，第二遍从左往右找第一个次数为 1 的下标。

思路

  • 第一遍只数数：cnt[c] 是字母 c 出现的次数，与位置无关。
  • 第二遍按原顺序再扫一遍字符串：第一个 cnt == 1 的字符的下标就是答案。
  • 必须两遍：一遍里无法同时知道「这个字符是不是唯一」和「它是不是最靠前」。
  • 扫完没有就返回 -1。

1class Solution {2    public int firstUniqChar(String s) {3        int n = s.length();4        // 第一遍：数每个字母出现的次数5        int[] cnt = new int[26];6        for (int i = 0; i < n; i++) cnt[s.charAt(i) - 'a']++;7        // 第二遍：从左往右找，第一个只出现 1 次的就是答案8        for (int i = 0; i < n; i++)9            if (cnt[s.charAt(i) - 'a'] == 1) return i;10        return -1;11    }12}
题目

给定一个字符串 s ，找到 它的第一个不重复的字符，并返回它的索引 。如果不存在，则返回 -1 。

示例 1：

输入: s = "leetcode"
输出: 0

示例 2:

输入: s = "loveleetcode"
输出: 2

示例 3:

输入: s = "aabb"
输出: -1

提示:

  • 1 <= s.length <= 105
  • s 只包含小写字母
