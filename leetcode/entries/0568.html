568. 最大休假天数

  • 困难
  • 频度 1
  • 动态规划
  • 数组
  • 动态规划
  • 矩阵
  • 未经力扣验证

逐周 DP：dp[i] = 本周一人在城市 i 的最大累计休假；每周从「留下或任一可达城市」转移。

思路

  • 状态 dp[i]：本周一人在城市 i 时已休的最大天数；-1 表示到不了。初始只有 dp[0] = 0。
  • 每周一二选一：原地不动（i == j 永远可行），或沿 flights[i][j] = 1 的航班飞；转移 ndp[j] = max(dp[i] + days[j][w])。
  • 滚动数组把空间压到 O(n)；答案取最后一周所有城市的最大值（人可以停在任何城市）。

最优解

时间复杂度 O(k·n²)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int maxVacationDays(int[][] flights, int[][] days) {5        int n = flights.length, k = days[0].length;6        // dp[i]：本周一人在城市 i 时，已经休掉的最大天数；-1 表示这个状态到不了7        int[] dp = new int[n];8        Arrays.fill(dp, -1);9        dp[0] = 0;10        for (int w = 0; w < k; w++) {11            int[] ndp = new int[n];12            Arrays.fill(ndp, -1);13            for (int j = 0; j < n; j++) {14                for (int i = 0; i < n; i++) {15                    // 原地不动永远可以；飞往 j 需要 i 到 j 有航班16                    if (dp[i] < 0 || (i != j && flights[i][j] == 0)) continue;17                    int v = dp[i] + days[j][w];18                    if (v > ndp[j]) ndp[j] = v;19                }20            }21            dp = ndp;22        }23        int ans = 0;24        for (int v : dp) ans = Math.max(ans, v);25        return ans;26    }27}
