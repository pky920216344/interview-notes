0 当万能位跳过；其余编号查重后只看跨度：非 0 的 max − min < 5 就能排成连续 5 个。

思路

  • 5 张牌规模恒定，直接一遍扫：0 是万能位，跳过；非 0 编号重复直接 false。
  • 用 seen[] 查重的同时维护非 0 编号的 min、max。
  • 判定只有一条：max − min < 5。跨度小于 5 时，缺的编号（含 0 之外的位置）全可由 0 补上；跨度 ≥ 5 则怎么补都连不成。

最优解

时间复杂度 O(1)（只有 5 张，常数），空间复杂度 O(1)
1class Solution {2    public boolean checkDynasty(int[] places) {3        // 0 是未知朝代，可当任意编号补空；其余编号必须互不重复4        boolean[] seen = new boolean[14];5        int min = 14, max = 0;6        for (int p : places) {7            if (p == 0) continue;         // 万能位：先跳过8            if (seen[p]) return false;    // 非 0 重复，必不连续9            seen[p] = true;10            min = Math.min(min, p);11            max = Math.max(max, p);12        }13        // 非 0 的跨度 < 5：中间空缺全可由 0 补上14        return max - min < 5;15    }16}
题目

展览馆展出来自 13 个朝代的文物，每排展柜展出 5 个文物。某排文物的摆放情况记录于数组 places，其中 places[i] 表示处于第 i 位文物的所属朝代编号。其中，编号为 0 的朝代表示未知朝代。请判断并返回这排文物的所属朝代编号是否能够视为连续的五个朝代（如遇未知朝代可算作连续情况）。

示例 1：

输入：places = [0, 6, 9, 0, 7]
输出：True

示例 2：

输入：places = [7, 8, 9, 10, 11]
输出：True

提示：

  • places.length = 5
  • 0 <= places[i] <= 13
