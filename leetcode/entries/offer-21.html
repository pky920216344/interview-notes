剑指 Offer 21. 训练计划 I

  • 简单
  • 频度 30
  • 双指针
  • 数组
  • 双指针
  • 排序
  • 力扣已通过

首尾双指针原地交换：left 找偶数、right 找奇数，找到一对就交换，两指针相向推进。

思路

  • 剑指原题不要求稳定，直接原地交换就行；& 1 判奇偶。
  • left 从左找偶数、right 从右找奇数：都是「放错位置」的元素，交换后两边各归各位。
  • 交换完 left++、right--，直到两指针相遇；只用一次遍历、零额外空间。
  • 返回的就是原数组 actions，题目只要奇数在偶数前，顺序不唯一。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] trainingPlan(int[] actions) {3        int left = 0, right = actions.length - 1;4        while (left < right) {5            // 左指针停在偶数上6            while (left < right && (actions[left] & 1) == 1) left++;7            // 右指针停在奇数上8            while (left < right && (actions[right] & 1) == 0) right--;9            if (left < right) {                 // 交换：奇数去前面，偶数去后面10                int t = actions[left];11                actions[left] = actions[right];12                actions[right] = t;13                left++;14                right--;15            }16        }17        return actions;18    }19}
题目

教练使用整数数组 actions 记录一系列核心肌群训练项目编号。为增强训练趣味性，需要将所有奇数编号训练项目调整至偶数编号训练项目之前。请将调整后的训练项目编号以 数组 形式返回。

示例 1：

输入：actions = [1,2,3,4,5]
输出：[1,3,5,2,4] 
解释：为正确答案之一

提示：

  • 0 <= actions.length <= 50000
  • 0 <= actions[i] <= 10000
