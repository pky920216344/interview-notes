把值当下标构成隐式链 i → nums[i]，重复数就是环入口；Floyd 快慢指针判圈，相遇后一个回起点同速再走。

思路

  • i → nums[i]：n+1 个下标、值都在 1..n，链上必有环，被指向两次的值正是环入口。
  • 快慢指针：慢的一次 nums[slow]，快的一次 nums[nums[fast]]，直到相遇（一定在环内）。
  • 相遇后把慢的放回起点，两个都改成一次一步，再相遇处就是环入口，直接返回。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int findDuplicate(int[] nums) {3        // 把值当下标：i → nums[i] 是一条隐式链，重复数就是环入口4        int slow = 0, fast = 0;5        // 快的每次走两步，慢的走一步，直到在环内相遇6        do {7            slow = nums[slow];8            fast = nums[nums[fast]];9        } while (slow != fast);10        // 慢的回起点，两个都改成一步一跳，再相遇处就是环入口11        slow = 0;12        while (slow != fast) {13            slow = nums[slow];14            fast = nums[fast];15        }16        return slow;17    }18}
题目

给定一个包含 n + 1 个整数的数组 nums ，其数字都在 [1, n] 范围内（包括 1 和 n），可知至少存在一个重复的整数。

假设 nums 只有 一个重复的整数 ，返回 这个重复的数 。

你设计的解决方案必须 不修改 数组 nums 且只用常量级 O(1) 的额外空间。

示例 1：

输入：nums = [1,3,4,2,2]
输出：2

示例 2：

输入：nums = [3,1,3,4,2]
输出：3

示例 3 :

输入：nums = [3,3,3,3,3]
输出：3

提示：

  • 1 <= n <= 105
  • nums.length == n + 1
  • 1 <= nums[i] <= n
  • nums 中 只有一个整数 出现 两次或多次 ，其余整数均只出现 一次
