1143. 最长公共子序列

  • 中等
  • 频度 203
  • 动态规划
  • 字符串
  • 动态规划
  • longest-common-subsequence
  • 力扣已通过

DP：dp[i][j] 是两个前缀的 LCS 长度；末尾字符相等取左上 + 1，不等取上、左较大值；滚动成一行。

思路

  • dp[i][j]：text1 前 i 个字符与 text2 前 j 个字符的最长公共子序列长度；有一个是空串就是 0。
  • 末尾字符相等：dp[i][j] = dp[i-1][j-1] + 1（左上 + 1）；不相等：dp[i][j] = max(dp[i-1][j], dp[i][j-1])（上、左取较大）。
  • 图解画的是完整二维表，代码把它压成一行：dp[j] 就是当前行，diag 暂存左上角，up 暂存上方；dp[j-1] 是刚算好的左边。
  • LCS 对两个串对称，短串放第二个（递归交换一次），dp 数组只要 min(m, n) + 1 格；答案是 dp[n]。

图解

最优解

时间复杂度 O(mn)，空间复杂度 O(min(m, n))
1class Solution {2    public int longestCommonSubsequence(String text1, String text2) {3        // 短串放第二个，dp 数组就只有 min(m, n) + 1 格4        if (text1.length() < text2.length()) {5            return longestCommonSubsequence(text2, text1);6        }7        int n = text2.length();8        // dp[j]：text1 前 i 个字符和 text2 前 j 个字符的 LCS 长度，i 是当前行9        int[] dp = new int[n + 1];10        for (int i = 1; i <= text1.length(); i++) {11            int diag = 0;         // 左上角 dp[i-1][j-1]12            for (int j = 1; j <= n; j++) {13                int up = dp[j];   // 上方 dp[i-1][j]，被覆盖前先存下14                if (text1.charAt(i - 1) == text2.charAt(j - 1)) dp[j] = diag + 1;15                else dp[j] = Math.max(up, dp[j - 1]);16                diag = up;17            }18        }19        return dp[n];20    }21}
题目

给定两个字符串 text1 和 text2，返回这两个字符串的最长 公共子序列 的长度。如果不存在 公共子序列 ，返回 0 。

一个字符串的 子序列 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

  • 例如，"ace" 是 "abcde" 的子序列，但 "aec" 不是 "abcde" 的子序列。

两个字符串的 公共子序列 是这两个字符串所共同拥有的子序列。

示例 1：

输入：text1 = "abcde", text2 = "ace" 
输出：3  
解释：最长公共子序列是 "ace" ，它的长度为 3 。

示例 2：

输入：text1 = "abc", text2 = "abc"
输出：3
解释：最长公共子序列是 "abc" ，它的长度为 3 。

示例 3：

输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列，返回 0 。

提示：

  • 1 <= text1.length, text2.length <= 1000
  • text1 和 text2 仅由小写英文字符组成。
