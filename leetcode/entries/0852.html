852. 山脉数组的峰顶索引

  • 简单
  • 频度 9
  • 二分查找
  • 数组
  • 二分查找
  • ternary-search
  • 待提交

二分：看 mid 和 mid+1 谁高——还在上坡就去右边找，已经开始下坡就把右边界收到 mid。

思路

  • 山脉数组严格先升后降，峰顶把数组分成上坡、下坡两段，二分判方向。
  • arr[mid] < arr[mid+1]：mid 在上坡段，峰顶在右边，left = mid + 1。
  • 否则 mid 已经在下坡（或是峰顶），right = mid，不能丢掉 mid 本身。
  • 峰顶不可能是 arr[0]、arr[n-1]，范围从 [1, n-2] 起步，不用判边界。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int peakIndexInMountainArray(int[] arr) {3        // 峰顶不在两端，在 [left, right] 里找4        int left = 1, right = arr.length - 2;5        while (left < right) {6            int mid = left + (right - left) / 2;7            if (arr[mid] < arr[mid + 1]) left = mid + 1;   // 在上坡：峰顶在右边8            else right = mid;                              // 在下坡：峰顶是 mid 或在左边9        }10        return left;11    }12}
题目

给定一个长度为 n 的整数 山脉 数组 arr ，其中的值递增到一个 峰值元素 然后递减。

返回峰值元素的下标。

你必须设计并实现时间复杂度为 O(log(n)) 的解决方案。

示例 1：

输入：arr = [0,1,0]
输出：1

示例 2：

输入：arr = [0,2,1,0]
输出：1

示例 3：

输入：arr = [0,10,5,2]
输出：1

提示：

  • 3 <= arr.length <= 105
  • 0 <= arr[i] <= 106
  • 题目数据 保证 arr 是一个山脉数组
