562. 矩阵中最长的连续1线段

  • 中等
  • 频度 1
  • 动态规划
  • 数组
  • 动态规划
  • 矩阵
  • 未经力扣验证

一遍扫矩阵，同时维护四个方向（水平/垂直/↘/↙）「以当前格结尾」的连续 1 长度，取最大。

思路

  • 每格为 1 时：水平接左格、垂直接上格、↘ 接左上、↙ 接右上，各 +1；为 0 则四个方向全归零。
  • 三个方向数组按列存（col/diag/anti），水平只用一个变量 row，每行行首归零。
  • 两个覆盖顺序细节：↘ 的左上在本行已被覆盖，要用先暂存的旧值（prevDiag）；↙ 的右上还没被本行覆盖，直接读就是上一行的值。

最优解

时间复杂度 O(mn)，空间复杂度 O(n)
1class Solution {2    public int longestLine(int[][] mat) {3        int m = mat.length, n = mat[0].length, ans = 0;4        // 一遍扫矩阵，同时维护四个方向「以当前格结尾」的连续 1 长度5        int[] col = new int[n];    // 垂直：来自上一行同列6        int[] diag = new int[n];   // 主对角线 ↘：来自左上7        int[] anti = new int[n];   // 反对角线 ↙：来自右上8        for (int i = 0; i < m; i++) {9            int row = 0, prevDiag = 0;   // prevDiag = 上一行 diag[j-1]（左上的旧值）10            for (int j = 0; j < n; j++) {11                if (mat[i][j] == 1) {12                    row++;13                    col[j]++;14                    // ↘ 接左上：左上在本行已更新，用暂存的旧值15                    int d = prevDiag + 1;16                    // ↙ 接右上：右上还没被本行覆盖，正好是上一行的值17                    int a = (j + 1 < n ? anti[j + 1] : 0) + 1;18                    ans = Math.max(ans, Math.max(Math.max(row, col[j]), Math.max(d, a)));19                    prevDiag = diag[j];   // 旧 diag[j] 留给下一列当左上20                    diag[j] = d;21                    anti[j] = a;22                } else {23                    row = 0;24                    col[j] = 0;25                    prevDiag = diag[j];26                    diag[j] = 0;27                    anti[j] = 0;28                }29            }30        }31        return ans;32    }33}
