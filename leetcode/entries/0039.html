39. 组合总和

  • 中等
  • 频度 96
  • 回溯
  • 数组
  • 回溯
  • 力扣已通过

回溯：候选排序后从 start 起试每个数，同一个数可重复选所以递归传 i；剩余为 0 记录，候选超剩余就剪枝。

思路

  • 先排序：候选从小到大，一旦 candidates[i] > remain，后面的只会更大，直接 break 剪掉整枝。
  • dfs(remain, start)：remain 减到 0 就把 path 存进答案；否则从 start 起试每个候选。
  • 选了 candidates[i] 后递归传 i（不是 i + 1），同一个数才能重复选；start 保证组合不重不漏。
  • 每层递归返回后 path 撤销最后一个数（回溯），换下一个候选继续。

1import java.util.*;2 3class Solution {4    private int[] candidates;5    private final List<List<Integer>> ans = new ArrayList<>();6    private final List<Integer> path = new ArrayList<>();7 8    public List<List<Integer>> combinationSum(int[] candidates, int target) {9        this.candidates = candidates;10        // 每次调用先清空，防上次的结果残留11        ans.clear();12        path.clear();13        // 排序：小数在前，剩余不够时才能提前剪枝14        Arrays.sort(candidates);15        dfs(target, 0);16        return ans;17    }18 19    // remain：还差多少；start：只能从 start 起往后挑20    private void dfs(int remain, int start) {21        if (remain == 0) {22            // 凑够了：把当前组合存进答案23            ans.add(new ArrayList<>(path));24            return;25        }26        for (int i = start; i < candidates.length; i++) {27            // 剩余比候选小，后面只会更大，整枝剪掉28            if (candidates[i] > remain) break;29            path.add(candidates[i]);30            // 传 i 不加 1：同一个数可以接着选31            dfs(remain - candidates[i], i);32            // 回溯：撤销刚才的选择33            path.remove(path.size() - 1);34        }35    }36}
题目

给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target ，找出 candidates 中可以使数字和为目标数 target 的 所有 不同组合 ，并以列表形式返回。你可以按 任意顺序 返回这些组合。

candidates 中的 同一个 数字可以 无限制重复被选取 。如果至少一个数字的被选数量不同，则两种组合是不同的。 

对于给定的输入，保证和为 target 的不同组合数少于 150 个。

示例 1：

输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。

示例 2：

输入: candidates = [2,3,5], target = 8
输出: [[2,2,2,2],[2,3,3],[3,5]]

示例 3：

输入: candidates = [2], target = 1
输出: []

提示：

  • 1 <= candidates.length <= 30
  • 2 <= candidates[i] <= 40
  • candidates 的所有元素 互不相同
  • 1 <= target <= 40
