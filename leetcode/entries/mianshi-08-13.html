按三边升序排序后做线性 DP：dp[i] = 以箱 i 为底的最大高度，从前面所有「三边严格更小」的箱子转移。

思路

  • 先按（宽、深、高）升序排序：能叠到箱 i 上面的箱子一定排在 i 前面，DP 只需回看。
  • dp[i] = box[i][2] + max(dp[j])，其中 j 满足三边严格小于箱 i——三边相等谁也压不住谁。
  • 排序保证「三边严格更小 ⇒ 下标更小」，所以从左到右一遍就算完；答案 = max(dp)。
  • 这是「最长递增子序列」的二维版：把箱子当成可叠的元素序列。

1import java.util.*;2 3class Solution {4    public int pileBox(int[][] box) {5        // 按宽、深、高升序排：能叠在箱 i 上面的箱子，排序后一定在 i 前面6        Arrays.sort(box, (a, b) -> a[0] != b[0] ? a[0] - b[0]7                : (a[1] != b[1] ? a[1] - b[1] : a[2] - b[2]));8        int n = box.length;9        int[] dp = new int[n];   // dp[i]：以箱 i 为底（最下面）的箱堆最大高度10        int ans = 0;11        for (int i = 0; i < n; i++) {12            dp[i] = box[i][2];   // 只有它自己13            for (int j = 0; j < i; j++) {14                // 三边都严格更小才能叠上去；宽相等时谁也压不住谁15                if (box[j][0] < box[i][0] && box[j][1] < box[i][1] && box[j][2] < box[i][2]) {16                    dp[i] = Math.max(dp[i], dp[j] + box[i][2]);17                }18            }19            ans = Math.max(ans, dp[i]);20        }21        return ans;22    }23}
题目

堆箱子。给你一堆n个箱子，箱子宽 wi、深 di、高 hi。箱子不能翻转，将箱子堆起来时，下面箱子的宽度、高度和深度必须大于上面的箱子。实现一种方法，搭出最高的一堆箱子。箱堆的高度为每个箱子高度的总和。

输入使用数组[wi, di, hi]表示每个箱子。

示例 1：

 输入：box = [[1, 1, 1], [2, 2, 2], [3, 3, 3]]
 输出：6

示例 2：

 输入：box = [[1, 1, 1], [2, 3, 4], [2, 6, 7], [3, 4, 5]]
 输出：10

提示:

  1. 箱子的数目不大于3000个。
