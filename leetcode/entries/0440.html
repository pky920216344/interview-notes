440. 字典序的第K小数字

  • 困难
  • 频度 42
  • 字典树
  • 数学
  • 字典树
  • 力扣已通过

十叉树前序计数：算 cur 子树里 ≤n 的个数 steps；steps ≤ k 就整棵子树跳过去右兄弟，否则进孩子层。

思路

  • 把 1..n 看成十叉树（前缀 x 的孩子是 10x..10x+9），字典序就是这棵树的前序遍历。
  • count(cur) 数 cur 子树里 ≤n 的个数：逐层对 [first, min(next, n+1)) 求和，first/next 是同层相邻前缀。
  • 每步二选一：steps ≤ k 就整棵子树跳过（k -= steps; cur++）；否则 cur 自己占一步（k--; cur *= 10）。
  • n 和计数都用 long：cur*10 会超过 int 范围。

最优解

时间复杂度 O(log²n)，空间复杂度 O(1)
1class Solution {2    public int findKthNumber(int n, int k) {3        // 十叉树前序：1..n 按前缀分棵子树；cur 是当前前缀4        long cur = 1;5        k--;   // 1 本身占第 1 步6        while (k > 0) {7            // cur 开头的子树里有 steps 个 ≤ n 的数8            long steps = count(cur, n);9            if (steps <= k) {10                // 整棵子树都排在答案前面：跳过它，去右兄弟11                k -= steps;12                cur++;13            } else {14                // 子树里还有更小的：cur 自己占一步，进入下一层15                cur *= 10;16                k--;17            }18        }19        return (int) cur;20    }21 22    // 以 cur 为前缀且 ≤ n 的数字个数：逐层对 [first, min(next, n+1)) 计数23    private long count(long cur, int n) {24        long total = 0, first = cur, next = cur + 1;25        while (first <= n) {26            total += Math.min(next, (long) n + 1) - first;27            first *= 10;28            next *= 10;29        }30        return total;31    }32}
题目

给定整数 n 和 k，返回  [1, n] 中字典序第 k 小的数字。

示例 1:

输入: n = 13, k = 2
输出: 10
解释: 字典序的排列是 [1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9]，所以第二小的数字是 10。

示例 2:

输入: n = 1, k = 1
输出: 1

提示:

  • 1 <= k <= n <= 109
