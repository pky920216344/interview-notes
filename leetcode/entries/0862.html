862. 和至少为 K 的最短子数组

  • 困难
  • 频度 19
  • 单调栈
  • 前缀和/差分
  • 队列
  • 数组
  • 二分查找
  • 前缀和
  • 滑动窗口
  • 单调队列
  • 堆（优先队列）
  • 力扣已通过

前缀和 + 单调队列：队列存下标且对应 pre 值递增；队头差 ≥ k 就弹出记长度，负数靠队尾保单调。

思路

  • 先算前缀和 pre（用 long，元素可负、和会溢出 int）；子数组和 = pre[i] - pre[j]。
  • 队列存下标，从队头到队尾 pre 值递增；每个 i 依次：弹队头、弹队尾、入队 i。
  • 队头满足 pre[i] - pre[队头] ≥ k：这段够 k，长度 i - 队头 更新答案后弹出（i 再靠右只会更长）。
  • 负数的关键：pre[i] 比队尾还小且更靠后 → 队尾那些更大的下标当左端点永远更差，直接弹出；普通滑窗在这里失效，必须用单调队列。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int shortestSubarray(int[] nums, int k) {3        int n = nums.length;4        long[] pre = new long[n + 1];   // 前缀和：pre[i] = 前 i 个数之和，用 long 防溢出5        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];6        int[] q = new int[n + 1];       // 队列存下标，对应的 pre 值从队头到队尾递增7        int head = 0, tail = 0, ans = n + 1;8        for (int i = 0; i <= n; i++) {9            // 队头凑够 k：这一段够长，弹出并记录长度10            while (head < tail && pre[i] - pre[q[head]] >= k) {11                ans = Math.min(ans, i - q[head++]);12            }13            // 负数让普通滑窗失效：pre[i] 更小还更靠后，队尾更大的下标当左端点只会更差14            while (head < tail && pre[q[tail - 1]] >= pre[i]) {15                tail--;16            }17            q[tail++] = i;18        }19        return ans > n ? -1 : ans;20    }21}
题目

给你一个整数数组 nums 和一个整数 k ，找出 nums 中和至少为 k 的 最短非空子数组 ，并返回该子数组的长度。如果不存在这样的 子数组 ，返回 -1 。

子数组 是数组中 连续 的一部分。

示例 1：

输入：nums = [1], k = 1
输出：1

示例 2：

输入：nums = [1,2], k = 4
输出：-1

示例 3：

输入：nums = [2,-1,2], k = 3
输出：3

提示：

  • 1 <= nums.length <= 105
  • -105 <= nums[i] <= 105
  • 1 <= k <= 109
