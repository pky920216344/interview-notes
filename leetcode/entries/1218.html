哈希 DP：dp[x] 记以值 x 结尾的最长定差子序列长度，扫一遍数组，每个数接在 x−difference 的链尾。

思路

  • 按 arr 顺序扫，dp[x] = 以值 x 结尾的最长链长；新来的 x 接在 dp[x−difference] 后面。
  • 更新取 max(旧 dp[x], dp[x−difference]+1)：同一个值会反复出现，更晚的出现不一定更长（如 1,3,5,3,7）。
  • 答案是过程中的最大 dp 值；difference 为 0 或负数时写法不变。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int longestSubsequence(int[] arr, int difference) {5        // dp[x]：以值 x 结尾的最长定差子序列长度6        Map<Integer, Integer> dp = new HashMap<>();7        int ans = 0;8        for (int x : arr) {9            // 接在 x−difference 那条链的后面10            int len = dp.getOrDefault(x - difference, 0) + 1;11            // 同值再现时保留历史最长：更晚的出现不一定更长12            dp.put(x, Math.max(len, dp.getOrDefault(x, 0)));13            ans = Math.max(ans, len);14        }15        return ans;16    }17}
题目

给你一个整数数组 arr 和一个整数 difference，请你找出并返回 arr 中最长等差子序列的长度，该子序列中相邻元素之间的差等于 difference 。

子序列 是指在不改变其余元素顺序的情况下，通过删除一些元素或不删除任何元素而从 arr 派生出来的序列。

示例 1：

输入：arr = [1,2,3,4], difference = 1
输出：4
解释：最长的等差子序列是 [1,2,3,4]。

示例 2：

输入：arr = [1,3,5,7], difference = 1
输出：1
解释：最长的等差子序列是任意单个元素。

示例 3：

输入：arr = [1,5,7,8,5,3,4,2,1], difference = -2
输出：4
解释：最长的等差子序列是 [7,5,3,1]。

提示：

  • 1 <= arr.length <= 105
  • -104 <= arr[i], difference <= 104
