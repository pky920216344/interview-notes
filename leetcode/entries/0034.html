34. 在排序数组中查找元素的第一个和最后一个位置

  • 中等
  • 频度 104
  • 二分查找
  • 数组
  • 二分查找
  • 力扣已通过

两次二分：lowerBound 找「第一个 ≥ target」，upperBound 找「第一个 > target」，后者减一就是结束位置。

思路

  • 找左端点：二分出第一个 >= target 的下标 lo；lo 越界或 nums[lo] != target 说明根本不存在，返回 [-1,-1]。
  • 找右端点：再二分出第一个 > target 的下标，- 1 就是最后一个 target。
  • 两个二分都是左闭右开 [left, right)，right 从 n 开始；nums[mid] 不够就 left = mid + 1，否则 right = mid。
  • 两趟唯一区别是 < 还是 <=：把等于的留在区间里，lowerBound 就停在第一个等值处。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int[] searchRange(int[] nums, int target) {3        // 第一趟：找第一个 >= target 的下标4        int lo = lowerBound(nums, target);5        // 越界或该位置不是 target：数组里没有6        if (lo == nums.length || nums[lo] != target) {7            return new int[]{-1, -1};8        }9        // 第二趟：第一个 > target 的下标减一，就是结束位置10        return new int[]{lo, upperBound(nums, target) - 1};11    }12 13    // 第一个 >= target 的下标14    private int lowerBound(int[] nums, int target) {15        // 左闭右开 [left, right)，right 从 n 开始16        int left = 0, right = nums.length;17        while (left < right) {18            int mid = left + (right - left) / 2;19            if (nums[mid] < target) left = mid + 1;20            // nums[mid] >= target：mid 可能就是答案21            else right = mid;22        }23        return left;24    }25 26    // 第一个 > target 的下标27    private int upperBound(int[] nums, int target) {28        int left = 0, right = nums.length;29        while (left < right) {30            int mid = left + (right - left) / 2;31            if (nums[mid] <= target) left = mid + 1;32            // nums[mid] > target：mid 可能就是答案33            else right = mid;34        }35        return left;36    }37}
题目

给你一个按照非递减顺序排列的整数数组 nums，和一个目标值 target。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 target，返回 [-1, -1]。

你必须设计并实现时间复杂度为 O(log n) 的算法解决此问题。

示例 1：

输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]

示例 2：

输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]

示例 3：

输入：nums = [], target = 0
输出：[-1,-1]

提示：

  • 0 <= nums.length <= 105
  • -109 <= nums[i] <= 109
  • nums 是一个非递减数组
  • -109 <= target <= 109
