1087. 花括号展开

从左往右扫，维护「当前所有已生成的串」：字母全员接尾，花括号段排序去重后做笛卡尔积，最后整体排序。

思路

  • 逐段处理：遇到字母，池里每串尾部追加它；遇到 {…}，把分支排序去重后与池中每串做笛卡尔积。
  • 分支先排序再展开，池内顺序天然保持字典序；结尾再整体 sort 兜底。
  • 题面保证无嵌套花括号，indexOf('}') 找配对即可；输出规模受题面约束不会爆炸。

最优解

时间复杂度 O(输出规模)，空间复杂度 O(输出规模)
1import java.util.*;2 3class Solution {4    public String[] expand(String s) {5        List<String> cur = new ArrayList<>();6        cur.add("");7        int i = 0;8        // 从左往右扫：字母直接接尾；花括号段排序去重后，让已有串各自乘上每个分支9        while (i < s.length()) {10            char c = s.charAt(i);11            if (c == '{') {12                int j = s.indexOf('}', i);   // 题面保证无嵌套，直接找配对右括号13                String[] raw = s.substring(i + 1, j).split(",");14                Arrays.sort(raw);15                List<String> next = new ArrayList<>();16                for (String pre : cur)17                    for (int k = 0; k < raw.length; k++) {18                        if (k > 0 && raw[k].equals(raw[k - 1])) continue;   // 重复分支去重19                        next.add(pre + raw[k]);20                    }21                cur = next;22                i = j + 1;23            } else {24                for (int k = 0; k < cur.size(); k++) cur.set(k, cur.get(k) + c);25                i++;26            }27        }28        Collections.sort(cur);29        return cur.toArray(new String[0]);30    }31}
