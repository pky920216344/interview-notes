136. 只出现一次的数字

  • 简单
  • 频度 53
  • 位运算
  • 位运算
  • 数组
  • 力扣已通过

全体异或一遍：x^x=0 且异或与顺序无关，成对的数全部抵消，剩下只出现一次的那个。

思路

  • 异或的性质：x^x=0、x^0=x，且交换、结合任意顺序结果不变。
  • 把所有数都异或进 ans：出现两次的互相抵消，最后只剩出现一次的。
  • 一遍扫描、一个变量，不用哈希表也不用排序。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int singleNumber(int[] nums) {3        // 异或：x^x=0，成对的数互相抵消，剩下只出现一次的那个4        int ans = 0;5        for (int x : nums) ans ^= x;6        return ans;7    }8}
题目

给你一个 非空 整数数组 nums ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

示例 1 ：

输入：nums = [2,2,1]

输出：1

示例 2 ：

输入：nums = [4,1,2,1,2]

输出：4

示例 3 ：

输入：nums = [1]

输出：1

提示：

  • 1 <= nums.length <= 3 * 104
  • -3 * 104 <= nums[i] <= 3 * 104
  • 除了某个元素只出现一次以外，其余每个元素均出现两次。
