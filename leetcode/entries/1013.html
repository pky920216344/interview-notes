1013. 将数组分成和相等的三个部分

  • 简单
  • 频度 8
  • 双指针
  • 贪心
  • 数组
  • 待提交

总和须是 3 的倍数；从两端各找最短的和为 third 的前缀、后缀，中间剩下的天然也是 third，只需中间非空。

思路

  • total % 3 != 0 直接 false；否则 third = total / 3。
  • 左指针找最短的和为 third 的前缀，右指针找最短的和为 third 的后缀——有解时二者必落在合法左段、右段之内。
  • 中间段 arr[i..j] 的和 = total − 2·third = third 自动成立，所以只需判 i ≤ j（中间至少剩一个元素）。
  • 全 0 数组：third = 0，两端各 1 个元素即命中，i ≤ j 自然满足，不用特判。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean canThreePartsEqualSum(int[] arr) {3        int n = arr.length, total = 0;4        for (int v : arr) total += v;5        // 总和不是 3 的倍数必不行；third 是每段该有的和6        if (total % 3 != 0) return false;7        int third = total / 3;8        // 左段：从左找最短的和为 third 的前缀（至少一个元素）9        int i = 1, s = arr[0];10        while (i < n && s != third) s += arr[i++];11        // 右段：从右找最短的和为 third 的后缀（至少一个元素）12        int j = n - 2, t = arr[n - 1];13        while (j >= 0 && t != third) t += arr[j--];14        // 中间 arr[i..j] 的和必为 total-2*third=third，只需至少剩一个元素15        return i <= j;16    }17}
题目

给你一个整数数组 arr，只有可以将其划分为三个和相等的 非空 部分时才返回 true，否则返回 false。

形式上，如果可以找出索引 i + 1 < j 且满足 (arr[0] + arr[1] + ... + arr[i] == arr[i + 1] + arr[i + 2] + ... + arr[j - 1] == arr[j] + arr[j + 1] + ... + arr[arr.length - 1]) 就可以将数组三等分。

示例 1：

输入：arr = [0,2,1,-6,6,-7,9,1,2,0,1]
输出：true
解释：0 + 2 + 1 = -6 + 6 - 7 + 9 + 1 = 2 + 0 + 1

示例 2：

输入：arr = [0,2,1,-6,6,7,9,-1,2,0,1]
输出：false

示例 3：

输入：arr = [3,3,6,5,-2,2,5,1,-9,4]
输出：true
解释：3 + 3 = 6 = 5 - 2 + 2 + 5 + 1 - 9 + 4

提示：

  • 3 <= arr.length <= 5 * 104
  • -104 <= arr[i] <= 104
