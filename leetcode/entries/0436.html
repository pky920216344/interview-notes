436. 寻找右区间

  • 中等
  • 频度 1
  • 二分查找
  • 数组
  • 二分查找
  • 排序
  • 待提交

把每个 start 连同原下标排序；对每个区间的 end 二分找「第一个 ≥ end 的 start」，取它的原下标。

思路

  • 右区间只由 start 决定：把 {start, 原下标} 按 start 升序排好，问题变成「在有序数组里找第一个 ≥ end 的位置」。
  • 二分 [lo, hi) 半开区间：sorted[mid][0] < end 说明太小，lo = mid + 1；否则 hi = mid 收左边界。
  • lo == n 说明所有 start 都 < end，没有右区间记 -1；否则答案就是 sorted[lo][1] 里的原下标。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] findRightInterval(int[][] intervals) {5        int n = intervals.length;6        int[][] sorted = new int[n][];   // 元素是 {start, 原下标}，按 start 升序7        for (int i = 0; i < n; i++) sorted[i] = new int[]{intervals[i][0], i};8        Arrays.sort(sorted, (a, b) -> a[0] - b[0]);9        int[] ans = new int[n];10        for (int i = 0; i < n; i++) {11            // 二分找第一个 >= end 的 start（start 互不相同，结果唯一）12            int lo = 0, hi = n;13            while (lo < hi) {14                int mid = (lo + hi) >>> 1;15                if (sorted[mid][0] < intervals[i][1]) lo = mid + 1;   // start 太小，往右找16                else hi = mid;                                        // 够大了，试着再往左收17            }18            ans[i] = lo == n ? -1 : sorted[lo][1];   // 落到 n 说明没有右区间19        }20        return ans;21    }22}
题目

给你一个区间数组 intervals ，其中 intervals[i] = [starti, endi] ，且每个 starti 都 不同 。

区间 i 的 右侧区间 是满足 startj >= endi，且 startj 最小 的区间 j。注意 i 可能等于 j 。

返回一个由每个区间 i 对应的 右侧区间 下标组成的数组。如果某个区间 i 不存在对应的 右侧区间 ，则下标 i 处的值设为 -1 。

 

示例 1：

输入：intervals = [[1,2]]
输出：[-1]
解释：集合中只有一个区间，所以输出-1。

示例 2：

输入：intervals = [[3,4],[2,3],[1,2]]
输出：[-1,0,1]
解释：对于 [3,4] ，没有满足条件的“右侧”区间。
对于 [2,3] ，区间[3,4]具有最小的“右”起点;
对于 [1,2] ，区间[2,3]具有最小的“右”起点。

示例 3：

输入：intervals = [[1,4],[2,3],[3,4]]
输出：[-1,2,-1]
解释：对于区间 [1,4] 和 [3,4] ，没有满足条件的“右侧”区间。
对于 [2,3] ，区间 [3,4] 有最小的“右”起点。

提示：

  • 1 <= intervals.length <= 2 * 104
  • intervals[i].length == 2
  • -106 <= starti <= endi <= 106
  • 每个间隔的起点都 不相同
