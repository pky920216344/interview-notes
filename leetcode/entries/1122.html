计数排序变体：cnt 数好 arr1 每个值的出现次数，先按 arr2 顺序倾倒，剩下的值升序接到尾部。

思路

  • cnt[v] 数出 arr1 每个值的出现次数，值域只有 0~1000，直接开数组。
  • 第一遍沿 arr2 走：值 x 有几个就连续写几个，写完把 cnt[x] 清零，防止第二遍再出现。
  • 第二遍从 0 到 1000 扫 cnt，没被 arr2 点名的值天然按升序接到尾部。
  • 全程原地写回 arr1，不用额外结果数组。

时间复杂度 O(n + 1000)，空间复杂度 O(1000)
1class Solution {2    public int[] relativeSortArray(int[] arr1, int[] arr2) {3        // cnt[v]：值 v 在 arr1 里出现了几次（值域 0~1000）4        int[] cnt = new int[1001];5        for (int x : arr1) cnt[x]++;6        int i = 0;7        // 第一遍：按 arr2 的顺序，把每种元素连续倾倒出去8        for (int x : arr2) {9            for (int t = 0; t < cnt[x]; t++) arr1[i++] = x;10            cnt[x] = 0;11        }12        // 第二遍：没被点名的值，从小到大接到尾部13        for (int x = 0; x <= 1000; x++)14            for (int t = 0; t < cnt[x]; t++) arr1[i++] = x;15        return arr1;16    }17}
题目

给你两个数组，arr1 和 arr2，arr2 中的元素各不相同，arr2 中的每个元素都出现在 arr1 中。

对 arr1 中的元素进行排序，使 arr1 中项的相对顺序和 arr2 中的相对顺序相同。未在 arr2 中出现过的元素需要按照升序放在 arr1 的末尾。

示例 1：

输入：arr1 = [2,3,1,3,2,4,6,7,9,2,19], arr2 = [2,1,4,3,9,6]
输出：[2,2,2,1,4,3,3,9,6,7,19]

示例  2:

输入：arr1 = [28,6,22,8,44,17], arr2 = [22,28,8,6]
输出：[22,28,8,6,17,44]

提示：

  • 1 <= arr1.length, arr2.length <= 1000
  • 0 <= arr1[i], arr2[i] <= 1000
  • arr2 中的元素 arr2[i]  各不相同 
  • arr2 中的每个元素 arr2[i] 都出现在 arr1 中
