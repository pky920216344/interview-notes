回溯枚举全部子序列：长度 ≥ 2 且非递减就收录；每层用哈希集合挡住重复值去重。

思路

  • 每个下标二选一（选 / 不选）：进入 dfs 先看收录——路径长度 ≥ 2 就拷贝一份进答案。
  • 只能选 nums[i] ≥ 路径末尾 的值，保证子序列非递减。
  • 去重是关键：每层局部开一个 used 集合，同一层某个值试过就跳过；同值同层只走第一条分支，重复子序列就全被挡住了（不能靠全局 visited，那会把不同层的同值也误杀）。

1import java.util.*;2 3class Solution {4    public List<List<Integer>> findSubsequences(int[] nums) {5        List<List<Integer>> ans = new ArrayList<>();6        dfs(nums, 0, new ArrayList<>(), ans);7        return ans;8    }9 10    private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> ans) {11        // 进入本层先收录：长度到 2 的前缀本身就是答案12        if (path.size() >= 2) ans.add(new ArrayList<>(path));13        // used：本层试过的值；同层同值只走第一条分支，天然去重14        Set<Integer> used = new HashSet<>();15        for (int i = start; i < nums.length; i++) {16            if (used.contains(nums[i])) continue;17            if (!path.isEmpty() && nums[i] < path.get(path.size() - 1)) continue;18            used.add(nums[i]);19            path.add(nums[i]);20            dfs(nums, i + 1, path, ans);21            path.remove(path.size() - 1);22        }23    }24}
题目

给你一个整数数组 nums ，找出并返回所有该数组中不同的递增子序列，递增子序列中 至少有两个元素 。你可以按 任意顺序 返回答案。

数组中可能含有重复元素，如出现两个整数相等，也可以视作递增序列的一种特殊情况。

示例 1：

输入：nums = [4,6,7,7]
输出：[[4,6],[4,6,7],[4,6,7,7],[4,7],[4,7,7],[6,7],[6,7,7],[7,7]]

示例 2：

输入：nums = [4,4,3,2,1]
输出：[[4,4]]

提示：

  • 1 <= nums.length <= 15
  • -100 <= nums[i] <= 100
