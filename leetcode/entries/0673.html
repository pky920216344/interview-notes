673. 最长递增子序列的个数

  • 中等
  • 频度 28
  • 动态规划
  • 树状数组
  • 线段树
  • 数组
  • 动态规划
  • longest-increasing-subsequence
  • 力扣已通过

双数组 O(n²) DP：len[i] 是以 i 结尾的最长递增子序列长度，cnt[i] 是它有几个；等长转移要累加而不是覆盖。

思路

  • len[i]、cnt[i]：以 i 结尾的最长递增子序列长度和个数；初值都是 1（自己单独成序列）。
  • 转移看所有 j < i 且 nums[j] < nums[i]：len[j]+1 更长就覆盖（len、cnt 都换成 j 的）；正好等长就累加 cnt[i] += cnt[j]。
  • 全局：len[i] > best 时 best、ans 换新；len[i] == best 时 ans += cnt[i]。
  • n ≤ 2000，O(n²) 足够；等长累加是最容易漏的一步。

最优解

时间复杂度 O(n²)，空间复杂度 O(n)
1class Solution {2    public int findNumberOfLIS(int[] nums) {3        int n = nums.length;4        int[] len = new int[n];   // len[i]：以 i 结尾的最长递增子序列长度5        int[] cnt = new int[n];   // cnt[i]：这样的子序列有几个6        int best = 0, ans = 0;7        for (int i = 0; i < n; i++) {8            len[i] = 1;9            cnt[i] = 1;10            for (int j = 0; j < i; j++) {11                if (nums[j] >= nums[i]) continue;    // 只能接在比 nums[i] 小的后面12                if (len[j] + 1 > len[i]) {           // 更长：长度覆盖，个数继承13                    len[i] = len[j] + 1;14                    cnt[i] = cnt[j];15                } else if (len[j] + 1 == len[i]) {   // 等长：个数累加16                    cnt[i] += cnt[j];17                }18            }19            if (len[i] > best) { best = len[i]; ans = cnt[i]; }20            else if (len[i] == best) ans += cnt[i];  // 全局最长并列就累加21        }22        return ans;23    }24}
题目

给定一个未排序的整数数组 nums ， 返回最长递增子序列的个数 。

注意 这个数列必须是 严格 递增的。

示例 1:

输入: [1,3,5,4,7]
输出: 2
解释: 有两个最长递增子序列，分别是 [1, 3, 4, 7] 和[1, 3, 5, 7]。

示例 2:

输入: [2,2,2,2,2]
输出: 5
解释: 最长递增子序列的长度是1，并且存在5个子序列的长度为1，因此输出5。

提示: 

  • 1 <= nums.length <= 2000
  • -106 <= nums[i] <= 106
