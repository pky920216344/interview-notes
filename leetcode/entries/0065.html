65. 有效数字

  • 字符串
  • 待提交

按 e/E 把串切成「主体 + 指数」：e 至多一个，主体是合法小数（或整数），指数必须是整数。

思路

  • 先扫一遍定位 e/E：出现第二个直接非法；e 后面可以是空串，交给整数检查判否。
  • 主体检查：可选 +/-，然后数字与小数点混写——小数点至多一个、数字至少一位（排除 "."、"+."）。
  • 指数检查：可选 +/- 后全是数字且至少一位，1e、1e+ 都在这里被拦下。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean isNumber(String s) {3        // 按 e/E 切成「主体 + 指数」：e 至多一个，主体是小数，指数必须是整数4        int e = -1;5        for (int i = 0; i < s.length(); i++) {6            char c = s.charAt(i);7            if (c == 'e' || c == 'E') {8                if (e >= 0) return false;   // 第二个 e 直接非法9                e = i;10            }11        }12        if (!isDecimal(e < 0 ? s : s.substring(0, e))) return false;13        return e < 0 || isInt(s.substring(e + 1));14    }15 16    /** 小数：可选符号，数字和小数点混写，但小数点至多一个、数字至少一位。 */17    private boolean isDecimal(String t) {18        int i = 0;19        if (i < t.length() && (t.charAt(i) == '+' || t.charAt(i) == '-')) i++;20        boolean dot = false, digit = false;21        for (; i < t.length(); i++) {22            char c = t.charAt(i);23            if (c == '.') {24                if (dot) return false;25                dot = true;26            } else if (c >= '0' && c <= '9') digit = true;27            else return false;28        }29        return digit;30    }31 32    /** 整数：可选符号后全是数字，至少一位。 */33    private boolean isInt(String t) {34        int i = 0;35        if (i < t.length() && (t.charAt(i) == '+' || t.charAt(i) == '-')) i++;36        if (i == t.length()) return false;37        for (; i < t.length(); i++) if (t.charAt(i) < '0' || t.charAt(i) > '9') return false;38        return true;39    }40}
题目

给定一个字符串 s ，返回 s 是否是一个 有效数字。

例如，下面的都是有效数字："2", "0089", "-0.1", "+3.14", "4.", "-.9", "2e10", "-90E3", "3e+7", "+6e-1", "53.5e93", "-123.456e789"，而接下来的不是："abc", "1a", "1e", "e3", "99e2.5", "--6", "-+3", "95a54e53"。

一般的，一个 有效数字 可以用以下的规则之一定义：

  1. 一个 整数 后面跟着一个 可选指数。
  2. 一个 小数 后面跟着一个 可选指数。

一个 整数 定义为一个 可选符号 '-' 或 '+' 后面跟着 数字。

一个 小数 定义为一个 可选符号 '-' 或 '+' 后面跟着下述规则：

  1. 数字 后跟着一个 小数点 .。
  2. 数字 后跟着一个 小数点 . 再跟着 数位。
  3. 一个 小数点 . 后跟着 数位。

指数 定义为指数符号 'e' 或 'E'，后面跟着一个 整数。

数字 定义为一个或多个数位。

示例 1：

输入：s = "0"

输出：true

示例 2：

输入：s = "e"

输出：false

示例 3：

输入：s = "."

输出：false

提示：

  • 1 <= s.length <= 20
  • s 仅含英文字母（大写和小写），数字（0-9），加号 '+' ，减号 '-' ，或者点 '.' 。
