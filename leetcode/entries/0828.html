828. 统计子串中的唯一字符

  • 困难
  • 频度 1
  • 数学
  • 哈希表
  • 字符串
  • 动态规划
  • 待提交

贡献法：不枚举子串，改成数每个字符的每次出现在多少个子串里是唯一的，乘起来直接累加。

思路

  • 答案 = Σ 子串的唯一字符数 = Σ 「(子串, 字符) 且该字符在子串里只出现一次」的对数。
  • 位置 i 的字符 c 作为唯一字符：起点必须在它上次出现之后（i - prev 种），终点必须在它下次出现之前（next - i 种），贡献 (i - prev) × (next - i)。
  • 没出现过的边界用 -1 / n 兜底；两次线性扫预出每个位置的 prev、next。
  • 乘积最大约 10^10，累加用 long，题目保证结果在 int 内。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int uniqueLetterString(String s) {5        int n = s.length();6        // 贡献法：位置 i 的字符在 (i − prev) × (next − i) 个子串里是唯一字符7        // prev / next 是它上一次 / 下一次出现的位置（没有就是 -1 / n）8        int[] prev = new int[n], next = new int[n], seen = new int[26];9        Arrays.fill(seen, -1);10        for (int i = 0; i < n; i++) {          // 左→右扫出每个位置的上次出现11            prev[i] = seen[s.charAt(i) - 'A'];12            seen[s.charAt(i) - 'A'] = i;13        }14        Arrays.fill(seen, n);15        for (int i = n - 1; i >= 0; i--) {     // 右→左扫出每个位置的下次出现16            next[i] = seen[s.charAt(i) - 'A'];17            seen[s.charAt(i) - 'A'] = i;18        }19        long ans = 0;                          // 乘积最大约 1e10，必须 long 累加20        for (int i = 0; i < n; i++) ans += (long) (i - prev[i]) * (next[i] - i);21        return (int) ans;22    }23}
题目

我们定义了一个函数 countUniqueChars(s) 来统计字符串 s 中的唯一字符，并返回唯一字符的个数。

例如：s = "LEETCODE" ，则其中 "L", "T","C","O","D" 都是唯一字符，因为它们只出现一次，所以 countUniqueChars(s) = 5 。

本题将会给你一个字符串 s ，我们需要返回 countUniqueChars(t) 的总和，其中 t 是 s 的子字符串。输入用例保证返回值为 32 位整数。

注意，某些子字符串可能是重复的，但你统计时也必须算上这些重复的子字符串（也就是说，你必须统计 s 的所有子字符串中的唯一字符）。

示例 1：

输入: s = "ABC"
输出: 10
解释: 所有可能的子串为："A","B","C","AB","BC" 和 "ABC"。
     其中，每一个子串都由独特字符构成。
     所以其长度总和为：1 + 1 + 1 + 2 + 2 + 3 = 10

示例 2：

输入: s = "ABA"
输出: 8
解释: 除了 countUniqueChars("ABA") = 1 之外，其余与示例 1 相同。

示例 3：

输入：s = "LEETCODE"
输出：92

提示：

  • 1 <= s.length <= 105
  • s 只包含大写英文字符
