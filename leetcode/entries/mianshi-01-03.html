面试题 01.03. URL化

  • 简单
  • 频度 1
  • 双指针
  • 字符串
  • 待提交

先数空格算出替换后长度，再从真实尾、新尾两个指针从后往前原地填：空格写 %20，其他照搬。

思路

  • 每个空格从 1 个字符变 3 个，多占 2 格：新长度 = length + 空格数 × 2，尾部缓冲题面保证够。
  • write 从新长度末尾出发，i 从真实内容末尾出发，都往左走：普通字符直接搬，空格连写 '0' '2' '%'。
  • 从后往前填是关键：新尾永远在真实尾右边（或重合），不会覆盖还没处理的字符。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)（原地，不算返回值）
1class Solution {2    public String replaceSpaces(String S, int length) {3        char[] a = S.toCharArray();4        int spaces = 0;5        for (int i = 0; i < length; i++) {6            if (a[i] == ' ') spaces++;7        }8        // 每个空格从 1 个字符变成 3 个，多占 2 格；从真实尾往新尾从后往前填，不会覆盖未处理的字符9        int write = length + spaces * 2;10        for (int i = length - 1; i >= 0; i--) {11            if (a[i] == ' ') {12                a[--write] = '0';13                a[--write] = '2';14                a[--write] = '%';15            } else {16                a[--write] = a[i];17            }18        }19        return new String(a, 0, length + spaces * 2);20    }21}
题目

URL化。编写一种方法，将字符串中的空格全部替换为%20。假定该字符串尾部有足够的空间存放新增字符，并且知道字符串的“真实”长度。（注：用Java实现的话，请使用字符数组实现，以便直接在数组上操作。）

示例 1：

输入："Mr John Smith    ", 13
输出："Mr%20John%20Smith"

示例 2：

输入："               ", 5
输出："%20%20%20%20%20"

提示：

  • 字符串长度在 [0, 500000] 范围内。
