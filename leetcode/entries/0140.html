回溯 + 记忆化：从 i 出发把「i 之后的所有拆法」缓存下来；拆不出的下标缓存空列表，再路过直接剪掉。

思路

  • dfs(i) 返回 s[i..] 的全部拆法：枚举词头 s[i..j)，在词典里就递归 dfs(j)，把返回的每种拆法拼上当前词。
  • 终点 i == n 返回 [""] 占位，上层拼接时不用特判「刚好切完」。
  • 失败也要缓存：memo[i] 是空列表表示「从 i 拆不出」，和「还没算」（get 返回 null）区分开，第二次走到直接剪。
  • 同一后缀的拆法被多条路径共享，重复子问题只算一次；结果顺序不限，输出时排序。

最优解

时间复杂度 O(2^n)（输出本身可达指数级），空间复杂度 O(n²) 级缓存
1import java.util.*;2 3class Solution {4    public List<String> wordBreak(String s, List<String> wordDict) {5        Set<String> dict = new HashSet<>(wordDict);6        // memo[i]：s[i..] 的全部拆法；没算过是 null，算过但拆不出是空列表，下次直接剪掉7        Map<Integer, List<String>> memo = new HashMap<>();8        return dfs(s, 0, dict, memo);9    }10 11    // 从 i 开始把剩余部分拆完的所有句子12    private List<String> dfs(String s, int i, Set<String> dict, Map<Integer, List<String>> memo) {13        List<String> cached = memo.get(i);14        if (cached != null) return cached;15        List<String> res = new ArrayList<>();16        if (i == s.length()) {17            res.add("");   // 空句子占位：上层拼接时不用特判18        } else {19            for (int j = i + 1; j <= s.length(); j++) {20                String word = s.substring(i, j);21                if (!dict.contains(word)) continue;22                for (String rest : dfs(s, j, dict, memo)) {23                    res.add(rest.isEmpty() ? word : word + " " + rest);24                }25            }26        }27        memo.put(i, res);28        return res;29    }30}
题目

给定一个字符串 s 和一个字符串字典 wordDict ，在字符串 s 中增加空格来构建一个句子，使得句子中所有的单词都在词典中。以任意顺序 返回所有这些可能的句子。

注意：词典中的同一个单词可能在分段中被重复使用多次。

示例 1：

输入:s = "catsanddog", wordDict = ["cat","cats","and","sand","dog"]
输出:["cats and dog","cat sand dog"]

示例 2：

输入:s = "pineapplepenapple", wordDict = ["apple","pen","applepen","pine","pineapple"]
输出:["pine apple pen apple","pineapple pen apple","pine applepen apple"]
解释: 注意你可以重复使用字典中的单词。

示例 3：

输入:s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
输出:[]

提示：

  • 1 <= s.length <= 20
  • 1 <= wordDict.length <= 1000
  • 1 <= wordDict[i].length <= 10
  • s 和 wordDict[i] 仅有小写英文字母组成
  • wordDict 中所有字符串都 不同
