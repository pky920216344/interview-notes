386. 字典序排数

  • 中等

  • 深度优先搜索
  • 字典树
  • 待提交

十叉树先序遍历：1~9 出发，孩子 = cur×10 + d（≤ n 才递归），访问顺序就是字典序。

思路

  • 把 [1, n] 看成一棵十叉树：结点 cur 的孩子是 cur*10 + 0..9；先序遍历（先父后子、兄弟从小到大）正好是字典序。
  • 外层对 1..9 各做一次 DFS；start > n 的直接跳过。
  • 递归里先 ans.add(cur) 再下探；孩子 cur*10 + d 一旦 > n 直接 return——后面的 d 更大，整枝剪掉。
  • 递归深度就是数字位数（n ≤ 5×10⁴ 时 ≤ 5 层），额外空间可视为 O(1)。

1import java.util.*;2 3class Solution {4    public List<Integer> lexicalOrder(int n) {5        List<Integer> ans = new ArrayList<>();6        // 十叉树先序遍历：1~9 各是一棵子树的根，孩子 = 父 × 10 + d7        for (int start = 1; start <= 9; start++) {8            if (start > n) break;9            dfs(start, n, ans);10        }11        return ans;12    }13 14    private void dfs(int cur, int n, List<Integer> ans) {15        ans.add(cur);16        // 先加自己（先序）；孩子 cur*10+d 一旦超出 n，后面的 d 更大，整枝剪掉17        cur *= 10;18        for (int d = 0; d <= 9; d++) {19            if (cur + d > n) return;20            dfs(cur + d, n, ans);21        }22    }23}
题目

给你一个整数 n ，按字典序返回范围 [1, n] 内所有整数。

你必须设计一个时间复杂度为 O(n) 且使用 O(1) 额外空间的算法。

示例 1：

输入：n = 13
输出：[1,10,11,12,13,2,3,4,5,6,7,8,9]

示例 2：

输入：n = 2
输出：[1,2]

提示：

  • 1 <= n <= 5 * 104
