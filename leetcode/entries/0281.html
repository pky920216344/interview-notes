281. 锯齿迭代器

两个列表各一个下标，加一个「轮到谁」的开关；一侧取空后，另一侧自动补位连取。

思路

  • i、j 分别是 v1、v2 的读入位置，turnA 记录轮到谁；next 取完就翻转开关。
  • 轮到的一侧取空时走「补位」分支取另一侧——这样一侧耗尽后，剩余元素会被连续取完。
  • hasNext 是「任一侧还有剩」；不复制数据，构造 O(1)。

时间复杂度 next/hasNext 均 O(1)，空间复杂度 O(1)
1import java.util.*;2 3class ZigzagIterator {4    private final List<Integer> a, b;5    private int i, j;6    private boolean turnA = true;7 8    public ZigzagIterator(List<Integer> v1, List<Integer> v2) {9        a = v1;10        b = v2;11    }12 13    public int next() {14        // 轮到谁就从谁取；自己这侧取空了，就从另一侧补位15        int v;16        if (turnA && i < a.size()) v = a.get(i++);17        else if (!turnA && j < b.size()) v = b.get(j++);18        else v = turnA ? b.get(j++) : a.get(i++);19        turnA = !turnA;20        return v;21    }22 23    public boolean hasNext() {24        return i < a.size() || j < b.size();25    }26}
