14. 最长公共前缀

  • 简单
  • 频度 85
  • 模拟
  • 字典树
  • 数组
  • 字符串
  • 力扣已通过

纵向扫描：拿第一串当基准逐列比较，第 i 列全相同才继续，对不上或有串到头就返回前 i 个字符。

思路

  • 拿 strs[0] 当基准，i 从 0 往右一列一列比：c = first.charAt(i)。
  • 每列检查所有串：i == s.length()（有串到头）或 s.charAt(i) != c（对不上）就返回 first.substring(0, i)。
  • 「到头」必须放在取字符之前判断，否则会越界。
  • 扫完整个基准串都一致：基准串本身就是答案。

最优解

时间复杂度 O(S)（S 为所有字符总数），空间复杂度 O(1)
1class Solution {2    public String longestCommonPrefix(String[] strs) {3        // 拿第一串当基准，逐列比较4        String first = strs[0];5        for (int i = 0; i < first.length(); i++) {6            char c = first.charAt(i);7            for (String s : strs) {8                // 有串到头了，或这一列对不上：前缀只到第 i 列9                if (i == s.length() || s.charAt(i) != c) {10                    return first.substring(0, i);11                }12            }13        }14        return first;15    }16}
题目

编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 ""。

示例 1：

输入：strs = ["flower","flow","flight"]
输出："fl"

示例 2：

输入：strs = ["dog","racecar","car"]
输出：""
解释：输入不存在公共前缀。

提示：

  • 1 <= strs.length <= 200
  • 0 <= strs[i].length <= 200
  • strs[i] 如果非空，则仅由小写英文字母组成
