902. 最大为 N 的数字组合

数位组合：先数「位数更少」的全部（高位全 0 自由段），再对同位数的逐位贴着上界走。

思路

  • 短位数：L（1..k-1）位的数高位全 0 也合法（digits 里没有 0），每位任选，共 m^L 个，累加。
  • 同位数：从最高位起贴着 n 走。第 i 位放「比 s[i] 小的」数字有 less 种选择，后面 k-1-i 位自由填，贡献 less × m^(k-1-i)。
  • 若 s[i] 本身也在 digits 里就继续贴下一位；否则后面全超界，直接 return。
  • 能一路贴到底说明 n 的每位都在 digits 里，n 自己也算一个，最后 +1。

图解

最优解

时间复杂度 O(log n × |D|)，空间复杂度 O(1)
1class Solution {2    public int atMostNGivenDigitSet(String[] digits, int n) {3        char[] s = Integer.toString(n).toCharArray();4        int k = s.length, m = digits.length, ans = 0;5        // 比 n 短的数：相当于高位全 0，每位任选，L 位共 m^L 个6        int p = 1;7        for (int L = 1; L < k; L++) { p *= m; ans += p; }8        // 同位数的：逐位贴着上界走，这一位放更小的数字则后面自由填9        for (int i = 0; i < k; i++) {10            int less = 0;11            boolean eq = false;12            for (String d : digits) {13                char c = d.charAt(0);14                if (c < s[i]) less++;15                else if (c == s[i]) eq = true;16            }17            int q = 1;18            for (int t = k - 1 - i; t > 0; t--) q *= m;19            ans += less * q;20            if (!eq) return ans;   // 上界这一位接不上，再往后全超，就此打住21        }22        return ans + 1;   // 走到最后：n 本身每位都在 digits 里，它也算一个23    }24}
题目

给定一个按 非递减顺序 排列的数字数组 digits 。你可以用任意次数 digits[i] 来写的数字。例如，如果 digits = ['1','3','5']，我们可以写数字，如 '13', '551', 和 '1351315'。

返回 可以生成的小于或等于给定整数 n 的正整数的个数 。

示例 1：

输入：digits = ["1","3","5","7"], n = 100
输出：20
解释：
可写出的 20 个数字是：
1, 3, 5, 7, 11, 13, 15, 17, 31, 33, 35, 37, 51, 53, 55, 57, 71, 73, 75, 77.

示例 2：

输入：digits = ["1","4","9"], n = 1000000000
输出：29523
解释：
我们可以写 3 个一位数字，9 个两位数字，27 个三位数字，
81 个四位数字，243 个五位数字，729 个六位数字，
2187 个七位数字，6561 个八位数字和 19683 个九位数字。
总共，可以使用D中的数字写出 29523 个整数。

示例 3:

输入：digits = ["7"], n = 8
输出：1

提示：

  • 1 <= digits.length <= 9
  • digits[i].length == 1
  • digits[i] 是从 '1' 到 '9' 的数
  • digits 中的所有值都 不同 
  • digits 按 非递减顺序 排列
  • 1 <= n <= 109
