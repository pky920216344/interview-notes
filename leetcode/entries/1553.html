1553. 吃掉 N 个橘子的最少天数

  • 困难
  • 频度 1
  • 动态规划
  • 记忆化
  • 动态规划
  • 待提交

记忆化递归：想整份吃就先一天一个补齐余数，f(n) = min(n%2+1+f(n/2), n%3+1+f(n/3))。

思路

  • 只剩 1、2 个时一天吃一个最划算，n ≤ 2 直接返回 n。
  • 想用「吃 n/2 个」或「吃 2n/3 个」必须先凑成倍数：先花 n%2（或 n%3）天一天吃一个，再花 1 天整份吃。
  • 两条路取小：f(n) = min(n%2 + 1 + f(n/2), n%3 + 1 + f(n/3))。
  • 千万别加「f(n-1)」分支：状态数会退化到 O(n)，哈希记忆只存 O(log²n) 个状态。

最优解

时间复杂度 O(log²n)，空间复杂度 O(log²n)
1import java.util.*;2 3class Solution {4    private final Map<Integer, Integer> memo = new HashMap<>();5 6    public int minDays(int n) {7        if (n <= 2) return n;                    // 剩 ≤ 2 个：一天吃一个最划算8        Integer cached = memo.get(n);9        if (cached != null) return cached;10        // 想用 /2 或 /3 整份吃，先一天一个把余数补没；不要 n−1 分支，否则退化成 O(n)11        int ans = Math.min(n % 2 + 1 + minDays(n / 2), n % 3 + 1 + minDays(n / 3));12        memo.put(n, ans);13        return ans;14    }15}
题目

厨房里总共有 n 个橘子，你决定每一天选择如下方式之一吃这些橘子：

  • 吃掉一个橘子。
  • 如果剩余橘子数 n 能被 2 整除，那么你可以吃掉 n/2 个橘子。
  • 如果剩余橘子数 n 能被 3 整除，那么你可以吃掉 2*(n/3) 个橘子。

每天你只能从以上 3 种方案中选择一种方案。

请你返回吃掉所有 n 个橘子的最少天数。

示例 1：

输入：n = 10
输出：4
解释：你总共有 10 个橘子。
第 1 天：吃 1 个橘子，剩余橘子数 10 - 1 = 9。
第 2 天：吃 6 个橘子，剩余橘子数 9 - 2*(9/3) = 9 - 6 = 3。（9 可以被 3 整除）
第 3 天：吃 2 个橘子，剩余橘子数 3 - 2*(3/3) = 3 - 2 = 1。
第 4 天：吃掉最后 1 个橘子，剩余橘子数 1 - 1 = 0。
你需要至少 4 天吃掉 10 个橘子。

示例 2：

输入：n = 6
输出：3
解释：你总共有 6 个橘子。
第 1 天：吃 3 个橘子，剩余橘子数 6 - 6/2 = 6 - 3 = 3。（6 可以被 2 整除）
第 2 天：吃 2 个橘子，剩余橘子数 3 - 2*(3/3) = 3 - 2 = 1。（3 可以被 3 整除）
第 3 天：吃掉剩余 1 个橘子，剩余橘子数 1 - 1 = 0。
你至少需要 3 天吃掉 6 个橘子。

示例 3：

输入：n = 1
输出：1

示例 4：

输入：n = 56
输出：6

提示：

  • 1 <= n <= 2*10^9
