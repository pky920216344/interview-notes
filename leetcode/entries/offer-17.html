答案就是 1 到 10^cnt-1 连续整数：先算上界 10^cnt，再按序填表 ans[i]=i+1，一遍写完。

思路

  • 数列就是 1, 2, …, 10^cnt - 1，没有任何挑选和判断，按顺序生成即可。
  • 上界用 end *= 10 连乘 cnt 次得到，别用 Math.pow（浮点不精确）。
  • ans 的长度是 end - 1，逐格 ans[i] = i + 1 填满后返回。
  • cnt = 0 时上界是 1，返回空数组。

最优解

时间复杂度 O(10^cnt)，空间复杂度 O(1)（不计返回数组）
1class Solution {2    public int[] countNumbers(int cnt) {3        // 上界是 10^cnt，要输出 1 .. 10^cnt - 14        int end = 1;5        for (int i = 0; i < cnt; i++) end *= 10;6        int[] ans = new int[end - 1];7        for (int i = 0; i < ans.length; i++) ans[i] = i + 1;8        return ans;9    }10}
