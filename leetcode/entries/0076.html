76. 最小覆盖子串

  • 困难
  • 频度 136
  • 滑动窗口
  • 哈希表
  • 哈希表
  • 字符串
  • 滑动窗口
  • 力扣已通过

滑动窗口：右指针扩张到覆盖 t，再收缩左指针求最短；lack 记还缺几种字符，O(1) 判断是否覆盖。

思路

  • need[c] 是窗口里还缺几个 c（负数表示多出来的），lack 是还没凑够的字符种类数；先用 t 填好。
  • right 右移读入字符：--need[c] == 0 说明 c 刚好凑齐，lack--。
  • lack == 0 就是窗口已覆盖 t：先更新最短答案，再移出 s[left]；++need[d] > 0 说明 d 又缺了，lack++，收缩停止。
  • 每个字符最多进窗口、出窗口各一次；没找到时 bestLen 还是初值，返回空串。

图解

最优解

时间复杂度 O(|s| + |t|)，空间复杂度 O(Σ)（Σ 为字符集大小）
1class Solution {2    public String minWindow(String s, String t) {3        // need[c]：窗口里还缺几个 c，负数表示多出来的4        int[] need = new int[128];5        // lack：还没凑够的字符种类数，为 0 即已覆盖 t6        int lack = 0;7        for (char c : t.toCharArray()) {8            if (need[c]++ == 0) lack++;9        }10        int left = 0, bestL = 0, bestLen = Integer.MAX_VALUE;11        for (int right = 0; right < s.length(); right++) {12            // 读入的字符刚好补齐，缺的种类少一种13            if (--need[s.charAt(right)] == 0) lack--;14            // 已覆盖：尽量收缩左边，每一步都试着更新最短15            while (lack == 0) {16                if (right - left + 1 < bestLen) {17                    bestLen = right - left + 1;18                    bestL = left;19                }20                // 移出的字符重新变成「缺」，覆盖就被破坏了21                if (++need[s.charAt(left++)] > 0) lack++;22            }23        }24        if (bestLen == Integer.MAX_VALUE) return "";25        return s.substring(bestL, bestL + bestLen);26    }27}
题目

给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的 最短窗口 子串，使得该子串包含 t 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 ""。

测试用例保证答案唯一。

示例 1：

输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

示例 2：

输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。

示例 3:

输入: s = "a", t = "aa"
输出: ""
解释: t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。

提示：

  • m == s.length
  • n == t.length
  • 1 <= m, n <= 105
  • s 和 t 由英文字母组成
