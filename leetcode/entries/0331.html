331. 验证二叉树的前序序列化

槽位法：开局 1 个槽；非空节点耗 1 产 2，# 只耗 1；中途清零必假，读完恰好归 0 才真。

思路

  • 把前序序列化想成「填坑」：开局只有根这 1 个坑位，每个记号都要先占掉一个坑。
  • 非空节点占 1 坑、又造出左右孩子 2 个新坑（净 +1）；# 只占坑不产坑（净 −1）。
  • 两个假信号：还没读完坑就清零（后面的节点没地方挂）；读完了坑还剩（有节点缺孩子声明）。
  • 读完且坑恰好为 0 才合法；split(",") 逐段扫一遍即可，不用栈也不用建树。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean isValidSerialization(String preorder) {3        // 槽位：还差几个「孩子位置」没填；开局只有根这 1 个位置4        int slots = 1;5        for (String t : preorder.split(",")) {6            // 还没读完槽位就清零：后面的节点没地方挂，必假7            if (slots == 0) return false;8            // 每个记号（含 #）都要先占掉一个槽位9            slots--;10            // 非空节点补上左右孩子两个新槽位；# 不产槽11            if (!t.equals("#")) slots += 2;12        }13        // 全部读完且槽位恰好归 0，才是合法的前序序列化14        return slots == 0;15    }16}
题目

序列化二叉树的一种方法是使用 前序遍历 。当我们遇到一个非空节点时，我们可以记录下这个节点的值。如果它是一个空节点，我们可以使用一个标记值记录，例如 #。

例如，上面的二叉树可以被序列化为字符串 "9,3,4,#,#,1,#,#,2,#,6,#,#"，其中 # 代表一个空节点。

给定一串以逗号分隔的序列，验证它是否是正确的二叉树的前序序列化。编写一个在不重构树的条件下的可行算法。

保证 每个以逗号分隔的字符或为一个整数或为一个表示 null 指针的 '#' 。

你可以认为输入格式总是有效的

  • 例如它永远不会包含两个连续的逗号，比如 "1,,3" 。

注意：不允许重建树。

示例 1:

输入: preorder = "9,3,4,#,#,1,#,#,2,#,6,#,#"
输出: true

示例 2:

输入: preorder = "1,#"
输出: false

示例 3:

输入: preorder = "9,#,#,1"
输出: false

提示:

  • 1 <= preorder.length <= 104
  • preorder 由以逗号 “，” 分隔的 [0,100] 范围内的整数和 “#” 组成
