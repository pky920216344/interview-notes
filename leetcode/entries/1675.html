1675. 数组的最小偏移量

  • 贪心

  • 有序集合
  • 堆（优先队列）
  • 待提交

有序集合：奇数先 ×2 顶到上限，之后每轮把当前最大值减半放回，随时维护 max−min 的最小值。

思路

  • 奇数只能 ×2，偶数能一路减半：先给奇数 ×2，每个数的可达范围就成了一条减半链。
  • 全部当前值放进 TreeSet：每次唯一的自由度是把最大值减半（变小只会更优）。
  • 减半放回后用 last − first 更新答案；最大值一旦是奇数就无法再缩，结束。
  • 偏移量只看 max 和 min，TreeSet 去重不影响结果。

最优解

时间复杂度 O(n·logV·logn)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int minimumDeviation(int[] nums) {5        // 有序集合装全部当前值：奇数先 ×2 顶到上限（它以后只能减半）6        TreeSet<Integer> set = new TreeSet<>();7        for (int x : nums) set.add(x % 2 == 1 ? x * 2 : x);8        int ans = set.last() - set.first();9        // 每轮只能把最大值减半：是偶数就减半放回，看 max−min 能压到多小10        while (set.last() % 2 == 0) {11            int max = set.last();12            set.remove(max);13            set.add(max / 2);14            ans = Math.min(ans, set.last() - set.first());15        }16        return ans;17    }18}
题目

给你一个由 n 个正整数组成的数组 nums 。

你可以对数组的任意元素执行任意次数的两类操作：

  • 如果元素是 偶数 ，除以 2
    • 例如，如果数组是 [1,2,3,4] ，那么你可以对最后一个元素执行此操作，使其变成 [1,2,3,2]
  • 如果元素是 奇数 ，乘上 2
    • 例如，如果数组是 [1,2,3,4] ，那么你可以对第一个元素执行此操作，使其变成 [2,2,3,4]

数组的 偏移量 是数组中任意两个元素之间的 最大差值 。

返回数组在执行某些操作之后可以拥有的 最小偏移量 。

示例 1：

输入：nums = [1,2,3,4]
输出：1
解释：你可以将数组转换为 [1,2,3,2]，然后转换成 [2,2,3,2]，偏移量是 3 - 2 = 1

示例 2：

输入：nums = [4,1,5,20,3]
输出：3
解释：两次操作后，你可以将数组转换为 [4,2,5,5,3]，偏移量是 5 - 2 = 3

示例 3：

输入：nums = [2,10,8]
输出：3

提示：

  • n == nums.length
  • 2 <= n <= 5 * 104
  • 1 <= nums[i] <= 109
