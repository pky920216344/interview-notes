三指针 DP：dp[i] 为第 i 个丑数；p2/p3/p5 各记「下一个待乘的丑数」下标，三个乘积取最小入表，乘积相等的指针一起前进防重复。

思路

  • dp[1] = 1；p2/p3/p5 分别指向还没被 ×2/×3/×5 用过的最靠前的丑数。
  • 每轮算三个乘积 dp[p2]·2、dp[p3]·3、dp[p5]·5，取最小作为 dp[i]。
  • 乘积等于最小值的指针全部前移（可能多个一起）——只移一个的话，同一个丑数会被重复计入。

1class Solution {2    public int nthUglyNumber(int n) {3        int[] dp = new int[n + 1];   // dp[i]：第 i 个丑数，dp[1] = 14        dp[1] = 1;5        int p2 = 1, p3 = 1, p5 = 1;  // 各质数「下一个待乘的丑数」下标6        for (int i = 2; i <= n; i++) {7            int a = dp[p2] * 2, b = dp[p3] * 3, c = dp[p5] * 5;8            dp[i] = Math.min(a, Math.min(b, c));9            if (dp[i] == a) p2++;    // 乘积相等的指针一起走，丑数不重复10            if (dp[i] == b) p3++;11            if (dp[i] == c) p5++;12        }13        return dp[n];14    }15}
题目

给你一个整数 n ，请你找出并返回第 n 个 丑数 。

说明：丑数是只包含质因数 2、3 和/或 5 的正整数；1 是丑数。

示例 1：

输入: n = 10
输出: 12
解释: 1, 2, 3, 4, 5, 6, 8, 9, 10, 12 是前 10 个丑数。

提示： 

  • 1 <= n <= 1690
