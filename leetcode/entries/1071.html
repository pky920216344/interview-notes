1071. 字符串的最大公因子

先验证 str1+str2 == str2+str1（存在公因子的充要条件），答案就是长度取 gcd 后的 str1 前缀。

思路

  • 若 x 能同时除尽两串，str1+str2 和 str2+str1 都是 x 的重复，必然相等；这个条件反过来也成立。
  • 相等时公因子长度恰为 gcd(len1, len2)，直接取 str1 的前缀，不必再逐字符验证。
  • 不相等直接返回空串。

图解

最优解

时间复杂度 O(m+n)，空间复杂度 O(m+n)
1class Solution {2    public String gcdOfStrings(String str1, String str2) {3        // str1+str2 == str2+str1 是「存在公因子串」的充要条件4        if (!(str1 + str2).equals(str2 + str1)) return "";5        // 相等时公因子长度就是两长度的 gcd，取 str1 的前缀即可6        return str1.substring(0, gcd(str1.length(), str2.length()));7    }8 9    private int gcd(int a, int b) {10        return b == 0 ? a : gcd(b, a % b);11    }12}
题目

对于字符串 s 和 t，只有在 s = t + t + t + ... + t + t（t 自身连接 1 次或多次）时，我们才认定 “t 能除尽 s”。

给定两个字符串 str1 和 str2 。返回 最长字符串 x，要求满足 x 能除尽 str1 且 x 能除尽 str2 。

示例 1：

输入：str1 = "ABCABC", str2 = "ABC"

输出："ABC"

示例 2：

输入：str1 = "ABABAB", str2 = "ABAB"

输出："AB"

示例 3：

输入：str1 = "LEET", str2 = "CODE"

输出：""

示例 4：

输入：str1 = "AAAAAB", str2 = "AAA"

输出：""

提示：

  • 1 <= str1.length, str2.length <= 1000
  • str1 和 str2 由大写英文字母组成
