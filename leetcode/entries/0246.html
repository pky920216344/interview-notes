246. 中心对称数

双指针从两端向中间，逐对检查两个字符能否旋转 180° 互换；镜像只有 0、1、8 和 6↔9。

思路

  • 合法镜像对只有 (0,0)、(1,1)、(8,8)、(6,9)、(9,6)；串里出现 2/3/4/5/7 直接 false。
  • left、right 从两端向中间走，每一对 (num[left], num[right]) 必须满足「左边旋转后正好是右边」。
  • 奇数长度时中间那格和自己配对：只能放 0/1/8——中间放 6 会转成 9 对不上，这是最容易被漏掉的坑。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean isStrobogrammatic(String num) {3        // 双指针从两端向中间：每一对 (左, 右) 要能旋转 180° 后互换4        for (int left = 0, right = num.length() - 1; left <= right; left++, right--) {5            if (!mirror(num.charAt(left), num.charAt(right))) return false;6        }7        return true;8    }9 10    // 左边字符 a 旋转后必须正好变成右边的 b；2、3、4、5、7 转完不是数字11    private boolean mirror(char a, char b) {12        switch (a) {13            case '0': return b == '0';14            case '1': return b == '1';15            case '8': return b == '8';16            case '6': return b == '9';17            case '9': return b == '6';18            default: return false;19        }20    }21}
