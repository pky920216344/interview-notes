453. 最小操作次数使数组元素相等

  • 简单
  • 频度 1
  • 数学
  • 数组
  • 数学
  • 待提交

换个方向看操作：n−1 个数 +1 等价于把剩下的那个数 −1；于是每个数都要降到最小值，答案是差额之和。

思路

  • 「每轮给 n−1 个数 +1」与「每轮给 1 个数 −1」效果等价：相对差距一样，轮数也一样。
  • 所以最优做法是只动「高出去的部分」：每个数降到全局最小值，ans = Σ(nums[i] − min)。
  • 先一遍扫出 min，再一遍累加差额；用 long 累加再转 int，防大数溢出。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int minMoves(int[] nums) {3        // n-1 个数 +1 等价于把剩下的 1 个数 −1：总共要让每个数降到最小值4        int min = nums[0];5        for (int x : nums) min = Math.min(min, x);6        long moves = 0;7        for (int x : nums) moves += x - min;8        return (int) moves;9    }10}
题目

给你一个长度为 n 的整数数组，每次操作将会使 n - 1 个元素增加 1 。返回让数组所有元素相等的最小操作次数。

示例 1：

输入：nums = [1,2,3]
输出：3
解释：
只需要3次操作（注意每次操作会增加两个元素的值）：
[1,2,3]  =>  [2,3,3]  =>  [3,4,3]  =>  [4,4,4]

示例 2：

输入：nums = [1,1,1]
输出：0

提示：

  • n == nums.length
  • 1 <= nums.length <= 105
  • -109 <= nums[i] <= 109
  • 答案保证符合 32-bit 整数
