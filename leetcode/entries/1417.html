1417. 重新格式化字符串

  • 简单
  • 频度 1
  • 模拟
  • 字符串
  • 待提交

字母、数字分两桶计数；数量差 > 1 无解，否则多的一桶先出、两桶交替各拿一个，多出的一个放队尾。

思路

  • 相邻必须异类 ⇔ 两种字符数量差不超过 1，先分桶数一遍就能判定可行性。
  • 交替拼接时数量多的那桶必须先出（差为 1 时它占第 1、3、5… 位），否则会撞车。
  • 两桶等长正好配对排完；多出 1 个时把它放在队尾，与前一字符异类，依然合法。
  • 答案不唯一（力扣用特判），本地按「多重集一致 + 相邻异类」的性质验证。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public String reformat(String s) {3        StringBuilder let = new StringBuilder(), dig = new StringBuilder();   // 分两桶：字母、数字4        for (char c : s.toCharArray()) {5            if (Character.isDigit(c)) dig.append(c);6            else let.append(c);7        }8        if (Math.abs(let.length() - dig.length()) > 1) return "";   // 数量差超过 1，必有同类相邻9        if (let.length() < dig.length()) {                          // 让 let 指向数量多的那桶10            StringBuilder t = let;11            let = dig;12            dig = t;13        }14        StringBuilder sb = new StringBuilder();15        for (int i = 0; i < dig.length(); i++) {                    // 多的一桶先出，一字母一数字交替16            sb.append(let.charAt(i)).append(dig.charAt(i));17        }18        if (let.length() > dig.length()) sb.append(let.charAt(let.length() - 1));   // 多出的一个放队尾19        return sb.toString();20    }21}
题目

给你一个混合了数字和字母的字符串 s，其中的字母均为小写英文字母。

请你将该字符串重新格式化，使得任意两个相邻字符的类型都不同。也就是说，字母后面应该跟着数字，而数字后面应该跟着字母。

请你返回 重新格式化后 的字符串；如果无法按要求重新格式化，则返回一个 空字符串 。

示例 1：

输入：s = "a0b1c2"
输出："0a1b2c"
解释："0a1b2c" 中任意两个相邻字符的类型都不同。 "a0b1c2", "0a1b2c", "0c2a1b" 也是满足题目要求的答案。

示例 2：

输入：s = "leetcode"
输出：""
解释："leetcode" 中只有字母，所以无法满足重新格式化的条件。

示例 3：

输入：s = "1229857369"
输出：""
解释："1229857369" 中只有数字，所以无法满足重新格式化的条件。

示例 4：

输入：s = "covid2019"
输出："c2o0v1i9d"

示例 5：

输入：s = "ab123"
输出："1a2b3"

提示：

  • 1 <= s.length <= 500
  • s 仅由小写英文字母和/或数字组成。
