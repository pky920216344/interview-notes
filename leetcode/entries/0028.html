28. 找出字符串中第一个匹配项的下标

KMP：先给 needle 建 next 表（最长相等前后缀），失配时 j 退到 next[j-1]，主串指针从不回头。

思路

  • next[i] = needle[0..i] 的最长相等前后缀长度；建表就是 needle 自己匹配自己。
  • 匹配时 j 表示已匹配长度：对上就 j++；失配就 j = next[j-1]，可能连退几次。
  • j == m 时匹配完成，起点 = i - m + 1。
  • 建表和匹配用的是同一套「失配回退」写法，记一套就够。

图解

最优解

时间复杂度 O(n+m)，空间复杂度 O(m)
1class Solution {2    public int strStr(String haystack, String needle) {3        int n = haystack.length(), m = needle.length();4        if (m == 0) return 0;5        // next[i]：needle[0..i] 的最长相等前后缀长度6        int[] next = new int[m];7        for (int i = 1, len = 0; i < m; i++) {8            while (len > 0 && needle.charAt(i) != needle.charAt(len)) len = next[len - 1];9            if (needle.charAt(i) == needle.charAt(len)) len++;10            next[i] = len;11        }12        // j 是 needle 已匹配的长度；失配就退到 next[j-1]，主串指针不回头13        for (int i = 0, j = 0; i < n; i++) {14            while (j > 0 && haystack.charAt(i) != needle.charAt(j)) j = next[j - 1];15            if (haystack.charAt(i) == needle.charAt(j)) j++;16            if (j == m) return i - m + 1;17        }18        return -1;19    }20}
题目

给你两个字符串 haystack 和 needle ，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回  -1。

示例 1：

输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 在下标 0 和 6 处匹配。
第一个匹配项的下标是 0 ，所以返回 0 。

示例 2：

输入：haystack = "leetcode", needle = "leeto"
输出：-1
解释："leeto" 没有在 "leetcode" 中出现，所以返回 -1 。

提示：

  • 1 <= haystack.length, needle.length <= 104
  • haystack 和 needle 仅由小写英文字符组成
