补充题2. 圆环回原点问题

  • 中等
  • 频度 35
  • 动态规划
  • 未经力扣验证

环上 DP：dp[j] 是走 i 步位于点 j 的方案数，每步由两个环上邻居上一轮相加得到；答案就是走 n 步后 dp[0]。

思路

  • 题意：圆环 10 个点（0~9），从 0 出发，每步顺/逆时针走 1 格，走 n 步回到 0 的方案数。
  • dp[j] = 走当前步数位于点 j 的方案数；点 j 的上一步只能来自 (j-1)%10 或 (j+1)%10。
  • 每轮新表 = 旧表两邻居之和，滚 n 轮，答案在 dp[0]；奇数步恒为 0（环长 10 是偶数）。
  • 与爬楼梯同构：走 n 步到 0 = 走 n-1 步到 1 的方案数 + 走 n-1 步到 9 的方案数。
