桶分治：桶宽 valueDiff+1，同桶必近；只查左右邻桶；下标差超 indexDiff 就删旧桶。

思路

  • 把值域切成宽 valueDiff + 1 的桶：同一桶里任意两数差必 ≤ valueDiff，同桶命中直接返回 true。
  • 相邻桶可能出近邻：只查左邻桶里「比自己小多少」、右邻桶里「比自己大多少」，各一次比较。
  • 用 Map<桶号, 值> + 滑动窗口：下标差超过 indexDiff 的元素把它的桶删掉；桶里同时最多一个数。
  • 负数桶号用 Math.floorDiv（向负无穷取整），别用 % 截断。

时间复杂度 O(n)，空间复杂度 O(min(n, indexDiff))
1import java.util.*;2 3class Solution {4    public boolean containsNearbyAlmostDuplicate(int[] nums, int indexDiff, int valueDiff) {5        // 桶宽 = valueDiff + 1：同一桶内任意两数差最多 valueDiff6        long w = (long) valueDiff + 1;7        Map<Long, Long> bucket = new HashMap<>();   // 桶号 -> 桶里那个数8        for (int i = 0; i < nums.length; i++) {9            long v = nums[i];10            long id = Math.floorDiv(v, w);11            if (bucket.containsKey(id)) return true;12            Long left = bucket.get(id - 1);13            if (left != null && v - left <= valueDiff) return true;14            Long right = bucket.get(id + 1);15            if (right != null && right - v <= valueDiff) return true;16            bucket.put(id, v);17            if (i >= indexDiff) bucket.remove(Math.floorDiv((long) nums[i - indexDiff], w));18        }19        return false;20    }21}
题目

给你一个整数数组 nums 和两个整数 indexDiff 和 valueDiff 。

找出满足下述条件的下标对 (i, j)：

  • i != j,
  • abs(i - j) <= indexDiff
  • abs(nums[i] - nums[j]) <= valueDiff

如果存在，返回 true ；否则，返回 false 。

示例 1：

输入：nums = [1,2,3,1], indexDiff = 3, valueDiff = 0
输出：true
解释：可以找出 (i, j) = (0, 3) 。
满足下述 3 个条件：
i != j --> 0 != 3
abs(i - j) <= indexDiff --> abs(0 - 3) <= 3
abs(nums[i] - nums[j]) <= valueDiff --> abs(1 - 1) <= 0

示例 2：

输入：nums = [1,5,9,1,5,9], indexDiff = 2, valueDiff = 3
输出：false
解释：尝试所有可能的下标对 (i, j) ，均无法满足这 3 个条件，因此返回 false 。

提示：

  • 2 <= nums.length <= 105
  • -109 <= nums[i] <= 109
  • 1 <= indexDiff <= nums.length
  • 0 <= valueDiff <= 109
