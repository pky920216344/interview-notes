416. 分割等和子集

  • 中等
  • 频度 31
  • 动态规划
  • 数组
  • 动态规划
  • knapsack-problem
  • 0-1-knapsack
  • 力扣已通过

0/1 背包：总和为奇数直接否；否则看能否用若干数凑出 sum/2，一维 dp 倒序更新。

思路

  • 两个子集和相等 ⟺ 总和是偶数且能凑出 sum/2；奇数直接返回 false。
  • dp[j] 表示能否从已处理的数里凑出和 j；初始只有 dp[0] 为真。
  • 每来一个数 x：dp[j] |= dp[j-x]，必须倒序从 target 扫到 x——正序会让 x 被用两次。
  • 答案就是 dp[target]；nums 全为正整数，j < x 的格子不用碰。

图解

最优解

时间复杂度 O(n·target)，空间复杂度 O(target)
1class Solution {2    public boolean canPartition(int[] nums) {3        int sum = 0;4        for (int x : nums) sum += x;5        if ((sum & 1) == 1) return false;   // 总和是奇数，必不可能平分6        int target = sum / 2;7        // dp[j]：能否从已处理的数里凑出和 j8        boolean[] dp = new boolean[target + 1];9        dp[0] = true;  // 什么都不选，凑出 010        for (int x : nums) {11            // 倒序扫：保证这一轮 x 只被用一次12            for (int j = target; j >= x; j--) dp[j] = dp[j] || dp[j - x];13        }14        return dp[target];15    }16}
题目

给你一个 只包含正整数 的 非空 数组 nums 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

示例 1：

输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11] 。

示例 2：

输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。

提示：

  • 1 <= nums.length <= 200
  • 1 <= nums[i] <= 100
