169. 多数元素

  • 力扣已通过

摩尔投票：同数 +1、异数 -1 互相抵票；count 归零就换候选，多数元素超过一半抵不完，最后必剩它。

思路

  • 只有候选 cand 和票数 count 两个变量：读到和候选相同的数 count++，不同的 count--，一票抵一票。
  • count == 0 说明前面各种数恰好互相抵消干净（各占一半），当前数当新候选。
  • 多数元素出现超过 ⌊n/2⌋，无论怎么抵消它都耗不完，扫描结束剩下的候选必是它。
  • 题目保证多数元素一定存在，所以不用再数一遍验证。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int majorityElement(int[] nums) {3        // 候选数 cand，票数 count4        int cand = 0, count = 0;5        for (int x : nums) {6            // 票归零：前面的数恰好互相抵消干净，换当前数当候选7            if (count == 0) cand = x;8            // 和候选相同 +1，不同 -1（一票抵一票）9            count += (x == cand) ? 1 : -1;10        }11        // 多数元素超过一半，抵不完，最后一定剩它12        return cand;13    }14}
题目

给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

示例 1：

输入：nums = [3,2,3]
输出：3

示例 2：

输入：nums = [2,2,1,1,1,2,2]
输出：2
提示：
  • n == nums.length
  • 1 <= n <= 5 * 104
  • -109 <= nums[i] <= 109
  • 输入保证数组中一定有一个多数元素。

进阶：尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。
