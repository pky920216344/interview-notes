1423. 可获得的最大点数

  • 中等
  • 频度 5
  • 滑动窗口
  • 数组
  • 前缀和
  • 滑动窗口
  • 待提交

换角度：从两头拿 k 张 ⇔ 中间留下 n−k 张连续段；答案 = 总和 − 中间最小区间和，滑窗求最小即可。

思路

  • 正着维护「两头各拿了多少」很绕；反过来看，没拿走的就是中间一段长度 n−k 的连续区间。
  • 先求总和 total；拿走的点数 = total − 窗口和，要拿得最多就是让留下的窗口和最小。
  • 定长滑窗：先算 [0, w) 的窗口和，再逐格右移 win += c[i] − c[i−w]，途中记最小值。
  • k = n 时 w = 0，窗口和为 0，答案就是总和；总和最大 1e5 × 1e4 = 1e9，int 装得下。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxScore(int[] cardPoints, int k) {3        int n = cardPoints.length;4        int total = 0;5        for (int p : cardPoints) total += p;6        // 拿走两头 k 张 ⇔ 留下中间 n−k 张连续段；要总分最大，就让留下的窗口和最小7        int w = n - k;8        int win = 0;   // 长度 w 的窗口和9        for (int i = 0; i < w; i++) win += cardPoints[i];10        int best = win;11        for (int i = w; i < n; i++) {12            win += cardPoints[i] - cardPoints[i - w];   // 窗口右移一格13            best = Math.min(best, win);14        }15        return total - best;16    }17}
题目

几张卡牌 排成一行，每张卡牌都有一个对应的点数。点数由整数数组 cardPoints 给出。

每次行动，你可以从行的开头或者末尾拿一张卡牌，最终你必须正好拿 k 张卡牌。

你的点数就是你拿到手中的所有卡牌的点数之和。

给你一个整数数组 cardPoints 和整数 k，请你返回可以获得的最大点数。

示例 1：

输入：cardPoints = [1,2,3,4,5,6,1], k = 3
输出：12
解释：第一次行动，不管拿哪张牌，你的点数总是 1 。但是，先拿最右边的卡牌将会最大化你的可获得点数。最优策略是拿右边的三张牌，最终点数为 1 + 6 + 5 = 12 。

示例 2：

输入：cardPoints = [2,2,2], k = 2
输出：4
解释：无论你拿起哪两张卡牌，可获得的点数总是 4 。

示例 3：

输入：cardPoints = [9,7,7,9,7,7,9], k = 7
输出：55
解释：你必须拿起所有卡牌，可以获得的点数为所有卡牌的点数之和。

示例 4：

输入：cardPoints = [1,1000,1], k = 1
输出：1
解释：你无法拿到中间那张卡牌，所以可以获得的最大点数为 1 。

示例 5：

输入：cardPoints = [1,79,80,1,1,1,200,1], k = 3
输出：202

提示：

  • 1 <= cardPoints.length <= 10^5
  • 1 <= cardPoints[i] <= 10^4
  • 1 <= k <= cardPoints.length
