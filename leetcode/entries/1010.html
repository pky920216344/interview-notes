1010. 总持续时间可被 60 整除的歌曲

按 t%60 计数：余 0、余 30 各自内部配 C(c,2) 对，其余余数 r 与 60−r 的个数相乘，只扫一半防重复。

思路

  • (a+b)%60==0 ⟺ 两者余数互补：a%60=r 就必须配 b%60=60−r。
  • cnt[r] 数完 60 个桶：余 0、余 30 只能同桶内部两两配，各贡献 C(c,2)=c×(c−1)/2。
  • 其余桶配对 r ↔ 60−r（r 只扫 1~29）：贡献 cnt[r]×cnt[60−r]，扫一半避免算两遍。
  • 对数最大约 1.8×10⁹，逼近 int 上限，中间量用 long 累加保险。

最优解

时间复杂度 O(n)，空间复杂度 O(60)
1class Solution {2    public int numPairsDivisibleBy60(int[] time) {3        // cnt[r]：时长除以 60 余 r 的歌曲数4        long[] cnt = new long[60];5        for (int t : time) cnt[t % 60]++;6        // 余 0 与余 30 只能自己配自己：C(c,2) = c×(c−1)/27        long ans = cnt[0] * (cnt[0] - 1) / 2 + cnt[30] * (cnt[30] - 1) / 2;8        // 其余余数 r 与 60−r 互补；r 只扫 1~29，避免重复计数9        for (int r = 1; r < 30; r++) ans += cnt[r] * cnt[60 - r];10        return (int) ans;11    }12}
题目

在歌曲列表中，第 i 首歌曲的持续时间为 time[i] 秒。

返回其总持续时间（以秒为单位）可被 60 整除的歌曲对的数量。形式上，我们希望下标数字 i 和 j 满足  i < j 且有 (time[i] + time[j]) % 60 == 0。

示例 1：

输入：time = [30,20,150,100,40]
输出：3
解释：这三对的总持续时间可被 60 整除：
(time[0] = 30, time[2] = 150): 总持续时间 180
(time[1] = 20, time[3] = 100): 总持续时间 120
(time[1] = 20, time[4] = 40): 总持续时间 60

示例 2：

输入：time = [60,60,60]
输出：3
解释：所有三对的总持续时间都是 120，可以被 60 整除。

提示：

  • 1 <= time.length <= 6 * 104
  • 1 <= time[i] <= 500
