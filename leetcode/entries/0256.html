256. 粉刷房子

  • 简单
  • 频度 5
  • 动态规划
  • 数组
  • 动态规划
  • 未经力扣验证

三色 DP：dp[i][色] = 本间房该色的成本 + 上一间另两种色的较小 dp；三个滚动变量收尾，最后一行三选一。

思路

  • 相邻不能同色，所以第 i 间涂红时，前面只可能是涂蓝或涂绿的最优解：新a = costs[i][0] + min(b, c)，另两色同理。
  • 只依赖上一行 → 用 a/b/c 三个变量滚动，算完一行整体覆盖。
  • 答案是最后一行的 min(a, b, c)。
  • 会员题：本地验证通过即可，不提交力扣。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int minCost(int[][] costs) {3        // a/b/c：刷到当前房子为止、且这房子涂红/蓝/绿时的最小总花费4        int a = 0, b = 0, c = 0;5        for (int[] p : costs) {6            // 当前房涂红：前面的房子只能涂蓝或绿，取较小的那份累计花费7            int na = p[0] + Math.min(b, c);8            int nb = p[1] + Math.min(a, c);9            int nc = p[2] + Math.min(a, b);10            a = na;11            b = nb;12            c = nc;13        }14        return Math.min(a, Math.min(b, c));15    }16}
