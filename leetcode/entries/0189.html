三次反转：先整体反转，再分别反转前 k 个和后 n−k 个；右移 k 位就地完成。

思路

  • k %= n 先去掉整数圈；k = 0 直接返回。
  • 右移 k 位 = 把右边 k 个搬到开头：整体反转后，这两段已在正确的一侧、只是各自内部反着。
  • 再反转前 k 个、后 n − k 个，两段各自恢复正序，总计三次反转、原地完成。
  • 例：[1,2,3,4,5,6,7]，k=3 → 整体 [7,6,5,4,3,2,1] → 前 3 [5,6,7,…] → 后 4 [5,6,7,1,2,3,4]。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public void rotate(int[] nums, int k) {3        int n = nums.length;4        // 转整数圈等于没转5        k %= n;6        if (k == 0) return;7        // 三次反转：整体、前 k 个、后 n-k 个；右边 k 个就换到了开头8        reverse(nums, 0, n - 1);9        reverse(nums, 0, k - 1);10        reverse(nums, k, n - 1);11    }12 13    // 反转 [l, r]：两端往中间换14    private void reverse(int[] a, int l, int r) {15        while (l < r) {16            int t = a[l]; a[l] = a[r]; a[r] = t;17            l++;18            r--;19        }20    }21}
题目

给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。

示例 1:

输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释:
向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]

示例 2:

输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释: 
向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]

提示：

  • 1 <= nums.length <= 105
  • -231 <= nums[i] <= 231 - 1
  • 0 <= k <= 105

进阶：

  • 尽可能想出更多的解决方案，至少有 三种 不同的方法可以解决这个问题。
  • 你可以使用空间复杂度为 O(1) 的 原地 算法解决这个问题吗？
