桶数组 + 手写拉链：key % 桶数定位桶，链上逐个比 key；put 头插，remove 拿 pre 摘结点。

思路

  • Node 里 key、val 都要存：同一条链上的结点 key 互不相同，比对时全靠它。
  • 定位：h = key % CAP（桶数取质数分布更均匀）；put 先沿链找，找到就更新，找不到头插新结点。
  • get 沿链比对 key，走完没有返回 -1。
  • remove 用 pre 记前驱：删头结点时桶直接指向 p.next，否则 pre.next = p.next。

最优解

时间复杂度 均摊 O(1)，空间复杂度 O(n)
1class MyHashMap {2    // 拉链法的结点：key 也要存，因为同一条链上 key 各不相同3    private static class Node {4        int key, val;5        Node next;6 7        Node(int key, int val, Node next) {8            this.key = key;9            this.val = val;10            this.next = next;11        }12    }13 14    // 桶数取质数，key % CAP 分布更均匀15    private static final int CAP = 769;16    private final Node[] buckets = new Node[CAP];17 18    public MyHashMap() {19    }20 21    public void put(int key, int value) {22        int h = key % CAP;23        for (Node p = buckets[h]; p != null; p = p.next) {24            if (p.key == key) { p.val = value; return; }   // 已有就原地更新25        }26        buckets[h] = new Node(key, value, buckets[h]);     // 新结点头插，O(1)27    }28 29    public int get(int key) {30        for (Node p = buckets[key % CAP]; p != null; p = p.next) {31            if (p.key == key) return p.val;32        }33        return -1;34    }35 36    public void remove(int key) {37        int h = key % CAP;38        Node pre = null, p = buckets[h];39        while (p != null) {40            if (p.key == key) {41                if (pre == null) buckets[h] = p.next;   // 删的是链表头，桶直接指向下一个42                else pre.next = p.next;43                return;44            }45            pre = p;46            p = p.next;47        }48    }49}50 51/**52 * Your MyHashMap object will be instantiated and called as such:53 * MyHashMap obj = new MyHashMap();54 * obj.put(key,value);55 * int param_2 = obj.get(key);56 * obj.remove(key);57 */
题目

不使用任何内建的哈希表库设计一个哈希映射（HashMap）。

实现 MyHashMap 类：

  • MyHashMap() 用空映射初始化对象
  • void put(int key, int value) 向 HashMap 插入一个键值对 (key, value) 。如果 key 已经存在于映射中，则更新其对应的值 value 。
  • int get(int key) 返回特定的 key 所映射的 value ；如果映射中不包含 key 的映射，返回 -1 。
  • void remove(key) 如果映射中存在 key 的映射，则移除 key 和它所对应的 value 。

示例：

输入：
["MyHashMap", "put", "put", "get", "get", "put", "get", "remove", "get"]
[[], [1, 1], [2, 2], [1], [3], [2, 1], [2], [2], [2]]
输出：
[null, null, null, 1, -1, null, 1, null, -1]

解释：
MyHashMap myHashMap = new MyHashMap();
myHashMap.put(1, 1); // myHashMap 现在为 [[1,1]]
myHashMap.put(2, 2); // myHashMap 现在为 [[1,1], [2,2]]
myHashMap.get(1);    // 返回 1 ，myHashMap 现在为 [[1,1], [2,2]]
myHashMap.get(3);    // 返回 -1（未找到），myHashMap 现在为 [[1,1], [2,2]]
myHashMap.put(2, 1); // myHashMap 现在为 [[1,1], [2,1]]（更新已有的值）
myHashMap.get(2);    // 返回 1 ，myHashMap 现在为 [[1,1], [2,1]]
myHashMap.remove(2); // 删除键为 2 的数据，myHashMap 现在为 [[1,1]]
myHashMap.get(2);    // 返回 -1（未找到），myHashMap 现在为 [[1,1]]

提示：

  • 0 <= key, value <= 106
  • 最多调用 104 次 put、get 和 remove 方法
