枚举每对 (j, i)：公差 d=nums[i]-nums[j]，dp[i][d]=dp[j][d]+1，没有就新开一对长 2；答案取全表最大。

思路

  • dp[i][d]＝以下标 i 结尾、公差 d 的最长等差子序列；对每个 j < i 用 nums[j]→nums[i] 接链。
  • dp[j][d] 为 0 表示 j 结尾还没有公差 d 的链，这对 (j, i) 自己就是开头，长度 2。
  • 公差范围 [-500, 500]，整体 +500 存进 dp[i][0..1000]，省掉哈希表。
  • 答案就是全表最大值（至少为 2）；dp 按 j 从小到大填，接链时源数据一定已就绪。

最优解

时间复杂度 O(n²)，空间复杂度 O(n·1001)
1class Solution {2    public int longestArithSeqLength(int[] nums) {3        int n = nums.length, ans = 1;4        // dp[i][d+500]：以 i 结尾、公差 d 的最长等差子序列长度，0 表示还没有5        int[][] dp = new int[n][1001];6        for (int i = 1; i < n; i++) {7            for (int j = 0; j < i; j++) {8                int d = nums[i] - nums[j] + 500;9                // j 结尾没有公差 d 的链，就让 (j, i) 这对开头；有就接上去10                int len = dp[j][d] > 0 ? dp[j][d] + 1 : 2;11                if (len > dp[i][d]) dp[i][d] = len;12                if (len > ans) ans = len;13            }14        }15        return ans;16    }17}
题目

给定一个整数数组 nums，返回 nums 中最长等差子序列的长度。

注意：

  • 子序列 是由另一个数组删除一些（也可以不删除）元素后得到的数组，并且不改变剩余元素之间的相对顺序。
  • 如果对于所有 0 <= i < seq.length - 1，seq[i + 1] - seq[i] 的值都相同，则称序列 seq 为等差序列。

示例 1：

输入： nums = [3, 6, 9, 12]

输出： 4

解释： 整个数组本身就是一个公差为 3 的等差序列，因此最长等差子序列为 [3, 6, 9, 12]，长度为 4。

示例 2：

输入： nums = [9, 4, 7, 2, 10]

输出： 3

解释： 最长等差子序列为 [4, 7, 10]（下标分别为 1、2、4），公差为 3。不存在长度为 4 的等差子序列。

示例 3：

输入： nums = [20, 1, 15, 3, 10, 5, 8]

输出： 4

解释： 最长等差子序列为 [20, 15, 10, 5]（下标分别为 0、2、4、5），公差为 -5。

提示：

  • 2 <= nums.length <= 1500
  • 0 <= nums[i] <= 500
