556. 下一个更大元素 III

  • 中等
  • 频度 20
  • 双指针
  • 数学
  • 双指针
  • 字符串
  • 力扣已通过

同「下一个排列」：从右找第一个升阶位，右侧找刚大的交换，后缀反转成最小；long 防溢出。

思路

  • 转成 char[]；从右往左找第一个 a[i] < a[i+1]，找不到说明整体已是最大排列，返回 -1。
  • i 右边的后缀是非升序的：从右往左第一个 > a[i] 的就是「刚大」的数，交换它（增量最小）。
  • 交换后后缀仍是降序，反转成升序 = 后缀能排出的最小值，整体就是下一个排列。
  • 位数最多 10 个：long 解析后和 Integer.MAX_VALUE 比较，超界返回 -1。

图解

最优解

时间复杂度 O(d)，d 是十进制位数，空间复杂度 O(d)
1class Solution {2    public int nextGreaterElement(int n) {3        char[] a = String.valueOf(n).toCharArray();4        int i = a.length - 2;5        while (i >= 0 && a[i] >= a[i + 1]) i--;   // 从右找第一个 a[i] < a[i+1] 的位置6        if (i < 0) return -1;                     // 整体已是最大排列，无解7        int j = a.length - 1;8        while (a[j] <= a[i]) j--;                 // 后缀降序：从右第一个 > a[i] 的刚好大一点9        char t = a[i]; a[i] = a[j]; a[j] = t;     // 交换，i 左边的前缀保持不变10        for (int l = i + 1, r = a.length - 1; l < r; l++, r--) {   // 后缀反转成升序 = 最小11            t = a[l]; a[l] = a[r]; a[r] = t;12        }13        long v = Long.parseLong(new String(a));   // 结果可能超 int，用 long 接住再比14        return v > Integer.MAX_VALUE ? -1 : (int) v;15    }16}
题目

给你一个正整数 n ，请你找出符合条件的最小整数，其由重新排列 n中存在的每位数字组成，并且其值大于 n 。如果不存在这样的正整数，则返回 -1 。

注意 ，返回的整数应当是一个 32 位整数 ，如果存在满足题意的答案，但不是 32 位整数 ，同样返回 -1 。

示例 1：

输入：n = 12
输出：21

示例 2：

输入：n = 21
输出：-1

提示：

  • 1 <= n <= 231 - 1
