1456. 定长子串中元音的最大数目

定长滑窗：先数第一个窗口的元音数，之后每右移一格只「进格加、出格减」，不重数。

思路

  • 窗口长度固定是 k，右移一格时只有一格进窗、一格出窗，元音数增量维护即可。
  • vowel[] 查表 O(1) 判断元音；进格是元音 cnt++，出格是元音 cnt--。
  • 每步用 cnt 更新答案；答案最多是 k（全是元音的窗口）。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxVowels(String s, int k) {3        // 元音查表：26 个小写字母里只有 a e i o u 算4        boolean[] vowel = new boolean[128];5        for (char c : "aeiou".toCharArray()) vowel[c] = true;6 7        // 先数第一个窗口 [0, k) 里的元音个数8        int cnt = 0;9        for (int i = 0; i < k; i++) if (vowel[s.charAt(i)]) cnt++;10 11        int ans = cnt;12        // 之后每右移一格，只有一格进、一格出，增量维护13        for (int i = k; i < s.length(); i++) {14            if (vowel[s.charAt(i)]) cnt++;15            if (vowel[s.charAt(i - k)]) cnt--;16            ans = Math.max(ans, cnt);17        }18        return ans;19    }20}
题目

给你字符串 s 和整数 k 。

请返回字符串 s 中长度为 k 的单个子字符串中可能包含的最大元音字母数。

英文中的 元音字母 为（a, e, i, o, u）。

示例 1：

输入：s = "abciiidef", k = 3
输出：3
解释：子字符串 "iii" 包含 3 个元音字母。

示例 2：

输入：s = "aeiou", k = 2
输出：2
解释：任意长度为 2 的子字符串都包含 2 个元音字母。

示例 3：

输入：s = "leetcode", k = 3
输出：2
解释："lee"、"eet" 和 "ode" 都包含 2 个元音字母。

示例 4：

输入：s = "rhythms", k = 4
输出：0
解释：字符串 s 中不含任何元音字母。

示例 5：

输入：s = "tryhard", k = 4
输出：1

提示：

  • 1 <= s.length <= 10^5
  • s 由小写英文字母组成
  • 1 <= k <= s.length
