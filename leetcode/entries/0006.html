6. Z 字形变换

  • 中等
  • 频度 20
  • 模拟
  • 字符串
  • 力扣已通过

按行模拟：维护当前行号 r 和方向 step，到底就掉头向上、到顶再翻回来，每个字符收进它所在行。

思路

  • 每个字符 rows[r].append，然后走一步：r == numRows-1 时 step 翻成 -1，r == 0 时翻回 1。
  • numRows == 1 或 numRows >= s.length() 时永远不会拐弯，直接返回原串（前者还避免 r 越界）。
  • 最后把各行按顺序拼起来就是答案；每行的字符内部顺序天然正确。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(numRows)
1class Solution {2    public String convert(String s, int numRows) {3        // 单行不会拐弯；行数够长时整串竖着排，都直接返回原串4        if (numRows == 1 || numRows >= s.length()) return s;5        StringBuilder[] rows = new StringBuilder[numRows];6        for (int i = 0; i < numRows; i++) rows[i] = new StringBuilder();7        int r = 0, step = 1;   // step：1 向下、-1 向上8        for (char ch : s.toCharArray()) {9            rows[r].append(ch);10            if (r == numRows - 1) step = -1;   // 走到最底，掉头向上11            else if (r == 0) step = 1;         // 回到最顶，再向下12            r += step;13        }14        StringBuilder ans = new StringBuilder();15        for (StringBuilder row : rows) ans.append(row);16        return ans.toString();17    }18}
题目

将一个给定字符串 s 根据给定的行数 numRows ，以从上往下、从左到右进行 Z 字形排列。

比如输入字符串为 "PAYPALISHIRING" 行数为 3 时，排列如下：

P   A   H   N
A P L S I I G
Y   I   R

之后，你的输出需要从左往右逐行读取，产生出一个新的字符串，比如："PAHNAPLSIIGYIR"。

请你实现这个将字符串进行指定行数变换的函数：

string convert(string s, int numRows);

示例 1：

输入：s = "PAYPALISHIRING", numRows = 3
输出："PAHNAPLSIIGYIR"
示例 2： 
输入：s = "PAYPALISHIRING", numRows = 4
输出："PINALSIGYAHRPI"
解释：
P     I    N
A   L S  I G
Y A   H R
P     I

示例 3：

输入：s = "A", numRows = 1
输出："A"

提示：

  • 1 <= s.length <= 1000
  • s 由英文字母（小写和大写）、',' 和 '.' 组成
  • 1 <= numRows <= 1000
