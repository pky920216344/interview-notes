原地负号标记：值 v 在槽 v−1 翻负表示「出现过」；二次踩到同一槽即重复，扫完还是正数的槽即缺失。

思路

  • 把值 v 记到下标 v-1：第一次到就把 nums[v-1] 翻成负数。
  • 第二次走到同一个槽发现已是负数 → v 重复（dup）。
  • 扫一遍下标，还是正数的槽 i 说明 i+1 从没出现 → miss。
  • 全程只用数组自身的符号位，O(1) 额外空间；结尾把负号翻回去还原输入。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] findErrorNums(int[] nums) {3        int dup = 0, miss = 0;4        // 第一遍：值 v 记到槽 v-1（把槽翻成负数）；5        // 发现槽已经是负数，v 就是重复出现的那个6        for (int v : nums) {7            int slot = Math.abs(v) - 1;8            if (nums[slot] < 0) dup = Math.abs(v);9            else nums[slot] = -nums[slot];10        }11        // 第二遍：还是正数的槽从没被标记，槽号 + 1 就是丢的数12        for (int i = 0; i < nums.length; i++) {13            if (nums[i] > 0) miss = i + 1;14            else nums[i] = -nums[i];      // 顺手把数组还原15        }16        return new int[]{dup, miss};17    }18}
题目

集合 s 包含从 1 到 n 的整数。不幸的是，因为数据错误，导致集合里面某一个数字复制成了集合里面的另外一个数字的值，导致集合 丢失了一个数字 并且 有一个数字重复 。

给定一个数组 nums 代表了该集合发生错误后的结果。

请你找出重复出现的整数，再找到丢失的整数，将它们以数组的形式返回。

示例 1：

输入：nums = [1,2,2,4]
输出：[2,3]

示例 2：

输入：nums = [1,1]
输出：[1,2]

提示：

  • 2 <= nums.length <= 104
  • 1 <= nums[i] <= 104
