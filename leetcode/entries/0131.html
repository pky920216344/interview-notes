先用区间 DP 预处理 isPal[i][j]，再回溯枚举切割点：每段是回文就切下去，切到串尾收方案，撤销换切点。

思路

  • 预处理 isPal[i][j]：s[i]==s[j] 且（长度 < 2 或 isPal[i+1][j-1]）；i 倒着算保证内部先算好，之后 O(1) 查询。
  • 回溯：从 start 枚举 end，isPal[start][end] 为真就 path.add 这一段并递归 end+1。
  • start == s.length() 时收进 ans（要 new ArrayList<>(path) 拷贝）；返回前 path.remove 撤销这一刀再试下一个切点。
  • 重复利用 isPal 表，别在回溯里每次现判回文（那是 O(n³) 起步）。

时间复杂度 O(n·2^n)（输出本身就有指数多个），空间复杂度 O(n²)
1import java.util.*;2 3class Solution {4    public List<List<String>> partition(String s) {5        int n = s.length();6        // isPal[i][j]：s[i..j] 是否回文；i 倒着算，长区间看两头字符和内部小区间7        boolean[][] isPal = new boolean[n][n];8        for (int i = n - 1; i >= 0; i--) {9            for (int j = i; j < n; j++) {10                isPal[i][j] = s.charAt(i) == s.charAt(j) && (j - i < 2 || isPal[i + 1][j - 1]);11            }12        }13        List<List<String>> ans = new ArrayList<>();14        dfs(s, 0, isPal, new ArrayList<>(), ans);15        return ans;16    }17 18    // 从 start 开始切剩余部分；path 是前面已经切好的回文段19    private void dfs(String s, int start, boolean[][] isPal, List<String> path, List<List<String>> ans) {20        if (start == s.length()) {          // 切到串尾，path 就是一种方案21            ans.add(new ArrayList<>(path));22            return;23        }24        for (int end = start; end < s.length(); end++) {25            if (!isPal[start][end]) continue;26            path.add(s.substring(start, end + 1));   // s[start..end] 是回文，切下这一段27            dfs(s, end + 1, isPal, path, ans);28            path.remove(path.size() - 1);            // 撤销这一刀，换下一个切点29        }30    }31}
题目

给你一个字符串 s，请你将 s 分割成一些 子串，使每个子串都是 回文串 。返回 s 所有可能的分割方案。

示例 1：

输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]

示例 2：

输入：s = "a"
输出：[["a"]]

提示：

  • 1 <= s.length <= 16
  • s 仅由小写英文字母组成
