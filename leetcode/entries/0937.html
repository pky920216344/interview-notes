937. 重新排列日志文件

  • 简单
  • 频度 1
  • 模拟
  • 数组
  • 字符串
  • 排序
  • 待提交

先把日志按「第一个空格后是数字还是字母」分两桶；字母桶按内容（再标识符）排序，数字桶原样保序，字母在前拼接。

思路

  • 分拣看第一个空格后的首字符：Character.isDigit → 数字日志，否则字母日志。
  • 字母日志排序键 = 「内容，再标识符」：内容比较用 substring(第一个空格后)；并列时直接整串 compareTo 恰好就是「先标识符后内容」的顺序。
  • List.sort 是稳定排序，数字桶不参与排序即可天然保持相对顺序。
  • 最后 letters.addAll(digits) 一次拼接，字母日志全部在前。

图解

最优解

时间复杂度 O(m × n log n)（n 条日志、每条长 m），空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public String[] reorderLogFiles(String[] logs) {5        // 第一个空格后的首字符是数字 → 数字日志；否则字母日志6        List<String> letters = new ArrayList<>(), digits = new ArrayList<>();7        for (String log : logs) {8            if (Character.isDigit(log.charAt(log.indexOf(' ') + 1))) digits.add(log);9            else letters.add(log);10        }11        // 字母日志按「内容、再标识符」排：整体 compareTo 恰好就是这个顺序12        letters.sort((a, b) -> {13            int body = a.substring(a.indexOf(' ') + 1).compareTo(b.substring(b.indexOf(' ') + 1));14            return body != 0 ? body : a.compareTo(b);15        });16        letters.addAll(digits);       // 数字日志保持原有相对顺序17        return letters.toArray(new String[0]);18    }19}
题目

给你一个日志数组 logs。每条日志都是以空格分隔的字串，其第一个字为字母与数字混合的 标识符 。

有两种不同类型的日志：

  • 字母日志：除标识符之外，所有字均由小写字母组成
  • 数字日志：除标识符之外，所有字均由数字组成

请按下述规则将日志重新排序：

  • 所有 字母日志 都排在 数字日志 之前。
  • 字母日志 在内容不同时，忽略标识符后，按内容 字典顺序 排序；在内容相同时，按标识符排序。
  • 数字日志 应该保留原来的相对顺序。

返回日志的 最终 顺序。

示例 1：

输入：logs = ["dig1 8 1 5 1","let1 art can","dig2 3 6","let2 own kit dig","let3 art zero"]
输出：["let1 art can","let3 art zero","let2 own kit dig","dig1 8 1 5 1","dig2 3 6"]
解释：
字母日志的内容都不同，所以顺序为 "art can", "art zero", "own kit dig" 。
数字日志保留原来的相对顺序 "dig1 8 1 5 1", "dig2 3 6" 。

示例 2：

输入：logs = ["a1 9 2 3 1","g1 act car","zo4 4 7","ab1 off key dog","a8 act zoo"]
输出：["g1 act car","a8 act zoo","ab1 off key dog","a1 9 2 3 1","zo4 4 7"]

提示：

  • 1 <= logs.length <= 100
  • 3 <= logs[i].length <= 100
  • logs[i] 中，字与字之间都用 单个 空格分隔
  • 题目数据保证 logs[i] 都有一个标识符，并且在标识符之后至少存在一个字
