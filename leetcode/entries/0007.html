7. 整数反转

  • 简单
  • 频度 45
  • 数学
  • 数学
  • 本人已 AC

逐位弹出末位拼到 ans；拼接前先判断 ans 再乘 10 加 pop 会不会超出 int 范围，超了返回 0。

思路

  • 每轮 pop = x % 10、x /= 10、ans = ans * 10 + pop；x、pop、ans 始终同号，正数只可能上溢、负数只可能下溢。
  • 溢出判断放在拼接前：ans > (MAX − pop) / 10（或负数对称的 (MIN − pop) / 10）就返回 0。
  • 末尾的 0 弹出后自然被丢掉（120 → 021 → 21），不用特殊处理。

时间复杂度 O(log|x|)，空间复杂度 O(1)
1class Solution {2    public int reverse(int x) {3        // 逐位弹出末位拼到 ans：x、pop、ans 始终同号4        int ans = 0;5        while (x != 0) {6            int pop = x % 10;7            x /= 10;8            // 拼接前判断溢出：正数只可能上溢，负数只可能下溢9            if (pop > 0 && ans > (Integer.MAX_VALUE - pop) / 10) return 0;10            if (pop < 0 && ans < (Integer.MIN_VALUE - pop) / 10) return 0;11            ans = ans * 10 + pop;12        }13        return ans;14    }15}
题目

给你一个 32 位的有符号整数 x ，返回将 x 中的数字部分反转后的结果。

如果反转后整数超过 32 位的有符号整数的范围 [−231,  231 − 1] ，就返回 0。

假设环境不允许存储 64 位整数（有符号或无符号）。

示例 1：

输入：x = 123
输出：321

示例 2：

输入：x = -123
输出：-321

示例 3：

输入：x = 120
输出：21

示例 4：

输入：x = 0
输出：0

提示：

  • -231 <= x <= 231 - 1
