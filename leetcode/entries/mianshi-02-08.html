面试题 02.08. 环路检测

  • 中等
  • 频度 2
  • 链表
  • 哈希表
  • 链表
  • 双指针
  • 待提交

快慢指针找相遇；相遇后一个指针回表头，两个同速前进，再相遇处就是入环结点。

思路

  • 第一阶段：slow 每次 1 步、fast 每次 2 步；fast 落到 null 就无环，相遇就有环（且相遇点在环内）。
  • 第二阶段：ptr 回到 head，与 slow 同速每次 1 步，再次相遇的结点就是入环点。
  • 为什么对：fast 路程是 slow 的 2 倍，可推出「表头到入环点」的距离等于「相遇点绕回入环点」的距离。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1public class Solution {2    public ListNode detectCycle(ListNode head) {3        ListNode slow = head, fast = head;4        while (fast != null && fast.next != null) {5            slow = slow.next;6            fast = fast.next.next;7            if (slow == fast) {8                // 相遇点不一定入环：ptr 回表头，两个同速前进，9                // 再相遇处就是入环结点（推导见：路程差是圈长的整数倍）10                ListNode ptr = head;11                while (ptr != slow) {12                    ptr = ptr.next;13                    slow = slow.next;14                }15                return ptr;16            }17        }18        return null;19    }20}
题目

给定一个链表，如果它是有环链表，实现一个算法返回环路的开头节点。若环不存在，请返回 null。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。 为了表示给定链表中的环，我们使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。 如果 pos 是 -1，则在该链表中没有环。注意：pos 不作为参数进行传递，仅仅是为了标识链表的实际情况。

示例 1：

输入：head = [3,2,0,-4], pos = 1
输出：tail connects to node index 1
解释：链表中有一个环，其尾部连接到第二个节点。

示例 2：

输入：head = [1,2], pos = 0
输出：tail connects to node index 0
解释：链表中有一个环，其尾部连接到第一个节点。

示例 3：

输入：head = [1], pos = -1
输出：no cycle
解释：链表中没有环。
