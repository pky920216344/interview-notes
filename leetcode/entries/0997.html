997. 找到小镇的法官

  • 简单
  • 频度 3
  • 模拟
  • 图
  • 数组
  • 哈希表
  • 待提交

统计每个人的入度（被信任数）和出度（信任别人数）；入度 = n-1 且出度 = 0 的人就是法官，找不到返回 -1。

思路

  • 一遍扫 trust：[a, b] 让 a 出度 +1、b 入度 +1。
  • 法官条件：入度 n-1（其余人都信他）且出度 0（他不信任何人），两者缺一不可。
  • 满足条件的人至多一个（两人都入度 n-1 会互相矛盾），扫到直接返回；扫完没有就 -1。

时间复杂度 O(n + E)，空间复杂度 O(n)
1class Solution {2    public int findJudge(int n, int[][] trust) {3        int[] indeg = new int[n + 1];    // 入度：有多少人信任他4        int[] outdeg = new int[n + 1];   // 出度：他信任多少人5        for (int[] t : trust) {6            outdeg[t[0]]++;7            indeg[t[1]]++;8        }9        for (int p = 1; p <= n; p++) {10            if (indeg[p] == n - 1 && outdeg[p] == 0) return p;   // 全员信他且他不信人11        }12        return -1;13    }14}
题目

小镇里有 n 个人，按从 1 到 n 的顺序编号。传言称，这些人中有一个暗地里是小镇法官。

如果小镇法官真的存在，那么：

  1. 小镇法官不会信任任何人。
  2. 每个人（除了小镇法官）都信任这位小镇法官。
  3. 只有一个人同时满足属性 1 和属性 2 。

给你一个数组 trust ，其中 trust[i] = [ai, bi] 表示编号为 ai 的人信任编号为 bi 的人。

如果小镇法官存在并且可以确定他的身份，请返回该法官的编号；否则，返回 -1 。

示例 1：

输入：n = 2, trust = [[1,2]]
输出：2

示例 2：

输入：n = 3, trust = [[1,3],[2,3]]
输出：3

示例 3：

输入：n = 3, trust = [[1,3],[2,3],[3,1]]
输出：-1
 

提示：

  • 1 <= n <= 1000
  • 0 <= trust.length <= 104
  • trust[i].length == 2
  • trust 中的所有trust[i] = [ai, bi] 互不相同
  • ai != bi
  • 1 <= ai, bi <= n
