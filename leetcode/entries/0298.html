298. 二叉树最长连续序列

  • 中等
  • 频度 2
  • 深度优先搜索/递归
  • 树
  • 深度优先搜索
  • 二叉树
  • dp-on-trees
  • 未经力扣验证

自上而下 DFS，把 (父结点值, 当前链长) 一路传下去：孩子值 == 父值 + 1 就链长 +1，否则重新开链。

思路

  • 连续序列只能沿父→孩子方向走，所以一遍自上而下 DFS 就够，不需要从每个结点重启。
  • 递归参数带 (parentVal, len)：node.val == parentVal + 1 时 len+1，否则重置为 1——重置这步是关键。
  • 每访问一个结点就用 len 刷新全局 best；空树返回 0。

最优解

时间复杂度 O(n)，空间复杂度 O(H)
1class Solution {2    private int best;3 4    public int longestConsecutive(TreeNode root) {5        best = 0;   // 顺便防同一实例被多次调用时残留旧答案6        dfs(root, 0, 0);7        return best;8    }9 10    // 自上而下传 (父结点值, 当前链长)：孩子值 == 父值 + 1 就接上，否则重新开链11    private void dfs(TreeNode node, int parentVal, int len) {12        if (node == null) return;13        len = len > 0 && node.val == parentVal + 1 ? len + 1 : 1;14        best = Math.max(best, len);15        dfs(node.left, node.val, len);16        dfs(node.right, node.val, len);17    }18}
