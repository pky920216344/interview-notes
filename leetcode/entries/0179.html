179. 最大数

自定义降序：比较 a+b 和 b+a 两种拼法，谁拼出来大谁在前；排完按序拼接，全 0 时只输出 "0"。

思路

  • 每个数转成字符串，比较 a + b 与 b + a：拼接结果大的排前面（降序）。
  • 只比数值大小会出错：比如 30 > 3，但 330 > 303，所以 3 要排在 30 前面；这个比较规则满足传递性，排序结果就是全局最大。
  • 排完按顺序拼接就是答案；注意 ss[0] == "0"（全是 0）时只返回 "0"，比如 [0,0]。
  • 数字可达 10^9，所以整体用字符串拼，不转数值比较。

1import java.util.*;2 3class Solution {4    public String largestNumber(int[] nums) {5        // 先全部转成字符串，按「拼起来谁大」排6        String[] ss = new String[nums.length];7        for (int i = 0; i < nums.length; i++) ss[i] = String.valueOf(nums[i]);8        // a+b 和 b+a 谁大谁在前（降序）9        Arrays.sort(ss, (a, b) -> (b + a).compareTo(a + b));10        // 排最前的还是 "0"：全是 0，只留一个 011        if (ss[0].equals("0")) return "0";12        StringBuilder sb = new StringBuilder();13        for (String s : ss) sb.append(s);14        return sb.toString();15    }16}
题目

给定一组非负整数 nums，重新排列每个数的顺序（每个数不可拆分）使之组成一个最大的整数。

注意：输出结果可能非常大，所以你需要返回一个字符串而不是整数。

示例 1：

输入：nums = [10,2]
输出："210"

示例 2：

输入：nums = [3,30,34,5,9]
输出："9534330"

提示：

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 109
