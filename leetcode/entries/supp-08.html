补充题8. 计算数组的小和

  • 中等
  • 频度 10
  • 分治
  • 未经力扣验证

归并排序顺带计数：取左半元素时它比右半剩下的所有数都小，一次加上它 ×(右半剩余个数)，相等时取右半不计数。

思路

  • 小和是逆序对的镜像问题：统计所有 i<j 且 a[i]<a[j] 对里的 a[i] 之和，归并排序一趟完成。
  • 归并中 aux[i] < aux[j] 时取左边：aux[i] 比右半剩余的 hi-j+1 个数都小，一次加 aux[i] × (hi-j+1)。
  • 相等（或左更大）时取右边：相等对不计小和，取左边会重复计数（和逆序对的条件正好相反）。
  • 总和可能爆 int，用 long 累加。

时间复杂度 O(n log n)，空间复杂度 O(n)
1class Solution {2    private long sum;   // 小和总数，归并过程中累加3 4    public long smallSum(int[] nums) {5        sum = 0;6        int[] a = nums.clone();   // 不动调用方的数组7        sort(a, new int[a.length], 0, a.length - 1);8        return sum;9    }10 11    // 归并排序 [lo, hi]，顺带把「左元素 < 右元素」的每个左元素累进 sum12    private void sort(int[] a, int[] aux, int lo, int hi) {13        if (lo >= hi) return;14        int mid = (lo + hi) >>> 1;15        sort(a, aux, lo, mid);16        sort(a, aux, mid + 1, hi);17        merge(a, aux, lo, mid, hi);18    }19 20    private void merge(int[] a, int[] aux, int lo, int mid, int hi) {21        for (int k = lo; k <= hi; k++) aux[k] = a[k];22        int i = lo, j = mid + 1;23        for (int k = lo; k <= hi; k++) {24            if (i > mid) a[k] = aux[j++];25            else if (j > hi) a[k] = aux[i++];26            else if (aux[i] < aux[j]) {27                // 左元素比右半剩下的所有数都小：一次加上 aux[i] × (hi-j+1)28                sum += (long) aux[i] * (hi - j + 1);29                a[k] = aux[i++];30            } else {31                a[k] = aux[j++];   // 相等或左更大时取右边：相等对不计小和32            }33        }34    }35}
