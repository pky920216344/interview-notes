1099. 小于 K 的两数之和

  • 简单
  • 频度 3
  • 双指针
  • 数组
  • 双指针
  • 二分查找
  • 排序
  • 未经力扣验证

排序后首尾双指针：和 < k 记下答案并右移小端，和 ≥ k 左移大端，扫一遍取最大和。

思路

  • 排序后 l 指最小、r 指最大：sum = nums[l] + nums[r]。
  • sum < k：这是 l 能配到的最大和，记入 ans 后 l++（换大一点的搭档）。
  • sum ≥ k：r 太大配谁都不行，r--。
  • 无任何搭配时返回 -1（ans 的初值）。

时间复杂度 O(n log n)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int twoSumLessThanK(int[] nums, int k) {5        Arrays.sort(nums);6        int l = 0, r = nums.length - 1, ans = -1;7        while (l < r) {8            int sum = nums[l] + nums[r];9            if (sum < k) {10                ans = Math.max(ans, sum);   // 和能小于 k：这是以 l 为小端的最大搭配11                l++;12            } else {13                r--;   // 和太大：最大的数配谁都不行，换小一号14            }15        }16        return ans;17    }18}
