1120. 子树的最大平均值

  • 中等
  • 频度 5
  • 深度优先搜索/递归
  • 树
  • 深度优先搜索
  • 二叉树
  • 未经力扣验证

后序 DFS 给每个子树算出 (和, 结点数)，就地算均值并用 double 比较更新最大值。

思路

  • 每棵子树的均值 = 子树和 ÷ 结点数；后序遍历把左右孩子的 (sum, cnt) 相加再加自己，一次 DFS 全算完。
  • 算出均值立刻 best = max(best, sum / cnt)——均值必须用 double 比较，整除会算错。
  • best 初始化成 -∞ 而不是 0：结点值可能全为负，均值全是负数。
  • 会员题：本地验证通过即可，不提交力扣。

时间复杂度 O(n)，空间复杂度 O(h)（递归栈）
1class Solution {2    private double best = 0;3 4    public double maximumAverageSubtree(TreeNode root) {5        if (root == null) return 0;6        best = Double.NEGATIVE_INFINITY;   // 均值可能为负，不能初始化成 07        dfs(root);8        return best;9    }10 11    // 返回 {子树和, 结点数}：后序把左右子树的这两样汇总上来，顺手更新答案12    private long[] dfs(TreeNode node) {13        if (node == null) return new long[]{0, 0};14        long[] l = dfs(node.left), r = dfs(node.right);15        long sum = l[0] + r[0] + node.val, cnt = l[1] + r[1] + 1;16        // 均值直接用 double 比较（整除会丢精度）17        best = Math.max(best, (double) sum / cnt);18        return new long[]{sum, cnt};19    }20}
