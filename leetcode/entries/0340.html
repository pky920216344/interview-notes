340. 至多包含 K 个不同字符的最长子串

  • 困难
  • 频度 14
  • 滑动窗口
  • 哈希表
  • 哈希表
  • 字符串
  • 滑动窗口
  • 未经力扣验证

滑窗 + 字符计数表：右扩一格后不同字符数超 k，就从左端收缩到刚好 k 种，随时更新最长。

思路

  • 窗口 [left, right] 里 cnt.size()（不同字符数）始终 ≤ k；右端每进一格先计数 +1 再检查。
  • 超 k：左端字符计数 −1，减到 0 就整个从表里删掉，直到 cnt.size() 回到 k。
  • 每步用 right - left + 1 更新最长长度；k = 0 时任何非空子串都不合法，直接返回 0。

时间复杂度 O(n)，空间复杂度 O(k)
1import java.util.*;2 3class Solution {4    public int lengthOfLongestSubstringKDistinct(String s, int k) {5        if (k == 0) return 0;6        // cnt：窗口内每个字符的出现次数，size 就是不同字符数7        Map<Character, Integer> cnt = new HashMap<>();8        int ans = 0, left = 0;9        for (int right = 0; right < s.length(); right++) {10            cnt.merge(s.charAt(right), 1, Integer::sum);11            // 不同字符超了 k 种：左端一直缩到刚好回到 k 种12            while (cnt.size() > k) {13                char d = s.charAt(left);14                if (cnt.merge(d, -1, Integer::sum) == 0) cnt.remove(d);15                left++;16            }17            ans = Math.max(ans, right - left + 1);18        }19        return ans;20    }21}
