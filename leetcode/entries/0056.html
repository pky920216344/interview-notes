56. 合并区间

  • 中等
  • 频度 250
  • 扫描线/排序
  • 数组
  • 排序
  • quicksort
  • 力扣已通过

按左端点排序，能合并的区间一定挨在一起；一次扫描，和结果里最后一段相交就延长它的右端点，不相交就另开一段。

思路

  • 先按左端点排序；res 里最后一段 last 就是「正在合并的区间」。
  • cur[0] > last[1]（cur 整个在 last 右边）就不相交，res.add(cur) 另开一段；端点相接（cur[0] == last[1]）也算相交，所以必须是严格大于。
  • 相交时右端点必须取 Math.max(last[1], cur[1])：cur 可能被 last 整个包住（比如 [1,6] 和 [4,5]），直接赋成 cur[1] 会把右端点缩回去。
  • 扫完 res 就是答案，不用再收尾。

1import java.util.*;2 3class Solution {4    public int[][] merge(int[][] intervals) {5        // 按左端点排序，能合并的区间一定挨在一起6        Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));7        List<int[]> res = new ArrayList<>();8        for (int[] cur : intervals) {9            // last：结果里的最后一段，还没有就是 null10            int[] last = res.isEmpty() ? null : res.get(res.size() - 1);11            if (last == null || cur[0] > last[1]) {12                // 不相交，另开一段13                res.add(cur);14            } else {15                // 相交（端点相接也算）：右端点取较大的，16                // 因为 cur 可能被 last 整个包住17                last[1] = Math.max(last[1], cur[1]);18            }19        }20        return res.toArray(new int[0][]);21    }22}
题目

以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi] 。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

示例 1：

输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].

示例 2：

输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。

示例 3：

输入：intervals = [[4,7],[1,4]]
输出：[[1,7]]
解释：区间 [1,4] 和 [4,7] 可被视为重叠区间。

提示：

  • 1 <= intervals.length <= 104
  • intervals[i].length == 2
  • 0 <= starti <= endi <= 104
