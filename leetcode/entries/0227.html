一个栈存已定号的项：读到下一个运算符（或末尾）时上一个才生效——+ 压栈、- 压负数、乘除当场和栈顶结算。

思路

  • num 逐位拼出完整数字；空格不是数字也不在四个运算符里，自然被跳过。
  • op 存「上一个运算符」，开局视为 '+'；读到新的 +-*/ 或扫到末尾（i == n-1，末尾是空格也触发）时，op 才对刚读完的 num 生效。
  • 生效规则：+ 压 num，- 压 -num；* / 弹栈顶算完压回——乘除的优先级就这样被「当场结算」。
  • 最后栈里只剩加号连接的项，直接求和。

1import java.util.*;2 3class Solution {4    public int calculate(String s) {5        // 栈里存「已定号的项」：+ 压正数、- 压负数，乘除和栈顶先算完再压回6        Deque<Integer> stack = new ArrayDeque<>();7        int num = 0;8        char op = '+';                       // 上一个运算符，开局当作 '+'9        int n = s.length();10        for (int i = 0; i < n; i++) {11            char c = s.charAt(i);12            if (c >= '0' && c <= '9') {13                num = num * 10 + (c - '0');  // 完整读多位数字14            }15            if (c == '+' || c == '-' || c == '*' || c == '/' || i == n - 1) {16                // 碰到下一个运算符（或扫到末尾），上一个运算符才生效17                switch (op) {18                    case '+': stack.push(num); break;19                    case '-': stack.push(-num); break;20                    case '*': stack.push(stack.pop() * num); break;21                    case '/': stack.push(stack.pop() / num); break;22                }23                op = c;24                num = 0;25            }26        }27        // 栈里全是加号连接的项，求和即可28        int ans = 0;29        for (int v : stack) ans += v;30        return ans;31    }32}
题目

给你一个字符串表达式 s ，请你实现一个基本计算器来计算并返回它的值。

整数除法仅保留整数部分。

你可以假设给定的表达式总是有效的。所有中间结果将在 [-231, 231 - 1] 的范围内。

注意：不允许使用任何将字符串作为数学表达式计算的内置函数，比如 eval() 。

示例 1：

输入：s = "3+2*2"
输出：7

示例 2：

输入：s = " 3/2 "
输出：1

示例 3：

输入：s = " 3+5 / 2 "
输出：5

提示：

  • 1 <= s.length <= 3 * 105
  • s 由整数和算符 ('+', '-', '*', '/') 组成，中间由一些空格隔开
  • s 表示一个有效表达式
  • 表达式中的所有整数都是非负整数，且在范围 [0, 231 - 1] 内
  • 题目数据 保证 答案是一个 32-bit 整数
