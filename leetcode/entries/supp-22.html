补充题22. IP地址与整数的转换

  • 中等
  • 频度 18
  • 位运算
  • 未经力扣验证

IP 四段各占一个字节：并入用左移 8 位（×256），取出右移 24/16/8/0 位再 & 255，整数用 long 存。

思路

  • toInt：逐段 v = v << 8 | 段值，四段并成一个 32 位无符号整数；用 long 存。
  • toIp：从高到低 v >>> 24/16/8/0 再 & 255 取出四段，用 . 连接。
  • 255.255.255.255 = 4294967295 超出 int，所以整数一律用 long。
  • 移位并入和右移取字节互为逆操作，往返转换无损。

1class Solution {2    // IPv4 → 32 位无符号整数：四段各占一个字节，逐段并入（左移 8 位腾低位）3    public long toInt(String ip) {4        long v = 0;5        for (String seg : ip.split("\\.")) {6            v = v << 8 | Integer.parseInt(seg);7        }8        return v;9    }10 11    // 整数 → IPv4：从最高字节开始，无符号右移 24/16/8/0 位再截低 8 位12    public String toIp(long v) {13        StringBuilder sb = new StringBuilder();14        for (int shift = 24; shift >= 0; shift -= 8) {15            if (shift < 24) sb.append('.');16            sb.append((v >>> shift) & 255);17        }18        return sb.toString();19    }20}
