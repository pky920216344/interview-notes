962. 最大宽度坡

  • 中等
  • 频度 1
  • 单调栈
  • 栈
  • 数组
  • 双指针
  • 单调栈
  • 待提交

单调递减栈存候选左端点；从右往左扫，栈顶值 ≤ 当前值就配成一对坡并弹栈，宽度 j−i 取最大。

思路

  • 从左往右建栈：只把「比栈顶还小」的下标压栈——更大的值当左端点只会更窄，不必记。
  • 从右往左扫 j：j 越靠右宽度越大，所以栈顶（最早的下标、最小的值）一旦 ≤ nums[j] 就能配出它这辈子最宽的坡，放心弹出。
  • 栈空或配不上就继续左移 j；全程取最大宽度。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int maxWidthRamp(int[] nums) {5        // 栈里存「候选左端点」下标：从底到顶值严格递减（比栈顶大的不可能是更优左端点）6        Deque<Integer> stack = new ArrayDeque<>();7        for (int i = 0; i < nums.length; i++)8            if (stack.isEmpty() || nums[i] < nums[stack.peek()]) stack.push(i);9        int ans = 0;10        // 从右往左：j 越早遇到，宽度越大；栈顶值 ≤ nums[j] 就配成一对坡并弹掉11        for (int j = nums.length - 1; j >= 0; j--)12            while (!stack.isEmpty() && nums[stack.peek()] <= nums[j])13                ans = Math.max(ans, j - stack.pop());14        return ans;15    }16}
题目

给定一个整数数组 A，坡是元组 (i, j)，其中  i < j 且 A[i] <= A[j]。这样的坡的宽度为 j - i。

找出 A 中的坡的最大宽度，如果不存在，返回 0 。

示例 1：

输入：[6,0,8,2,1,5]
输出：4
解释：
最大宽度的坡为 (i, j) = (1, 5): A[1] = 0 且 A[5] = 5.

示例 2：

输入：[9,8,1,0,1,9,4,0,4,1]
输出：7
解释：
最大宽度的坡为 (i, j) = (2, 9): A[2] = 1 且 A[9] = 1.

提示：

  1. 2 <= A.length <= 50000
  2. 0 <= A[i] <= 50000
