每个下标挂一个「版本号 → 值」的 TreeMap：set 只写当前版本（覆盖），get 用 floorEntry 找 ≤ snap_id 的最近版本。

思路

  • 不复制数组：snap() 只把版本号 +1 返回旧值，快照本身零成本。
  • set(index, val) 记成 版本号 → 值；同一版本内重复 set 走 TreeMap 覆盖写，不堆积重复键。
  • get(index, snap_id) = 在该下标的版本表里找 ≤ snap_id 的最大版本（floorEntry），表空返回初始值 0。
  • 空间只与写入次数成正比，与 length 和快照数无关——这正是这题的核心收益。

时间复杂度 set/snap O(1)，get O(log 写入次数)，空间复杂度 O(set 次数)
1import java.util.*;2 3class SnapshotArray {4    // 每个下标一个 TreeMap：版本号 -> 值；同版本重复 set 直接覆盖5    private final List<TreeMap<Integer, Integer>> a = new ArrayList<>();6    private int snapId = 0;   // 当前版本号，也是下一次 snap 的返回值7 8    public SnapshotArray(int length) {9        for (int i = 0; i < length; i++) a.add(new TreeMap<>());10    }11 12    public void set(int index, int val) {13        // 只写当前版本这一个键，历史版本不动14        a.get(index).put(snapId, val);15    }16 17    public int snap() {18        return snapId++;   // 先返回旧编号再自增，数组本身不用复制19    }20 21    public int get(int index, int snap_id) {22        // 快照 snap_id 的值 = 版本号 ≤ snap_id 的最近一次写入；没有就是初始值 023        Map.Entry<Integer, Integer> e = a.get(index).floorEntry(snap_id);24        return e == null ? 0 : e.getValue();25    }26}
题目

实现支持下列接口的「快照数组」- SnapshotArray：

  • SnapshotArray(int length) - 初始化一个与指定长度相等的 类数组 的数据结构。初始时，每个元素都等于 0。
  • void set(index, val) - 会将指定索引 index 处的元素设置为 val。
  • int snap() - 获取该数组的快照，并返回快照的编号 snap_id（快照号是调用 snap() 的总次数减去 1）。
  • int get(index, snap_id) - 根据指定的 snap_id 选择快照，并返回该快照指定索引 index 的值。

示例：

输入：["SnapshotArray","set","snap","set","get"]
     [[3],[0,5],[],[0,6],[0,0]]
输出：[null,null,0,null,5]
解释：
SnapshotArray snapshotArr = new SnapshotArray(3); // 初始化一个长度为 3 的快照数组
snapshotArr.set(0,5);  // 令 array[0] = 5
snapshotArr.snap();  // 获取快照，返回 snap_id = 0
snapshotArr.set(0,6);
snapshotArr.get(0,0);  // 获取 snap_id = 0 的快照中 array[0] 的值，返回 5

提示：

  • 1 <= length <= 50000
  • 题目最多进行50000 次set，snap，和 get的调用 。
  • 0 <= index < length
  • 0 <= snap_id < 我们调用 snap() 的总次数
  • 0 <= val <= 10^9
