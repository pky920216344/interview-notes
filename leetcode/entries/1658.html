1658. 将 x 减到 0 的最小操作数

反向转化：把「删两端凑 x」变成「中间留一段和为 total−x 的最长子数组」；元素全为正，滑窗取最长即可。

思路

  • 删掉的是前缀加后缀，留下的就是一段连续子数组；它越长删得越少，答案 = n − 最长保留长度。
  • 目标和 target = total − x；target < 0（全删光都不够）直接返回 −1。
  • 元素全为正 → 标准滑窗：和超过 target 缩左端，恰好等于时用窗口长度更新最长。
  • target = 0（x 等于总和）时窗口取空、长度 0，答案 = n（全删光），公式自然覆盖。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int minOperations(int[] nums, int x) {3        // 转化：中间留一段和为 total-x 的最长子数组，删的次数 = n - 该长度4        int n = nums.length;5        long target = 0;6        for (int v : nums) target += v;7        target -= x;8        // 全删光都不够 x，无解9        if (target < 0) return -1;10        long sum = 0;11        int left = 0, best = -1;12        for (int right = 0; right < n; right++) {13            sum += nums[right];14            // 元素全为正，窗口和超了就缩左端15            while (sum > target) sum -= nums[left++];16            if (sum == target) best = Math.max(best, right - left + 1);17        }18        // target=0 时窗口取空，best=0，答案 n（全删光）19        return best < 0 ? -1 : n - best;20    }21}
题目

给你一个整数数组 nums 和一个整数 x 。每一次操作时，你应当移除数组 nums 最左边或最右边的元素，然后从 x 中减去该元素的值。请注意，需要 修改 数组以供接下来的操作使用。

如果可以将 x 恰好 减到 0 ，返回 最小操作数 ；否则，返回 -1 。

示例 1：

输入：nums = [1,1,4,2,3], x = 5
输出：2
解释：最佳解决方案是移除后两个元素，将 x 减到 0 。

示例 2：

输入：nums = [5,6,7,8,9], x = 4
输出：-1

示例 3：

输入：nums = [3,2,20,1,1,3], x = 10
输出：5
解释：最佳解决方案是移除后三个元素和前两个元素（总共 5 次操作），将 x 减到 0 。

提示：

  • 1 <= nums.length <= 105
  • 1 <= nums[i] <= 104
  • 1 <= x <= 109
