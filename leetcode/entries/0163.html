163. 缺失的区间

  • 中等
  • 频度 1
  • 模拟
  • 数组
  • 未经力扣验证

哨兵扫描：把 lower−1、upper+1 当虚拟端点，扫相邻两数，差 ≥ 2 中间的空档就是缺失区间。

思路

  • prev 从 lower−1 起步，cur 依次取每个 nums[i]，最后补一个 upper+1 哨兵收尾。
  • 相邻两数差 cur − prev ≥ 2 说明 [prev+1, cur−1] 整段缺失，直接收进答案。
  • 端点 ±1 用 long 算：lower/upper 可能是 int 极值，加减一会溢出。
  • 空数组时两哨兵相邻，天然输出整段 [lower, upper]。

时间复杂度 O(n)，空间复杂度 O(1)（不算输出）
1import java.util.*;2 3class Solution {4    public List<List<Integer>> findMissingRanges(int[] nums, int lower, int upper) {5        List<List<Integer>> ans = new ArrayList<>();6        // prev 是已覆盖到的上一个数；lower-1 和 upper+1 当哨兵，用 long 防 ±1 溢出7        long prev = (long) lower - 1;8        for (int i = 0; i <= nums.length; i++) {9            // cur 依次取每个数，最后取 upper+1 哨兵收尾10            long cur = i < nums.length ? nums[i] : (long) upper + 1;11            if (cur - prev >= 2) {12                ans.add(Arrays.asList((int) (prev + 1), (int) (cur - 1)));13            }14            prev = cur;15        }16        return ans;17    }18}
