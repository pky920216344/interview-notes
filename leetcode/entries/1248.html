前缀奇数计数配对：右端点凑到 odd 个奇数时，答案加 cnt[odd−k]。

思路

  • 子数组 [l, r] 恰含 k 个奇数 ⇔ 前缀奇数计数 odd(r) − odd(l−1) = k；固定右端 r，合法左端就是计数为 odd(r) − k 的那些前缀。
  • cnt[c] 边扫边记「奇数个数为 c 的前缀」出现过几次，每步先 ans += cnt[odd − k] 再登记当前前缀。
  • cnt[0] = 1 代表空前缀：让从下标 0 开始、自己就恰含 k 个奇数的子数组也能配上。
  • 奇偶判断用 x & 1，不用取模；负数不存在（题面保证 nums[i] ≥ 1）。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int numberOfSubarrays(int[] nums, int k) {3        // cnt[c]：奇数个数恰为 c 的前缀出现过几次（空前缀算 0 个奇数）4        int[] cnt = new int[nums.length + 1];5        cnt[0] = 1;6        int odd = 0, ans = 0;7        for (int x : nums) {8            odd += x & 1;9            // 右端点定在这：左端选「恰有 odd-k 个奇数」的前缀，都合法10            if (odd >= k) ans += cnt[odd - k];11            cnt[odd]++;12        }13        return ans;14    }15}
题目

给你一个整数数组 nums 和一个整数 k。如果某个连续子数组中恰好有 k 个奇数数字，我们就认为这个子数组是「优美子数组」。

请返回这个数组中 「优美子数组」 的数目。

示例 1：

输入：nums = [1,1,2,1,1], k = 3
输出：2
解释：包含 3 个奇数的子数组是 [1,1,2,1] 和 [1,2,1,1] 。

示例 2：

输入：nums = [2,4,6], k = 1
输出：0
解释：数列中不包含任何奇数，所以不存在优美子数组。

示例 3：

输入：nums = [2,2,2,1,2,2,1,2,2,2], k = 2
输出：16

提示：

  • 1 <= nums.length <= 50000
  • 1 <= nums[i] <= 10^5
  • 1 <= k <= nums.length
