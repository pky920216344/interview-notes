255. 验证二叉搜索树的前序遍历序列

递减栈 + 下界：遇到比栈顶大的数就把小于它的依次弹出（左子树结束），最后弹出的值成为下界；之后任何数小于下界即非法。

思路

  • 前序里一段严格递减就是一路向左，依次入栈；遇到更大的数 x，说明某个左子树结束、开始进入右子树。
  • 把所有 < x 的栈顶弹出，最后弹出的值 lower 是「当前右子树的根」：右子树里所有数都必须 > lower。
  • 后面再遇到 < lower 的数直接判非法；栈里剩下的就是还没确定右子树的祖先。

1import java.util.*;2 3class Solution {4    public boolean verifyPreorder(int[] preorder) {5        Deque<Integer> stack = new ArrayDeque<>();6        // lower：最近一次弹出的值。它右子树里的所有数都必须严格大于它7        int lower = Integer.MIN_VALUE;8        for (int x : preorder) {9            // 比 lower 还小，说明落进了某个已弹出的右子树里，非法10            if (x < lower) return false;11            // 递减栈：x 比栈顶大，说明某个左子树结束，依次弹出并把下界抬高12            while (!stack.isEmpty() && stack.peek() < x) lower = stack.pop();13            stack.push(x);14        }15        return true;16    }17}
