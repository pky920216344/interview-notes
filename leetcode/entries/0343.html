343. 整数拆分

DP：dp[i] 是把 i 拆成至少两个正整数的最大乘积；枚举第一段 j，剩下的不拆、继续拆两者取大。

思路

  • dp[i]：把 i 拆成至少两个正整数的最大乘积，答案就是 dp[n]。
  • 枚举第一段 j：剩余 i-j 不再拆是 j*(i-j)，继续拆是 j*dp[i-j]，两种都要比（dp[7] 靠 2*dp[5]=12 赢过不拆的 2*5）。
  • dp[2]=1 由转移自然算出（i=2, j=1），不用单独赋初值；dp[0]、dp[1] 用不上。

最优解

时间复杂度 O(n²)，空间复杂度 O(n)
1class Solution {2    public int integerBreak(int n) {3        // dp[i]：把 i 拆成至少两个正整数后能得到的最大乘积4        int[] dp = new int[n + 1];5        for (int i = 2; i <= n; i++) {6            // 枚举第一段 j：剩下的 i-j 要么不再拆、要么继续拆7            for (int j = 1; j < i; j++) {8                dp[i] = Math.max(dp[i], Math.max(j * (i - j), j * dp[i - j]));9            }10        }11        return dp[n];12    }13}
题目

给定一个正整数 n ，将其拆分为 k 个 正整数 的和（ k >= 2 ），并使这些整数的乘积最大化。

返回 你可以获得的最大乘积 。

示例 1:

输入: n = 2
输出: 1
解释: 2 = 1 + 1, 1 × 1 = 1。

示例 2:

输入: n = 10
输出: 36
解释: 10 = 3 + 3 + 4, 3 × 3 × 4 = 36。

提示:

  • 2 <= n <= 58
