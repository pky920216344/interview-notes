215. 数组中的第K个最大元素

  • 中等
  • 频度 608
  • 分治
  • 数组
  • 分治
  • 快速选择
  • 排序
  • 堆（优先队列）
  • 力扣已通过

快速选择：随机选基准，三向划分成「小于 / 等于 / 大于」三段，只钻进含目标下标的那一段，平均 O(n)。

思路

  • 第 k 大就是升序排好后下标 n - k 的数，记作 target；不用真排序，只要把它「选」出来。
  • 每轮随机选一个 pivot，三向划分：[lo, lt) 小于，[lt, gt] 等于，(gt, hi] 大于。
  • target < lt 就只留左段（hi = lt - 1），target > gt 就只留右段（lo = gt + 1），落在中间段直接返回 pivot。
  • 必须三向：大量重复值时两向划分每轮只缩小一点，会退化成 O(n^2)；随机基准让期望是 O(n)。

1import java.util.*;2 3class Solution {4    public int findKthLargest(int[] nums, int k) {5        Random rnd = new Random();6        // 第 k 大 = 升序排好后下标为 n - k 的数7        int target = nums.length - k;8        int lo = 0, hi = nums.length - 1;9        while (true) {10            // 随机选基准，避免有序数组退化11            int pivot = nums[lo + rnd.nextInt(hi - lo + 1)];12            // 三向划分，i 从左往右扫：13            // [lo, lt) 小于，[lt, i) 等于，(gt, hi] 大于14            int lt = lo, i = lo, gt = hi;15            while (i <= gt) {16                if (nums[i] < pivot) swap(nums, lt++, i++);17                else if (nums[i] > pivot) swap(nums, i, gt--);18                else i++;19            }20            // target 落在哪一段，就只在那一段继续找21            if (target < lt) hi = lt - 1;22            else if (target > gt) lo = gt + 1;23            else return pivot;24        }25    }26 27    private void swap(int[] a, int i, int j) {28        int t = a[i];29        a[i] = a[j];30        a[j] = t;31    }32}
题目

给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

请注意，你需要找的是数组排序后的第 k 个最大的元素，而不是第 k 个不同的元素。

你必须设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1:

输入: [3,2,1,5,6,4], k = 2
输出: 5

示例 2:

输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4

提示：

  • 1 <= k <= nums.length <= 105
  • -104 <= nums[i] <= 104
