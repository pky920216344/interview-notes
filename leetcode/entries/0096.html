卡特兰数 DP：枚举根的排名 j，种数 = 左子树 dp[j-1] 种 × 右子树 dp[i-j] 种，累加求和。

思路

  • dp[i]：i 个结点能组成的 BST 种数；值只用「相对大小」，具体是哪几个数不重要。
  • 枚举根是第 j 小的结点：左边必然是 j-1 个、右边 i-j 个，两边独立选形，相乘。
  • dp[i] = Σ dp[j-1] × dp[i-j]，j 从 1 到 i；dp[0] = 1（空树）是基石，别漏。
  • n ≤ 19，答案 1767263190 还在 int 范围内。

最优解

时间复杂度 O(n^2)，空间复杂度 O(n)
1class Solution {2    public int numTrees(int n) {3        // dp[i]：i 个结点能组成的 BST 种数（卡特兰数）4        int[] dp = new int[n + 1];5        dp[0] = 1;  // 空树也算一种，是整个递推的基石6        for (int i = 1; i <= n; i++) {7            // 枚举根的排名 j：左边 j-1 个结点，右边 i-j 个结点8            for (int j = 1; j <= i; j++) dp[i] += dp[j - 1] * dp[i - j];9        }10        return dp[n];11    }12}
题目

给你一个整数 n ，求恰由 n 个节点组成且节点值从 1 到 n 互不相同的 二叉搜索树 有多少种？返回满足题意的二叉搜索树的种数。

示例 1：

输入：n = 3
输出：5

示例 2：

输入：n = 1
输出：1

提示：

  • 1 <= n <= 19
