426. 将二叉搜索树转化为排序的双向链表

  • 二叉树
  • 双向链表

BST 中序递归：访问 cur 时和上一个访问的 last 互连前驱后继，最后首尾连成环，返回最左结点。

思路

  • 中序遍历 BST 得到升序序列：维护 last（上一个访问的结点），访问 cur 时 last.right = cur、cur.left = last 双向互连。
  • 第一个（最左）访问的结点没有前驱，记为表头 first，也是最终返回值。
  • 遍历完后 last 是最大结点：last.right = first、first.left = last 首尾成环。
  • 进场先把 first、last 复位：力扣可能用同一个 Solution 实例连跑多个用例。
