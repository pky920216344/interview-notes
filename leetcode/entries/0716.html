716. 最大栈

双栈：主栈存数据，max 栈只存「前缀最大值」记录；pop 弹到最大值就同步弹 max 栈，popMax 下扫暂存重压。

思路

  • max 栈顶永远是主栈当前最大值：push 只在 x ≥ max.peek()（创新高，相等也算）时压入，所以 peekMax O(1)。
  • pop()：弹出 v；若 v == max.peek()，弹的正是当前最大值，max 栈同步弹一条记录。
  • popMax()：记下 m = peekMax()，从主栈顶往下找最上面的 m，路过的元素暂存 buf；弹掉 m 和 max 栈顶后把 buf 按原序 push 回去，max 栈随之自动重建。
  • 相等值也压 max 栈是关键：每个最大值在主栈里都有一条对应记录，popMax 删最上面的那个不会错删。

时间复杂度 push/top/peekMax/pop O(1)，popMax O(n)，空间复杂度 O(n)
1import java.util.*;2 3class MaxStack {4    // 主栈存数据；max 栈只存「前缀最大值」记录，栈顶 = 主栈当前最大值5    private final Deque<Integer> stack = new ArrayDeque<>();6    private final Deque<Integer> max = new ArrayDeque<>();7 8    public void push(int x) {9        stack.push(x);10        // 创新高才进 max 栈；相等也压，重复最大值各留一条记录11        if (max.isEmpty() || x >= max.peek()) max.push(x);12    }13 14    public int pop() {15        int v = stack.pop();16        // 弹的正是当前最大值，max 栈同步弹掉它的记录17        if (v == max.peek()) max.pop();18        return v;19    }20 21    public int top() {22        return stack.peek();23    }24 25    public int peekMax() {26        return max.peek();27    }28 29    public int popMax() {30        int m = max.peek();31        // 从主栈顶往下找最上面的 m，路过的元素暂存 buf32        Deque<Integer> buf = new ArrayDeque<>();33        while (stack.peek() != m) buf.push(stack.pop());34        stack.pop();   // 弹掉最上面的 m35        max.pop();     // max 栈顶正是它的记录36        // buf 按原序压回，max 栈随 push 自动重建37        while (!buf.isEmpty()) push(buf.pop());38        return m;39    }40}
