计数后用大小为 k 的小根堆养着「最好的 k 个」：堆顶是最差的（频次低、同频字典序大），超员就挤掉它，最后反序输出。

思路

  • LinkedHashMap 数次数并保持首次出现顺序，堆的比较器 频次升序、同频字典序降序——谁排前面谁就是该被挤掉的「最差」。
  • 逐个进堆，超过 k 就 poll 堆顶：结束时堆里恰好是全局最好的 k 个。
  • 从堆顶往外取得到的是「从差到好」，反序后才是「频次高在前、同频字典序小在前」的答案。

最优解

时间复杂度 O(n log k)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public List<String> topKFrequent(String[] words, int k) {5        // 数每个单词的出现次数；LinkedHashMap 保持首次出现顺序6        Map<String, Integer> cnt = new LinkedHashMap<>();7        for (String w : words) cnt.merge(w, 1, Integer::sum);8        // 小根堆装「目前最好的 k 个」：堆顶是最差的（频次低，同频字典序大）9        PriorityQueue<String> heap = new PriorityQueue<>((a, b) -> {10            int byFreq = cnt.get(a) - cnt.get(b);11            return byFreq != 0 ? byFreq : b.compareTo(a);12        });13        for (String w : cnt.keySet()) {14            heap.offer(w);15            // 超过 k 个就挤掉堆顶那个最差的16            if (heap.size() > k) heap.poll();17        }18        // 堆里剩下的就是最好的 k 个；从堆顶取是从差到好，反序才是答案19        List<String> ans = new ArrayList<>();20        while (!heap.isEmpty()) ans.add(heap.poll());21        Collections.reverse(ans);22        return ans;23    }24}
题目

给定一个单词列表 words 和一个整数 k ，返回前 k 个出现次数最多的单词。

返回的答案应该按单词出现频率由高到低排序。如果不同的单词有相同出现频率， 按字典顺序 排序。

示例 1：

输入: words = ["i", "love", "leetcode", "i", "love", "coding"], k = 2
输出: ["i", "love"]
解析: "i" 和 "love" 为出现次数最多的两个单词，均为2次。
    注意，按字母顺序 "i" 在 "love" 之前。

示例 2：

输入: ["the", "day", "is", "sunny", "the", "the", "the", "sunny", "is", "is"], k = 4
输出: ["the", "is", "sunny", "day"]
解析: "the", "is", "sunny" 和 "day" 是出现次数最多的四个单词，
    出现次数依次为 4, 3, 2 和 1 次。

注意：

  • 1 <= words.length <= 500
  • 1 <= words[i].length <= 10
  • words[i] 由小写英文字母组成。
  • k 的取值范围是 [1, 不同 words[i] 的数量]

进阶：尝试以 O(n log k) 时间复杂度和 O(n) 空间复杂度解决。
