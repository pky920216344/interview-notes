717. 1 比特与 2 比特字符

  • 简单
  • 频度 1
  • 模拟
  • 数组
  • 待提交

从左往右扫：1 开头必是双比特跳 2 位，0 必是单比特跳 1 位；恰好停在最后的 0 上就返回 true。

思路

  • 解码是唯一的：1 只能当双比特的开头，0 只能是单比特，从左到右没有任何分支。
  • 指针 i 一路跳：bits[i]==1 跳 2 位，否则跳 1 位；直到 i 不再小于 n-1。
  • 停在 n-1 说明最后的 0 单独成字符返回 true；跳过头（停在 n）说明它被并进了双比特，返回 false。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean isOneBitCharacter(int[] bits) {3        int n = bits.length;4        int i = 0;5        // 从左往右解码是唯一的：1 开头必是双比特，0 必是单比特6        while (i < n - 1) {7            i += bits[i] == 1 ? 2 : 1;8        }9        // 恰好停在最后的 0 上：它单独成一个单比特字符10        return i == n - 1;11    }12}
题目

有两种特殊字符：

  • 第一种字符可以用一比特 0 表示
  • 第二种字符可以用两比特（10 或 11）表示

给你一个以 0 结尾的二进制数组 bits ，如果最后一个字符必须是一个一比特字符，则返回 true 。

示例 1:

输入: bits = [1, 0, 0]
输出: true
解释: 唯一的解码方式是将其解析为一个两比特字符和一个一比特字符。
所以最后一个字符是一比特字符。

示例 2:

输入：bits = [1,1,1,0]
输出：false
解释：唯一的解码方式是将其解析为两比特字符和两比特字符。
所以最后一个字符不是一比特字符。

提示:

  • 1 <= bits.length <= 1000
  • bits[i] 为 0 或 1
