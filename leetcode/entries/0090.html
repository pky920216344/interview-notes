先排序，回溯生成子集；同层里「和前一个元素相同且不是第一个」的分支直接跳过，就不会出现重复子集。

思路

  • 排序后相同元素相邻；回溯树上每一层 = 「本层从 start 开始选哪个数」，每个结点收下一次 path。
  • 去重规则：i > start && nums[i] == nums[i-1] 就 continue——同一层里同值的数只允许选第一个，后面的整棵分支剪掉。
  • 和「树层去重」区分：i > start 只限制同层；往下递归传 i + 1，同一条路径上可以继续选相同值（如 [1,2,2]）。
  • 结果规模就是 2^n 个（去重后的），每个子集复制一份收进 ans。

1import java.util.*;2 3class Solution {4    public List<List<Integer>> subsetsWithDup(int[] nums) {5        Arrays.sort(nums);                       // 排序后相同元素相邻，同层判重才成立6        List<List<Integer>> ans = new ArrayList<>();7        dfs(nums, 0, new ArrayList<>(), ans);8        return ans;9    }10 11    // 从 start 开始选数；path 是正在搭建的子集12    private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> ans) {13        ans.add(new ArrayList<>(path));          // 树上每个结点都对应一个子集，先收下14        for (int i = start; i < nums.length; i++) {15            // 同层去重：不是本层第一个、又和前一个元素相同，整个分支跳过16            if (i > start && nums[i] == nums[i - 1]) continue;17            path.add(nums[i]);18            dfs(nums, i + 1, path, ans);19            path.remove(path.size() - 1);20        }21    }22}
题目

给你一个整数数组 nums ，其中可能包含重复元素，请你返回该数组所有可能的 子集（幂集）。

解集 不能 包含重复的子集。返回的解集中，子集可以按 任意顺序 排列。

示例 1：

输入：nums = [1,2,2]
输出：[[],[1],[1,2],[1,2,2],[2],[2,2]]

示例 2：

输入：nums = [0]
输出：[[],[0]]

提示：

  • 1 <= nums.length <= 10
  • -10 <= nums[i] <= 10
