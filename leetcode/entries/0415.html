415. 字符串相加

双指针从两个数的末尾往前逐位相加，维护进位；结果从低位往高位写，最后反转。

思路

  • i、j 分别指向两个数的个位，carry 记进位；每轮取 x + y + carry，写入 sum % 10，新进位是 sum / 10。
  • 某个数读完了，这一位就当 0，所以循环条件是 i >= 0 || j >= 0 || carry > 0。
  • 最高位还有进位（比如 99 + 1）也要再走一轮，别漏掉 carry > 0。
  • StringBuilder 是低位在前写的，返回前 reverse()。

最优解

时间复杂度 O(max(m, n))，空间复杂度 O(1)（不计输出）
1class Solution {2    public String addStrings(String num1, String num2) {3        StringBuilder sb = new StringBuilder();4        int i = num1.length() - 1, j = num2.length() - 1;5        int carry = 0;6        // 两个数都读完、也没有进位，才算加完7        while (i >= 0 || j >= 0 || carry > 0) {8            // 短的那个读完了，这一位就当 09            int x = i >= 0 ? num1.charAt(i) - '0' : 0;10            int y = j >= 0 ? num2.charAt(j) - '0' : 0;11            i--;12            j--;13            int sum = x + y + carry;14            sb.append(sum % 10);15            carry = sum / 10;16        }17        // 是从低位往高位写的，要反转18        return sb.reverse().toString();19    }20}
题目

给定两个字符串形式的非负整数 num1 和num2 ，计算它们的和并同样以字符串形式返回。

你不能使用任何內建的用于处理大整数的库（比如 BigInteger）， 也不能直接将输入的字符串转换为整数形式。

示例 1：

输入：num1 = "11", num2 = "123"
输出："134"

示例 2：

输入：num1 = "456", num2 = "77"
输出："533"

示例 3：

输入：num1 = "0", num2 = "0"
输出："0"

提示：

  • 1 <= num1.length, num2.length <= 104
  • num1 和num2 都只包含数字 0-9
  • num1 和num2 都不包含任何前导零
