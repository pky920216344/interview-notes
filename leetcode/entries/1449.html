1449. 数位成本和为目标值的最大数字

  • 困难

  • 动态规划
  • 贪心
  • 数组
  • 动态规划
  • knapsack-problem
  • complete-knapsack
  • 待提交

完全背包先求「恰好花 target 能拼出的最大位数」，再从高位到低位贪心：每位放剩下的成本仍可达的最大数字。

思路

  • dp[c] = 恰好花成本 c 能拼出的最大位数，-1 表示拼不出；放数字 d 花费 cost[d-1]，转移 dp[c] = max(dp[c - cost[d-1]] + 1)。
  • 位数越多数越大，所以先只求位数；dp[target] ≤ 0 直接返回 "0"。
  • 重建：从高位到低位，每位从 9 往下试，只要「剩下的成本 c - cost[d-1] 还能拼出剩余位数（dp[c - cost[d-1]] == len - 1）」就放这个 d——位数定死时逐位放大即全局最大。
  • 成本要恰好等于 target，所以状态是「恰好装满」的完全背包，初始只有 dp[0] = 0 可达。

时间复杂度 O(9 × target)，空间复杂度 O(target)
1import java.util.*;2 3class Solution {4    public String largestNumber(int[] cost, int target) {5        // dp[c]：恰好花成本 c 能拼出的最大位数，-1 表示拼不出6        int[] dp = new int[target + 1];7        Arrays.fill(dp, -1);8        dp[0] = 0;9        for (int c = 1; c <= target; c++) {10            for (int d = 1; d <= 9; d++) {11                // 试放数字 d：剩下的成本也必须恰好拼得出12                int p = c - cost[d - 1];13                if (p >= 0 && dp[p] >= 0) dp[c] = Math.max(dp[c], dp[p] + 1);14            }15        }16        if (dp[target] <= 0) return "0";17        // 位数已定死，从高到低逐位贪心：数字尽量大，18        // 前提是剩余成本还能拼出剩余位数19        StringBuilder sb = new StringBuilder();20        int c = target;21        for (int len = dp[target]; len > 0; len--) {22            for (int d = 9; d >= 1; d--) {23                if (c >= cost[d - 1] && dp[c - cost[d - 1]] == len - 1) {24                    sb.append(d);25                    c -= cost[d - 1];26                    break;27                }28            }29        }30        return sb.toString();31    }32}
题目

给你一个整数数组 cost 和一个整数 target 。请你返回满足如下规则可以得到的 最大 整数：

  • 给当前结果添加一个数位（i + 1）的成本为 cost[i] （cost 数组下标从 0 开始）。
  • 总成本必须恰好等于 target 。
  • 添加的数位中没有数字 0 。

由于答案可能会很大，请你以字符串形式返回。

如果按照上述要求无法得到任何整数，请你返回 "0" 。

示例 1：

输入：cost = [4,3,2,5,6,7,2,5,5], target = 9
输出："7772"
解释：添加数位 '7' 的成本为 2 ，添加数位 '2' 的成本为 3 。所以 "7772" 的代价为 2*3+ 3*1 = 9 。 "977" 也是满足要求的数字，但 "7772" 是较大的数字。
 数字     成本
  1  ->   4
  2  ->   3
  3  ->   2
  4  ->   5
  5  ->   6
  6  ->   7
  7  ->   2
  8  ->   5
  9  ->   5

示例 2：

输入：cost = [7,6,5,5,5,6,8,7,8], target = 12
输出："85"
解释：添加数位 '8' 的成本是 7 ，添加数位 '5' 的成本是 5 。"85" 的成本为 7 + 5 = 12 。

示例 3：

输入：cost = [2,4,6,2,4,6,4,4,4], target = 5
输出："0"
解释：总成本是 target 的条件下，无法生成任何整数。

示例 4：

输入：cost = [6,10,15,40,40,40,40,40,40], target = 47
输出："32211"

提示：

  • cost.length == 9
  • 1 <= cost[i] <= 5000
  • 1 <= target <= 5000
