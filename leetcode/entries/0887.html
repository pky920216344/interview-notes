887. 鸡蛋掉落

  • 频度 30
  • 动态规划
  • 数学
  • 二分查找
  • 动态规划

换个定义：dp[t][k] = t 次操作、k 个蛋最多能测多少层；t 一轮轮涨到首次盖住 n 就是答案。

思路

  • 不问「n 层要几次」，反问「t 次能测几层」：dp[t][k] = dp[t-1][k-1] + dp[t-1][k] + 1。
  • 扔一层：碎了往它下面测 dp[t-1][k-1] 层，没碎往上面测 dp[t-1][k] 层，加上本层共 +1。
  • 一维数组从 j = k 倒序更新，dp[j-1] 用的才是上一轮的旧值；dp[j] 封顶在 n 防溢出。
  • t 从 1 起每轮整体重算，dp[k] 首次 ≥ n 时的 t 就是答案，复杂度 O(k·answer)。

图解

最优解

时间复杂度 O(k·answer)，空间复杂度 O(k)
1class Solution {2    public int superEggDrop(int k, int n) {3        // dp[j]：t 次操作、j 个鸡蛋最多能确定多少层楼4        int[] dp = new int[k + 1];5        int t = 0;6        while (dp[k] < n) {                  // 还测不满 n 层就再来一轮7            t++;8            for (int j = k; j >= 1; j--) {   // 倒序：dp[j-1] 要用上一轮的旧值9                // 扔一层：碎了往下测 dp[j-1] 层 + 没碎往上测 dp[j] 层 + 当前这层10                dp[j] = dp[j - 1] + dp[j] + 1;11                if (dp[j] > n) dp[j] = n;    // 封顶，防止溢出12            }13        }14        return t;15    }16}
题目

给你 k 枚相同的鸡蛋，并可以使用一栋从第 1 层到第 n 层共有 n 层楼的建筑。

已知存在楼层 f ，满足 0 <= f <= n ，任何从 高于 f 的楼层落下的鸡蛋都会碎，从 f 楼层或比它低的楼层落下的鸡蛋都不会破。

每次操作，你可以取一枚没有碎的鸡蛋并把它从任一楼层 x 扔下（满足 1 <= x <= n）。如果鸡蛋碎了，你就不能再次使用它。如果某枚鸡蛋扔下后没有摔碎，则可以在之后的操作中 重复使用 这枚鸡蛋。

请你计算并返回要确定 f 确切的值 的 最小操作次数 是多少？

 

示例 1：

输入：k = 1, n = 2
输出：2
解释：
鸡蛋从 1 楼掉落。如果它碎了，肯定能得出 f = 0 。 
否则，鸡蛋从 2 楼掉落。如果它碎了，肯定能得出 f = 1 。 
如果它没碎，那么肯定能得出 f = 2 。 
因此，在最坏的情况下我们需要移动 2 次以确定 f 是多少。

示例 2：

输入：k = 2, n = 6
输出：3

示例 3：

输入：k = 3, n = 14
输出：4

提示：

  • 1 <= k <= 100
  • 1 <= n <= 104
