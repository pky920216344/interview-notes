1089. 复写零

  • 简单
  • 频度 2
  • 模拟
  • 双指针
  • 数组
  • 双指针
  • 待提交

两遍：先从左往右数出复写后的总长度、找到最后一个留得下的元素；再从右往左把元素放回复写后的位置，被挤出去的 0 只保留一个。

思路

  • 第一遍扫一遍：非 0 占 1 格、0 占 2 格，累加出 top；top 第一次 ≥ n 时停下，此时的 i 就是最后一个留得下的元素。
  • 若 top == n + 1：末尾这个 0 只挤得下一格，先在 arr[n-1] 写一个 0，读指针、写指针各退一格。
  • 第二遍 i 从右往左读、j 从右往左写：非 0 抄一格，0 连写两格；j ≥ i 恒成立，原地写不会踩到还没读的元素。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public void duplicateZeros(int[] arr) {3        int n = arr.length;4        // 第一遍：top 记复写后的总长度，i 记最后一个能留在数组里的原元素5        int top = 0, i = -1;6        while (top < n) {7            i++;8            top += arr[i] == 0 ? 2 : 1;9        }10        int j = n - 1;11        if (top == n + 1) {          // 末尾这个 0 只挤得下一个：截断12            arr[j] = 0;13            j--;14            i--;15        }16        // 第二遍：从右往左，把留下的元素放回复写后的位置17        while (i >= 0) {18            arr[j] = arr[i];19            j--;20            if (arr[i] == 0) {       // 零要占两格，再补一个21                arr[j] = 0;22                j--;23            }24            i--;25        }26    }27}
题目

给你一个长度固定的整数数组 arr ，请你将该数组中出现的每个零都复写一遍，并将其余的元素向右平移。

注意：请不要在超过该数组长度的位置写入元素。请对输入的数组 就地 进行上述修改，不要从函数返回任何东西。

示例 1：

输入：arr = [1,0,2,3,0,4,5,0]
输出：[1,0,0,2,3,0,0,4]
解释：调用函数后，输入的数组将被修改为：[1,0,0,2,3,0,0,4]

示例 2：

输入：arr = [1,2,3]
输出：[1,2,3]
解释：调用函数后，输入的数组将被修改为：[1,2,3]

提示：

  • 1 <= arr.length <= 104
  • 0 <= arr[i] <= 9
