1301. 最大得分的路径数目

  • 困难

  • 动态规划

  • 动态规划
  • 矩阵
  • 待提交

从 S 出发反向 DP：best 记到每格的最大得分、cnt 记方案数；走进数字格才计分，得分并列时方案数相加。

思路

  • best[i][j] = 从 S 走到 (i,j) 的最大得分，-1 表示到不了；S 初始 best=0, cnt=1。
  • 每步只能上 / 左 / 左上，坐标严格变小 → 按 i,j 从大到小扫一遍就是拓扑序。
  • 扩展到新格时把新格的数字计入（E 计 0，X 直接跳过）；v 更大则覆盖并继承 cnt，相等则 cnt 相加取模。
  • 到不了 E（best[0][0] < 0）返回 [0,0]；注意得分 0 但可达时要返回 [0, 方案数]。

时间复杂度 O(n²)，空间复杂度 O(n²)
1import java.util.*;2 3class Solution {4    public int[] pathsWithMaxScore(List<String> board) {5        final int MOD = 1_000_000_007;6        int n = board.size(), m = board.get(0).length();7        long[][] best = new long[n][m];   // best[i][j]：从 S 走到 (i,j) 的最大得分，-1 表示到不了8        long[][] cnt = new long[n][m];    // 取到最大得分的方案数（mod 1e9+7）9        for (long[] row : best) Arrays.fill(row, -1);10        best[n - 1][m - 1] = 0;   // 起点自己不计分11        cnt[n - 1][m - 1] = 1;12        int[][] dirs = {{-1, 0}, {0, -1}, {-1, -1}};   // 从 S 出发是往上、左、左上走13        for (int i = n - 1; i >= 0; i--) {14            for (int j = m - 1; j >= 0; j--) {15                if (best[i][j] < 0) continue;   // X 格和到不了的格子没法向外扩展16                for (int[] d : dirs) {17                    int ni = i + d[0], nj = j + d[1];18                    if (ni < 0 || nj < 0) continue;19                    char c = board.get(ni).charAt(nj);20                    if (c == 'X') continue;   // 障碍进不去21                    long v = best[i][j] + (c == 'E' ? 0 : c - '0');   // 走进新格子才把它的数字计入22                    if (v > best[ni][nj]) {23                        best[ni][nj] = v;24                        cnt[ni][nj] = cnt[i][j];25                    } else if (v == best[ni][nj]) {26                        cnt[ni][nj] = (cnt[ni][nj] + cnt[i][j]) % MOD;   // 得分并列：方案数相加27                    }28                }29            }30        }31        if (best[0][0] < 0) return new int[]{0, 0};32        return new int[]{(int) (best[0][0] % MOD), (int) cnt[0][0]};33    }34}
题目

给你一个正方形字符数组 board ，你从数组最右下方的字符 'S' 出发。

你的目标是到达数组最左上角的字符 'E' ，数组剩余的部分为数字字符 1, 2, ..., 9 或者障碍 'X'。在每一步移动中，你可以向上、向左或者左上方移动，可以移动的前提是到达的格子没有障碍。

一条路径的 「得分」 定义为：路径上所有数字的和。

请你返回一个列表，包含两个整数：第一个整数是 「得分」 的最大值，第二个整数是得到最大得分的方案数，请把结果对 10^9 + 7 取余。

如果没有任何路径可以到达终点，请返回 [0, 0] 。

示例 1：

输入：board = ["E23","2X2","12S"]
输出：[7,1]

示例 2：

输入：board = ["E12","1X1","21S"]
输出：[4,2]

示例 3：

输入：board = ["E11","XXX","11S"]
输出：[0,0]

提示：

  • 2 <= board.length == board[i].length <= 100
