1636. 按照频率将数组升序排序

  • 数组
  • 哈希表

哈希计数后自定义排序：频次升序，频次相同数值降序。

思路

  • 用数组 count[v + 100] 计数（值域 −100…100，偏移 100 防止负下标）。
  • 比较器：次数不同比次数（升序）；次数相同比数值（降序，b − a）。
  • 带自定义比较器排序要装箱成 Integer[]，排完再写回 nums 返回。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] frequencySort(int[] nums) {5        // count[v + 100]：值 v 的出现次数（值域 [-100,100]，+100 防止负下标）6        int[] count = new int[201];7        for (int v : nums) count[v + 100]++;8        Integer[] arr = new Integer[nums.length];9        for (int i = 0; i < nums.length; i++) arr[i] = nums[i];10        // 频次小的在前；频次相同，数值大的在前11        Arrays.sort(arr, (a, b) -> count[a + 100] != count[b + 100]12                ? count[a + 100] - count[b + 100] : b - a);13        for (int i = 0; i < arr.length; i++) nums[i] = arr[i];14        return nums;15    }16}
题目

给你一个整数数组 nums ，请你将数组按照每个值的频率 升序 排序。如果有多个值的频率相同，请你按照数值本身将它们 降序 排序。 

请你返回排序后的数组。

示例 1：

输入：nums = [1,1,2,2,2,3]
输出：[3,1,1,2,2,2]
解释：'3' 频率为 1，'1' 频率为 2，'2' 频率为 3 。

示例 2：

输入：nums = [2,3,1,3,2]
输出：[1,3,3,2,2]
解释：'2' 和 '3' 频率都为 2 ，所以它们之间按照数值本身降序排序。

示例 3：

输入：nums = [-1,1,-6,4,5,-6,1,4,1]
输出：[5,-1,4,4,-6,-6,1,1,1]

提示：

  • 1 <= nums.length <= 100
  • -100 <= nums[i] <= 100
