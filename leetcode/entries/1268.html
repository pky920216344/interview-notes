产品先排序；对每个前缀二分找第一个 ≥ 前缀的下标，从那里连续取至多 3 个以该前缀开头的。

思路

  • 排序后所有以 prefix 开头的产品在数组里是连续一段，且天然按字典序排好。
  • 每个前缀二分找 lo：第一个 ≥ prefix 的下标（比它小的都以该前缀为界被跳过）。
  • 从 lo 向右取，遇到不以 prefix 开头的就停，最多取 3 个。
  • 每个前缀独立做一遍，共 searchWord.length() 轮。

最优解

时间复杂度 O(n log n + m log n)，空间复杂度 O(1)（不计输出）
1import java.util.*;2 3class Solution {4    public List<List<String>> suggestedProducts(String[] products, String searchWord) {5        Arrays.sort(products);   // 排序后，前缀相同的产品是连续的一段，且按字典序排好6        List<List<String>> out = new ArrayList<>();7        int n = products.length;8        for (int i = 1; i <= searchWord.length(); i++) {9            String prefix = searchWord.substring(0, i);10            // 二分找第一个 >= prefix 的位置：以 prefix 开头的产品从这里开始11            int lo = 0, hi = n;12            while (lo < hi) {13                int mid = (lo + hi) / 2;14                if (products[mid].compareTo(prefix) < 0) lo = mid + 1;15                else hi = mid;16            }17            List<String> picks = new ArrayList<>();18            for (int j = lo; j < n && picks.size() < 3 && products[j].startsWith(prefix); j++) picks.add(products[j]);19            out.add(picks);20        }21        return out;22    }23}
题目

给你一个产品数组 products 和一个字符串 searchWord ，products  数组中每个产品都是一个字符串。

请你设计一个推荐系统，在依次输入单词 searchWord 的每一个字母后，推荐 products 数组中前缀与 searchWord 相同的最多三个产品。如果前缀相同的可推荐产品超过三个，请按字典序返回最小的三个。

请你以二维列表的形式，返回在输入 searchWord 每个字母后相应的推荐产品的列表。

示例 1：

输入：products = ["mobile","mouse","moneypot","monitor","mousepad"], searchWord = "mouse"
输出：[
["mobile","moneypot","monitor"],
["mobile","moneypot","monitor"],
["mouse","mousepad"],
["mouse","mousepad"],
["mouse","mousepad"]
]
解释：按字典序排序后的产品列表是 ["mobile","moneypot","monitor","mouse","mousepad"]
输入 m 和 mo，由于所有产品的前缀都相同，所以系统返回字典序最小的三个产品 ["mobile","moneypot","monitor"]
输入 mou， mous 和 mouse 后系统都返回 ["mouse","mousepad"]

示例 2：

输入：products = ["havana"], searchWord = "havana"
输出：[["havana"],["havana"],["havana"],["havana"],["havana"],["havana"]]

示例 3：

输入：products = ["bags","baggage","banner","box","cloths"], searchWord = "bags"
输出：[["baggage","bags","banner"],["baggage","bags","banner"],["baggage","bags"],["bags"]]

示例 4：

输入：products = ["havana"], searchWord = "tatiana"
输出：[[],[],[],[],[],[],[]]

提示：

  • 1 <= products.length <= 1000
  • 1 <= Σ products[i].length <= 2 * 10^4
  • products[i] 中所有的字符都是小写英文字母。
  • 1 <= searchWord.length <= 1000
  • searchWord 中所有字符都是小写英文字母。
