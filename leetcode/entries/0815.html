BFS 建在「线路」上而不是站点上：起点所在线路先入队，坐一条新线路即到达它的全部站点；共站即可换乘。

思路

  • 「坐一辆车」是 BFS 的一步：换乘靠共站，所以先建倒排表 站点 → 线路。
  • 起点所在线路全部入队（坐第 1 辆车）；出队一条线路就扫它沿路的站：命中终点返回，否则把共站的没坐过的线路入队。
  • taken[] 防线路重复入队；seenStops 让每站的线路表只展开一次，总时间与站点总数成正比。
  • 起点即终点返回 0；起点或终点不在任何线路上返回 -1。

时间复杂度 O(Σ 线路长度)，空间复杂度 O(Σ 线路长度)
1import java.util.*;2 3class Solution {4    public int numBusesToDestination(int[][] routes, int source, int target) {5        // 本来就在终点：一辆车都不用坐6        if (source == target) return 0;7        // 站点 → 经过它的线路：换乘只发生在「共站」的线路之间8        Map<Integer, List<Integer>> stopToRoutes = new HashMap<>();9        for (int r = 0; r < routes.length; r++)10            for (int s : routes[r])11                stopToRoutes.computeIfAbsent(s, k -> new ArrayList<>()).add(r);12 13        // BFS 的单位是「线路」：起点所在线路全部入队，坐过的线路不再坐14        Queue<Integer> q = new ArrayDeque<>();15        boolean[] taken = new boolean[routes.length];16        for (int r : stopToRoutes.getOrDefault(source, Collections.emptyList())) {17            taken[r] = true;18            q.add(r);19        }20 21        Set<Integer> seenStops = new HashSet<>();22        seenStops.add(source);   // 起点的线路已在队里，不用再展开23        int buses = 1;   // 队列里的线路都是「坐 1 辆车就能上车」的24        while (!q.isEmpty()) {25            for (int size = q.size(); size > 0; size--) {26                int r = q.poll();27                // 这条车沿路每个站：是终点就返回；共站的线路发展进来（每站只展开一次）28                for (int s : routes[r]) {29                    if (s == target) return buses;30                    if (seenStops.add(s)) {31                        for (int nr : stopToRoutes.get(s)) {32                            if (!taken[nr]) {33                                taken[nr] = true;34                                q.add(nr);35                            }36                        }37                    }38                }39            }40            buses++;41        }42        return -1;43    }44}
题目

给你一个数组 routes ，表示一系列公交线路，其中每个 routes[i] 表示一条公交线路，第 i 辆公交车将会在上面循环行驶。

  • 例如，路线 routes[0] = [1, 5, 7] 表示第 0 辆公交车会一直按序列 1 -> 5 -> 7 -> 1 -> 5 -> 7 -> 1 -> ... 这样的车站路线行驶。

现在从 source 车站出发（初始时不在公交车上），要前往 target 车站。 期间仅可乘坐公交车。

求出 最少乘坐的公交车数量 。如果不可能到达终点车站，返回 -1 。

示例 1：

输入：routes = [[1,2,7],[3,6,7]], source = 1, target = 6
输出：2
解释：最优策略是先乘坐第一辆公交车到达车站 7 , 然后换乘第二辆公交车到车站 6 。

示例 2：

输入：routes = [[7,12],[4,5,15],[6],[15,19],[9,12,13]], source = 15, target = 12
输出：-1

提示：

  • 1 <= routes.length <= 500.
  • 1 <= routes[i].length <= 105
  • routes[i] 中的所有值 互不相同
  • sum(routes[i].length) <= 105
  • 0 <= routes[i][j] < 106
  • 0 <= source, target < 106
