793. 阶乘函数后 K 个零

二分最小的 z(x) ≥ k 的 x（z = x/5 + x/25 + … 单调不减）；z(x)=k 若取得到必是连续 5 个 x，答案只会是 5 或 0。

思路

  • z(x)（末尾 0 个数 = 因子 5 的个数）随 x 单调不减，可以二分；上界取 5(k+1)，此时 z ≥ k+1 必然够。
  • 二分出最小的 z(x) ≥ k 的 x：z(x) 只在 5 的倍数处跳、平坡长恰为 5，所以 z(x)=k 有解就是连续 5 个 x 命中。
  • 最后判 z(lo) == k：等于则返回 5，否则 k 被跳过了返回 0。
  • x 和 z 都可能超出 int（k 到 1e9 时 x 到 5e9），全程用 long。

题目

 f(x) 是 x! 末尾是 0 的数量。回想一下 x! = 1 * 2 * 3 * ... * x，且 0! = 1 。

  • 例如， f(3) = 0 ，因为 3! = 6 的末尾没有 0 ；而 f(11) = 2 ，因为 11!= 39916800 末端有 2 个 0 。

给定 k，找出返回能满足 f(x) = k 的非负整数 x 的数量。

示例 1：

输入：k = 0
输出：5
解释：0!, 1!, 2!, 3!, 和 4! 均符合 k = 0 的条件。

示例 2：

输入：k = 5
输出：0
解释：没有匹配到这样的 x!，符合 k = 5 的条件。

示例 3:

输入: k = 3
输出: 5

提示:

  • 0 <= k <= 109
