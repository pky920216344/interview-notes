125. 验证回文串

  • 简单
  • 频度 43
  • 双指针
  • 双指针
  • 字符串
  • 力扣已通过

首尾双指针：两边各跳过非字母数字，有效字符转小写比较一对，不等即假，相遇即真。

思路

  • left、right 从两端向中间走；遇到非字母数字就继续跳，内层 while 要带上 left < right 防越界。
  • 两个有效字符用 Character.toLowerCase 归一后比较，不等返回 false。
  • 比完或相遇（含清洗后为空串）都是回文，返回 true。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean isPalindrome(String s) {3        // 首尾双指针：跳过非字母数字，有效字符转小写再比较4        int left = 0, right = s.length() - 1;5        while (left < right) {6            // 内层跳过时也要带上 left < right，别越过对方7            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) left++;8            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) right--;9            // 都归一成小写再比：'P' 与 'p' 相等，'0' 与 'P' 不等10            if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) return false;11            left++;12            right--;13        }14        // 比完或相遇（含清洗后为空）都是回文15        return true;16    }17}
题目

如果在将所有大写字符转换为小写字符、并移除所有非字母和非数字字符之后，短语正着读和反着读都一样。则可以认为该短语是一个 回文串 。

字母和数字都属于字母数字字符。

给你一个字符串 s，如果它是 回文串 ，返回 true ；否则，返回 false 。

示例 1：

输入: s = "A man, a plan, a canal: Panama"
输出：true
解释："amanaplanacanalpanama" 是回文串。

示例 2：

输入：s = "race a car"
输出：false
解释："raceacar" 不是回文串。

示例 3：

输入：s = " "
输出：true
解释：在移除非字母数字字符之后，s 是一个空字符串 "" 。
由于空字符串正着反着读都一样，所以是回文串。

提示：

  • 1 <= s.length <= 2 * 105
  • s 仅由可打印的 ASCII 字符组成
