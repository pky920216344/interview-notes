剑指 Offer 05. 路径加密

  • 简单
  • 频度 3
  • 模拟
  • 字符串
  • 待提交

转成字符数组从左往右扫，遇到分隔符「.」就地改成空格，其余字符原样保留。

思路

  • 新旧字符串等长：String 不可变，先 toCharArray() 拿到可写的字符数组，改完再包回 String。
  • 逐格判断：a[i] == '.' 就写成 ' '，别的字符一律不动，一遍扫完。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public String pathEncryption(String path) {3        // 转成字符数组原地改，避免反复拼串产生中间字符串4        char[] a = path.toCharArray();5        for (int i = 0; i < a.length; i++) {6            if (a[i] == '.') a[i] = ' ';7        }8        return new String(a);9    }10}
题目

假定一段路径记作字符串 path，其中以 "." 作为分隔符。现需将路径加密，加密方法为将 path 中的分隔符替换为空格 " "，请返回加密后的字符串。

示例 1：

输入：path = "a.aef.qerf.bb"

输出："a aef qerf bb"

限制：

0 <= path.length <= 10000
