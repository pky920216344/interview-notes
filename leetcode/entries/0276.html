276. 栅栏涂色

  • 简单
  • 频度 1
  • 动态规划
  • 动态规划
  • 未经力扣验证

双状态 DP：same=末两根同色的方案数、diff=末两根不同色；同色只能接在 diff 后，换色随便接。

思路

  • 只需要知道末尾两根是否同色，就能决定下一根怎么涂，两个变量滚动即可。
  • 新的 same = 旧 diff（连涂两根同色只有在「前一根换过色」时合法，否则三连）。
  • 新的 diff = (same + diff) × (k−1)：换色不受三连限制，任何合法前驱都有 k−1 种新颜色。
  • 初始 same=0, diff=k（第一根随便涂）；答案 same + diff。用 long 算防溢出。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int numWays(int n, int k) {5        if (n == 0 || k == 0) return 0;6        // same：末尾两根同色的方案数；diff：末尾两根不同色的方案数7        long same = 0, diff = k;8        for (int i = 2; i <= n; i++) {9            long ns = diff;                        // 想跟前一根同色，前一根必须已「不同色」10            long nd = (same + diff) * (k - 1);     // 换色：任何合法前驱都能换 (k-1) 种颜色11            same = ns;12            diff = nd;13        }14        // 题目保证答案在 int 范围内，用 long 算防中间溢出15        return (int) (same + diff);16    }17}
