面试题 01.06. 字符串压缩

双指针数连续段：j 扫到段尾，拼「字符 + 个数」；压完不比原串短就返回原串。

思路

  • i 是段首，j 一直右移到第一个不同的字符，[i, j) 就是一段连续相同字符。
  • 每段往 StringBuilder 拼「字符 + 段长」；个数是 1 也要写（a1 不能省）。
  • 拼完和原串比长度：不更短就返回原串，相等也不算变短（如 aabb → a2b2 仍返回原串）。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public String compressString(String S) {3        int n = S.length();4        StringBuilder sb = new StringBuilder();5        int i = 0;6        while (i < n) {7            int j = i;8            // j 一直右移，走过这一段相同的字符9            while (j < n && S.charAt(j) == S.charAt(i)) j++;10            // 每段拼「字符 + 个数」，个数是 1 也不能省11            sb.append(S.charAt(i)).append(j - i);12            // 下一段从 j 重新开始13            i = j;14        }15        // 压缩串不比原串短就放弃，返回原串16        return sb.length() < n ? sb.toString() : S;17    }18}
题目

字符串压缩。利用字符重复出现的次数，编写一种方法，实现基本的字符串压缩功能。比如，字符串aabcccccaaa会变为a2b1c5a3。若“压缩”后的字符串没有变短，则返回原先的字符串。你可以假设字符串中只包含大小写英文字母（a至z）。

示例 1：

输入："aabcccccaaa"
输出："a2b1c5a3"

示例 2：

输入："abbccd"
输出："abbccd"
解释："abbccd"压缩后为"a1b2c2d1"，比原字符串长度更长。

提示：

  1. 字符串长度在 [0, 50000] 范围内。
