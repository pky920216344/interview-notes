单调递减双端队列存下标：新数先弹掉不比它大的队尾，滑出窗口的队头也弹掉，队头就是窗口最大值。

思路

  • 队列里存下标，对应值从队头到队尾递减，队头永远是当前窗口的最大值。
  • 新数 heights[i] 进队前，把队尾所有不比它大的下标弹掉：它们又旧又小，不可能再当最大值。
  • 弹完把 i 放队尾；队头下标 <= i - limit 说明已滑出窗口，弹掉（每步最多滑出一个，用 if 就够）。
  • i >= limit - 1 时窗口满了，heights[队头] 就是 ans[i - limit + 1]。

最优解

时间复杂度 O(n)，空间复杂度 O(limit)
1import java.util.*;2 3class Solution {4    public int[] maxAltitude(int[] heights, int limit) {5        int n = heights.length;6        int[] ans = new int[n - limit + 1];7        // 队列存下标，值从队头到队尾递减，8        // 所以队头就是窗口最大值9        Deque<Integer> dq = new ArrayDeque<>();10        for (int i = 0; i < n; i++) {11            // 队尾不比新数大，以后不可能再是最大值12            while (!dq.isEmpty() && heights[dq.peekLast()] <= heights[i]) {13                dq.pollLast();14            }15            dq.offerLast(i);16            // 队头滑出了窗口 [i - limit + 1, i]17            if (dq.peekFirst() <= i - limit) dq.pollFirst();18            // 窗口满了才有答案19            if (i >= limit - 1) ans[i - limit + 1] = heights[dq.peekFirst()];20        }21        return ans;22    }23}
题目

科技馆内有一台虚拟观景望远镜，它可以用来观测特定纬度地区的地形情况。该纬度的海拔数据记于数组 heights ，其中 heights[i] 表示对应位置的海拔高度。请找出并返回望远镜视野范围 limit 内，可以观测到的最高海拔值。

示例 1：

输入：heights = [14,2,27,-5,28,13,39], limit = 3
输出：[27,27,28,28,39]
解释：
  滑动窗口的位置                最大值
---------------               -----
[14 2 27] -5 28 13 39          27
14 [2 27 -5] 28 13 39          27
14 2 [27 -5 28] 13 39          28
14 2 27 [-5 28 13] 39          28
14 2 27 -5 [28 13 39]          39

提示：

你可以假设输入总是有效的，在输入数组不为空的情况下：

  • 1 <= limit <= heights.length
  • -10000 <= heights[i] <= 10000
