404. 左叶子之和

  • 二叉树
  • 待提交

DFS 每个结点只看一件事：我的左孩子是不是叶子（没有任何孩子），是就收下它的值。

思路

  • 「左叶子」由父结点判定：root.left 存在且 root.left 没有左右孩子，它才是左叶子。
  • 是左叶子：答案 = root.left.val + 右子树的递归结果（左子树不用再进，它只是个叶子）。
  • 不是（左孩子为空或非叶子）：答案 = 左子树递归 + 右子树递归，空结点返回 0。
  • 右叶子不算：叶子身份必须是「从左边走到的」，根自己也不是左叶子。

最优解

时间复杂度 O(n)，空间复杂度 O(h)（递归栈）
1class Solution {2    public int sumOfLeftLeaves(TreeNode root) {3        if (root == null) return 0;4        // 左孩子存在且没有孩子：它就是左叶子，收下它的值，右边另外递归5        if (root.left != null && root.left.left == null && root.left.right == null) {6            return root.left.val + sumOfLeftLeaves(root.right);7        }8        // 左孩子不是叶子：左右两边都递归9        return sumOfLeftLeaves(root.left) + sumOfLeftLeaves(root.right);10    }11}
题目

给定二叉树的根节点 root ，返回所有左叶子之和。

示例 1：

输入: root = [3,9,20,null,null,15,7] 
输出: 24 
解释: 在这个二叉树中，有两个左叶子，分别是 9 和 15，所以返回 24

示例 2:

输入: root = [1]
输出: 0

提示:

  • 节点数在 [1, 1000] 范围内
  • -1000 <= Node.val <= 1000
