186. 反转字符串中的单词 II

  • 中等
  • 频度 2
  • 双指针
  • 双指针
  • 字符串
  • 未经力扣验证

原地两步反转：先把整串字符反转（单词顺序就对了），再把每个单词内部反转回来。

思路

  • 第一步 reverse(0, n-1)：整串反转后单词顺序正确，但每个词内部字符是反的。
  • 第二步扫一遍：j 走到空格或串尾就反转 [i, j-1] 这个词，然后 i = j + 1 跳过空格。
  • reverse 用双指针交换实现；题目保证单词间恰好一个空格，没有多余边界。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public void reverseWords(char[] s) {3        reverse(s, 0, s.length - 1);     // 整串反转：单词顺序对了，词内字符是反的4        for (int i = 0, j = 0; j <= s.length; j++) {5            if (j == s.length || s[j] == ' ') {6                reverse(s, i, j - 1);    // 逐词反转，恢复每个词内部顺序7                i = j + 1;8            }9        }10    }11 12    private void reverse(char[] a, int l, int r) {13        while (l < r) {14            char t = a[l]; a[l] = a[r]; a[r] = t;15            l++; r--;16        }17    }18}
