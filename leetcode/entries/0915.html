一遍扫：curMax 记全局最大、leftMax 记左段最大；谁比 leftMax 还小，左段就必须延长到谁。

思路

  • 左段 [0..idx] 一旦定下，条件是「左段每个数 ≤ 右段每个数」，即 leftMax ≤ 右段 min。
  • 从左往右扫：curMax 记见过的最大值；遇到 nums[i] < leftMax，说明 i 只能进左段，左段延长到 i，且新左段最大就是 curMax。
  • nums[i] ≥ leftMax 的数都留在右段，只更新 curMax。
  • 扫完的 idx + 1 就是最小左段长度；相等（==）不算冲突，可以留在右段。

1class Solution {2    public int partitionDisjoint(int[] nums) {3        // leftMax：当前左段 [0..idx] 的最大值；curMax：截至目前全体的最大值4        int leftMax = nums[0], curMax = nums[0], idx = 0;5        for (int i = 1; i < nums.length; i++) {6            curMax = Math.max(curMax, nums[i]);7            // nums[i] 比左段最大还小 → 左段必须延长到 i，左段最大更新为 curMax8            if (nums[i] < leftMax) {9                leftMax = curMax;10                idx = i;11            }12        }13        // idx 是左段的最后一个下标，长度 = idx + 114        return idx + 1;15    }16}
题目

给定一个数组 nums ，将其划分为两个连续子数组 left 和 right， 使得：

  • left 中的每个元素都小于或等于 right 中的每个元素。
  • left 和 right 都是非空的。
  • left 的长度要尽可能小。

在完成这样的分组后返回 left 的 长度 。

用例可以保证存在这样的划分方法。

示例 1：

输入：nums = [5,0,3,8,6]
输出：3
解释：left = [5,0,3]，right = [8,6]

示例 2：

输入：nums = [1,1,1,0,6,12]
输出：4
解释：left = [1,1,1,0]，right = [6,12]

提示：

  • 2 <= nums.length <= 105
  • 0 <= nums[i] <= 106
  • 可以保证至少有一种方法能够按题目所描述的那样对 nums 进行划分。
