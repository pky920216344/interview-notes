  • 位运算
  • 数组
  • 待提交

逐字节状态机：首字节的前导 1 决定字符占几字节，remain 记还差几个 10 开头的续字节。

思路

  • 状态 remain：当前字符还欠几个续字节；> 0 时每个字节必须 10xxxxxx，否则 false。
  • remain == 0 时按首字节判长度：110→2 字节、1110→3 字节、11110→4 字节，10 开头或 11111 开头直接 false。
  • 扫完后 remain != 0 说明末尾缺续字节，也是 false。
  • 位运算取头部：b >> 6、b >> 5、b >> 4、b >> 3 分别对上 10、110、1110、11110。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean validUtf8(int[] data) {3        int remain = 0;   // 当前字符还差几个 10xxxxxx 续字节4        for (int b : data) {5            if (remain > 0) {6                // 续字节必须以 10 开头7                if ((b >> 6) != 0b10) return false;8                remain--;9            } else if ((b >> 5) == 0b110) remain = 1;    // 110xxxxx：2 字节10            else if ((b >> 4) == 0b1110) remain = 2;     // 1110xxxx：3 字节11            else if ((b >> 3) == 0b11110) remain = 3;    // 11110xxx：4 字节12            else if ((b >> 7) != 0) return false;        // 首字节非法：10 开头或 11111 开头13        }14        // 扫完还有字符没凑齐字节：false15        return remain == 0;16    }17}
题目

给定一个表示数据的整数数组 data ，返回它是否为有效的 UTF-8 编码。

UTF-8 中的一个字符可能的长度为 1 到 4 字节，遵循以下的规则：

  1. 对于 1 字节 的字符，字节的第一位设为 0 ，后面 7 位为这个符号的 unicode 码。
  2. 对于 n 字节 的字符 (n > 1)，第一个字节的前 n 位都设为1，第 n+1 位设为 0 ，后面字节的前两位一律设为 10 。剩下的没有提及的二进制位，全部为这个符号的 unicode 码。

这是 UTF-8 编码的工作方式：

      Number of Bytes  |        UTF-8 octet sequence
                       |              (binary)
   --------------------+---------------------------------------------
            1          | 0xxxxxxx
            2          | 110xxxxx 10xxxxxx
            3          | 1110xxxx 10xxxxxx 10xxxxxx
            4          | 11110xxx 10xxxxxx 10xxxxxx 10xxxxxx

x 表示二进制形式的一位，可以是 0 或 1。

注意：输入是整数数组。只有每个整数的 最低 8 个有效位 用来存储数据。这意味着每个整数只表示 1 字节的数据。

示例 1：

输入：data = [197,130,1]
输出：true
解释：数据表示字节序列:11000101 10000010 00000001。
这是有效的 utf-8 编码，为一个 2 字节字符，跟着一个 1 字节字符。

示例 2：

输入：data = [235,140,4]
输出：false
解释：数据表示 8 位的序列: 11101011 10001100 00000100.
前 3 位都是 1 ，第 4 位为 0 表示它是一个 3 字节字符。
下一个字节是开头为 10 的延续字节，这是正确的。
但第二个延续字节不以 10 开头，所以是不符合规则的。

提示:

  • 1 <= data.length <= 2 * 104
  • 0 <= data[i] <= 255
