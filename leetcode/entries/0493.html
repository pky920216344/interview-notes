归并排序：两半各自有序后，右半每移一格，左半里 > 2×它的下标一次算清，再归并。

思路

  • 翻转对带 i < j，按「左半 vs 右半」统计：递归排序两半，跨中点的对在合并前算。
  • 两半已有序：右半 j 右移一格时，左半里所有 > 2×a[j] 的下标正好是 i..mid，一次 += mid−i+1。
  • 比较写成 long：2×a[j] 会溢出 int（如 2×(−2³¹)）。
  • 统计完照常归并成有序段，逐层向上加总。

时间复杂度 O(n log n)，空间复杂度 O(n)
1class Solution {2    private int count;3    private int[] tmp;4 5    public int reversePairs(int[] nums) {6        count = 0;7        tmp = new int[nums.length];8        sort(nums, 0, nums.length - 1);9        return count;10    }11 12    // 归并排序 [lo, hi]；合并前先统计跨中点的翻转对13    private void sort(int[] a, int lo, int hi) {14        if (lo >= hi) return;15        int mid = (lo + hi) >>> 1;16        sort(a, lo, mid);17        sort(a, mid + 1, hi);18        // 两半各自有序：右半 j 右移一格，左半里 > 2×a[j] 的全算上19        int i = lo, j = mid + 1;20        while (i <= mid && j <= hi) {21            if ((long) a[i] > 2L * a[j]) {22                count += mid - i + 1;23                j++;24            } else {25                i++;26            }27        }28        // 标准归并：把 [lo, hi] 合并成有序29        i = lo;30        j = mid + 1;31        int k = lo;32        while (i <= mid && j <= hi) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];33        while (i <= mid) tmp[k++] = a[i++];34        while (j <= hi) tmp[k++] = a[j++];35        System.arraycopy(tmp, lo, a, lo, hi - lo + 1);36    }37}
题目

给定一个数组 nums ，如果 i < j 且 nums[i] > 2*nums[j] 我们就将 (i, j) 称作一个重要翻转对。

你需要返回给定数组中的重要翻转对的数量。

示例 1:

输入: [1,3,2,3,1]
输出: 2

示例 2:

输入: [2,4,3,5,1]
输出: 3

注意:

  1. 给定数组的长度不会超过50000。
  2. 输入数组中的所有数字都在32位整数的表示范围内。
