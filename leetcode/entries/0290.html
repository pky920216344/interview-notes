双向哈希映射：字母→单词、单词→字母各查一遍，任一方向冲突就 false；词数和字母数先比相等。

思路

  • 先 split(" ") 拆词，词数不等于字母数直接 false。
  • c2w 查「这个字母是否已配过别的词」，w2c 查「这个词是否已配过别的字母」。
  • 两个方向都要查——只查单向会漏掉 abba/dog dog dog dog 这种多对一。
  • 每对通过检查就同时写进两张表，全部通过返回 true。

图解

最优解

时间复杂度 O(n + m)，空间复杂度 O(n + m)
1import java.util.*;2 3class Solution {4    public boolean wordPattern(String pattern, String s) {5        String[] words = s.split(" ");6        if (words.length != pattern.length()) return false;7        Map<Character, String> c2w = new HashMap<>();8        Map<String, Character> w2c = new HashMap<>();9        for (int i = 0; i < pattern.length(); i++) {10            char c = pattern.charAt(i);11            String w = words[i];12            // 双向各查一次：字母已配过别的词、或词已配过别的字母，都算冲突13            if (c2w.containsKey(c) && !c2w.get(c).equals(w)) return false;14            if (w2c.containsKey(w) && w2c.get(w) != c) return false;15            c2w.put(c, w);16            w2c.put(w, c);17        }18        return true;19    }20}
题目

给定一种规律 pattern 和一个字符串 s ，判断 s 是否遵循相同的规律。

这里的 遵循 指完全匹配，例如， pattern 里的每个字母和字符串 s中的每个非空单词之间存在着双向连接的对应规律。具体来说：

  • pattern 中的每个字母都 恰好 映射到 s 中的一个唯一单词。
  • s 中的每个唯一单词都 恰好 映射到 pattern 中的一个字母。
  • 没有两个字母映射到同一个单词，也没有两个单词映射到同一个字母。

示例1:

输入: pattern = "abba", s = "dog cat cat dog"
输出: true

示例 2:

输入:pattern = "abba", s = "dog cat cat fish"
输出: false

示例 3:

输入: pattern = "aaaa", s = "dog cat cat dog"
输出: false

提示:

  • 1 <= pattern.length <= 300
  • pattern 只包含小写英文字母
  • 1 <= s.length <= 3000
  • s 只包含小写英文字母和 ' '
  • s 不包含 任何前导或尾随对空格
  • s 中每个单词都被 单个空格 分隔
