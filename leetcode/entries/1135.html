1135. 最低成本连通所有城市

  • 中等
  • 频度 2
  • 图算法
  • 并查集
  • 并查集
  • 图
  • 最小生成树
  • 堆（优先队列）
  • 未经力扣验证

Kruskal 最小生成树：边按成本排序后从小到大收，并查集判两端是否已连通；收不满 n−1 条就是不连通。

思路

  • 想要总成本最小又恰好连通：就是最小生成树，n 个城市恰好收 n−1 条边。
  • 边按成本升序排序，逐条看：两端不同根才收（并查集合并），同根说明已有更便宜的路径，收了只会成环。
  • 收满 n−1 条提前返回；扫完仍不满，说明图不连通，返回 -1（n=1 时收 0 条返回 0，靠「不满才返回 -1」天然正确）。

时间复杂度 O(E log E)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    private int[] pa;5 6    public int minimumCost(int n, int[][] connections) {7        pa = new int[n + 1];8        for (int i = 1; i <= n; i++) pa[i] = i;   // 城市编号 1..n9        // Kruskal：边按成本从小到大收，用并查集判断两端是否已连通10        Arrays.sort(connections, (a, b) -> a[2] - b[2]);11        int cost = 0, merged = 0;12        for (int[] e : connections) {13            int ra = find(e[0]), rb = find(e[1]);14            if (ra == rb) continue;   // 两端已连通：这条边只会成环，跳过15            pa[ra] = rb;16            cost += e[2];17            if (++merged == n - 1) return cost;18        }19        return merged == n - 1 ? cost : -1;   // 收不满 n-1 条：图不连通20    }21 22    private int find(int x) {23        while (pa[x] != x) {24            pa[x] = pa[pa[x]];   // 路径减半压缩25            x = pa[x];26        }27        return x;28    }29}
