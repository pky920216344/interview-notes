26 叉前缀树：结点存 26 个孩子指针和 isEnd；路径在即前缀在，isEnd 才算完整单词。

思路

  • 每个结点有 children[26] 和 isEnd；插入沿字符往下走，缺结点就新建，走完把末端 isEnd = true。
  • 公共查找 find(s)：沿字符走，路径断了返回 null。
  • search：走到头且 isEnd（路径在但没标记结尾，只是前缀）；startsWith：只要路径存在。

图解

最优解

时间复杂度 insert/search/startsWith 均 O(L)，L 为字符串长，空间复杂度 O(总结点数 × 26)
1import java.util.*;2 3class Trie {4    // 26 叉孩子数组 + isEnd：路径在即前缀在，isEnd 才算完整单词5    private final Trie[] children = new Trie[26];6    private boolean isEnd;7 8    public Trie() {9    }10 11    public void insert(String word) {12        Trie cur = this;13        for (char c : word.toCharArray()) {14            int i = c - 'a';15            if (cur.children[i] == null) cur.children[i] = new Trie();16            cur = cur.children[i];17        }18        // 路径终点标记为完整单词19        cur.isEnd = true;20    }21 22    // 沿字符往下走，路径断了返回 null23    private Trie find(String s) {24        Trie cur = this;25        for (char c : s.toCharArray()) {26            cur = cur.children[c - 'a'];27            if (cur == null) return null;28        }29        return cur;30    }31 32    public boolean search(String word) {33        Trie node = find(word);34        // 要走到头且标记过结尾：只是前缀不算35        return node != null && node.isEnd;36    }37 38    public boolean startsWith(String prefix) {39        // 只要路径存在即可，不要求 isEnd40        return find(prefix) != null;41    }42}
题目

Trie（发音类似 "try"）或者说 前缀树 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 Trie 类：

  • Trie() 初始化前缀树对象。
  • void insert(String word) 向前缀树中插入字符串 word 。
  • boolean search(String word) 如果字符串 word 在前缀树中，返回 true（即，在检索之前已经插入）；否则，返回 false 。
  • boolean startsWith(String prefix) 如果之前已经插入的字符串 word 的前缀之一为 prefix ，返回 true ；否则，返回 false 。

示例：

输入
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
输出
[null, null, true, false, true, null, true]

解释
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 True
trie.search("app");     // 返回 False
trie.startsWith("app"); // 返回 True
trie.insert("app");
trie.search("app");     // 返回 True

提示：

  • 1 <= word.length, prefix.length <= 2000
  • word 和 prefix 仅由小写英文字母组成
  • insert、search 和 startsWith 调用次数 总计 不超过 3 * 104 次
