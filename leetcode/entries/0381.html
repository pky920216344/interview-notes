数组紧凑存所有出现（可重复），哈希表 val→下标集合；删除时抓任一出现下标，用尾部元素搬来补洞。

思路

  • insert 一律追加到数组尾（重复也照加）；getRandom 均匀抽下标，出现几次就是几份概率。
  • pos[val] 是它所有出现下标的集合；删除时抓任意一个 i，把尾部元素搬到 i 补洞，数组保持紧凑。
  • 顺序坑：先从 val 的集合删掉 i，再给尾元素换下标——当 val 自己就是尾元素时，两个操作动的是同一个集合，反了会把新下标误删。
  • 次数归零就 pos.remove(val)：下次 insert 才能正确返回「第一次插入」。

时间复杂度 每步平均 O(1)，空间复杂度 O(出现总个数)
1import java.util.*;2 3class RandomizedCollection {4    private final List<Integer> vals = new ArrayList<>();           // 所有出现（可重复）紧凑存放5    private final Map<Integer, Set<Integer>> pos = new HashMap<>(); // val → 它的出现下标集合6    private final Random rnd = new Random();7 8    public RandomizedCollection() { }9 10    public boolean insert(int val) {11        Set<Integer> set = pos.computeIfAbsent(val, k -> new HashSet<>());12        boolean first = set.isEmpty();   // 空集合只会是新建的：即 val 此前不存在13        set.add(vals.size());            // 新出现的位置在数组尾14        vals.add(val);15        return first;16    }17 18    public boolean remove(int val) {19        Set<Integer> set = pos.get(val);20        if (set == null) return false;21        int i = set.iterator().next();       // 抓 val 任意一个出现下标22        int last = vals.get(vals.size() - 1);23        set.remove(i);                       // 先从 val 的集合里删掉这个下标24        vals.set(i, last);                   // 尾元素搬过来补洞25        if (i < vals.size() - 1) {26            pos.get(last).remove(vals.size() - 1);   // 尾元素旧下标作废27            pos.get(last).add(i);                    // 记录尾元素的新下标28        }29        vals.remove(vals.size() - 1);30        if (set.isEmpty()) pos.remove(val);  // 次数归零删 key，insert 才能判「第一次」31        return true;32    }33 34    public int getRandom() {35        return vals.get(rnd.nextInt(vals.size()));36    }37}
题目

RandomizedCollection 是一种包含数字集合(可能是重复的)的数据结构。它应该支持插入和删除特定元素，以及删除随机元素。

实现 RandomizedCollection 类:

  • RandomizedCollection()初始化空的 RandomizedCollection 对象。
  • bool insert(int val) 将一个 val 项插入到集合中，即使该项已经存在。如果该项不存在，则返回 true ，否则返回 false 。
  • bool remove(int val) 如果存在，从集合中移除一个 val 项。如果该项存在，则返回 true ，否则返回 false 。注意，如果 val 在集合中出现多次，我们只删除其中一个。
  • int getRandom() 从当前的多个元素集合中返回一个随机元素。每个元素被返回的概率与集合中包含的相同值的数量 线性相关 。

您必须实现类的函数，使每个函数的 平均 时间复杂度为 O(1) 。

注意：生成测试用例时，只有在 RandomizedCollection 中 至少有一项 时，才会调用 getRandom 。

示例 1:

输入
["RandomizedCollection", "insert", "insert", "insert", "getRandom", "remove", "getRandom"]
[[], [1], [1], [2], [], [1], []]
输出
[null, true, false, true, 2, true, 1]

解释
RandomizedCollection collection = new RandomizedCollection();// 初始化一个空的集合。
collection.insert(1);   // 返回 true，因为集合不包含 1。
                        // 将 1 插入到集合中。
collection.insert(1);   // 返回 false，因为集合包含 1。
                        // 将另一个 1 插入到集合中。集合现在包含 [1,1]。
collection.insert(2);   // 返回 true，因为集合不包含 2。
                        // 将 2 插入到集合中。集合现在包含 [1,1,2]。
collection.getRandom(); // getRandom 应当:
                        // 有 2/3 的概率返回 1,
                        // 1/3 的概率返回 2。
collection.remove(1);   // 返回 true，因为集合包含 1。
                        // 从集合中移除 1。集合现在包含 [1,2]。
collection.getRandom(); // getRandom 应该返回 1 或 2，两者的可能性相同。

提示:

  • -231 <= val <= 231 - 1
  • insert, remove 和 getRandom 最多 总共 被调用 2 * 105 次
  • 当调用 getRandom 时，数据结构中 至少有一个 元素
