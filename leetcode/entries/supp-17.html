补充题17. 两个有序数组第k小的数

  • 困难
  • 频度 9
  • 二分查找
  • 未经力扣验证

二分「a 贡献前 i 个」：合法切分要求 a 的边界值 ≤ b 的下一个、b 的边界值 ≤ a 的下一个；第 k 小就是两侧边界里较大的。

思路

  • 合并后的前 k 个数 = a 的前 i 个 + b 的前 k-i 个；要找的是一个合法切分：a[i-1] ≤ b[k-i] 且 b[k-i-1] ≤ a[i]。
  • i 越大「a 边界 ≤ b 边界」越难成立：该条件随 i 单调变假，可以二分出最大的合法 i。
  • 范围 [max(0, k-m), min(k, n)]：a 至多贡献 k 个（b 要凑满 k），也至多贡献自己全部；i=0 或 b 全贡献时切分天然合法。
  • 第 k 小 = max(a[i-1], b[k-i-1])（某侧没拿就视为 -∞）；边界四值两两比较，越界即取 ±∞。

最优解

时间复杂度 O(log k)，空间复杂度 O(1)
1class Solution {2    // 合并两个升序数组后的第 k 小（k 从 1 数）：二分「a 贡献前 i 个」，比较切分边界3    public int kth(int[] a, int[] b, int k) {4        int n = a.length, m = b.length;5        int lo = Math.max(0, k - m), hi = Math.min(k, n);   // a 贡献 i 个的可行范围6        while (lo < hi) {                                   // 找最大的合法 i7            int i = (lo + hi + 1) / 2;8            // i=0 或 b 全贡献时切分天然合法；否则要求 a 的第 i 个 ≤ b 的第 k-i+1 个9            if (i == 0 || k - i == m || a[i - 1] <= b[k - i]) lo = i;10            else hi = i - 1;11        }12        // 第 k 小 = 两侧「最后拿到的」里较大的那个（没拿的一侧视为 -∞）13        int l1 = lo >= 1 ? a[lo - 1] : Integer.MIN_VALUE;14        int l2 = k - lo >= 1 ? b[k - lo - 1] : Integer.MIN_VALUE;15        return Math.max(l1, l2);16    }17}
