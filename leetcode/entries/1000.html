1000. 合并石头的最低成本

  • 困难
  • 频度 3
  • 动态规划
  • 前缀和/差分
  • 数组
  • 动态规划
  • 前缀和
  • 待提交

区间 DP 三维状态：dp[i][j][p] = 把 i..j 合成 p 堆的最低成本；p=1 时额外加整段和作为「最后一合」的成本。

思路

  • 先判可行性：每次合并少 k-1 堆，要剩 1 堆必须 (n-1) % (k-1) == 0，否则 -1。
  • dp[i][j][p] = min_t dp[i][t][p-1] + dp[t+1][j][1]：右段先并成 1 堆再并进左边。
  • 关键：dp[i][j][1] = dp[i][j][k] + sum(i..j)——并成 1 堆的最后一下要搬整段石子，成本就是区间和（前缀和 O(1) 取）。
  • 不可达状态存 INF，转移前判 < INF 防止把垃圾值加进答案。

图解

最优解

时间复杂度 O(n³·k)，空间复杂度 O(n²·k)
1class Solution {2    public int mergeStones(int[] stones, int k) {3        int n = stones.length;4        // 每次合并少 k-1 堆，最后要剩 1 堆：n-1 必须是 k-1 的倍数5        if ((n - 1) % (k - 1) != 0) return -1;6        int[] pre = new int[n + 1];   // 前缀和：区间和 = pre[j+1] - pre[i]7        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + stones[i];8        final int INF = 1 << 20;9        // dp[i][j][p]：把 i..j 合成 p 堆的最低成本；不可达就是 INF10        int[][][] dp = new int[n][n][k + 1];11        for (int i = 0; i < n; i++) {12            for (int j = i; j < n; j++) {13                for (int p = 1; p <= k; p++) dp[i][j][p] = INF;14            }15            dp[i][i][1] = 0;   // 单堆不用合16        }17        for (int len = 2; len <= n; len++) {18            for (int i = 0; i + len <= n; i++) {19                int j = i + len - 1;20                for (int p = 2; p <= k; p++) {21                    int best = INF;22                    for (int t = i; t < j; t++) {23                        // 左边 i..t 合成 p-1 堆，右边 t+1..j 合成 1 堆24                        if (dp[i][t][p - 1] < INF && dp[t + 1][j][1] < INF) {25                            best = Math.min(best, dp[i][t][p - 1] + dp[t + 1][j][1]);26                        }27                    }28                    dp[i][j][p] = best;29                }30                // k 堆并成 1 堆这一下的成本就是整段石子总数31                if (dp[i][j][k] < INF) dp[i][j][1] = dp[i][j][k] + pre[j + 1] - pre[i];32            }33        }34        return dp[0][n - 1][1];35    }36}
题目

有 n 堆石头排成一排，第 i 堆中有 stones[i] 块石头。

每次 移动 需要将 连续的 k 堆石头合并为一堆，而这次移动的成本为这 k 堆中石头的总数。

返回把所有石头合并成一堆的最低成本。如果无法合并成一堆，返回 -1 。

示例 1：

输入：stones = [3,2,4,1], K = 2
输出：20
解释：
从 [3, 2, 4, 1] 开始。
合并 [3, 2]，成本为 5，剩下 [5, 4, 1]。
合并 [4, 1]，成本为 5，剩下 [5, 5]。
合并 [5, 5]，成本为 10，剩下 [10]。
总成本 20，这是可能的最小值。

示例 2：

输入：stones = [3,2,4,1], K = 3
输出：-1
解释：任何合并操作后，都会剩下 2 堆，我们无法再进行合并。所以这项任务是不可能完成的。.

示例 3：

输入：stones = [3,5,1,2,6], K = 3
输出：25
解释：
从 [3, 5, 1, 2, 6] 开始。
合并 [5, 1, 2]，成本为 8，剩下 [3, 8, 6]。
合并 [3, 8, 6]，成本为 17，剩下 [17]。
总成本 25，这是可能的最小值。

提示：

  • n == stones.length
  • 1 <= n <= 30
  • 1 <= stones[i] <= 100
  • 2 <= k <= 30
