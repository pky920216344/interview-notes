区间 DP 算净胜分：dp[i][j] = 当前玩家在 [i,j] 的最大「自己 − 对手」= max(nums[i]−dp[i+1][j], nums[j]−dp[i][j-1])。

思路

  • dp[i][j]：轮到当前玩家时，他在 [i,j] 上能拿到的最大净胜分。
  • 拿走一端后轮到对手，对手在剩余区间的净胜分要减掉：拿左 nums[i] − dp[i+1][j]，拿右 nums[j] − dp[i][j-1]，取大。
  • dp[i][i] = nums[i]（只剩一个数全拿），i 从右往左填。
  • 答案 dp[0][n-1] >= 0：净胜分非负（含平局）玩家 1 就赢。

时间复杂度 O(n²)，空间复杂度 O(n²)
1class Solution {2    public boolean predictTheWinner(int[] nums) {3        int n = nums.length;4        // dp[i][j]：当前轮到谁，他在 [i,j] 上能拿到的最大「净胜分」（自己 − 对手）5        int[][] dp = new int[n][n];6        for (int i = n - 1; i >= 0; i--) {7            dp[i][i] = nums[i];               // 区间只剩一个数，先手全拿8            for (int j = i + 1; j < n; j++) {9                // 拿走一端后轮到对手；对手在剩余区间的净胜分要减掉10                dp[i][j] = Math.max(nums[i] - dp[i + 1][j], nums[j] - dp[i][j - 1]);11            }12        }13        return dp[0][n - 1] >= 0;             // 净胜分 ≥ 0（含平局）就算玩家 1 赢14    }15}
题目

给你一个整数数组 nums。

玩家 1 和玩家 2 基于这个数组设计了一个游戏。

玩家 1 和玩家 2 轮流进行自己的回合，玩家 1 先手。开始时，两个玩家的初始分值都是 0 。

每一回合，玩家从数组的 任意一端 取一个数字（即，nums[0] 或 nums[nums.length - 1]），取到的数字将会从数组中 移除（数组长度减 1 ）。玩家选中的数字将会加到他的得分上。当数组中没有剩余数字可取时，游戏结束。

如果玩家 1 能成为赢家，返回 true 。

注意，如果两个玩家得分相等，同样认为玩家 1 是游戏的赢家。你可以假设每个玩家的玩法都会使他的分数最大化。

示例 1：

输入：nums = [1,5,2]

输出：false

解释：

  • 玩家 1 必须先取 1 或 2，两种选择都会导致相同的结果。
  • 如果玩家 1 取 1，数组变为 [5, 2]。玩家 2 取 5，剩下 2 给玩家 1。
  • 如果玩家 1 取 2，数组变为 [1, 5]。玩家 2 取 5，剩下 1 给玩家 1。
  • 无论哪种情况，玩家 1 最终得到 1 + 2 = 3，玩家 2 得到 5。玩家 1 永远无法获胜，所以返回 false。

示例 2：

输入：nums = [1,5,233,7]

输出：true

解释：

  • 玩家 1 先取 1，剩下 [5,233,7]。然后玩家 2 必须在 5 和 7 之间选择，无论玩家 2 选择哪个数字，玩家 1 在下一次回合都可以取 233。
  • 玩家 1 的得分（234）高于玩家 2（12），所以返回 true。

提示：

  • 1 <= nums.length <= 20
  • 0 <= nums[i] <= 107
