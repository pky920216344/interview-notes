前序第一个是根；哈希存「中序值→下标」一次定位，把中序切成左右两半递归建树。

思路

  • 中序里根的左边全是左子树、右边全是右子树，按区间 [lo, hi] 递归。
  • 哈希表 pos 把「在中序里找根」从 O(n) 降到 O(1)，整体 O(n)。
  • 全局 pre 指向前序；先递归左再递归右，pre 恰好按前序顺序推进。
  • 多次调用要复位 pre 和哈希表。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    // pos：中序值 -> 下标；pre：前序里下一个该当根的位置5    private Map<Integer, Integer> pos = new HashMap<>();6    private int pre;7 8    public TreeNode deduceTree(int[] preorder, int[] inorder) {9        // 每次调用先复位，防上一次调用的残留10        pre = 0;11        pos.clear();12        for (int i = 0; i < inorder.length; i++) pos.put(inorder[i], i);13        return build(preorder, 0, inorder.length - 1);14    }15 16    // 中序区间 [lo, hi] 建树：先取前序当前值当根，再切左右两半17    private TreeNode build(int[] preorder, int lo, int hi) {18        if (lo > hi) return null;19        TreeNode root = new TreeNode(preorder[pre++]);20        int mid = pos.get(root.val);21        root.left = build(preorder, lo, mid - 1);22        // 先左后右，pre 恰好按前序顺序推进23        root.right = build(preorder, mid + 1, hi);24        return root;25    }26}
题目

某二叉树的先序遍历结果记录于整数数组 preorder，它的中序遍历结果记录于整数数组 inorder。请根据 preorder 和 inorder 的提示构造出这棵二叉树并返回其根节点。

注意：preorder 和 inorder 中均不含重复数字。

示例 1：

输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]

输出: [3,9,20,null,null,15,7]

示例 2:

输入: preorder = [-1], inorder = [-1]

输出: [-1]

提示:

  • 1 <= preorder.length <= 3000
  • inorder.length == preorder.length
  • -3000 <= preorder[i], inorder[i] <= 3000
  • inorder 均出现在 preorder
  • preorder 保证 为二叉树的前序遍历序列
  • inorder 保证 为二叉树的中序遍历序列

注意：本题与主站 105 题重复：https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/
