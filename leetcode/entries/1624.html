1624. 两个相同字符之间的最长子字符串

  • 哈希表

记每个字符最早出现的位置；再次见到 c 时用「当前位置 − 首次位置 − 1」更新答案；没有重复字符就是 -1。

思路

  • first[c] 存字符 c 第一次出现的下标，初始 -1 表示没见过。
  • 再次见到 c：候选答案是 i − first[c] − 1（两端的 c 本身不算长），取最大即可；用最早的位置一定最长。
  • 一遍扫描完成；初始答案 -1 正好覆盖「没有任何字符出现两次」的情况。

时间复杂度 O(n)，空间复杂度 O(26)
1import java.util.*;2 3class Solution {4    public int maxLengthBetweenEqualCharacters(String s) {5        int[] first = new int[26];6        Arrays.fill(first, -1);                       // first[c]：字符 c 最早出现的位置7        int ans = -1;8        for (int i = 0; i < s.length(); i++) {9            int c = s.charAt(i) - 'a';10            if (first[c] < 0) first[c] = i;           // 第一次见：记下位置11            else ans = Math.max(ans, i - first[c] - 1);   // 再次见：中间这段长 i - first - 112        }13        return ans;14    }15}
题目

给你一个字符串 s，请你返回 两个相同字符之间的最长子字符串的长度 ，计算长度时不含这两个字符。如果不存在这样的子字符串，返回 -1 。

子字符串 是字符串中的一个连续字符序列。

示例 1：

输入：s = "aa"
输出：0
解释：最优的子字符串是两个 'a' 之间的空子字符串。

示例 2：

输入：s = "abca"
输出：2
解释：最优的子字符串是 "bc" 。

示例 3：

输入：s = "cbzxy"
输出：-1
解释：s 中不存在出现出现两次的字符，所以返回 -1 。

示例 4：

输入：s = "cabbac"
输出：4
解释：最优的子字符串是 "abba" ，其他的非最优解包括 "bb" 和 "" 。

提示：

  • 1 <= s.length <= 300
  • s 只含小写英文字母
