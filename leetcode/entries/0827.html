先把每座岛染成独立编号并记下面积；再逐个 0 试填——1 + 四邻不同岛的面积之和，取最大。

思路

  • 两遍：DFS 染色把每座岛整体改成自己的编号（2 起），area[id] 记面积；之后格子的数值就是岛编号。
  • 对每个 0：看四邻出现过哪些不同编号（Set 去重，防止同一个岛被加两次），候选 = 1 + Σ面积。
  • 「不填」也是合法操作：现有最大岛先打底（全 1 网格就靠它返回 n²）。
  • n ≤ 500，用显式栈的迭代 DFS，避免递归 25 万层爆栈。

1import java.util.*;2 3class Solution {4    public int largestIsland(int[][] grid) {5        int n = grid.length;6        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};7        int[] area = new int[n * n + 2];              // 岛编号(从 2 起) → 面积8        int id = 2;9        for (int r = 0; r < n; r++) {10            for (int c = 0; c < n; c++) {11                if (grid[r][c] != 1) continue;12                // 迭代 DFS：整座岛染成编号 id，顺手数出面积13                Deque<int[]> stack = new ArrayDeque<>();14                stack.push(new int[]{r, c});15                grid[r][c] = id;16                int cnt = 0;17                while (!stack.isEmpty()) {18                    int[] cur = stack.pop();19                    cnt++;20                    for (int[] d : dirs) {21                        int x = cur[0] + d[0], y = cur[1] + d[1];22                        if (x >= 0 && x < n && y >= 0 && y < n && grid[x][y] == 1) {23                            grid[x][y] = id;24                            stack.push(new int[]{x, y});25                        }26                    }27                }28                area[id++] = cnt;29            }30        }31        int best = 0;32        for (int a : area) best = Math.max(best, a);   // 「不填」也是合法操作：现有最大岛先打底33        for (int r = 0; r < n; r++) {34            for (int c = 0; c < n; c++) {35                if (grid[r][c] != 0) continue;36                Set<Integer> around = new HashSet<>(); // 四邻里不同的岛各记一次（防同一岛重复加）37                for (int[] d : dirs) {38                    int x = r + d[0], y = c + d[1];39                    if (x >= 0 && x < n && y >= 0 && y < n && grid[x][y] >= 2) around.add(grid[x][y]);40                }41                int sum = 1;                            // 填上的这一格自己算 142                for (int t : around) sum += area[t];43                best = Math.max(best, sum);44            }45        }46        return best;47    }48}
题目

给你一个大小为 n x n 二进制矩阵 grid 。最多 只能将一格 0 变成 1 。

返回执行此操作后，grid 中最大的岛屿面积是多少？

岛屿 由一组上、下、左、右四个方向相连的 1 形成。

示例 1:

输入: grid = [[1, 0], [0, 1]]
输出: 3
解释: 将一格0变成1，最终连通两个小岛得到面积为 3 的岛屿。

示例 2:

输入: grid =[[1, 1], [1, 0]]
输出: 4
解释: 将一格0变成1，岛屿的面积扩大为 4。

示例 3:

输入: grid = [[1, 1], [1, 1]]
输出: 4
解释: 没有0可以让我们变成1，面积依然为 4。

提示：

  • n == grid.length
  • n == grid[i].length
  • 1 <= n <= 500
  • grid[i][j] 为 0 或 1
