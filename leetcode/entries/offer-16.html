剑指 Offer 16. Pow(x, n)

  • 中等
  • 频度 3
  • 位运算
  • 递归
  • 数学
  • 待提交

快速幂：把 |n| 按二进制拆开，base 不断平方，逢 1 的位乘进 ans；负指数最后统一取倒数。

思路

  • n 先升成 long 再取 |n|：n 可能是 Integer.MIN_VALUE，直接取负会溢出。
  • 循环里 base 每轮自乘（x→x²→x⁴…），当前位是 1 就 ans *= base。
  • 负指数放到最后取倒数：先算 x^|n| 再 1/ans。若一上来就用 1/x 当底数，大指数用例的精度过不了。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public double myPow(double x, int n) {3        // 快速幂：|n| 按二进制拆开，base 不断自乘平方，逢 1 的位把当时的 base 乘进结果4        long m = n;              // n 可能是 Integer.MIN_VALUE，直接取负会溢出，先升成 long5        boolean neg = m < 0;6        if (neg) m = -m;7        double ans = 1, base = x;8        while (m > 0) {9            if ((m & 1) == 1) ans *= base;   // 这一位是 1：结果乘上 x 的 2^k 次方10            base *= base;                    // base 自乘：从 x^(2^k) 变 x^(2^(k+1))11            m >>= 1;12        }13        // 负指数最后统一取倒数：先算 x^|n| 再除，精度才对（先取倒数会被大指数精度用例拒绝）14        return neg ? 1 / ans : ans;15    }16}
题目

实现 pow(x, n) ，即计算 x 的 n 次幂函数（即，xn）。

示例 1：

输入：x = 2.00000, n = 10
输出：1024.00000

示例 2：

输入：x = 2.10000, n = 3
输出：9.26100

示例 3：

输入：x = 2.00000, n = -2
输出：0.25000
解释：2-2 = 1/22 = 1/4 = 0.25

提示：

  • -100.0 < x < 100.0
  • -231 <= n <= 231-1
  • -104 <= xn <= 104
