81. 搜索旋转排序数组 II

  • 二分查找

二分：和右端相等时分不清哪半有序就 hi-- 缩一格；否则照 33 题判出有序的一半看 target 在不在里面。

思路

  • nums[mid] == target 直接返回；nums[mid] == nums[hi] 时有序性存疑（如 [1,0,1,1,1]），hi-- 逐步排除重复。
  • nums[mid] < nums[hi] 说明右半有序：target 落在 (nums[mid], nums[hi]] 才去右半，否则去左半。
  • 否则左半有序：target 落在 [nums[lo], nums[mid]) 才去左半，否则去右半。
  • 与 33 题唯一的区别就是多了 hi-- 这一步，最坏（全相同）退化成 O(n)。

图解

最优解

时间复杂度 O(log n) 均摊，最坏 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean search(int[] nums, int target) {3        int lo = 0, hi = nums.length - 1;4        while (lo <= hi) {5            int mid = (lo + hi) / 2;6            if (nums[mid] == target) return true;7            if (nums[mid] == nums[hi]) { hi--; continue; }   // 和右端相等时没法判断哪半有序，缩一格8            if (nums[mid] < nums[hi]) {   // 右半 [mid+1..hi] 有序9                if (target > nums[mid] && target <= nums[hi]) lo = mid + 1;10                else hi = mid - 1;11            } else {                      // 左半 [lo..mid-1] 有序12                if (target >= nums[lo] && target < nums[mid]) hi = mid - 1;13                else lo = mid + 1;14            }15        }16        return false;17    }18}
题目

已知存在一个按非降序排列的整数数组 nums ，数组中的值不必互不相同。

在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了 旋转 ，使数组变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]（下标 从 0 开始 计数）。例如， [0,1,2,4,4,4,5,6,6,7] 在下标 5 处经旋转后可能变为 [4,5,6,6,7,0,1,2,4,4] 。

给你 旋转后 的数组 nums 和一个整数 target ，请你编写一个函数来判断给定的目标值是否存在于数组中。如果 nums 中存在这个目标值 target ，则返回 true ，否则返回 false 。

你必须尽可能减少整个操作步骤。

示例 1：

输入：nums = [2,5,6,0,0,1,2], target = 0
输出：true

示例 2：

输入：nums = [2,5,6,0,0,1,2], target = 3
输出：false

提示：

  • 1 <= nums.length <= 5000
  • -104 <= nums[i] <= 104
  • 题目数据保证 nums 在预先未知的某个下标上进行了旋转
  • -104 <= target <= 104
