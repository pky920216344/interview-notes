组合数 DP：dp[i][s] = i 颗骰子点数和为 s 的组合数，新骰子的 6 个面把 dp[i-1] 累加到 s+1..s+6；最后除以 6^n。

思路

  • dp[s]：当前颗数下点数和为 s 的组合数；1 颗时 dp[1..6] = 1。
  • 再掷一颗：ndp[s+k] += dp[s]（k=1..6）——新和由上一轮的 s-1..s-6 六种来源累加，滚动数组即可。
  • 答案数组第 i 位对应点数和 num+i（共 5n+1 个），值为 dp[s] / 6^n；组合数用 long（6^11 ≈ 3.6e8 超过 int 的幂次累加安全，但除法前转 double）。

最优解

时间复杂度 O(n²)，空间复杂度 O(n)
1class Solution {2    public double[] statisticsProbability(int num) {3        // dp[s]：当前颗数下点数和为 s 的组合数；s 的范围 [dice, 6*dice]4        long[] dp = new long[6 * num + 1];5        for (int s = 1; s <= 6; s++) dp[s] = 1;6        // 再掷一颗：新和 s 由上一轮的 s-1..s-6 六种来源累加7        for (int dice = 2; dice <= num; dice++) {8            long[] ndp = new long[6 * num + 1];9            for (int s = dice - 1; s <= 6 * (dice - 1); s++) {10                for (int k = 1; k <= 6; k++) ndp[s + k] += dp[s];11            }12            dp = ndp;13        }14        // 组合数除以总方案数 6^num 得概率；数组第 i 位对应点数和 num+i15        long total = 1;16        for (int i = 0; i < num; i++) total *= 6;17        double[] ans = new double[5 * num + 1];18        for (int s = num; s <= 6 * num; s++) ans[s - num] = (double) dp[s] / total;19        return ans;20    }21}
题目

你选择掷出 num 个色子，请返回所有点数总和的概率。

你需要用一个浮点数数组返回答案，其中第 i 个元素代表这 num 个骰子所能掷出的点数集合中第 i 小的那个的概率。

输入：num = 3
