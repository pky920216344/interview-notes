265. 粉刷房子 II

  • 困难
  • 频度 2
  • 动态规划
  • 数组
  • 动态规划
  • 未经力扣验证

DP 每行只记最小和次小：当前色 = 上一行最小所在色就加次小，否则加最小，一遍扫完。

思路

  • dp[i][j] = 粉前 i 个房子且房子 i 涂色 j 的最小总代价；转移要上一行「非 j 色的最小」。
  • 上一行只需两个值：最小 min1（所在色 minIdx）和次小 min2；j == minIdx 用 min2，否则用 min1。
  • 每行顺手维护本行的最小/次小滚给下一行，空间 O(1)；k ≥ 2 保证次小一定存在。
  • 第 0 行没有上一行，相当于 min1 = 0、minIdx = -1，公式不用特判。

时间复杂度 O(nk)，空间复杂度 O(1)
1class Solution {2    public int minCostII(int[][] costs) {3        if (costs.length == 0) return 0;4        // 上一行的最小、次小和最小所在颜色；转移时同色只能用次小5        int min1 = 0, min2 = 0, minIdx = -1;6        for (int[] cost : costs) {7            int c1 = Integer.MAX_VALUE, c2 = Integer.MAX_VALUE, ci = -1;8            for (int j = 0; j < cost.length; j++) {9                int c = cost[j] + (j == minIdx ? min2 : min1);10                if (c < c1) { c2 = c1; c1 = c; ci = j; }11                else if (c < c2) c2 = c;12            }13            min1 = c1; min2 = c2; minIdx = ci;14        }15        return min1;16    }17}
