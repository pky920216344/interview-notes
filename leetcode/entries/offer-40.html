大根堆只留最小的 cnt 个：没满就进堆；满了且比堆顶小就换掉堆顶；堆顶是「前 cnt 小里最大的」守门员。

思路

  • 维护大小为 cnt 的大根堆：堆顶是已见过的 cnt 个最小值里最大的那个，相当于守门员。
  • 没满直接进堆；来了更小的就弹出堆顶、放进新值；不比堆顶小直接跳过。
  • cnt 为 0 时堆是空的，判 heap.isEmpty() 再 peek，别抛异常。

图解

最优解

时间复杂度 O(n log cnt)，空间复杂度 O(cnt)
1import java.util.*;2 3class Solution {4    public int[] inventoryManagement(int[] stock, int cnt) {5        // 大根堆只留「目前见过的 cnt 个最小值」，堆顶是它们里最大的守门员6        PriorityQueue<Integer> heap = new PriorityQueue<>((a, b) -> b - a);7        for (int v : stock) {8            // 没满：先收进来9            if (heap.size() < cnt) {10                heap.offer(v);11            // 满了且比堆顶小：换掉守门员12            } else if (!heap.isEmpty() && v < heap.peek()) {13                heap.poll();14                heap.offer(v);15            }16        }17        // 堆里剩下的就是最小的 cnt 个，题目对顺序不限18        int[] ans = new int[heap.size()];19        for (int i = 0; i < ans.length; i++) ans[i] = heap.poll();20        return ans;21    }22}
题目

仓库管理员以数组 stock 形式记录商品库存表，其中 stock[i] 表示对应商品库存余量。请返回库存余量最少的 cnt 个商品余量，返回 顺序不限。

示例 1：

输入：stock = [2,5,7,4], cnt = 1
输出：[2]

示例 2：

输入：stock = [0,2,3,6], cnt = 2
输出：[0,2] 或 [2,0]

提示：

  • 0 <= cnt <= stock.length <= 10000
  • 0 <= stock[i] <= 10000
