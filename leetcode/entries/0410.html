410. 分割数组的最大值

二分答案：给定上限 cap，贪心数「和超过 cap 就另起一段」的段数，段数 ≤ k 即可行。

思路

  • 答案范围 [最大元素, 总和]：下界是最大的单元素必占一段，上界是全部并成一段。
  • check(cap)：从左到右贪心，sum + x > cap 就另起一段；需要的段数 ≤ k 则 cap 可行。
  • cap 越大段数只会越少（单调）→ 二分最小的可行 cap：可行 hi = mid，不可行 lo = mid + 1。
  • 贪心每段尽量装满，段数才最少；连最少段数都超 k，其他切法只会更多，所以判定可信。

图解

最优解

时间复杂度 O(n log sum)，空间复杂度 O(1)
1class Solution {2    public int splitArray(int[] nums, int k) {3        long lo = 0, hi = 0;                       // 答案范围：[最大元素, 总和]4        for (int x : nums) { lo = Math.max(lo, x); hi += x; }5        while (lo < hi) {6            long mid = (lo + hi) >>> 1;7            if (check(nums, k, mid)) hi = mid;     // cap 可行 → 试试更小的8            else lo = mid + 1;                     // 不可行 → 只能更大9        }10        return (int) lo;11    }12 13    // 上限 cap 下贪心分段：和一旦超过 cap 就另起一段，段数 ≤ k 就可行14    private boolean check(int[] nums, int k, long cap) {15        int cnt = 1;                               // 至少一段16        long sum = 0;17        for (int x : nums) {18            if (sum + x > cap) { cnt++; sum = x; }   // 装不下 → 另起一段19            else sum += x;20        }21        return cnt <= k;22    }23}
题目

给定一个非负整数数组 nums 和一个整数 k ，你需要将这个数组分成 k 个非空的连续子数组，使得这 k 个子数组各自和的最大值 最小。

返回分割后最小的和的最大值。

子数组 是数组中连续的部分。

示例 1：

输入：nums = [7,2,5,10,8], k = 2
输出：18
解释：
一共有四种方法将 nums 分割为 2 个子数组。 
其中最好的方式是将其分为 [7,2,5] 和 [10,8] 。
因为此时这两个子数组各自的和的最大值为18，在所有情况中最小。

示例 2：

输入：nums = [1,2,3,4,5], k = 2
输出：9

示例 3：

输入：nums = [1,4,4], k = 3
输出：4

提示：

  • 1 <= nums.length <= 1000
  • 0 <= nums[i] <= 106
  • 1 <= k <= min(50, nums.length)
