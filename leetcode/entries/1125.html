1125. 最小的必要团队

技能压成 ≤16 位掩码，dp[mask] = 覆盖 mask 的最少人数，每人倒序松弛一次；从 full 回溯出团队。

思路

  • 技能只有 ≤ 16 项 → 每种「已凑齐的技能集合」是一个位掩码，共 2^k 个状态。
  • dp[mask] = 覆盖 mask 的最少人数；枚举每个人 p，dp[mask | skill[p]] = min(dp[mask | skill[p]], dp[mask] + 1)。
  • 每人倒序枚举 mask（mask | skill[p] ≥ mask），保证每人最多选一次；同时记 from/who 便于回溯。
  • 答案从 full 沿 from 走回 0，途经的 who 倒序就是团队；题目只要任一最小团队。

时间复杂度 O(m·2^k)（k = 技能数 ≤ 16），空间复杂度 O(2^k)
1import java.util.*;2 3class Solution {4    public int[] smallestSufficientTeam(String[] req_skills, List<List<String>> people) {5        int ns = req_skills.length, full = (1 << ns) - 1, m = people.size();6        Map<String, Integer> id = new HashMap<>();7        for (int i = 0; i < ns; i++) id.put(req_skills[i], i);8        // 每个人的技能集合压成位掩码9        int[] skill = new int[m];10        for (int i = 0; i < m; i++)11            for (String s : people.get(i)) skill[i] |= 1 << id.get(s);12        // dp[mask] = 覆盖技能集 mask 的最少人数；from/who 记录转移便于回溯13        int[] dp = new int[1 << ns], from = new int[1 << ns], who = new int[1 << ns];14        Arrays.fill(dp, 99);15        dp[0] = 0;16        for (int p = 0; p < m; p++) {17            // 倒序枚举旧状态，保证每人最多选一次18            for (int mask = full; mask >= 0; mask--) {19                int t = mask | skill[p];20                if (dp[mask] + 1 < dp[t]) { dp[t] = dp[mask] + 1; from[t] = mask; who[t] = p; }21            }22        }23        // 从 full 沿 from 走回 0，收集途经选的人24        List<Integer> team = new ArrayList<>();25        for (int mask = full; mask != 0; mask = from[mask]) team.add(who[mask]);26        Collections.reverse(team);27        int[] out = new int[team.size()];28        for (int i = 0; i < team.size(); i++) out[i] = team.get(i);29        return out;30    }31}
题目

作为项目经理，你规划了一份需求的技能清单 req_skills，并打算从备选人员名单 people 中选出些人组成一个「必要团队」（ 编号为 i 的备选人员 people[i] 含有一份该备选人员掌握的技能列表）。

所谓「必要团队」，就是在这个团队中，对于所需求的技能列表 req_skills 中列出的每项技能，团队中至少有一名成员已经掌握。可以用每个人的编号来表示团队中的成员：

  • 例如，团队 team = [0, 1, 3] 表示掌握技能分别为 people[0]，people[1]，和 people[3] 的备选人员。

请你返回 任一 规模最小的必要团队，团队成员用人员编号表示。你可以按 任意顺序 返回答案，题目数据保证答案存在。

示例 1：

输入：req_skills = ["java","nodejs","reactjs"], people = [["java"],["nodejs"],["nodejs","reactjs"]]
输出：[0,2]

示例 2：

输入：req_skills = ["algorithms","math","java","reactjs","csharp","aws"], people = [["algorithms","math","java"],["algorithms","math","reactjs"],["java","csharp","aws"],["reactjs","csharp"],["csharp","math"],["aws","java"]]
输出：[1,2]

提示：

  • 1 <= req_skills.length <= 16
  • 1 <= req_skills[i].length <= 16
  • req_skills[i] 由小写英文字母组成
  • req_skills 中的所有字符串 互不相同
  • 1 <= people.length <= 60
  • 0 <= people[i].length <= 16
  • 1 <= people[i][j].length <= 16
  • people[i][j] 由小写英文字母组成
  • people[i] 中的所有字符串 互不相同
  • people[i] 中的每个技能是 req_skills 中的技能
  • 题目数据保证「必要团队」一定存在
