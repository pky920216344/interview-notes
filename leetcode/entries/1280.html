1280. 学生们参加各科测试的次数

  • 简单
  • 频度 7
  • SQL
  • 数据库
  • 力扣已通过

先 CROSS JOIN 补全「每个学生 × 每个出现过的科目」的全部组合，再 LEFT JOIN 统计每人每科考试次数，COUNT 只数匹配行所以没考就是 0。

思路

  • 难点不是计数，是补全：没参加考试的学生×科目组合也要输出 0 行。
  • 科目清单来自 Subjects 表（不是 Examinations 里出现的科目——从没被考过的科目也要输出），CROSS JOIN Subjects 把（学生, 科目）展开成全部组合。
  • LEFT JOIN Examinations 按（学生, 科目）双键连表，COUNT(e.subject_name) 只数连上的行——COUNT(*) 会把没考试的行也算成 1，这是本题最大的坑。
  • GROUP BY 学生 + 科目后计数，最后按 student_id、subject_name 排序。

最优解

时间复杂度 O(S×E)，空间复杂度 O(S×E)
1-- 1415（codetop 1280）学生们参加各科测试的次数（MySQL）2-- 题意：Students(student_id, student_name)、Subjects(subject_name)、Examinations(student_id, subject_name)。3-- 对每个学生 × Subjects 表里的每个科目，报告参加考试次数（0 也要报），按 student_id、subject_name 排序。4-- 注意科目清单来自 Subjects 表（不是 Examinations 里的 DISTINCT——没被考过的科目也要输出 0 行）。5SELECT s.student_id,6       s.student_name,7       sub.subject_name,8       COUNT(e.subject_name) AS attended_exams9FROM Students s10CROSS JOIN Subjects sub11LEFT JOIN Examinations e12       ON s.student_id = e.student_id13      AND sub.subject_name = e.subject_name14GROUP BY s.student_id, s.student_name, sub.subject_name15ORDER BY s.student_id, sub.subject_name;
题目

学生表: Students

+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| student_id    | int     |
| student_name  | varchar |
+---------------+---------+
在 SQL 中，主键为 student_id（学生ID）。
该表内的每一行都记录有学校一名学生的信息。

科目表: Subjects

+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| subject_name | varchar |
+--------------+---------+
在 SQL 中，主键为 subject_name（科目名称）。
每一行记录学校的一门科目名称。

考试表: Examinations

+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| student_id   | int     |
| subject_name | varchar |
+--------------+---------+
这个表可能包含重复数据（换句话说，在 SQL 中，这个表没有主键）。
学生表里的一个学生修读科目表里的每一门科目。
这张考试表的每一行记录就表示学生表里的某个学生参加了一次科目表里某门科目的测试。

查询出每个学生参加每一门科目测试的次数，结果按 student_id 和 subject_name 排序。

查询结构格式如下所示。

示例 1：

输入：
Students table:
+------------+--------------+
| student_id | student_name |
+------------+--------------+
| 1          | Alice        |
| 2          | Bob          |
| 13         | John         |
| 6          | Alex         |
+------------+--------------+
Subjects table:
+--------------+
| subject_name |
+--------------+
| Math         |
| Physics      |
| Programming  |
+--------------+
Examinations table:
+------------+--------------+
| student_id | subject_name |
+------------+--------------+
| 1          | Math         |
| 1          | Physics      |
| 1          | Programming  |
| 2          | Programming  |
| 1          | Physics      |
| 1          | Math         |
| 13         | Math         |
| 13         | Programming  |
| 13         | Physics      |
| 2          | Math         |
| 1          | Math         |
+------------+--------------+
输出：
+------------+--------------+--------------+----------------+
| student_id | student_name | subject_name | attended_exams |
+------------+--------------+--------------+----------------+
| 1          | Alice        | Math         | 3              |
| 1          | Alice        | Physics      | 2              |
| 1          | Alice        | Programming  | 1              |
| 2          | Bob          | Math         | 1              |
| 2          | Bob          | Physics      | 0              |
| 2          | Bob          | Programming  | 1              |
| 6          | Alex         | Math         | 0              |
| 6          | Alex         | Physics      | 0              |
| 6          | Alex         | Programming  | 0              |
| 13         | John         | Math         | 1              |
| 13         | John         | Physics      | 1              |
| 13         | John         | Programming  | 1              |
+------------+--------------+--------------+----------------+
解释：
结果表需包含所有学生和所有科目（即便测试次数为0）：
Alice 参加了 3 次数学测试, 2 次物理测试，以及 1 次编程测试；
Bob 参加了 1 次数学测试, 1 次编程测试，没有参加物理测试；
Alex 啥测试都没参加；
John  参加了数学、物理、编程测试各 1 次。
