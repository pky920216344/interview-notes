4. 寻找两个正序数组的中位数

  • 困难
  • 频度 175
  • 二分查找
  • 数组
  • 二分查找
  • 分治
  • 本人已 AC

在较短数组上二分「划分线」，让左半部分的最大值 ≤ 右半部分的最小值；中位数就由四个边界值算出。

思路

  • 只在较短的 nums1 上二分（这样 j 不会越界）：左半共 half = (m + n + 1) / 2 个数，nums1 取 i 个，nums2 取 j = half - i 个，总数为奇数时左半多一个。
  • 四个边界值 l1、r1、l2、r2 是两条划分线两侧紧挨着的数，越界的分别用 MIN_VALUE、MAX_VALUE 代替。
  • l1 > r2：nums1 取多了，hi = i - 1；l2 > r1：取少了，lo = i + 1。
  • 两个条件都不触发，划分就是对的：奇数个返回 max(l1, l2)，偶数个返回 (max(l1, l2) + min(r1, r2)) / 2.0。

最优解

时间复杂度 O(log min(m, n))，空间复杂度 O(1)
1class Solution {2    public double findMedianSortedArrays(int[] nums1, int[] nums2) {3        // 只在较短的数组上二分，j 才不会越界4        if (nums1.length > nums2.length) {5            return findMedianSortedArrays(nums2, nums1);6        }7        int m = nums1.length, n = nums2.length;8        // 左半部分共 half 个数，总数为奇数时左边多一个9        int half = (m + n + 1) / 2;10        int lo = 0, hi = m;11        while (lo <= hi) {12            // 划分线：nums1 左边取 i 个，nums2 左边取 j 个13            int i = lo + (hi - lo) / 2, j = half - i;14            // 四个边界值，没有的用正负无穷代替15            int l1 = i == 0 ? Integer.MIN_VALUE : nums1[i - 1];16            int r1 = i == m ? Integer.MAX_VALUE : nums1[i];17            int l2 = j == 0 ? Integer.MIN_VALUE : nums2[j - 1];18            int r2 = j == n ? Integer.MAX_VALUE : nums2[j];19            if (l1 > r2) {20                // nums1 取多了，划分线左移21                hi = i - 1;22            } else if (l2 > r1) {23                // nums1 取少了，划分线右移24                lo = i + 1;25            } else {26                // 左半最大 <= 右半最小，划分正确27                int leftMax = Math.max(l1, l2);28                if ((m + n) % 2 == 1) return leftMax;29                return (leftMax + Math.min(r1, r2)) / 2.0;30            }31        }32        // 两个数组都有序时，一定会在循环里返回33        return 0;34    }35}
题目

给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请你找出并返回这两个正序数组的 中位数 。

算法的时间复杂度应该为 O(log (m+n)) 。

示例 1：

输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2

示例 2：

输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5

提示：

  • nums1.length == m
  • nums2.length == n
  • 0 <= m <= 1000
  • 0 <= n <= 1000
  • 1 <= m + n <= 2000
  • -106 <= nums1[i], nums2[i] <= 106
