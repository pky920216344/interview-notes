计数桶：h 不超过 n，引用超 n 的进桶 n；从 i=n 往下累加篇数 s，第一次 s ≥ i 的 i 就是答案。

思路

  • h 指数 ≤ 论文总数 n，桶数组只要 n + 1 格：cnt[Math.min(c, n)]++。
  • 从 i = n 往下扫，s 累加出「引用数 ≥ i」的论文篇数。
  • 第一次 s >= i 就返回 i；i 从大到小扫，保证取到最大的 h。
  • i = 0 时 s >= 0 必成立，循环必然返回；全 0 数组自然得到 0。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int hIndex(int[] citations) {3        // h 不可能超过论文篇数 n，引用数超过 n 的论文都记进最后一个桶4        int n = citations.length;5        int[] cnt = new int[n + 1];6        for (int c : citations) cnt[Math.min(c, n)]++;7        // 从大到小累加：s 是引用数 >= i 的论文篇数8        int s = 0;9        for (int i = n; i >= 0; i--) {10            s += cnt[i];11            // 至少有 i 篇论文被引用 >= i 次，h 指数就是 i12            if (s >= i) return i;13        }14        return 0;15    }16}
题目

给你一个整数数组 citations ，其中 citations[i] 表示研究者的第 i 篇论文被引用的次数。计算并返回该研究者的 h 指数。

根据维基百科上 h 指数的定义：h 代表“高引用次数” ，一名科研人员的 h 指数 是指他（她）至少发表了 h 篇论文，并且 至少 有 h 篇论文被引用次数大于等于 h 。如果 h 有多种可能的值，h 指数 是其中最大的那个。

示例 1：

输入：citations = [3,0,6,1,5]
输出：3 
解释：给定数组表示研究者总共有 5 篇论文，每篇论文相应的被引用了 3, 0, 6, 1, 5 次。
     由于研究者有 3 篇论文每篇 至少 被引用了 3 次，其余两篇论文每篇被引用 不多于 3 次，所以她的 h 指数是 3。

示例 2：

输入：citations = [1,3,1]
输出：1

提示：

  • n == citations.length
  • 1 <= n <= 5000
  • 0 <= citations[i] <= 1000
