347. 前 K 个高频元素

  • 中等
  • 频度 47
  • 哈希表
  • 数组
  • 哈希表
  • 分治
  • 桶排序
  • 计数
  • 快速选择
  • 排序
  • 堆（优先队列）
  • 力扣已通过

哈希计数 + 桶排序：桶下标就是出现次数，从最高频的桶往下收满 k 个；不比较、不建堆，O(n) 拿下。

思路

  • 先用哈希表数频次：cnt.merge(x, 1, Integer::sum) 一行完成计数。
  • 开 n+1 个桶，桶下标 = 出现次数，把每个值放进自己频次对应的桶；桶内不用排序。
  • 从 f = n 往下扫桶，遇到非空桶就整桶收进 out，收满 k 个立即停。
  • 桶排序避开比较，整体 O(n)；题目保证前 k 高频集合唯一，不存在截断处的频次并列。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] topKFrequent(int[] nums, int k) {5        // 计数：值 → 出现次数6        Map<Integer, Integer> cnt = new HashMap<>();7        for (int x : nums) cnt.merge(x, 1, Integer::sum);8        // 桶：下标 = 出现次数，桶里放出现这么多次的所有值9        List<List<Integer>> buckets = new ArrayList<>();10        for (int i = 0; i <= nums.length; i++) buckets.add(new ArrayList<>());11        for (Map.Entry<Integer, Integer> e : cnt.entrySet()) {12            buckets.get(e.getValue()).add(e.getKey());13        }14        // 从频次最高的桶往下收，收满 k 个为止15        int[] out = new int[k];16        int idx = 0;17        for (int f = nums.length; f >= 1 && idx < k; f--) {18            for (int x : buckets.get(f)) out[idx++] = x;19        }20        return out;21    }22}
题目

给你一个整数数组 nums 和一个整数 k ，请你返回其中出现频率前 k 高的元素。你可以按 任意顺序 返回答案。

示例 1：

输入：nums = [1,1,1,2,2,3], k = 2

输出：[1,2]

示例 2：

输入：nums = [1], k = 1

输出：[1]

示例 3：

输入：nums = [1,2,1,2,1,2,3,1,3,2], k = 2

输出：[1,2]

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104
  • k 的取值范围是 [1, 数组中不相同的元素的个数]
  • 题目数据保证答案唯一，换句话说，数组中前 k 个高频元素的集合是唯一的

进阶：你所设计算法的时间复杂度 必须 优于 O(n log n) ，其中 n 是数组大小。
