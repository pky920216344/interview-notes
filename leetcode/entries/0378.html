378. 有序矩阵中第 K 小的元素

  • 中等
  • 频度 27
  • 二分查找
  • 双指针
  • 数组
  • 二分查找
  • 矩阵
  • 排序
  • 堆（优先队列）
  • 力扣已通过

值域二分：在 [最小值, 最大值] 上猜 mid，用左下角阶梯走法 O(n) 数出 ≤ mid 的个数，不够 k 就抬高下界。

思路

  • 不在矩阵里二分，在值域上二分：low = matrix[0][0]，high = matrix[n-1][n-1]。
  • count(≤ mid) 有单调性，从左下角走阶梯：≤ mid 就整列都算上（count += row+1）往右走，否则往上走，一趟 O(n)。
  • count < k → 答案 > mid，low = mid + 1；否则 high = mid。
  • 收敛到 low == high 时它一定是矩阵里真实存在的数；端点 ±10⁹ 会溢出 int，用 long。

图解

最优解

时间复杂度 O(n log(max−min))，空间复杂度 O(1)
1class Solution {2    public int kthSmallest(int[][] matrix, int k) {3        int n = matrix.length;4        // 不在矩阵里二分，在「值域」上二分：答案夹在最小值和最大值之间；5        // 端点能到 ±10^9，差值会超 int，用 long 防溢出6        long low = matrix[0][0], high = matrix[n - 1][n - 1];7        while (low < high) {8            long mid = low + (high - low) / 2;9            // 从左下角沿阶梯数一遍 ≤ mid 的个数，一趟 O(n)10            int count = 0;11            for (int row = n - 1, col = 0; row >= 0 && col < n; ) {12                if (matrix[row][col] <= mid) { count += row + 1; col++; }13                else row--;14            }15            if (count < k) low = mid + 1;   // ≤ mid 的不够 k 个：答案比 mid 大16            else high = mid;                // 够了：答案 ≤ mid，mid 本身可能就是17        }18        return (int) low;   // 收敛到的 low 一定是矩阵里真实存在的数19    }20}
题目

给你一个 n x n 矩阵 matrix ，其中每行和每列元素均按升序排序，找到矩阵中第 k 小的元素。
请注意，它是 排序后 的第 k 小元素，而不是第 k 个 不同 的元素。

你必须找到一个内存复杂度优于 O(n2) 的解决方案。

示例 1：

输入：matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8
输出：13
解释：矩阵中的元素为 [1,5,9,10,11,12,13,13,15]，第 8 小元素是 13

示例 2：

输入：matrix = [[-5]], k = 1
输出：-5

提示：

  • n == matrix.length
  • n == matrix[i].length
  • 1 <= n <= 300
  • -109 <= matrix[i][j] <= 109
  • 题目数据 保证 matrix 中的所有行和列都按 非递减顺序 排列
  • 1 <= k <= n2
