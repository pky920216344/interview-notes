471. 编码最短长度的字符串

  • 困难
  • 频度 1
  • 动态规划
  • 字符串
  • 动态规划
  • 未经力扣验证

区间 DP：dp[i][j] = min(原样, 折叠成 次数[单位最优编码], 从 k 切开拼接两段最优)；按长度从小到大算。

思路

  • dp[i][j] 表示 s[i..j] 的最短编码，按区间长度从小到大填表；任何最优编码要么是整段折叠，要么在某个位置切成两半各自编码。
  • 折叠：若整段是前 p 个字符重复 len/p 次形成（len % p == 0 且逐字符对得上），候选就是 次数[dp[单位]]——单位直接用它的最优编码，所以嵌套折叠自动覆盖（abbbabbbc → 2[abbb]c，整串 → 2[2[abbb]c]）。
  • 三个候选取长度最小者；并列时保留先算出的那个，两边（Java/图解）顺序一致。
  • k[...] 形式长度至少 4，所以很短的子串折叠自然落选，不用特判。

时间复杂度 O(n^3)，空间复杂度 O(n^2)
1class Solution {2    public String encode(String s) {3        int n = s.length();4        // dp[i][j]：s[i..j] 的最短编码；短区间先算好，长区间在它们之上拼5        String[][] dp = new String[n][n];6        for (int len = 1; len <= n; len++) {7            for (int i = 0, j = i + len - 1; j < n; i++, j++) {8                String best = s.substring(i, j + 1);9                String folded = fold(s, i, j, dp);   // 整段折叠：次数[单位编码]10                if (folded != null && folded.length() < best.length()) best = folded;11                for (int k = i; k < j; k++) {        // 从中间切开，两段各自最优编码拼接12                    String joined = dp[i][k] + dp[k + 1][j];13                    if (joined.length() < best.length()) best = joined;14                }15                dp[i][j] = best;16            }17        }18        return dp[0][n - 1];19    }20 21    // 枚举所有周期 p（整段 = 前 p 个字符重复 len/p 次），返回最短的折叠形式，没有则 null22    private String fold(String s, int i, int j, String[][] dp) {23        int len = j - i + 1;24        String best = null;25        for (int p = 1; p * 2 <= len; p++) {26            if (len % p != 0) continue;27            boolean ok = true;28            for (int k = i + p; k <= j && ok; k++) ok = s.charAt(k) == s.charAt(k - p);29            if (!ok) continue;30            String cand = (len / p) + "[" + dp[i][i + p - 1] + "]";31            if (best == null || cand.length() < best.length()) best = cand;32        }33        return best;34    }35}
