624. 数组列表中的最大距离

  • 简单
  • 频度 1
  • 贪心
  • 贪心
  • 数组
  • 待提交

只看每个数组的两端：边扫边维护全局最小首和最大尾，当前数组用「尾−最小首、最大尾−首」更新答案。

思路

  • 数组各自升序，跨数组取两数的最大差一定出现在「某数组的尾」和「另一数组的首」之间。
  • 扫到第 i 个数组时先用之前的全局 minFirst/maxLast 更新答案，再把当前数组的首尾纳入——先算后更，避免自己和自己配对。
  • 只维护两个变量，不用真的比较所有数组对。

图解

最优解

时间复杂度 O(m)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int maxDistance(List<List<Integer>> arrays) {5        // 答案一定是「某个数组的尾」减「另一个数组的首」6        int ans = 0;7        int minFirst = arrays.get(0).get(0);8        int maxLast = arrays.get(0).get(arrays.get(0).size() - 1);9        for (int i = 1; i < arrays.size(); i++) {10            List<Integer> a = arrays.get(i);11            // 先算再更新：自己的首尾不能和自己配对12            ans = Math.max(ans, a.get(a.size() - 1) - minFirst);13            ans = Math.max(ans, maxLast - a.get(0));14            minFirst = Math.min(minFirst, a.get(0));15            maxLast = Math.max(maxLast, a.get(a.size() - 1));16        }17        return ans;18    }19}
题目

给定 m 个数组，每个数组都已经按照升序排好序了。

现在你需要从两个不同的数组中选择两个整数（每个数组选一个）并且计算它们的距离。两个整数 a 和 b 之间的距离定义为它们差的绝对值 |a-b| 。

返回最大距离。

示例 1：

输入：[[1,2,3],[4,5],[1,2,3]]
输出：4
解释：
一种得到答案 4 的方法是从第一个数组或者第三个数组中选择 1，同时从第二个数组中选择 5 。

示例 2：

输入：arrays = [[1],[1]]
输出：0

提示：

  • m == arrays.length
  • 2 <= m <= 105
  • 1 <= arrays[i].length <= 500
  • -104 <= arrays[i][j] <= 104
  • arrays[i] 以 升序 排序。
  • 所有数组中最多有 105 个整数。
