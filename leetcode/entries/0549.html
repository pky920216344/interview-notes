549. 二叉树最长连续序列 II

  • 频度 1

  • 深度优先搜索/递归
  • 树
  • 深度优先搜索
  • 二叉树
  • dp-on-trees
  • 未经力扣验证

后序 DFS 给每个结点带两个数：向下最长升链、最长降链；拐弯路径长 = 升 + 降 − 1，全局取最大。

思路

  • 路径可以「先向上再向下」拐一个弯（如 1-2-3-4），拐点两侧必是一条降链接一条升链。
  • dfs 返回 [inc, dec]：孩子值 == node.val+1 接升链，== node.val-1 接降链，各自取最大。
  • 每个结点处用 inc + dec - 1（自己被数了两次）更新答案；纯升/纯降路径自然被 dec=1/inc=1 覆盖。

时间复杂度 O(n)，空间复杂度 O(h)
1class Solution {2    private int best;3 4    public int longestConsecutive2(TreeNode root) {5        best = 0;                        // 防同一实例复用时残留旧值6        dfs(root);7        return best;8    }9 10    // 返回 [inc, dec]：从 node 向下走的最长升链/降链长度（都含 node 自己）11    private int[] dfs(TreeNode node) {12        if (node == null) return new int[2];13        int inc = 1, dec = 1;14        for (TreeNode child : new TreeNode[]{node.left, node.right}) {15            if (child == null) continue;16            int[] c = dfs(child);17            // 孩子值差 ±1：把孩子的升链/降链接上来18            if (child.val == node.val + 1) inc = Math.max(inc, c[0] + 1);19            if (child.val == node.val - 1) dec = Math.max(dec, c[1] + 1);20        }21        // 路径可拐弯（如 1-2-3-4）：升链 + 降链 − 1，node 数了两次22        best = Math.max(best, inc + dec - 1);23        return new int[]{inc, dec};24    }25}
