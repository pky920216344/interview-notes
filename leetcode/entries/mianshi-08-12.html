面试题 08.12. 八皇后

  • 困难
  • 频度 12
  • 回溯
  • 数组
  • 回溯
  • 待提交

逐行回溯：每行选一列放皇后，用列集合 + 两条对角线集合 O(1) 判冲突；r−c、r+c 是对角线的编号。

思路

  • 一行只能放一个皇后 → 按「行」回溯：dfs(r) 在第 r 行试每一列，放好就进 dfs(r+1)。
  • 冲突用三组布尔集合 O(1) 判断：cols[c] 管列；主对角线 r−c 为定值（加 n 防负数），副对角线 r+c 为定值。
  • 递归到 r == n 收一个解：每行按 queens[r] 拼出 "....Q..."；返回前记得回溯撤标记。
  • 与 51. N 皇后同型；面试手写时先把「列 / r−c / r+c」三个集合的名字想清楚就不会乱。

时间复杂度 O(n!)（剪枝后远小于），空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public List<List<String>> solveNQueens(int n) {5        List<List<String>> ans = new ArrayList<>();6        int[] queens = new int[n];   // queens[r]：第 r 行的皇后放在哪一列7        dfs(0, queens, new boolean[n], new boolean[2 * n], new boolean[2 * n], ans);8        return ans;9    }10 11    // 逐行放：cols 管列，d1 管主对角线（r−c 为定值），d2 管副对角线（r+c 为定值）12    private void dfs(int r, int[] queens, boolean[] cols, boolean[] d1, boolean[] d2, List<List<String>> ans) {13        int n = queens.length;14        if (r == n) {15            List<String> board = new ArrayList<>();16            for (int q : queens) {17                char[] row = new char[n];18                Arrays.fill(row, '.');19                row[q] = 'Q';20                board.add(new String(row));21            }22            ans.add(board);23            return;24        }25        for (int c = 0; c < n; c++) {26            int a = r - c + n, b = r + c;27            // 列或任一条对角线已被占：这格不放28            if (cols[c] || d1[a] || d2[b]) continue;29            queens[r] = c;30            cols[c] = d1[a] = d2[b] = true;31            dfs(r + 1, queens, cols, d1, d2, ans);32            cols[c] = d1[a] = d2[b] = false;   // 回溯：撤掉占位，试下一列33        }34    }35}
题目

设计一种算法，打印 N 皇后在 N × N 棋盘上的各种摆法，其中每个皇后都不同行、不同列，也不在对角线上。这里的“对角线”指的是所有的对角线，不只是平分整个棋盘的那两条对角线。

注意：本题相对原题做了扩展

 输入：4
 输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
