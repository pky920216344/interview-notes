递归下降：t/f 直接返回；遇 !&| 跳过 op(，val 取单位元（& 从 true、| 从 false），递归算子式逐个累计，逗号继续、括号收尾返回。

思路

  • 全局下标 i 各层递归共用：parse() 看当前字符，是 t/f 就吃掉返回真假。
  • !/&/| 后必是 (：跳两格进括号；val 先设成单位元——& 从 true 起步、| 从 false 起步（最容易忘的一点）。
  • 循环里递归解析子表达式并按 op 累计（! 直接取反）；, 吃掉继续，) 吃掉并把 val 返回上一层。

最优解

时间复杂度 O(n)，空间复杂度 O(n)（递归栈）
1class Solution {2    private int i;          // 全局扫描下标：递归各层共用一个指针3    private String s;4 5    public boolean parseBoolExpr(String expression) {6        s = expression;7        i = 0;8        return parse();9    }10 11    private boolean parse() {12        char c = s.charAt(i);13        if (c == 't') { i++; return true; }14        if (c == 'f') { i++; return false; }15        i += 2;                        // 跳过 "op("，c 就是这一层的运算符16        boolean val = c == '&';        // & 从 true 起步，| 从 false 起步17        while (true) {18            boolean sub = parse();     // 递归解析一个子表达式19            if (c == '&') val &= sub;20            else if (c == '|') val |= sub;21            else val = !sub;           // ! 只有一个操作数22            if (s.charAt(i) == ',') { i++; continue; }23            i++;                       // 吃掉 ')'24            return val;25        }26    }27}
题目

布尔表达式 是计算结果不是 true 就是 false 的表达式。有效的表达式需遵循以下约定：

  • 't'，运算结果为 true
  • 'f'，运算结果为 false
  • '!(subExpr)'，运算过程为对内部表达式 subExpr 进行 逻辑非（NOT）运算
  • '&(subExpr1, subExpr2, ..., subExprn)'，运算过程为对 2 个或以上内部表达式 subExpr1, subExpr2, ..., subExprn 进行 逻辑与（AND）运算
  • '|(subExpr1, subExpr2, ..., subExprn)'，运算过程为对 2 个或以上内部表达式 subExpr1, subExpr2, ..., subExprn 进行 逻辑或（OR）运算

给你一个以字符串形式表述的 布尔表达式 expression，返回该式的运算结果。

题目测试用例所给出的表达式均为有效的布尔表达式，遵循上述约定。

示例 1：

输入：expression = "&(|(f))"
输出：false
解释：
首先，计算 |(f) --> f ，表达式变为 "&(f)" 。
接着，计算 &(f) --> f ，表达式变为 "f" 。
最后，返回 false 。

示例 2：

输入：expression = "|(f,f,f,t)"
输出：true
解释：计算 (false OR false OR false OR true) ，结果为 true 。

示例 3：

输入：expression = "!(&(f,t))"
输出：true
解释：
首先，计算 &(f,t) --> (false AND true) --> false --> f ，表达式变为 "!(f)" 。
接着，计算 !(f) --> NOT false --> true ，返回 true 。

提示：

  • 1 <= expression.length <= 2 * 104
  • expression[i] 为 '('、')'、'&'、'|'、'!'、't'、'f' 和 ',' 之一
