两遍遍历：先数长度开出正好大小的数组，第二遍从头走、把值从数组末尾往前填，天然得到倒序。

思路

  • 第一遍只做一件事：数出结点个数 n，按它分配 ans，不借助任何集合。
  • 第二遍从头走：ans[--n] = p.val——链表的第 1 个结点放进结果末尾，n 同时当写入位置和剩余计数。
  • 走完 n 归 0，ans 正好是倒序；空链表两遍都不进循环，返回空数组。
  • 相比「收进栈再弹出」省掉整个栈的空间；递归写法有 O(n) 栈深度风险，不取。

最优解

时间复杂度 O(n)，空间复杂度 O(1)（不算返回数组）
1class Solution {2    public int[] reverseBookList(ListNode head) {3        // 先数一遍长度，才知道结果数组开多大4        int n = 0;5        for (ListNode p = head; p != null; p = p.next) n++;6        int[] ans = new int[n];7        // 再走一遍：倒数第 1 个放末尾、倒数第 2 个放倒数第二……从尾往头回填8        for (ListNode p = head; p != null; p = p.next) ans[--n] = p.val;9        return ans;10    }11}
题目

书店店员有一张链表形式的书单，每个节点代表一本书，节点中的值表示书的编号。为更方便整理书架，店员需要将书单倒过来排列，就可以从最后一本书开始整理，逐一将书放回到书架上。请倒序返回这个书单链表。

示例 1：

输入：head = [3,6,4,1]

输出：[1,4,6,3]

提示：

0 <= 链表长度 <= 10000
