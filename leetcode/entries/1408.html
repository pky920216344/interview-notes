1408. 数组中的字符串匹配

  • 简单
  • 频度 1
  • 模拟
  • 数组
  • 字符串
  • 字符串匹配
  • 待提交

双层循环：对每个词查它是否是另一个词的子串（contains），是就收集；词互不相同，不会重复收集。

思路

  • 对每个 words[i]，在其余单词里找一遍：某个 words[j]（j != i）contains 它就收集，找到即 break。
  • words[i] 藏进多个单词也只收集一次（词互不相同，每个下标最多加一次）。
  • 输出顺序题目不限，按 i 的自然顺序返回即可。

图解

最优解

时间复杂度 O(n²·L²)（L 为词长），空间复杂度 O(1)（不计输出）
1import java.util.*;2 3class Solution {4    public List<String> stringMatching(String[] words) {5        List<String> ans = new ArrayList<>();6        for (int i = 0; i < words.length; i++) {7            for (int j = 0; j < words.length; j++) {8                // words[i] 藏在另一个单词（j != i）里就收集，找到即止9                if (i != j && words[j].contains(words[i])) {10                    ans.add(words[i]);11                    break;12                }13            }14        }15        return ans;16    }17}
题目

给你一个字符串数组 words ，数组中的每个字符串都可以看作是一个单词。请你按 任意 顺序返回 words 中是其他单词的 子字符串 的所有单词。

示例 1：

输入：words = ["mass","as","hero","superhero"]
输出：["as","hero"]
解释："as" 是 "mass" 的子字符串，"hero" 是 "superhero" 的子字符串。
["hero","as"] 也是有效的答案。

示例 2：

输入：words = ["leetcode","et","code"]
输出：["et","code"]
解释："et" 和 "code" 都是 "leetcode" 的子字符串。

示例 3：

输入：words = ["blue","green","bu"]
输出：[]

提示：

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 30
  • words[i] 仅包含小写英文字母。
  • 题目数据 保证 words 的每个字符串都是独一无二的。
