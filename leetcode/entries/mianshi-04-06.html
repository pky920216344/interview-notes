p 有右子树 → 右子树最左结点；没有右子树 → 从根下行，记下最后一次「往左拐」的结点。

思路

  • 中序后继是「比 p 大的数里最小的」。p.right != null 时就是右子树里一路向左的终点。
  • 没有右子树时，从根走到 p：比 p 大的结点只会在往左拐时踩到，最后一次左拐即答案。
  • 若一路都往右拐，说明 p 是最大值，返回 null。
  • 只走根到 p 的一条路径，比「整树中序遍历找下一位」省时间省空间。

最优解

时间复杂度 O(h)，空间复杂度 O(1)
1class Solution {2    public TreeNode inorderSuccessor(TreeNode root, TreeNode p) {3        // 有右子树：后继是右子树里最左的结点（中序下一段的第一个）4        if (p.right != null) {5            TreeNode s = p.right;6            while (s.left != null) s = s.left;7            return s;8        }9        // 没有右子树：后继在从根到 p 的路径上，是最后一次「往左拐」时踩住的结点10        TreeNode cur = root, ans = null;11        while (cur != p) {12            if (p.val < cur.val) {13                ans = cur;          // p 在左边，cur 可能是后继，先记下14                cur = cur.left;15            } else {16                cur = cur.right;    // p 在右边，cur 太小，不可能17            }18        }19        return ans;20    }21}
题目

设计一个算法，找出二叉搜索树中指定节点的“下一个”节点（也即中序后继）。

如果指定节点没有对应的“下一个”节点，则返回null。

示例 1：

输入：root = [2,1,3], p = 1

  2
 / \
1   3

输出：2

示例 2：

输入：root = [5,3,6,2,4,null,null,1], p = 6

      5
     / \
    3   6
   / \
  2   4
 /   
1

输出：null
