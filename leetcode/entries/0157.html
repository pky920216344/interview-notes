157. 用 Read4 读取 N 个字符

  • 简单
  • 频度 1
  • 模拟
  • 数组
  • 交互
  • 模拟
  • 未经力扣验证

循环调 read4 进 4 字符中转缓冲，把「实际读到的、还需要的」复制进 buf，凑满 n 或文件枯竭就停。

思路

  • read4 一次最多搬 4 个字符，数量不足说明文件见底；read4 返回 0 就是文件读完，break。
  • 中转缓冲 buf4 收下这一批，再按 min(实际读到, 还需要) 复制进 buf——最后一次可能只用一部分。
  • 循环直到凑满 n 或文件枯竭；返回 total（可能小于 n）。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)（buf4 是固定 4 格）
1/**2 * read4 由力扣提供（父类 Reader4 的 API）：从文件读最多 4 个字符进 buf4，返回实际个数；3 * 本地验证时它定义在 Check.java 里。4 */5class Solution extends Reader4 {6    public int read(char[] buf, int n) {7        char[] buf4 = new char[4];   // 一次最多从文件取 4 个字符的中转缓冲8        int total = 0;               // 已写进 buf 的字符数9        while (total < n) {10            int got = read4(buf4);   // 文件里有多少给多少，可能不足 411            if (got == 0) break;     // 文件读完了12            for (int i = 0; i < got && total < n; i++) buf[total++] = buf4[i];13        }14        return total;15    }16}
