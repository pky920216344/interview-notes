656. 成本最小路径

  • 困难
  • 频度 1
  • 动态规划
  • 数组
  • 动态规划
  • 未经力扣验证

倒序 DP：dp[i] = 从 i 到末尾的最小花费（坑为不可达）；重建时在并列花费里选下标最小的下一跳，即字典序最小路径。

思路

  • dp[i] = a[i] + min(dp[i+1..i+b])，从右往左算；a[i] = -1 或所有下一跳都不可达则 dp[i] = ∞。
  • 转移时 j 从小到大扫、严格小于才更新：并列花费自动留下标最小的一跳，重建出来的就是字典序最小路径。
  • 重建从 0 沿 next 走到 n−1，输出 1 起始下标；dp[0] = ∞ 说明走不通，返回空。

时间复杂度 O(n·b)，空间复杂度 O(n)

INF : a[n - 1];9        for (int i = n - 2; i >= 0; i--) {10            dp[i] = INF;11            if (a[i] < 0) continue;   // -1 是坑，落不上去12            // j 从小到大扫、严格小于才更新 → 并列花费自动留下标最小的一跳（字典序最小）13            for (int j = i + 1; j <= Math.min(n - 1, i + b); j++)14                if (dp[j] < dp[i]) { dp[i] = dp[j]; next[i] = j; }15            if (dp[i] < INF) dp[i] += a[i];16        }17        List<Integer> path = new ArrayList<>();18        if (dp[0] < INF)19            for (int i = 0; ; i = next[i]) {20                path.add(i + 1);      // 题目要 1 起始的下标21                if (i == n - 1) break;22            }23        return path;24    }25}
