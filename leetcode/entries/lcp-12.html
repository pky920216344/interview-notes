LCP 12. 小张刷题计划

二分最忙一天的耗时 T，贪心 check：逐题装进当天，超了就求助删当天最耗时的一道（每天一次），删完还超就开新的一天。

思路

  • 答案单调：T 越大越容易在 m 天内排完，可二分 T ∈ [0, Σtime]。
  • check 贪心装天：sum 超过 T 且当天还没用过求助时，删掉当天最耗时的一道（可能正是当前题），sum 必然回到不超。
  • 求助已用还超就开新的一天；新的一天第一题就超 T，就求助它自己，代价归 0。
  • 求助永远删当天最大值是最优的：这样当天能装下更多题，不会更差。

时间复杂度 O(n log Σtime)，空间复杂度 O(1)
1class Solution {2    public int minTime(int[] time, int m) {3        // 二分「最忙那天的耗时 T」：T 越大越容易在 m 天内排完，可行域单调4        long lo = 0, hi = 0;5        for (int t : time) hi += t;6        while (lo < hi) {7            long mid = (lo + hi) / 2;8            if (check(time, m, mid)) hi = mid;9            else lo = mid + 1;10        }11        return (int) lo;12    }13 14    // 贪心装天：超时就求助删掉当天最耗时的题（每天最多一次）；还超就开新的一天15    private boolean check(int[] time, int m, long T) {16        int days = 1;17        long sum = 0;      // 当天求助之后还要做的总时间18        int max = 0;       // 当天最耗时的一道题19        boolean helped = false;20        for (int t : time) {21            max = Math.max(max, t);22            sum += t;23            if (sum > T) {24                if (!helped) {25                    helped = true;26                    sum -= max;   // 求助删掉当天最大的一道（可能正是 t），必然回到不超27                } else {28                    days++;29                    sum = t;30                    max = t;31                    helped = false;32                    if (sum > T) {   // 新的一天第一题就超：求助它自己，代价归 033                        helped = true;34                        sum = 0;35                    }36                }37            }38        }39        return days <= m;40    }41}
题目

为了提高自己的代码能力，小张制定了 LeetCode 刷题计划，他选中了 LeetCode 题库中的 n 道题，编号从 0 到 n-1，并计划在 m 天内按照题目编号顺序刷完所有的题目（注意，小张不能用多天完成同一题）。

在小张刷题计划中，小张需要用 time[i] 的时间完成编号 i 的题目。此外，小张还可以使用场外求助功能，通过询问他的好朋友小杨题目的解法，可以省去该题的做题时间。为了防止“小张刷题计划”变成“小杨刷题计划”，小张每天最多使用一次求助。

我们定义 m 天中做题时间最多的一天耗时为 T（小杨完成的题目不计入做题总时间）。请你帮小张求出最小的 T是多少。

示例 1：

输入：time = [1,2,3,3], m = 2

输出：3

解释：第一天小张完成前三题，其中第三题找小杨帮忙；第二天完成第四题，并且找小杨帮忙。这样做题时间最多的一天花费了 3 的时间，并且这个值是最小的。

示例 2：

输入：time = [999,999,999], m = 4

输出：0

解释：在前三天中，小张每天求助小杨一次，这样他可以在三天内完成所有的题目并不花任何时间。

限制：

  • 1 <= time.length <= 10^5
  • 1 <= time[i] <= 10000
  • 1 <= m <= 1000
