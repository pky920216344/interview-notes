贪心双指针：每轮从两端找「最短的」相等前后缀配成一对摘掉（段越短段数越多）；剩下配不成对的中段记 1。

思路

  • 双指针 l、r 夹住剩余段；每轮从 len=1 起试 text[l..l+len) == text[r-len..r)，取最短的相等前后缀。
  • 取最短是对的：aaaa 若先摘 aa|aa 只得 2 段，逐字符摘得 4 段；对拍用暴力验证过。
  • 一轮里连 len=1 都配不上（前后缀必然重叠），说明剩余部分只能整段独立 → 答案 k+1。

最优解

时间复杂度 O(n²)，空间复杂度 O(n)
1class Solution {2    public int longestDecomposition(String text) {3        int n = text.length(), l = 0, r = n, k = 0;4        // 每轮：从两端找「最短的」相等前后缀，配成一对摘掉（越短段数越多）5        while (l < r) {6            int len = 1;7            while (l + len <= r - len && !text.substring(l, l + len).equals(text.substring(r - len, r))) len++;8            if (l + len > r - len) break;   // 一对都配不出来：剩下的整体就是一段9            k += 2;10            l += len;11            r -= len;12        }13        return l < r ? k + 1 : k;14    }15}
题目

你会得到一个字符串 text 。你应该把它分成 k 个子字符串 (subtext1, subtext2，…， subtextk) ，要求满足:

  • subtexti 是 非空 字符串
  • 所有子字符串的连接等于 text ( 即subtext1 + subtext2 + ... + subtextk == text )
  • 对于所有 i 的有效值( 即 1 <= i <= k ) ，subtexti == subtextk - i + 1 均成立

返回k可能最大值。

示例 1：

输入：text = "ghiabcdefhelloadamhelloabcdefghi"
输出：7
解释：我们可以把字符串拆分成 "(ghi)(abcdef)(hello)(adam)(hello)(abcdef)(ghi)"。

示例 2：

输入：text = "merchant"
输出：1
解释：我们可以把字符串拆分成 "(merchant)"。

示例 3：

输入：text = "antaprezatepzapreanta"
输出：11
解释：我们可以把字符串拆分成 "(a)(nt)(a)(pre)(za)(tep)(za)(pre)(a)(nt)(a)"。

提示：

  • 1 <= text.length <= 1000
  • text 仅由小写英文字符组成
