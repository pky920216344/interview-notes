利用 BST 有序迭代下行：p、q 都小往左、都大往右；一旦分居两侧（或撞上其中之一）即答案。

思路

  • 从根往下走，比较 p.val、q.val 和当前结点：同小于当前 → 一起往左；同大于 → 一起往右。
  • 第一次「分居两侧」（或 p、q 之一就是当前结点）时停下，当前结点就是最近公共祖先——再往下走两者就要分开了。
  • 不用递归不用栈，一路循环 O(h)；比通用树的 LCA 解法少了「两边找再汇合」的回溯。

最优解

时间复杂度 O(h)，空间复杂度 O(1)
1class Solution {2    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {3        TreeNode cur = root;4        // BST 有序：p、q 同在一边就继续下行；一旦分居两侧（或撞上其中之一）就是答案5        while (cur != null) {6            if (p.val < cur.val && q.val < cur.val) cur = cur.left;7            else if (p.val > cur.val && q.val > cur.val) cur = cur.right;8            else break;9        }10        return cur;11    }12}
题目

给定一个二叉搜索树, 找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为：“对于有根树 T 的两个结点 p、q，最近公共祖先表示为一个结点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

例如，给定如下二叉搜索树:  root = [6,2,8,0,4,7,9,null,null,3,5]

示例 1：

输入：root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
输出：6 
解释：节点 2 和节点 8 的最近公共祖先是 6。

示例 2：

输入：root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 4
输出：2
解释：节点 2 和节点 4 的最近公共祖先是 2, 因为根据定义最近公共祖先节点可以为节点本身。

说明：

  • 所有节点的值都是唯一的。
  • p、q 为不同节点且均存在于给定的二叉搜索树中。
