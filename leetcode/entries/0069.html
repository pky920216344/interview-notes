69. x 的平方根

  • 简单
  • 频度 150
  • 数学
  • 数学
  • 二分查找
  • newtons-method
  • 力扣已通过

牛顿迭代：r 偏大时 x / r 偏小，取平均更接近根号 x；从 r = x 一路降到 r * r <= x。

思路

  • 用 long r，起点 r = x：r * r 在 x 接近 2^31 - 1 时会超出 int。
  • 每轮 r = (r + x / r) / 2（整数除法）：r 严格递减，而且不会降到答案以下。
  • while (r * r > x) 一停，r 就是答案，返回 (int) r；x = 0 时不进循环，也不会除以 0。
  • 前半段 r 每轮约减半，快到根号 x 时误差成平方缩小，x 取到 2^31 - 1 也只要约 20 轮。

题目

给你一个非负整数 x ，计算并返回 x 的 算术平方根 。

由于返回类型是整数，结果只保留 整数部分 ，小数部分将被 舍去 。

注意：不允许使用任何内置指数函数和算符，例如 pow(x, 0.5) 或者 x ** 0.5 。

示例 1：

输入：x = 4
输出：2

示例 2：

输入：x = 8
输出：2
解释：8 的算术平方根是 2.82842..., 由于返回类型是整数，小数部分将被舍去。

提示：

  • 0 <= x <= 231 - 1
