1356. 根据数字二进制下 1 的数目排序

装箱后带比较器排序：比较键是「1 的个数, 数值本身」，bitCount 一条指令数出 1 的个数。

思路

  • 两级排序键：主键 Integer.bitCount(x) 升序，次键数值升序。
  • Arrays.sort 的比较器版本只收对象数组，先把 int[] 装箱成 Integer[]，排完再写回去。
  • bitCount 内建就是 Hamming 权重，不用手写循环数 1。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] sortByBits(int[] arr) {5        int n = arr.length;6        // Arrays.sort 对对象数组是稳定排序；基本类型要装箱后才能带比较器7        Integer[] a = new Integer[n];8        for (int i = 0; i < n; i++) a[i] = arr[i];9        Arrays.sort(a, (x, y) -> {10            // 比较键：先比 1 的个数，再比数值本身11            int c = Integer.compare(Integer.bitCount(x), Integer.bitCount(y));12            return c != 0 ? c : Integer.compare(x, y);13        });14        for (int i = 0; i < n; i++) arr[i] = a[i];15        return arr;16    }17}
题目

给你一个整数数组 arr 。请你将数组中的元素按照其二进制表示中数字 1 的数目升序排序。

如果存在多个数字二进制中 1 的数目相同，则必须将它们按照数值大小升序排列。

请你返回排序后的数组。

示例 1：

输入：arr = [0,1,2,3,4,5,6,7,8]
输出：[0,1,2,4,8,3,5,6,7]
解释：[0] 是唯一一个有 0 个 1 的数。
[1,2,4,8] 都有 1 个 1 。
[3,5,6] 有 2 个 1 。
[7] 有 3 个 1 。
按照 1 的个数排序得到的结果数组为 [0,1,2,4,8,3,5,6,7]

示例 2：

输入：arr = [1024,512,256,128,64,32,16,8,4,2,1]
输出：[1,2,4,8,16,32,64,128,256,512,1024]
解释：数组中所有整数二进制下都只有 1 个 1 ，所以你需要按照数值大小将它们排序。

示例 3：

输入：arr = [10000,10000]
输出：[10000,10000]

示例 4：

输入：arr = [2,3,5,7,11,13,17,19]
输出：[2,3,5,17,7,11,13,19]

示例 5：

输入：arr = [10,100,1000,10000]
输出：[10,100,10000,1000]

提示：

  • 1 <= arr.length <= 500
  • 0 <= arr[i] <= 10^4
