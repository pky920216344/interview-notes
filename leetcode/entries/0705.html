定长数组当桶数组，key % 质数 769 定位桶，桶内用普通链表串起来，增删查都沿链走。

思路

  • hash(key) = key % 769：质数取模让 key 分布均匀；冲突的 key 链在同一个桶里。
  • add：桶里没有才加（集合语义）；remove：找到就摘掉，找不到不动。
  • remove 必须传 Integer.valueOf(key)：List 重载里按值删的是 remove(Object)。

图解

最优解

时间复杂度 O(1) 均摊（期望），空间复杂度 O(n + 桶数)
1import java.util.*;2 3class MyHashSet {4    // 桶数取质数 769：key % 769 分布更均匀5    private static final int BASE = 769;6    private final List<Integer>[] buckets = new List[BASE];7 8    public MyHashSet() {9        for (int i = 0; i < BASE; i++) buckets[i] = new ArrayList<>();10    }11 12    private int hash(int key) {13        return key % BASE;14    }15 16    public void add(int key) {17        List<Integer> bucket = buckets[hash(key)];18        if (!bucket.contains(key)) bucket.add(key);  // 集合语义：重复 add 不生效19    }20 21    public void remove(int key) {22        // List.remove(Object) 才是按值删；直接传 int 会按下标删23        buckets[hash(key)].remove(Integer.valueOf(key));24    }25 26    public boolean contains(int key) {27        return buckets[hash(key)].contains(key);28    }29}
题目

不使用任何内建的哈希表库设计一个哈希集合（HashSet）。

实现 MyHashSet 类：

  • void add(key) 向哈希集合中插入值 key 。
  • bool contains(key) 返回哈希集合中是否存在这个值 key 。
  • void remove(key) 将给定值 key 从哈希集合中删除。如果哈希集合中没有这个值，什么也不做。
 

示例：

输入：
["MyHashSet", "add", "add", "contains", "contains", "add", "contains", "remove", "contains"]
[[], [1], [2], [1], [3], [2], [2], [2], [2]]
输出：
[null, null, null, true, false, null, true, null, false]

解释：
MyHashSet myHashSet = new MyHashSet();
myHashSet.add(1);      // set = [1]
myHashSet.add(2);      // set = [1, 2]
myHashSet.contains(1); // 返回 True
myHashSet.contains(3); // 返回 False ，（未找到）
myHashSet.add(2);      // set = [1, 2]
myHashSet.contains(2); // 返回 True
myHashSet.remove(2);   // set = [1]
myHashSet.contains(2); // 返回 False ，（已移除）

提示：

  • 0 <= key <= 106
  • 最多调用 104 次 add、remove 和 contains
