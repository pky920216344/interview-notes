746. 使用最小花费爬楼梯

  • 简单
  • 频度 4
  • 动态规划
  • 数组
  • 动态规划
  • 待提交

dp[i] = 站上第 i 级的最小花费 = min(dp[i-1], dp[i-2]) + cost[i]；答案从最后两级跨一步到顶楼，取 min(dp[n-1], dp[n-2])。

思路

  • 「站上第 i 级」就必须付 cost[i]；从第 i-1 或 i-2 级跨过来，挑已花得少的那个。
  • 起点是第 0 或第 1 级（免费站上去），所以 dp[0]=cost[0]、dp[1]=cost[1]。
  • 顶楼是下标 n 的位置：到达它不付钱，答案 = min(dp[n-1], dp[n-2])。
  • 只依赖前两级，用两个变量 f2/f1 滚动即可，不需要数组。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int minCostClimbingStairs(int[] cost) {3        // f2/f1 = 站上第 i-2 / i-1 级的最小花费（站上去就要付 cost[i]）4        int f2 = cost[0], f1 = cost[1];5        for (int i = 2; i < cost.length; i++) {6            int f = Math.min(f1, f2) + cost[i];   // 从前两级中便宜的那级跨过来7            f2 = f1;8            f1 = f;9        }10        // 顶楼不花钱：从最后一级或倒数第二级跨过去，取小的11        return Math.min(f1, f2);12    }13}
题目

给你一个整数数组 cost ，其中 cost[i] 是从楼梯第 i 个台阶向上爬需要支付的费用。

一旦你支付此费用，即可选择向上爬 一个 或者 两个 台阶。

你可以选择从下标为 0 或下标为 1 的台阶开始爬楼梯。

请你计算并返回达到楼梯顶部的 最低 花费，即最后一步之后的那个位置（下标 cost.length）。

示例 1：

输入：cost = [10,15,20]
输出：15
解释：你将从下标为 1 的台阶开始。
- 支付 15 ，向上爬两个台阶，到达楼梯顶部。
总花费为 15 。

示例 2：

输入：cost = [1,100,1,1,1,100,1,1,100,1]
输出：6
解释：你将从下标为 0 的台阶开始。
- 支付 1 ，向上爬两个台阶，到达下标为 2 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 4 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 6 的台阶。
- 支付 1 ，向上爬一个台阶，到达下标为 7 的台阶。
- 支付 1 ，向上爬两个台阶，到达下标为 9 的台阶。
- 支付 1 ，向上爬一个台阶，到达楼梯顶部。
总花费为 6 。

提示：

  • 2 <= cost.length <= 1000
  • 0 <= cost[i] <= 999
