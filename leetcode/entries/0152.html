152. 乘积最大子数组

  • 中等
  • 频度 91
  • 动态规划
  • 数组
  • 动态规划
  • 力扣已通过

同时维护以 i 结尾的最大、最小乘积：负数一乘两者互换，每步在 x 自己、×maxP、×minP 三个候选里各取一遍。

思路

  • maxP、minP 是以当前元素结尾的最大 / 最小乘积，ans 随手取最大。
  • 候选永远三种：x 自己另起一段、接在最大后面 maxP*x、接在最小后面 minP*x；最大最小都从这三个里挑。
  • 乘到负数时最大变最小、最小变最大，所以两种必须一起维护——只记最大会丢掉「负得最多」那段。
  • 先用旧的 maxP、minP 把 mx、mn 都算出来再赋值，边算边覆盖会串。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxProduct(int[] nums) {3        // maxP / minP：以 i 结尾的最大 / 最小乘积4        int ans = nums[0], maxP = nums[0], minP = nums[0];5        for (int i = 1; i < nums.length; i++) {6            int x = nums[i];7            // 负数一乘，最大最小互换，三种候选都比一遍8            int mx = Math.max(x, Math.max(maxP * x, minP * x));9            int mn = Math.min(x, Math.min(maxP * x, minP * x));10            maxP = mx;11            minP = mn;12            ans = Math.max(ans, maxP);13        }14        return ans;15    }16}
题目

给你一个整数数组 nums ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 32-位 整数。

请注意，一个只包含一个元素的数组的乘积是这个元素的值。

示例 1:

输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。

示例 2:

输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是子数组。

提示:

  • 1 <= nums.length <= 2 * 104
  • -10 <= nums[i] <= 10
  • nums 的任何子数组的乘积都 保证 是一个 32-位 整数
