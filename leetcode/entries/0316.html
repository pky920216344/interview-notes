316. 去除重复字母

  • 力扣已通过

单调栈 + 剩余计数：字母已在栈里就跳过；栈顶比当前大且后面还会再来就弹掉，给更小的让位。

思路

  • remain[c] 记每个字母还剩几个没读，弹栈前看一眼：后面还有就不怕丢。
  • 当前字母已在栈里就只减 remain，绝不重复入栈——每个字母最终恰好一个。
  • 栈顶比当前大且 remain > 0：弹掉换小的，字典序更优；否则当前字母入栈。
  • 栈底到栈顶就是答案。

最优解

时间复杂度 O(n)，空间复杂度 O(26)
1class Solution {2    public String removeDuplicateLetters(String s) {3        int[] remain = new int[26];      // 每个字母还剩几个没读过4        boolean[] in = new boolean[26];  // 是否已经在栈里5        for (int i = 0; i < s.length(); i++) remain[s.charAt(i) - 'a']++;6        char[] stack = new char[26];7        int top = 0;8        for (int i = 0; i < s.length(); i++) {9            char c = s.charAt(i);10            if (!in[c - 'a']) {11                // 栈顶比 c 大且后面还会再来：弹掉，给更小的 c 让位12                while (top > 0 && stack[top - 1] > c && remain[stack[top - 1] - 'a'] > 0) {13                    in[stack[--top] - 'a'] = false;14                }15                stack[top++] = c;16                in[c - 'a'] = true;17            }18            remain[c - 'a']--;19        }20        return new String(stack, 0, top);21    }22}
题目

给你一个字符串 s ，请你去除字符串中重复的字母，使得每个字母只出现一次。需保证 返回结果的字典序最小（要求不能打乱其他字符的相对位置）。

示例 1：

输入：s = "bcabc"
输出："abc"

示例 2：

输入：s = "cbacdcbc"
输出："acdb"

提示：

  • 1 <= s.length <= 104
  • s 由小写英文字母组成

注意：该题与 1081 https://leetcode.cn/problems/smallest-subsequence-of-distinct-characters 相同
