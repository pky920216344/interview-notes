300. 最长递增子序列

贪心 + 二分：tails[k] 是长度 k+1 的递增子序列的最小末尾；每个数二分覆盖，tails 长度即答案。

思路

  • tails[k] 是长度为 k+1 的严格递增子序列里最小的末尾：末尾越小，越容易接上后面的数。tails 本身严格递增，所以能二分。
  • 对每个 x，二分找 tails 里第一个 >= x 的位置 lo，把 tails[lo] 改成 x；若 lo == size（x 比所有末尾都大），就接在最后并 size++。
  • 找 >= x 而不是 > x：要求严格递增，等于 x 的末尾只能被覆盖，不能往后接（7 7 7 的答案是 1）。
  • 答案是 size。tails 不一定是一条真实的子序列，只有它的长度有意义。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1class Solution {2    public int lengthOfLIS(int[] nums) {3        // tails[k]：长度为 k+1 的递增子序列的最小末尾4        int[] tails = new int[nums.length];5        int size = 0;6        for (int x : nums) {7            // 二分找 tails 里第一个 >= x 的位置8            int lo = 0, hi = size;9            while (lo < hi) {10                int mid = (lo + hi) / 2;11                if (tails[mid] < x) lo = mid + 1;12                else hi = mid;13            }14            // 比所有末尾都大就接在最后，否则覆盖它15            tails[lo] = x;16            if (lo == size) size++;17        }18        return size;19    }20}
题目

给你一个整数数组 nums ，找到其中最长严格递增子序列的长度。

子序列 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。

 

示例 1：

输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。

示例 2：

输入：nums = [0,1,0,3,2,3]
输出：4

示例 3：

输入：nums = [7,7,7,7,7,7,7]
输出：1

提示：

  • 1 <= nums.length <= 2500
  • -104 <= nums[i] <= 104
