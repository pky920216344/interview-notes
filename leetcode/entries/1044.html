二分重复子串的长度 + 滚动哈希（Rabin-Karp）：预处理前缀哈希后每个窗口 O(1)，双哈希让碰撞几乎不可能。

思路

  • 长度有单调性：长度 L 有重复 ⇒ L−1 也有（取它前缀即可），所以二分长度，对每个候选长度查一遍。
  • 查法：所有长度为 L 的窗口算哈希放进哈希表，撞上即存在重复；用双哈希（两组模数同时相同才算撞上）防碰撞。
  • 预处理前缀哈希 h 和 base 幂 p：窗口 [i, i+L) 的哈希 = h[i+L] − h[i]·p[L]，减出负数先补模数再取模。
  • 撞上的两条记录里，先出现的那条起点就是答案子串的起点。

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    private static final long BASE = 131L, MOD1 = 1_000_000_007L, MOD2 = 998_244_353L;5 6    public String longestDupSubstring(String s) {7        int n = s.length();8        // 预处理前缀哈希和 base 幂：任意窗口的哈希都能 O(1) 拼出来9        long[] h1 = new long[n + 1], h2 = new long[n + 1], p1 = new long[n + 1], p2 = new long[n + 1];10        p1[0] = p2[0] = 1;11        for (int i = 0; i < n; i++) {12            h1[i + 1] = (h1[i] * BASE + s.charAt(i)) % MOD1;13            h2[i + 1] = (h2[i] * BASE + s.charAt(i)) % MOD2;14            p1[i + 1] = p1[i] * BASE % MOD1;15            p2[i + 1] = p2[i] * BASE % MOD2;16        }17        // 二分答案：最大的 L 使得存在出现两次的长度 L 子串18        int lo = 1, hi = n - 1, best = 0, start = -1;19        while (lo <= hi) {20            int mid = (lo + hi) >>> 1;21            int at = find(s, h1, h2, p1, p2, mid);22            if (at >= 0) {23                best = mid;24                start = at;25                lo = mid + 1;26            } else {27                hi = mid - 1;28            }29        }30        return best == 0 ? "" : s.substring(start, start + best);31    }32 33    // 找长度 len 的重复子串：窗口哈希第一次撞上已有记录，就返回先出现的那个起点34    private int find(String s, long[] h1, long[] h2, long[] p1, long[] p2, int len) {35        Map<Long, Integer> seen = new HashMap<>();36        for (int i = 0; i + len <= s.length(); i++) {37            // 减掉窗口左侧的高位贡献，得到 [i, i+len) 这段的哈希；减出负数先补模数38            long k1 = (h1[i + len] - h1[i] * p1[len] % MOD1 + MOD1) % MOD1;39            long k2 = (h2[i + len] - h2[i] * p2[len] % MOD2 + MOD2) % MOD2;40            Integer prev = seen.putIfAbsent(k1 * MOD2 + k2, i);41            if (prev != null) return prev;42        }43        return -1;44    }45}
题目

给你一个字符串 s ，考虑其所有 重复子串 ：即 s 的（连续）子串，在 s 中出现 2 次或更多次。这些出现之间可能存在重叠。

返回 任意一个 可能具有最长长度的重复子串。如果 s 不含重复子串，那么答案为 "" 。

示例 1：

输入：s = "banana"
输出："ana"

示例 2：

输入：s = "abcd"
输出：""

提示：

  • 2 <= s.length <= 3 * 104
  • s 由小写英文字母组成
