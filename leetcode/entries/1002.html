1002. 查找共用字符

  • 哈希表

每个单词做 26 格计数，与累计的 mn 逐字符取 min；最后 mn[c] 是几就输出几个 c。

思路

  • mn[c] = 字符 c 在「每一个」单词里都至少出现的次数，初始为 ∞。
  • 每来一个单词：数出 cnt，然后 mn[c] = min(mn[c], cnt[c]) 逐字符压小。
  • 某个单词里没有的字符会被压成 0，自动淘汰。
  • 输出按字母序展开：mn[c] 是几，就输出几个 c（重复字符保留多份）。

时间复杂度 O(所有字符总数)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public List<String> commonChars(String[] words) {5        // mn[c]：字符 c 在「每一个」单词里都至少出现这么多次6        int[] mn = new int[26];7        Arrays.fill(mn, Integer.MAX_VALUE);8        for (String w : words) {9            int[] cnt = new int[26];10            for (char c : w.toCharArray()) cnt[c - 'a']++;11            // 逐字符取 min：哪个单词里没有，就直接归 012            for (int c = 0; c < 26; c++) mn[c] = Math.min(mn[c], cnt[c]);13        }14        List<String> ans = new ArrayList<>();15        // 按字母序展开：mn[c] 是几，就输出几个这个字符16        for (int c = 0; c < 26; c++) {17            for (int k = 0; k < mn[c]; k++) ans.add(String.valueOf((char) ('a' + c)));18        }19        return ans;20    }21}
题目
给你一个字符串数组 words ，请你找出所有在 words 的每个字符串中都出现的共用字符（包括重复字符），并以数组形式返回。你可以按 任意顺序 返回答案。

示例 1：

输入：words = ["bella","label","roller"]
输出：["e","l","l"]

示例 2：

输入：words = ["cool","lock","cook"]
输出：["c","o"]

提示：

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 100
  • words[i] 由小写英文字母组成
