32. 最长有效括号

  • 困难
  • 频度 151
  • 贪心
  • 栈
  • 字符串
  • 动态规划
  • bracket-sequences
  • 力扣已通过

左右各扫一遍计数：相等就记 2×right，右括号多了就清零；反向再扫，改成左括号多了清零。

思路

  • 正向扫：遇 ( 令 left++，遇 ) 令 right++。
  • left == right：这一段刚好配平，长度是 2 * right，用来更新 ans。
  • right > left：多出来的 ) 永远配不上，left、right 清零，从下一个字符重新数。
  • 只正向扫不够：像 (() 这样 ( 多出来时，left 永远比 right 大，答案记不到。所以再反向扫一遍，对称地换成 left > right 时清零。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int longestValidParentheses(String s) {3        int ans = 0;4        // 正向扫：')' 多了，多出的那个永远配不上，清零5        int left = 0, right = 0;6        for (int i = 0; i < s.length(); i++) {7            if (s.charAt(i) == '(') left++;8            else right++;9            if (left == right) ans = Math.max(ans, 2 * right);10            else if (right > left) left = right = 0;11        }12        // 反向再扫：这回 '(' 多了才清零13        left = 0; right = 0;14        for (int i = s.length() - 1; i >= 0; i--) {15            if (s.charAt(i) == '(') left++;16            else right++;17            if (left == right) ans = Math.max(ans, 2 * left);18            else if (left > right) left = right = 0;19        }20        return ans;21    }22}
题目

给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号 子串 的长度。

左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 "(()())"。

示例 1：

输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"

示例 2：

输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"

示例 3：

输入：s = ""
输出：0

提示：

  • 0 <= s.length <= 3 * 104
  • s[i] 为 '(' 或 ')'
