找每个数字的独有字母定序剥离：z/w/u/x/g 直接定 0/2/4/6/8，再用扣除法定 1/3/5/7/9。

思路

  • 一遍统计 26 个字母的计数。
  • z/w/u/x/g 只出现在 zero/two/four/six/eight 里 → 直接得出这五个偶数的个数。
  • 奇数用扣除法：one 的 o 扣掉 zero/two/four，three 的 t 扣掉 two/eight，five 的 f 扣掉 four，seven 的 s 扣掉 six，nine 的 i 扣掉 six/eight/five。
  • 按 0→9 逐个展开拼接，天然升序。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public String originalDigits(String s) {3        int[] cnt = new int[26];4        for (char c : s.toCharArray()) cnt[c - 'a']++;5        int[] num = new int[10];6        // z/w/u/x/g 分别只在 zero/two/four/six/eight 里，先定偶数7        num[0] = cnt['z' - 'a'];8        num[2] = cnt['w' - 'a'];9        num[4] = cnt['u' - 'a'];10        num[6] = cnt['x' - 'a'];11        num[8] = cnt['g' - 'a'];12        // 其余的用扣除法：把这个字母已被前面数字占用的个数减掉13        num[1] = cnt['o' - 'a'] - num[0] - num[2] - num[4];14        num[3] = cnt['t' - 'a'] - num[2] - num[8];15        num[5] = cnt['f' - 'a'] - num[4];16        num[7] = cnt['s' - 'a'] - num[6];17        num[9] = cnt['i' - 'a'] - num[6] - num[8] - num[5];18        StringBuilder sb = new StringBuilder();19        for (int d = 0; d < 10; d++) {20            for (int i = 0; i < num[d]; i++) sb.append((char) ('0' + d));21        }22        return sb.toString();23    }24}
题目

给你一个字符串 s ，其中包含字母顺序打乱的用英文单词表示的若干数字（0-9）。按 升序 返回原始的数字。

示例 1：

输入：s = "owoztneoer"
输出："012"

示例 2：

输入：s = "fviefuro"
输出："45"

提示：

  • 1 <= s.length <= 105
  • s[i] 为 ["e","g","f","i","h","o","n","s","r","u","t","w","v","x","z"] 这些字符之一
  • s 保证是一个符合题目要求的字符串
