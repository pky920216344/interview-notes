213. 打家劫舍 II

  • 中等
  • 频度 42
  • 动态规划
  • 数组
  • 动态规划
  • 力扣已通过

环形拆成两条线性链：不偷尾（0..n-2）与 不偷首（1..n-1）各跑一遍打家劫舍，取较大者。

思路

  • 环上首尾相邻不能同偷：分成「不偷尾」和「不偷首」两条线性链，答案必在其中一条里。
  • 每条链用滚动两变量：偷当前 = 不偷上一间 + 当前金额；不偷当前 = 两个旧状态取大。
  • 只有一间时首尾是同一间，直接返回它，别套两条链的公式。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int rob(int[] nums) {3        int n = nums.length;4        // 只有一间：首尾是同一间，直接偷5        if (n == 1) return nums[0];6        // 环形拆成两条线性链：不偷尾（0..n-2）或不偷首（1..n-1），取较大者7        return Math.max(rob(nums, 0, n - 2), rob(nums, 1, n - 1));8    }9 10    // 线性打家劫舍：区间 [from, to] 内相邻不能同偷的最大和11    private int rob(int[] nums, int from, int to) {12        // rob：偷当前这间的最优；skip：不偷当前这间的最优13        int rob = 0, skip = 0;14        for (int i = from; i <= to; i++) {15            // 偷当前，上一间必须不偷16            int newRob = skip + nums[i];17            // 不偷当前：上一间偷不偷都行，取大18            skip = Math.max(rob, skip);19            rob = newRob;20        }21        return Math.max(rob, skip);22    }23}
题目

你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方所有的房屋都 围成一圈 ，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警 。

给定一个代表每个房屋存放金额的非负整数数组，计算你 在不触动警报装置的情况下 ，今晚能够偷窃到的最高金额。

示例 1：

输入：nums = [2,3,2]
输出：3
解释：你不能先偷窃 1 号房屋（金额 = 2），然后偷窃 3 号房屋（金额 = 2）, 因为他们是相邻的。

示例 2：

输入：nums = [1,2,3,1]
输出：4
解释：你可以先偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
     偷窃到的最高金额 = 1 + 3 = 4 。

示例 3：

输入：nums = [1,2,3]
输出：3

提示：

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 1000
