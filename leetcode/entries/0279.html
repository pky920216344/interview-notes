完全背包：dp[i] = 凑出 i 的最少平方数个数；每个 j*j 当可重复用的物品，i 正序推。

思路

  • dp[i] 表示凑出 i 最少用几个平方数；dp[0] = 0，其余先设成无穷大。
  • 物品是 1, 4, 9, …，可无限次使用（完全背包），所以 i 要从小到大正序推。
  • 转移 dp[i] = min(dp[i], dp[i - j*j] + 1)：枚举「最后一个用的平方数」取最小。
  • min 不能省：贪心先拿大平方会变差，12 = 4+4+4 是 3 个，比 9+1+1+1 的 4 个更少。

1import java.util.*;2 3class Solution {4    public int numSquares(int n) {5        // dp[i]：凑出 i 最少要几个完全平方数6        int[] dp = new int[n + 1];7        Arrays.fill(dp, Integer.MAX_VALUE);8        dp[0] = 0;9        // 完全背包：每个平方数可重复用，i 正序推10        for (int j = 1; j * j <= n; j++) {11            int sq = j * j;12            for (int i = sq; i <= n; i++) {13                dp[i] = Math.min(dp[i], dp[i - sq] + 1);14            }15        }16        return dp[n];17    }18}
题目

给你一个整数 n ，返回 和为 n 的完全平方数的最少数量 。

完全平方数 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，1、4、9 和 16 都是完全平方数，而 3 和 11 不是。

示例 1：

输入：n = 12
输出：3 
解释：12 = 4 + 4 + 4

示例 2：

输入：n = 13
输出：2
解释：13 = 4 + 9
 

提示：

  • 1 <= n <= 104
