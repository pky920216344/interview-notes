524. 通过删除字母匹配到字典里最长单词

逐个词用双指针验证「能否由 s 删字母得到」，在能匹配的词里挑更长、同长挑字典序更小的。

思路

  • 判定子序列：i 指向词、j 扫 s，相同就 i++；扫完 i 到词尾即成功，贪心不会错。
  • 先比再验：候选不如 best 长、或同长但不更小，直接跳过，省掉子序列判定。
  • 同长字典序更小才替换：compareTo < 0；比 best 短的永远不换。
  • 没有任何词匹配时 best 保持空串返回。

时间复杂度 O(N × (|s| + |w|))，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public String findLongestWord(String s, List<String> dictionary) {5        String best = "";6        for (String word : dictionary) {7            // 先比再查：不如 best 长、或同长但字典序不更小，就没必要验证子序列8            if (word.length() < best.length()) continue;9            if (word.length() == best.length() && word.compareTo(best) >= 0) continue;10            if (isSub(s, word)) best = word;11        }12        return best;13    }14 15    // 贪心双指针：word 的每个字符按顺序在 s 里找，找齐就是子序列16    private boolean isSub(String s, String word) {17        int i = 0;18        for (int j = 0; j < s.length() && i < word.length(); j++) {19            if (s.charAt(j) == word.charAt(i)) i++;20        }21        return i == word.length();22    }23}
题目

给你一个字符串 s 和一个字符串数组 dictionary ，找出并返回 dictionary 中最长的字符串，该字符串可以通过删除 s 中的某些字符得到。

如果答案不止一个，返回长度最长且字母序最小的字符串。如果答案不存在，则返回空字符串。

示例 1：

输入：s = "abpcplea", dictionary = ["ale","apple","monkey","plea"]
输出："apple"

示例 2：

输入：s = "abpcplea", dictionary = ["a","b","c"]
输出："a"

提示：

  • 1 <= s.length <= 1000
  • 1 <= dictionary.length <= 1000
  • 1 <= dictionary[i].length <= 1000
  • s 和 dictionary[i] 仅由小写英文字母组成
