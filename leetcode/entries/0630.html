按截止日排序后逐门先收下；总时长超期就退掉大顶堆里最耗时的课，堆的大小就是最多能修的门数。

思路

  • 截止日早的先考虑，给后面留最大余地；这是交换论证的标准贪心。
  • 每门课先「收下」：time += 时长 并压入大顶堆；一旦 time > 截止日，弹出堆顶（最耗时的课）把 time 压回去。
  • 被退掉的可能正是刚收的，也可能是之前某门大课——堆保证每次退掉的都是当前选择里最亏的那门。
  • 课程数很大时堆里始终是「同样门数下总时长最短」的组合，堆的大小就是答案。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int scheduleCourse(int[][] courses) {5        // 截止日早的先安排：给后面留最大余地6        Arrays.sort(courses, (a, b) -> a[1] - b[1]);7        // 大顶堆装已选课程的时长；总时长超期就退掉最耗时的那门8        PriorityQueue<Integer> heap = new PriorityQueue<>((a, b) -> b - a);9        int time = 0;10        for (int[] c : courses) {11            time += c[0];12            heap.offer(c[0]);13            if (time > c[1]) time -= heap.poll();14        }15        return heap.size();16    }17}
题目

这里有 n 门不同的在线课程，按从 1 到 n 编号。给你一个数组 courses ，其中 courses[i] = [durationi, lastDayi] 表示第 i 门课将会 持续 上 durationi 天课，并且必须在不晚于 lastDayi 的时候完成。

你的学期从第 1 天开始。且不能同时修读两门及两门以上的课程。

返回你最多可以修读的课程数目。

示例 1：

输入：courses = [[100, 200], [200, 1300], [1000, 1250], [2000, 3200]]
输出：3
解释：
这里一共有 4 门课程，但是你最多可以修 3 门：
首先，修第 1 门课，耗费 100 天，在第 100 天完成，在第 101 天开始下门课。
第二，修第 3 门课，耗费 1000 天，在第 1100 天完成，在第 1101 天开始下门课程。
第三，修第 2 门课，耗时 200 天，在第 1300 天完成。
第 4 门课现在不能修，因为将会在第 3300 天完成它，这已经超出了关闭日期。

示例 2：

输入：courses = [[1,2]]
输出：1

示例 3：

输入：courses = [[3,2],[4,3]]
输出：0

提示:

  • 1 <= courses.length <= 104
  • 1 <= durationi, lastDayi <= 104
