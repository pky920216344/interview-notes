946. 验证栈序列

  • 中等
  • 频度 15
  • 栈
  • 贪心
  • 栈
  • 数组
  • 模拟
  • 待提交

贪心模拟：pushed 依次压栈，栈顶等于 popped 当前位就连着弹；扫完后栈空才合法。

思路

  • popped 的每个数弹出时必须在栈顶，所以按 pushed 顺序压栈，每压一个就尽量弹，别无其他选择。
  • 连弹是关键：弹掉一个后新栈顶可能又要弹，while 一直弹到栈顶 ≠ popped[j] 为止。
  • 扫完 pushed 后栈必须空（top == -1）；还剩元素说明有数被压在别的数下面，弹不出来了。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public boolean validateStackSequences(int[] pushed, int[] popped) {3        // 数组当栈：top 是栈顶下标，-1 表示空栈4        int[] stack = new int[pushed.length];5        int top = -1, j = 0;6        for (int x : pushed) {7            stack[++top] = x;8            // 栈顶正好是 popped 要弹的，就连着弹9            while (top >= 0 && stack[top] == popped[j]) {10                top--;11                j++;12            }13        }14        // 扫完 pushed 后栈必须空：还剩元素就是弹不出来15        return top == -1;16    }17}
题目

给定 pushed 和 popped 两个序列，每个序列中的 值都不重复，只有当它们可能是在最初空栈上进行的推入 push 和弹出 pop 操作序列的结果时，返回 true；否则，返回 false 。

示例 1：

输入：pushed = [1,2,3,4,5], popped = [4,5,3,2,1]
输出：true
解释：我们可以按以下顺序执行：
push(1), push(2), push(3), push(4), pop() -> 4,
push(5), pop() -> 5, pop() -> 3, pop() -> 2, pop() -> 1

示例 2：

输入：pushed = [1,2,3,4,5], popped = [4,3,5,1,2]
输出：false
解释：1 不能在 2 之前弹出。

提示：

  • 1 <= pushed.length <= 1000
  • 0 <= pushed[i] <= 1000
  • pushed 的所有元素 互不相同
  • popped.length == pushed.length
  • popped 是 pushed 的一个排列
