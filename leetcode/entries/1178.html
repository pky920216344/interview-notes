每个词压成 26 位掩码建计数表；每个谜面拆成「必含的首字母 + 其余 6 字母」，枚举其余部分的全部子集去查表。

思路

  • 词的字母种类压成 int 掩码（重复字母无所谓），相同掩码的词在 HashMap 里累加计数。
  • 谜底条件 = 含谜面首字母 + 每个字母 ∈ 谜面 → 掩码必须含 first 位且 ⊆ 谜面掩码。
  • 把谜面掩码异或掉首字母得 rest（6 位）：合法掩码 = s | first，s 取 rest 的所有子集，共 2⁶ = 64 个。
  • 子集枚举套路：s = (s − 1) & rest 递减，从 rest 扫到 0（含空集），注意 rest = 0 时也要查一次。

时间复杂度 O(词总长 + 谜面数·2⁶)，空间复杂度 O(不同掩码数)
1import java.util.*;2 3class Solution {4    public List<Integer> findNumOfValidWords(String[] words, String[] puzzles) {5        Map<Integer, Integer> cnt = new HashMap<>();6        for (String w : words) {7            int mask = 0;8            for (int i = 0; i < w.length(); i++) mask |= 1 << (w.charAt(i) - 'a');9            cnt.merge(mask, 1, Integer::sum);   // 只关心用过的字母种类，重复字母无所谓10        }11        List<Integer> ans = new ArrayList<>();12        for (String p : puzzles) {13            int mask = 0;14            for (int i = 0; i < p.length(); i++) mask |= 1 << (p.charAt(i) - 'a');15            int first = 1 << (p.charAt(0) - 'a');16            int rest = mask ^ first;   // 除首字母外的 6 个字母17            int total = 0;18            // 合法谜底 = 必含首字母 + 其余字母是 rest 的子集 → 枚举 rest 的全部子集去查表19            for (int s = rest; ; s = (s - 1) & rest) {20                Integer c = cnt.get(s | first);21                if (c != null) total += c;22                if (s == 0) break;   // 子集枚举套路：s−1 再与 rest，正好扫完包括空集23            }24            ans.add(total);25        }26        return ans;27    }28}
题目

外国友人仿照中国字谜设计了一个英文版猜字谜小游戏，请你来猜猜看吧。

字谜的迷面 puzzle 按字符串形式给出，如果一个单词 word 符合下面两个条件，那么它就可以算作谜底：

  • 单词 word 中包含谜面 puzzle 的第一个字母。
  • 单词 word 中的每一个字母都可以在谜面 puzzle 中找到。
    例如，如果字谜的谜面是 "abcdefg"，那么可以作为谜底的单词有 "faced", "cabbage", 和 "baggage"；而 "beefed"（不含字母 "a"）以及 "based"（其中的 "s" 没有出现在谜面中）都不能作为谜底。

返回一个答案数组 answer，数组中的每个元素 answer[i] 是在给出的单词列表 words 中可以作为字谜迷面 puzzles[i] 所对应的谜底的单词数目。

示例：

输入：
words = ["aaaa","asas","able","ability","actt","actor","access"], 
puzzles = ["aboveyz","abrodyz","abslute","absoryz","actresz","gaswxyz"]
输出：[1,1,3,2,4,0]
解释：
1 个单词可以作为 "aboveyz" 的谜底 : "aaaa" 
1 个单词可以作为 "abrodyz" 的谜底 : "aaaa"
3 个单词可以作为 "abslute" 的谜底 : "aaaa", "asas", "able"
2 个单词可以作为 "absoryz" 的谜底 : "aaaa", "asas"
4 个单词可以作为 "actresz" 的谜底 : "aaaa", "asas", "actt", "access"
没有单词可以作为 "gaswxyz" 的谜底，因为列表中的单词都不含字母 'g'。

提示：

  • 1 <= words.length <= 10^5
  • 4 <= words[i].length <= 50
  • 1 <= puzzles.length <= 10^4
  • puzzles[i].length == 7
  • words[i][j], puzzles[i][j] 都是小写英文字母。
  • 每个 puzzles[i] 所包含的字符都不重复。
