759. 员工空闲时间

  • 困难
  • 频度 3
  • 扫描线/排序
  • 数组
  • 排序
  • 扫描线
  • 堆（优先队列）
  • 未经力扣验证

公共空闲 = 忙碌并集的补：把所有员工的忙段摊平排序，扫描合并出并集，相邻并集块之间的空隙就是答案。

思路

  • 谁在何时忙不影响结果，只把所有员工的忙段摊平到一起按开始时间排序。
  • 扫描维护 coverEnd（已扫过忙段的并集右端）：新段 it[0] > coverEnd 说明中间有空隙。
  • 空隙记为 [coverEnd, it[0]]：忙段两端都算忙，连续时间轴上 (3,4) 这样的开区间按惯例写成 [3,4]；有重叠就 coverEnd = max(coverEnd, it[1])。
  • 区间表示：本题无力扣模板，这里用 int[][][]（员工 → 忙段列表）和 int[][]（空闲段列表）。

1import java.util.*;2 3class Solution {4    // 员工的忙碌区间用 [start, end]（两端都算忙）表示；schedule[e] 是员工 e 的区间列表。5    // 返回所有人的公共空闲时段：区间是连续时间轴上的开区间 (coverEnd, itStart)，按题面惯例写成 [coverEnd, itStart]。6    public int[][] employeeFreeTime(int[][][] schedule) {7        // 公共空闲只取决于「忙的并集」：把所有员工的区间摊平到一起8        List<int[]> all = new ArrayList<>();9        for (int[][] emp : schedule) {10            for (int[] it : emp) all.add(it);11        }12        all.sort((a, b) -> a[0] - b[0]);13        List<int[]> free = new ArrayList<>();14        int coverEnd = all.isEmpty() ? 0 : all.get(0)[1];15        // coverEnd：已扫过的忙碌时段并集的右端点16        for (int i = 1; i < all.size(); i++) {17            int[] it = all.get(i);18            if (it[0] > coverEnd) {19                // 新忙段接不上：中间 (coverEnd, it[0]) 人人都闲20                free.add(new int[]{coverEnd, it[0]});21                coverEnd = it[1];22            } else if (it[1] > coverEnd) {23                coverEnd = it[1];   // 有重叠：并集右端外扩24            }25        }26        return free.toArray(new int[0][]);27    }28}
