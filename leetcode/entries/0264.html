三指针 DP：dp[i] = min(dp[p2]·2, dp[p3]·3, dp[p5]·5)，谁被选中谁前移；候选相等时几个指针一起进，同一个丑数就不会生成两次。

思路

  • 每个丑数都是前面某个丑数 ×2、×3 或 ×5 得来的：dp 存已生成的丑数，三个指针指向各自「下一个还没乘过」的位置。
  • 三个候选取最小填进 dp[i]，dp 天然严格递增。
  • 用 == 判断谁被选中：相等时几个指针一起 ++（如 6 = 2×3 = 3×2），保证每个丑数只生成一次。

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int nthUglyNumber(int n) {3        // dp[i] 是第 i+1 个丑数；p2/p3/p5 指向各自「还没乘过 2/3/5」的丑数4        int[] dp = new int[n];5        dp[0] = 1;6        int p2 = 0, p3 = 0, p5 = 0;7        for (int i = 1; i < n; i++) {8            // 三个候选取最小；相同的候选指针都要前进，不然同一个丑数会出现两次9            int c2 = dp[p2] * 2, c3 = dp[p3] * 3, c5 = dp[p5] * 5;10            dp[i] = Math.min(c2, Math.min(c3, c5));11            if (dp[i] == c2) p2++;12            if (dp[i] == c3) p3++;13            if (dp[i] == c5) p5++;14        }15        return dp[n - 1];16    }17}
题目

给你一个整数 n ，请你找出并返回第 n 个 丑数 。

丑数 就是质因子只包含 2、3 和 5 的正整数。

示例 1：

输入：n = 10
输出：12
解释：[1, 2, 3, 4, 5, 6, 8, 9, 10, 12] 是由前 10 个丑数组成的序列。

示例 2：

输入：n = 1
输出：1
解释：1 通常被视为丑数。

提示：

  • 1 <= n <= 1690
