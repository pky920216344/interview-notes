670. 最大交换

  • 中等
  • 频度 24
  • 贪心
  • 贪心

  • 力扣已通过

记下每个数字最后出现的位置；从左找第一位「右边有更大数字」的位，与那个最大数字的最后一次出现交换。

思路

  • last[d] 记数字 d 最后出现的下标；让数值变大，必须动最靠前的「能变大的位」。
  • 对每一位 i，从 9 往下找第一个 v > cs[i] 且 last[v] > i 的 v，交换后直接返回。
  • 取 last[v]（最后一次出现）：把换下去的小数字放到尽量靠右，结果才最大。
  • 扫完都没有这样的位，说明原数已是最大，原样返回。

图解

最优解

时间复杂度 O(log n)（位数 ≤ 10），空间复杂度 O(1)
1class Solution {2    public int maximumSwap(int num) {3        char[] cs = String.valueOf(num).toCharArray();4        int n = cs.length;5        // last[d]：数字 d 最后出现的位置（没出现记 0）6        int[] last = new int[10];7        for (int i = 0; i < n; i++) last[cs[i] - '0'] = i;8        // 从左往右找第一位「右边存在更大数字」的位9        for (int i = 0; i < n; i++) {10            int d = cs[i] - '0';11            for (int v = 9; v > d; v--) {12                // 与最后一次出现的那个 v 交换：小的数换到尽量靠右，结果才最大13                if (last[v] > i) {14                    char t = cs[i];15                    cs[i] = cs[last[v]];16                    cs[last[v]] = t;17                    return Integer.parseInt(new String(cs));18                }19            }20        }21        // 每一位都不小于右边：原数已是最大22        return num;23    }24}
题目

给定一个非负整数，你至多可以交换一次数字中的任意两位。返回你能得到的最大值。

示例 1 :

输入: 2736
输出: 7236
解释: 交换数字2和数字7。

示例 2 :

输入: 9973
输出: 9973
解释: 不需要交换。

注意:

  1. 给定数字的范围是 [0, 108]
