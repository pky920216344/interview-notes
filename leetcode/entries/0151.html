151. 反转字符串中的单词

  • 中等
  • 频度 107
  • 双指针
  • 双指针
  • 字符串
  • 力扣已通过

从右往左双指针收割单词：跳过空格后 i 停在词尾，j 走到词头前一格，把 s[j+1..i] 逐词拼进结果。

思路

  • i 从最右端往左扫：先跳过一段空格，i 就停在每个单词的末字符上。
  • j 从 i 继续往左走，碰到空格（或走到 -1）停，单词就是 s[j+1 .. i]。
  • 拼接前给已收的词补一个单空格（sb.length() > 0 时），结果就不会有前导/尾随空格。
  • 收完 i = j 继续，i < 0 结束；单词间的多个空格自然被跳掉。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public String reverseWords(String s) {3        StringBuilder sb = new StringBuilder();4        int i = s.length() - 1;5        while (i >= 0) {6            // 先跳过单词右边的空格7            while (i >= 0 && s.charAt(i) == ' ') i--;8            if (i < 0) break;9            // j 从单词右端往左走，停在单词左端的前一格10            int j = i;11            while (j >= 0 && s.charAt(j) != ' ') j--;12            // 收过词了就先补一个空格，保证词间单空格13            if (sb.length() > 0) sb.append(' ');14            sb.append(s, j + 1, i + 1);15            i = j;16        }17        return sb.toString();18    }19}
题目

给你一个字符串 s ，请你反转字符串中 单词 的顺序。

单词 是由非空格字符组成的字符串。s 中使用至少一个空格将字符串中的 单词 分隔开。

返回 单词 顺序颠倒且 单词 之间用单个空格连接的结果字符串。

注意：输入字符串 s中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

示例 1：

输入：s = "the sky is blue"
输出："blue is sky the"

示例 2：

输入：s = "  hello world  "
输出："world hello"
解释：反转后的字符串中不能存在前导空格和尾随空格。

示例 3：

输入：s = "a good   example"
输出："example good a"
解释：如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。

提示：

  • 1 <= s.length <= 104
  • s 包含英文大小写字母、数字和空格 ' '
  • s 中 至少存在一个 单词

进阶：如果字符串在你使用的编程语言中是一种可变数据类型，请尝试使用 O(1) 额外空间复杂度的 原地 解法。
