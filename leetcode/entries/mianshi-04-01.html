有向图可达性：把边建成邻接表，从 start 出发 BFS 标记所有能走到的点，弹出 target 就返回 true。

思路

  • 邻接表 g[a] 存 a 的所有出边（自环、平行边照常挂）。
  • BFS 从 start 出发：出队的点先判是不是 target，再把没走过的邻居标 seen 入队。
  • seen 保证每个点只入队一次，队空还没碰到 target 就是不连通。

时间复杂度 O(n + E)，空间复杂度 O(n + E)
1import java.util.*;2 3class Solution {4    public boolean findWhetherExistsPath(int n, int[][] graph, int start, int target) {5        // 邻接表：把有向边按起点分组6        List<List<Integer>> g = new ArrayList<>();7        for (int i = 0; i < n; i++) g.add(new ArrayList<>());8        for (int[] e : graph) g.get(e[0]).add(e[1]);9        // 从 start 出发 BFS，走到的点都标记为已见10        boolean[] seen = new boolean[n];11        ArrayDeque<Integer> queue = new ArrayDeque<>();12        seen[start] = true;13        queue.add(start);14        while (!queue.isEmpty()) {15            int u = queue.poll();16            if (u == target) return true;17            for (int v : g.get(u)) {18                if (seen[v]) continue;19                seen[v] = true;20                queue.add(v);21            }22        }23        return false;24    }25}
题目

节点间通路。给定有向图，设计一个算法，找出两个节点之间是否存在一条路径。

示例 1：

 输入：n = 3, graph = [[0, 1], [0, 2], [1, 2], [1, 2]], start = 0, target = 2
 输出：true

示例 2：

 输入：n = 5, graph = [[0, 1], [0, 2], [0, 4], [0, 4], [0, 1], [1, 3], [1, 4], [1, 3], [2, 3], [3, 4]], start = 0, target = 4
 输出：true

提示：

  1. 节点数量n在[0, 1e5]范围内。
  2. 节点编号大于等于 0 小于 n。
  3. 图中可能存在自环和平行边。
