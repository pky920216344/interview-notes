补充题21. 字符串相减

  • 中等
  • 频度 12
  • 模拟
  • 未经力扣验证

大数竖式减法：从低位往高位逐位相减，不够减向高位借 1；结果反转后去前导零，小减大就换位再补负号。

思路

  • 先比较大小（先比长度再逐位比）：相等返回 "0"；a < b 就算 b − a 再补 -。
  • 双指针从末位对齐，d = a[i] − borrow − b[j]（越界位当 0）；d < 0 就 borrow = 1、本位写 d + 10。
  • 低位先算压进 StringBuilder，最后 reverse；再去掉前导零（100−99=001 这种），至少留一位。

1class Solution {2    // 大数减法竖式：a、b 是不含前导零的非负整数十进制串，返回 a−b 的十进制串；3    // a < b 时返回带负号的结果。签名自定（本题无力扣页面），不提交力扣。4    public String subtract(String a, String b) {5        int cmp = a.length() != b.length() ? a.length() - b.length() : a.compareTo(b);6        if (cmp == 0) return "0";7        if (cmp < 0) return "-" + subtract(b, a);   // 小减大：换过来算，前面补负号8        StringBuilder sb = new StringBuilder();9        int i = a.length() - 1, j = b.length() - 1, borrow = 0;10        while (i >= 0 || j >= 0) {11            int da = i >= 0 ? a.charAt(i--) - '0' : 0;12            int db = j >= 0 ? b.charAt(j--) - '0' : 0;13            int d = da - borrow - db;14            borrow = d < 0 ? 1 : 0;   // 不够减：向高位借 1，本位加 1015            sb.append(d < 0 ? d + 10 : d);16        }17        sb.reverse();18        int start = 0;   // 去掉前导零（如 100−99=001），但至少留一位19        while (sb.length() - start > 1 && sb.charAt(start) == '0') start++;20        return sb.substring(start);21    }22}
