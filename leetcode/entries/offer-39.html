摩尔投票：不同的数两两抵消，cnt 归零就换候选人；超过一半的数一定活到最后。

思路

  • 维护候选人 cand 和计数 cnt：读到相同的数 cnt+1，不同的 cnt-1。
  • cnt 归零说明前面的正好互相抵完，换当前数当候选人重新起算。
  • 出现超过一半的数抵消后必有剩余，扫完的候选人就是答案；题目保证存在，不用再验证一遍。

1class Solution {2    public int inventoryManagement(int[] stock) {3        // 摩尔投票：不同的数两两抵消，剩下的必然是超过一半的那个4        int cand = 0, cnt = 0;5        for (int x : stock) {6            if (cnt == 0) cand = x;   // 抵消光了就换当前数当候选人7            cnt += x == cand ? 1 : -1;8        }9        return cand;10    }11}
题目

仓库管理员以数组 stock 形式记录商品库存表。stock[i] 表示商品 id，可能存在重复。请返回库存表中数量大于 stock.length / 2 的商品 id。

示例 1：

输入：stock = [6, 1, 3, 1, 1, 1]
输出：1

提示：

  • 1 <= stock.length <= 50000
  • 给定数组为非空数组，且存在结果数字
