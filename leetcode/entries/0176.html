176. 第二高的薪水

  • 简单
  • 频度 2
  • SQL
  • 数据库
  • 待提交

DISTINCT 去重后按工资降序，LIMIT 1 OFFSET 1 跳过第一名取第二名；标量子查询天然在没数时返回 NULL。

思路

  • 去重是第一坑：ORDER BY salary DESC LIMIT 1 OFFSET 1 若不去重，两个相同最高工资会让第二行还是第一名。
  • 没有第二高要返回 NULL 而不是空集：把子查询包在 SELECT (...) AS SecondHighestSalary 里——标量子查询查不到就是 NULL，正好凑出「一行 NULL」的要求。
  • 直接 SELECT MAX 排除最高值的写法（WHERE salary < (SELECT MAX...)）也可以，但空表/单行时同样靠外层包一层才返回 NULL。

最优解

时间复杂度 O(n log n)，空间复杂度 O(1)
1-- 176（codetop 0176）第二高的薪水（MySQL）2-- 题意：Employee(id, salary)。返回第二高的不同薪水；不存在则返回 NULL（表里要有这一行，列名 SecondHighestSalary）。3SELECT (4    SELECT DISTINCT salary5    FROM Employee6    ORDER BY salary DESC7    LIMIT 1 OFFSET 18) AS SecondHighestSalary;
题目
Employee 表： 
+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| salary      | int  |
+-------------+------+
id 是这个表的主键。
表的每一行包含员工的工资信息。

查询并返回 Employee 表中第二高的 不同 薪水 。如果不存在第二高的薪水，查询应该返回 null(Pandas 则返回 None) 。

查询结果如下例所示。

示例 1：

输入：
Employee 表：
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
+----+--------+
输出：
+---------------------+
| SecondHighestSalary |
+---------------------+
| 200                 |
+---------------------+

示例 2：

输入：
Employee 表：
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
+----+--------+
输出：
+---------------------+
| SecondHighestSalary |
+---------------------+
| null                |
+---------------------+
