BFS 逐层：层号就是变换次数，beginWord 算第 1 个词；弹出 endWord 时返回当前层号；邻居用「每个位置换 26 个字母」在字典里查。

思路

  • 起点 beginWord 算第 1 个词，depth 从 1 起；一次处理一整层，层号 = 当前序列长度。
  • 邻居生成：每个位置试 26 个字母，dict.contains(next) && visited.add(next) 才入队（add 返回 false 就是来过，顺便去重）。
  • 弹出 endWord 时返回当前 depth——BFS 第一次到达就是最短。
  • 开头先判 endWord 在不在字典里，不在直接返回 0。

时间复杂度 O(26·L·n·L)，空间复杂度 O(n·L)
1import java.util.*;2 3class Solution {4    public int ladderLength(String beginWord, String endWord, List<String> wordList) {5        Set<String> dict = new HashSet<>(wordList);6        if (!dict.contains(endWord)) return 0;7        Set<String> visited = new HashSet<>();8        visited.add(beginWord);9        Queue<String> queue = new ArrayDeque<>();10        queue.add(beginWord);11        int depth = 1;                        // 序列里的单词数，beginWord 算第 1 个12        while (!queue.isEmpty()) {13            int size = queue.size();          // 一次处理一整层：层号就是当前序列长度14            while (size-- > 0) {15                String cur = queue.poll();16                if (cur.equals(endWord)) return depth;17                // 邻居怎么找：每个位置换 26 个字母，在字典里且没访问过的就是下一步18                for (int i = 0; i < cur.length(); i++) {19                    char[] cs = cur.toCharArray();20                    for (char c = 'a'; c <= 'z'; c++) {21                        cs[i] = c;22                        String next = new String(cs);23                        // visited.add 返回 false 说明来过，顺便完成去重24                        if (dict.contains(next) && visited.add(next)) queue.add(next);25                    }26                }27            }28            depth++;29        }30        return 0;   // 扫完所有层都没碰到 endWord31    }32}
题目

字典 wordList 中从单词 beginWord 到 endWord 的 转换序列 是一个按下述规格形成的序列 beginWord -> s1 -> s2 -> ... -> sk：

  • 每一对相邻的单词只差一个字母。
  •  对于 1 <= i <= k 时，每个 si 都在 wordList 中。注意， beginWord 不需要在 wordList 中。
  • sk == endWord

给你两个单词 beginWord 和 endWord 和一个字典 wordList ，返回 从 beginWord 到 endWord 的 最短转换序列 中的 单词数目 。如果不存在这样的转换序列，返回 0 。

 

示例 1：

输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
输出：5
解释：一个最短转换序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog", 返回它的长度 5。

示例 2：

输入：beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
输出：0
解释：endWord "cog" 不在字典中，所以无法进行转换。

提示：

  • 1 <= beginWord.length <= 10
  • endWord.length == beginWord.length
  • 1 <= wordList.length <= 5000
  • wordList[i].length == beginWord.length
  • beginWord、endWord 和 wordList[i] 由小写英文字母组成
  • beginWord != endWord
  • wordList 中的所有字符串 互不相同
