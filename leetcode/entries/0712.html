712. 两个字符串的最小ASCII删除和

LCS 变形 DP：两字符相等就都留下抄左上角，否则删掉其中一个、把它的 ASCII 加进代价，取较小。

思路

  • dp[i][j]：把 s1 前 i 个和 s2 前 j 个变相等要删的最小 ASCII 和。
  • s1[i-1] == s2[j-1]：这对字符留下最优（ASCII 都是正数，删了只会更贵），dp[i][j] = dp[i-1][j-1]。
  • 不等：删 s1 的字符（dp[i-1][j] + s1[i-1]）或删 s2 的（dp[i][j-1] + s2[j-1]），取小。
  • 边界：一边为空就把另一边整段删掉；Java 压成滚动数组，diag 变量存左上角旧值。

时间复杂度 O(nm)，空间复杂度 O(m)
1class Solution {2    public int minimumDeleteSum(String s1, String s2) {3        int n = s1.length(), m = s2.length();4        // 滚动数组：dp[j] = s1 前 i 个与 s2 前 j 个对齐的最小删除和5        int[] dp = new int[m + 1];6        for (int j = 1; j <= m; j++) dp[j] = dp[j - 1] + s2.charAt(j - 1);   // 第 0 行：删光 s2 前缀7        for (int i = 1; i <= n; i++) {8            int diag = dp[0];                    // 左上角旧值 dp[i-1][j-1]9            dp[0] = diag + s1.charAt(i - 1);     // 第 0 列：删光 s1 前缀10            for (int j = 1; j <= m; j++) {11                char a = s1.charAt(i - 1), b = s2.charAt(j - 1);12                int up = dp[j];                  // dp[i-1][j]，滚给下一列当左上角13                if (a == b) dp[j] = diag;        // 相等：都留下最优，斜抄14                else dp[j] = Math.min(up + a, dp[j - 1] + b);   // 删 a 或删 b，取小15                diag = up;16            }17        }18        return dp[m];19    }20}
题目

给定两个字符串s1 和 s2，返回 使两个字符串相等所需删除字符的 ASCII 值的最小和 。

示例 1:

输入: s1 = "sea", s2 = "eat"
输出: 231
解释: 在 "sea" 中删除 "s" 并将 "s" 的值(115)加入总和。
在 "eat" 中删除 "t" 并将 116 加入总和。
结束时，两个字符串相等，115 + 116 = 231 就是符合条件的最小和。

示例 2:

输入: s1 = "delete", s2 = "leet"
输出: 403
解释: 在 "delete" 中删除 "dee" 字符串变成 "let"，
将 100[d]+101[e]+101[e] 加入总和。在 "leet" 中删除 "e" 将 101[e] 加入总和。
结束时，两个字符串都等于 "let"，结果即为 100+101+101+101 = 403 。
如果改为将两个字符串转换为 "lee" 或 "eet"，我们会得到 433 或 417 的结果，比答案更大。

提示:

  • 1 <= s1.length, s2.length <= 1000
  • s1 和 s2 由小写英文字母组成
