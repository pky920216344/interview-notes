1100. 长度为 K 的无重复字符子串

  • 中等
  • 频度 2
  • 滑动窗口
  • 哈希表
  • 哈希表
  • 字符串
  • 滑动窗口
  • 未经力扣验证

定长滑窗：右端进窗时计数到 2 就 dup++，左端出窗计数降回 1 就 dup--；每步看「dup == 0 且窗口已满」就计一个。

思路

  • 窗口长度固定为 k：右端 i 进一格、左端 i-k 出一格，进出各只动一个计数。
  • dup 记窗口里「出现 ≥2 次的字符种数」：进窗计数变成 2 时 dup++，出窗计数降回 1 时 dup--，dup == 0 即无重复。
  • i >= k-1（窗口已满）且 dup == 0 时 ans++；k > 26 直接返回 0（26 个字母必重复）。

最优解

时间复杂度 O(n)，空间复杂度 O(26)
1class Solution {2    public int numKLenSubstrNoRepeats(String s, int k) {3        if (k > 26) return 0;   // 26 个字母装不下更长的无重复窗口4        int n = s.length();5        int[] cnt = new int[26];6        int dup = 0, ans = 0;   // dup：窗口里出现 ≥2 次的字符种数7        for (int i = 0; i < n; i++) {8            if (++cnt[s.charAt(i) - 'a'] == 2) dup++;       // 右端进窗9            if (i >= k && --cnt[s.charAt(i - k) - 'a'] == 1) dup--;   // 左端出窗10            if (i >= k - 1 && dup == 0) ans++;   // 窗口恰好 k 长且无重复11        }12        return ans;13    }14}
