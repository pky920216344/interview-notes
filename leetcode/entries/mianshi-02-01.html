面试题 02.01. 移除重复节点

哈希集合记见过的值：下一个结点的值出现过就跨过它，一直跨到下一个没见过的为止。

思路

  • seen 存已保留的值；cur 走到哪都先把自己的值记进去，保证「保留最先出现的」。
  • 值重复的结点不走进它，而是改 cur.next 直接跨过（可能一次跨多个重复结点）。
  • 进阶「不用临时缓冲区」：双重循环，对每个结点用 cur.val 检查后面所有结点，O(n²) 时间换 O(1) 空间。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public ListNode removeDuplicateNodes(ListNode head) {5        Set<Integer> seen = new HashSet<>();6        ListNode cur = head;7        while (cur != null) {8            seen.add(cur.val);9            // 下一个结点的值出现过就跨过它，一直跨到下一个没见过的为止10            while (cur.next != null && seen.contains(cur.next.val)) cur.next = cur.next.next;11            cur = cur.next;12        }13        return head;14    }15}
题目

编写代码，移除未排序链表中的重复节点。保留最开始出现的节点。

示例1：

 输入：[1, 2, 3, 3, 2, 1]
 输出：[1, 2, 3]

示例2：

 输入：[1, 1, 1, 1, 2]
 输出：[1, 2]

提示：

  1. 链表长度在[0, 20000]范围内。
  2. 链表元素在[0, 20000]范围内。
