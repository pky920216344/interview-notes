720. 词典中最长的单词

字典序升序排序 + 哈希集合：逐词检查「去掉尾字符的前缀已建成」，接得上就入集合并挑战答案。

思路

  • 字典序升序保证每个词的前缀都排在它前面，逐词扫一遍时前缀一定先入集合。
  • 词能入选 ⟺ 长度为 1，或去掉尾字符的前缀已在集合里（链上前缀也必然都建成了）。
  • 只在「严格更长」时更新答案：同长时先出现的字典序更小，天然取到最小者。

最优解

时间复杂度 O(n·L log n)（L 为词长），空间复杂度 O(n·L)
1import java.util.*;2 3class Solution {4    public String longestWord(String[] words) {5        // 字典序升序：单词的每个前缀都排在它前面，逐个检查时前缀一定先入集合6        Arrays.sort(words);7        Set<String> built = new HashSet<>();8        String ans = "";9        for (String w : words) {10            // 长度 1 的词可以直接开始；更长的必须去掉尾字符后已经建成11            if (w.length() == 1 || built.contains(w.substring(0, w.length() - 1))) {12                built.add(w);13                // 只在更长时更新：同长里先出现的字典序更小14                if (w.length() > ans.length()) ans = w;15            }16        }17        return ans;18    }19}
题目

给出一个字符串数组 words 组成的一本英语词典。返回能够通过 words 中其它单词逐步添加一个字母来构造得到的 words 中最长的单词。

若其中有多个可行的答案，则返回答案中字典序最小的单词。若无答案，则返回空字符串。

请注意，单词应该从左到右构建，每个额外的字符都添加到前一个单词的结尾。

示例 1：

输入：words = ["w","wo","wor","worl", "world"]
输出："world"
解释： 单词"world"可由"w", "wo", "wor", 和 "worl"逐步添加一个字母组成。

示例 2：

输入：words = ["a", "banana", "app", "appl", "ap", "apply", "apple"]
输出："apple"
解释："apply" 和 "apple" 都能由词典中的单词组成。但是 "apple" 的字典序小于 "apply"

提示：

  • 1 <= words.length <= 1000
  • 1 <= words[i].length <= 30
  • 所有输入的字符串 words[i] 都只包含小写字母。
