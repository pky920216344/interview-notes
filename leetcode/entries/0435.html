435. 无重叠区间

按右端点排序贪心：右端小的不碍事，能保就保；保住最多的不重叠区间，其余删掉。

思路

  • 按右端点从小到大排序：先保右端最小的，给后面留的空间最大。
  • 从左往右扫：起点 ≥ 上一个保住区间的右端点就保住并更新 end（触碰端点不算重叠，所以是 ≥）。
  • 保住的个数就是最多不重叠区间数，答案 = n − 保住的个数。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(log n)
1import java.util.*;2 3class Solution {4    public int eraseOverlapIntervals(int[][] intervals) {5        // 按右端点排序：右端越小，给后面留的空间越多6        Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));7        int kept = 0;8        // 上一个保住区间的右端点9        int end = Integer.MIN_VALUE;10        for (int[] v : intervals) {11            // 起点没压到上一个右端点就不重叠（触碰不算），保住它12            if (v[0] >= end) {13                kept++;14                end = v[1];15            }16        }17        // 保住的个数已是最多不重叠区间数，剩下的都得删18        return intervals.length - kept;19    }20}
题目

给定一个区间的集合 intervals ，其中 intervals[i] = [starti, endi] 。返回 需要移除区间的最小数量，使剩余区间互不重叠 。

注意 只在一点上接触的区间是 不重叠的。例如 [1, 2] 和 [2, 3] 是不重叠的。

示例 1:

输入: intervals = [[1,2],[2,3],[3,4],[1,3]]
输出: 1
解释: 移除 [1,3] 后，剩下的区间没有重叠。

示例 2:

输入: intervals = [ [1,2], [1,2], [1,2] ]
输出: 2
解释: 你需要移除两个 [1,2] 来使剩下的区间没有重叠。

示例 3:

输入: intervals = [ [1,2], [2,3] ]
输出: 0
解释: 你不需要移除任何区间，因为它们已经是无重叠的了。

提示:

  • 1 <= intervals.length <= 105
  • intervals[i].length == 2
  • -5 * 104 <= starti < endi <= 5 * 104
