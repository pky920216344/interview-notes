1031. 两个无重叠子数组的最大和

  • 数组
  • 动态规划
  • 滑动窗口
  • 待提交

一遍滑窗同时推两个窗口：R 窗每右移一格，就用 bestL（R 窗左侧 L 窗的历史最大和）配当前 R 窗更新答案；两种先后顺序各跑一遍取大。

思路

  • 固定「L 窗在前、R 窗在后」：R 窗右端点 i 从 L+R 扫到末尾，能和它搭配的 L 窗右端点最远到 i-R。
  • sumL、sumR 随窗口各右移一格增量更新；bestL 只增不减地记 L 窗的历史最大和。
  • 每步 ans = max(ans, bestL + sumR)——L 窗取历史最大、R 窗取当前，两者不重叠（L 窗永远在 R 窗左侧）。
  • 长 firstLen 的窗和长 secondLen 的窗谁前谁后是两种摆法，help 跑两遍取 max。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxSumTwoNoOverlap(int[] nums, int firstLen, int secondLen) {3        // 谁在前谁在后是两种不同的摆法，各算一遍取大4        return Math.max(help(nums, firstLen, secondLen), help(nums, secondLen, firstLen));5    }6 7    // L 窗在前、R 窗在后：右端点 i 扫过去，维护「R 窗左侧」L 窗的最大和8    private int help(int[] nums, int L, int R) {9        int n = nums.length;10        int sumL = 0, sumR = 0;11        for (int i = 0; i < L; i++) sumL += nums[i];12        for (int i = L; i < L + R; i++) sumR += nums[i];13        int bestL = sumL;           // 扫过位置里 L 窗的最大和14        int ans = sumL + sumR;15        for (int i = L + R; i < n; i++) {16            sumR += nums[i] - nums[i - R];                  // R 窗右移一格17            sumL += nums[i - R] - nums[i - R - L];          // L 窗跟着右移，仍在 R 窗左边18            bestL = Math.max(bestL, sumL);19            ans = Math.max(ans, bestL + sumR);20        }21        return ans;22    }23}
题目

给你一个整数数组 nums 和两个整数 firstLen 和 secondLen，请你找出并返回两个无重叠 子数组 中元素的最大和，长度分别为 firstLen 和 secondLen 。

长度为 firstLen 的子数组可以出现在长为 secondLen 的子数组之前或之后，但二者必须是无重叠。

子数组是数组的一个 连续 部分。

示例 1：

输入：nums = [0,6,5,2,2,5,1,9,4], firstLen = 1, secondLen = 2
输出：20
解释：子数组的一种选择中，[9] 长度为 1，[6,5] 长度为 2。

示例 2：

输入：nums = [3,8,1,3,2,1,8,9,0], firstLen = 3, secondLen = 2
输出：29
解释：子数组的一种选择中，[3,8,1] 长度为 3，[8,9] 长度为 2。

示例 3：

输入：nums = [2,1,5,6,0,9,5,0,3,8], firstLen = 4, secondLen = 3
输出：31
解释：子数组的一种选择中，[5,6,0,9] 长度为 4，[0,3,8] 长度为 3。

提示：

  • 1 <= firstLen, secondLen <= 1000
  • 2 <= firstLen + secondLen <= 1000
  • firstLen + secondLen <= nums.length <= 1000
  • 0 <= nums[i] <= 1000
