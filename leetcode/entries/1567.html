1567. 乘积为正数的最长子数组长度

  • 中等
  • 频度 2
  • 动态规划
  • 贪心
  • 数组
  • 动态规划
  • 待提交

双状态 DP：pos/neg 记以当前元素结尾、乘积为正/为负的最长长度；正数各加 1，负数把两状态互换，0 双双归零。

思路

  • pos、neg 是以当前元素结尾的最长「乘积为正/为负」子数组长度，边扫边更新。
  • 正数：pos+1；neg 只有原本 > 0 才能接上（否则乘积里没有负因子，仍是「不存在」记 0）。
  • 负数：符号翻转——新 pos 接在旧 neg 上、新 neg 接在旧 pos 上（旧 neg 为 0 时新 pos 归 0）。
  • 遇 0：两状态都归零，从下一个元素重新起头；答案取所有 pos 的最大值。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int getMaxLen(int[] nums) {3        int ans = 0;4        // pos/neg：以当前元素结尾、乘积为正/为负的最长子数组长度5        int pos = 0, neg = 0;6        for (int x : nums) {7            if (x == 0) {8                // 乘积被 0 清掉：两种状态都归零，从下一个元素重新起头9                pos = 0;10                neg = 0;11            } else if (x > 0) {12                pos = pos + 1;13                neg = neg > 0 ? neg + 1 : 0;14            } else {15                // 负数把符号翻转：新「正」只能接在旧「负」上，新「负」接在旧「正」上16                int nextPos = neg > 0 ? neg + 1 : 0;17                neg = pos + 1;18                pos = nextPos;19            }20            ans = Math.max(ans, pos);21        }22        return ans;23    }24}
题目

给你一个整数数组 nums ，请你求出乘积为正数的最长子数组的长度。

一个数组的子数组是由原数组中零个或者更多个连续数字组成的数组。

请你返回乘积为正数的最长子数组长度。

示例  1：

输入：nums = [1,-2,-3,4]
输出：4
解释：数组本身乘积就是正数，值为 24 。

示例 2：

输入：nums = [0,1,-2,-3,-4]
输出：3
解释：最长乘积为正数的子数组为 [1,-2,-3] ，乘积为 6 。
注意，我们不能把 0 也包括到子数组中，因为这样乘积为 0 ，不是正数。

示例 3：

输入：nums = [-1,-2,-3,0,1]
输出：2
解释：乘积为正数的最长子数组是 [-1,-2] 或者 [-2,-3] 。

提示：

  • 1 <= nums.length <= 10^5
  • -10^9 <= nums[i] <= 10^9
