双栈分工：push 只进 in；pop/peek 时若 out 空了，把 in 整体倒进 out，栈顶即队首。

思路

  • in 栈只管进，out 栈只管出：两个栈一倒腾，先进先出的顺序就出来了。
  • pop/peek：out 空了才把 in 全部倒入 out（每个元素最多被倒一次，均摊 O(1)）；out 不空就直接用栈顶。
  • empty：两个栈都空才是空队列。
  • 关键点：不要每次 pop 都倒腾，只在 out 空时倒，倒一半会破坏顺序。

题目

实现一个MyQueue类，该类用两个栈来实现一个队列。


示例：

MyQueue queue = new MyQueue();

queue.push(1);
queue.push(2);
queue.peek();  // 返回 1
queue.pop();   // 返回 1
queue.empty(); // 返回 false


说明：

  • 你只能使用标准的栈操作 -- 也就是只有 push to top, peek/pop from top, size 和 is empty 操作是合法的。
  • 你所使用的语言也许不支持栈。你可以使用 list 或者 deque（双端队列）来模拟一个栈，只要是标准的栈操作即可。
  • 假设所有操作都是有效的 （例如，一个空的队列不会调用 pop 或者 peek 操作）。
