73. 矩阵置零

  • 中等
  • 频度 11
  • 模拟
  • 数组
  • 哈希表
  • 矩阵
  • 待提交

O(1) 空间：把第一行、第一列征用作「该行/该列有 0」的标记数组，它们自己是否含 0 用两个布尔先记下。

思路

  • 征用前先扫一遍第一行、第一列，把「它们自己是否含 0」记进 row0、col0 两个布尔。
  • 扫其余部分：matrix[i][j] == 0 就在 matrix[i][0]、matrix[0][j] 打上 0 记号。
  • 置零顺序很关键：先按记号清内部，最后才清第一行、第一列——内部清零会重写记号区，先清就全乱了。
  • 最后 row0 / col0 为真才把第一行/列整体置零。

最优解

时间复杂度 O(mn)，空间复杂度 O(1)
1class Solution {2    public void setZeroes(int[][] matrix) {3        int m = matrix.length, n = matrix[0].length;4        // 第一行/第一列自己是否含 0：它们要被征用当记号，得先单独记下来5        boolean row0 = false, col0 = false;6        for (int j = 0; j < n; j++) if (matrix[0][j] == 0) row0 = true;7        for (int i = 0; i < m; i++) if (matrix[i][0] == 0) col0 = true;8        // 扫内部：哪个位置是 0，就把它的第一行、第一列打上 0 记号9        for (int i = 1; i < m; i++) {10            for (int j = 1; j < n; j++) {11                if (matrix[i][j] == 0) {12                    matrix[i][0] = 0;13                    matrix[0][j] = 0;14                }15            }16        }17        // 按记号置零：先清内部，第一行/列还留着记号不能用18        for (int i = 1; i < m; i++) {19            for (int j = 1; j < n; j++) {20                if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;21            }22        }23        if (row0) for (int j = 0; j < n; j++) matrix[0][j] = 0;24        if (col0) for (int i = 0; i < m; i++) matrix[i][0] = 0;25    }26}
题目

给定一个 m x n 的矩阵，如果一个元素为 0 ，则将其所在行和列的所有元素都设为 0 。请使用 原地 算法。

示例 1：

输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]

示例 2：

输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]

提示：

  • m == matrix.length
  • n == matrix[0].length
  • 1 <= m, n <= 200
  • -231 <= matrix[i][j] <= 231 - 1

进阶：

  • 一个直观的解决方案是使用  O(mn) 的额外空间，但这并不是一个好的解决方案。
  • 一个简单的改进方案是使用 O(m + n) 的额外空间，但这仍然不是最好的解决方案。
  • 你能想出一个仅使用常量空间的解决方案吗？
