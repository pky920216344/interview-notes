并查集把同义词对全合并，合并时让字典序小的名字当根；频次按根求和，每组输出「字典序最小的名字(总频次)」。

思路

  • 同义词关系有传递性（John=Jon、Jon=Johnny ⇒ John=Johnny），自然用并查集：每对 synonyms 合并一次。
  • 合并时把字典序大的根挂到小的下面，这样根就是组内字典序最小的名字，直接当「真实名字」。
  • 只出现在同义词对里、没进公布名单的名字也登记进并查集：它们可能是组里字典序最小的，频次按 0 参与聚合。
  • 频次按根累加后输出 真实名字(总频次)；判题机不限输出顺序（实测），实现按组频次降序、并列按名字典序。

1import java.util.*;2 3class Solution {4    private final Map<String, String> parent = new HashMap<>();5 6    public String[] trulyMostPopular(String[] names, String[] synonyms) {7        Map<String, Integer> freq = new HashMap<>();8        for (String item : names) {9            int i = item.indexOf('(');10            // 同名条目若出现多次，全部累加11            freq.merge(item.substring(0, i), Integer.parseInt(item.substring(i + 1, item.length() - 1)), Integer::sum);12        }13        for (String pair : synonyms) {14            String[] p = pair.substring(1, pair.length() - 1).split(",");15            union(p[0], p[1]);16        }17        // 频次归到组根名下；根 = 组内字典序最小的名字18        Map<String, Integer> total = new HashMap<>();19        for (Map.Entry<String, Integer> e : freq.entrySet()) {20            total.merge(find(e.getKey()), e.getValue(), Integer::sum);21        }22        // 输出顺序：组频次大的在前，并列按组名字典序升23        List<Map.Entry<String, Integer>> groups = new ArrayList<>(total.entrySet());24        groups.sort((x, y) -> x.getValue().intValue() != y.getValue().intValue()25                ? y.getValue() - x.getValue() : x.getKey().compareTo(y.getKey()));26        String[] ans = new String[groups.size()];27        for (int i = 0; i < groups.size(); i++) {28            ans[i] = groups.get(i).getKey() + "(" + groups.get(i).getValue() + ")";29        }30        return ans;31    }32 33    // 合并时把字典序大的根挂到小的下面，根就是组内字典序最小的名字34    private void union(String a, String b) {35        String ra = find(a), rb = find(b);36        if (ra.equals(rb)) return;37        if (ra.compareTo(rb) < 0) parent.put(rb, ra); else parent.put(ra, rb);38    }39 40    private String find(String x) {41        // 只出现在同义词对里的名字也是组成员，首次遇到时登记42        if (!parent.containsKey(x)) parent.put(x, x);43        while (!parent.get(x).equals(x)) {44            parent.put(x, parent.get(parent.get(x)));   // 路径减半45            x = parent.get(x);46        }47        return x;48    }49}
题目

每年，政府都会公布一万个最常见的婴儿名字和它们出现的频率，也就是同名婴儿的数量。有些名字有多种拼法，例如，John 和 Jon 本质上是相同的名字，但被当成了两个名字公布出来。给定两个列表，一个是名字及对应的频率，另一个是本质相同的名字对。设计一个算法打印出每个真实名字的实际频率。注意，如果 John 和 Jon 是相同的，并且 Jon 和 Johnny 相同，则 John 与 Johnny 也相同，即它们有传递和对称性。

在结果列表中，选择 字典序最小 的名字作为真实名字。

示例：

输入：names = ["John(15)","Jon(12)","Chris(13)","Kris(4)","Christopher(19)"], synonyms = ["(Jon,John)","(John,Johnny)","(Chris,Kris)","(Chris,Christopher)"]
输出：["John(27)","Chris(36)"]

提示：

  • names.length <= 100000
