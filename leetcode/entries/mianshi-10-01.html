面试题 10.01. 合并排序的数组

  • 简单
  • 频度 2
  • 双指针
  • 数组
  • 双指针
  • 排序
  • 待提交

三个指针从右往左：i 指 A 的有效尾、j 指 B 的尾、p 指 A 的总尾，谁大谁放到 p，B 放完即结束。

思路

  • 正着合并会覆盖 A 里没处理的数；从后往前填，A 尾部的空位正好先被用掉。
  • A[i] > B[j] 时 A[p--] = A[i--]，否则 A[p--] = B[j--]；相等取哪边都行。
  • 循环条件只看 j >= 0：B 一空，A 剩下的前缀本来就在正确位置，不用再搬。

最优解

时间复杂度 O(m + n)，空间复杂度 O(1)
1class Solution {2    public void merge(int[] A, int m, int[] B, int n) {3        // 从后往前填：p 是 A 的总尾；A 尾部本来就是空位，不怕覆盖4        int i = m - 1, j = n - 1, p = m + n - 1;5        while (j >= 0) {6            // 谁大谁放到 p；i 走空了就只能填 B7            if (i >= 0 && A[i] > B[j]) A[p--] = A[i--];8            else A[p--] = B[j--];9        }10    }11}
题目

给定两个排序后的数组 A 和 B，其中 A 的末端有足够的缓冲空间容纳 B。 编写一个方法，将 B 合并入 A 并排序。

初始化 A 和 B 的元素数量分别为 m 和 n。

示例：

输入：
A = [1,2,3,0,0,0], m = 3
B = [2,5,6],       n = 3

输出： [1,2,2,3,5,6]

说明：

  • A.length == n + m
