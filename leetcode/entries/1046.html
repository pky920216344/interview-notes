1046. 最后一块石头的重量

  • 简单
  • 频度 1
  • 堆
  • 数组
  • 堆（优先队列）
  • 待提交

大顶堆反复取最重的两块：相等一起粉碎，不等把差值放回堆，直到剩不超过 1 块。

思路

  • 每回合都要「当前最重的两块」→ 大顶堆：Java 用 PriorityQueue + Collections.reverseOrder()。
  • 弹出 y ≥ x：相等则两块同时消失，什么都不放回；不等则把 y - x 放回堆。
  • 结束时堆里剩 0 块返回 0，剩 1 块返回它。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int lastStoneWeight(int[] stones) {5        PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());   // 大顶堆6        for (int s : stones) pq.add(s);7        while (pq.size() > 1) {8            int y = pq.poll(), x = pq.poll();   // 最重的两块，y ≥ x9            if (y > x) pq.add(y - x);           // 相等就一起粉碎，什么都不剩10        }11        return pq.isEmpty() ? 0 : pq.poll();12    }13}
题目

有一堆石头，每块石头的重量都是正整数。

每一回合，从中选出两块 最重的 石头，然后将它们一起粉碎。假设石头的重量分别为 x 和 y，且 x <= y。那么粉碎的可能结果如下：

  • 如果 x == y，那么两块石头都会被完全粉碎；
  • 如果 x != y，那么重量为 x 的石头将会完全粉碎，而重量为 y 的石头新重量为 y-x。

最后，最多只会剩下一块石头。返回此石头的重量。如果没有石头剩下，就返回 0。

示例：

输入：[2,7,4,1,8,1]
输出：1
解释：
先选出 7 和 8，得到 1，所以数组转换为 [2,4,1,1,1]，
再选出 2 和 4，得到 2，所以数组转换为 [2,1,1,1]，
接着是 2 和 1，得到 1，所以数组转换为 [1,1,1]，
最后选出 1 和 1，得到 0，最终数组转换为 [1]，这就是最后剩下那块石头的重量。

提示：

  • 1 <= stones.length <= 30
  • 1 <= stones[i] <= 1000
