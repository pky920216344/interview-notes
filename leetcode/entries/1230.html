1230. 抛掷硬币

  • 中等
  • 频度 1
  • 动态规划
  • 数组
  • 数学
  • 动态规划
  • 概率与统计
  • 未经力扣验证

DP 计数概率：dp[j] = 目前恰有 j 枚朝上的概率；每来一枚硬币，dp[j] = dp[j]·(1−p) + dp[j−1]·p，逆序滚动更新。

思路

  • 「恰好 target 枚朝上」是计数型概率 DP：状态就是朝上的枚数，不需要关心是哪几枚。
  • 新硬币正面概率 p：恰 j 枚朝上 = 上一轮已 j 枚、这枚反面，或上一轮 j−1 枚、这枚正面。
  • 一维滚动要逆序更新（j 从大到小），否则 dp[j−1] 已被本轮覆盖，等于同一枚硬币算了两次。

最优解

时间复杂度 O(n·target)，空间复杂度 O(target)
1class Solution {2    public double probabilityOfHeads(double[] prob, int target) {3        // dp[j]：已处理的硬币里恰有 j 枚朝上的概率4        double[] dp = new double[target + 1];5        dp[0] = 1.0;6        for (double p : prob) {7            // 逆序更新：一枚硬币只参与一轮，相当于 0/1 背包8            for (int j = target; j >= 1; j--) {9                dp[j] = dp[j] * (1 - p) + dp[j - 1] * p;10            }11            dp[0] *= 1 - p;12        }13        return dp[target];14    }15}
