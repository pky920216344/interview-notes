209. 长度最小的子数组

  • 中等
  • 频度 74
  • 滑动窗口
  • 数组
  • 二分查找
  • 前缀和
  • 滑动窗口
  • 力扣已通过

正数滑动窗口：右扩张加和，sum ≥ target 就左收缩，边缩边记最短。

思路

  • 数组全是正数：右扩张 sum 只增、左收缩只减，单调性保证左右各走一遍就够，O(n)。
  • right 每右移一格就把 nums[right] 加进 sum；sum >= target 进内层收缩。
  • 内层先 ans = min(ans, right-left+1) 记最短，再 sum -= nums[left++]，缩到 sum < target 停。
  • 从没达标过就返回 0。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int minSubArrayLen(int target, int[] nums) {3        // ans：最短长度，先放大数表示还没找到4        int ans = Integer.MAX_VALUE;5        int sum = 0;6        // 窗口 [left, right]：全是正数，右扩加和，左缩减和7        int left = 0;8        for (int right = 0; right < nums.length; right++) {9            sum += nums[right];10            // 达标就左收缩：先记最短，再移出左端11            while (sum >= target) {12                ans = Math.min(ans, right - left + 1);13                sum -= nums[left++];14            }15        }16        return ans == Integer.MAX_VALUE ? 0 : ans;17    }18}
题目

给定一个含有 n个正整数的数组和一个正整数 target 。

找出该数组中满足其总和大于等于target的长度最小的 子数组 [numsl, numsl+1, ..., numsr-1, numsr] ，并返回其长度。如果不存在符合条件的子数组，返回 0 。

示例 1：

输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是该条件下的长度最小的子数组。

示例 2：

输入：target = 4, nums = [1,4,4]
输出：1

示例 3：

输入：target = 11, nums = [1,1,1,1,1,1,1,1]
输出：0

提示：

  • 1 <= target <= 109
  • 1 <= nums.length <= 105
  • 1 <= nums[i] <= 104

进阶：

  • 如果你已经实现 O(n) 时间复杂度的解法, 请尝试设计一个 O(n log(n)) 时间复杂度的解法。
