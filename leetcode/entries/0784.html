784. 字母大小写全排列

逐位回溯：数字只有一种走法，字母分「保持原样 / 翻大小写」两支，走完恢复现场。

思路

  • 从位置 0 往后走，cs 就地改：非字母位只有一条路，字母位先走原样、再走翻转。
  • 大小写互换就是 cs[i] ^= 32：同一字母的大小写恰差二进制第 5 位。
  • 翻转分支走完必须把字符改回来（再异或一次 32），否则上层分支看到的是被改过的字符。
  • i == cs.length 时 cs 就是一个完整排列，直接收进答案。

最优解

时间复杂度 O(n · 2^字母数)，空间复杂度 O(n)（递归深度，输出不计）
1import java.util.*;2 3class Solution {4    public List<String> letterCasePermutation(String s) {5        List<String> ans = new ArrayList<>();6        dfs(s.toCharArray(), 0, ans);7        return ans;8    }9 10    // 逐位决定：数字只有一种走法，字母先走「保持原样」再走「翻大小写」11    private void dfs(char[] cs, int i, List<String> ans) {12        if (i == cs.length) {13            ans.add(new String(cs));   // 每个字母的选择都定下来了14            return;15        }16        dfs(cs, i + 1, ans);           // 分支一：这个字符保持原样17        if (Character.isLetter(cs[i])) {18            cs[i] ^= 32;               // 大小写字母恰差二进制第 5 位，异或 32 互换19            dfs(cs, i + 1, ans);       // 分支二：换成另一写法再往后走20            cs[i] ^= 32;               // 回溯：恢复现场，上一层还要用原字符21        }22    }23}
题目

给定一个字符串 s ，通过将字符串 s 中的每个字母转变大小写，我们可以获得一个新的字符串。

返回 所有可能得到的字符串集合 。以 任意顺序 返回输出。

示例 1：

输入：s = "a1b2"
输出：["a1b2", "a1B2", "A1b2", "A1B2"]

示例 2:

输入: s = "3z4"
输出: ["3z4","3Z4"]

提示:

  • 1 <= s.length <= 12
  • s 由小写英文字母、大写英文字母和数字组成
