40. 组合总和 II

  • 中等
  • 频度 55
  • 回溯
  • 深度优先搜索/递归
  • 数组
  • 回溯
  • 力扣已通过

排序 + 回溯：递归传 i+1 保证每个数只用一次，同层跳过重复值防重复组合，超出 target 就剪枝。

思路

  • 先排序：同值相邻才能「同层去重」，也才能提前 break 剪枝。
  • dfs(start, target)：target==0 记下 path；否则从 start 起逐个候选尝试。
  • 去重关键：i > start && a[i] == a[i-1] 时 continue——同一层不重复选相同的值。
  • 每个候选只能用一次：递归传 i+1（不是 i）。

1import java.util.*;2 3class Solution {4    public List<List<Integer>> combinationSum2(int[] candidates, int target) {5        Arrays.sort(candidates);   // 排序后同值相邻，才好去重和剪枝6        List<List<Integer>> ans = new ArrayList<>();7        dfs(candidates, target, 0, new ArrayList<>(), ans);8        return ans;9    }10 11    private void dfs(int[] a, int target, int start, List<Integer> path, List<List<Integer>> ans) {12        if (target == 0) {13            ans.add(new ArrayList<>(path));   // path 就是一组答案14            return;15        }16        for (int i = start; i < a.length; i++) {17            // 同一层里和前一个值相同：这个分支上一轮已经找过，跳过防重复组合18            if (i > start && a[i] == a[i - 1]) continue;19            if (a[i] > target) break;   // 已排序，后面的更大，剪枝20            path.add(a[i]);21            dfs(a, target - a[i], i + 1, path, ans);   // 每个候选只能用一次，传 i+122            path.remove(path.size() - 1);23        }24    }25}
题目

给定一个候选人编号的集合 candidates 和一个目标数 target ，找出 candidates 中所有可以使数字和为 target 的组合。

candidates 中的每个数字在每个组合中只能使用 一次 。

注意：解集不能包含重复的组合。 

示例 1:

输入: candidates = [10,1,2,7,6,1,5], target = 8,
输出:
[
[1,1,6],
[1,2,5],
[1,7],
[2,6]
]

示例 2:

输入: candidates = [2,5,2,1,2], target = 5,
输出:
[
[1,2,2],
[5]
]

提示:

  • 1 <= candidates.length <= 100
  • 1 <= candidates[i] <= 50
  • 1 <= target <= 30
