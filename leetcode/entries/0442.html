442. 数组中重复的数据

  • 中等
  • 频度 48
  • 哈希表
  • 数组
  • 哈希表
  • 排序
  • 力扣已通过

原地负号标记：值 v 把 nums[v-1] 翻成负数当「见过」；再次遇到 v 时那个位置已是负号，v 就是重复数。

思路

  • 值都在 1..n，正好映射到下标 v-1：第一次遇到 v，把 nums[v-1] 翻负，当作「v 见过」的标记。
  • 再次遇到 v：nums[v-1] 已是负数 → v 出现两次，收进答案；标记不用恢复。
  • 当前读到的数可能已被翻负，先 Math.abs(v) 还原真实值再当下标用。
  • 一趟扫描、原地完成；输出按扫描顺序，面试时说一句「顺序无关」即可。

最优解

时间复杂度 O(n)，空间复杂度 O(1)（不算输出）
1import java.util.*;2 3class Solution {4    public List<Integer> findDuplicates(int[] nums) {5        List<Integer> out = new ArrayList<>();6        // 值 v 对应下标 v-1：第一次遇到 v，把 nums[v-1] 翻成负数当「见过」标记7        for (int v : nums) {8            int x = Math.abs(v);               // 该位置可能已被翻负，先还原真实值9            if (nums[x - 1] < 0) out.add(x);   // 又遇到 v：标记已在，v 就是重复数10            else nums[x - 1] = -nums[x - 1];11        }12        return out;13    }14}
题目

给你一个长度为 n 的整数数组 nums ，其中 nums 的所有整数都在范围 [1, n] 内，且每个整数出现 最多两次 。请你找出所有出现 两次 的整数，并以数组形式返回。

你必须设计并实现一个时间复杂度为 O(n) 且仅使用常量额外空间（不包括存储输出所需的空间）的算法解决此问题。

示例 1：

输入：nums = [4,3,2,7,8,2,3,1]
输出：[2,3]

示例 2：

输入：nums = [1,1,2]
输出：[1]

示例 3：

输入：nums = [1]
输出：[]

提示：

  • n == nums.length
  • 1 <= n <= 105
  • 1 <= nums[i] <= n
  • nums 中的每个元素出现 一次 或 两次
