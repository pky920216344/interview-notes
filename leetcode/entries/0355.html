每个用户一条按时间从新到旧的推文链表加关注集合；getNewsFeed 把各链表头多路归并，取最新的 10 条。

思路

  • 推文链表新插表头：全局时钟 time++ 让不同用户的推文也可比。
  • getNewsFeed：来源 = 关注的人 + 自己（推送永远含自己的推文）；收齐各链表头，每轮线性挑时间最新的头，取满 10 条为止。
  • 挑中的头沿 next 走，链表空了从候选里去掉；来源少、只取 10 条，线性挑头就够。
  • follow/unfollow 只动 HashSet，与推文无关。

图解

最优解

时间复杂度 post O(1)；feed O(来源数 × 10)，空间复杂度 O(推文总数 + 关注关系数)
1import java.util.*;2 3class Twitter {4    private int time;   // 全局时钟：每次发推 +1，越大越新5 6    // 推文结点：next 指向同一用户的上一条（更旧的）推文7    private static class Node {8        int id, time;9        Node next;10 11        Node(int id, int time) { this.id = id; this.time = time; }12    }13 14    // 用户 -> 自己的推文链表（表头最新）15    private final Map<Integer, Node> tweets = new HashMap<>();16    // 用户 -> 关注的人17    private final Map<Integer, Set<Integer>> follows = new HashMap<>();18 19    public Twitter() { }20 21    public void postTweet(int userId, int tweetId) {22        Node node = new Node(tweetId, time++);23        // 新推文插到表头24        node.next = tweets.get(userId);25        tweets.put(userId, node);26    }27 28    public List<Integer> getNewsFeed(int userId) {29        // 来源 = 关注的人 + 自己；收齐每人的链表头30        Set<Integer> src = new HashSet<>(follows.getOrDefault(userId, new HashSet<>()));31        src.add(userId);32        List<Node> heads = new ArrayList<>();33        for (int u : src) {34            Node h = tweets.get(u);35            if (h != null) heads.add(h);36        }37        List<Integer> out = new ArrayList<>();38        // 多路归并取前 10：每轮线性挑时间最新的链表头39        while (out.size() < 10 && !heads.isEmpty()) {40            int k = 0;41            for (int i = 1; i < heads.size(); i++) if (heads.get(i).time > heads.get(k).time) k = i;42            Node best = heads.get(k);43            out.add(best.id);44            if (best.next != null) heads.set(k, best.next);45            else heads.remove(k);46        }47        return out;48    }49 50    public void follow(int followerId, int followeeId) {51        follows.computeIfAbsent(followerId, x -> new HashSet<>()).add(followeeId);52    }53 54    public void unfollow(int followerId, int followeeId) {55        Set<Integer> s = follows.get(followerId);56        if (s != null) s.remove(followeeId);57    }58}
题目

设计一个简化版的推特(Twitter)，可以让用户实现发送推文，关注/取消关注其他用户，能够看见关注人（包括自己）的最近 10 条推文。

实现 Twitter 类：

  • Twitter() 初始化简易版推特对象
  • void postTweet(int userId, int tweetId) 根据给定的 tweetId 和 userId 创建一条新推文。每次调用此函数都会使用一个不同的 tweetId 。
  • List<Integer> getNewsFeed(int userId) 检索当前用户新闻推送中最近  10 条推文的 ID 。新闻推送中的每一项都必须是由用户关注的人或者是用户自己发布的推文。推文必须 按照时间顺序由最近到最远排序 。
  • void follow(int followerId, int followeeId) ID 为 followerId 的用户开始关注 ID 为 followeeId 的用户。
  • void unfollow(int followerId, int followeeId) ID 为 followerId 的用户不再关注 ID 为 followeeId 的用户。

示例：

输入
["Twitter", "postTweet", "getNewsFeed", "follow", "postTweet", "getNewsFeed", "unfollow", "getNewsFeed"]
[[], [1, 5], [1], [1, 2], [2, 6], [1], [1, 2], [1]]
输出
[null, null, [5], null, null, [6, 5], null, [5]]

解释
Twitter twitter = new Twitter();
twitter.postTweet(1, 5); // 用户 1 发送了一条新推文 (用户 id = 1, 推文 id = 5)
twitter.getNewsFeed(1);  // 用户 1 的获取推文应当返回一个列表，其中包含一个 id 为 5 的推文
twitter.follow(1, 2);    // 用户 1 关注了用户 2
twitter.postTweet(2, 6); // 用户 2 发送了一个新推文 (推文 id = 6)
twitter.getNewsFeed(1);  // 用户 1 的获取推文应当返回一个列表，其中包含两个推文，id 分别为 -> [6, 5] 。推文 id 6 应当在推文 id 5 之前，因为它是在 5 之后发送的
twitter.unfollow(1, 2);  // 用户 1 取消关注了用户 2
twitter.getNewsFeed(1);  // 用户 1 获取推文应当返回一个列表，其中包含一个 id 为 5 的推文。因为用户 1 已经不再关注用户 2

提示：

  • 1 <= userId, followerId, followeeId <= 500
  • 0 <= tweetId <= 104
  • 所有推特的 ID 都互不相同
  • postTweet、getNewsFeed、follow 和 unfollow 方法最多调用 3 * 104 次
  • 用户不能关注自己
