730. 统计不同回文子序列

  • 困难
  • 频度 1
  • 动态规划
  • 字符串
  • 动态规划
  • 待提交

按「首尾字符」分类的区间 DP：dp[c][i][j] = 区间内以 c 开头结尾的回文子序列数，用首末出现位置递推，答案为四类之和。

思路

  • 每个回文按首尾字符归类：dp[c][i][j] 只数「两头都是 c」的，答案 = 四类相加，天然不重不漏。
  • 区间里找 c 的首次 L、末次 R（nxt/prv 预处理）：L==R 只有 c 一种；L<R 时 = c、cc 两种 + 给中间 [L+1..R−1] 的每种回文套 c…c 外壳。
  • 中间每种回文 X 只会被外壳包一次，且不同 X 生成不同回文——这正是「不同」计数的关键。
  • 递归记忆化实现，逐层 % 10⁹+7；求和用 long（四类相加可超 int）。

1import java.util.*;2 3class Solution {4    private static final int MOD = 1_000_000_007;5    private int[][][] memo;   // memo[c][i][j]：s[i..j] 里以 c 开头且以 c 结尾的回文子序列个数6    private int[][] nxt, prv; // nxt[i][c]：i 起第一个 c（没有为 n）；prv[j][c]：j 止最后一个 c（没有为 -1）7    private String s;8 9    public int countPalindromicSubsequences(String s) {10        this.s = s;11        int n = s.length();12        memo = new int[4][n][n];13        for (int c = 0; c < 4; c++)14            for (int i = 0; i < n; i++)15                Arrays.fill(memo[c][i], -1);16        nxt = new int[n + 1][4];17        prv = new int[n + 1][4];18        for (int c = 0; c < 4; c++) {19            nxt[n][c] = n;20            for (int i = n - 1; i >= 0; i--) nxt[i][c] = s.charAt(i) - 'a' == c ? i : nxt[i + 1][c];21            prv[0][c] = s.charAt(0) - 'a' == c ? 0 : -1;22            for (int j = 1; j < n; j++) prv[j][c] = s.charAt(j) - 'a' == c ? j : prv[j - 1][c];23        }24        long ans = 0;25        for (int c = 0; c < 4; c++) ans += dp(c, 0, n - 1);   // 四种字符各自负责「首尾同字母」的回文26        return (int) (ans % MOD);27    }28 29    private int dp(int c, int i, int j) {30        if (i > j) return 0;31        if (memo[c][i][j] != -1) return memo[c][i][j];32        int L = nxt[i][c], R = prv[j][c];33        int ans;34        if (L > j) ans = 0;           // 区间里没有 c35        else if (L == R) ans = 1;     // 只有一个 c：只有「c」自己36        else {37            // 「c」「cc」两种，再给中间每种回文 X 套上 c...c 外壳38            long sum = 2;39            for (int d = 0; d < 4; d++) sum += dp(d, L + 1, R - 1);40            ans = (int) (sum % MOD);41        }42        memo[c][i][j] = ans;43        return ans;44    }45}
题目

给你一个字符串 s ，返回 s 中不同的非空回文子序列个数 。由于答案可能很大，请返回对 109 + 7 取余 的结果。

字符串的子序列可以经由字符串删除 0 个或多个字符获得。

如果一个序列与它反转后的序列一致，那么它是回文序列。

如果存在某个 i , 满足 ai != bi ，则两个序列 a1, a2, ... 和 b1, b2, ... 不同。

示例 1：

输入：s = 'bccb'
输出：6
解释：6 个不同的非空回文子字符序列分别为：'b', 'c', 'bb', 'cc', 'bcb', 'bccb'。
注意：'bcb' 虽然出现两次但仅计数一次。

示例 2：

输入：s = 'abcdabcdabcdabcdabcdabcdabcdabcddcbadcbadcbadcbadcbadcbadcbadcba'
输出：104860361
解释：共有 3104860382 个不同的非空回文子序列，104860361 是对 109 + 7 取余后的值。

提示：

  • 1 <= s.length <= 1000
  • s[i] 仅包含 'a', 'b', 'c' 或 'd'
