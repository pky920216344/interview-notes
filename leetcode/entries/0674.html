674. 最长连续递增序列

  • 简单
  • 频度 17
  • 模拟
  • 数组
  • 待提交

一遍扫：当前数比前一个大就把当前长度加 1，否则重置为 1，顺手更新最大值。

思路

  • len 表示「以 i 结尾的连续递增长度」：nums[i] > nums[i-1] 就 len++，否则重置 len = 1（等于也算断，要严格大于）。
  • 每步用 len 更新答案；数组只有一个元素时答案是 1，循环不用跑。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int findLengthOfLCIS(int[] nums) {3        int ans = 1;    // 至少是单个元素4        int len = 1;    // 以当前元素结尾的连续递增长度5        for (int i = 1; i < nums.length; i++) {6            if (nums[i] > nums[i - 1]) len++;   // 比前一个大：延长7            else len = 1;                        // 断了：从 i 重新开始数8            ans = Math.max(ans, len);9        }10        return ans;11    }12}
题目

给定一个未经排序的整数数组，找到最长且 连续递增的子序列，并返回该序列的长度。

连续递增的子序列 可以由两个下标 l 和 r（l < r）确定，如果对于每个 l <= i < r，都有 nums[i] < nums[i + 1] ，那么子序列 [nums[l], nums[l + 1], ..., nums[r - 1], nums[r]] 就是连续递增子序列。

示例 1：

输入：nums = [1,3,5,4,7]
输出：3
解释：最长连续递增序列是 [1,3,5], 长度为3。
尽管 [1,3,5,7] 也是升序的子序列, 但它不是连续的，因为 5 和 7 在原数组里被 4 隔开。

示例 2：

输入：nums = [2,2,2,2,2]
输出：1
解释：最长连续递增序列是 [2], 长度为1。

提示：

  • 1 <= nums.length <= 104
  • -109 <= nums[i] <= 109
