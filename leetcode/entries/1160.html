26 格计数：先数 chars 的字母当库存，每个词逐字母「要货」，任一字母要的次数超过库存就拼不出。

思路

  • 先把 chars 清点成 26 格库存表 cnt[c]。
  • 每个词单独开一张 need 表逐字母累加，一旦 need[c] > cnt[c] 立即判负跳出——重复字母不够用是唯一的坑。
  • 拼得出的词把词长累加进答案。

图解

最优解

时间复杂度 O(len(words) + len(chars))，空间复杂度 O(26)
1class Solution {2    public int countCharacters(String[] words, String chars) {3        // 库存：chars 里每个字母各有几个4        int[] cnt = new int[26];5        for (char c : chars.toCharArray()) cnt[c - 'a']++;6        int ans = 0;7        for (String w : words) {8            // need：这个词已用掉的字母数，任一字母超过库存就拼不出来9            int[] need = new int[26];10            boolean ok = true;11            for (char c : w.toCharArray()) {12                if (++need[c - 'a'] > cnt[c - 'a']) { ok = false; break; }13            }14            if (ok) ans += w.length();15        }16        return ans;17    }18}
题目

给定一个字符串数组 words 和一个字符串 chars。

如果字符串可以由 chars 中的字符组成（每个字符在 每个 words 中只能使用一次），则认为它是好的。

返回 words 中所有好的字符串的长度之和。

示例 1：

输入：words = ["cat","bt","hat","tree"], chars = "atach"
输出：6
解释： 
可以形成字符串 "cat" 和 "hat"，所以答案是 3 + 3 = 6。

示例 2：

输入：words = ["hello","world","leetcode"], chars = "welldonehoneyr"
输出：10
解释：
可以形成字符串 "hello" 和 "world"，所以答案是 5 + 5 = 10。

提示：

  • 1 <= words.length <= 1000
  • 1 <= words[i].length, chars.length <= 100
  • words[i] 和 chars 中都仅包含小写英文字母
