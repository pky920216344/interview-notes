1490. 克隆 N 叉树

  • 中等
  • 频度 3
  • 深度优先搜索/递归
  • 树
  • 深度优先搜索
  • 广度优先搜索
  • 哈希表
  • 未经力扣验证

递归自顶向下：先给当前结点造一个带空孩子表的新壳，再把每个孩子递归克隆后挂上去。

思路

  • 克隆整棵树 = 克隆根 + 克隆每棵子树：new Node(root.val, 新列表) 后，对每个孩子 copy.children.add(cloneTree(child))。
  • 空树返回 null，是递归出口。
  • 新壳必须自带 children 列表（用两参构造器 new Node(val, new ArrayList<>())），单参构造器的 children 是 null，往上面 add 会抛异常。

最优解

时间复杂度 O(n)，空间复杂度 O(n)（新树）+ O(树高)（递归栈）
