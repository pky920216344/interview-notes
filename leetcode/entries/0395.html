395. 至少有 K 个重复字符的最长子串

  • 中等
  • 频度 28

  • 哈希表
  • 字符串

  • 滑动窗口
  • 力扣已通过

分治：统计区间频次，只要有一个字符出现 < k 次，它就不能出现在任何合法子串里，拿它当分割点递归两侧。

思路

  • 每层先数 [l, r) 里 26 个字母的频次。
  • 从左扫到第一个出现次数 < k 的字符：任何包含它的子串都不合法，答案只可能在它两侧，递归 [l, i) 和 [i+1, r) 取最大。
  • 扫完没找到坏字符：整段所有字符都 ≥ k，r - l 直接就是答案。
  • 每层递归至少丢掉一个字符，层数 ≤ 26，每层总共扫 O(n)。

最优解

时间复杂度 O(26n)，空间复杂度 O(26)（递归栈 O(26) 层）
1class Solution {2    public int longestSubstring(String s, int k) {3        return dfs(s, 0, s.length(), k);4    }5 6    // 区间 [l, r) 里所有字符都出现 ≥ k 次：整段就是答案；7    // 否则挑一个出现不足 k 次的字符当分割点——合法子串不可能包含它，答案只在两侧8    private int dfs(String s, int l, int r, int k) {9        int[] cnt = new int[26];10        for (int i = l; i < r; i++) cnt[s.charAt(i) - 'a']++;11        for (int i = l; i < r; i++) {12            if (cnt[s.charAt(i) - 'a'] < k) {13                return Math.max(dfs(s, l, i, k), dfs(s, i + 1, r, k));14            }15        }16        return r - l;17    }18}
题目

给你一个字符串 s 和一个整数 k ，请你找出 s 中的最长子串， 要求该子串中的每一字符出现次数都不少于 k 。返回这一子串的长度。

如果不存在这样的子字符串，则返回 0。

示例 1：

输入：s = "aaabb", k = 3
输出：3
解释：最长子串为 "aaa" ，其中 'a' 重复了 3 次。

示例 2：

输入：s = "ababbc", k = 2
输出：5
解释：最长子串为 "ababb" ，其中 'a' 重复了 2 次， 'b' 重复了 3 次。

提示：

  • 1 <= s.length <= 104
  • s 仅由小写英文字母组成
  • 1 <= k <= 105
