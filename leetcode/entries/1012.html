1012. 至少有 1 位重复的数字

  • 困难
  • 频度 1
  • 数学
  • 数学
  • 动态规划
  • 待提交

正难则反：数 [1,n] 内「各位互不相同」的个数 ans，答案 = n − ans；按「比 n 短的位数 + 贴着 n 的前缀」计数。

思路

  • 先数位数比 n 短的：L 位无重复 = 9×9×8×…（首位 1~9，后面从没用过的数字里排列）。
  • 再贴着 n 的前缀走：第 i 位填比 n[i] 小的没用过的数字，后缀 len−1−i 位自由排列（乘 9×8×…），逐位累加。
  • 若贴前缀时某位数字已被用过（n 的前缀开始重复），后面同前缀的数全有重复，直接停。
  • n 本身若无重复再 +1；答案 = n − ans（无重复的补集就是有重复的）。

最优解

时间复杂度 O(len²)（len ≤ 10），空间复杂度 O(1)
1class Solution {2    public int numDupDigitsAtMostN(int n) {3        char[] cs = Integer.toString(n).toCharArray();4        int len = cs.length, ans = 0;   // ans：[1,n] 里各位互不相同的数的个数5        // 位数比 n 短的随便排：L 位无重复 = 9×9×8×…（首位不能 0）6        for (int L = 1; L < len; L++) {7            int ways = 9;8            for (int j = 1; j < L; j++) ways *= 10 - j;9            ans += ways;10        }11        // 和 n 同长：贴着 n 的前缀走，每位填比 n 当前位小的、没用过的数字12        boolean[] used = new boolean[10];13        boolean same = true;   // n 自己是否各位无重复14        for (int i = 0; i < len; i++) {15            int d = cs[i] - '0';16            for (int x = i == 0 ? 1 : 0; x < d; x++) {17                if (used[x]) continue;18                int ways = 1;19                for (int j = i + 1; j < len; j++) ways *= 10 - j;20                ans += ways;   // 前缀同 n、当前位更小，后面的位随便排21            }22            if (used[d]) { same = false; break; }   // n 的前缀从这儿开始重复，再贴没有无重复的数23            used[d] = true;24        }25        if (same) ans++;   // n 本身也无重复26        return n - ans;    // 无重复的补集 = 至少 1 位重复27    }28}
题目

给定正整数 n，返回在 [1, n] 范围内具有 至少 1 位 重复数字的正整数的个数。

示例 1：

输入：n = 20
输出：1
解释：具有至少 1 位重复数字的正数（<= 20）只有 11 。

示例 2：

输入：n = 100
输出：10
解释：具有至少 1 位重复数字的正数（<= 100）有 11，22，33，44，55，66，77，88，99 和 100 。

示例 3：

输入：n = 1000
输出：262

提示：

  • 1 <= n <= 109
