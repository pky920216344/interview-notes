1058. 最小化舍入误差以满足目标

  • 中等
  • 频度 1
  • 贪心
  • 贪心
  • 数组
  • 数学
  • 字符串
  • 排序
  • 未经力扣验证

全部先向下取整；缺多少（need）就挑小数部分最大的那么多个向上取整——向上的浪费 1−f 最小。

思路

  • 每个价格拆成整数部分 + 三位小数 f（千分之几）；先全向下取整，need = target − floor和。
  • 可行性：need < 0（全向下都超了）或 need > 小数非零的个数 → -1。
  • 误差只来自小数：向下付 f，向上付 1−f；必须恰好向上 need 个 → 按 f 从大到小挑，总误差用整数「毫」算，避免浮点误差。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public String minimizeError(List<String> prices, int target) {5        int n = prices.size();6        int[] frac = new int[n];   // 每个价格的小数部分（千分之几）7        int need = target, slots = 0, base = 0;8        for (int i = 0; i < n; i++) {9            String s = prices.get(i);10            int dot = s.indexOf('.');11            int f = Integer.parseInt(s.substring(dot + 1));   // 题面保证恰好 3 位小数12            need -= Integer.parseInt(s.substring(0, dot));    // 先全部向下取整13            frac[i] = f;14            if (f > 0) slots++;15            base += f;16        }17        // 全向下仍超出 target，或最多能补的高度不够 → 无解18        if (need < 0 || need > slots) return "-1";19        // 必须恰好把 need 个向上取整：挑小数最大的（向上浪费 1−f 最小）20        Arrays.sort(frac);21        long milli = base;22        for (int i = n - need; i < n; i++) milli += 1000 - 2 * frac[i];23        return String.format("%d.%03d", milli / 1000, milli % 1000);24    }25}
