155. 最小栈

  • 简单
  • 频度 99
  • 栈
  • 设计
  • 栈
  • 设计
  • 力扣已通过

辅助栈与主栈同步：每次 push 把 min(x, 辅助栈顶) 一起压进去，getMin 直接看辅助栈顶。

思路

  • 两个栈一起进出：stack 存所有元素，mins 每层存「到这一层为止的最小值」。
  • push(x) 压入 mins.isEmpty() ? x : min(x, mins.peek())；更小值跟着下探，永不丢失。
  • pop() 两个栈同步弹，上一层最小自动恢复，不用重新算。
  • getMin() 就是 mins.peek()，所有操作都是 O(1)。

题目

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

  • MinStack() 初始化堆栈对象。
  • void push(int value) 将元素 value 推入堆栈。
  • void pop() 删除堆栈顶部的元素。
  • int top() 获取堆栈顶部的元素。
  • int getMin() 获取堆栈中的最小元素。

示例 1:

输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.

提示：

  • -231 <= val <= 231 - 1
  • pop、top 和 getMin 操作总是在 非空栈 上调用
  • push, pop, top, and getMin最多被调用 3 * 104 次
