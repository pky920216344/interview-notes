反中序（右→根→左）遍历 BST，累加器 sum 一路加上访问到的值；赋值时 sum 正是 ≥ 当前值的所有值之和。

思路

  • BST 中序是有序的；反中序（先右后左）就是从大到小访问，走过的值恰好都 ≥ 当前结点。
  • 成员变量 sum 当累加器：先递归右子树，再 sum += root.val，然后直接写回 root.val。
  • 最后走左子树，把包含当前结点的新 sum 传下去；整棵树结构不变，只改值。

时间复杂度 O(n)，空间复杂度 O(h)
1class Solution {2    private int sum = 0;   // 反中序已访问结点的值之和，全是 ≥ 当前结点的值3 4    public TreeNode bstToGst(TreeNode root) {5        if (root != null) {6            bstToGst(root.right);   // 先走右子树：那些值都更大，先进 sum7            sum += root.val;8            root.val = sum;         // 此刻 sum 正是 ≥ 它的所有值之和9            bstToGst(root.left);10        }11        return root;12    }13}
题目

给定一个二叉搜索树 root (BST)，请将它的每个节点的值替换成树中大于或者等于该节点值的所有节点值之和。

提醒一下， 二叉搜索树 满足下列约束条件：

  • 节点的左子树仅包含键 小于 节点键的节点。
  • 节点的右子树仅包含键 大于 节点键的节点。
  • 左右子树也必须是二叉搜索树。

示例 1：

输入：[4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]
输出：[30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]

示例 2：

输入：root = [0,null,1]
输出：[1,null,1]

提示：

  • 树中的节点数在 [1, 100] 范围内。
  • 0 <= Node.val <= 100
  • 树中的所有值均 不重复 。

注意：该题目与 538: https://leetcode.cn/problems/convert-bst-to-greater-tree/  相同
