856. 括号的分数

  • 中等

  • 栈

  • 待提交

栈存每层括号已累计的分数：读到 ( 压 0 开新层；读到 ) 弹出本层，空层记 1、非空层翻倍，加给外层。

思路

  • ( 进一层：压入 0，这一层的分数从零开始累计。
  • ) 收账：弹出本层分数 v；v=0 说明是 ()，记 1 分；否则是 (A)，翻倍成 2v。
  • 收完的分数加到新的栈顶（外面一层）上；扫完栈里剩下的就是总分。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int scoreOfParentheses(String s) {5        // 栈里存每层括号已累计的分数；栈底垫个 0 存总和6        Deque<Integer> stack = new ArrayDeque<>();7        stack.push(0);8        for (char c : s.toCharArray()) {9            if (c == '(') {10                stack.push(0);                // 进一层：这层的分数从 0 累计11            } else {12                int v = stack.pop();          // 本层括号里累计的分数13                v = v == 0 ? 1 : 2 * v;       // () 得 1 分；(A) 得 2A 分14                stack.push(stack.pop() + v);  // 累加到外面一层15            }16        }17        return stack.peek();18    }19}
题目

给定一个平衡括号字符串 S，按下述规则计算该字符串的分数：

  • () 得 1 分。
  • AB 得 A + B 分，其中 A 和 B 是平衡括号字符串。
  • (A) 得 2 * A 分，其中 A 是平衡括号字符串。

示例 1：

输入： "()"
输出： 1

示例 2：

输入： "(())"
输出： 2

示例 3：

输入： "()()"
输出： 2

示例 4：

输入： "(()(()))"
输出： 6

提示：

  1. S 是平衡括号字符串，且只含有 ( 和 ) 。
  2. 2 <= S.length <= 50
