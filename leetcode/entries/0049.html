49. 字母异位词分组

异位词的 26 字母计数串相同，拿它当哈希键把词分进同一组，省掉每个词排序的 O(k log k)。

思路

  • 两个词是异位词 ⇔ 每个字母出现次数都相同 → 26 位计数串相同的词进同一组。
  • 计数只要 O(k)，排序键要 O(k log k)；计数之间加分隔符，防止 1,0 和 10 拼接出同一个键。
  • HashMap<键, 组>：键没见过就开新组，见过就把词追加进已有组；最后把所有组收进 List 返回。

图解

最优解

时间复杂度 O(n·k)，空间复杂度 O(n·k)
1import java.util.*;2 3class Solution {4    public List<List<String>> groupAnagrams(String[] strs) {5        // 键：26 个字母的出现次数拼成计数串，异位词的键相同（省掉每个词的排序）6        Map<String, List<String>> groups = new HashMap<>();7        for (String s : strs) {8            int[] cnt = new int[26];9            for (int i = 0; i < s.length(); i++) cnt[s.charAt(i) - 'a']++;10            StringBuilder key = new StringBuilder();11            for (int c : cnt) key.append(c).append(',');12            String k = key.toString();13            List<String> list = groups.get(k);14            if (list == null) groups.put(k, list = new ArrayList<>());15            list.add(s);16        }17        return new ArrayList<>(groups.values());18    }19}
题目

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

示例 1:

输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

输出: [["bat"],["nat","tan"],["ate","eat","tea"]]

解释：

  • 在 strs 中没有字符串可以通过重新排列来形成 "bat"。
  • 字符串 "nat" 和 "tan" 是字母异位词，因为它们可以重新排列以形成彼此。
  • 字符串 "ate" ，"eat" 和 "tea" 是字母异位词，因为它们可以重新排列以形成彼此。

示例 2:

输入: strs = [""]

输出: [[""]]

示例 3:

输入: strs = ["a"]

输出: [["a"]]

提示：

  • 1 <= strs.length <= 104
  • 0 <= strs[i].length <= 100
  • strs[i] 仅包含小写字母
