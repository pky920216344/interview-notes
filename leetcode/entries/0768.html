768. 最多能完成排序的块 II

单调栈存「每个已定块的最大值」：新数小于栈顶就把那些块并进来取最大，最后栈深即块数。

思路

  • 块与块之间必须「左边整块 ≤ 右边整块」，所以从左到右块最大值严格递增——栈里就存这些最大值。
  • 新数 x ≥ 栈顶：自己开一块（相等也算，[4][4] 能分开）。
  • x 更小：所有最大值 > x 的块与 x 必须同块，弹出合并，新块最大值 = max(x, 弹出值)，回栈。
  • 答案 = 最终栈深。重复值不会被迫合并，所以比 768.I 版本多靠「值比较」而不是下标。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int maxChunksToSorted(int[] arr) {3        // 栈里存每个「已定块」的最大值，从栈底到栈顶严格递增4        int[] stack = new int[arr.length];5        int top = 0;6        for (int x : arr) {7            // 不小于栈顶（当前最右块的最大值）：x 自己能开一块8            if (top == 0 || x >= stack[top - 1]) {9                stack[top++] = x;10                continue;11            }12            // x 更小：把所有最大值比 x 大的块都并进来，合并块的最大值记下来13            int mx = x;14            while (top > 0 && stack[top - 1] > x) mx = Math.max(mx, stack[--top]);15            stack[top++] = mx;16        }17        // 栈里剩几个块最大值，就最多能分几块18        return top;19    }20}
题目

给你一个整数数组 arr 。

将 arr 分割成若干 块 ，并将这些块分别进行排序。之后再连接起来，使得连接的结果和按升序排序后的原数组相同。

返回能将数组分成的最多块数？

 

示例 1：

输入：arr = [5,4,3,2,1]
输出：1
解释：
将数组分成2块或者更多块，都无法得到所需的结果。 
例如，分成 [5, 4], [3, 2, 1] 的结果是 [4, 5, 1, 2, 3]，这不是有序的数组。

示例 2：

输入：arr = [2,1,3,4,4]
输出：4
解释：
可以把它分成两块，例如 [2, 1], [3, 4, 4]。 
然而，分成 [2, 1], [3], [4], [4] 可以得到最多的块数。

提示：

  • 1 <= arr.length <= 2000
  • 0 <= arr[i] <= 108
