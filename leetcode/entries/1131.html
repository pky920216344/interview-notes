1131. 绝对值表达式的最大值

  • 中等
  • 频度 1
  • 数学

  • 数学
  • 待提交

|a|+|b|+|c| 等于 8 种符号组合中最大的带符号和；每种组合的式子拆成 g[i]−g[j]，一遍扫出最大减最小。

思路

  • 关键转化：|x| = max(x, −x)，所以三项绝对值之和 = 枚举 8 种符号组合取最大。
  • 固定符号 (s1, s2, s3) 后，s1·arr1[i] + s2·arr2[i] + s3·i 只跟单个下标有关，记为 g[i]；表达式值 = g[i] − g[j]。
  • 每种组合一遍扫出 g 的最大值和最小值，差值就是该组合的最大答案，8 个组合取最大。
  • 8 个组合里正负成对等价，但都枚举也就 8 遍线性扫，写起来最不容易错。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxAbsValExpr(int[] arr1, int[] arr2) {3        int n = arr1.length, ans = 0;4        // |a|+|b|+|c| = 8 种符号组合里最大的那个带符号和；每种组合拆成 g[i] − g[j]5        for (int s1 = -1; s1 <= 1; s1 += 2) {6            for (int s2 = -1; s2 <= 1; s2 += 2) {7                for (int s3 = -1; s3 <= 1; s3 += 2) {8                    int mx = Integer.MIN_VALUE, mn = Integer.MAX_VALUE;9                    for (int i = 0; i < n; i++) {10                        int g = s1 * arr1[i] + s2 * arr2[i] + s3 * i;11                        mx = Math.max(mx, g);12                        mn = Math.min(mn, g);13                    }14                    ans = Math.max(ans, mx - mn);15                }16            }17        }18        return ans;19    }20}
题目

给你两个长度相等的整数数组，返回下面表达式的最大值：

|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|

其中下标 i，j 满足 0 <= i, j < arr1.length。

示例 1：

输入：arr1 = [1,2,3,4], arr2 = [-1,4,5,6]
输出：13

示例 2：

输入：arr1 = [1,-2,-5,0,10], arr2 = [0,-2,-1,-7,-4]
输出：20

提示：

  • 2 <= arr1.length == arr2.length <= 40000
  • -10^6 <= arr1[i], arr2[i] <= 10^6
