447. 回旋镖的数量

  • 简单
  • 频度 1
  • 哈希表
  • 数组
  • 哈希表
  • 数学
  • 待提交

逐个点当拐点 i：哈希表统计其余点到 i 的距离平方，同一距离有 c 个点就贡献 c×(c−1) 个回旋镖。

思路

  • 固定拐点 i 后，回旋镖形如 (j, i, k)：只要 j、k 到 i 等距即可，j、k 换顺序算两种 → c 个点贡献 c×(c−1)。
  • 距离只算平方再比较，不开方就没有浮点误差。
  • 用下标 j != i 跳过拐点自身，不能比数组内容（点可能值相同）。

最优解

时间复杂度 O(n²)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int numberOfBoomerangs(int[][] points) {5        int n = points.length, ans = 0;6        // 逐个点当拐点 i：到 i 距离相等的点有 c 个，选有序对 (j,k) 共 c×(c−1) 种7        for (int i = 0; i < n; i++) {8            Map<Integer, Integer> cnt = new HashMap<>();9            for (int j = 0; j < n; j++) {10                if (j == i) continue;11                int dx = points[i][0] - points[j][0], dy = points[i][1] - points[j][1];12                // 距离用平方比较，不开方就没有浮点误差13                cnt.merge(dx * dx + dy * dy, 1, Integer::sum);14            }15            for (int c : cnt.values()) ans += c * (c - 1);16        }17        return ans;18    }19}
题目

给定平面上 n 对 互不相同 的点 points ，其中 points[i] = [xi, yi] 。回旋镖 是由点 (i, j, k) 表示的元组 ，其中 i 和 j 之间的欧式距离和 i 和 k 之间的欧式距离相等（需要考虑元组的顺序）。

返回平面上所有回旋镖的数量。

 

示例 1：

输入：points = [[0,0],[1,0],[2,0]]
输出：2
解释：两个回旋镖为 [[1,0],[0,0],[2,0]] 和 [[1,0],[2,0],[0,0]]

示例 2：

输入：points = [[1,1],[2,2],[3,3]]
输出：2

示例 3：

输入：points = [[1,1]]
输出：0

提示：

  • n == points.length
  • 1 <= n <= 500
  • points[i].length == 2
  • -104 <= xi, yi <= 104
  • 所有点都 互不相同
