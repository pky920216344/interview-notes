双哈希（val→次数、频次→按新旧摞的 val 组）加 maxFreq：push 进对应频次组，pop 取最大频次组的栈顶。

思路

  • freq[val] 是出现次数；每次 push 往 groups[新次数] 的栈顶摞一个条目，maxFreq 取最大。
  • pop 取 groups[maxFreq] 的栈顶 = 最大频次里最近压入的；然后 val 次数减 1。
  • 关键不变式：val 更早压入时的低频条目一直留在原组里，弹出后不用重新插回低频组。
  • 组空了才 maxFreq--；更低频的组必然非空（到过频次 f 的 val 在 1..f 各组都有条目）。

时间复杂度 每步 O(1)，空间复杂度 O(压入总次数)
1import java.util.*;2 3class FreqStack {4    private final Map<Integer, Integer> freq = new HashMap<>();           // val → 当前出现次数5    private final Map<Integer, Deque<Integer>> groups = new HashMap<>();  // 频次 → 该频次的 val，按新旧摞放6    private int maxFreq = 0;7 8    public FreqStack() { }9 10    public void push(int val) {11        int f = freq.merge(val, 1, Integer::sum);   // 次数也是 val 的「辈分」12        groups.computeIfAbsent(f, k -> new ArrayDeque<>()).push(val);13        maxFreq = Math.max(maxFreq, f);14    }15 16    public int pop() {17        Deque<Integer> group = groups.get(maxFreq);18        int val = group.pop();   // 最大频次组里最近压入的那个19        freq.merge(val, -1, Integer::sum);20        if (group.isEmpty()) groups.remove(maxFreq--);   // 组空了最大频次才降级21        return val;22    }23}
题目

设计一个类似堆栈的数据结构，将元素推入堆栈，并从堆栈中弹出出现频率最高的元素。

实现 FreqStack 类:

  • FreqStack() 构造一个空的堆栈。
  • void push(int val) 将一个整数 val 压入栈顶。
  • int pop() 删除并返回堆栈中出现频率最高的元素。
    • 如果出现频率最高的元素不只一个，则移除并返回最接近栈顶的元素。

示例 1：

输入：
["FreqStack","push","push","push","push","push","push","pop","pop","pop","pop"],
[[],[5],[7],[5],[7],[4],[5],[],[],[],[]]
输出：[null,null,null,null,null,null,null,5,7,5,4]
解释：
FreqStack = new FreqStack();
freqStack.push (5);//堆栈为 [5]
freqStack.push (7);//堆栈是 [5,7]
freqStack.push (5);//堆栈是 [5,7,5]
freqStack.push (7);//堆栈是 [5,7,5,7]
freqStack.push (4);//堆栈是 [5,7,5,7,4]
freqStack.push (5);//堆栈是 [5,7,5,7,4,5]
freqStack.pop ();//返回 5 ，因为 5 出现频率最高。堆栈变成 [5,7,5,7,4]。
freqStack.pop ();//返回 7 ，因为 5 和 7 出现频率最高，但7最接近顶部。堆栈变成 [5,7,5,4]。
freqStack.pop ();//返回 5 ，因为 5 出现频率最高。堆栈变成 [5,7,4]。
freqStack.pop ();//返回 4 ，因为 4, 5 和 7 出现频率最高，但 4 是最接近顶部的。堆栈变成 [5,7]。

提示：

  • 0 <= val <= 109
  • push 和 pop 的操作数不大于 2 * 104。
  • 输入保证在调用 pop 之前堆栈中至少有一个元素。
