从高位往低位读指数：每读一位，已得结果自乘 10 次幂，再乘 a^当前位，全程 mod 1337。

思路

  • a^(b[0]…bk) = (a^(b[0]…b[k−1]))^10 × a^b[k]，按位扫描即可，不必碰大数。
  • 先 a %= 1337，之后所有乘法都在 int 范围内（1337² 远够不着溢出）。
  • pow(x, k) 是标准快速幂，k ≤ 10 很小；a 可达 int 最大值，必须先取模再参与乘法。

题目

你的任务是计算 ab 对 1337 取模，a 是一个正整数，b 是一个非常大的正整数且会以数组形式给出。

示例 1：

输入： a = 2, b = [3]

输出： 8

解释：

数组 b = [3] 表示指数 3。因此，a3 = 23 = 8，所以结果为 8。

示例 2：

输入： a = 2, b = [1,0]

输出： 1024

解释：

数组 b = [1, 0] 表示指数 10。因此，a10 = 210 = 1024，所以结果为 1024。

示例 3：

输入： a = 1, b = [4,3,3,8,5,2]

输出： 1

解释：

数组 b = [4, 3, 3, 8, 5, 2] 表示一个正整数指数。由于 a = 1，1 的任意正整数次幂都等于 1。因此，结果为 1。

提示：

  • 1 <= a <= 231 - 1
  • 1 <= b.length <= 2000
  • 0 <= b[i] <= 9
  • b 不含前导 0
