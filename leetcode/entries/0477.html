477. 汉明距离总和

逐位统计：某一位上 1 的个数是 c，这一位对总距离的贡献就是 c×(n−c)，30 位累加。

思路

  • 汉明距离按位独立：一对数在某一位上不同就贡献 1，各位互不影响。
  • 某位上有 c 个 1、n−c 个 0，这一位不同的对数就是 c × (n−c)，省掉两两枚举的 O(n²)。
  • nums[i] ≤ 10^9 < 2^30，循环低 30 位足够；答案题目保证在 int 范围内。

最优解

时间复杂度 O(30n)，空间复杂度 O(1)
1class Solution {2    public int totalHammingDistance(int[] nums) {3        int n = nums.length, ans = 0;4        // 逐位统计：该位上 1 有 c 个，两两不同就贡献 c*(n-c) 对5        for (int bit = 0; bit < 30; bit++) {6            // nums[i] ≤ 1e9 < 2^30，看低 30 位足够7            int c = 0;8            for (int x : nums) c += (x >> bit) & 1;9            ans += c * (n - c);10        }11        return ans;12    }13}
题目

两个整数的 汉明距离 指的是这两个数字的二进制数对应位不同的数量。

给你一个整数数组 nums，请你计算并返回 nums 中任意两个数之间 汉明距离的总和 。

示例 1：

输入：nums = [4,14,2]
输出：6
解释：在二进制表示中，4 表示为 0100 ，14 表示为 1110 ，2表示为 0010 。（这样表示是为了体现后四位之间关系）
所以答案为：
HammingDistance(4, 14) + HammingDistance(4, 2) + HammingDistance(14, 2) = 2 + 2 + 2 = 6

示例 2：

输入：nums = [4,14,4]
输出：4

提示：

  • 1 <= nums.length <= 104
  • 0 <= nums[i] <= 109
  • 给定输入的对应答案符合 32-bit 整数范围
