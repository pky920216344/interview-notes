两次扫描：从左到右记最后一个「小于左侧最大值」的位置 r，从右到左记最后一个「大于右侧最小值」的位置 l，答案 r−l+1。

思路

  • 左→右维护已扫过的最大值 max：nums[i] < max 说明 i 放错位置，记下最后一个这样的 r。
  • 右→左维护已扫过的最小值 min：nums[i] > min 说明 i 放错位置，记下最左边这样的 l。
  • [l, r] 就是必须重排的最短区间，长度 r - l + 1；一次逆序都没有（r 没动过）返回 0。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int findUnsortedSubarray(int[] nums) {3        int n = nums.length;4        // 从左往右：记最后一个「比左边出现过的最大值还小」的位置 r，它必须被重排5        int r = -1, max = Integer.MIN_VALUE;6        for (int i = 0; i < n; i++) {7            if (nums[i] < max) r = i;8            else max = nums[i];9        }10        if (r < 0) return 0;                     // 一次逆序都没有，整个数组本来就有序11        // 从右往左：记最后一个（也就是最左边的）「比右边出现过的最小值还大」的位置 l12        int l = n, min = Integer.MAX_VALUE;13        for (int i = n - 1; i >= 0; i--) {14            if (nums[i] > min) l = i;15            else min = nums[i];16        }17        return r - l + 1;18    }19}
题目

给你一个整数数组 nums ，你需要找出一个 连续子数组 ，如果对这个子数组进行升序排序，那么整个数组都会变为升序排序。

请你找出符合题意的 最短 子数组，并输出它的长度。

示例 1：

输入：nums = [2,6,4,8,10,9,15]
输出：5
解释：你只需要对 [6, 4, 8, 10, 9] 进行升序排序，那么整个表都会变为升序排序。

示例 2：

输入：nums = [1,2,3,4]
输出：0

示例 3：

输入：nums = [1]
输出：0

提示：

  • 1 <= nums.length <= 104
  • -105 <= nums[i] <= 105
