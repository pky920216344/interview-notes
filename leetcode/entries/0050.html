50. Pow(x, n)

  • 中等
  • 频度 43
  • 位运算
  • 数学
  • 递归
  • 数学
  • 力扣已通过

快速幂：把 n 拆成二进制，x 逐轮自乘翻倍，n 的每个 1 位把当前这份 x 乘进答案；负指数最后才取倒数。

思路

  • n 先转 long 再取负：Integer.MIN_VALUE 直接取负会溢出；负指数等价于取倒数，但倒数要留到最后。
  • 迭代二进制拆分：x 每轮平方（x¹→x²→x⁴…），n 的当前二进制位是 1 就把这份 x 乘进 ans。
  • 先算 1/x 再快速幂会挂精度用例：1/x 带进的 1 ulp 误差会被大指数放大，叠加在本底上超判题容差；底数全程用原始 x、最后才 1/ans 就只剩本底误差。
  • 本底也要心里有数：平方会把已有相对误差翻倍（(1+ε)²≈1+2ε），31 层平方链 ≈ 2³⁰ 倍放大，n~1e9 时快速幂天生带 ~1e-8 相对误差，这是 double 的极限，不是 bug。
  • 循环只走 log n 轮，额外空间就两个变量。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public double myPow(double x, int n) {3        // n 要取负：先转 long，Integer.MIN_VALUE 取负才不溢出4        long e = n;5        boolean inv = e < 0;6        if (inv) e = -e;7        // 二进制拆分：底数全程用原始 x，取倒数放到最后8        // （先取倒数会把底数 1 ulp 的误差放大 N 倍，挂精度用例）9        double ans = 1.0;10        while (e > 0) {11            // 最低位是 1：把当前这份 x 乘进答案12            if ((e & 1) == 1) ans *= x;13            // x 逐轮自乘：x^1 → x^2 → x^4 …14            x *= x;15            e >>= 1;16        }17        return inv ? 1 / ans : ans;18    }19}
题目

实现 pow(x, n) ，即计算 x 的整数 n 次幂函数（即，xn ）。

示例 1：

输入：x = 2.00000, n = 10
输出：1024.00000

示例 2：

输入：x = 2.10000, n = 3
输出：9.26100

示例 3：

输入：x = 2.00000, n = -2
输出：0.25000
解释：2-2 = 1/22 = 1/4 = 0.25

提示：

  • -100.0 < x < 100.0
  • -231 <= n <= 231-1
  • n 是一个整数
  • 要么 x 不为零，要么 n > 0 。
  • -104 <= xn <= 104
