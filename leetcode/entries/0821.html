821. 字符的最短距离

  • 频度 3
  • 模拟
  • 数组
  • 双指针
  • 字符串
  • 待提交

两遍扫：从左往右填「到左侧最近 c」的距离，再从右往左用「到右侧最近 c」的距离取较小值。

思路

  • 第一遍维护 prev = 左侧最近 c 的下标，ans[i] = i - prev；没有左侧 c 时用哨兵 -n，先填个大数。
  • 第二遍从右往左维护 next = 右侧最近 c 的下标，ans[i] = min(ans[i], next - i)；哨兵 2n 保证不会胜出。
  • 每个 c 出现的位置距离为 0，两遍扫描自然覆盖；答案 = 左右两个方向距离的较小者。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)（不算输出）
1class Solution {2    public int[] shortestToChar(String s, char c) {3        int n = s.length();4        int[] ans = new int[n];5        // 两遍扫：先只看左边的 c，再只看右边的 c，取较小的距离6        int prev = -n;   // 左侧最近 c 的位置，还没有时给个足够远的哨兵7        for (int i = 0; i < n; i++) {8            if (s.charAt(i) == c) prev = i;9            ans[i] = i - prev;10        }11        int next = 2 * n;   // 右侧最近 c 的位置，还没有时给个足够远的哨兵12        for (int i = n - 1; i >= 0; i--) {13            if (s.charAt(i) == c) next = i;14            ans[i] = Math.min(ans[i], next - i);15        }16        return ans;17    }18}
题目

给你一个字符串 s 和一个字符 c ，且 c 是 s 中出现过的字符。

返回一个整数数组 answer ，其中 answer.length == s.length 且 answer[i] 是 s 中从下标 i 到离它 最近 的字符 c 的 距离 。

两个下标 i 和 j 之间的 距离 为 abs(i - j) ，其中 abs 是绝对值函数。

示例 1：

输入：s = "loveleetcode", c = "e"
输出：[3,2,1,0,1,0,0,1,2,2,1,0]
解释：字符 'e' 出现在下标 3、5、6 和 11 处（下标从 0 开始计数）。
距下标 0 最近的 'e' 出现在下标 3 ，所以距离为 abs(0 - 3) = 3 。
距下标 1 最近的 'e' 出现在下标 3 ，所以距离为 abs(1 - 3) = 2 。
对于下标 4 ，出现在下标 3 和下标 5 处的 'e' 都离它最近，但距离是一样的 abs(4 - 3) == abs(4 - 5) = 1 。
距下标 8 最近的 'e' 出现在下标 6 ，所以距离为 abs(8 - 6) = 2 。

示例 2：

输入：s = "aaab", c = "b"
输出：[3,2,1,0]
提示：
  • 1 <= s.length <= 104
  • s[i] 和 c 均为小写英文字母
  • 题目数据保证 c 在 s 中至少出现一次
