67. 二进制求和

竖式加法：从低位往高位逐位加，本位写 sum%2、进位 sum/2（最多 1），最后反转输出。

思路

  • i、j 从两个串的末尾出发，carry 记进位；某一边读完这一位就当 0。
  • 二进制只有 0/1：1+1=2 写 0 进 1；1+1+1=3 写 1 进 1——进位永远是 0 或 1。
  • 循环条件要带上 carry > 0：两个数都读完时最高位可能还欠一个进位。
  • sb 是低位在前 append 出来的，最后 reverse 才是正常顺序。

最优解

时间复杂度 O(max(m,n))，空间复杂度 O(1)
1class Solution {2    public String addBinary(String a, String b) {3        StringBuilder sb = new StringBuilder();4        int i = a.length() - 1, j = b.length() - 1, carry = 0;5        // 两个都读完、进位也归零，才算加完6        while (i >= 0 || j >= 0 || carry > 0) {7            int sum = carry;8            // 短的那个读完了，这一位就当 09            if (i >= 0) sum += a.charAt(i--) - '0';10            if (j >= 0) sum += b.charAt(j--) - '0';11            sb.append(sum & 1);   // 二进制：本位留 sum % 212            carry = sum >> 1;     // 进位 = sum / 2，最多 113        }14        // 是从低位往高位写的，要反转15        return sb.reverse().toString();16    }17}
题目

给你两个二进制字符串 a 和 b ，以二进制字符串的形式返回它们的和。

示例 1：

输入:a = "11", b = "1"
输出："100"

示例 2：

输入：a = "1010", b = "1011"
输出："10101"

提示：

  • 1 <= a.length, b.length <= 104
  • a 和 b 仅由字符 '0' 或 '1' 组成
  • 字符串如果不是 "0" ，就不含前导零
