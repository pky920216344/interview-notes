一遍数出每个字母的次数，第二遍仍从左往右扫，第一个次数为 1 的就是答案。

思路

  • 字母表固定 26 个，int[26] 计数即可，空间 O(1)。
  • 第二遍按原顺序扫：第一个 cnt==1 的字母就是答案，保序是关键。
  • 都有重复返回空格 ' '；空串同样返回 ' '。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public char dismantlingAction(String arr) {3        // 第一遍：数每个字母出现的次数4        int[] cnt = new int[26];5        for (int i = 0; i < arr.length(); i++) cnt[arr.charAt(i) - 'a']++;6        // 第二遍：按原顺序找第一个只出现一次的7        for (int i = 0; i < arr.length(); i++) {8            if (cnt[arr.charAt(i) - 'a'] == 1) return arr.charAt(i);9        }10        // 都有重复就没有答案，返回空格11        return ' ';12    }13}
题目

某套连招动作记作仅由小写字母组成的序列 arr，其中 arr[i] 第 i 个招式的名字。请返回第一个只出现一次的招式名称，如不存在请返回空格。

示例 1：

输入：arr = "abbccdeff"
输出：'a'

示例 2：

输入：arr = "ccdd"
输出：' '

限制：

0 <= arr.length <= 50000
