自增发号器：encode 给每个新 URL 发一个号、36 进制当短码，两张哈希表双向各记一条。

思路

  • encode：新 URL 就发自增号 id，短码 = http://tinyurl.com/ + 36 进制的 id；见过的 URL 直接复用旧短码。
  • 两张哈希表各写一条：longToShort 供复用，shortToLong 供还原。
  • decode：查 shortToLong 一步还原，O(1)。
  • 短码互异由发号器保证，decode 才不会撞车。

图解

最优解

时间复杂度 O(1)，空间复杂度 O(n)
1import java.util.*;2 3class Codec {4    private final Map<String, String> longToShort = new HashMap<>();5    private final Map<String, String> shortToLong = new HashMap<>();6    private int id = 0;                          // 自增发号器7 8    // 同一个 URL 重复加密时复用第一次的短码9    public String encode(String longUrl) {10        String known = longToShort.get(longUrl);11        if (known != null) return known;12        String shortUrl = "http://tinyurl.com/" + Long.toString(id++, 36);13        longToShort.put(longUrl, shortUrl);14        shortToLong.put(shortUrl, longUrl);15        return shortUrl;16    }17 18    public String decode(String shortUrl) {19        return shortToLong.get(shortUrl);20    }21}
题目

TinyURL 是一种 URL 简化服务， 比如：当你输入一个 URL https://leetcode.com/problems/design-tinyurl 时，它将返回一个简化的URL http://tinyurl.com/4e9iAk 。请你设计一个类来加密与解密 TinyURL 。

加密和解密算法如何设计和运作是没有限制的，你只需要保证一个 URL 可以被加密成一个 TinyURL ，并且这个 TinyURL 可以用解密方法恢复成原本的 URL 。

实现 Solution 类：

  • Solution() 初始化 TinyURL 系统对象。
  • String encode(String longUrl) 返回 longUrl 对应的 TinyURL 。
  • String decode(String shortUrl) 返回 shortUrl 原本的 URL 。题目数据保证给定的 shortUrl 是由同一个系统对象加密的。

示例：

输入：url = "https://leetcode.com/problems/design-tinyurl"
输出："https://leetcode.com/problems/design-tinyurl"

解释：
Solution obj = new Solution();
string tiny = obj.encode(url); // 返回加密后得到的 TinyURL 。
string ans = obj.decode(tiny); // 返回解密后得到的原本的 URL 。

提示：

  • 1 <= url.length <= 104
  • 题目数据保证 url 是一个有效的 URL
