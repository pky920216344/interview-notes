加虚拟水源点 0，井费变成 0→i 的边权；所有边一起跑 Kruskal 最小生成树。

思路

  • 每个房子要么自建井、要么靠管道连到有水的房子：造虚拟水源 0，向房子 i 连权 wells[i-1] 的边。
  • 「建井」和「铺管」统一成 n+1 个点的最小生成树：Kruskal 按边权从小到大试，并查集判环，能连就连。
  • 选满 n 条边即停（n+1 个点的生成树恰 n 条边），答案为选中边权之和。

1import java.util.Arrays;2 3class Solution {4    private int[] parent;5 6    public int minCostToSupplyWater(int n, int[] wells, int[][] pipes) {7        // 虚拟水源 0：建井费用是边 (0, i)；所有边一起跑 Kruskal 最小生成树8        int[][] edges = new int[pipes.length + n][];9        for (int i = 0; i < pipes.length; i++) edges[i] = pipes[i];10        for (int i = 0; i < n; i++) edges[pipes.length + i] = new int[]{0, i + 1, wells[i]};11        Arrays.sort(edges, (x, y) -> x[2] - y[2]);12        parent = new int[n + 1];13        for (int i = 0; i <= n; i++) parent[i] = i;14        int ans = 0, picked = 0;15        for (int[] e : edges) {16            int a = find(e[0]), b = find(e[1]);17            if (a == b) continue;   // 两端已连通，这条边成环不要18            parent[a] = b;19            ans += e[2];20            if (++picked == n) break;   // n+1 个点的生成树只要 n 条边21        }22        return ans;23    }24 25    private int find(int x) {26        while (parent[x] != x) {27            parent[x] = parent[parent[x]];   // 路径减半28            x = parent[x];29        }30        return x;31    }32}
