478. 在圆内随机生成点

拒绝采样：在外接正方形 [−r,r]² 上均匀取点，落在圆外就重取；正方形密度均匀，留下的点在圆内也均匀。

思路

  • 用 Math.random() 取 u, v ∈ [−1,1)，得到正方形上的均匀点。
  • u² + v² ≤ 1 才算圆内（圆周也算），否则重取；接受率 π/4，均摊常数次。
  • 命中后映射回圆内坐标：x = xc + r·u，y = yc + r·v。
  • 不能用「半径 × 随机角度」：角度均匀时点会向圆心聚集，不均匀。

最优解

时间复杂度 O(1) 均摊（每轮接受率 π/4），空间复杂度 O(1)
1class Solution {2    private final double radius, xc, yc;3 4    public Solution(double radius, double x_center, double y_center) {5        this.radius = radius;6        this.xc = x_center;7        this.yc = y_center;8    }9 10    public double[] randPoint() {11        // 拒绝采样：在外接正方形 [−r,r]² 上均匀取点，落在圆外就重取（圆周也算圆内）12        while (true) {13            double u = Math.random() * 2 - 1, v = Math.random() * 2 - 1;14            if (u * u + v * v <= 1) return toWorld(u, v);15        }16    }17 18    // 本地验证用：给定候选 (u,v) 序列，返回第一个落在圆内的候选映射成的点19    double[] firstHit(double[] uv) {20        for (int i = 0; i + 1 < uv.length; i += 2) {21            double u = uv[i], v = uv[i + 1];22            if (inside(u, v)) return toWorld(u, v);23        }24        return toWorld(0, 0);   // 全被拒时兜底返回圆心（圆心必在圆内）25    }26 27    private boolean inside(double u, double v) {28        return u * u + v * v <= 1;29    }30 31    private double[] toWorld(double u, double v) {32        // 正方形里的相对坐标 (u,v) 放大 r 倍再平移到圆心33        return new double[]{xc + radius * u, yc + radius * v};34    }35}
题目

给定圆的半径和圆心的位置，实现函数 randPoint ，在圆中产生均匀随机点。

实现 Solution 类:

  • Solution(double radius, double x_center, double y_center) 用圆的半径 radius 和圆心的位置 (x_center, y_center) 初始化对象
  • randPoint() 返回圆内的一个随机点。圆周上的一点被认为在圆内。答案作为数组返回 [x, y] 。

示例 1：

输入: 
["Solution","randPoint","randPoint","randPoint"]
[[1.0, 0.0, 0.0], [], [], []]
输出: [null, [-0.02493, -0.38077], [0.82314, 0.38945], [0.36572, 0.17248]]
解释:
Solution solution = new Solution(1.0, 0.0, 0.0);
solution.randPoint ();//返回[-0.02493，-0.38077]
solution.randPoint ();//返回[0.82314,0.38945]
solution.randPoint ();//返回[0.36572,0.17248]

提示：

  • 0 < radius <= 108
  • -107 <= x_center, y_center <= 107
  • randPoint 最多被调用 3 * 104 次
