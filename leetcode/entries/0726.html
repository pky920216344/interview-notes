递归解析化学式：'(' 就递归一层，原子=大写+小写尾巴+数字倍数；每层一张计数表，TreeMap 输出天然有序。

思路

  • 全局下标 i 一路消耗 formula；遇 ( 先递归解析子式拿到它的计数表，跳过 ) 再读倍数 k，里层每个原子 ×k 并回本层。
  • 原子名 = 大写字母 + 后续小写尾巴；后面没数字按 1 个计。
  • 用 TreeMap<String, Long> 计数：输出时天然按原子名字典序，个数 > 1 才拼数字。
  • 输出形态：K4N2O14S4（名字 + 省略 1 的数量）。

1import java.util.*;2 3class Solution {4    private int i;   // 当前解析位置（递归体一路消耗 formula）5 6    public String countOfAtoms(String formula) {7        i = 0;8        Map<String, Long> cnt = parse(formula.toCharArray());9        StringBuilder sb = new StringBuilder();10        for (Map.Entry<String, Long> e : cnt.entrySet()) {   // TreeMap 已按名字排序11            sb.append(e.getKey());12            if (e.getValue() > 1) sb.append(e.getValue());13        }14        return sb.toString();15    }16 17    // 解析当前层，遇 ')' 或结尾停；返回时 i 停在 ')' 之后（或结尾）18    private Map<String, Long> parse(char[] s) {19        Map<String, Long> cnt = new TreeMap<>();20        while (i < s.length && s[i] != ')') {21            if (s[i] == '(') {22                i++;   // 跳过 '('，递归解析子式23                Map<String, Long> inner = parse(s);24                i++;   // 跳过 ')'25                long k = num(s, 1);   // 括号后的倍数，缺省 126                for (Map.Entry<String, Long> e : inner.entrySet())27                    cnt.merge(e.getKey(), e.getValue() * k, Long::sum);28            } else {29                int start = i++;   // 大写字母起头30                while (i < s.length && s[i] >= 'a' && s[i] <= 'z') i++;   // 吞掉小写尾巴31                String name = new String(s, start, i - start);   // 先取名字，数字不属于名字32                long k = num(s, 1);33                cnt.merge(name, k, Long::sum);34            }35        }36        return cnt;37    }38 39    // 读当前数字（没有给 def），并把 i 推过去40    private long num(char[] s, long def) {41        if (i >= s.length || s[i] < '0' || s[i] > '9') return def;42        long x = 0;43        while (i < s.length && s[i] >= '0' && s[i] <= '9') x = x * 10 + (s[i++] - '0');44        return x;45    }46}
题目

给你一个字符串化学式 formula ，返回 每种原子的数量 。

原子总是以一个大写字母开始，接着跟随 0 个或任意个小写字母，表示原子的名字。

如果数量大于 1，原子后会跟着数字表示原子的数量。如果数量等于 1 则不会跟数字。

  • 例如，"H2O" 和 "H2O2" 是可行的，但 "H1O2" 这个表达是不可行的。

两个化学式连在一起可以构成新的化学式。

  • 例如 "H2O2He3Mg4" 也是化学式。

由括号括起的化学式并佐以数字（可选择性添加）也是化学式。

  • 例如 "(H2O2)" 和 "(H2O2)3" 是化学式。

返回所有原子的数量，格式为：第一个（按字典序）原子的名字，跟着它的数量（如果数量大于 1），然后是第二个原子的名字（按字典序），跟着它的数量（如果数量大于 1），以此类推。

示例 1：

输入：formula = "H2O"
输出："H2O"
解释：原子的数量是 {'H': 2, 'O': 1}。

示例 2：

输入：formula = "Mg(OH)2"
输出："H2MgO2"
解释：原子的数量是 {'H': 2, 'Mg': 1, 'O': 2}。

示例 3：

输入：formula = "K4(ON(SO3)2)2"
输出："K4N2O14S4"
解释：原子的数量是 {'K': 4, 'N': 2, 'O': 14, 'S': 4}。

提示：

  • 1 <= formula.length <= 1000
  • formula 由英文字母、数字、'(' 和 ')' 组成
  • formula 总是有效的化学式
