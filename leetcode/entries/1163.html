1163. 按字典序排在最后的子串

  • 待提交

双指针挑战制：i 是当前最优起点、j 是挑战者、k 是已匹配长度；挑战者胜则 i 跳到 max(i+k+1, j)，输则 j 跳过 k+1 位。

思路

  • 比较两个候选时若前 k 位都相同，只需看第 k 位：大的一方整段胜出，输家连同它已匹配的前缀都不可能再是答案，指针直接跳过。
  • 挑战者胜：i = max(i+k+1, j)——i 自己开头的串输了，i..i+k 这些起点也只会更差；挑战者的起点若更远，取更远的。
  • 挑战者输：j = j+k+1——j 与 i 共享前 k 位，j 开头的串必小于 i 开头的对应串，连同前缀一起跳。
  • 全同字符、k 走到串尾都安全：循环条件 j+k < n 兜底，答案为 s.substring(i)。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public String lastSubstring(String s) {5        int n = s.length();6        // i：当前最优候选的起点；j：挑战者起点；k：两串已匹配的长度7        int i = 0, j = 1, k = 0;8        while (j + k < n) {9            if (s.charAt(i + k) == s.charAt(j + k)) {10                k++;                        // 继续比下一位11            } else if (s.charAt(i + k) < s.charAt(j + k)) {12                // 挑战者胜出：i 之前连同 i+k 都不可能再当最优起点，跳过去13                i = Math.max(i + k + 1, j);14                j = i + 1;15                k = 0;16            } else {17                j = j + k + 1;              // 挑战者输掉：连同它已匹配的前缀一起跳过18                k = 0;19            }20        }21        return s.substring(i);22    }23}
题目

给你一个字符串 s ，找出它的所有子串并按字典序排列，返回排在最后的那个子串。

示例 1：

输入：s = "abab"
输出："bab"
解释：我们可以找出 7 个子串 ["a", "ab", "aba", "abab", "b", "ba", "bab"]。按字典序排在最后的子串是 "bab"。

示例 2：

输入：s = "leetcode"
输出："tcode"

提示：

  • 1 <= s.length <= 4 * 105
  • s 仅含有小写英文字符。
