BFS 三类边：i±1 和「所有等值下标」；等值整组入队后立刻把传送门拆掉，防止同值互跳把图炸掉。

思路

  • 无权图最短步数用 BFS：每个下标的邻居是 i−1、i+1 和所有 arr[j] == arr[i] 的 j。
  • 同值下标预先分组；第一次扩展某值时把整组一起入队，然后删掉该组——此后组内成员全已访问，再跳也不会有新收获。
  • 逐层扩展，终点获得下标时的层数即答案；起点即终点（n=1）返回 0。

1import java.util.*;2 3class Solution {4    public int minJumps(int[] arr) {5        int n = arr.length;6        if (n == 1) return 0;7        // 等值下标分组：同值的格子之间有「传送门」8        Map<Integer, List<Integer>> same = new HashMap<>();9        for (int i = 0; i < n; i++) same.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);10        boolean[] vis = new boolean[n];11        vis[0] = true;12        Deque<Integer> queue = new ArrayDeque<>();13        queue.addLast(0);14        int step = 0;15        while (!queue.isEmpty()) {16            step++;17            for (int k = queue.size(); k > 0; k--) {18                int i = queue.pollFirst();19                // 两类普通边：左右各走一步20                int[] near = {i - 1, i + 1};21                for (int j : near) {22                    if (j >= 0 && j < n && !vis[j]) {23                        vis[j] = true;24                        queue.addLast(j);25                    }26                }27                // 传送门：整组一起入队；用完立刻拆门，防止同值之间反复互跳28                List<Integer> group = same.get(arr[i]);29                if (group != null) {30                    for (int j : group) {31                        if (!vis[j]) {32                            vis[j] = true;33                            queue.addLast(j);34                        }35                    }36                    same.remove(arr[i]);37                }38            }39            if (vis[n - 1]) return step;40        }41        return -1;42    }43}
题目

给你一个整数数组 arr ，你一开始在数组的第一个元素处（下标为 0）。

每一步，你可以从下标 i 跳到下标 i + 1 、i - 1 或者 j ：

  • i + 1 需满足：i + 1 < arr.length
  • i - 1 需满足：i - 1 >= 0
  • j 需满足：arr[i] == arr[j] 且 i != j

请你返回到达数组最后一个元素的下标处所需的 最少操作次数 。

注意：任何时候你都不能跳到数组外面。

示例 1：

输入：arr = [100,-23,-23,404,100,23,23,23,3,404]
输出：3
解释：那你需要跳跃 3 次，下标依次为 0 --> 4 --> 3 --> 9 。下标 9 为数组的最后一个元素的下标。

示例 2：

输入：arr = [7]
输出：0
解释：一开始就在最后一个元素处，所以你不需要跳跃。

示例 3：

输入：arr = [7,6,9,6,9,6,9,7]
输出：1
解释：你可以直接从下标 0 处跳到下标 7 处，也就是数组的最后一个元素处。

提示：

  • 1 <= arr.length <= 5 * 104
  • -108 <= arr[i] <= 108
