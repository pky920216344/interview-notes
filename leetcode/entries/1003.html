1003. 检查替换后的词是否有效

  • 中等
  • 频度 1
  • 栈
  • 栈
  • 字符串
  • 待提交

栈模拟插入的逆过程：a、b 压栈，读到 c 就核对栈顶是 b、其下是 a，弹两个；读完栈空才有效。

思路

  • 每个插入的 "abc" 一定是按 a→b→c 的顺序被读到的：看到 c 时，它前面刚压栈的就是 b、a。
  • 遇 c：栈顶两个恰好是 b、a 就弹掉（栈不足两个直接无效）。
  • 扫完后栈必须为空，剩着 a、b 说明有 "abc" 没凑齐。
  • 用字符数组当栈（top 计数），避免 StringBuilder 删字符的搬移开销。

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public boolean isValid(String s) {3        // 字符数组当栈：top 指向栈顶的下一位4        char[] st = new char[s.length()];5        int top = 0;6        for (int i = 0; i < s.length(); i++) {7            char c = s.charAt(i);8            if (c == 'c') {9                // 凑一个 "abc"：栈顶必须是 b、再下面是 a，否则无效10                if (top < 2 || st[top - 1] != 'b' || st[top - 2] != 'a') return false;11                top -= 2;12            } else {13                st[top++] = c;14            }15        }16        // 读完了还有剩，说明 abc 没凑完17        return top == 0;18    }19}
题目
给你一个字符串 s ，请你判断它是否 有效 。

字符串 s 有效 需要满足：假设开始有一个空字符串 t = "" ，你可以执行 任意次 下述操作将t 转换为 s ：

  • 将字符串 "abc" 插入到 t 中的任意位置。形式上，t 变为 tleft + "abc" + tright，其中 t == tleft + tright 。注意，tleft 和 tright 可能为 空 。

如果字符串 s 有效，则返回 true；否则，返回 false。

示例 1：

输入：s = "aabcbc"
输出：true
解释：
"" -> "abc" -> "aabcbc"
因此，"aabcbc" 有效。

示例 2：

输入：s = "abcabcababcc"
输出：true
解释：
"" -> "abc" -> "abcabc" -> "abcabcabc" -> "abcabcababcc"
因此，"abcabcababcc" 有效。

示例 3：

输入：s = "abccba"
输出：false
解释：执行操作无法得到 "abccba" 。

提示：

  • 1 <= s.length <= 2 * 104
  • s 由字母 'a'、'b' 和 'c' 组成
