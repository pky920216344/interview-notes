33. 搜索旋转排序数组

  • 中等
  • 频度 323
  • 二分查找
  • 数组
  • 二分查找
  • 力扣已通过

二分：以 mid 切开，总有一半是有序的；看 target 落不落在有序那一半的值域里，在就留它，不在就留另一半。

思路

  • nums[left] <= nums[mid] 说明左半 [left, mid] 有序（必须取 <=：left == mid 时左半只有一个数，也算有序），否则右半 [mid, right] 有序。
  • 左半有序：nums[left] <= target < nums[mid] 就留左半（right = mid - 1），否则去右半。
  • 右半有序：nums[mid] < target <= nums[right] 就留右半（left = mid + 1），否则去左半。
  • 先判 nums[mid] == target 直接返回；left > right 说明没找到，返回 -1。

图解

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int search(int[] nums, int target) {3        int left = 0, right = nums.length - 1;4        while (left <= right) {5            int mid = left + (right - left) / 2;6            if (nums[mid] == target) return mid;7            // 以 mid 切开，必有一半是有序的8            if (nums[left] <= nums[mid]) {9                // 左半有序：target 落在里面就留左半10                if (nums[left] <= target && target < nums[mid]) right = mid - 1;11                else left = mid + 1;12            } else {13                // 右半有序：target 落在里面就留右半14                if (nums[mid] < target && target <= nums[right]) left = mid + 1;15                else right = mid - 1;16            }17        }18        return -1;19    }20}
题目

整数数组 nums 按升序排列，数组中的值 互不相同 。

在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了 向左旋转，使数组变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]（下标 从 0 开始 计数）。例如， [0,1,2,4,5,6,7] 下标 3 上向左旋转后可能变为 [4,5,6,7,0,1,2] 。

给你 旋转后 的数组 nums 和一个整数 target ，如果 nums 中存在这个目标值 target ，则返回它的下标，否则返回 -1 。

你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。

示例 1：

输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4

示例 2：

输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1

示例 3：

输入：nums = [1], target = 0
输出：-1

提示：

  • 1 <= nums.length <= 5000
  • -104 <= nums[i] <= 104
  • nums 中的每个值都 独一无二
  • 题目数据保证 nums 在预先未知的某个下标上进行了旋转
  • -104 <= target <= 104
