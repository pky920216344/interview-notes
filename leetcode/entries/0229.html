摩尔投票推广：出现超过 n/3 的元素至多 2 个；两个候选互抵，最后再数一遍验票。

思路

  • 出现超过 n/3 次的元素至多有 2 个：维护两个候选席位，各带一个计数。
  • 当前数与某候选相同 → 该计数加一；某席位空 → 顶替入席；与两个候选都不同 → 三数互抵，两个计数各减一。
  • 席位被顶替过就不可信：第二遍再数一次真实出现次数，严格大于 n/3 才收进答案。

题目

给定一个大小为 n 的整数数组，找出其中所有出现超过 ⌊n / 3⌋ 次的元素。

示例 1：

输入：nums = [3,2,3]
输出：[3]

示例 2：

输入：nums = [1]
输出：[1]

示例 3：

输入：nums = [1,2]
输出：[1,2]

提示：

  • 1 <= nums.length <= 5 * 104
  • -109 <= nums[i] <= 109
