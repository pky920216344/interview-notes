459. 重复的子字符串

  • 频度 21
  • 双指针

  • z-algorithm

KMP 的 next 数组：最长相等前后缀之外就是最小循环节，n 能整除 (n - next[n-1]) 且 next[n-1] > 0 即成立。

思路

  • next[i]：s[0..i] 的最长相等前后缀长度；失配时 j = next[j-1] 一步跳到次长前后缀，不用逐格退。
  • 设 len = next[n-1]：整个串的最长相等前后缀；去掉它，剩下 n - len 就是最小循环节。
  • len > 0 && n % (n - len) == 0 → 由循环节重复构成。len = 0 说明没有周期；不整除说明循环节不完整。
  • 直观记法：n - len 是「多出来的尾巴」，它既是周期又能整除 n，串就是它重复出来的。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public boolean repeatedSubstringPattern(String s) {3        int n = s.length();4        // next[i]：s[0..i] 的最长相等前后缀长度5        int[] next = new int[n];6        for (int i = 1, j = 0; i < n; i++) {7            // 失配：沿着 next 链回退，退到没得退为止8            while (j > 0 && s.charAt(i) != s.charAt(j)) j = next[j - 1];9            if (s.charAt(i) == s.charAt(j)) j++;10            next[i] = j;11        }12        // 去掉最长相等前后缀，剩下的就是最小循环节；n 能整除它才成立13        int len = next[n - 1];14        return len > 0 && n % (n - len) == 0;15    }16}
题目

给定一个非空的字符串 s ，检查是否可以通过由它的一个子串重复多次构成。

示例 1:

输入: s = "abab"
输出: true
解释: 可由子串 "ab" 重复两次构成。

示例 2:

输入: s = "aba"
输出: false

示例 3:

输入: s = "abcabcabcabc"
输出: true
解释: 可由子串 "abc" 重复四次构成。 (或子串 "abcabc" 重复两次构成。)

提示：

  • 1 <= s.length <= 104
  • s 由小写英文字母组成
