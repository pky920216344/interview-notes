1005. K 次取反后最大化的数组和

  • 简单
  • 频度 1
  • 贪心
  • 贪心
  • 数组
  • 排序
  • 待提交

贪心：先把负数从小到大逐个翻成正数（收益最大）；翻完后 k 若还剩奇数次，就翻绝对值最小的那个元素。

思路

  • 翻一个负数 x 和增加 2×|x| 等价，所以优先翻绝对值大的负数：升序排序后从下标 0 翻起。
  • 负数全翻完 k 还有剩：翻两次等于没翻，只需看 k 的奇偶；奇数就翻绝对值最小的元素（此时必为非负数，损失最小）。
  • 有 0 时奇数次剩余翻 0 即可，不损和；上面"翻绝对值最小"自动覆盖这种情况。

时间复杂度 O(n log n)，空间复杂度 O(log n)
1import java.util.*;2 3class Solution {4    public int largestSumAfterKNegations(int[] nums, int k) {5        // 升序排：负数集中在前面，从小到大（绝对值从大到小）逐个翻6        Arrays.sort(nums);7        for (int i = 0; i < nums.length && k > 0 && nums[i] < 0; i++) {8            nums[i] = -nums[i];9            k--;10        }11        // k 还有奇数次剩余：翻绝对值最小的那个，损失最小12        if (k % 2 == 1) {13            int min = 0;14            for (int i = 1; i < nums.length; i++) {15                if (Math.abs(nums[i]) < Math.abs(nums[min])) min = i;16            }17            nums[min] = -nums[min];18        }19        int sum = 0;20        for (int v : nums) sum += v;21        return sum;22    }23}
题目

给你一个整数数组 nums 和一个整数 k ，按以下方法修改该数组：

  • 选择某个下标 i 并将 nums[i] 替换为 -nums[i] 。

重复这个过程恰好 k 次。可以多次选择同一个下标 i 。

以这种方式修改数组后，返回数组 可能的最大和 。

示例 1：

输入：nums = [4,2,3], k = 1
输出：5
解释：选择下标 1 ，nums 变为 [4,-2,3] 。

示例 2：

输入：nums = [3,-1,0,2], k = 3
输出：6
解释：选择下标 (1, 2, 2) ，nums 变为 [3,1,0,2] 。

示例 3：

输入：nums = [2,-3,-1,5,-4], k = 2
输出：13
解释：选择下标 (1, 4) ，nums 变为 [2,3,-1,5,4] 。

提示：

  • 1 <= nums.length <= 104
  • -100 <= nums[i] <= 100
  • 1 <= k <= 104
