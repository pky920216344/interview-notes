949. 给定数字能组成的最大时间

  • 简单
  • 频度 4
  • 模拟
  • 数组
  • 字符串
  • 回溯
  • 枚举
  • 待提交

暴力但够用：4 个数字的全排列只有 24 种，逐个当成 HH:MM 试，筛掉小时 ≥ 24 或分钟 ≥ 60 的，剩下的取字符串最大。

思路

  • 四重循环选 4 个下标的排列，第 4 个下标用 l = 6 - i - j - k 直接算出，不用第四层循环。
  • h = arr[i]·10 + arr[j] 当小时、m = arr[k]·10 + arr[l] 当分钟，要求 h < 24 && m < 60。
  • 合法时间格式化成定长 "HH:MM"（补零），字符串比较就是时间比较，和 best 取大。
  • 一个合法的都没有就返回空串（best 初始值）。

最优解

时间复杂度 O(24) = O(1)，空间复杂度 O(1)
1class Solution {2    public String largestTimeFromDigits(int[] arr) {3        String best = "";4        // 4 个数字的全排列只有 24 种：前两个当 HH，后两个当 MM5        for (int i = 0; i < 4; i++)6            for (int j = 0; j < 4; j++) {7                if (j == i) continue;8                for (int k = 0; k < 4; k++) {9                    if (k == i || k == j) continue;10                    int l = 6 - i - j - k;   // 剩下的那个下标，不用第四层循环11                    int h = arr[i] * 10 + arr[j], m = arr[k] * 10 + arr[l];12                    // 小时 < 24、分钟 < 60 才合法；定长补零后直接比字符串13                    if (h < 24 && m < 60) {14                        String t = String.format("%02d:%02d", h, m);15                        if (t.compareTo(best) > 0) best = t;16                    }17                }18            }19        return best;20    }21}
题目

给定一个由 4 位数字组成的数组，返回可以设置的符合 24 小时制的最大时间。

24 小时格式为 "HH:MM" ，其中 HH 在 00 到 23 之间，MM 在 00 到 59 之间。最小的 24 小时制时间是 00:00 ，而最大的是 23:59 。从 00:00 （午夜）开始算起，过得越久，时间越大。

以长度为 5 的字符串，按 "HH:MM" 格式返回答案。如果不能确定有效时间，则返回空字符串。

示例 1：

输入：arr = [1,2,3,4]
输出："23:41"
解释：有效的 24 小时制时间是 "12:34"，"12:43"，"13:24"，"13:42"，"14:23"，"14:32"，"21:34"，"21:43"，"23:14" 和 "23:41" 。这些时间中，"23:41" 是最大时间。

示例 2：

输入：arr = [5,5,5,5]
输出：""
解释：不存在有效的 24 小时制时间，因为 "55:55" 无效。

示例 3：

输入：arr = [0,0,0,0]
输出："00:00"

示例 4：

输入：arr = [0,0,1,0]
输出："10:00"

提示：

  • arr.length == 4
  • 0 <= arr[i] <= 9
