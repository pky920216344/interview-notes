按长度降序、同长字典序排序后逐个试；对候选词做「真前缀 + 词集切词」DFS（带备忘录），第一个能拼出的就是答案。

思路

  • 排序：长度降序、同长按字典序升序——找到的第一个合法词天然就是「最长且字典序最小」。
  • 对候选词 w：首段必须是真前缀（整词匹配自己不算「由其他单词组成」），枚举每个切分点，前缀在词集里就递归切后缀。
  • 后缀切词带 fail 备忘录：某起点拼不完就记下，避免重复搜索（aaaa…a 这类输入会指数爆炸）。
  • 词集用 HashSet，切出的每段 O(1) 查询；词可以复用（aa = a + a 合法）。

1import java.util.*;2 3class Solution {4    public String longestWord(String[] words) {5        // 长度降序、同长按字典序升序：扫到的第一个合格单词就是答案6        Arrays.sort(words, (a, b) -> a.length() != b.length() ? b.length() - a.length() : a.compareTo(b));7        Set<String> dict = new HashSet<>(Arrays.asList(words));8        for (String w : words)9            if (composable(w, 0, dict, new Boolean[w.length() + 1])) return w;10        return "";11    }12 13    // w 从 start 位起的后缀能否由「其他单词」拼出：后缀整体是词典词（真子串，必是别的词），14    // 或切掉一个非空前缀后，剩余部分还能继续拼15    private boolean composable(String w, int start, Set<String> dict, Boolean[] memo) {16        if (memo[start] != null) return memo[start];17        boolean ok = start > 0 && dict.contains(w.substring(start));18        for (int i = start + 1; !ok && i < w.length(); i++)19            if (dict.contains(w.substring(start, i)) && composable(w, i, dict, memo)) ok = true;20        memo[start] = ok;21        return ok;22    }23}
题目

给定一组单词words，编写一个程序，找出其中的最长单词，且该单词由这组单词中的其他单词组合而成。若有多个长度相同的结果，返回其中字典序最小的一项，若没有符合要求的单词则返回空字符串。

示例：

输入： ["cat","banana","dog","nana","walk","walker","dogwalker"]
输出： "dogwalker"
解释： "dogwalker"可由"dog"和"walker"组成。

提示：

  • 0 <= len(words) <= 200
  • 1 <= len(words[i]) <= 100
