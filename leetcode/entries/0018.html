18. 四数之和

  • 中等
  • 频度 23
  • 双指针
  • 数组
  • 双指针
  • 排序
  • 力扣已通过

排序后固定前两个数 i、j，在右边用双指针 l、r 凑 target；i、j、l/r 三处跳过重复值，和用 long 防溢出。

思路

  • 排序后两层循环固定 i、j，内层对 [j+1, n-1] 用双指针：和小 l++，和大 r--，命中记一组。
  • 三处去重：i、j 各自跳过和前一个相同的值；命中后 l、r 也各跳过重复值，同一四元组只记一次。
  • 四个 1e9 相加会超 int，sum 必须声明成 long 再和 target 比较。

最优解

时间复杂度 O(n³)，空间复杂度 O(log n)（排序栈；不计返回值）
1import java.util.*;2 3class Solution {4    public List<List<Integer>> fourSum(int[] nums, int target) {5        Arrays.sort(nums);6        List<List<Integer>> ans = new ArrayList<>();7        int n = nums.length;8        // 固定前两个数 i、j，在 (j, n) 区间用双指针找后两个数9        for (int i = 0; i < n - 3; i++) {10            // i 去重：同一个开头数只当一次 i11            if (i > 0 && nums[i] == nums[i - 1]) continue;12            for (int j = i + 1; j < n - 2; j++) {13                // j 去重：同一个第二数只当一次 j14                if (j > i + 1 && nums[j] == nums[j - 1]) continue;15                int l = j + 1, r = n - 1;16                while (l < r) {17                    // 四个 1e9 相加会超 int，和必须用 long 接18                    long sum = (long) nums[i] + nums[j] + nums[l] + nums[r];19                    if (sum < target) {20                        l++;    // 和太小：l 右移才可能变大21                    } else if (sum > target) {22                        r--;    // 和太大：r 左移才可能变小23                    } else {24                        ans.add(Arrays.asList(nums[i], nums[j], nums[l], nums[r]));25                        l++;26                        r--;27                        // 命中后跳过重复值，同样的 (l, r) 只记一次28                        while (l < r && nums[l] == nums[l - 1]) l++;29                        while (l < r && nums[r] == nums[r + 1]) r--;30                    }31                }32            }33        }34        return ans;35    }36}
题目

给你一个由 n 个整数组成的数组 nums ，和一个目标值 target 。请你找出并返回满足下述全部条件且不重复的四元组 [nums[a], nums[b], nums[c], nums[d]] （若两个四元组元素一一对应，则认为两个四元组重复）：

  • 0 <= a, b, c, d < n
  • a、b、c 和 d 互不相同
  • nums[a] + nums[b] + nums[c] + nums[d] == target

你可以按 任意顺序 返回答案 。

示例 1：

输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

示例 2：

输入：nums = [2,2,2,2,2], target = 8
输出：[[2,2,2,2]]

提示：

  • 1 <= nums.length <= 200
  • -109 <= nums[i] <= 109
  • -109 <= target <= 109
