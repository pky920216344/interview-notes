698. 划分为k个相等的子集

记忆化回溯：数字从大到小依次试放 k 个桶；剩余相同的桶只试一个，空桶失败就整支剪掉。

思路

  • total % k != 0 直接 false；target = total / k，每个桶都要恰好凑到 target。
  • Arrays.sort 后从大到小放：大数先定位置，失败得早、剪得狠。
  • 两个剪枝：剩余相同的桶效果一样，tried 去重只试一个；放进空桶失败则其余空桶等价，break。
  • 所有数都放下（每步都没超 target）即 true；某个数哪儿都放不下就回溯。

时间复杂度 O(k^n)（剪枝后远小），空间复杂度 O(n+k)
1import java.util.*;2 3class Solution {4    public boolean canPartitionKSubsets(int[] nums, int k) {5        int total = 0;6        for (int x : nums) total += x;7        // 每桶目标 total/k；除不尽直接无解8        if (total % k != 0) return false;9        int target = total / k;10        Arrays.sort(nums);11        return dfs(nums, nums.length - 1, new int[k], target);12    }13 14    // 把 nums[idx] 及更小的数依次放进桶里，任何桶都不许超过 target15    private boolean dfs(int[] nums, int idx, int[] buckets, int target) {16        if (idx < 0) return true;17        int x = nums[idx];18        Set<Integer> tried = new HashSet<>();19        for (int i = 0; i < buckets.length; i++) {20            if (buckets[i] + x > target) continue;21            // 剩余相同的桶效果一样，试一个就够22            if (!tried.add(buckets[i])) continue;23            buckets[i] += x;24            if (dfs(nums, idx - 1, buckets, target)) return true;25            buckets[i] -= x;26            // 空桶都放不下：其余空桶等价，整支剪掉27            if (buckets[i] == 0) break;28        }29        return false;   // 所有桶都试不通30    }31}
题目

给定一个整数数组  nums 和一个正整数 k，找出是否有可能把这个数组分成 k 个非空子集，其总和都相等。

示例 1：

输入： nums = [4, 3, 2, 3, 5, 2, 1], k = 4
输出： True
说明： 有可能将其分成 4 个子集（5），（1,4），（2,3），（2,3）等于总和。

示例 2:

输入: nums = [1,2,3,4], k = 3
输出: false

提示：

  • 1 <= k <= len(nums) <= 16
  • 0 < nums[i] < 10000
  • 每个元素的频率在 [1,4] 范围内
