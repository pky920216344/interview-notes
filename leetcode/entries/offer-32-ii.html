BFS 逐层走：每轮先记下队列长度 size，弹 size 个收进同一行，剩下的队列正好是下一层。

思路

  • 队列里永远只放「还没展开的结点」；size = q.size() 是这一层的确切个数。
  • 弹 size 个：值收进同一行 level，孩子全部排到队尾。
  • 这轮结束后队列里剩下的恰好全是下一层——循环天然按层推进，空树直接返回空列表。

1import java.util.*;2 3class Solution {4    public List<List<Integer>> decorateRecord(TreeNode root) {5        List<List<Integer>> ans = new ArrayList<>();6        Queue<TreeNode> q = new ArrayDeque<>();7        if (root != null) q.add(root);8        // 每轮开头记下队列长度：正好是这一层的结点数，弹完这层队列里全是下一层9        while (!q.isEmpty()) {10            int size = q.size();11            List<Integer> level = new ArrayList<>();12            for (int k = 0; k < size; k++) {13                TreeNode node = q.poll();14                level.add(node.val);15                if (node.left != null) q.add(node.left);16                if (node.right != null) q.add(node.right);17            }18            ans.add(level);19        }20        return ans;21    }22}
题目

一棵圣诞树记作根节点为 root 的二叉树，节点值为该位置装饰彩灯的颜色编号。请按照从左到右的顺序返回每一层彩灯编号，每一层的结果记录于一行。

示例 1：

输入：root = [8,17,21,18,null,null,6]
输出：[[8],[17,21],[18,6]]

提示：

  1. 节点总数 <= 1000
