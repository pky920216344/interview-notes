BFS 用队列逐层处理：每层先记下队列长度 size，只弹 size 个结点，孩子排到队尾就是下一层。

思路

  • 根结点先入队；队列不空，就处理一层。
  • 每层开始先记下 size = queue.size()：此刻队列里恰好是这一层。必须先存下来，弹出时队列还在变长。
  • 弹出 size 个结点，值放进这一层的列表，非空的左右孩子排到队尾（属于下一层）。
  • 这一层弹完，把列表加进 ans；根为空直接返回空列表。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public List<List<Integer>> levelOrder(TreeNode root) {5        if (root == null) return new ArrayList<>();6        List<List<Integer>> ans = new ArrayList<>();7        Queue<TreeNode> queue = new ArrayDeque<>();8        queue.add(root);9        while (!queue.isEmpty()) {10            // 此刻队列里恰好是同一层的全部结点11            int size = queue.size();12            List<Integer> level = new ArrayList<>();13            for (int i = 0; i < size; i++) {14                TreeNode node = queue.poll();15                level.add(node.val);16                // 孩子排到队尾，属于下一层17                if (node.left != null) queue.add(node.left);18                if (node.right != null) queue.add(node.right);19            }20            ans.add(level);21        }22        return ans;23    }24}
题目

给你二叉树的根节点 root ，返回其节点值的 层序遍历 。 （即逐层地，从左到右访问所有节点）。

示例 1：

输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]

示例 2：

输入：root = [1]
输出：[[1]]

示例 3：

输入：root = []
输出：[]

提示：

  • 树中节点数目在范围 [0, 2000] 内
  • -1000 <= Node.val <= 1000
