钟表是环：时间换成 0~1439 分钟做布尔表；最小差只会出现在「相邻出现时间」之间，再补一个跨零点的首尾差。

思路

  • 每个时刻换算成分钟数 m；seen[m] 已为真说明同一分钟出现两次，差就是 0。
  • 排序解法的替代：把出现过的分钟在 first..last 里扫一遍，只算相邻出现时间的间隔。
  • 别忘了首尾环绕差 1440 + first - last：23:59 和 00:05 只差 6 分钟，跨零点的这一对最容易漏。
  • 三个候选取最小：所有相邻间隔、首尾环绕差。

1import java.util.*;2 3class Solution {4    public int findMinDifference(List<String> timePoints) {5        // 钟表是个环：把时间换成 0~1439 分钟，答案只可能出现在「相邻出现时间」之间6        boolean[] seen = new boolean[24 * 60];7        int first = 24 * 60, last = -1;8        for (String t : timePoints) {9            int m = toMin(t);10            if (seen[m]) return 0;   // 同一分钟出现两次，差为 011            seen[m] = true;12            if (m < first) first = m;13            if (m > last) last = m;14        }15        // 首尾环绕差：最晚的 23:xx 跨过零点到最早的 00:xx16        int ans = 24 * 60 + first - last;17        int prev = first;18        for (int m = first + 1; m <= last; m++)19            if (seen[m]) {20                ans = Math.min(ans, m - prev);   // 只看相邻出现时间的间隔21                prev = m;22            }23        return ans;24    }25 26    // "HH:MM" → 从 0 点起的分钟数27    private int toMin(String t) {28        return ((t.charAt(0) - '0') * 10 + (t.charAt(1) - '0')) * 60 + (t.charAt(3) - '0') * 10 + (t.charAt(4) - '0');29    }30}
题目

给定一个 24 小时制（小时:分钟 "HH:MM"）的时间列表，找出列表中任意两个时间的最小时间差并以分钟数表示。

示例 1：

输入：timePoints = ["23:59","00:00"]
输出：1

示例 2：

输入：timePoints = ["00:00","23:59","00:00"]
输出：0

提示：

  • 2 <= timePoints.length <= 2 * 104
  • timePoints[i] 格式为 "HH:MM"
