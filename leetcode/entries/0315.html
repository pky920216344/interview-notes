归并排序统计：下标跟着值一起归并；左半的值出队时，右半已出队的个数就是它右侧更小数的增量。

思路

  • 答案要按原始下标落位，所以归并时 idx 数组跟着值一起换位，统计记在 cnt[原下标] 上。
  • 归并两段各自有序：右半的值 a[j] < a[i] 就先出队；轮到左半的 a[i] 出队时，右半已出队 j−(mid+1) 个，它们全部 < a[i] 且都在原数组里位于它右侧。
  • 相等时左半先出队（a[j] < a[i] 才跳），保证相等的右侧元素不计入。
  • 左半收尾时右半必已全出队，剩余元素一口气 + (r−mid)。

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public List<Integer> countSmaller(int[] nums) {5        int n = nums.length;6        int[] a = nums.clone();   // 不动入参：在副本上归并7        int[] idx = new int[n], cnt = new int[n];8        for (int i = 0; i < n; i++) idx[i] = i;9        // 值带着原始下标一起归并，统计才能落回原位10        mergeSort(a, idx, new int[n], new int[n], cnt, 0, n - 1);11        List<Integer> ans = new ArrayList<>(n);12        for (int c : cnt) ans.add(c);13        return ans;14    }15 16    // 归并排序 a[l..r]；idx 与 a 同步换位，cnt[原下标] 记右侧更小数17    private void mergeSort(int[] a, int[] idx, int[] ta, int[] tidx, int[] cnt, int l, int r) {18        if (l >= r) return;19        int mid = (l + r) >>> 1;20        mergeSort(a, idx, ta, tidx, cnt, l, mid);21        mergeSort(a, idx, ta, tidx, cnt, mid + 1, r);22        int i = l, j = mid + 1, k = l;23        while (i <= mid && j <= r) {24            if (a[j] < a[i]) { ta[k] = a[j]; tidx[k] = idx[j]; j++; }25            else {26                // a[i] 出队时，右半已有 j-(mid+1) 个更小的先出队，全记在它头上27                cnt[idx[i]] += j - mid - 1;28                ta[k] = a[i]; tidx[k] = idx[i]; i++;29            }30            k++;31        }32        // 左半剩下的：右半已全部出队，个个都更小33        while (i <= mid) { cnt[idx[i]] += r - mid; ta[k] = a[i]; tidx[k] = idx[i]; i++; k++; }34        while (j <= r) { ta[k] = a[j]; tidx[k] = idx[j]; j++; k++; }35        System.arraycopy(ta, l, a, l, r - l + 1);36        System.arraycopy(tidx, l, idx, l, r - l + 1);37    }38}
题目

给你一个整数数组 nums ，按要求返回一个新数组 counts 。数组 counts 有该性质： counts[i] 的值是  nums[i] 右侧小于 nums[i] 的元素的数量。

示例 1：

输入：nums = [5,2,6,1]
输出：[2,1,1,0] 
解释：
5 的右侧有 2 个更小的元素 (2 和 1)
2 的右侧仅有 1 个更小的元素 (1)
6 的右侧有 1 个更小的元素 (1)
1 的右侧有 0 个更小的元素

示例 2：

输入：nums = [-1]
输出：[0]

示例 3：

输入：nums = [-1,-1]
输出：[0,0]

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104
