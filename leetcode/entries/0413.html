413. 等差数列划分

一遍扫：cur 记以 i 结尾的等差子数组个数，差不变就加一（老段延长 + 新段），变了就清零，答案累加 cur。

思路

  • 等差子数组长度至少 3，所以从 i = 2 开始看：nums[i]−nums[i−1] == nums[i−1]−nums[i−2] 时才可能有以 i 结尾的等差段。
  • 差不变时 cur = cur + 1：以 i−1 结尾的每段延长一格还是等差（cur 段），再加上新落地的 [i−2, i−1, i] 一段。
  • 差变了就 cur = 0：任何以 i 结尾的子数组都不等差。
  • 每一步把 cur 加进答案——以每个位置结尾的段数互不重叠，加起来就是全部。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int numberOfArithmeticSlices(int[] nums) {3        int ans = 0, cur = 0;   // cur：以 i 结尾的等差子数组个数4        for (int i = 2; i < nums.length; i++) {5            // 差没变：以 i 结尾的段 = 以 i-1 结尾的段各延长一格 + 自己新开的一段6            if (nums[i] - nums[i - 1] == nums[i - 1] - nums[i - 2]) cur++;7            else cur = 0;8            ans += cur;9        }10        return ans;11    }12}
题目

如果一个数列 至少有三个元素 ，并且任意两个相邻元素之差相同，则称该数列为等差数列。

  • 例如，[1,3,5,7,9]、[7,7,7,7] 和 [3,-1,-5,-9] 都是等差数列。

给你一个整数数组 nums ，返回数组 nums 中所有为等差数组的 子数组 个数。

子数组 是数组中的一个连续序列。

示例 1：

输入：nums = [1,2,3,4]
输出：3
解释：nums 中有三个子等差数组：[1, 2, 3]、[2, 3, 4] 和 [1,2,3,4] 自身。

示例 2：

输入：nums = [1]
输出：0

提示：

  • 1 <= nums.length <= 5000
  • -1000 <= nums[i] <= 1000
