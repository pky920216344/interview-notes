排序后取中位数当目标值：所有数到中位数的绝对差之和就是最少操作数。

思路

  • 每次操作把一个数 ±1，相当于选一个目标值 t，答案 = Σ|a−t| 的最小值。
  • 这个和在中位数处取到最小：左右两侧的数个数最均衡（偶数个时取中间两个之一都行）。
  • 排序后直接取 nums[n/2]，逐个累加绝对差；用 long 累加防溢出，题面保证结果在 32 位内。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(log n)（排序栈深）
1import java.util.Arrays;2 3class Solution {4    public int minMoves2(int[] nums) {5        Arrays.sort(nums);6        // 目标值取中位数：所有数到它的绝对距离之和最小7        int mid = nums[nums.length / 2];8        long moves = 0;9        for (int x : nums) moves += Math.abs(x - mid);10        return (int) moves;11    }12}
题目

给你一个长度为 n 的整数数组 nums ，返回使所有数组元素相等需要的最小操作数。

在一次操作中，你可以使数组中的一个元素加 1 或者减 1 。

测试用例经过设计以使答案在 32 位 整数范围内。

示例 1：

输入：nums = [1,2,3]
输出：2
解释：
只需要两次操作（每次操作只能使一个元素加 1 或减 1）：
[1,2,3]  =>  [2,2,3]  =>  [2,2,2]

示例 2：

输入：nums = [1,10,2,9]
输出：16

提示：

  • n == nums.length
  • 1 <= nums.length <= 105
  • -109 <= nums[i] <= 109
