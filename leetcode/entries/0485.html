485. 最大连续 1 的个数

  • 简单
  • 频度 2
  • 模拟
  • 数组
  • 待提交

一遍扫描：遇 1 把当前连续长度 cur 加一并更新答案，遇 0 把 cur 归零重新数。

思路

  • 只需要「当前这段有多长」：cur 数到几，遇 1 就 cur++，遇 0 直接归零。
  • 每次延长后用 cur 更新 ans = max(ans, cur)，答案在扫描中顺手记下。
  • 空数组、全 0 自然得 0；全 1 时 cur 一路涨到 n。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int findMaxConsecutiveOnes(int[] nums) {3        int ans = 0, cur = 0;                     // cur：当前这段连续 1 的长度4        for (int x : nums) {5            if (x == 1) {6                cur++;7                ans = Math.max(ans, cur);         // 这段又变长了，随时更新答案8            } else {9                cur = 0;                          // 被 0 打断，重新数10            }11        }12        return ans;13    }14}
题目

给定一个二进制数组 nums ， 计算其中最大连续 1 的个数。

示例 1：

输入：nums = [1,1,0,1,1,1]
输出：3
解释：开头的两位和最后的三位都是连续 1 ，所以最大连续 1 的个数是 3.

示例 2:

输入：nums = [1,0,1,1,0,1]
输出：2

提示：

  • 1 <= nums.length <= 105
  • nums[i] 不是 0 就是 1.
