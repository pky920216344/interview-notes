1191. K 次串联后最大子数组之和

  • 中等
  • 频度 1
  • 动态规划
  • 前缀和/差分
  • 数组
  • 动态规划
  • 待提交

单份 Kadane + 全和 + 前/后缀最大：答案只在「单份内、跨两份、跨满 k 份」三种形态里取最大。

思路

  • 拼接数组里的最大子数组只有三种形态：完全在一份里（Kadane 的 best）、跨相邻两份（上一份后缀最大 + 下一份前缀最大）、跨更多份。
  • 多跨一份就多一整个 total：total > 0 时垫满 k 份最优，total ≤ 0 时跨两份就够，两个候选都算出来取 max 不吃亏。
  • k == 1 只能取单份内的 best；子数组允许为空，所以答案至少是 0。
  • 全程用 long 算准确值（最大约 10^14），最后对 10^9+7 取模。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int kConcatenationMaxSum(int[] arr, int k) {3        final int MOD = 1_000_000_007;4        long total = 0, cur = 0, best = 0;                 // best：单份内最大子数组和（允许空，至少 0）5        long preMax = Long.MIN_VALUE, sufMax = Long.MIN_VALUE;6        long pre = 0, suf = 0;7        for (int x : arr) {                                // 一趟同时算：Kadane、总和、前缀最大8            total += x;9            cur = Math.max(cur + x, x);10            best = Math.max(best, cur);11            pre += x;12            preMax = Math.max(preMax, pre);13        }14        for (int i = arr.length - 1; i >= 0; i--) {        // 后缀最大：从右往左再扫一趟15            suf += arr[i];16            sufMax = Math.max(sufMax, suf);17        }18        long ans = best;                                   // 形态一：完全在一份里19        if (k >= 2) {                                      // 多跨一份就多一整个 total20            ans = Math.max(ans, sufMax + preMax);                          // 形态二：跨相邻两份21            ans = Math.max(ans, sufMax + (k - 2) * total + preMax);        // 形态三：跨满 k 份22        }23        return (int) (ans % MOD);                          // ans ≥ 0，直接取模24    }25}
题目

给定一个整数数组 arr 和一个整数 k ，通过重复 k 次来修改数组。

例如，如果 arr = [1, 2] ， k = 3 ，那么修改后的数组将是 [1, 2, 1, 2, 1, 2] 。

返回修改后的数组中的最大的子数组之和。注意，子数组长度可以是 0，在这种情况下它的总和也是 0。

由于 结果可能会很大，需要返回结果对 109 + 7 取 模。

示例 1：

输入：arr = [1,2], k = 3
输出：9

示例 2：

输入：arr = [1,-2,1], k = 5
输出：2

示例 3：

输入：arr = [-1,-2], k = 7
输出：0

提示：

  • 1 <= arr.length <= 105
  • 1 <= k <= 105
  • -104 <= arr[i] <= 104
