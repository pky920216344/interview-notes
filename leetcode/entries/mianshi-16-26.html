单栈一遍扫描：加减把带符号的项压栈攒着，乘除优先级高、当场弹栈顶算完压回，最后整栈求和。

思路

  • 维护「当前数字 num」和「它前面等待生效的运算符 op」（初始 +）；扫到运算符或结尾时结算 num。
  • 结算规则：op 是 +/− 就把 ±num 压栈；是 *// 就弹出栈顶算完压回——乘除必须立刻做。
  • 把字符串结尾当虚拟运算符 #，最后一个数字才会被结算；空格直接跳过。
  • 栈里剩下的全是待加的项，最后求和。除法用 Java 截断语义：/ 前把项存成负数（如 -22/3=-7），结果才对。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int calculate(String s) {5        Deque<Integer> stack = new ArrayDeque<>();   // 栈里放「项」，乘除当场折进栈顶6        char op = '+';                               // 当前数字前面等待生效的运算符7        int num = 0;8        // i 走到 length 时用 '#' 当虚拟结尾，把最后一个数字结算掉9        for (int i = 0; i <= s.length(); i++) {10            char c = i < s.length() ? s.charAt(i) : '#';11            if (c == ' ') continue;12            if (c >= '0' && c <= '9') { num = num * 10 + (c - '0'); continue; }13            if (op == '+') stack.push(num);                        // 加减先入栈，最后一起加14            else if (op == '-') stack.push(-num);15            else if (op == '*') stack.push(stack.pop() * num);     // 乘除优先级高，立刻算16            else stack.push(stack.pop() / num);17            op = c;                                                // 记下新运算符等下一个数字18            num = 0;19        }20        int ans = 0;21        while (!stack.isEmpty()) ans += stack.pop();   // 栈里剩下的项全加起来22        return ans;23    }24}
题目

给定一个包含正整数、加(+)、减(-)、乘(*)、除(/)的算数表达式(括号除外)，计算其结果。

表达式仅包含非负整数，+， - ，*，/ 四种运算符和空格  。 整数除法仅保留整数部分。

示例 1：

输入："3+2*2"
输出：7

示例 2：

输入：" 3/2 "
输出：1

示例 3：

输入：" 3+5 / 2 "
输出：5

说明：

  • 你可以假设所给定的表达式都是有效的。
  • 请不要使用内置的库函数 eval。
