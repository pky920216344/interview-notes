1542. 找出最长的超赞子字符串

10 位奇偶掩码记前缀：两前缀掩码相同或恰差一位，中间子串就能重排成回文；哈希记首现取最长。

思路

  • 能重排成回文 ⇔ 奇数字符个数 ≤ 1；数字只有 0~9，用 10 位掩码记每个数字出现次数的奇偶。
  • 前缀掩码逐字符异或；子串 [j..i] 的奇偶 = pre[i+1] ^ pre[j]，所以查表 first[m]。
  • 同掩码（全成对）或恰差一位（一个落单）都合法，取 i+1-j 最大；10 个「差一位」逐个试。
  • first 只记每个掩码的首现下标（越早子串越长），空串掩码 0 在下标 0；ans 初始 1。

最优解

时间复杂度 O(10n)，空间复杂度 O(2^10)
1import java.util.Arrays;2 3class Solution {4    public int longestAwesome(String s) {5        // first[m]：前缀奇偶掩码 m 的最早位置，-2 表示没出现过6        int[] first = new int[1 << 10];7        Arrays.fill(first, -2);8        first[0] = 0;   // 空前缀：一个字符还没读9        int mask = 0, ans = 1;10        for (int i = 0; i < s.length(); i++) {11            // 读入 s[i]，翻转它的奇偶位12            mask ^= 1 << (s.charAt(i) - '0');13            // 全配对：与前缀掩码相同的最早位置配对，中间全成对14            if (first[mask] >= 0) ans = Math.max(ans, i + 1 - first[mask]);15            // 差一位：允许恰好一个数字落单16            for (int d = 0; d < 10; d++) {17                int j = first[mask ^ (1 << d)];18                if (j >= 0) ans = Math.max(ans, i + 1 - j);19            }20            // 只记首现：越早的前缀，将来配出的子串越长21            if (first[mask] == -2) first[mask] = i + 1;22        }23        return ans;24    }25}
题目

给你一个字符串 s 。请返回 s 中最长的 超赞子字符串 的长度。

「超赞子字符串」需满足满足下述两个条件：

  • 该字符串是 s 的一个非空子字符串
  • 进行任意次数的字符交换后，该字符串可以变成一个回文字符串

示例 1：

输入：s = "3242415"
输出：5
解释："24241" 是最长的超赞子字符串，交换其中的字符后，可以得到回文 "24142"

示例 2：

输入：s = "12345678"
输出：1

示例 3：

输入：s = "213123"
输出：6
解释："213123" 是最长的超赞子字符串，交换其中的字符后，可以得到回文 "231132"

示例 4：

输入：s = "00"
输出：2

提示：

  • 1 <= s.length <= 10^5
  • s 仅由数字组成
