按长度排序 + DP：dp[w] = 1 + 最长前身链长；前身 = w 删掉一个字符，直接哈希表查。

思路

  • 按长度从短到长排序，保证算 w 时它所有可能的前身都已算完。
  • 枚举 w 的 L 个「删掉一位」变体，哈希表查到的前身链长 +1 取最大。
  • dp[w] 存「以 w 结尾的最长链」，全局 ans 取最大值。
  • 前身必须「删恰好一个字符」——变体生成天然保证长度差 1，顺序不变。

图解

最优解

时间复杂度 O(n × L²)（L 为词长），空间复杂度 O(n × L)
1import java.util.*;2 3class Solution {4    public int longestStrChain(String[] words) {5        // 按长度从短到长：算到长词时，它的前身一定已经算完6        Arrays.sort(words, (a, b) -> a.length() - b.length());7        Map<String, Integer> dp = new HashMap<>();8        int ans = 0;9        for (String w : words) {10            int best = 1;11            // 枚举删掉一个字符的全部变体，查表取最长前身链12            for (int i = 0; i < w.length(); i++) {13                String prev = w.substring(0, i) + w.substring(i + 1);14                Integer d = dp.get(prev);15                if (d != null) best = Math.max(best, d + 1);16            }17            dp.put(w, best);18            ans = Math.max(ans, best);19        }20        return ans;21    }22}
题目

给出一个单词数组 words ，其中每个单词都由小写英文字母组成。

如果我们可以 不改变其他字符的顺序 ，在 wordA 的任何地方添加 恰好一个 字母使其变成 wordB ，那么我们认为 wordA 是 wordB 的 前身 。

  • 例如，"abc" 是 "abac" 的 前身 ，而 "cba" 不是 "bcad" 的 前身

词链是单词 [word_1, word_2, ..., word_k] 组成的序列，k >= 1，其中 word1 是 word2 的前身，word2 是 word3 的前身，依此类推。一个单词通常是 k == 1 的 单词链 。

从给定单词列表 words 中选择单词组成词链，返回 词链的 最长可能长度 。
 

示例 1：

输入：words = ["a","b","ba","bca","bda","bdca"]
输出：4
解释：最长单词链之一为 ["a","ba","bda","bdca"]

示例 2:

输入：words = ["xbc","pcxbcf","xb","cxbc","pcxbc"]
输出：5
解释：所有的单词都可以放入单词链 ["xb", "xbc", "cxbc", "pcxbc", "pcxbcf"].

示例 3:

输入：words = ["abcd","dbqca"]
输出：1
解释：字链["abcd"]是最长的字链之一。
["abcd"，"dbqca"]不是一个有效的单词链，因为字母的顺序被改变了。

提示：

  • 1 <= words.length <= 1000
  • 1 <= words[i].length <= 16
  • words[i] 仅由小写英文字母组成。
