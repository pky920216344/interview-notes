1249. 移除无效的括号

  • 中等
  • 频度 5
  • 栈
  • 栈
  • 字符串
  • 待提交

一遍扫描：栈存没配上对的「(」的下标；配不上的「)」当场标记必删，扫完栈里剩的「(」也删，其余原样保留。

思路

  • 栈里只放「还没配上对的 (」的下标；读到 ) 时栈非空就弹一个配对，空则当场标记这个 ) 必删。
  • 扫完后栈里剩下的 ( 全都没等到右括号，一并标记删除。
  • 没被标记的字符原样拼起来：字母一个不动，留下的括号都配对。
  • 删的个数正好 = 配不上对的括号数，所以是最少删除。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public String minRemoveToMakeValid(String s) {5        // 栈里存「还没配上对的 (」的下标6        Deque<Integer> stack = new ArrayDeque<>();7        boolean[] del = new boolean[s.length()];8        for (int i = 0; i < s.length(); i++) {9            char c = s.charAt(i);10            if (c == '(') {11                stack.push(i);12            } else if (c == ')') {13                // 有左括号可配就消掉一个，否则这个 ) 必删14                if (!stack.isEmpty()) stack.pop();15                else del[i] = true;16            }17        }18        // 扫完还留在栈里的 ( 都没等到右括号，一并删19        while (!stack.isEmpty()) del[stack.pop()] = true;20        // 没被标记的原样保留：字母一个不动，留下的括号都配对21        StringBuilder sb = new StringBuilder();22        for (int i = 0; i < s.length(); i++) {23            if (!del[i]) sb.append(s.charAt(i));24        }25        return sb.toString();26    }27}
题目

给你一个由 '('、')' 和小写字母组成的字符串 s。

你需要从字符串中删除最少数目的 '(' 或者 ')' （可以删除任意位置的括号)，使得剩下的「括号字符串」有效。

请返回任意一个合法字符串。

有效「括号字符串」应当符合以下 任意一条 要求：

  • 空字符串或只包含小写字母的字符串
  • 可以被写作 AB（A 连接 B）的字符串，其中 A 和 B 都是有效「括号字符串」
  • 可以被写作 (A) 的字符串，其中 A 是一个有效的「括号字符串」

示例 1：

输入：s = "lee(t(c)o)de)"
输出："lee(t(c)o)de"
解释："lee(t(co)de)" , "lee(t(c)ode)" 也是一个可行答案。

示例 2：

输入：s = "a)b(c)d"
输出："ab(c)d"

示例 3：

输入：s = "))(("
输出：""
解释：空字符串也是有效的

提示：

  • 1 <= s.length <= 105
  • s[i] 可能是 '('、')' 或英文小写字母
