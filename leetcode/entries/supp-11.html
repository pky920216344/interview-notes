补充题11. 翻转URL字符串里的单词

  • 中等
  • 频度 5
  • 双指针
  • 未经力扣验证

从右往左扫：r 跳过空格停在词尾，l 左扫到词首，整词收割进结果、词间补一个空格。

思路

  • 约定：输入是空格分隔的单词串，输出单词顺序反转、词间单个空格、无首尾空格。
  • r 从右往左先跳过空格（顺带处理多余空格），停在词尾；l 从词尾左扫到词首（l-1 是空格或到头）。
  • 整词 substring(l, r+1) 追加进 sb，词间补一个空格；r = l - 1 继续找下一个词。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    /**3     * 翻转 URL 字符串里的单词（codetop 补充题，无力扣页面，这里自定约定）：4     * 输入是空格分隔的单词串（如 URL 里的查询词）；返回单词顺序反转后的串，5     * 词间用单个空格分隔，首尾不留空格（输入若有多余空格也一并去掉）。6     */7    public String reverseWords(String s) {8        StringBuilder sb = new StringBuilder();9        // r 从右往左：跳过空格停在词尾，l 左扫到词首，整词收割10        int r = s.length() - 1;11        while (r >= 0) {12            while (r >= 0 && s.charAt(r) == ' ') r--;13            if (r < 0) break;14            int l = r;15            while (l > 0 && s.charAt(l - 1) != ' ') l--;16            if (sb.length() > 0) sb.append(' ');17            sb.append(s.substring(l, r + 1));18            r = l - 1;19        }20        return sb.toString();21    }22}
