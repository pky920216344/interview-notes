927. 三等分

  • 困难
  • 频度 1
  • 模拟
  • 数组
  • 数学
  • 待提交

每段含 ones/3 个 1；三段从各自首个 1 起对齐逐位比 len 位，通过即定出边界。

思路

  • 每段必须含 ones/3 个 1：不是 3 的倍数直接失败；全 0 任意切，返回 [0, n−1]。
  • 三段去前导零后必须完全相同：第三段是后缀（长 len = n − p3），三段各自的首个 1（第 1、k+1、2k+1 个）就是对齐锚点。
  • 从锚点起逐位比 len 位；通过则第一段截至 p1+len−1、第三段从 p2+len 起——前导零不影响值，多出的零塞给中间段和第三段开头。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] threeEqualParts(int[] arr) {3        int n = arr.length, ones = 0;4        for (int v : arr) ones += v;5        if (ones == 0) return new int[]{0, n - 1};    // 全 0：怎么切都相等6        if (ones % 3 != 0) return new int[]{-1, -1};  // 1 的个数分不成三等份7        int k = ones / 3;8        // 三段各自首个 1：第 1、k+1、2k+1 个 1；第三段是后缀，长度 len9        int p1 = -1, p2 = -1, p3 = -1, seen = 0;10        for (int t = 0; t < n; t++) {11            if (arr[t] == 1) {12                seen++;13                if (seen == 1) p1 = t;14                if (seen == k + 1) p2 = t;15                if (seen == 2 * k + 1) p3 = t;16            }17        }18        // 三段去前导零后必须逐位相同：从各自首个 1 起比 len 位19        int len = n - p3;20        for (int d = 0; d < len; d++) {21            if (arr[p1 + d] != arr[p3 + d] || arr[p2 + d] != arr[p3 + d]) {22                return new int[]{-1, -1};23            }24        }25        // 第一段截至 p1+len−1，第三段从 p2+len 起，多出的前导零不影响值26        return new int[]{p1 + len - 1, p2 + len};27    }28}
题目

给定一个由 0 和 1 组成的数组 arr ，将数组分成  3 个非空的部分 ，使得所有这些部分表示相同的二进制值。

如果可以做到，请返回任何 [i, j]，其中 i+1 < j，这样一来：

  • arr[0], arr[1], ..., arr[i] 为第一部分；
  • arr[i + 1], arr[i + 2], ..., arr[j - 1] 为第二部分；
  • arr[j], arr[j + 1], ..., arr[arr.length - 1] 为第三部分。
  • 这三个部分所表示的二进制值相等。

如果无法做到，就返回 [-1, -1]。

注意，在考虑每个部分所表示的二进制时，应当将其看作一个整体。例如，[1,1,0] 表示十进制中的 6，而不会是 3。此外，前导零也是被允许的，所以 [0,1,1] 和 [1,1] 表示相同的值。

示例 1：

输入：arr = [1,0,1,0,1]
输出：[0,3]

示例 2：

输入：arr = [1,1,0,1,1]
输出：[-1,-1]

示例 3:

输入：arr = [1,1,0,0,1]
输出：[0,2]

提示：

  • 3 <= arr.length <= 3 * 104
  • arr[i] 是 0 或 1
