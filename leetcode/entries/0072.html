72. 编辑距离

  • 困难
  • 频度 208
  • 动态规划
  • 字符串
  • 动态规划
  • 力扣已通过

DP：dp[i][j] 是前缀变前缀的最少步数；字符相等取左上，不等取左上、上、左的最小值 + 1；滚动成一行。

思路

  • dp[i][j]：word1 前 i 个字符变成 word2 前 j 个字符的最少操作数。边界：第 0 行 dp[0][j] = j（全插入），第 0 列 dp[i][0] = i（全删除）。
  • 末尾字符相等：dp[i][j] = dp[i-1][j-1]（左上，不用操作）；不相等：dp[i][j] = 1 + min(左上, 上, 左)，分别是替换、删除、插入。
  • 图解画的是完整二维表，代码把它压成一行：dp[j] 是当前行，diag 暂存左上角，up 暂存上方，dp[j-1] 是刚算好的左边。
  • 编辑距离对两个串对称，短串放第二个（递归交换一次），dp 数组只要 min(m, n) + 1 格。

最优解

时间复杂度 O(mn)，空间复杂度 O(min(m, n))
1class Solution {2    public int minDistance(String word1, String word2) {3        // 短串放第二个，dp 数组就只有 min(m, n) + 1 格4        if (word1.length() < word2.length()) {5            return minDistance(word2, word1);6        }7        int m = word1.length(), n = word2.length();8        // dp[j]：word1 前 i 个字符变成 word2 前 j 个字符的最少步数9        // i 是当前行，上一行的值被逐格覆盖10        int[] dp = new int[n + 1];11        for (int j = 0; j <= n; j++) dp[j] = j;   // 第 0 行：全靠插入12        for (int i = 1; i <= m; i++) {13            int diag = dp[0];     // 左上角 dp[i-1][j-1]14            dp[0] = i;            // 第 0 列：全靠删除15            for (int j = 1; j <= n; j++) {16                int up = dp[j];   // 上方 dp[i-1][j]，被覆盖前先存下17                if (word1.charAt(i - 1) == word2.charAt(j - 1)) dp[j] = diag;18                else dp[j] = 1 + Math.min(diag, Math.min(up, dp[j - 1]));19                diag = up;20            }21        }22        return dp[n];23    }24}
题目

给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数  。

你可以对一个单词进行如下三种操作：

  • 插入一个字符
  • 删除一个字符
  • 替换一个字符

示例 1：

输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')

示例 2：

输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')

提示：

  • 0 <= word1.length, word2.length <= 500
  • word1 和 word2 由小写英文字母组成
