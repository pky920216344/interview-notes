984. 不含 AAA 或 BBB 的字符串

  • 中等
  • 频度 3
  • 贪心
  • 贪心
  • 字符串
  • 待提交

贪心逐个写字母：结尾已连两个就强制换另一种，否则谁剩得多写谁，多的一方先被拉平。

思路

  • 每一步看结尾：若已是 aa（或 bb），再写同款就违规，强制写另一个。
  • 否则「谁剩得多写谁」：保证数量多的字母优先耗散，不会在结尾堆出三个。
  • 正确性关键：只有剩得多的一方才会连写两个，而它连写两个后立刻被强制换边，交替消化。
  • 题目保证有解（即 a ≤ 2(b+1) 且 b ≤ 2(a+1)），此贪心在有解时必然构造成功。

最优解

时间复杂度 O(a + b)，空间复杂度 O(1)（不计输出）
1class Solution {2    public String strWithout3a3b(int a, int b) {3        StringBuilder sb = new StringBuilder();4        while (a > 0 || b > 0) {5            int n = sb.length();6            boolean writeA;7            if (n >= 2 && sb.charAt(n - 1) == sb.charAt(n - 2)) {8                writeA = sb.charAt(n - 1) == 'b';   // 结尾已连两个：只能写另一种字母9            } else {10                writeA = a >= b;   // 否则谁剩得多就写谁，多的一方先被拉平11            }12            if (writeA) { sb.append('a'); a--; } else { sb.append('b'); b--; }13        }14        return sb.toString();15    }16}
题目

给定两个整数 a 和 b ，返回 任意 字符串 s ，要求满足：

  • s 的长度为 a + b，且正好包含 a 个 'a' 字母与 b 个 'b' 字母；
  • 子串 'aaa' 没有出现在 s 中；
  • 子串 'bbb' 没有出现在 s 中。

示例 1：

输入：a = 1, b = 2
输出："abb"
解释："abb", "bab" 和 "bba" 都是正确答案。

示例 2：

输入：a = 4, b = 1
输出："aabaa"

提示：

  • 0 <= a, b <= 100
  • 对于给定的 a 和 b，保证存在满足要求的 s
