剑指 Offer 62. 破冰游戏

  • 频度 32
  • 数学
  • 递归
  • 数学
  • 力扣已通过

约瑟夫环倒推：f(1)=0；i 人圈的答案 = (i-1 人圈的答案 + target) mod i，一遍循环推回 num。

思路

  • 正面模拟要 O(num·target)；倒着推只要一遍循环：已知 i-1 人圈的幸存者编号，求 i 人圈的。
  • i 人圈先淘汰第 target 个（编号 (target-1)%i），剩下的人重新编号后就是 i-1 人圈。
  • 新旧编号相差 target：旧编号 = (新编号 + target) mod i，所以 f(i) = (f(i-1) + target) % i。
  • f(1) = 0 起步，循环里只有一行，背这一行就够。

1class Solution {2    public int iceBreakingGame(int num, int target) {3        // 约瑟夫环倒推：f(i) 是 i 人圈里最后留下者的编号4        int ans = 0;  // f(1) = 0：只剩 1 人时留下的必是 0 号5        for (int i = 2; i <= num; i++) {6            // i 人圈先淘汰 (target-1)%i 号，剩 i-1 人的答案整体右移 target 位7            ans = (ans + target) % i;8        }9        return ans;10    }11}
题目

社团共有 num 位成员参与破冰游戏，编号为 0 ~ num-1。成员们按照编号顺序围绕圆桌而坐。社长抽取一个数字 target，从 0 号成员起开始计数，排在第 target 位的成员离开圆桌，且成员离开后从下一个成员开始计数。请返回游戏结束时最后一位成员的编号。

示例 1：

输入：num = 7, target = 4
输出：1

示例 2：

输入：num = 12, target = 5
输出：0

提示：

  • 1 <= num <= 10^5
  • 1 <= target <= 10^6
