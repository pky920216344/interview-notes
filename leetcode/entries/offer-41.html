双堆对半分：左大顶堆装较小一半、右小顶堆装较大一半，大小差 ≤ 1；中位数从两堆顶拼出来。

思路

  • add：先入左堆，再把左堆最大值挪到右堆——这一步保证左堆的数都不大于右堆的数。
  • 若右堆比左堆多，再挪一个回左堆：两堆大小差永远 ≤ 1，且约定左堆可以多 1 个。
  • 中位数：奇数个取左堆顶；偶数个取两堆顶的平均。

时间复杂度 每次 add O(log n)，查询 O(1)，空间复杂度 O(n)
1import java.util.*;2 3class MedianFinder {4    // left 大顶堆装较小的一半，right 小顶堆装较大的一半5    private final PriorityQueue<Integer> left = new PriorityQueue<>(Collections.reverseOrder());6    private final PriorityQueue<Integer> right = new PriorityQueue<>();7 8    public MedianFinder() {9    }10 11    public void addNum(int num) {12        // 先进左堆，再把左堆最大的挪给右堆：左堆的数从此都不大于右堆13        left.offer(num);14        right.offer(left.poll());15        // 右堆多了就挪一个回左堆：两堆大小差永远不超过 116        if (right.size() > left.size()) left.offer(right.poll());17    }18 19    public double findMedian() {20        // 奇数个：左堆顶（较小一半的最大值）就是中位数21        return left.size() > right.size() ? left.peek() : (left.peek() + (double) right.peek()) / 2;22    }23}
题目

中位数 是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

例如，
[2,3,4] 的中位数是 3
[2,3] 的中位数是 (2 + 3) / 2 = 2.5
设计一个支持以下两种操作的数据结构：

  • void addNum(int num) - 从数据流中添加一个整数到数据结构中。
  • double findMedian() - 返回目前所有元素的中位数。

示例 1：

输入：
["MedianFinder","addNum","addNum","findMedian","addNum","findMedian"]
[[],[1],[2],[],[3],[]]
输出：[null,null,null,1.50000,null,2.00000]

示例 2：

输入：
["MedianFinder","addNum","findMedian","addNum","findMedian"]
[[],[2],[],[3],[]]
输出：[null,null,2.00000,null,2.50000]

提示：

  • 最多会对 addNum、findMedian 进行 50000 次调用。
