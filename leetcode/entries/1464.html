1464. 数组中两元素的最大乘积

  • 简单
  • 频度 2
  • 模拟
  • 数组
  • 排序
  • 堆（优先队列）
  • 待提交

一遍扫维护最大 a 与次大 b，答案是 (a-1)×(b-1)。

思路

  • 值全为正：两数越大乘积越大，直接取最大的两个值，与下标无关（下标不同、值可以相同）。
  • 扫描更新规则：x > a 先把旧最大降级给 b 再换 a；否则 x > b 才更新 b。
  • 必须用 else if：同一个元素不能同时充当最大和次大（如 [5,4,9] 会错算成 9×9）。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxProduct(int[] nums) {3        // a 记最大值，b 记次大值；两个下标不同，值可以相等4        int a = 0, b = 0;5        for (int x : nums) {6            if (x > a) {7                b = a;   // 旧的最大降级为次大8                a = x;9            } else if (x > b) {10                b = x;11            }12        }13        // 值全 ≥ 1：(最大-1)×(次大-1) 就是答案14        return (a - 1) * (b - 1);15    }16}
题目

给你一个整数数组 nums。

请你选择数组的两个 不同 下标 i 和 j，

返回 (nums[i] - 1) * (nums[j] - 1) 的 最大值。

示例 1：

输入：nums = [3,4,5,2]
输出：12 
解释：如果选择下标 i=1 和 j=2（下标从 0 开始），则可以获得最大值，(nums[1]-1)*(nums[2]-1) = (4-1)*(5-1) = 3*4 = 12 。

示例 2：

输入：nums = [1,5,4,5]
输出：16
解释：选择下标 i=1 和 j=3（下标从 0 开始），则可以获得最大值 (5-1)*(5-1) = 16 。

示例 3：

输入：nums = [3,7]
输出：12

提示：

  • 2 <= nums.length <= 500
  • 1 <= nums[i] <= 10^3
