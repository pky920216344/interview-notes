状压 DP：dp[mask] = 把 mask 这些元素分成合法子集的最小不兼容性和；下一个子集强制包含 mask 最低位元素，枚举它所在的子集转移。

思路

  • 先判不可行：某值出现次数 > k 直接返回 −1（每个子集内不能重复）。
  • 把 k 个子集一个一个装：dp[mask] 表示已把 mask 里的元素分完；转移时强制包含 mask 的最低位元素，枚举含它的合法子集（大小 n/k、值互不相同），避免同一划分被数多遍。
  • 子集代价 = 最大值 − 最小值；数组排过序，就是最高位与最低位对应的值之差。
  • 值互不相同用「值位掩码」判：vmask[s] 的位数 = 子集大小。

最优解

时间复杂度 O(3^n)，空间复杂度 O(2^n)
1import java.util.*;2 3class Solution {4    public int minimumIncompatibility(int[] nums, int k) {5        int n = nums.length, size = n / k;6        int[] cnt = new int[n + 1];7        for (int v : nums) {8            // 子集内不能有重复值 ⇒ 一个值最多进 k 个子集9            if (++cnt[v] > k) return -1;10        }11        if (size == 1) return 0;   // 每个子集只有一个数，不兼容性都是 012        int[] a = nums.clone();13        Arrays.sort(a);14        int full = (1 << n) - 1;15        // vmask[m]：子集 m 里出现过的值的位掩码；值都不同 ⇔ vmask 的位数 = 子集大小16        int[] vmask = new int[full + 1];17        for (int m = 1; m <= full; m++) {18            int low = m & -m;19            vmask[m] = vmask[m ^ low] | (1 << a[Integer.numberOfTrailingZeros(low)]);20        }21        int[] dp = new int[full + 1];22        Arrays.fill(dp, -1);       // -1 = 这些元素无法被合法划分23        dp[0] = 0;24        for (int m = 1; m <= full; m++) {25            if (Integer.bitCount(m) % size != 0) continue;26            int low = m & -m;      // 下一个子集必须含最低位元素，划分才不会重复计数27            int rest = m ^ low;28            int best = Integer.MAX_VALUE;29            for (int s2 = rest; ; s2 = (s2 - 1) & rest) {30                int s = s2 | low;31                if (Integer.bitCount(s) == size && Integer.bitCount(vmask[s]) == size) {32                    int prev = dp[m ^ s];33                    if (prev >= 0) {34                        // 升序数组里：最高位=最大值，最低位=最小值35                        int cost = a[31 - Integer.numberOfLeadingZeros(s)] - a[Integer.numberOfTrailingZeros(s)];36                        best = Math.min(best, prev + cost);37                    }38                }39                if (s2 == 0) break;40            }41            if (best < Integer.MAX_VALUE) dp[m] = best;42        }43        return dp[full];44    }45}
题目

给你一个整数数组 nums​​​ 和一个整数 k 。你需要将这个数组划分到 k 个相同大小的子集中，使得同一个子集里面没有两个相同的元素。

一个子集的 不兼容性 是该子集里面最大值和最小值的差。

请你返回将数组分成 k 个子集后，各子集 不兼容性 的 和 的 最小值 ，如果无法分成分成 k 个子集，返回 -1 。

子集的定义是数组中一些数字的集合，对数字顺序没有要求。

示例 1：

输入：nums = [1,2,1,4], k = 2
输出：4
解释：最优的分配是 [1,2] 和 [1,4] 。
不兼容性和为 (2-1) + (4-1) = 4 。
注意到 [1,1] 和 [2,4] 可以得到更小的和，但是第一个集合有 2 个相同的元素，所以不可行。

示例 2：

输入：nums = [6,3,8,1,3,1,2,2], k = 4
输出：6
解释：最优的子集分配为 [1,2]，[2,3]，[6,8] 和 [1,3] 。
不兼容性和为 (2-1) + (3-2) + (8-6) + (3-1) = 6 。

示例 3：

输入：nums = [5,3,3,6,3,3], k = 3
输出：-1
解释：没办法将这些数字分配到 3 个子集且满足每个子集里没有相同数字。

提示：

  • 1 <= k <= nums.length <= 16
  • nums.length 能被 k 整除。
  • 1 <= nums[i] <= nums.length
