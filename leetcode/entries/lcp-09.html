LCP 09. 最小跳跃次数

  • 广度优先搜索
  • 线段树
  • 数组
  • 动态规划
  • 待提交

逐层 BFS：从每个已到点向右试跳 jump[i]；「向左」能到的位置是一个前缀，用 left 指针一次补齐，整体 O(n)。

思路

  • 在 i 处可右跳 i+jump[i]、也可左跳到任意 0..i-1——所以同层所有位置的左可达并集是 [0, 最大 i)。
  • BFS 按层扩展；left 记录「还没因向左入过队」的最左下标：处理 i 时把 [left, i) 一次补入队，left 只进不退。
  • 向右目标 r = i+jump[i] 没去过才入队；r ≥ n 说明这一跳直接弹出机器，答案 = 当前层数 + 1。
  • 每个位置至多入队一次、left 单调右移，总复杂度 O(n)，扛得住 n = 10^6。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int minJump(int[] jump) {5        int n = jump.length;6        Deque<Integer> q = new ArrayDeque<>();7        boolean[] vis = new boolean[n];8        q.offer(0);9        vis[0] = true;10        int ans = 0, left = 0;   // left：向左还没补入队过的最左下标，[0,left) 都已入过队11        while (!q.isEmpty()) {12            int sz = q.size();13            for (int s = 0; s < sz; s++) {14                int i = q.poll();15                int r = i + jump[i];16                if (r >= n) return ans + 1;   // 向右这一跳直接弹出机器17                if (!vis[r]) { vis[r] = true; q.offer(r); }18                // 同层任何位置向左都能到 i 左边：把 [left, i) 里没入过队的一次补齐19                while (left < i) {20                    if (!vis[left]) { vis[left] = true; q.offer(left); }21                    left++;22                }23            }24            ans++;25        }26        return ans;27    }28}
题目

为了给刷题的同学一些奖励，力扣团队引入了一个弹簧游戏机。游戏机由 N 个特殊弹簧排成一排，编号为 0 到 N-1。初始有一个小球在编号 0 的弹簧处。若小球在编号为 i 的弹簧处，通过按动弹簧，可以选择把小球向右弹射 jump[i] 的距离，或者向左弹射到任意左侧弹簧的位置。也就是说，在编号为 i 弹簧处按动弹簧，小球可以弹向 0 到 i-1 中任意弹簧或者 i+jump[i] 的弹簧（若 i+jump[i]>=N ，则表示小球弹出了机器）。小球位于编号 0 处的弹簧时不能再向左弹。

为了获得奖励，你需要将小球弹出机器。请求出最少需要按动多少次弹簧，可以将小球从编号 0 弹簧弹出整个机器，即向右越过编号 N-1 的弹簧。

示例 1：

输入：jump = [2, 5, 1, 1, 1, 1]

输出：3

解释：小 Z 最少需要按动 3 次弹簧，小球依次到达的顺序为 0 -> 2 -> 1 -> 6，最终小球弹出了机器。

限制：

  • 1 <= jump.length <= 10^6
  • 1 <= jump[i] <= 10000
