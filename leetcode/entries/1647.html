1647. 字符频次唯一的最小删除次数

  • 中等
  • 频度 1

  • 贪心
  • 哈希表
  • 字符串
  • 排序
  • 待提交

频次降序扫一遍：右边的频次已定，左边撞车就压到「右边减一」，删掉的个数累加。

思路

  • 只有 26 种字符：先数频次，再排序（升序，最大在末尾）。
  • 从次大到小扫：cnt[i+1] 已是最终值，cnt[i] 若不小于它就压到 max(cnt[i+1]−1, 0)，差值计入答案。
  • 频次 0 可以重复——删光的字符不算冲突，所以 target 取 max(·, 0) 即可。
  • 贪心最优：保留的频次越高、删得越少，压到「右边减一」已是能保留的最大值。

最优解

时间复杂度 O(n + 26 log 26)，空间复杂度 O(26)
1import java.util.*;2 3class Solution {4    public int minDeletions(String s) {5        int[] cnt = new int[26];6        for (int i = 0; i < s.length(); i++) cnt[s.charAt(i) - 'a']++;7        Arrays.sort(cnt);                     // 升序，最大的在末尾8        int del = 0;9        // 从次大到小扫：右边的最终频次已定，左边撞车就压到「右边减一」，删掉的计入 del10        for (int i = 24; i >= 0; i--) {11            if (cnt[i] >= cnt[i + 1]) {12                int target = Math.max(cnt[i + 1] - 1, 0);13                del += cnt[i] - target;14                cnt[i] = target;15            }16        }17        return del;18    }19}
题目

如果字符串 s 中 不存在 两个不同字符 频次 相同的情况，就称 s 是 优质字符串 。

给你一个字符串 s，返回使 s 成为 优质字符串 需要删除的 最小 字符数。

字符串中字符的 频次 是该字符在字符串中的出现次数。例如，在字符串 "aab" 中，'a' 的频次是 2，而 'b' 的频次是 1 。

示例 1：

输入：s = "aab"
输出：0
解释：s 已经是优质字符串。

示例 2：

输入：s = "aaabbbcc"
输出：2
解释：可以删除两个 'b' , 得到优质字符串 "aaabcc" 。
另一种方式是删除一个 'b' 和一个 'c' ，得到优质字符串 "aaabbc" 。

示例 3：

输入：s = "ceabaacb"
输出：2
解释：可以删除两个 'c' 得到优质字符串 "eabaab" 。
注意，只需要关注结果字符串中仍然存在的字符。（即，频次为 0 的字符会忽略不计。）

提示：

  • 1 <= s.length <= 105
  • s 仅含小写英文字母
