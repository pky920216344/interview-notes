记忆化 DFS：dfs(i,j) = 从该格出发的最长递增链，四个方向只走严格更大的格子，结果缓存进 memo，全局取最大。

思路

  • dfs(i, j)：向四个方向试探，只走严格更大的格子，本格链长 = 邻格链长 + 1 的最大者，至少为 1。
  • 沿路值严格递增，走不回头也不成环，所以不需要 visited 数组。
  • memo[i][j] 缓存结果，0 表示没算过（算过的至少是 1）；命中直接返回，每格只真算一次。
  • 外层把每个格子都当起点跑一遍 dfs，答案取全局最大值。

时间复杂度 O(mn)，空间复杂度 O(mn)
1import java.util.*;2 3class Solution {4    private int[][] memo;5    private int[][] grid;6    private static final int[][] DIRS = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};7 8    public int longestIncreasingPath(int[][] matrix) {9        grid = matrix;10        int m = matrix.length, n = matrix[0].length;11        memo = new int[m][n];   // 0 = 还没算过；算过的至少是 112        int ans = 0;13        for (int i = 0; i < m; i++) {14            for (int j = 0; j < n; j++) {15                ans = Math.max(ans, dfs(i, j));16            }17        }18        return ans;19    }20 21    // dfs(i, j)：从该格出发的最长递增路径长度22    // 沿路严格变大，走不回头也不成环，无需 visited23    private int dfs(int i, int j) {24        if (memo[i][j] != 0) return memo[i][j];   // 记忆化：算过直接返回25        int best = 1;                             // 路径至少含自己这一格26        for (int[] d : DIRS) {27            int x = i + d[0], y = j + d[1];28            if (x < 0 || x >= grid.length || y < 0 || y >= grid[0].length) continue;29            if (grid[x][y] <= grid[i][j]) continue;   // 只能走向严格更大的格子30            best = Math.max(best, dfs(x, y) + 1);31        }32        return memo[i][j] = best;33    }34}
题目

给定一个 m x n 整数矩阵 matrix ，找出其中 最长递增路径 的长度。

对于每个单元格，你可以往上，下，左，右四个方向移动。 你 不能 在 对角线 方向上移动或移动到 边界外（即不允许环绕）。

示例 1：

输入：matrix = [[9,9,4],[6,6,8],[2,1,1]]
输出：4 
解释：最长递增路径为 [1, 2, 6, 9]。

示例 2：

输入：matrix = [[3,4,5],[3,2,6],[2,2,1]]
输出：4 
解释：最长递增路径是 [3, 4, 5, 6]。注意不允许在对角线方向上移动。

示例 3：

输入：matrix = [[1]]
输出：1

提示：

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 200
  • 0 <= matrix[i][j] <= 231 - 1
