贡献法 + 单调栈：每个元素当「最小值」时数出左右可选起终点数，贡献 = 值 × 左 × 右，求和取模。

思路

  • 不枚举子数组，改算每个元素的贡献：以 arr[i] 为最小值的子数组个数 = 左可选起点数 × 右可选终点数。
  • 单调栈一次求出两侧边界：弹栈时，右边界 = 当前下标 i（右边第一个严格更小），左边界 = 新栈顶（左边第一个≤ 它的）。
  • 一侧严格一侧非严格，重复值不会把同一子数组算两次（平局归左边的元素）。
  • i == n 时补哨兵 0 清空栈；贡献可能到 3e4×3e4×3e4，用 long 乘再取模 1e9+7。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int sumSubarrayMins(int[] arr) {3        int n = arr.length;4        long ans = 0;5        int[] stack = new int[n + 1];6        int top = -1;7        // i == n 时补一个比谁都小的哨兵 0，把栈里剩下的元素全部结算掉8        for (int i = 0; i <= n; i++) {9            int cur = i == n ? 0 : arr[i];10            // cur 更小：栈顶元素「当最小值」的子数组已经到头，弹栈结算11            while (top >= 0 && cur < arr[stack[top]]) {12                int mid = stack[top--];13                // 左边界 = 新栈顶（≤ arr[mid]），右边界 = i（< arr[mid]）：一侧非严格一侧严格，不重不漏14                int left = top < 0 ? -1 : stack[top];15                // 以 arr[mid] 为最小值：左可选 mid-left 种起点 × 右可选 i-mid 种终点16                long cnt = (long) (mid - left) * (i - mid);17                ans = (ans + arr[mid] * cnt) % 1_000_000_007L;18            }19            stack[++top] = i;20        }21        return (int) ans;22    }23}
题目

给定一个整数数组 arr，找到 min(b) 的总和，其中 b 的范围为 arr 的每个（连续）子数组。

由于答案可能很大，因此 返回答案模 10^9 + 7 。

示例 1：

输入：arr = [3,1,2,4]
输出：17
解释：
子数组为[3]，[1]，[2]，[4]，[3,1]，[1,2]，[2,4]，[3,1,2]，[1,2,4]，[3,1,2,4]。 
最小值为 3，1，2，4，1，1，2，1，1，1，和为 17。

示例 2：

输入：arr = [11,81,94,43,3]
输出：444

提示：

  • 1 <= arr.length <= 3 * 104
  • 1 <= arr[i] <= 3 * 104
