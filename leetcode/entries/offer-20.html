剑指 Offer 20. 有效数字

  • 模拟

  • 待提交

掐掉首尾空格后逐字符扫：符号只能在段首，点只能在 e 前且最多一个，e 最多一个且前后都得有数字。

思路

  • 先掐掉首尾空格；中间再出现空格或别的字符直接判非法。全空格（或空串）也是 false。
  • 用三个开关边扫边查：num（当前段是否出现过数字）、dot（小数点只能在 e 前且最多一个）、exp（e/E 最多一个）。
  • 符号 +/- 只能出现在「段首」：e 前主体的开头，或 e 后指数的开头（用 segStart 记录段起点）。
  • 结尾只需 return num：遇到 e 时把 num 重置，于是「有 e 看指数段、没有 e 看主体段」统一成同一个判断。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean validNumber(String s) {3        int i = 0, j = s.length() - 1;4        while (i <= j && s.charAt(i) == ' ') i++;        // 掐掉首部空格5        while (i <= j && s.charAt(j) == ' ') j--;        // 掐掉尾部空格6        if (i > j) return false;                         // 全是空格（或空串）不是数7        boolean num = false, dot = false, exp = false;   // num：当前段里有没有数字8        int segStart = i;                                // 当前段起点：符号只允许出现在这里9        for (; i <= j; i++) {10            char c = s.charAt(i);11            if (c >= '0' && c <= '9') num = true;12            else if (c == '+' || c == '-') {13                if (i != segStart) return false;         // 符号只能在段首14            } else if (c == '.') {15                if (exp || dot) return false;            // 小数点只能在 e 前，且最多一个16                dot = true;17            } else if (c == 'e' || c == 'E') {18                if (exp || !num) return false;           // e 最多一个，且前面必须有数字19                exp = true;20                num = false;                             // 指数段重新要求至少一位数字21                segStart = i + 1;22            } else return false;                         // 其余字符一律非法23        }24        return num;                                      // 有 e 看指数段有没有数字，没有就看主体25    }26}
题目

有效数字（按顺序）可以分成以下几个部分：

  1. 若干空格
  2. 一个 小数 或者 整数
  3. （可选）一个 'e' 或 'E' ，后面跟着一个 整数
  4. 若干空格

小数（按顺序）可以分成以下几个部分：

  1. （可选）一个符号字符（'+' 或 '-'）
  2. 下述格式之一：
    1. 至少一位数字，后面跟着一个点 '.'
    2. 至少一位数字，后面跟着一个点 '.' ，后面再跟着至少一位数字
    3. 一个点 '.' ，后面跟着至少一位数字

整数（按顺序）可以分成以下几个部分：

  1. （可选）一个符号字符（'+' 或 '-'）
  2. 至少一位数字

部分有效数字列举如下：["2", "0089", "-0.1", "+3.14", "4.", "-.9", "2e10", "-90E3", "3e+7", "+6e-1", "53.5e93", "-123.456e789"]

部分无效数字列举如下：["abc", "1a", "1e", "e3", "99e2.5", "--6", "-+3", "95a54e53"]

给你一个字符串 s ，如果 s 是一个 有效数字 ，请返回 true 。

示例 1：

输入：s = "0"
输出：true

示例 2：

输入：s = "e"
输出：false

示例 3：

输入：s = "."
输出：false

提示：

  • 1 <= s.length <= 20
  • s 仅含英文字母（大写和小写），数字（0-9），加号 '+' ，减号 '-' ，空格 ' ' 或者点 '.' 。
