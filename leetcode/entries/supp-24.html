补充题24. 双栈排序

  • 中等
  • 频度 8
  • 图算法
  • 广度优先搜索
  • 栈
  • 未经力扣验证

冲突图二染色：i<j、a[i]<a[j] 且 j 后面还有比 a[i] 小的数，这两个数被迫同栈却后大先出，必须分居两栈；染得出色就能排好。

思路

  • 同一个栈里先进的在下面、后出的：想升序出栈，被迫同时在场的两个数必须「后小前大」。
  • i<j 且 a[i]<a[j] 时，若 j 之后还有比 a[i] 小的数，a[i] 在 a[j] 进栈前弹不掉（更小的还没出），被迫同场却后大先出 → 冲突，分居两栈（用 suffMin 后缀最小值 O(n²) 建边）。
  • 冲突图 BFS 二染色：染出奇环即无解；染成功后按颜色进栈、能弹就弹，栈内自然「上小下大」，必能排成 1..n。

1import java.util.*;2 3/**4 * codetop 补充题：双栈排序（力扣上无对应页面，本地验证）。5 * nums 是 1..n 的一个排列：元素按给定顺序依次进栈（进 a、b 任一个），6 * 任意时刻可以弹出任一栈的栈顶；问能否让出栈序列恰好是 1,2,…,n。7 * 可行 ⟺ 冲突图可二染色（染色成功后按颜色模拟，栈内自然保持上小下大）。8 */9class Solution {10    public boolean canSort(int[] nums) {11        int n = nums.length;12        // suffMin[j] = min(nums[j..n-1])：j 及之后还会来的最小值13        int[] suffMin = new int[n + 1];14        suffMin[n] = Integer.MAX_VALUE;15        for (int j = n - 1; j >= 0; j--) suffMin[j] = Math.min(nums[j], suffMin[j + 1]);16        // 冲突：i<j 且 nums[i]<nums[j] 且 j 之后还有比 nums[i] 小的数——17        // nums[i] 在 nums[j] 进栈前弹不掉（还有更小的没出），被迫同栈却后大先出，只能分居两栈18        List<List<Integer>> adj = new ArrayList<>();19        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());20        for (int j = 1; j < n; j++) {21            for (int i = 0; i < j; i++) {22                if (nums[i] < nums[j] && suffMin[j + 1] < nums[i]) {23                    adj.get(i).add(j);24                    adj.get(j).add(i);25                }26            }27        }28        // BFS 二染色：0/1 两色对应两个栈，染出奇环就无解29        int[] color = new int[n];30        Arrays.fill(color, -1);31        for (int s = 0; s < n; s++) {32            if (color[s] >= 0) continue;33            color[s] = 0;34            Queue<Integer> q = new ArrayDeque<>();35            q.add(s);36            while (!q.isEmpty()) {37                int u = q.poll();38                for (int v : adj.get(u)) {39                    if (color[v] < 0) { color[v] = color[u] ^ 1; q.add(v); }40                    else if (color[v] == color[u]) return false;41                }42            }43        }44        // 按染色模拟：能弹就弹，再把 x 压进自己颜色的栈（染色合法时栈顶必比它大）45        Deque<Integer> a = new ArrayDeque<>(), b = new ArrayDeque<>();46        int need = 1;47        for (int i = 0; i < n; i++) {48            need = drain(a, b, need);49            (color[i] == 0 ? a : b).push(nums[i]);50        }51        need = drain(a, b, need);52        return need > n;53    }54 55    // 两个栈顶轮着看，等于 need 就弹，直到弹不动为止；返回新的 need56    private int drain(Deque<Integer> a, Deque<Integer> b, int need) {57        for (boolean moved = true; moved; ) {58            moved = false;59            while (!a.isEmpty() && a.peek() == need) { a.pop(); need++; moved = true; }60            while (!b.isEmpty() && b.peek() == need) { b.pop(); need++; moved = true; }61        }62        return need;63    }64}
