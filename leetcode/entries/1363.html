数字和 %3 决定删谁：余 1 删一个 1/4/7（没有就删两个 2/5/8），余 2 对称；剩下降序拼接，全 0 输出 "0"。

思路

  • 一个数是 3 的倍数 ⟺ 数字和是 3 的倍数，所以问题变成「删最少的数字使余数归零」。
  • 余 1：优先删最小的 1/4/7；一个都没有就删两个最小的 2/5/8（余 2 对称；由同余式 #1 − #2 ≡ r (mod 3) 保证第二次必有得删）。
  • 删完后数字从大到小拼接即最大；降序首位是 0 说明全是 0，直接返回 "0"。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public String largestMultipleOfThree(int[] digits) {3        int[] cnt = new int[10];4        int sum = 0;5        for (int d : digits) { cnt[d]++; sum += d; }6        int[] one = {1, 4, 7}, two = {2, 5, 8};   // 升序：要删就先删小的7        int r = sum % 3;8        // 余 1：删一个余 1 的数；一个都没有就删两个余 2 的（个数满足同余式，必有得删）9        if (r == 1 && take(cnt, one, 1) == 0) take(cnt, two, 2);10        if (r == 2 && take(cnt, two, 1) == 0) take(cnt, one, 2);11        // 从大到小拼；降序后首位是 0 说明全是 0，答案就是 "0"12        StringBuilder sb = new StringBuilder();13        for (int d = 9; d >= 0; d--) {14            for (int t = 0; t < cnt[d]; t++) sb.append((char) ('0' + d));15        }16        if (sb.length() > 0 && sb.charAt(0) == '0') return "0";17        return sb.toString();18    }19 20    /** 从 cnt 里删掉 need 个 mods 组里最小的数，返回实际删掉几个。 */21    private int take(int[] cnt, int[] mods, int need) {22        int took = 0;23        for (int d : mods) {24            int t = Math.min(cnt[d], need - took);25            cnt[d] -= t;26            took += t;27            if (took == need) break;28        }29        return took;30    }31}
题目

给你一个整数数组 digits，你可以通过按 任意顺序 连接其中某些数字来形成 3 的倍数，请你返回所能得到的最大的 3 的倍数。

由于答案可能不在整数数据类型范围内，请以字符串形式返回答案。如果无法得到答案，请返回一个空字符串。返回的结果不应包含不必要的前导零。

示例 1：

输入：digits = [8,1,9]
输出："981"

示例 2：

输入：digits = [8,6,7,1,0]
输出："8760"

示例 3：

输入：digits = [1]
输出：""

示例 4：

输入：digits = [0,0,0,0,0,0]
输出："0"

提示：

  • 1 <= digits.length <= 10^4
  • 0 <= digits[i] <= 9
