一次后序 DFS：每棵子树向父亲报告 (最深叶深度, 包住这些叶的最小子树根)；两侧同深就在本结点汇合，否则沿更深一侧原样上传。

思路

  • 空子树报告 (0, null)；叶子报告 (1, 自己)，天然覆盖单叶情形。
  • 左右同深 → 最深叶分居两侧，本结点是它们的汇合点，报告 (深+1, 本结点)。
  • 不同深 → 答案完全在更深一侧，把那侧的子树根原样上传；根的报告就是最终答案。

最优解

时间复杂度 O(n)，空间复杂度 O(树高)
1class Solution {2    public TreeNode subtreeWithAllDeepest(TreeNode root) {3        return dfs(root).node;4    }5 6    // 后序 DFS：向父亲报告 (子树最深叶子的深度, 包住这些叶子的最小子树根)7    private Res dfs(TreeNode node) {8        if (node == null) return new Res(0, null);9        Res l = dfs(node.left), r = dfs(node.right);10        // 两侧同深：最深叶子分居两侧（或本结点自己就是叶），在本结点汇合11        if (l.depth == r.depth) return new Res(l.depth + 1, node);12        // 否则答案全在更深一侧，原样上传13        return l.depth > r.depth ? new Res(l.depth + 1, l.node) : new Res(r.depth + 1, r.node);14    }15 16    private static class Res {17        int depth;18        TreeNode node;19 20        Res(int depth, TreeNode node) {21            this.depth = depth;22            this.node = node;23        }24    }25}
题目

给定一个根为 root 的二叉树，每个节点的深度是 该节点到根的最短距离 。

返回包含原始树中所有 最深节点 的 最小子树 。

如果一个节点在 整个树 的任意节点之间具有最大的深度，则该节点是 最深的 。

一个节点的 子树 是该节点加上它的所有后代的集合。

示例 1：

输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2,7,4]
解释：
我们返回值为 2 的节点，在图中用黄色标记。
在图中用蓝色标记的是树的最深的节点。
注意，节点 5、3 和 2 包含树中最深的节点，但节点 2 的子树最小，因此我们返回它。

示例 2：

输入：root = [1]
输出：[1]
解释：根节点是树中最深的节点。

示例 3：

输入：root = [0,1,3,null,2]
输出：[2]
解释：树中最深的节点为 2 ，有效子树为节点 2、1 和 0 的子树，但节点 2 的子树最小。

提示：

  • 树中节点的数量在 [1, 500] 范围内。
  • 0 <= Node.val <= 500
  • 每个节点的值都是 独一无二 的。
