1365. 有多少小于当前数字的数字

排序后记下每个值首次出现的下标（= 严格小于它的个数），再按原序查表填答案。

思路

  • 复制一份排序；有序数组里一个值首次出现的下标，正好是严格小于它的数字个数，重复值只记第一个。
  • 哈希表 值 → 首次下标 存好后，按原数组顺序逐个查表填答案。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] smallerNumbersThanCurrent(int[] nums) {5        int[] sorted = nums.clone();6        Arrays.sort(sorted);7        // 有序数组里每个值首次出现的下标 = 严格小于它的数字个数（重复值只记第一个）8        Map<Integer, Integer> first = new HashMap<>();9        for (int i = 0; i < sorted.length; i++) first.putIfAbsent(sorted[i], i);10        int[] ans = new int[nums.length];11        for (int i = 0; i < nums.length; i++) ans[i] = first.get(nums[i]);12        return ans;13    }14}
题目

给你一个数组 nums，对于其中每个元素 nums[i]，请你统计数组中比它小的所有数字的数目。

换而言之，对于每个 nums[i] 你必须计算出有效的 j 的数量，其中 j 满足 j != i 且 nums[j] < nums[i] 。

以数组形式返回答案。

示例 1：

输入：nums = [8,1,2,2,3]
输出：[4,0,1,1,3]
解释： 
对于 nums[0]=8 存在四个比它小的数字：（1，2，2 和 3）。 
对于 nums[1]=1 不存在比它小的数字。
对于 nums[2]=2 存在一个比它小的数字：（1）。 
对于 nums[3]=2 存在一个比它小的数字：（1）。 
对于 nums[4]=3 存在三个比它小的数字：（1，2 和 2）。

示例 2：

输入：nums = [6,5,4,8]
输出：[2,1,0,3]

示例 3：

输入：nums = [7,7,7,7]
输出：[0,0,0,0]

提示：

  • 2 <= nums.length <= 500
  • 0 <= nums[i] <= 100
