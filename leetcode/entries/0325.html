325. 和等于 k 的最长子数组长度

  • 中等
  • 频度 7
  • 前缀和/差分
  • 哈希表
  • 数组
  • 哈希表
  • 前缀和
  • 未经力扣验证

前缀和哈希表只记「每个前缀和最早出现的下标」：读到 i 查 sum−k 是否在表里，命中则 i−j 就是和为 k 的子数组长度。

思路

  • sum 是到 i 为止的前缀和；(j, i] 的和为 k ⟺ sum[i] − sum[j] = k，即用 sum − k 查表拿最早的 j。
  • 表里只存每个前缀和最早的下标（putIfAbsent 不覆盖）：j 越早，i − j 越长。
  • 哨兵 0 → −1 让「从头开始」的子数组也能配上；前缀和最坏 ±2×10⁹，要用 long。

1import java.util.*;2 3class Solution {4    // 前缀和 + 哈希表：sum[i] - sum[j] = k ⇒ 子数组 (j, i] 的和为 k；5    // 表里记每个前缀和「最早」出现的下标，区间越长越好6    public int maxSubArrayLen(int[] nums, int k) {7        Map<Long, Integer> first = new HashMap<>();   // 前缀和 → 最早出现的下标8        first.put(0L, -1);                            // 空前缀：下标 -19        long sum = 0;10        int ans = 0;11        for (int i = 0; i < nums.length; i++) {12            sum += nums[i];13            // 之前出现过前缀和 sum - k，中间那段 (j, i] 就是候选14            Integer j = first.get(sum - k);15            if (j != null) ans = Math.max(ans, i - j);16            // 只记最早出现：越早，后面配出的子数组越长17            first.putIfAbsent(sum, i);18        }19        return ans;20    }21}
