867. 转置矩阵

  • 简单
  • 频度 2
  • 模拟
  • 数组
  • 矩阵
  • 模拟
  • 待提交

开一个 n×m 的新矩阵，逐格把原坐标 (i, j) 的值搬到新坐标 (j, i)，行列索引互换。

思路

  • 转置只做一件事：原坐标 (i, j) 的新位置是 (j, i)，开新矩阵逐格搬过去即可。
  • 结果尺寸要反过来：m 行 n 列转置后是 n 行 m 列，res = new int[n][m]。
  • 方阵也可以就地交换 a[i][j] 与 a[j][i]，但非方阵必须开新矩阵，统一用新矩阵最稳。

图解

最优解

时间复杂度 O(m·n)，空间复杂度 O(m·n)
1class Solution {2    public int[][] transpose(int[][] matrix) {3        int m = matrix.length, n = matrix[0].length;4        // m 行 n 列转置后是 n 行 m 列5        int[][] res = new int[n][m];6        for (int i = 0; i < m; i++) {7            for (int j = 0; j < n; j++) {8                // 原来的 (i, j) 搬到 (j, i)：行列互换9                res[j][i] = matrix[i][j];10            }11        }12        return res;13    }14}
题目

给你一个二维整数数组 matrix， 返回 matrix 的 转置矩阵 。

矩阵的 转置 是指将矩阵的主对角线翻转，交换矩阵的行索引与列索引。

示例 1：

输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[1,4,7],[2,5,8],[3,6,9]]

示例 2：

输入：matrix = [[1,2,3],[4,5,6]]
输出：[[1,4],[2,5],[3,6]]

提示：

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 1000
  • 1 <= m * n <= 105
  • -109 <= matrix[i][j] <= 109
