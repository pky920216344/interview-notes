数组 + front + count：判空判满只看 count（不用留空位），入队写 (front+count)%k，出队只挪 front。

思路

  • 只存 front（队首下标）和 count（元素个数）：count == 0 空、count == k 满，不用牺牲空位。
  • 入队写到 (front + count) % k——队尾的下一格，越过末尾自动绕回开头。
  • 出队只把 front 挪到 (front + 1) % k，元素不搬动。
  • Front 读 a[front]，Rear 读 a[(front + count - 1) % k]，空队都返回 -1。

1class MyCircularQueue {2    private final int[] a;3    private int front = 0, count = 0;   // front：队首下标；count：元素个数，判空判满都看它4 5    public MyCircularQueue(int k) {6        a = new int[k];7    }8 9    public boolean enQueue(int value) {10        if (isFull()) return false;11        a[(front + count) % a.length] = value;   // 写到队尾的下一格，绕回开头靠取模12        count++;13        return true;14    }15 16    public boolean deQueue() {17        if (isEmpty()) return false;18        front = (front + 1) % a.length;   // 只挪队首下标，元素不用搬19        count--;20        return true;21    }22 23    public int Front() {24        return isEmpty() ? -1 : a[front];25    }26 27    public int Rear() {28        return isEmpty() ? -1 : a[(front + count - 1) % a.length];29    }30 31    public boolean isEmpty() {32        return count == 0;33    }34 35    public boolean isFull() {36        return count == a.length;37    }38}
题目

设计你的循环队列实现。 循环队列是一种线性数据结构，其操作表现基于 FIFO（先进先出）原则并且队尾被连接在队首之后以形成一个循环。它也被称为“环形缓冲器”。

循环队列的一个好处是我们可以利用这个队列之前用过的空间。在一个普通队列里，一旦一个队列满了，我们就不能插入下一个元素，即使在队列前面仍有空间。但是使用循环队列，我们能使用这些空间去存储新的值。

你的实现应该支持如下操作：

  • MyCircularQueue(k): 构造器，设置队列长度为 k 。
  • Front: 从队首获取元素。如果队列为空，返回 -1 。
  • Rear: 获取队尾元素。如果队列为空，返回 -1 。
  • enQueue(value): 向循环队列插入一个元素。如果成功插入则返回真。
  • deQueue(): 从循环队列中删除一个元素。如果成功删除则返回真。
  • isEmpty(): 检查循环队列是否为空。
  • isFull(): 检查循环队列是否已满。

示例：

MyCircularQueue circularQueue = new MyCircularQueue(3); // 设置长度为 3
circularQueue.enQueue(1);  // 返回 true
circularQueue.enQueue(2);  // 返回 true
circularQueue.enQueue(3);  // 返回 true
circularQueue.enQueue(4);  // 返回 false，队列已满
circularQueue.Rear();  // 返回 3
circularQueue.isFull();  // 返回 true
circularQueue.deQueue();  // 返回 true
circularQueue.enQueue(4);  // 返回 true
circularQueue.Rear();  // 返回 4

提示：

  • 所有的值都在 0 至 1000 的范围内；
  • 操作数将在 1 至 1000 的范围内；
  • 请不要使用内置的队列库。
