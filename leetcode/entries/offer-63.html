剑指 Offer 63. 买卖芯片的最佳时机

一遍扫描：min 记历史最低价，每天先算「今天卖出」的利润 p − min 更新答案，再用今天更新 min。

思路

  • 一次交易 = 一个历史最低点买入 + 某个之后的最高点卖出；扫描到第 i 天时，最优买入点必然已在前面出现过。
  • ans = max(ans, p − min) 先算今天卖出的利润；min = min(min, p) 再把今天纳入历史——顺序保证不是同一天买卖。
  • 全程下跌时 p − min 始终 ≤ 0，ans 初始 0 兜底，正确返回「不交易」。
  • 本题与 121 完全相同，换了个题面。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int bestTiming(int[] prices) {3        int ans = 0, min = Integer.MAX_VALUE;4        for (int p : prices) {5            ans = Math.max(ans, p - min);   // 在历史最低点买入、今天卖出6            min = Math.min(min, p);         // 再把今天纳入「历史」，供后面的天参考7        }8        return ans;9    }10}
题目

数组 prices 记录了某芯片近期的交易价格，其中 prices[i] 表示的 i 天该芯片的价格。你只能选择 某一天 买入芯片，并选择在 未来的某一个不同的日子 卖出该芯片。请设计一个算法计算并返回你从这笔交易中能获取的最大利润。

如果你不能获取任何利润，返回 0。

示例 1：

输入：prices = [3, 6, 2, 9, 8, 5]
输出：7
解释：在第 3 天（芯片价格 = 2）买入，在第 4 天（芯片价格 = 9）卖出，最大利润 = 9 - 2 = 7。

示例 2：

输入：prices = [8, 12, 15, 7, 3, 10]
输出：7
解释：在第 5 天（芯片价格 = 3）买入，在第 6 天（芯片价格 = 10）卖出，最大利润 = 10 - 3 = 7。

提示：

  • 0 <= prices.length <= 10^5
  • 0 <= prices[i] <= 10^4
