647. 回文子串

中心扩展：枚举 2n-1 个中心（每个字符 + 每个间隙），从中心向两边扩，每扩成功一次就多一个回文。

思路

  • 回文都对称：枚举 2n-1 个中心——n 个字符（奇长度）加 n-1 个间隙（偶长度）。
  • 每个中心从中间往两边走：两侧字符相等就 ans++ 再扩，不等或越界就停。
  • 每个「成功扩一次」恰好对应一个回文子串，不漏不重；中心定位用 l = c/2, r = l + c%2 一行搞定。

最优解

时间复杂度 O(n²)，空间复杂度 O(1)
1class Solution {2    public int countSubstrings(String s) {3        int n = s.length(), ans = 0;4        // 2n-1 个中心：n 个字符（奇长度）加 n-1 个间隙（偶长度）5        for (int c = 0; c < 2 * n - 1; c++) {6            int l = c / 2, r = l + c % 2;7            // 从中心向两边扩，两侧相等就能再延伸一个回文8            while (l >= 0 && r < n && s.charAt(l) == s.charAt(r)) {9                ans++;10                l--;11                r++;12            }13        }14        return ans;15    }16}
题目

给你一个字符串 s ，请你统计并返回这个字符串中 回文子串 的数目。

回文字符串 是正着读和倒过来读一样的字符串。

子字符串 是字符串中的由连续字符组成的一个序列。

示例 1：

输入：s = "abc"
输出：3
解释：三个回文子串: "a", "b", "c"

示例 2：

输入：s = "aaa"
输出：6
解释：6个回文子串: "a", "a", "a", "aa", "aa", "aaa"

提示：

  • 1 <= s.length <= 1000
  • s 由小写英文字母组成
