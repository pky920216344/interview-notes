801. 使序列递增的最小交换次数

  • 中等
  • 频度 1
  • 动态规划
  • 数组
  • 动态规划
  • 待提交

双状态 DP：keep[i] / swap[i] 是第 i 位不换/换时的最小交换数；相邻两位只要「同状态自然有序」或「交叉有序」就能转移。

思路

  • keep / swap 滚动两个变量：第 i 位不换、换的最小代价；初始 keep=0, swap=1。
  • 同状态转移：nums1[i-1]<nums1[i] 且 nums2[i-1]<nums2[i] 时，i-1、i 都不换（或都换）天然有序 → keep 接 keep、swap 接 swap+1。
  • 交叉转移：nums1[i-1]<nums2[i] 且 nums2[i-1]<nums1[i] 时，一换一不换有序 → keep 接 swap、swap 接 keep+1。
  • 答案 min(keep, swap)；两条转移都查一遍取最小，题目保证有解。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int minSwap(int[] nums1, int[] nums2) {5        // keep：i 不换的最小交换数；swap：i 换的最小交换数（滚动变量，O(1) 空间）6        int keep = 0, swap = 1;7        for (int i = 1; i < nums1.length; i++) {8            int nk = Integer.MAX_VALUE, ns = Integer.MAX_VALUE;9            if (nums1[i - 1] < nums1[i] && nums2[i - 1] < nums2[i]) {10                // i-1、i 状态相同（都不换或都换）时天然有序11                nk = Math.min(nk, keep);12                ns = Math.min(ns, swap + 1);13            }14            if (nums1[i - 1] < nums2[i] && nums2[i - 1] < nums1[i]) {15                // i-1、i 状态相反时交叉有序16                nk = Math.min(nk, swap);17                ns = Math.min(ns, keep + 1);18            }19            keep = nk;20            swap = ns;21        }22        return Math.min(keep, swap);23    }24}
题目

我们有两个长度相等且不为空的整型数组 nums1 和 nums2 。在一次操作中，我们可以交换 nums1[i] 和 nums2[i]的元素。

  • 例如，如果 nums1 = [1,2,3,8] ， nums2 =[5,6,7,4] ，你可以交换 i = 3 处的元素，得到 nums1 =[1,2,3,4] 和 nums2 =[5,6,7,8] 。

返回 使 nums1 和 nums2 严格递增 所需操作的最小次数 。

数组 arr 严格递增 且  arr[0] < arr[1] < arr[2] < ... < arr[arr.length - 1] 。

注意：

  • 用例保证可以实现操作。

示例 1:

输入: nums1 = [1,3,5,4], nums2 = [1,2,3,7]
输出: 1
解释: 
交换 A[3] 和 B[3] 后，两个数组如下:
A = [1, 3, 5, 7] ， B = [1, 2, 3, 4]
两个数组均为严格递增的。

示例 2:

输入: nums1 = [0,3,5,8,9], nums2 = [2,1,4,6,9]
输出: 1

提示:

  • 2 <= nums1.length <= 105
  • nums2.length == nums1.length
  • 0 <= nums1[i], nums2[i] <= 2 * 105
