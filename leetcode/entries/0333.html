333. 最大二叉搜索子树

  • 中等
  • 频度 2
  • 动态规划
  • 深度优先搜索/递归
  • 树
  • 深度优先搜索
  • 二叉搜索树
  • 动态规划
  • 二叉树
  • dp-on-trees
  • 未经力扣验证

后序递归返回四元组 (是否BST, 结点数, 子树min, 子树max)，空树当作合法 BST，合法就合并刷新答案。

思路

  • 空树返回 (1, 0, +∞, −∞)：天然合法、min/max 是哨兵，方便合并。
  • 结点合法条件：左右都返回 是 BST，且 val > 左子树max、val < 右子树min（严格，重复值不算 BST）。
  • 合法 → 大小 = 左右大小 + 1，刷新答案；min/max 取 min(左min, val)、max(右max, val)。
  • 不合法 → 上传 (0, …)，父结点看到 0 就永远合并不上，天然把「最大 BST 只能是完整子树」切断。

最优解

时间复杂度 O(n)，空间复杂度 O(h)
1class Solution {2    private int ans = 0;3 4    public int largestBSTSubtree(TreeNode root) {5        ans = 0;6        dfs(root);7        return ans;8    }9 10    // 返回 {是否 BST(1/0), 结点数, 子树最小值, 子树最大值}；空树视作合法 BST：大小 0、min=+∞、max=−∞11    private long[] dfs(TreeNode node) {12        if (node == null) return new long[]{1, 0, Long.MAX_VALUE, Long.MIN_VALUE};13        long[] L = dfs(node.left), R = dfs(node.right);14        // 左右都是 BST，且当前值严格大于左子树最大、小于右子树最小，合起来才是 BST15        if (L[0] == 1 && R[0] == 1 && node.val > L[3] && node.val < R[2]) {16            int size = (int) (L[1] + R[1] + 1);17            ans = Math.max(ans, size);18            // 左子树非空时 min 就是 L[2]；右子树非空时 max 就是 R[3]19            return new long[]{1, size, Math.min(L[2], node.val), Math.max(R[3], node.val)};20        }21        // 不是 BST：往上传一个永远合并不上的标记22        return new long[]{0, 0, 0, 0};23    }24}
