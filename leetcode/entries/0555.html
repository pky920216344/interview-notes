555. 分割连接字符串

  • 中等
  • 频度 1
  • 模拟

  • 贪心

  • 字符串
  • 未经力扣验证

枚举切分点落在哪个串的哪个字符后；其余串各自取原串/反串里大的朝向，切分串按「残尾+绕回残头」试两种朝向。

思路

  • 不被切开的串整段出现，而反串长度不变：逐串独立取 max(原串, 反串) 就是它的最优朝向。
  • 切分点在第 i 串的 k 字符后：正则串 = o[k+1..] + i 之后的串 + i 之前的串 + o[0..k]——环从切点后一位读起。
  • 对第 i 串两种朝向、每个 k 都试一遍，取字典序最大的候选。

1import java.util.*;2 3class Solution {4    public String splitLoopedString(String[] strs) {5        int n = strs.length;6        // 不参与切分的串一律取原串/反串中字典序大的朝向7        String[] best = new String[n];8        for (int i = 0; i < n; i++) {9            String rev = new StringBuilder(strs[i]).reverse().toString();10            best[i] = rev.compareTo(strs[i]) > 0 ? rev : strs[i];11        }12        String ans = "";13        // 枚举切分点：它总落在某个串的某个字符后面14        for (int i = 0; i < n; i++) {15            // 其余串按原顺序拼成两段：i 之后一段、i 之前一段（环回的顺序）16            StringBuilder s1 = new StringBuilder(), s2 = new StringBuilder();17            for (int j = i + 1; j < n; j++) s1.append(best[j]);18            for (int j = 0; j < i; j++) s2.append(best[j]);19            String aft = s1.toString(), bef = s2.toString();20            String rev = new StringBuilder(strs[i]).reverse().toString();21            for (String o : new String[]{strs[i], rev}) {22                // 切在 o[k] 后面：先读完 o[k+1..]，绕一圈最后读 o[0..k]23                for (int k = 0; k < o.length(); k++) {24                    String cand = o.substring(k + 1) + aft + bef + o.substring(0, k + 1);25                    if (cand.compareTo(ans) > 0) ans = cand;26                }27            }28        }29        return ans;30    }31}
