1059. 从起点到终点的所有路径

  • 中等
  • 频度 2
  • 深度优先搜索/递归
  • 图
  • 拓扑排序
  • kosarajus-algorithm
  • tarjans-scc-algorithm
  • 未经力扣验证

DFS 三色标记：出度为 0 的结点必须是终点；撞到「还在栈上」的灰点说明有环；某结点所有出边都验证通过就染黑，之后不再重看。

思路

  • 建邻接表，从 source DFS；color 三态：0 没访问、1 在递归栈上、2 已确认通向终点。
  • 出度为 0 的结点：只有它本身就是 destination 才算这条路通，否则直接 false。
  • 递归中撞到灰点 = 有环（路径会无限绕圈），false；黑点直接放行，白点才递归。
  • 某结点的所有出边都验证通过就染黑回传；source == destination 且无出边是合法的平凡情形。

1import java.util.*;2 3class Solution {4    public boolean leadsToDestination(int n, int[][] edges, int source, int destination) {5        // 邻接表：adj[u] 存 u 的所有出边终点6        List<List<Integer>> adj = new ArrayList<>();7        for (int i = 0; i < n; i++) adj.add(new ArrayList<>());8        for (int[] e : edges) adj.get(e[0]).add(e[1]);9        // color：0 没访问、1 在递归栈上、2 已确认出边全通向终点10        return dfs(source, destination, adj, new int[n]);11    }12 13    private boolean dfs(int node, int destination, List<List<Integer>> adj, int[] color) {14        // 路走到头（出度为 0）：必须正好停在终点，否则这条路不通15        if (adj.get(node).isEmpty()) return node == destination;16        color[node] = 1;17        for (int next : adj.get(node)) {18            // 撞见还在栈上的结点 = 有环，这条路会无限绕圈19            if (color[next] == 1) return false;20            // 已确认的黑点直接放行，没访问过的才递归21            if (color[next] == 0 && !dfs(next, destination, adj, color)) return false;22        }23        color[node] = 2;   // 所有出边都验证通过，回传给父结点24        return true;25    }26}
