871. 最低加油次数

  • 困难
  • 频度 2
  • 贪心
  • 堆
  • 贪心
  • 数组
  • 动态规划
  • 堆（优先队列）
  • 待提交

反悔式贪心：油够就往前开，沿途加油站的油量进大顶堆；一旦油不够，就从堆里取最大的油量加一次。

思路

  • 油箱无限大 ⇒ 在哪桶油「实际加油」不重要：路过每站先把油量入堆，相当于先记账、后决定。
  • 每当油走不到下一站（或终点），从堆里取最大油量加一次，这样加油次数最少。
  • 堆空还到不了 → 返回 -1；位置、油量都可达 1e9，油量累加用 long。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int minRefuelStops(int target, int startFuel, int[][] stations) {5        // 大顶堆：路过的加油站先把油量存进堆，缺油时才加「最大」的那桶6        PriorityQueue<Integer> heap = new PriorityQueue<>((a, b) -> b - a);7        long fuel = startFuel;   // 位置、油量都可达 1e9，累加用 long8        int ans = 0, i = 0, n = stations.length;9        while (fuel < target) {10            // 开到现在这个位置，沿途能到的加油站油量全部入堆11            while (i < n && stations[i][0] <= fuel) {12                heap.add(stations[i][1]);13                i++;14            }15            // 到不了终点，堆里也没有油可加 → 失败16            if (heap.isEmpty()) return -1;17            // 贪心：每次只加油量最大的那桶，加油次数才最少18            fuel += heap.poll();19            ans++;20        }21        return ans;22    }23}
题目

汽车从起点出发驶向目的地，该目的地位于出发位置东面 target 英里处。

沿途有加油站，用数组 stations 表示。其中 stations[i] = [positioni, fueli] 表示第 i 个加油站位于出发位置东面 positioni 英里处，并且有 fueli 升汽油。

假设汽车油箱的容量是无限的，其中最初有 startFuel 升燃料。它每行驶 1 英里就会用掉 1 升汽油。当汽车到达加油站时，它可能停下来加油，将所有汽油从加油站转移到汽车中。

为了到达目的地，汽车所必要的最低加油次数是多少？如果无法到达目的地，则返回 -1 。

注意：如果汽车到达加油站时剩余燃料为 0，它仍然可以在那里加油。如果汽车到达目的地时剩余燃料为 0，仍然认为它已经到达目的地。

示例 1：

输入：target = 1, startFuel = 1, stations = []
输出：0
解释：可以在不加油的情况下到达目的地。

示例 2：

输入：target = 100, startFuel = 1, stations = [[10,100]]
输出：-1
解释：无法抵达目的地，甚至无法到达第一个加油站。

示例 3：

输入：target = 100, startFuel = 10, stations = [[10,60],[20,30],[30,30],[60,40]]
输出：2
解释：
出发时有 10 升燃料。
开车来到距起点 10 英里处的加油站，消耗 10 升燃料。将汽油从 0 升加到 60 升。
然后，从 10 英里处的加油站开到 60 英里处的加油站（消耗 50 升燃料），
并将汽油从 10 升加到 50 升。然后开车抵达目的地。
沿途在两个加油站停靠，所以返回 2 。

提示：

  • 1 <= target, startFuel <= 109
  • 0 <= stations.length <= 500
  • 1 <= positioni < positioni+1 < target
  • 1 <= fueli < 109
