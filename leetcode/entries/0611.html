611. 有效三角形的个数

排序后固定最大边 nums[k]，双指针在左边找「两小边之和 > 最大边」的组合数，累加。

思路

  • 排序后，三角形条件只剩「两条小边之和 > 最大边」，另外两个不等式自动成立。
  • 固定最大边 nums[k]，在 [0, k) 里用 left、right 找两条小边。
  • nums[left] + nums[right] > nums[k]：则 left..right-1 每个都能配 right，一次加 right - left 个，right--。
  • 和不够就 left++；left 只前进不回退，每个 k 一趟 O(n)。

最优解

时间复杂度 O(n^2)，空间复杂度 O(log n)
1import java.util.*;2 3class Solution {4    public int triangleNumber(int[] nums) {5        Arrays.sort(nums);                    // 排序后只需查：两条小边之和 > 最大边6        int ans = 0;7        for (int k = 2; k < nums.length; k++) {8            int left = 0, right = k - 1;      // 在 [0, k) 里找两条小边9            while (left < right) {10                if (nums[left] + nums[right] > nums[k]) {11                    ans += right - left;      // left..right-1 任取一个配 right 都成立12                    right--;                  // right 左移，继续数13                } else {14                    left++;                   // 和太小，左边的边换大一点15                }16            }17        }18        return ans;19    }20}
题目

给定一个包含非负整数的数组 nums ，返回其中可以组成三角形三条边的三元组个数。

示例 1:

输入: nums = [2,2,3,4]
输出: 3
解释:有效的组合是: 
2,3,4 (使用第一个 2)
2,3,4 (使用第二个 2)
2,2,3

示例 2:

输入: nums = [4,2,3,4]
输出: 4

提示:

  • 1 <= nums.length <= 1000
  • 0 <= nums[i] <= 1000
