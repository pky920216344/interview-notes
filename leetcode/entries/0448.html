448. 找到所有数组中消失的数字

  • 简单
  • 频度 3
  • 哈希表
  • 数组
  • 哈希表
  • 待提交

值 v 出现过就把下标 v−1 翻成负数当标记；最后仍是正数的位置 +1 即消失的数，原地 O(1) 空间。

思路

  • 值域恰好是 1..n，让「值 v」占用「下标 v−1」：扫到 v 就把 nums[v-1] 翻负（已负就跳过，防二次翻转）。
  • 取 Math.abs(v) 再定位：前面的操作可能把当前值翻负了，必须按绝对值读。
  • 第二遍扫：仍为正数的下标 i 没被任何值标记 → i+1 消失；顺手翻回负号把数组复原。

最优解

时间复杂度 O(n)，空间复杂度 O(1)（输出不计）
1import java.util.*;2 3class Solution {4    public List<Integer> findDisappearedNumbers(int[] nums) {5        // 值 v 出现过，就把下标 v-1 上的数翻成负数当「到过此处」的标记6        for (int v : nums) {7            int idx = Math.abs(v) - 1;8            if (nums[idx] > 0) nums[idx] = -nums[idx];9        }10        // 还是正数的位置没人来标记过：下标 +1 就是消失的数；顺手把数组复原11        List<Integer> out = new ArrayList<>();12        for (int i = 0; i < nums.length; i++) {13            if (nums[i] > 0) out.add(i + 1);14            else nums[i] = -nums[i];15        }16        return out;17    }18}
题目

给你一个含 n 个整数的数组 nums ，其中 nums[i] 在区间 [1, n] 内。请你找出所有在 [1, n] 范围内但没有出现在 nums 中的数字，并以数组的形式返回结果。

示例 1：

输入：nums = [4,3,2,7,8,2,3,1]
输出：[5,6]

示例 2：

输入：nums = [1,1]
输出：[2]

提示：

  • n == nums.length
  • 1 <= n <= 105
  • 1 <= nums[i] <= n

进阶：你能在不使用额外空间且时间复杂度为 O(n) 的情况下解决这个问题吗? 你可以假定返回的数组不算在额外空间内。
