1654. 到家的最少跳跃次数

  • 频度 3

  • 广度优先搜索
  • 数组
  • 哈希表
  • 待提交

BFS，状态是「位置 + 上一步是否后跳」：前跳任意次都行，后跳只能在「上一步不是后跳」时来一次；位置上限 max(x, 最远禁区) + a + b。

思路

  • 连续两次后跳不合法 → BFS 状态要带「上一步是不是后跳」，seen[p][2] 双份去重。
  • 位置上限取 max(x, 最远禁区) + a + b：再远的位置不可能出现在最短路上。
  • 逐层 BFS 数步数；第一次 poll 到 x 的层数即答案，队列空则 -1（x=0 时直接 0）。

时间复杂度 O(limit)，空间复杂度 O(limit)
1import java.util.*;2 3class Solution {4    public int minimumJumps(int[] forbidden, int a, int b, int x) {5        // 位置上限：比「家和最远禁区」高出 a+b 的位置不可能出现在最短路上6        int limit = x;7        for (int f : forbidden) limit = Math.max(limit, f);8        limit += a + b;9        Set<Integer> banned = new HashSet<>();10        for (int f : forbidden) banned.add(f);11        // seen[p][1] 表示「上一步是往后跳到达 p」——这种状态不能再往后跳（不许连续两次）12        boolean[][] seen = new boolean[limit + 1][2];13        Queue<int[]> q = new ArrayDeque<>();14        seen[0][0] = true;15        q.add(new int[]{0, 0});16        int steps = 0;17        while (!q.isEmpty()) {18            for (int size = q.size(); size > 0; size--) {19                int[] cur = q.poll();20                int p = cur[0], back = cur[1];21                if (p == x) return steps;22                int np = p + a;   // 往前跳 a：任何状态都可以23                if (np <= limit && !banned.contains(np) && !seen[np][0]) {24                    seen[np][0] = true;25                    q.add(new int[]{np, 0});26                }27                if (back == 0) {   // 上一步没往后跳，才能再往后跳一次 b28                    np = p - b;29                    if (np >= 0 && !banned.contains(np) && !seen[np][1]) {30                        seen[np][1] = true;31                        q.add(new int[]{np, 1});32                    }33                }34            }35            steps++;36        }37        return -1;38    }39}
题目

有一只跳蚤的家在数轴上的位置 x 处。请你帮助它从位置 0 出发，到达它的家。

跳蚤跳跃的规则如下：

  • 它可以 往前 跳恰好 a 个位置（即往右跳）。
  • 它可以 往后 跳恰好 b 个位置（即往左跳）。
  • 它不能 连续 往后跳 2 次。
  • 它不能跳到任何 forbidden 数组中的位置。

跳蚤可以往前跳 超过 它的家的位置，但是它 不能跳到负整数 的位置。

给你一个整数数组 forbidden ，其中 forbidden[i] 是跳蚤不能跳到的位置，同时给你整数 a， b 和 x ，请你返回跳蚤到家的最少跳跃次数。如果没有恰好到达 x 的可行方案，请你返回 -1 。

示例 1：

输入：forbidden = [14,4,18,1,15], a = 3, b = 15, x = 9
输出：3
解释：往前跳 3 次（0 -> 3 -> 6 -> 9），跳蚤就到家了。

示例 2：

输入：forbidden = [8,3,16,6,12,20], a = 15, b = 13, x = 11
输出：-1

示例 3：

输入：forbidden = [1,6,2,14,5,17,4], a = 16, b = 9, x = 7
输出：2
解释：往前跳一次（0 -> 16），然后往回跳一次（16 -> 7），跳蚤就到家了。

提示：

  • 1 <= forbidden.length <= 1000
  • 1 <= a, b, forbidden[i] <= 2000
  • 0 <= x <= 2000
  • forbidden 中所有位置互不相同。
  • 位置 x 不在 forbidden 中。
