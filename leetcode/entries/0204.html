埃氏筛：从 2 扫到 n-1，没被标记的就是质数，并从 i² 起把它的倍数全标成合数。

思路

  • isComposite[x] 记 x 是否被某个更小的质数标记过；扫到没被标记的 i，它就是质数，count++。
  • 标记从 i*i 开始：i*2、i*3… 这些更小的倍数早被更小的质数标过，再标是重复功。
  • i*i 要用 long 算（i 接近 n 时会溢出 int）；i² ≥ n 时循环自然不执行。
  • 边界：n ≤ 2 时一个质数都没有，返回 0。

时间复杂度 O(n log log n)，空间复杂度 O(n)
1class Solution {2    public int countPrimes(int n) {3        // isComposite[x]：x 是否已被某个更小的质数标记成合数4        boolean[] isComposite = new boolean[n];5        int count = 0;6        for (int i = 2; i < n; i++) {7            if (isComposite[i]) continue;   // 被标过的是合数，跳过8            count++;                        // 没被任何质数标过，i 就是质数9            // 从 i*i 开始标记：更小的倍数（如 i*2）早已被更小的质数标过10            for (long j = (long) i * i; j < n; j += i) isComposite[(int) j] = true;11        }12        return count;13    }14}
题目

给定整数 n ，返回 所有小于非负整数 n 的质数的数量 。

示例 1：

输入：n = 10
输出：4
解释：小于 10 的质数一共有 4 个, 它们是 2, 3, 5, 7 。

示例 2：

输入：n = 0
输出：0

示例 3：

输入：n = 1
输出：0

提示：

  • 0 <= n <= 5 * 106
