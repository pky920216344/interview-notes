栈里存每层列表的迭代器；hasNext 不断展开栈顶直到吐出一个整数，next 只负责交出暂存的整数。

思路

  • 构造时把最外层的迭代器压栈；栈顶迭代器的 next 就是全局下一个待处理元素。
  • hasNext：栈顶用完就弹出（本层读完退回上层）；是嵌套列表就压入它的迭代器（进层）；直到栈顶给出整数，暂存进 cached 并返回 true。
  • next：直接返回 cached 并清空。这样每次 next 前 hasNext 已把工作做完，两个方法都接近 O(1)（均摊）。
  • 空列表（如 [[]]）会被压栈后立刻弹出，不会产生输出；深度即栈高。

时间复杂度 均摊 O(1)，空间复杂度 O(深度)
1import java.util.*;2 3class NestedIterator implements Iterator<Integer> {4    // 栈里存每一层列表的迭代器，栈顶是当前正在读的那层5    private final Deque<Iterator<NestedInteger>> stack = new ArrayDeque<>();6    private Integer cached;   // hasNext() 展开后暂存的下一个整数7 8    public NestedIterator(List<NestedInteger> nestedList) {9        stack.push(nestedList.iterator());10    }11 12    @Override13    public Integer next() {14        Integer v = cached;   // hasNext() 已经把下一个整数准备好15        cached = null;16        return v;17    }18 19    @Override20    public boolean hasNext() {21        if (cached != null) return true;22        while (!stack.isEmpty()) {23            Iterator<NestedInteger> it = stack.peek();24            if (!it.hasNext()) { stack.pop(); continue; }   // 本层读完，退回上层25            NestedInteger ni = it.next();26            if (ni.isInteger()) { cached = ni.getInteger(); return true; }27            stack.push(ni.getList().iterator());   // 是列表：进入更深层28        }29        return false;30    }31}
题目

给你一个嵌套的整数列表 nestedList 。每个元素要么是一个整数，要么是一个列表；该列表的元素也可能是整数或者是其他列表。请你实现一个迭代器将其扁平化，使之能够遍历这个列表中的所有整数。

实现扁平迭代器类 NestedIterator ：

  • NestedIterator(List<NestedInteger> nestedList) 用嵌套列表 nestedList 初始化迭代器。
  • int next() 返回嵌套列表的下一个整数。
  • boolean hasNext() 如果仍然存在待迭代的整数，返回 true ；否则，返回 false 。

你的代码将会用下述伪代码检测：

initialize iterator with nestedList
res = []
while iterator.hasNext()
    append iterator.next() to the end of res
return res

如果 res 与预期的扁平化列表匹配，那么你的代码将会被判为正确。

示例 1：

输入：nestedList = [[1,1],2,[1,1]]
输出：[1,1,2,1,1]
解释：通过重复调用 next 直到 hasNext 返回 false，next 返回的元素的顺序应该是: [1,1,2,1,1]。

示例 2：

输入：nestedList = [1,[4,[6]]]
输出：[1,4,6]
解释：通过重复调用 next 直到 hasNext 返回 false，next 返回的元素的顺序应该是: [1,4,6]。

提示：

  • 1 <= nestedList.length <= 500
  • 嵌套列表中的整数值在范围 [-106, 106] 内
