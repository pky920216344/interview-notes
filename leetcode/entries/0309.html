309. 买卖股票的最佳时机含冷冻期

  • 中等
  • 频度 6
  • 动态规划
  • 数组
  • 动态规划
  • 待提交

三状态 DP：持有 / 今天刚卖（明天冷冻）/ 空仓，每天按转移式滚动一遍，答案取两个空仓态的最大值。

思路

  • sold = hold + p（卖必来自昨天持有）；hold = max(hold, rest − p)（冷冻期不能买，只有空仓能买）；rest = max(rest, 昨天刚卖)。
  • 更新顺序要用旧值：先存 preSold，三行全从昨天的三态推今天。
  • 最后一天还持股没卖等于白买，答案 = max(sold, rest)。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxProfit(int[] prices) {3        // hold：持股；sold：今天刚卖（明天冷冻）；rest：空仓且不在冷冻期4        int hold = Integer.MIN_VALUE, sold = 0, rest = 0;5        for (int p : prices) {6            int preSold = sold;7            sold = hold + p;                  // 今天卖：必然来自昨天持股8            hold = Math.max(hold, rest - p);  // 持有：昨天就有，或今天从空仓买入9            rest = Math.max(rest, preSold);   // 空仓：延续，或昨天卖出、今天冷冻10        }11        // 最后一天持股没卖等于白买，答案只在两个空仓态里取12        return Math.max(sold, rest);13    }14}
题目

给定一个整数数组prices，其中第  prices[i] 表示第 i 天的股票价格 。​

设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）:

  • 卖出股票后，你无法在第二天买入股票 (即冷冻期为 1 天)。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

示例 1:

输入: prices = [1,2,3,0,2]
输出: 3 
解释: 对应的交易状态为: [买入, 卖出, 冷冻期, 买入, 卖出]

示例 2:

输入: prices = [1]
输出: 0

提示：

  • 1 <= prices.length <= 5000
  • 0 <= prices[i] <= 1000
