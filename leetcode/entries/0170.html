add 进计数哈希表；find 扫表中每个数 x，查补数 value−x 在不在表里，补数是自己时要求次数 ≥ 2。

思路

  • 只记「加过什么、各几次」：Map<数, 次数>，add 就是一次计数合并。
  • find(value) 扫表中每个已加的 x：补数 value - x 在表里即成对，返回 true。
  • 关键坑：补数等于 x 自己时（找 2x），必须 x 的次数 ≥ 2，不能拿同一个数配自己。

最优解

时间复杂度 add O(1)，find O(n)，空间复杂度 O(n)
