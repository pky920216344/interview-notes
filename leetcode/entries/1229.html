两人的空闲时段各自按开始时间排序，归并双指针：交集够 duration 就定在交集开头，否则先结束的那段让位。

思路

  • 拍平的 [s1,e1,s2,e2,…] 还原成时段并按开始时间排序。
  • 双指针各指一段：共同空闲 = [max(两起点), min(两终点)]，长度 ≥ duration 就返回 [lo, lo+duration]（双指针保证这是最早的）。
  • 交集不够长时，先结束的那段让位（end 小的一侧指针前进）：它和对方后面任何段都不可能有更长的交集。
  • 输入时段本身可以无序，排序是必要前置；任何一边走完都没有就返回空表。

1import java.util.*;2 3class Solution {4    public List<Integer> minAvailableDuration(int[] slots1, int[] slots2, int duration) {5        int[][] a = toPairs(slots1), b = toPairs(slots2);   // 各自按开始时间排序6        int i = 0, j = 0;7        while (i < a.length && j < b.length) {8            // 共同空闲 = [max(两起点), min(两终点)]，够长就把会议定在这开头9            int lo = Math.max(a[i][0], b[j][0]);10            int hi = Math.min(a[i][1], b[j][1]);11            if (hi - lo >= duration) return Arrays.asList(lo, lo + duration);12            // 先结束的那段，不可能再和对方靠后的段产生交集，让位13            if (a[i][1] < b[j][1]) i++;14            else j++;15        }16        return new ArrayList<>();17    }18 19    // 拍平的 [s1,e1,s2,e2,…] 还原成时间段并按开始时间排序20    private int[][] toPairs(int[] slots) {21        int[][] p = new int[slots.length / 2][2];22        for (int k = 0; k < p.length; k++) {23            p[k][0] = slots[2 * k];24            p[k][1] = slots[2 * k + 1];25        }26        Arrays.sort(p, (x, y) -> x[0] - y[0]);27        return p;28    }29}
