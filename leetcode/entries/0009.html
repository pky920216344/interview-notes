9. 回文数

  • 简单
  • 频度 33
  • 数学
  • 数学
  • 力扣已通过

反转一半数字：低位一位位搬进 rev，x ≤ rev 就停；偶数位比 x == rev，奇数位去掉正中那位再比。

思路

  • 先排除不可能：负数带符号、末尾为 0 的正数倒过来开头是 0（0 本身除外），直接 false。
  • 循环条件 x > rev：rev 追上 x 时恰好搬完一半，不用先算位数；也保证了全程不溢出（只反转一半，不像全反转那样会顶到 int 上限）。
  • 停止时偶数位 x == rev；奇数位正中间那位多搬进了 rev 末尾，x == rev / 10。
  • 例：12321 → x=12, rev=123 → 12 == 123/10 ✓。

图解

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public boolean isPalindrome(int x) {3        // 负数带符号、末尾为 0 的正数（0 除外）不可能是回文4        if (x < 0 || (x % 10 == 0 && x != 0)) return false;5        // 只反转后半段，和剩下的一半比，全程不会溢出6        int rev = 0;7        while (x > rev) {8            rev = rev * 10 + x % 10;9            x /= 10;10        }11        // 偶数位：x == rev；奇数位：正中间那位在 rev 末尾，去掉再比12        return x == rev || x == rev / 10;13    }14}
题目

给你一个整数 x ，如果 x 是一个回文整数，返回 true ；否则，返回 false 。

回文数是指正序（从左向右）和倒序（从右向左）读都是一样的整数。

  • 例如，121 是回文，而 123 不是。

示例 1：

输入：x = 121
输出：true

示例 2：

输入：x = -121
输出：false
解释：从左向右读, 为 -121 。 从右向左读, 为 121- 。因此它不是一个回文数。

示例 3：

输入：x = 10
输出：false
解释：从右向左读, 为 01 。因此它不是一个回文数。

提示：

  • -231 <= x <= 231 - 1
