并查集：两两判「相似」（差 0 处或差 2 处且互换相等），相似就合并，答案 = 分量个数。

思路

  • 相似判定一遍扫描：记录不同的位置，超过 2 处立刻 false；恰 2 处时验证交叉相等。
  • 先 find(i) != find(j) 再比字符串：同组的免比较，省掉大量重复判定。
  • 每成功合并一次组数减一；「A~B、B~C 但 A 不直接相似」由传递性自动归到同组。

1class Solution {2    int[] parent;3 4    public int numSimilarGroups(String[] strs) {5        int n = strs.length;6        parent = new int[n];7        for (int i = 0; i < n; i++) parent[i] = i;8        int groups = n;9        for (int i = 0; i < n; i++) {10            for (int j = i + 1; j < n; j++) {11                // 同组就免了再比字符串；相似才合并，每合并一次分量数减一12                if (find(i) != find(j) && similar(strs[i], strs[j])) {13                    parent[find(i)] = find(j);14                    groups--;15                }16            }17        }18        return groups;19    }20 21    // 相似：完全相同，或恰好两处不同且互换后相等22    private boolean similar(String a, String b) {23        int p = -1, q = -1;24        for (int i = 0; i < a.length(); i++) {25            if (a.charAt(i) != b.charAt(i)) {26                if (p < 0) p = i;27                else if (q < 0) q = i;28                else return false;   // 已经三处不同29            }30        }31        return p < 0   // 完全相同也算相似32            || (q >= 0 && a.charAt(p) == b.charAt(q) && a.charAt(q) == b.charAt(p));33    }34 35    private int find(int x) {36        while (parent[x] != x) {37            parent[x] = parent[parent[x]];38            x = parent[x];39        }40        return x;41    }42}
题目

如果交换字符串 X 中的两个不同位置的字母，使得它和字符串 Y 相等，那么称 X 和 Y 两个字符串相似。如果这两个字符串本身是相等的，那它们也是相似的。

例如，"tars" 和 "rats" 是相似的 (交换 0 与 2 的位置)； "rats" 和 "arts" 也是相似的，但是 "star" 不与 "tars"，"rats"，或 "arts" 相似。

总之，它们通过相似性形成了两个关联组：{"tars", "rats", "arts"} 和 {"star"}。注意，"tars" 和 "arts" 是在同一组中，即使它们并不相似。形式上，对每个组而言，要确定一个单词在组中，只需要这个词和该组中至少一个单词相似。

给你一个字符串列表 strs。列表中的每个字符串都是 strs 中其它所有字符串的一个字母异位词。请问 strs 中有多少个相似字符串组？

示例 1：

输入：strs = ["tars","rats","arts","star"]
输出：2

示例 2：

输入：strs = ["omv","ovm"]
输出：1

提示：

  • 1 <= strs.length <= 300
  • 1 <= strs[i].length <= 300
  • strs[i] 只包含小写字母。
  • strs 中的所有单词都具有相同的长度，且是彼此的字母异位词。
