1574. 删除最短的子数组使剩余数组有序

  • 单调栈
  • 待提交

先量出左升前缀和右升后缀，答案是「只留一边」或「前后缀拼接」三类候选的最小值；拼接用双指针找第一个能接上的位置。

思路

  • l 扫到左端最长非递减前缀的末尾，r 找右端最长非递减后缀的开头；l == n-1 说明本来有序，返回 0。
  • 两类平凡候选：只留前缀（删 n-1-l）或只留后缀（删 r）。
  • 拼接候选：i 在前缀里、j 在后缀里，要 arr[i] <= arr[j]，删中间 j-i-1 个；i 右移时 j 只会右移（单调）。
  • 关键不变量：删掉的窗口外两段必须各自非递减，这就是只用 l、r 作边界的原因。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int findLengthOfShortestSubarray(int[] arr) {3        int n = arr.length;4        int l = 0;                          // 左侧最长非递减前缀的末尾下标5        while (l + 1 < n && arr[l] <= arr[l + 1]) l++;6        if (l == n - 1) return 0;           // 整个数组已经有序7        int r = n - 1;                      // 右侧最长非递减后缀的开头下标8        while (r > 0 && arr[r - 1] <= arr[r]) r--;9        int ans = Math.min(n - 1 - l, r);   // 只留前缀 或 只留后缀10        // 再试「前缀 + 后缀」拼起来：i 在前缀里右移，j 在后缀里找第一个 >= arr[i] 的位置11        int i = 0, j = r;12        while (i <= l && j < n) {13            if (arr[i] <= arr[j]) { ans = Math.min(ans, j - i - 1); i++; }14            else j++;                       // arr[j] 太小，后缀起点右移15        }16        return ans;17    }18}
题目

给你一个整数数组 arr ，请你删除一个子数组（可以为空），使得 arr 中剩下的元素是 非递减 的。

一个子数组指的是原数组中连续的一个子序列。

请你返回满足题目要求的最短子数组的长度。

示例 1：

输入：arr = [1,2,3,10,4,2,3,5]
输出：3
解释：我们需要删除的最短子数组是 [10,4,2] ，长度为 3 。剩余元素形成非递减数组 [1,2,3,3,5] 。
另一个正确的解为删除子数组 [3,10,4] 。

示例 2：

输入：arr = [5,4,3,2,1]
输出：4
解释：由于数组是严格递减的，我们只能保留一个元素。所以我们需要删除长度为 4 的子数组，要么删除 [5,4,3,2]，要么删除 [4,3,2,1]。

示例 3：

输入：arr = [1,2,3]
输出：0
解释：数组已经是非递减的了，我们不需要删除任何元素。

示例 4：

输入：arr = [1]
输出：0

提示：

  • 1 <= arr.length <= 10^5
  • 0 <= arr[i] <= 10^9
