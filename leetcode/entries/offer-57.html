剑指 Offer 57. 查找总价格为目标值的两个商品

  • 简单
  • 频度 2
  • 双指针
  • 数组
  • 双指针
  • 二分查找
  • 待提交

升序数组用首尾双指针：和太大说明右边的数大了，收右；和太小说明左边的数小了，进左。

思路

  • l 从头、r 从尾：price[l] + price[r] > target 时 r--（换更小的数），< target 时 l++（换更大的数）。
  • 正确性：每次移动都淘汰掉一个不可能再配对的数，l、r 相遇前必找到答案。
  • 有序才敢这么跳：这是「排序 + 对撞双指针」的标配套路。

题目

购物车内的商品价格按照升序记录于数组 price。请在购物车中找到两个商品的价格总和刚好是 target。若存在多种情况，返回任一结果即可。

示例 1：

输入：price = [3, 9, 12, 15], target = 18
输出：[3,15] 或者 [15,3]

示例 2：

输入：price = [8, 21, 27, 34, 52, 66], target = 61
输出：[27,34] 或者 [34,27]

提示：

  • 1 <= price.length <= 10^5
  • 1 <= price[i] <= 10^6
  • 1 <= target <= 2*10^6
