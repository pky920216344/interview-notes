剑指 Offer 04. 寻找目标值 - 二维数组

  • 简单
  • 频度 35

  • 数组
  • 二分查找
  • 分治
  • 矩阵
  • 力扣已通过

从右上角出发：比目标大往左（整列排除），比目标小往下（整行排除），每步干掉一行或一列。

思路

  • 站在右上角 (0, m−1)：它是该行最大、该列最小，往左变小、往下变大，两个方向单调。
  • 当前值 > target：这一列剩下的都更大，整列排除，j--；< target：这一行剩下的都更小，整行排除，i++；相等就找到。
  • 每步一行或一列，最多 m+n 步；从左下角出发是对称做法（小往上、大往右）。
  • 空矩阵、空行：j 初始化为 -1，循环不进，直接 false。

1class Solution {2    public boolean findTargetIn2DPlants(int[][] plants, int target) {3        // 从右上角出发：它下面整列更大，左边整行更小4        int i = 0;5        int j = plants.length == 0 ? -1 : plants[0].length - 1;6        while (i < plants.length && j >= 0) {7            int v = plants[i][j];8            if (v == target) return true;9            // 大了：这列剩下的都更大，往左；小了：这行剩下的都更小，往下10            if (v > target) j--; else i++;11        }12        return false;13    }14}
题目

m*n 的二维数组 plants 记录了园林景观的植物排布情况，具有以下特性：

  • 每行中，每棵植物的右侧相邻植物不矮于该植物；
  • 每列中，每棵植物的下侧相邻植物不矮于该植物。

请判断 plants 中是否存在目标高度值 target。

示例 1：

输入：plants = [[2,3,6,8],[4,5,8,9],[5,9,10,12]], target = 8

输出：true

示例 2：

输入：plants = [[1,3,5],[2,5,7]], target = 4

输出：false

提示：

  • 0 <= n <= 1000
  • 0 <= m <= 1000
