1390. 四因数

对每个数枚举 i 到 √n 配对找全部因数 (i, n/i)，同时数个数、算和；恰有 4 个因数的才把因数和加进答案。

思路

  • 因数成对出现：i 是因数则 n/i 也是；枚举 i ≤ √n 一遍抓齐所有因数。
  • i == n/i（完全平方数）只算一个，否则一对算两个。
  • 恰 4 个因数的数只有两种形状：p³ 或 p·q（p、q 不同质数）——不用记，计数器自然判掉。

最优解

时间复杂度 O(n·√m)，空间复杂度 O(1)
1class Solution {2    public int sumFourDivisors(int[] nums) {3        int ans = 0;4        for (int n : nums) {5            // 枚举 i 到 sqrt(n)：每次抓到一对因数 (i, n/i)，因数个数和因数和同步累计6            int cnt = 0, sum = 0;7            for (int i = 1; i * i <= n; i++) {8                if (n % i != 0) continue;9                cnt++;10                sum += i;11                if (i != n / i) {12                    cnt++;13                    sum += n / i;14                }15            }16            // 因数恰好 4 个才把它的因数和计入答案17            if (cnt == 4) ans += sum;18        }19        return ans;20    }21}
题目

给你一个整数数组 nums，请你返回该数组中恰有四个因数的这些整数的各因数之和。如果数组中不存在满足题意的整数，则返回 0 。

示例 1：

输入：nums = [21,4,7]
输出：32
解释：
21 有 4 个因数：1, 3, 7, 21
4 有 3 个因数：1, 2, 4
7 有 2 个因数：1, 7
答案仅为 21 的所有因数的和。

示例 2:

输入: nums = [21,21]
输出: 64

示例 3:

输入: nums = [1,2,3,4,5]
输出: 0

提示：

  • 1 <= nums.length <= 104
  • 1 <= nums[i] <= 105
