长除法：先算整数部分，之后每步「余数×10 再除」得一位小数；余数重复出现 → 从它上次的位置开始就是循环节。

思路

  • 符号先定（两数异或），后面全按绝对值算；必须用 long：Integer.MIN_VALUE 取绝对值会溢出 int。
  • 每步 r *= 10 再除，商就是下一位小数，r %= b 是新余数；Map<余数, sb 位置> 记下每个余数首次出现的下标。
  • 余数变 0 → 有限小数，直接返回；余数重复 → 在它上次的位置插入 (，末尾补 )。

时间复杂度 O(循环节长)，空间复杂度 O(循环节长)
1import java.util.*;2 3class Solution {4    public String fractionToDecimal(int numerator, int denominator) {5        if (numerator == 0) return "0";6        StringBuilder sb = new StringBuilder();7        // 符号只由两数异号决定，先定下来，后面全按绝对值算8        if ((numerator < 0) != (denominator < 0)) sb.append('-');9        // 用 long：Integer.MIN_VALUE 的绝对值会溢出 int10        long a = Math.abs((long) numerator), b = Math.abs((long) denominator);11        sb.append(a / b);12        long r = a % b;13        if (r != 0) sb.append('.');   // 有小数部分才需要小数点14        // seen 记「余数 → 它产生的下一位小数在 sb 里的位置」15        Map<Long, Integer> seen = new HashMap<>();16        // 余数没重复就一直除下去；余数变 0 是有限小数17        while (r != 0 && !seen.containsKey(r)) {18            seen.put(r, sb.length());19            r *= 10;20            sb.append(r / b);21            r %= b;22        }23        // 余数重复：循环节从它上次出现的位置开始，套上括号24        if (r != 0) sb.insert(seen.get(r), "(").append(')');25        return sb.toString();26    }27}
题目

给定两个整数，分别表示分数的分子 numerator 和分母 denominator，以 字符串形式返回小数 。

如果小数部分为循环小数，则将循环的部分括在括号内。

如果存在多个答案，只需返回 任意一个 。

对于所有给定的输入，保证 答案字符串的长度小于 104 。

注意，如果分数可以表示为有限长度的字符串，则 必须 返回它。

示例 1：

输入：numerator = 1, denominator = 2
输出："0.5"

示例 2：

输入：numerator = 2, denominator = 1
输出："2"

示例 3：

输入：numerator = 4, denominator = 333
输出："0.(012)"

提示：

  • -231 <= numerator, denominator <= 231 - 1
  • denominator != 0
