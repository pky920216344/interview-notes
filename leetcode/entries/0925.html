925. 长按键入

  • 简单
  • 频度 1
  • 双指针
  • 双指针
  • 字符串
  • 待提交

双指针：typed 的字符能对上 name[i] 就前进 i，否则必须和前一格相同（长按）；最后 i 要走完 name。

思路

  • i 指向 name 中下一个待匹配的字符，j 扫 typed；对上了就 i++。
  • 对不上时只有一种合法情况：typed[j] == typed[j-1]（长按产生的重复），否则直接 false。
  • 关键坑：typed 里多出来的重复段必须是 name 已有字符的长按；出现 name 没有的字符就 false。
  • 循环结束还要 i == name.length：typed 比 name 短时补不回来。

最优解

时间复杂度 O(n+m)，空间复杂度 O(1)
1class Solution {2    public boolean isLongPressedName(String name, String typed) {3        int i = 0;4        // j 扫 typed：能对上 name[i] 就前进 i；否则必须是「长按」的重复字符5        for (int j = 0; j < typed.length(); j++) {6            if (i < name.length() && name.charAt(i) == typed.charAt(j)) i++;7            else if (j == 0 || typed.charAt(j) != typed.charAt(j - 1)) return false;8        }9        // name 没被匹配完，说明 typed 缺字符10        return i == name.length();11    }12}
题目

你的朋友正在使用键盘输入他的名字 name。偶尔，在键入字符 c 时，按键可能会被长按，而字符可能被输入 1 次或多次。

你将会检查键盘输入的字符 typed。如果它对应的可能是你的朋友的名字（其中一些字符可能被长按），那么就返回 True。

示例 1：

输入：name = "alex", typed = "aaleex"
输出：true
解释：'alex' 中的 'a' 和 'e' 被长按。

示例 2：

输入：name = "saeed", typed = "ssaaedd"
输出：false
解释：'e' 一定需要被键入两次，但在 typed 的输出中不是这样。

提示：

  • 1 <= name.length, typed.length <= 1000
  • name 和 typed 的字符都是小写字母
