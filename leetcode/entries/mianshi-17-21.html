双指针从两端向中间夹逼：两侧最大值谁小，那一端的真实水位就已确定，先结算再收指针。

思路

  • 每列水位 = min(左侧最大, 右侧最大)；夹逼时较小一侧的最大值就是它的真实水位。
  • 更新后若 leftMax <= rightMax：左端水 = leftMax - height[left]（右边必还有更高的墙兜底），结算后 left++。
  • 否则对称地结算右端 right--；两指针相遇时全部列结算完毕。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int trap(int[] height) {3        int left = 0, right = height.length - 1;4        int leftMax = 0, rightMax = 0, water = 0;5        while (left < right) {6            leftMax = Math.max(leftMax, height[left]);7            rightMax = Math.max(rightMax, height[right]);8            // 水位 = 两侧最大值中较小者：低的一侧答案已定，先结算它9            if (leftMax <= rightMax) water += leftMax - height[left++];10            else water += rightMax - height[right--];11        }12        return water;13    }14}
题目

给定一个直方图(也称柱状图)，假设有人从上面源源不断地倒水，最后直方图能存多少水量?直方图的宽度为 1。

上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的直方图，在这种情况下，可以接 6 个单位的水（蓝色部分表示水）。 感谢 Marcos 贡献此图。

示例：

输入：[0,1,0,2,1,0,1,3,2,1,2,1]
