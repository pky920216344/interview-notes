751. IP 到 CIDR

  • 简单
  • 频度 2
  • 贪心
  • 位运算
  • 位运算
  • 字符串
  • 未经力扣验证

贪心切最大块：每步块大小取「start 末尾 0 允许的对齐上限」和「不超过 n 的最大 2 的幂」中较小者。

思路

  • CIDR /x 块覆盖 2^(32-x) 个地址，且起点必须按块大小对齐：start 末尾有 t 个 0 就最多切 2^t。
  • 块大小还受剩余量约束：不能超过 n，即取不大于 n 的最大 2 的幂；两者取小，切完 start += 块大小。
  • 每块都是「起点能对齐出的最大块」，块数最少；n 与 start 都用 long 存避免符号位干扰。
  • 口诀：块 2^len 个地址对应前缀 /(32-len)；255.0.0.7 起步只能 /32，走到对齐的 .8 就能 /29。

最优解

时间复杂度 O(输出块数)，最多 64 块，空间复杂度 O(1)（不计输出）
1import java.util.*;2 3class Solution {4    public List<String> ipToCIDR(String ip, int n) {5        // IP 转成 32 位无符号整数（用 long 存，避免符号位干扰）6        long start = 0;7        for (String part : ip.split("\\.")) start = (start << 8) | Long.parseLong(part);8        List<String> ans = new ArrayList<>();9        while (n > 0) {10            // 块大小取两个上限的较小者：start 末尾 0 允许的对齐上限、不超过 n 的最大 2 的幂11            int align = start == 0 ? 32 : Long.numberOfTrailingZeros(start);12            int cap = 31 - Integer.numberOfLeadingZeros(n);   // floor(log2(n))，块最大 2^cap13            int len = Math.min(align, cap);                   // 块覆盖 2^len 个地址14            ans.add(toIp(start) + "/" + (32 - len));15            n -= 1 << len;16            start += 1L << len;17        }18        return ans;19    }20 21    // 32 位整数还原成点分十进制（掩码保证不越界）22    private String toIp(long v) {23        v &= 0xFFFFFFFFL;24        return (v >>> 24) + "." + ((v >>> 16) & 255) + "." + ((v >>> 8) & 255) + "." + (v & 255);25    }26}
