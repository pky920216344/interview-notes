1485. 按日期分组销售产品

  • 简单
  • 频度 1
  • SQL
  • 数据库
  • 待提交

按 sell_date 分组：COUNT(DISTINCT product) 数不同产品，GROUP_CONCAT(DISTINCT product ORDER BY product) 输出排序后的清单。

思路

  • COUNT(DISTINCT product) 数每个日期的不同产品数——同一产品同日卖多次只算一次。
  • GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',')：DISTINCT 去重 + ORDER BY 在聚合内排序（聚合函数内的 ORDER BY 才能保证拼接顺序，外层排序管不了组内）。
  • 默认分隔符就是逗号，SEPARATOR ',' 可省略但写明更稳。
  • 整体按 sell_date 排序输出。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1-- 1485（codetop 1485）按日期分组销售产品（MySQL）2-- 题意：Activities(sell_date, product)。找出每个日期销售的不同产品数量与名称（名称按字典序排列），按 sell_date 排序。3-- GROUP_CONCAT 默认以逗号连接；要字典序需在聚合前排序（GROUP_CONCAT(ORDER BY product)）。4SELECT sell_date,5       COUNT(DISTINCT product) AS num_sold,6       GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',') AS products7FROM Activities8GROUP BY sell_date9ORDER BY sell_date;
题目

表 Activities：

+-------------+---------+
| 列名         | 类型    |
+-------------+---------+
| sell_date   | date    |
| product     | varchar |
+-------------+---------+
该表没有主键(具有唯一值的列)。它可能包含重复项。
此表的每一行都包含产品名称和在市场上销售的日期。

编写解决方案找出每个日期、销售的不同产品的数量及其名称。
每个日期的销售产品名称应按词典序排列。
返回按 sell_date 排序的结果表。
结果表结果格式如下例所示。

示例 1:

输入：
Activities 表：
+------------+-------------+
| sell_date  | product     |
+------------+-------------+
| 2020-05-30 | Headphone   |
| 2020-06-01 | Pencil      |
| 2020-06-02 | Mask        |
| 2020-05-30 | Basketball  |
| 2020-06-01 | Bible       |
| 2020-06-02 | Mask        |
| 2020-05-30 | T-Shirt     |
+------------+-------------+
输出：
+------------+----------+------------------------------+
| sell_date  | num_sold | products                     |
+------------+----------+------------------------------+
| 2020-05-30 | 3        | Basketball,Headphone,T-shirt |
| 2020-06-01 | 2        | Bible,Pencil                 |
| 2020-06-02 | 1        | Mask                         |
+------------+----------+------------------------------+
解释：
对于2020-05-30，出售的物品是 (Headphone, Basketball, T-shirt)，按词典序排列，并用逗号 ',' 分隔。
对于2020-06-01，出售的物品是 (Pencil, Bible)，按词典序排列，并用逗号分隔。
对于2020-06-02，出售的物品是 (Mask)，只需返回该物品名。
