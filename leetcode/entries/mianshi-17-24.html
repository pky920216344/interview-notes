面试题 17.24. 最大子矩阵

  • 困难
  • 频度 20
  • 动态规划
  • 前缀和/差分
  • 数组
  • 动态规划
  • 矩阵
  • 前缀和
  • 力扣已通过

枚举上下边界把矩阵压成一维列和数组，对它跑 Kadane 找最大子段，顺便记下四角坐标。

思路

  • 枚举上边界 top，下边界 bottom 从 top 往下扩；colSum[j] 随 bottom 逐行累加，就是这两行之间每一列的和。
  • 对 colSum 跑 Kadane：cur 负了就丢掉前缀、start = j + 1 重开，cur 超过 best 就记下四角 (top, start, bottom, j)。
  • 先更新答案再判负重置，全负矩阵也能正确取到最大的单格。
  • 本质：把二维最大子矩阵问题降维成 rows² 次一维最大子段和。

最优解

时间复杂度 O(rows² × cols)，空间复杂度 O(cols)
1import java.util.*;2 3class Solution {4    public int[] getMaxMatrix(int[][] matrix) {5        int rows = matrix.length, cols = matrix[0].length;6        int best = Integer.MIN_VALUE, r1 = 0, c1 = 0, r2 = 0, c2 = 0;7        int[] colSum = new int[cols];   // 上下边界之间每一列的和8        for (int top = 0; top < rows; top++) {9            Arrays.fill(colSum, 0);   // 上边界换了，列和重新累计10            for (int bottom = top; bottom < rows; bottom++) {11                // 下边界每扩一行，colSum 就变成一维数组的最大子段问题12                for (int j = 0; j < cols; j++) colSum[j] += matrix[bottom][j];13                int cur = 0, start = 0;14                for (int j = 0; j < cols; j++) {15                    cur += colSum[j];16                    if (cur > best) {   // 当前方块 [top..bottom] × [start..j] 更大17                        best = cur;18                        r1 = top; c1 = start; r2 = bottom; c2 = j;19                    }20                    if (cur < 0) { cur = 0; start = j + 1; }   // 前缀是负资产，丢掉重开21                }22            }23        }24        return new int[]{r1, c1, r2, c2};25    }26}
题目

给定一个正整数、负整数和 0 组成的 N × M 矩阵，编写代码找出元素总和最大的子矩阵。

返回一个数组 [r1, c1, r2, c2]，其中 r1, c1 分别代表子矩阵左上角的行号和列号，r2, c2 分别代表右下角的行号和列号。若有多个满足条件的子矩阵，返回任意一个均可。

注意：本题相对书上原题稍作改动

示例：

输入：
[
   [-1,0],
   [0,-1]
]
输出：[0,1,0,1]
解释：输入中标粗的元素即为输出所表示的矩阵

说明：

  • 1 <= matrix.length, matrix[0].length <= 200
