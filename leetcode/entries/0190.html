190. 颠倒二进制位

  • 简单
  • 频度 3
  • 位运算
  • 位运算
  • 分治
  • 待提交

逐位拼回：每轮把 n 的最低位取出来，先让 ans 左移腾位再拼上；32 轮后位序正好颠倒。

思路

  • 固定循环 32 次：ans = (ans << 1) | (n & 1)，再 n >>>= 1 丢掉已取的位。
  • n & 1 取最低位；用无符号右移 >>>，负数也按位图案处理，不会符号扩展。
  • 原理：第 i 轮拼入的位在 ans 里被后续左移推到第 31-i 位，正好完成整个颠倒。

题目

颠倒给定的 32 位有符号整数的二进制位。

示例 1：

输入：n = 43261596

输出：964176192

解释：

整数 二进制
43261596 00000010100101000001111010011100
964176192 00111001011110000010100101000000

示例 2：

输入：n = 2147483644

输出：1073741822

解释：

整数 二进制
2147483644 01111111111111111111111111111100
1073741822 00111111111111111111111111111110

提示：

  • 0 <= n <= 231 - 2
  • n 为偶数
