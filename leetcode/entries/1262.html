1262. 可被三整除的最大和

  • 频度 20

  • 贪心
  • 数组
  • 动态规划
  • 排序
  • 力扣已通过

求出总和；若余 1 就减去「最小的余 1 数」或「两个最小的余 2 数」中较小的代价，余 2 对称。

思路

  • 全选的总和 total 是上界，只需减掉最少的数让总和余 0：余 1 时减掉的集合要余 1，余 2 时要余 2。
  • 每个余数类只记最小的两个数（a[r]、b[r]，没有记成 MAX）：要减就减最小的，损失才最小。
  • 余 1 的两类减法：减一个余 1 的（a[1]），或减两个余 2 的（a[2]+b[2]）；余 2 对称。三个以上的减法每个数都 ≥ 1，代价必更大，不用考虑。
  • 若 a[r] 不存在（是 MAX），另一类减法一定存在（总和余 r 蕴含了它），不会漏。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxSumDivThree(int[] nums) {3        final int BIG = Integer.MAX_VALUE;4        int total = 0;5        // a[r]、b[r]：余数为 r 的数里最小的两个，没有就记 BIG6        int[] a = {BIG, BIG, BIG}, b = {BIG, BIG, BIG};7        for (int x : nums) {8            total += x;9            int r = x % 3;10            if (x < a[r]) { b[r] = a[r]; a[r] = x; }11            else if (x < b[r]) b[r] = x;12        }13        if (total % 3 == 0) return total;14        // 总和余 r：减一个余 r 的最小数，或两个余 3-r 的最小数15        int r = total % 3, other = 3 - r;16        int cost = a[r];17        if (b[other] != BIG) cost = Math.min(cost, a[other] + b[other]);18        return total - cost;19    }20}
题目

给你一个整数数组 nums，请你找出并返回能被三整除的元素 最大和。

示例 1：

输入：nums = [3,6,5,1,8]
输出：18
解释：选出数字 3, 6, 1 和 8，它们的和是 18（可被 3 整除的最大和）。

示例 2：

输入：nums = [4]
输出：0
解释：4 不能被 3 整除，所以无法选出数字，返回 0。

示例 3：

输入：nums = [1,2,3,4,4]
输出：12
解释：选出数字 1, 3, 4 以及 4，它们的和是 12（可被 3 整除的最大和）。

提示：

  • 1 <= nums.length <= 4 * 104
  • 1 <= nums[i] <= 104
