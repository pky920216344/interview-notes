311. 稀疏矩阵的乘法

  • 中等
  • 频度 5
  • 模拟
  • 数组
  • 哈希表
  • linear-algebra
  • 矩阵
  • 未经力扣验证

不按定义硬乘三重循环：外层只枚举 A 的非零项，A[i][k]=0 时 B 的整行直接跳过。

思路

  • 把循环次序改成 i → k → j：内两层只在 mat[i][k] ≠ 0 时展开，0 直接 continue。
  • 展开时一行搞定：res[i][j] += a × mat2[k][j]，即把 B 的第 k 行按倍数 a 累加进 res 的第 i 行。
  • 0 越多省得越多，最坏（全非零）退化为普通三重循环，但不会更差。

最优解

时间复杂度 O(m·k·n)，非零项少时远快，空间复杂度 O(1)（不计输出）
1class Solution {2    public int[][] multiply(int[][] mat, int[][] mat2) {3        int m = mat.length, n = mat2[0].length;4        int[][] res = new int[m][n];5        for (int i = 0; i < m; i++) {6            for (int k = 0; k < mat[i].length; k++) {7                // A 的 0 跳过：B 的整行都不用乘，稀疏性就省在这里8                if (mat[i][k] == 0) continue;9                int a = mat[i][k];10                for (int j = 0; j < n; j++)11                    res[i][j] += a * mat2[k][j];12            }13        }14        return res;15    }16}
