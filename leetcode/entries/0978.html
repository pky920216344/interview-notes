978. 最长湍流子数组

  • 动态规划
  • 滑动窗口

双状态 DP：up[i] 是「以 i 结尾、末步上升」的最长湍流，down[i] 是末步下降的；方向一换就交替接力，相等就归 1。

思路

  • 湍流 = 相邻比较符号严格交替。以 i 结尾的湍流只分两种：末步上升（up）和末步下降（down），滚动变量即可。
  • arr[i] > arr[i-1] 时 up = down + 1：新段只能接在「末步下降」的段后面；down 重置为 1。
  • arr[i] < arr[i-1] 时对称地 down = up + 1；相邻相等时两个状态都要重置为 1，这是最容易漏的分支。
  • 每步用 max(up, down) 更新答案。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxTurbulenceSize(int[] arr) {3        // up：以 i 结尾、最后一步上升的湍流长度；down：最后一步下降4        int up = 1, down = 1, ans = 1;5        for (int i = 1; i < arr.length; i++) {6            if (arr[i] > arr[i - 1]) {7                // 升：接在「以上一步结尾是下降」的段后面8                up = down + 1;9                down = 1;10            } else if (arr[i] < arr[i - 1]) {11                // 降：接在「以上一步结尾是上升」的段后面12                down = up + 1;13                up = 1;14            } else {15                // 相等：两边的段都断，长度重置为 116                up = down = 1;17            }18            ans = Math.max(ans, Math.max(up, down));19        }20        return ans;21    }22}
题目

给定一个整数数组 arr ，返回 arr 的 最大湍流子数组的长度。

如果比较符号在子数组中的每个相邻元素对之间翻转，则该子数组是 湍流子数组 。

更正式地来说，当 arr 的子数组 A[i], A[i+1], ..., A[j] 满足仅满足下列条件时，我们称其为湍流子数组：

  • 若 i <= k < j ：
    • 当 k 为奇数时， A[k] > A[k+1]，且
    • 当 k 为偶数时，A[k] < A[k+1]；
  • 或 若 i <= k < j ：
    • 当 k 为偶数时，A[k] > A[k+1] ，且
    • 当 k 为奇数时， A[k] < A[k+1]。

示例 1：

输入：arr = [9,4,2,10,7,8,8,1,9]
输出：5
解释：arr[1] > arr[2] < arr[3] > arr[4] < arr[5]

示例 2：

输入：arr = [4,8,12,16]
输出：2

示例 3：

输入：arr = [100]
输出：1

提示：

  • 1 <= arr.length <= 4 * 104
  • 0 <= arr[i] <= 109
