1200. 最小绝对差

  • 简单
  • 频度 1
  • 模拟
  • 数组
  • 排序
  • 待提交

排序后最小差只会出现在相邻两数之间；扫一遍相邻对，差更小就清空重来，相等就继续收集。

思路

  • 先 sort：任意两数的差 ≥ 某个相邻对的差，所以只需检查 n−1 个相邻对。
  • 差 d 比 minDiff 小：清空答案、更新 minDiff、收下这对；d == minDiff 就追加。
  • 排序保证扫出的对天然按首个元素升序，无需再排。

最优解

时间复杂度 O(n log n)，空间复杂度 O(1)（不计输出）
1import java.util.*;2 3class Solution {4    public List<List<Integer>> minimumAbsDifference(int[] arr) {5        Arrays.sort(arr);6        List<List<Integer>> ans = new ArrayList<>();7        int minDiff = Integer.MAX_VALUE;8        // 排序后最小差只会出现在相邻两数之间，逐对检查即可9        for (int i = 1; i < arr.length; i++) {10            int d = arr[i] - arr[i - 1];11            if (d < minDiff) {12                minDiff = d;                        // 出现更小的差：之前收集的作废13                ans.clear();14                ans.add(Arrays.asList(arr[i - 1], arr[i]));15            } else if (d == minDiff) {16                ans.add(List.of(arr[i - 1], arr[i]));17            }18        }19        return ans;20    }21}
题目

给你个整数数组 arr，其中每个元素都 不相同。

请你找到所有具有最小绝对差的元素对，并且按升序的顺序返回。

每对元素对 [a,b] 如下：

  • a , b 均为数组 arr 中的元素
  • a < b
  • b - a 等于 arr 中任意两个元素的最小绝对差

示例 1：

输入：arr = [4,2,1,3]
输出：[[1,2],[2,3],[3,4]]

示例 2：

输入：arr = [1,3,6,10,15]
输出：[[1,3]]

示例 3：

输入：arr = [3,8,-10,23,19,-4,-14,27]
输出：[[-14,-10],[19,23],[23,27]]

提示：

  • 2 <= arr.length <= 10^5
  • -10^6 <= arr[i] <= 10^6
