排序后只有「在哪分割」一种自由度：前段全部 +k、后段全部 -k，枚举分割点用 max/min 直接算新差值，取最小。

思路

  • 同加同减不改变最大最小差，所以最优解一定长这样：排序后某一段全 +k，其余全 -k，只有分割点要枚举。
  • 分割后差值 = max(nums[i]+k, 末尾-k) - min(开头+k, nums[i+1]-k)，四端点直接算，不用重建数组。
  • 先按「全 +k」把答案设为 末尾 - 开头，再逐个分割点收紧；分割点在末尾之前不存在（全 +k 已算过）。

最优解

时间复杂度 O(n log n)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int smallestRangeII(int[] nums, int k) {5        Arrays.sort(nums);6        int n = nums.length;7        // 全部同加同减不改变差值，等于全部 +k 的基准答案8        int ans = nums[n - 1] - nums[0];9        // 枚举分割点：前 i+1 个 +k，其余 -k（只有「在哪分割」一种自由度）10        for (int i = 0; i < n - 1; i++) {11            // 前段最大是 nums[i]+k，后段最大是末尾 -k12            int high = Math.max(nums[i] + k, nums[n - 1] - k);13            // 首元素 +k 与分割后第一个 -k 里取小者14            int low = Math.min(nums[0] + k, nums[i + 1] - k);15            ans = Math.min(ans, high - low);16        }17        return ans;18    }19}
题目

给你一个整数数组 nums，和一个整数 k 。

对于每个下标 i（0 <= i < nums.length），将 nums[i] 变成 nums[i] + k 或 nums[i] - k 。

nums 的 分数 是 nums 中最大元素和最小元素的差值。

在更改每个下标对应的值之后，返回 nums 的最小 分数 。

示例 1：

输入：nums = [1], k = 0
输出：0
解释：分数 = max(nums) - min(nums) = 1 - 1 = 0 。

示例 2：

输入：nums = [0,10], k = 2
输出：6
解释：将数组变为 [2, 8] 。分数 = max(nums) - min(nums) = 8 - 2 = 6 。

示例 3：

输入：nums = [1,3,6], k = 3
输出：3
解释：将数组变为 [4, 6, 3] 。分数 = max(nums) - min(nums) = 6 - 3 = 3 。

提示：

  • 1 <= nums.length <= 104
  • 0 <= nums[i] <= 104
  • 0 <= k <= 104
