补充题9. 36进制加法

  • 中等
  • 频度 25
  • 模拟
  • 双指针
  • 未经力扣验证

和十进制竖式加法一样：从最低位逐位相加、满 36 进一；'0'-'9' 与 'a'-'z' 各做一次 数字↔字符 互转，低位拼完 reverse。

思路

  • 双指针从两个串的末尾往前走：sum = 两位数字 + 进位，本位写 sum % 36，进位 sum / 36。
  • 一方走完就只加另一方的位；两边走完还有进位就再补一位（zz + 1 = 100 就是典型）。
  • 数字 ↔ 字符：'0'..'9' → 0..9，'a'..'z' → 10..35，写出时反向转换。
  • 结果是低位在前拼出来的，最后 reverse 一次。

时间复杂度 O(max(|a|, |b|))，空间复杂度 O(1)（不计输出）
1class Solution {2    // 36 进制加法：a、b 是 0-9、a-z 组成的非负整数，返回它们的和（同样 36 进制）3    public String add36(String a, String b) {4        int i = a.length() - 1, j = b.length() - 1, carry = 0;5        StringBuilder sb = new StringBuilder();6        while (i >= 0 || j >= 0 || carry > 0) {7            // 从最低位开始：两位数字相加，再加低位进位8            int sum = carry;9            if (i >= 0) sum += digit(a.charAt(i--));10            if (j >= 0) sum += digit(b.charAt(j--));11            sb.append(charOf(sum % 36));   // 本位12            carry = sum / 36;              // 满 36 进一13        }14        return sb.reverse().toString();15    }16 17    // '0'-'9' → 0..9，'a'-'z' → 10..3518    private int digit(char c) {19        return c <= '9' ? c - '0' : c - 'a' + 10;20    }21 22    // 反向：0..9 → '0'-'9'，10..35 → 'a'-'z'23    private char charOf(int d) {24        return d < 10 ? (char) ('0' + d) : (char) ('a' + d - 10);25    }26}
