779. 第K个语法符号

  • 中等

  • 位运算
  • 递归
  • 数学
  • 待提交

从 (n, k) 一路回推到根：k 是偶数位就把翻转次数加一并走到上位 k=⌈k/2⌉，到根后答案 = 翻转次数的奇偶。

思路

  • 生成规则 0→01、1→10：一对里左位继承父位、右位是父位取反，所以第 k 位（1 起始）是偶数位时相对父位翻转一次。
  • 父位下标：k = ⌈k/2⌉，一路回推到 k = 1（第 1 行的 0）。
  • 答案 = 回推路上翻转次数的奇偶；等价写法是 bitCount(k−1) & 1。
  • 行数 n 不影响答案：只要 k ≤ 2^(n−1)，每一行都是同一棵二叉树的不同深度切片。

时间复杂度 O(log k)，空间复杂度 O(1)
1class Solution {2    public int kthGrammar(int n, int k) {3        // 从 (n, k) 一路回推到根：k 落在偶数位说明这一位是父位取反4        int flips = 0;5        while (k > 1) {6            if ((k & 1) == 0) flips++;7            k = (k + 1) / 2;8        }9        // 根是 0；翻转次数的奇偶决定最终值（等价于 bitCount(k-1) 的奇偶）10        return flips & 1;11    }12}
题目

我们构建了一个包含 n 行( 索引从 1  开始 )的表。首先在第一行我们写上一个 0。接下来的每一行，将前一行中的0替换为01，1替换为10。

  • 例如，对于 n = 3 ，第 1 行是 0 ，第 2 行是 01 ，第3行是 0110 。

给定行数 n 和序数 k，返回第 n 行中第 k 个字符。（ k 从索引 1 开始）


示例 1:

输入: n = 1, k = 1
输出: 0
解释: 第一行：0

示例 2:

输入: n = 2, k = 1
输出: 0
解释: 
第一行: 0 
第二行: 01

示例 3:

输入: n = 2, k = 2
输出: 1
解释:
第一行: 0
第二行: 01

提示:

  • 1 <= n <= 30
  • 1 <= k <= 2n - 1
