KMP 自匹配：构造 s + '#' + reverse(s)，next 末值就是 s 的最长回文前缀长度；把剩余尾巴反转接到开头。

思路

  • 要补的字符被回文约束唯一确定：前置串 = s 去掉最长回文前缀后的尾巴的反转，所以只需求最长回文前缀。
  • 求「前缀 = 反转前缀」用 KMP 自匹配：t = s + '#' + rev，# 挡住跨界匹配，next[t.len-1] 即最长回文前缀长度。
  • KMP 的 j 失配时跳 next[j-1]，匹配则 j++；末位置的 j 就是答案长度 len。
  • 结果 = rev 的前 n−len 个字符 + s；空串时 next 全 0，自然返回空串。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public String shortestPalindrome(String s) {3        // 拼 s + '#' + 反转(s)：KMP next 末值 = s 的最长回文前缀长度4        String rev = new StringBuilder(s).reverse().toString();5        String t = s + '#' + rev;6        int n = t.length();7        // next[i]：t[0..i] 最长的相等真前后缀长度8        int[] next = new int[n];9        for (int i = 1, j = 0; i < n; i++) {10            // 失配就顺着 next 回跳，跳过不可能的长度11            while (j > 0 && t.charAt(i) != t.charAt(j)) j = next[j - 1];12            if (t.charAt(i) == t.charAt(j)) j++;13            next[i] = j;14        }15        int len = next[n - 1];16        // s 没被回文前缀盖住的尾巴，反转后补到开头17        return rev.substring(0, s.length() - len) + s;18    }19}
题目

给定一个字符串 s，你可以通过在字符串前面添加字符将其转换为回文串。找到并返回可以用这种方式转换的最短回文串。

示例 1：

输入：s = "aacecaaa"
输出："aaacecaaa"

示例 2：

输入：s = "abcd"
输出："dcbabcd"

提示：

  • 0 <= s.length <= 5 * 104
  • s 仅由小写英文字母组成
