35. 搜索插入位置

  • 简单
  • 频度 8
  • 二分查找
  • 数组
  • 二分查找
  • 待提交

二分找 lowerBound：第一个 ≥ target 的下标——target 存在时就是它的下标，不存在时就是插入位置。

思路

  • 「插入位置」就是 lowerBound：第一个满足 nums[i] ≥ target 的下标；target 已存在时正好落在它自己身上。
  • 左闭右开区间 [left, right)：nums[mid] ≥ target 说明答案在 mid 或它左边，right = mid；否则 left = mid + 1。
  • 循环到 left == right 结束，left 就是答案；全都小于 target 时 left 停在 nums.length，即插到末尾。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int searchInsert(int[] nums, int target) {3        // 就是 lowerBound：第一个 ≥ target 的下标；全都小于 target 时就是 nums.length4        int left = 0, right = nums.length;   // 左闭右开 [left, right)5        while (left < right) {6            int mid = (left + right) >>> 1;7            // nums[mid] ≥ target：mid 可能就是答案，缩右边界8            if (nums[mid] >= target) right = mid;9            else left = mid + 1;10        }11        return left;12    }13}
题目

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 O(log n) 的算法。

示例 1:

输入: nums = [1,3,5,6], target = 5
输出: 2

示例 2:

输入: nums = [1,3,5,6], target = 2
输出: 1

示例 3:

输入: nums = [1,3,5,6], target = 7
输出: 4

提示:

  • 1 <= nums.length <= 104
  • -104 <= nums[i] <= 104
  • nums 为 无重复元素 的 升序 排列数组
  • -104 <= target <= 104
