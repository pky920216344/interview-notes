回溯：前两段自由切，之后每段必须等于前两段之和；切完整串即成功，走不通就吐段回溯。

思路

  • 从左往右切段：list 里已有两段以上时，新段的值必须等于前两段之和，否则不用再试。
  • 剪枝都在段长上：值比 need 小就再加一位（continue），比 need 大或超 int、或撞前导零就放弃整支（break）——更长的段只会更大。
  • 用 long 解析段值，超过 Integer.MAX_VALUE 直接判死；"0" 只能单独成段。
  • 切到串尾且段数 ≥ 3 就成功；否则回溯换切法。

1import java.util.ArrayList;2import java.util.List;3 4class Solution {5    private List<Integer> list;6 7    public List<Integer> splitIntoFibonacci(String num) {8        list = new ArrayList<>();9        return dfs(num, 0) ? list : new ArrayList<>();10    }11 12    // 从 pos 切出下一段；list 已有两段以上时，这一段必须等于前两段之和13    private boolean dfs(String num, int pos) {14        if (pos == num.length()) return list.size() >= 3;15        long v = 0;   // 当前段用 long 解析，一超 int 立即判死16        for (int end = pos + 1; end <= num.length(); end++) {17            // 前导零：只有 "0" 本身合法18            if (num.charAt(pos) == '0' && end > pos + 1) break;19            v = v * 10 + (num.charAt(end - 1) - '0');20            if (v > Integer.MAX_VALUE) break;21            if (list.size() >= 2) {22                long need = (long) list.get(list.size() - 2) + list.get(list.size() - 1);23                if (v < need) continue;   // 这段还太短，再加一位才可能凑到24                if (v > need) break;      // 已经过头，更长的段只会更大25            }26            list.add((int) v);27            if (dfs(num, end)) return true;28            list.remove(list.size() - 1);29        }30        return false;31    }32}
题目

给定一个数字字符串 num，比如 "123456579"，我们可以将它分成「斐波那契式」的序列 [123, 456, 579]。

形式上，斐波那契式 序列是一个非负整数列表 f，且满足：

  • 0 <= f[i] < 231 ，（也就是说，每个整数都符合 32 位 有符号整数类型）
  • f.length >= 3
  • 对于所有的0 <= i < f.length - 2，都有 f[i] + f[i + 1] = f[i + 2]

另外，请注意，将字符串拆分成小块时，每个块的数字一定不要以零开头，除非这个块是数字 0 本身。

返回从 num 拆分出来的任意一组斐波那契式的序列块，如果不能拆分则返回 []。

示例 1：

输入：num = "1101111"
输出：[11,0,11,11]
解释：输出 [110,1,111] 也可以。

示例 2：

输入: num = "112358130"
输出: []
解释: 无法拆分。

示例 3：

输入："0123"
输出：[]
解释：每个块的数字不能以零开头，因此 "01"，"2"，"3" 不是有效答案。

提示：

  • 1 <= num.length <= 200
  • num 中只含有数字
