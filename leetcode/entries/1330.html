1330. 翻转子数组得到最大的数组值

翻转只影响左右两条边界，把边界增益用 |x−y| 拆符号后取到 2*(maxMin−minMax)，端点翻转单独枚举，整体 O(n)。

思路

  • base = 相邻差之和；翻 [l,r] 只改 (l−1,l) 和 (r,r+1) 两条边界，中间的差翻转后不变。
  • 端点情形（翻前缀 [0,i] / 翻后缀 [i+1,n−1]）只动一条边界：base − cut + |新差|，逐条边试。
  • 内部翻转动两条边界：对增益式用 |x−y| = max(x−y, y−x) 拆符号，混合符号的候选恒 ≤ 0，有用的只剩 2*min(某边) − 2*max(另一边)，取到最大就是 2*(maxMin − minMax)，其中 maxMin/minMax 是每条边 min 的最大值 / 每条边 max 的最小值。
  • 答案 = max(base, base + 端点增益, base + 2*(maxMin − minMax))。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxValueAfterReverse(int[] nums) {3        int n = nums.length;4        int base = 0;5        for (int i = 0; i + 1 < n; i++) {6            base += Math.abs(nums[i] - nums[i + 1]);   // 原始数组值7        }8        int ans = base;9        // 翻前缀 [0,i] / 翻后缀 [i+1,n-1]：只动一条边界，逐个试10        for (int i = 0; i + 1 < n; i++) {11            int cut = Math.abs(nums[i] - nums[i + 1]);12            ans = Math.max(ans, base - cut + Math.abs(nums[0] - nums[i + 1]));13            ans = Math.max(ans, base - cut + Math.abs(nums[i] - nums[n - 1]));14        }15        // 内部翻转动左右两条边界，增益拆成 2*(min 较大边 − max 较小边)16        int maxMin = Integer.MIN_VALUE, minMax = Integer.MAX_VALUE;17        for (int i = 0; i + 1 < n; i++) {18            maxMin = Math.max(maxMin, Math.min(nums[i], nums[i + 1]));19            minMax = Math.min(minMax, Math.max(nums[i], nums[i + 1]));20        }21        ans = Math.max(ans, base + 2 * (maxMin - minMax));22        return ans;23    }24}
题目

给你一个整数数组 nums 。「数组值」定义为所有满足 0 <= i < nums.length-1 的 |nums[i]-nums[i+1]| 的和。

你可以选择给定数组的任意子数组，并将该子数组翻转。但你只能执行这个操作 一次 。

请你找到可行的最大 数组值 。

示例 1：

输入：nums = [2,3,1,5,4]
输出：10
解释：通过翻转子数组 [3,1,5] ，数组变成 [2,5,1,3,4] ，数组值为 10 。

示例 2：

输入：nums = [2,4,9,24,2,1,10]
输出：68

提示：

  • 2 <= nums.length <= 3*104
  • -105 <= nums[i] <= 105
  • 答案保证在 32 位整数范围内。
