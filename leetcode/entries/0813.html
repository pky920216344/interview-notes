813. 最大平均值和的分组

DP：dp[t][i] = 前 i 个数分 t 组的最大分数；枚举最后一组的开头 j，dp[t−1][j] + 平均(j..i−1)。

思路

  • 前缀和 sum 让任意段平均值变成 (sum[i]-sum[j])/(i-j)，O(1) 取得。
  • 转移：最后一组是 j..i-1，dp[t][i] = max(dp[t-1][j] + 段平均)，j 从 t-1 到 i-1。
  • 边界 dp[1][i] = 前 i 个数的整体平均；答案 dp[k][n]。
  • 「平均值之和」里分段越多通常分越高——大数单独成组最划算。

最优解

时间复杂度 O(n²k)，空间复杂度 O(nk)
1class Solution {2    public double largestSumOfAverages(int[] nums, int k) {3        int n = nums.length;4        // sum[i]：前 i 个数的和，段 (j..i-1) 的平均 = (sum[i]-sum[j])/(i-j)5        int[] sum = new int[n + 1];6        for (int i = 0; i < n; i++) sum[i + 1] = sum[i] + nums[i];7        // dp[t][i]：前 i 个数分成 t 组的最大分数8        double[][] dp = new double[k + 1][n + 1];9        for (int i = 1; i <= n; i++) dp[1][i] = (double) sum[i] / i;10        for (int t = 2; t <= k; t++) {11            for (int i = t; i <= n; i++) {12                for (int j = t - 1; j < i; j++) {13                    // 上一组在 j 结束，最后一组是 j..i-114                    dp[t][i] = Math.max(dp[t][i], dp[t - 1][j] + (double) (sum[i] - sum[j]) / (i - j));15                }16            }17        }18        return dp[k][n];19    }20}
题目

给定数组 nums 和一个整数 k 。我们将给定的数组 nums 分成 最多 k 个非空子数组，且数组内部是连续的 。 分数 由每个子数组内的平均值的总和构成。

注意我们必须使用 nums 数组中的每一个数进行分组，并且分数不一定需要是整数。

返回我们所能得到的最大 分数 是多少。答案误差在 10-6 内被视为是正确的。

示例 1:

输入: nums = [9,1,2,3,9], k = 3
输出: 20.00000
解释: 
nums 的最优分组是[9], [1, 2, 3], [9]. 得到的分数是 9 + (1 + 2 + 3) / 3 + 9 = 20. 
我们也可以把 nums 分成[9, 1], [2], [3, 9]. 
这样的分组得到的分数为 5 + 2 + 6 = 13, 但不是最大值.

示例 2:

输入: nums = [1,2,3,4,5,6,7], k = 4
输出: 20.50000

提示:

  • 1 <= nums.length <= 100
  • 1 <= nums[i] <= 104
  • 1 <= k <= nums.length
