按位数分类计数：长度 L 的数首位有 9 种（不能 0），之后每往右一位可用数字少 1，各长度累加。

思路

  • 0 <= x < 10^n 拆成「长度 0,1,…,n」分别数；0 本身单独算 1 个（它补齐了长度 1 里缺的那个）。
  • 长度 L ≥ 2：首位 9 种（1~9），第 2 位 9 种，第 3 位 8 种……逐位递减，乘积即该长度贡献。
  • n = 0 时只有 0，答案 1；n ≤ 8 保证乘积在 int 内。

1class Solution {2    public int countNumbersWithUniqueDigits(int n) {3        // 0 单独算 1 个（0 <= x < 10^0 时只有 0）4        int ans = 1;5        // 长度 L 的数：首位 9 种（1~9），之后每往右一位可用数字少 16        for (int len = 1; len <= n; len++) {7            int cnt = 9;8            for (int d = 1; d < len; d++) {9                cnt *= 10 - d;10            }11            ans += cnt;12        }13        return ans;14    }15}
题目
给你一个整数 n ，统计并返回各位数字都不同的数字 x 的个数，其中 0 <= x < 10n 。

示例 1：

输入：n = 2
输出：91
解释：答案应为除去 11、22、33、44、55、66、77、88、99 外，在 0 ≤ x < 100 范围内的所有数字。

示例 2：

输入：n = 0
输出：1

提示：

  • 0 <= n <= 8
