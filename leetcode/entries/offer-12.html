网格 DFS 回溯：每个格子试作起点；对上就改成 # 当已访问，四邻接不上再恢复原字符。

思路

  • 外层双循环把每个格子都试作起点，调 dfs(i, j, k)，k 是 target 下一个要匹配的下标。
  • 越界或 grid[i][j] != target[k] 直接剪掉；k 已是最后一个字符 → 找到。
  • 对上就改成 '#' 再向四邻递归：同一条路径不会重复踩一格。
  • 递归返回前把 # 恢复成原字符：这条岔路放弃后，别的路径还能用这格。

时间复杂度 O(m·n·3^L)，空间复杂度 O(L)
1class Solution {2    public boolean wordPuzzle(char[][] grid, String target) {3        int m = grid.length, n = grid[0].length;4        boolean found = false;5        // 每个格子都试作起点；一旦找到就提前收工6        for (int i = 0; i < m && !found; i++) {7            for (int j = 0; j < n && !found; j++) {8                found = dfs(grid, target, i, j, 0);9            }10        }11        return found;12    }13 14    // 从 (i,j) 出发，接着匹配 target[k..]15    private boolean dfs(char[][] grid, String target, int i, int j, int k) {16        if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length) return false;17        // 字符对不上，剪掉18        if (grid[i][j] != target.charAt(k)) return false;19        if (k == target.length() - 1) return true;   // 最后一个字符也对上了20        char keep = grid[i][j];21        grid[i][j] = '#';    // 原地标记：这条路径不再踩这格22        boolean hit = dfs(grid, target, i - 1, j, k + 1) || dfs(grid, target, i + 1, j, k + 1)23                || dfs(grid, target, i, j - 1, k + 1) || dfs(grid, target, i, j + 1, k + 1);24        grid[i][j] = keep;   // 回溯：恢复这格，别的路径还能用25        return hit;26    }27}
题目

字母迷宫游戏初始界面记作 m x n 二维字符串数组 grid，请判断玩家是否能在 grid 中找到目标单词 target。
注意：寻找单词时 必须 按照字母顺序，通过水平或垂直方向相邻的单元格内的字母构成，同时，同一个单元格内的字母 不允许被重复使用 。

示例 1：

输入：grid = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], target = "ABCCED"
输出：true

示例 2：

输入：grid = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], target = "SEE"
输出：true

示例 3：

输入：grid = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], target = "ABCB"
输出：false

提示：

  • m == grid.length
  • n = grid[i].length
  • 1 <= m, n <= 6
  • 1 <= target.length <= 15
  • grid 和 target 仅由大小写英文字母组成
