枚举两边各拿几个（nums1 拿 i 个、nums2 拿 k−i 个），各自用单调栈选出最大子序列，再按「后缀字典序大者优先」归并，取全局最大。

思路

  • 单调栈选「长度 t 的最大子序列」：来的数比栈顶大且还有丢弃配额就弹栈；栈满装不下就丢弃来数。
  • 归并两个子序列时不能只比头：头部相等要往后看，后缀字典序大的一边先出（否则会埋没后面的大数）。
  • 一方耗尽时另一方整体接上：耗尽的更「小」，所以后缀比较里 j 到底 就取 a。
  • 枚举所有 i（max(0,k−n) ≤ i ≤ min(m,k)），整体字典序最大的候选即答案。

时间复杂度 O(k·(m+n+k))，空间复杂度 O(k)
1class Solution {2    public int[] maxNumber(int[] nums1, int[] nums2, int k) {3        int m = nums1.length, n = nums2.length;4        int[] best = new int[k];5        // 枚举 nums1 拿 i 个、nums2 拿 k-i 个的所有分法，取整体字典序最大的6        for (int i = Math.max(0, k - n); i <= Math.min(m, k); i++) {7            int[] cand = merge(pick(nums1, i), pick(nums2, k - i));8            if (greater(cand, best)) best = cand;9        }10        return best;11    }12 13    // 单调栈：从 nums 里选出最大的长度 need 子序列14    private int[] pick(int[] nums, int need) {15        int[] st = new int[need];16        int top = -1, drop = nums.length - need;   // 还能丢弃几个数17        for (int x : nums) {18            while (top >= 0 && drop > 0 && st[top] < x) { top--; drop--; }   // 来的数更大就弹栈顶19            if (top + 1 < need) st[++top] = x;20            else drop--;   // 栈满装不下：这个数直接丢21        }22        return st;23    }24 25    // 合并两个子序列：每一次都取「当前后缀」字典序更大的一边（相等时往后多看几位）26    private int[] merge(int[] a, int[] b) {27        int[] out = new int[a.length + b.length];28        int i = 0, j = 0, r = 0;29        while (i < a.length || j < b.length) {30            if (suffixGreater(a, i, b, j)) out[r++] = a[i++];31            else out[r++] = b[j++];32        }33        return out;34    }35 36    // a[i..] 是否大于 b[j..]：先比到第一个不同处；一方耗尽则短的更小37    private boolean suffixGreater(int[] a, int i, int[] b, int j) {38        while (i < a.length && j < b.length && a[i] == b[j]) { i++; j++; }39        return j == b.length || (i < a.length && a[i] > b[j]);40    }41 42    private boolean greater(int[] a, int[] b) {43        for (int i = 0; i < a.length; i++)44            if (a[i] != b[i]) return a[i] > b[i];45        return false;46    }47}
题目

给你两个整数数组 nums1 和 nums2，它们的长度分别为 m 和 n。数组 nums1 和 nums2 分别代表两个数各位上的数字。同时你也会得到一个整数 k。

请你利用这两个数组中的数字创建一个长度为 k <= m + n 的最大数。同一数组中数字的相对顺序必须保持不变。

返回代表答案的长度为 k 的数组。

示例 1：

输入：nums1 = [3,4,6,5], nums2 = [9,1,2,5,8,3], k = 5
输出：[9,8,6,5,3]

示例 2：

输入：nums1 = [6,7], nums2 = [6,0,4], k = 5
输出：[6,7,6,0,4]

示例 3：

输入：nums1 = [3,9], nums2 = [8,9], k = 3
输出：[9,8,9]

提示：

  • m == nums1.length
  • n == nums2.length
  • 1 <= m, n <= 500
  • 0 <= nums1[i], nums2[i] <= 9
  • 1 <= k <= m + n
  • nums1 和 nums2 没有前导 0。
