滑动窗口：右端逐格扩进来并累加开销 |s[i]−t[i]|，一旦总开销超过 maxCost 就从左端退出，窗口越长越好。

思路

  • 窗口 [left, right] 表示「当前能把这一段 s 改成 t」的子串，cost 是窗口内 |s[i] − t[i]| 的总和。
  • right 每右移一格就加上该格开销；一旦 cost > maxCost，左端一格一格退出（减去该格开销），直到付得起。
  • 窗口每一步都合法，所以答案就是 right − left + 1 的最大值；付不起的单格会把窗口缩空，自然返回 0。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int equalSubstring(String s, String t, int maxCost) {3        int left = 0, cost = 0, ans = 0;4        for (int right = 0; right < s.length(); right++) {5            // 右端进窗：收下这一格的改装开销6            cost += Math.abs(s.charAt(right) - t.charAt(right));7            // 超预算就把左端一格一格退出去，直到付得起8            while (cost > maxCost) {9                cost -= Math.abs(s.charAt(left) - t.charAt(left));10                left++;11            }12            ans = Math.max(ans, right - left + 1);13        }14        return ans;15    }16}
题目

给你两个长度相同的字符串，s 和 t。

将 s 中的第 i 个字符变到 t 中的第 i 个字符需要 |s[i] - t[i]| 的开销（开销可能为 0），也就是两个字符的 ASCII 码值的差的绝对值。

用于变更字符串的最大预算是 maxCost。在转化字符串时，总开销应当小于等于该预算，这也意味着字符串的转化可能是不完全的。

如果你可以将 s 的子字符串转化为它在 t 中对应的子字符串，则返回可以转化的最大长度。

如果 s 中没有子字符串可以转化成 t 中对应的子字符串，则返回 0。

示例 1：

输入：s = "abcd", t = "bcdf", maxCost = 3
输出：3
解释：s中的"abc" 可以变为 "bcd"。开销为 3，所以最大长度为 3。

示例 2：

输入：s = "abcd", t = "cdef", maxCost = 3
输出：1
解释：s 中的任一字符要想变成 t 中对应的字符，其开销都是 2。因此，最大长度为 1。

示例 3：

输入：s = "abcd", t = "acde", maxCost = 0
输出：1
解释：a -> a, cost = 0，字符串未发生变化，所以最大长度为 1。

提示：

  • 1 <= s.length <= 105
  • t.length == s.length
  • 0 <= maxCost <= 106
  • s 和 t 都只含小写英文字母。
