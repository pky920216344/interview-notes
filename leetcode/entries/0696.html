696. 计数二进制子串

按连续相同字符切段，长度记 a1,a2,…；答案 = Σ min(相邻两段的长度)，因为合法子串必然横跨一个段交界且两段等长。

思路

  • 合法子串形如 00…011…1（或反过来）且两段等长，它必然恰好横跨一组相邻段的交界，且不能跨两个交界。
  • 所以以交界为单元统计：每个交界贡献 min(左段长, 右段长)。例：00110011 切成 2,2,2,2，答案 2+2+2+2 = 6。
  • 一遍扫描：prev 记上一段长、cur 记当前段长，切换时结算 ans += min(prev, cur)。
  • 循环到 i == n 用哨兵强制最后一段也结算，省掉循环外补一次的写法。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int countBinarySubstrings(String s) {3        int n = s.length();4        // prev：上一段连续同字符的长度，cur：当前段的长度5        int prev = 0, cur = 1, ans = 0;6        for (int i = 1; i <= n; i++) {7            // i == n 是哨兵：强制最后一段也在这里结算8            if (i < n && s.charAt(i) == s.charAt(i - 1)) {9                cur++;10            } else {11                ans += Math.min(prev, cur);12                prev = cur;13                cur = 1;14            }15        }16        return ans;17    }18}
题目

给定一个字符串 s，统计并返回具有相同数量 0 和 1 的非空（连续）子字符串的数量，并且这些子字符串中的所有 0 和所有 1 都是成组连续的。

重复出现（不同位置）的子串也要统计它们出现的次数。

 

示例 1：

输入：s = "00110011"
输出：6
解释：6 个子串满足具有相同数量的连续 1 和 0 ："0011"、"01"、"1100"、"10"、"0011" 和 "01" 。
注意，一些重复出现的子串（不同位置）要统计它们出现的次数。
另外，"00110011" 不是有效的子串，因为所有的 0（还有 1 ）没有组合在一起。

示例 2：

输入：s = "10101"
输出：4
解释：有 4 个子串："10"、"01"、"10"、"01" ，具有相同数量的连续 1 和 0 。

提示：

  • 1 <= s.length <= 105
  • s[i] 为 '0' 或 '1'
