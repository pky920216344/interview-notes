贪心逐座位对修：左边坐谁就把他的伴侣换过来；每次交换至少修好一对，次数最少。

思路

  • 情侣编号 (0,1)(2,3)…，所以伴侣 = x ^ 1；pos[] 记每个人在哪，O(1) 找到伴侣座位。
  • 从左往右扫座位对 (i, i+1)：row[i+1] 不是 row[i] 的伴侣，就把伴侣从 j 换到 i+1，交换数 +1。
  • 交换时同步维护 pos：被换走的人记新座位 j，伴侣记 i+1。
  • 最少性：每次交换都让左边一对永久配对，也从不拆散已配好的对，所以交换数最少。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int minSwapsCouples(int[] row) {3        int n = row.length;4        int[] pos = new int[n];   // pos[人] = 他现在坐的座位下标5        for (int i = 0; i < n; i++) pos[row[i]] = i;6        int ans = 0;7        for (int i = 0; i < n; i += 2) {8            int want = row[i] ^ 1;   // 伴侣编号：情侣 (0,1)(2,3)…，编号恰差 1，异或 1 即得9            if (row[i + 1] == want) continue;   // 这一对已经牵手10            int j = pos[want];   // 伴侣现在坐在 j11            // 把伴侣换到 i+1：先记被换走的人的新座位，再交换两人12            pos[row[i + 1]] = j;13            row[j] = row[i + 1];14            row[i + 1] = want;15            pos[want] = i + 1;16            ans++;17        }18        return ans;19    }20}
题目

n 对情侣坐在连续排列的 2n 个座位上，想要牵到对方的手。

人和座位由一个整数数组 row 表示，其中 row[i] 是坐在第 i 个座位上的人的 ID。情侣们按顺序编号，第一对是 (0, 1)，第二对是 (2, 3)，以此类推，最后一对是 (2n - 2, 2n - 1)。

返回 最少交换座位的次数，以便每对情侣可以并肩坐在一起。 每次交换可选择任意两人，让他们站起来交换座位。

示例 1:

输入: row = [0,2,1,3]
输出: 1
解释: 只需要交换第二个人（row[1]）和第三个人（row[2]）的位置即可。

示例 2:

输入: row = [3,2,0,1]
输出: 0
解释: 无需交换座位，所有的情侣都已经可以手牵手了。

提示:

  • 2n == row.length
  • 2 <= n <= 30
  • n 是偶数
  • 0 <= row[i] < 2n
  • row 中所有元素均 无重复
