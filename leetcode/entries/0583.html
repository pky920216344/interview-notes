583. 两个字符串的删除操作

  • 中等
  • 频度 3
  • 动态规划
  • 字符串
  • 动态规划
  • longest-common-subsequence
  • 待提交

DP：dp[i][j] = 两前缀变相同的最少删除数；尾字符相等斜抄左上，否则删一方尾字符取较小 +1。

思路

  • 边界：一方为空就只能把另一方删光，dp[i][0]=i、dp[0][j]=j。
  • 尾字符相等：这对字符都保留，dp[i][j] = dp[i-1][j-1]。
  • 不等：删 word1 尾或删 word2 尾，1 + min(dp[i-1][j], dp[i][j-1])。
  • 等价公式：m + n − 2·LCS——保住最长公共子序列，其余全删。

最优解

时间复杂度 O(mn)，空间复杂度 O(mn)
1class Solution {2    public int minDistance(String word1, String word2) {3        int m = word1.length(), n = word2.length();4        // dp[i][j]：把 word1 前 i 个、word2 前 j 个变相同的最少删除数5        int[][] dp = new int[m + 1][n + 1];6        for (int i = 1; i <= m; i++) dp[i][0] = i;7        for (int j = 1; j <= n; j++) dp[0][j] = j;8        for (int i = 1; i <= m; i++) {9            for (int j = 1; j <= n; j++) {10                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {11                    dp[i][j] = dp[i - 1][j - 1];  // 尾字符相同：不用删12                } else {13                    // 不同：删 word1 的尾 或 删 word2 的尾，取小的加一14                    dp[i][j] = 1 + Math.min(dp[i - 1][j], dp[i][j - 1]);15                }16            }17        }18        return dp[m][n];19    }20}
题目

给定两个单词 word1 和 word2 ，返回使得 word1 和  word2 相同所需的最小步数。

每步 可以删除任意一个字符串中的一个字符。

示例 1：

输入: word1 = "sea", word2 = "eat"
输出: 2
解释: 第一步将 "sea" 变为 "ea" ，第二步将 "eat "变为 "ea"

示例  2:

输入：word1 = "leetcode", word2 = "etco"
输出：4

提示：

  • 1 <= word1.length, word2.length <= 500
  • word1 和 word2 只包含小写英文字母
