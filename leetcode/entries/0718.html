718. 最长重复子数组

dp[i][j] = 以 A[i-1]、B[j-1] 结尾的最长公共后缀：相等 = 左上 + 1，不等归零。

思路

  • dp[i][j] 表示同时以 nums1[i-1]、nums2[j-1] 结尾的公共子数组长度，是「后缀」长度，所以不等时必须归零。
  • 相等时 dp[i][j] = dp[i-1][j-1] + 1（左上角 + 1），过程中顺手取最大值就是答案。
  • Java 只滚动一行并倒序扫，保证 dp[j-1] 读到的还是上一行的值，空间 O(n)。

图解

最优解

时间复杂度 O(mn)，空间复杂度 O(n)
1class Solution {2    public int findLength(int[] nums1, int[] nums2) {3        int n = nums2.length;4        // dp[j]：以两数组当前元素结尾的公共子数组长度（滚动一行）5        int[] dp = new int[n + 1];6        int ans = 0;7        for (int i = 1; i <= nums1.length; i++) {8            // 倒着扫，dp[j-1] 读到的还是上一行的值（左上角）9            for (int j = n; j >= 1; j--) {10                if (nums1[i - 1] == nums2[j - 1]) {11                    dp[j] = dp[j - 1] + 1;12                    ans = Math.max(ans, dp[j]);13                } else {14                    dp[j] = 0;15                }16            }17        }18        return ans;19    }20}
题目

给两个整数数组 nums1 和 nums2 ，返回 两个数组中 公共的 、长度最长的子数组的长度 。

示例 1：

输入：nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
输出：3
解释：长度最长的公共子数组是 [3,2,1] 。

示例 2：

输入：nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
输出：5

提示：

  • 1 <= nums1.length, nums2.length <= 1000
  • 0 <= nums1[i], nums2[i] <= 100
