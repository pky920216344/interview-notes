排序后首尾双指针：每艘船先载最重的人，最轻的人能塞进同一船就捎上，否则最重者独占一船。

思路

  • 最重的人必须上一艘船：能和他同船的只有最轻的人（第二重都可能超载），所以先看 people[l] + people[r] ≤ limit。
  • 能同船就把两人一起送走（l++、r--）；不能就最重者独占一船（r--），此时船数必须加一。
  • 每轮恰好处理掉最重的那个人，所以循环次数就是船数；不用单独计数公式，boats++ 即可。
  • 「最轻配最重」不会更差：若最轻的都带不动最重的，谁都带不动，独船是唯一选择。

时间复杂度 O(n log n)，空间复杂度 O(log n)
1import java.util.*;2 3class Solution {4    public int numRescueBoats(int[] people, int limit) {5        Arrays.sort(people);6        int l = 0, r = people.length - 1, boats = 0;7        while (l <= r) {8            // 每艘船先载最重的；最轻的人能凑一对就捎上，否则重者独占一船9            if (people[l] + people[r] <= limit) l++;10            r--;11            boats++;12        }13        return boats;14    }15}
题目

给定数组 people 。people[i]表示第 i 个人的体重 ，船的数量不限，每艘船可以承载的最大重量为 limit。

每艘船最多可同时载两人，但条件是这些人的重量之和最多为 limit。

返回 承载所有人所需的最小船数 。

示例 1：

输入：people = [1,2], limit = 3
输出：1
解释：1 艘船载 (1, 2)

示例 2：

输入：people = [3,2,2,1], limit = 3
输出：3
解释：3 艘船分别载 (1, 2), (2) 和 (3)

示例 3：

输入：people = [3,5,3,4], limit = 5
输出：4
解释：4 艘船分别载 (3), (3), (4), (5)

提示：

  • 1 <= people.length <= 5 * 104
  • 1 <= people[i] <= limit <= 3 * 104
