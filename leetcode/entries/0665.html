665. 非递减数列

  • 简单
  • 频度 2
  • 贪心
  • 数组
  • 待提交

一遍扫描，发现逆序就当场修复（只许一次）；修复方向看 a[i-2]：能降前一个就降前一个，否则抬当前。

思路

  • 扫到 a[i] < a[i-1] 就是必须修复的一处；出现第二次逆序直接 false。
  • 修复二选一：若 i >= 2 且 a[i-2] > a[i]，降 a[i-1] 会破坏前面的非降，只能抬 a[i] 为 a[i-1]；否则降 a[i-1] 为 a[i]（保住后面的余量，例如 3,4,2,3 必须抬 2）。
  • 原地修改不影响判断：后面只用修复后的值继续比，正确性由「最优修复就是这两种」保证。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean checkPossibility(int[] nums) {3        int cnt = 0;4        for (int i = 1; i < nums.length; i++) {5            // 发现一处逆序；出现第二处就再也没救6            if (nums[i] < nums[i - 1]) {7                if (++cnt > 1) return false;8                // 修复二选一：nums[i-2] <= nums[i] 时降 nums[i-1] 更划算（后面还有余量）；9                // 否则只能抬 nums[i] 顶到 nums[i-1]10                if (i >= 2 && nums[i - 2] > nums[i]) nums[i] = nums[i - 1];11                else nums[i - 1] = nums[i];12            }13        }14        return true;15    }16}
题目

给你一个长度为 n 的整数数组 nums ，请你判断在 最多 改变 1 个元素的情况下，该数组能否变成一个非递减数列。

我们是这样定义一个非递减数列的： 对于数组中任意的 i (0 <= i <= n-2)，总满足 nums[i] <= nums[i + 1]。

示例 1:

输入: nums = [4,2,3]
输出: true
解释: 你可以通过把第一个 4 变成 1 来使得它成为一个非递减数列。

示例 2:

输入: nums = [4,2,1]
输出: false
解释: 你不能在只改变一个元素的情况下将其变为非递减数列。

提示：

  • n == nums.length
  • 1 <= n <= 104
  • -105 <= nums[i] <= 105
