26 个字母用一个 int 的低 26 位做位图：先查位，已是 1 就有重复，否则置位继续。

思路

  • seen 的第 c-'a' 位记录字母 c 是否出现过，一个 int 装下全部 26 个字母。
  • 每读一个字符：bit = 1 << (c-'a')；seen & bit != 0 说明见过，直接 return false。
  • 否则 seen |= bit 置位继续；扫完没冲突返回 true。

题目

实现一个算法，确定一个字符串 s 的所有字符是否全都不同。

示例 1：

输入: s = "leetcode"
输出: false

示例 2：

输入: s = "abc"
输出: true

限制：

  • 0 <= len(s) <= 100
  • s[i]仅包含小写字母
  • 如果你不使用额外的数据结构，会很加分。
