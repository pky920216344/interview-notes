两棵 BST 各做一个反向中序迭代器（一升一降），像有序数组两端的 two sum 一样夹逼：和偏小升序进一位，偏大降序退一位。

思路

  • BST 的中序是有序序列：root1 做升序迭代器、root2 做降序迭代器，就等价于在两个有序数组两端放指针。
  • 迭代器 = 栈：先把左链（升序）或右链（降序）压栈；next 弹栈并把该结点的右链/左链压入。
  • 夹逼规则：a + b < target 时 a 进一位（变大），> target 时 b 退一位（变小），相等即成功。
  • 和用 long 求更稳；一边走完还没命中就返回 false。空间只有两条栈深，比「哈希集存一棵树」省。

1import java.util.ArrayDeque;2import java.util.Deque;3 4class Solution {5    public boolean twoSumBSTs(TreeNode root1, TreeNode root2, int target) {6        Deque<TreeNode> asc = new ArrayDeque<>(), desc = new ArrayDeque<>();7        leftChain(asc, root1);    // 升序迭代器：root1 的中序从小到大8        rightChain(desc, root2);  // 降序迭代器：root2 的中序从大到小9        TreeNode a = nextAsc(asc), b = nextDesc(desc);10        // 双指针夹逼：和偏小 a 进一位，偏大 b 退一位11        while (a != null && b != null) {12            long sum = (long) a.val + b.val;   // 值可达 1e9 量级，求和用 long 稳妥13            if (sum == target) return true;14            if (sum < target) a = nextAsc(asc);15            else b = nextDesc(desc);16        }17        return false;18    }19 20    // 把 node 沿左链压栈：之后逐个 pop 就得到从小到大21    private void leftChain(Deque<TreeNode> st, TreeNode node) {22        for (; node != null; node = node.left) st.push(node);23    }24 25    // 把 node 沿右链压栈：之后逐个 pop 就得到从大到小26    private void rightChain(Deque<TreeNode> st, TreeNode node) {27        for (; node != null; node = node.right) st.push(node);28    }29 30    private TreeNode nextAsc(Deque<TreeNode> st) {31        if (st.isEmpty()) return null;32        TreeNode node = st.pop();33        leftChain(st, node.right);   // 后继在右子树的最左结点34        return node;35    }36 37    private TreeNode nextDesc(Deque<TreeNode> st) {38        if (st.isEmpty()) return null;39        TreeNode node = st.pop();40        rightChain(st, node.left);   // 前驱在左子树的最右结点41        return node;42    }43}
