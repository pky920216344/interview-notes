剑指 Offer 34. 二叉树中和为目标值的路径

DFS 回溯：路径列表 + 剩余目标 rest，到叶子且 rest 归零就存路径的拷贝，回溯时弹掉当前结点。

思路

  • dfs(node, rest)：结点先进 path，rest 减去它的值，再递归左右孩子。
  • 到叶子且 rest == 0：把 path 的拷贝存进答案；不拷贝的话回溯会把存进去的路径改掉。
  • 左右递归完必须弹出 path 末尾结点，回到父结点时路径才正确——这就是回溯。
  • 结点值可能是负数，rest 中途变大变小都正常，不能提前剪枝。
  • 与主站 113 题相同。

最优解

时间复杂度 O(n²)，空间复杂度 O(h)
1import java.util.*;2 3class Solution {4    private List<List<Integer>> ans = new ArrayList<>();5    private List<Integer> path = new ArrayList<>();6 7    public List<List<Integer>> pathTarget(TreeNode root, int target) {8        dfs(root, target);9        return ans;10    }11 12    // rest：走到 node 之前还差的和13    private void dfs(TreeNode node, int rest) {14        if (node == null) return;15        path.add(node.val);   // 选中当前结点进路径16        rest -= node.val;17        if (node.left == null && node.right == null && rest == 0) {18            ans.add(new ArrayList<>(path));   // 到叶子刚好凑够：存路径的拷贝19        }20        dfs(node.left, rest);21        dfs(node.right, rest);22        path.remove(path.size() - 1);   // 回溯：撤销当前结点23    }24}
题目

给你二叉树的根节点 root 和一个整数目标和 targetSum ，找出所有 从根节点到叶子节点 路径总和等于给定目标和的路径。

叶子节点 是指没有子节点的节点。

示例 1：

输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：[[5,4,11,2],[5,8,4,5]]

示例 2：

输入：root = [1,2,3], targetSum = 5
输出：[]

示例 3：

输入：root = [1,2], targetSum = 0
输出：[]

提示：

  • 树中节点总数在范围 [0, 5000] 内
  • -1000 <= Node.val <= 1000
  • -1000 <= targetSum <= 1000

注意：本题与主站 113 题相同：https://leetcode.cn/problems/path-sum-ii/
