134. 加油站

  • 中等
  • 频度 27
  • 贪心
  • 贪心
  • 数组
  • 力扣已通过

总和 ≥ 0 必有解；攒油一旦见底，见底前的起点全出局，从下一站重新攒，最后一个重置点就是答案。

思路

  • 每站看成净油量 gas[i] - cost[i]：总和 total ≥ 0 是能绕一圈的充要条件，先一路累加。
  • tank 是从 start 出发攒到现在剩的油；一旦 < 0，说明 start..i 之间任何站当起点都撑不过这一段，直接 start = i + 1、tank 清零。
  • 扫完时若 total ≥ 0，最后那个重置点必然成功：它之后油量再没见底，绕回前面的亏空由全环盈余补上（重置点恰好是净油量前缀和的最小值处）。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int canCompleteCircuit(int[] gas, int[] cost) {3        // net[i] = gas[i] - cost[i]：在 i 加油、开到下一站的净油量4        int total = 0, tank = 0, start = 0;5        for (int i = 0; i < gas.length; i++) {6            int net = gas[i] - cost[i];7            total += net;   // 净油量总和 ≥ 0 才可能有解8            tank += net;    // tank 是从 start 出发开到 i 后剩的油9            // 一见底：start..i 这些起点都撑不过这一段，从下一站重新攒10            if (tank < 0) {11                start = i + 1;12                tank = 0;13            }14        }15        // 总和够就一定轮到最后那个重置点成功16        return total >= 0 ? start : -1;17    }18}
题目

在一条环路上有 n 个加油站，其中第 i 个加油站有汽油 gas[i] 升。

你有一辆油箱容量无限的的汽车，从第 i 个加油站开往第 i+1 个加油站需要消耗汽油 cost[i] 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 gas 和 cost ，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 -1 。如果存在解，则 保证 它是 唯一 的。

示例 1:

输入: gas = [1,2,3,4,5], cost = [3,4,5,1,2]
输出: 3
解释:
从 3 号加油站(索引为 3 处)出发，可获得 4 升汽油。此时油箱有 = 0 + 4 = 4 升汽油
开往 4 号加油站，此时油箱有 4 - 1 + 5 = 8 升汽油
开往 0 号加油站，此时油箱有 8 - 2 + 1 = 7 升汽油
开往 1 号加油站，此时油箱有 7 - 3 + 2 = 6 升汽油
开往 2 号加油站，此时油箱有 6 - 4 + 3 = 5 升汽油
开往 3 号加油站，你需要消耗 5 升汽油，正好足够你返回到 3 号加油站。
因此，3 可为起始索引。

示例 2:

输入: gas = [2,3,4], cost = [3,4,3]
输出: -1
解释:
你不能从 0 号或 1 号加油站出发，因为没有足够的汽油可以让你行驶到下一个加油站。
我们从 2 号加油站出发，可以获得 4 升汽油。 此时油箱有 = 0 + 4 = 4 升汽油
开往 0 号加油站，此时油箱有 4 - 3 + 2 = 3 升汽油
开往 1 号加油站，此时油箱有 3 - 3 + 3 = 3 升汽油
你无法返回 2 号加油站，因为返程需要消耗 4 升汽油，但是你的油箱只有 3 升汽油。
因此，无论怎样，你都不可能绕环路行驶一周。

提示:

  • n == gas.length == cost.length
  • 1 <= n <= 105
  • 0 <= gas[i], cost[i] <= 104
  • 输入保证答案唯一。
