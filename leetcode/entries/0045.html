贪心按层跳：i 从左往右扫，扫到这一跳的边界 currentEnd 时步数 +1，边界外推到扫到的最远处 farthest。

思路

  • 第 k 次跳跃能到达的位置构成一段连续区间，currentEnd 就是这段区间的右端点。
  • i 扫过区间里每个位置，用 i + nums[i] 更新 farthest；i == currentEnd 时这一跳看完，steps + 1、currentEnd = farthest。
  • 循环只到 n - 2：走到最后一个下标就算到了，从它再起跳只会多算一步。
  • 若 farthest 停在 currentEnd 之前说明卡死，题面保证可达，不用处理。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int jump(int[] nums) {3        // currentEnd：这一跳的最右边界；farthest：扫到的位置里能跳到的最远处4        int steps = 0, currentEnd = 0, farthest = 0;5        // 只扫到 n-2：走到 n-1 就算到了，不需要再从它起跳6        for (int i = 0; i < nums.length - 1; i++) {7            farthest = Math.max(farthest, i + nums[i]);8            // i 撞上边界：这一跳的所有位置都看完了，步数 +1、边界外推9            if (i == currentEnd) {10                steps++;11                currentEnd = farthest;12            }13        }14        return steps;15    }16}
题目

给定一个长度为 n 的 0 索引整数数组 nums。初始位置在下标 0。

每个元素 nums[i] 表示从索引 i 向后跳转的最大长度。换句话说，如果你在索引 i 处，你可以跳转到任意 (i + j) 处：

  • 0 <= j <= nums[i] 且
  • i + j < n

返回到达 n - 1 的最小跳跃次数。测试用例保证可以到达 n - 1。

示例 1:

输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到最后一个位置的最小跳跃数是 2。
     从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。

示例 2:

输入: nums = [2,3,0,1,4]
输出: 2

提示:

  • 1 <= nums.length <= 104
  • 0 <= nums[i] <= 1000
  • 题目保证可以到达 n - 1
