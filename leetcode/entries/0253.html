253. 会议室 II

  • 未经力扣验证

按开始时间排序 + 小根堆：堆里存每间房的结束时间；新会议来时堆顶（最早空出的房）赶得上就复用，否则开新房。

思路

  • 会议按开始时间排序，逐场处理：开始早的先安排。
  • 小根堆存每间房「空出来的时刻」；新会议 [s, e]：堆顶 ≤ s 说明最早空出的房接得上，poll 后复用。
  • 无论复用还是开新房，都要把 e 入堆；堆的大小就是同时进行的最多会议数。
  • 同一时刻「上一场结束、下一场开始」算可复用（≤），边界就靠这个不等号。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int minMeetingRooms(int[][] intervals) {5        // 按开始时间排序：同一时刻先处理「腾房」再「开会」6        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);7        // 小根堆存每间房「空出来的时刻」，堆顶是最早空出的那间8        PriorityQueue<Integer> heap = new PriorityQueue<>();9        for (int[] it : intervals) {10            if (!heap.isEmpty() && heap.peek() <= it[0]) heap.poll();   // 最早空出的房能接上，复用11            heap.add(it[1]);12        }13        return heap.size();   // 堆里剩几间房，就是同时开会的峰值14    }15}
