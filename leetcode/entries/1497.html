1497. 检查数组对是否可以被 k 整除

按余数计数：余 r 的数必须和余 k−r 的一样多才能一一配对；余 0（和 k 偶数时的余 k/2）必须自己配自己，个数是偶数。

思路

  • a + b ≡ 0 (mod k) ⇔ 两数余数互补：r 配 (k−r) % k。
  • 负数取余要先修正：((a % k) + k) % k。
  • 三类特殊检查：cnt[0] 为偶数；r 与 k−r 计数相等（双指针两头往中间扫）；k 为偶数时 cnt[k/2] 为偶数。

最优解

时间复杂度 O(n + k)，空间复杂度 O(k)
1class Solution {2    public boolean canArrange(int[] arr, int k) {3        // 统计每个非负余数的个数：a+b ≡ 0 (mod k) ⇔ 两数的余数互补4        int[] cnt = new int[k];5        for (int a : arr) cnt[((a % k) + k) % k]++;   // 负数先修正成非负余数6        if (cnt[0] % 2 != 0) return false;            // 余 0 的只能内部互配，必须偶数个7        for (int r = 1, s = k - 1; r < s; r++, s--) {8            if (cnt[r] != cnt[s]) return false;       // 余 r 和余 k−r 必须一样多，一一配对9        }10        // k 为偶数时余 k/2 的没有搭档，自己配自己，也得是偶数个11        if (k % 2 == 0 && cnt[k / 2] % 2 != 0) return false;12        return true;13    }14}
题目

给你一个整数数组 arr 和一个整数 k ，其中数组长度是偶数，值为 n 。

现在需要把数组恰好分成 n / 2 对，以使每对数字的和都能够被 k 整除。

如果存在这样的分法，请返回 true ；否则，返回 false。

示例 1：

输入：arr = [1,2,3,4,5,10,6,7,8,9], k = 5
输出：true
解释：划分后的数字对为 (1,9),(2,8),(3,7),(4,6) 以及 (5,10) 。

示例 2：

输入：arr = [1,2,3,4,5,6], k = 7
输出：true
解释：划分后的数字对为 (1,6),(2,5) 以及 (3,4) 。

示例 3：

输入：arr = [1,2,3,4,5,6], k = 10
输出：false
解释：无法在将数组中的数字分为三对的同时满足每对数字和能够被 10 整除的条件。

提示：

  • arr.length == n
  • 1 <= n <= 105
  • n 为偶数
  • -109 <= arr[i] <= 109
  • 1 <= k <= 105
