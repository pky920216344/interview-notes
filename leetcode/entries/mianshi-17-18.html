滑动窗口：右扩到 small 全覆盖，再左缩到刚缺为止，途中记录最短窗口；多余的重复不算缺。

思路

  • rem[x] 记 x 还差几次覆盖（可为负 = 窗口里有多余重复），missing 记还缺几种，两者配合判断「齐 / 缺」。
  • 右指针扩张：读到的元素若 rem > 0 就 missing--；missing == 0 说明窗口已覆盖全部种类。
  • 左指针收缩：只要仍覆盖就继续缩并更新最短；拿走的元素 rem + 1，只有从 0 变正（拿走了「刚好够用」那份）才算真缺。
  • 答案要左端点最小：扫描中右端点只增不减，同长度的窗口左端点随之变大，所以只在严格更短时更新即可。

最优解

时间复杂度 O(n)，空间复杂度 O(m)（m 为 small 长度）
1import java.util.*;2 3class Solution {4    public int[] shortestSeq(int[] big, int[] small) {5        // rem[x]：x 还差几次才覆盖够（small 元素互不相同，初始都是 1）6        Map<Integer, Integer> rem = new HashMap<>();7        for (int x : small) rem.put(x, 1);8        int missing = small.length;                 // 还缺的种类数9        int best = Integer.MAX_VALUE, bestL = -1, left = 0;10        for (int right = 0; right < big.length; right++) {11            Integer r = rem.get(big[right]);12            if (r != null) {                        // 只有 small 里的元素影响覆盖13                if (r > 0) missing--;14                rem.put(big[right], r - 1);15            }16            // 凑齐就尽量左缩：每缩一步窗口仍覆盖，顺手记录最短17            while (missing == 0) {18                if (right - left + 1 < best) { best = right - left + 1; bestL = left; }19                Integer l = rem.get(big[left]);20                if (l != null) {21                    rem.put(big[left], l + 1);22                    if (l == 0) missing++;          // 拿走的是「刚好够用」那份才变缺23                }24                left++;25            }26        }27        return bestL < 0 ? new int[0] : new int[]{bestL, bestL + best - 1};28    }29}
题目

假设你有两个数组，一个长一个短，短的元素均不相同。找到长数组中包含短数组所有的元素的最短子数组，其出现顺序无关紧要。

返回最短子数组的左端点和右端点，如有多个满足条件的子数组，返回左端点最小的一个。若不存在，返回空数组。

示例 1：

输入：
big = [7,5,9,0,2,1,3,5,7,9,1,1,5,8,8,9,7]
small = [1,5,9]
输出：[7,10]

示例 2：

输入：
big = [1,2,3]
small = [4]
输出：[]

提示：

  • big.length <= 100000
  • 1 <= small.length <= 100000
