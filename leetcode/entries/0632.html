每列表一个指针入最小堆，记下当前最大；区间 = [堆顶最小, 当前最大]，每次只把最小值的指针右移，直到某列表耗尽。

思路

  • 堆里放每个列表当前的数，curMax 记全体当前最大；区间就是 [堆顶, curMax]。
  • 想变窄只能挪最小值——挪最大值只会更宽；所以每次弹出堆顶，把它在其列表里的指针右移一位再入堆。
  • 某个列表耗尽就停：最小值再也无法右移，区间没法更窄了。
  • 过程中每个 [堆顶, curMax] 都试一次，更窄就记下（同宽时先到的 a 更小，正好符合题面平局规则）。

最优解

时间复杂度 O(n·log k)，空间复杂度 O(k)
1import java.util.*;2 3class Solution {4    public int[] smallestRange(List<List<Integer>> nums) {5        // 堆里是每个列表当前的数：{值, 列表号, 列表内下标}6        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);7        int curMax = Integer.MIN_VALUE;8        for (int i = 0; i < nums.size(); i++) {9            heap.add(new int[]{nums.get(i).get(0), i, 0});10            curMax = Math.max(curMax, nums.get(i).get(0));11        }12        int[] ans = {heap.peek()[0], curMax};13        // 贪心：想变窄只能挪最小值（挪最大值只会更宽），挪到某列表耗尽为止14        while (heap.size() == nums.size()) {15            int[] top = heap.poll();16            int i = top[1], j = top[2] + 1;17            if (j == nums.get(i).size()) break;18            int v = nums.get(i).get(j);19            curMax = Math.max(curMax, v);20            heap.add(new int[]{v, i, j});21            // 区间始终 = [当前最小, 当前最大]，更窄就记下来22            if (curMax - heap.peek()[0] < ans[1] - ans[0]) ans = new int[]{heap.peek()[0], curMax};23        }24        return ans;25    }26}
题目

你有 k 个 非递减排列 的整数列表。找到一个 最小 区间，使得 k 个列表中的每个列表至少有一个数包含在其中。

我们定义如果 b-a < d-c 或者在 b-a == d-c 时 a < c，则区间 [a,b] 比 [c,d] 小。

示例 1：

输入：nums = [[4,10,15,24,26], [0,9,12,20], [5,18,22,30]]
输出：[20,24]
解释： 
列表 1：[4, 10, 15, 24, 26]，24 在区间 [20,24] 中。
列表 2：[0, 9, 12, 20]，20 在区间 [20,24] 中。
列表 3：[5, 18, 22, 30]，22 在区间 [20,24] 中。

示例 2：

输入：nums = [[1,2,3],[1,2,3],[1,2,3]]
输出：[1,1]

提示：

  • nums.length == k
  • 1 <= k <= 3500
  • 1 <= nums[i].length <= 50
  • -105 <= nums[i][j] <= 105
  • nums[i] 按非递减顺序排列
