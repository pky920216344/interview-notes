658. 找到 K 个最接近的元素

  • 二分查找

  • 待提交

答案必是连续 k 个：二分窗口左端，比较 x−arr[mid] 与 arr[mid+k]−x，左端更远就右移窗口。

思路

  • k 个最靠近 x 的数在升序数组里一定连续，且同距取值小 → 只需定出窗口左端 lo ∈ [0, n−k]。
  • 二分比较：x − arr[mid] > arr[mid+k] − x 说明 arr[mid] 离 x 更远，窗口该右移（lo = mid+1）；否则左移（hi = mid）。
  • 两个差都是带符号的：x 在窗口外一侧时结论自动成立，不用取绝对值；同距时走 else，窗口保留在左边（值更小）。
  • 收尾直接从 lo 拷 k 个元素，天然升序。

时间复杂度 O(log(n−k) + k)，空间复杂度 O(1)（不计输出）
1import java.util.*;2 3class Solution {4    public List<Integer> findClosestElements(int[] arr, int k, int x) {5        // 二分的是窗口左端：候选窗口 [lo, lo+k-1]，最终答案必是连续的 k 个6        int lo = 0, hi = arr.length - k;7        while (lo < hi) {8            int mid = (lo + hi) >>> 1;9            // arr[mid] 比 arr[mid+k] 离 x 更远（同距时右边的算近）：窗口整个左移不如右移10            if (x - arr[mid] > arr[mid + k] - x) lo = mid + 1;11            else hi = mid;12        }13        List<Integer> ans = new ArrayList<>(k);14        for (int i = lo; i < lo + k; i++) ans.add(arr[i]);15        return ans;16    }17}
题目

给定一个 排序好 的数组 arr ，两个整数 k 和 x ，从数组中找到最靠近 x（两数之差最小）的 k 个数。返回的结果必须要是按升序排好的。

整数 a 比整数 b 更接近 x 需要满足：

  • |a - x| < |b - x| 或者
  • |a - x| == |b - x| 且 a < b

示例 1：

输入：arr = [1,2,3,4,5], k = 4, x = 3
输出：[1,2,3,4]

示例 2：

输入：arr = [1,1,2,3,4,5], k = 4, x = -1
输出：[1,1,2,3]

提示：

  • 1 <= k <= arr.length
  • 1 <= arr.length <= 104
  • arr 按 升序 排列
  • -104 <= arr[i], x <= 104
