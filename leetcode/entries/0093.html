93. 复原 IP 地址

  • 中等
  • 频度 188
  • 回溯
  • 字符串
  • 回溯
  • 力扣已通过

回溯：从 start 起切出下一段（1~3 位、不超过 255、不含前导 0），切满 4 段且用完整个串才记录。

思路

  • dfs(start, path)：path 是已经切好的段，下一段从 s[start] 开始，长度 len 依次试 1~3。
  • 一段合法要同时满足：不含前导 0（len > 1 且首字符是 '0' 就 break），数值不超过 255（超了就 break，再长只会更大）。
  • 合法就加入 path，递归 dfs(start + len)，回来后弹出最后一段，换下一个 len。
  • path 满 4 段时，必须 start == s.length() 才记录，还有字符没用完就丢弃。段数固定为 4，搜索树大小是常数，所以时间、空间都是 O(1)。

最优解

时间复杂度 O(1)，空间复杂度 O(1)（不计输出）
1import java.util.*;2 3class Solution {4    public List<String> restoreIpAddresses(String s) {5        List<String> ans = new ArrayList<>();6        dfs(s, 0, new ArrayList<>(), ans);7        return ans;8    }9 10    // start：下一段从 s[start] 开始；path：已经切好的段11    private void dfs(String s, int start, List<String> path, List<String> ans) {12        if (path.size() == 4) {13            // 恰好 4 段，并且整个串用完，才是一个答案14            if (start == s.length()) ans.add(String.join(".", path));15            return;16        }17        for (int len = 1; len <= 3 && start + len <= s.length(); len++) {18            // 前导 0：只有单独的 "0" 才合法19            if (len > 1 && s.charAt(start) == '0') break;20            String seg = s.substring(start, start + len);21            // 超过 255 就不行，再长只会更大22            if (Integer.parseInt(seg) > 255) break;23            path.add(seg);24            dfs(s, start + len, path, ans);25            path.remove(path.size() - 1);26        }27    }28}
题目

有效 IP 地址 正好由四个整数（每个整数位于 0 到 255 之间组成，且不能含有前导 0），整数之间用 '.' 分隔。

  • 例如："0.1.2.201" 和 "192.168.1.1" 是 有效 IP 地址，但是 "0.011.255.245"、"192.168.1.312" 和 "192.168@1.1" 是 无效 IP 地址。

给定一个只包含数字的字符串 s ，用以表示一个 IP 地址，返回所有可能的有效 IP 地址，这些地址可以通过在 s 中插入 '.' 来形成。你 不能 重新排序或删除 s 中的任何数字。你可以按 任何 顺序返回答案。

示例 1：

输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]

示例 2：

输入：s = "0000"
输出：["0.0.0.0"]

示例 3：

输入：s = "101023"
输出：["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"]

提示：

  • 1 <= s.length <= 20
  • s 仅由数字组成
