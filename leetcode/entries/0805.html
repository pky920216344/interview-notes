换权值 w = n·x − total 后，问题变成「是否存在权值和为 0 的非空真子集」；折半枚举子集和配对。

思路

  • 核心转化：avg(A) = avg(B) ⟺ avg(A) = avg(整体) ⟺ n·sum(A) = total·|A|。把每个元素换成权值 w = n·x − total，条件就是「子集权值和 = 0」。
  • A 非空、非全集 ⟺ 子集大小在 1..n−1 之间。
  • 折半：左半枚举全部子集（n≤30 时 ≤ 2¹⁵），哈希表记「权值和 → 出现过的子集大小（位图）」；右半枚举子集，拿 -s 查左表，大小相加落在 1..n−1 即成功。
  • 左表把「同一个和的不同大小」都记下（位图），空集/全集这些边界大小不会被误用。

时间复杂度 O(2^(n/2)·n)，空间复杂度 O(2^(n/2))
1import java.util.*;2 3class Solution {4    public boolean splitArraySameAverage(int[] nums) {5        int n = nums.length, total = 0;6        for (int x : nums) total += x;7        // 等均值 ⟺ 存在非空真子集 A：n·sum(A) = total·|A|8        // 每个元素换成权值 w = n·x − total，问题变成：有没有非空真子集的权值和为 09        int[] w = new int[n];10        for (int i = 0; i < n; i++) w[i] = n * nums[i] - total;11        // 折半：左半所有子集的权值和 → 出现过的子集大小（位掩码）12        int half = n / 2, rest = n - half;13        Map<Integer, Integer> left = new HashMap<>();14        for (int mask = 0; mask < 1 << half; mask++) {15            int s = 0;16            for (int i = 0; i < half; i++) if ((mask & (1 << i)) != 0) s += w[i];17            int sizes = left.getOrDefault(s, 0);18            left.put(s, sizes | (1 << Integer.bitCount(mask)));19        }20        // 右半枚举子集，配对权值和为 0 的左子集，且两边合计非空、非全集21        for (int mask = 0; mask < 1 << rest; mask++) {22            int s = 0;23            for (int i = 0; i < rest; i++) if ((mask & (1 << i)) != 0) s += w[half + i];24            Integer sizes = left.get(-s);25            if (sizes == null) continue;26            for (int kl = 0; kl <= half; kl++) {27                if ((sizes & (1 << kl)) != 0 && kl + Integer.bitCount(mask) >= 128                        && kl + Integer.bitCount(mask) <= n - 1) return true;29            }30        }31        return false;32    }33}
题目

给定你一个整数数组 nums

我们要将 nums 数组中的每个元素移动到 A 数组 或者 B 数组中，使得 A 数组和 B 数组不为空，并且 average(A) == average(B) 。

如果可以完成则返回true ， 否则返回 false  。

注意：对于数组 arr ,  average(arr) 是 arr 的所有元素的和除以 arr 长度。

示例 1:

输入: nums = [1,2,3,4,5,6,7,8]
输出: true
解释: 我们可以将数组分割为 [1,4,5,8] 和 [2,3,6,7], 他们的平均值都是4.5。

示例 2:

输入: nums = [3,1]
输出: false

提示:

  • 1 <= nums.length <= 30
  • 0 <= nums[i] <= 104
