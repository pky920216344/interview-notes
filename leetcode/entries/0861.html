861. 翻转矩阵后的得分

  • 中等

  • 数组
  • 矩阵
  • 待提交

贪心：先让每行首位变 1（行翻转），再逐列比较 1 和 0 的个数，1 不足一半就整列翻转。

思路

  • 最高位权重最大：第一列全 1 严格不劣于任何方案，所以首位是 0 的行必翻。
  • 其余各列互相独立：某列 1 的个数不到一半就整列翻转，等价于每位取 max(1 数, 0 数)。
  • 行翻转只由首位决定、列翻转按列独立统计，两类操作互不干扰，顺序无所谓。
  • 最后按二进制求和：row[j] << (n-1-j)。

最优解

时间复杂度 O(mn)，空间复杂度 O(1)
1class Solution {2    public int matrixScore(int[][] grid) {3        int m = grid.length, n = grid[0].length;4        // 第一列权重最大：首位是 0 的行整行翻成 1 开头5        for (int[] row : grid) {6            if (row[0] == 0) for (int j = 0; j < n; j++) row[j] ^= 1;7        }8        // 其余每列独立：1 的个数不到一半，就整列翻转让 1 变多9        for (int j = 1; j < n; j++) {10            int ones = 0;11            for (int[] row : grid) ones += row[j];12            if (ones * 2 < m) for (int[] row : grid) row[j] ^= 1;13        }14        // 此时每行都是它能取到的最大二进制值，直接求和15        int ans = 0;16        for (int[] row : grid) {17            for (int j = 0; j < n; j++) ans += row[j] << (n - 1 - j);18        }19        return ans;20    }21}
题目

给你一个大小为 m x n 的二元矩阵 grid ，矩阵中每个元素的值为 0 或 1 。

一次 移动 是指选择任一行或列，并转换该行或列中的每一个值：将所有 0 都更改为 1，将所有 1 都更改为 0。

在做出任意次数的移动后，将该矩阵的每一行都按照二进制数来解释，矩阵的 得分 就是这些数字的总和。

在执行任意次 移动 后（含 0 次），返回可能的最高分数。

示例 1：

输入：grid = [[0,0,1,1],[1,0,1,0],[1,1,0,0]]
输出：39
解释：0b1111 + 0b1001 + 0b1111 = 15 + 9 + 15 = 39

示例 2：

输入：grid = [[0]]
输出：1

提示：

  • m == grid.length
  • n == grid[i].length
  • 1 <= m, n <= 20
  • grid[i][j] 为 0 或 1
