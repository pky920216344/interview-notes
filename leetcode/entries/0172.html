172. 阶乘后的零

  • 简单
  • 频度 13
  • 数学
  • 数学
  • 待提交

尾零个数 = 因子 5 的个数 = n/5 + n/25 + n/125 + …，每除一次 5 就把商累加进答案。

思路

  • 尾零由 2×5 产生；因子 2 远多于 5，只数 5 的个数。
  • n/5 数出 5 的倍数，n/25 再补上 25 里多出的那个 5……每除一次累加一层商。
  • 例：n=25 → 25/5 + 25/25 = 5 + 1 = 6，25! 末尾 6 个零。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int trailingZeroes(int n) {3        // 尾零来自 2×5；2 远比 5 多，只需数因子 5 的个数4        int ans = 0;5        while (n > 0) {6            // 除一次多算一层：/5 数 5 的倍数，/25 再数 25 里多出的 5…7            n /= 5;8            ans += n;9        }10        return ans;11    }12}
题目

给定一个整数 n ，返回 n! 结果中尾随零的数量。

提示 n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1

示例 1：

输入：n = 3
输出：0
解释：3! = 6 ，不含尾随 0

示例 2：

输入：n = 5
输出：1
解释：5! = 120 ，有一个尾随 0

示例 3：

输入：n = 0
输出：0

提示：

  • 0 <= n <= 104
