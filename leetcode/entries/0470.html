470. 用 Rand7() 实现 Rand10()

拒绝采样：两次 rand7 拼出均匀的 1..49，>40 的舍弃重来，剩下 40 个恰好每数 4 格，映射到 1..10。

思路

  • 两次 rand7() 拼 x = (a-1)*7 + b：49 种组合等概率，正好铺满 7×7。
  • 49 不能整除 10，直接取模会不均匀；把 41..49（9 格）舍弃、整对重来，只留 1..40。
  • 1..40 里每个值恰好占 4 格，(x - 1) % 10 + 1 均匀映射到 1..10。
  • 一次成功率 40/49，期望调用 2 × 49/40 ≈ 2.45 次 rand7。

图解

最优解

时间复杂度 O(1)（每次期望 2.45 个 rand7），空间复杂度 O(1)
1class Solution extends SolBase {2    public int rand10() {3        while (true) {4            // 两次 rand7 拼出 1..49 的均匀整数：a 定大方向、b 定小偏移5            int x = (rand7() - 1) * 7 + rand7();6            // 41..49 没法均分给 10 个数，舍弃重来7            if (x <= 40) return (x - 1) % 10 + 1;8        }9    }10}
题目

给定方法 rand7 可生成 [1,7] 范围内的均匀随机整数，试写一个方法 rand10 生成 [1,10] 范围内的均匀随机整数。

你只能调用 rand7() 且不能调用其他方法。请不要使用系统的 Math.random() 方法。

每个测试用例将有一个内部参数 n，即你实现的函数 rand10() 在测试时将被调用的次数。请注意，这不是传递给 rand10() 的参数。

示例 1:

输入: 1
输出: [2]

示例 2:

输入: 2
输出: [2,8]

示例 3:

输入: 3
输出: [3,8,10]

提示:

  • 1 <= n <= 105

进阶:

  • rand7()调用次数的 期望值 是多少 ?
  • 你能否尽量少调用 rand7() ?
