164. 最大间距

  • 困难
  • 频度 13
  • 数学
  • 数组
  • 桶排序
  • 基数排序
  • 排序
  • pigeonhole-principle
  • 待提交

不排序：n 个数放进 n+1 个等宽桶，必有空桶；最大间距 = 相邻非空桶之间「本桶 min − 上桶 max」的最大值。

思路

  • 鸽笼原理：n−1 个相邻间距的和是 max−min，所以答案 ≥ (max−min)/(n−1)；把桶宽做成比它小，桶内的间距不可能就是答案。
  • 每个数用 (x−min)·(n+1)/(max−min+1) 算桶号（分母 +1 让 max 正好落在最后一桶），每桶只记 min 和 max。
  • 扫描非空桶：ans = max(ans, 桶i.min − 上个非空桶.max)，空桶直接跳过；全相等要提前返回 0。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int maximumGap(int[] nums) {5        int n = nums.length;6        if (n < 2) return 0;7        int min = Integer.MAX_VALUE, max = Integer.MIN_VALUE;8        for (int x : nums) { min = Math.min(min, x); max = Math.max(max, x); }9        if (min == max) return 0;10        // n 个数放进 n+1 个桶：必有空桶，桶内间距小于桶宽11        // 而桶宽 ≤ 真答案，所以答案只可能在桶之间12        long range = (long) max - min;   // 用 long 做差：int 里 max−min 会溢出13        int[] bMin = new int[n + 1], bMax = new int[n + 1];14        Arrays.fill(bMin, Integer.MAX_VALUE);   // bMin 还是 MAX_VALUE 说明桶是空的15        Arrays.fill(bMax, Integer.MIN_VALUE);16        for (int x : nums) {17            // 线性映射到 0..n：min 落 0 号桶，max 落 n 号桶（分母 +1 保证不越界）18            long d = (long) x - min;   // 用 long 做差：int 里 max−min 会溢出19            int idx = (int) (d * (n + 1) / (range + 1));20            bMin[idx] = Math.min(bMin[idx], x);21            bMax[idx] = Math.max(bMax[idx], x);22        }23        // 扫非空桶：本桶 min 减上一非空桶的 max，取最大24        int ans = 0, prevMax = bMax[0];25        for (int i = 1; i <= n; i++) {26            if (bMin[i] == Integer.MAX_VALUE) continue;   // 空桶：跨过去27            ans = Math.max(ans, bMin[i] - prevMax);28            prevMax = bMax[i];29        }30        return ans;31    }32}
题目

给定一个无序的数组 nums，返回 数组在排序之后，相邻元素之间最大的差值 。如果数组元素个数小于 2，则返回 0 。

您必须编写一个在「线性时间」内运行并使用「线性额外空间」的算法。

示例 1:

输入: nums = [3,6,9,1]
输出: 3
解释: 排序后的数组是 [1,3,6,9], 其中相邻元素 (3,6) 和 (6,9) 之间都存在最大差值 3。

示例 2:

输入: nums = [10]
输出: 0
解释: 数组元素个数小于 2，因此返回 0。

提示:

  • 1 <= nums.length <= 105
  • 0 <= nums[i] <= 109
