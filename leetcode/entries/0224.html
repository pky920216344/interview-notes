只剩加减：扫一遍，数字按当前符号累加；遇 ( 把当前和与符号压栈从零算，遇 ) 弹出合回去。

思路

  • 维护当前层的累计和 ans 与「下一个数字的符号」sign：+ 置 1、- 置 -1，数字读完按 sign 累加。
  • 遇 (：把 ans、sign 依次压栈，ans 清零——括号内是独立的一层。
  • 遇 )：弹出符号 prev 和外层的和，合回 ans = 外层 + prev × 括号内的和。
  • 开头的 -2、-(...) 这类一元负号天然被 sign=-1 覆盖。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.ArrayDeque;2import java.util.Deque;3 4class Solution {5    public int calculate(String s) {6        // 栈里存每个未闭合「(」之前累计的结果和生效符号7        Deque<Integer> stack = new ArrayDeque<>();8        int ans = 0;    // 当前括号层内已累计的和9        int sign = 1;   // 下一个数字前的正负号10        int i = 0, n = s.length();11        while (i < n) {12            char c = s.charAt(i);13            if (c == ' ') { i++; continue; }14            if (c == '+') { sign = 1; i++; }15            else if (c == '-') { sign = -1; i++; }16            else if (c == '(') {17                // 进入括号：把当前层的和与符号存起来，括号内重新从 0 算18                stack.push(ans);19                stack.push(sign);20                ans = 0;21                sign = 1;22                i++;23            } else if (c == ')') {24                // 括号算完：弹出符号和上一层结果，合回去25                int prev = stack.pop();26                ans = stack.pop() + prev * ans;27                i++;28            } else {29                // 读一个完整的数字，按当前符号累加30                long num = 0;31                while (i < n && s.charAt(i) >= '0' && s.charAt(i) <= '9') {32                    num = num * 10 + (s.charAt(i) - '0');33                    i++;34                }35                ans += sign * (int) num;36            }37        }38        return ans;39    }40}
题目

给你一个字符串表达式 s ，请你实现一个基本计算器来计算并返回它的值。

注意:不允许使用任何将字符串作为数学表达式计算的内置函数，比如 eval() 。

示例 1：

输入：s = "1 + 1"
输出：2

示例 2：

输入：s = " 2-1 + 2 "
输出：3

示例 3：

输入：s = "(1+(4+5+2)-3)+(6+8)"
输出：23

提示：

  • 1 <= s.length <= 3 * 105
  • s 由数字、'+'、'-'、'('、')'、和 ' ' 组成
  • s 表示一个有效的表达式
  • '+' 不能用作一元运算(例如， "+1" 和 "+(2 + 3)" 无效)
  • '-' 可以用作一元运算(即 "-1" 和 "-(2 + 3)" 是有效的)
  • 输入中不存在两个连续的操作符
  • 每个数字和运行的计算将适合于一个有符号的 32位 整数
