1288. 删除被覆盖区间

  • 中等
  • 频度 7
  • 扫描线/排序
  • 数组
  • 排序
  • 待提交

起点升序、同起点终点降序排序后扫一遍：终点没超过历史最大终点的就被罩住删掉，其余保留并更新 maxEnd。

思路

  • 排序后每个区间只需和「历史最大终点」比：终点 ≤ 它就是被覆盖（起点小这一半排序已保证）。
  • 同起点时终点降序排：长区间先扫到、先更新 maxEnd，同起点的短区间才判得出被罩住。
  • 终点要严格更大才保留（终点相等也算被罩住）；maxEnd 一路只增。

时间复杂度 O(n log n)，空间复杂度 O(log n)
1import java.util.*;2 3class Solution {4    public int removeCoveredIntervals(int[][] intervals) {5        // 起点升序，起点相同终点降序：被覆盖的区间一定在前面区间的「罩子」里6        Arrays.sort(intervals, (x, y) -> x[0] != y[0] ? x[0] - y[0] : y[1] - x[1]);7        int kept = 0, maxEnd = 0;                  // 目前见过的最大终点8        for (int[] it : intervals) {9            // 终点没超过历史最大终点 ⇒ 起点终点都被罩住，删10            if (it[1] > maxEnd) {11                kept++;12                maxEnd = it[1];13            }14        }15        return kept;16    }17}
题目

给你一个区间列表，请你删除列表中被其他区间所覆盖的区间。

只有当 c <= a 且 b <= d 时，我们才认为区间 [a,b) 被区间 [c,d) 覆盖。

在完成所有删除操作后，请你返回列表中剩余区间的数目。

示例：

输入：intervals = [[1,4],[3,6],[2,8]]
输出：2
解释：区间 [3,6] 被区间 [2,8] 覆盖，所以它被删除了。

提示：​​​​​​

  • 1 <= intervals.length <= 1000
  • 0 <= intervals[i][0] < intervals[i][1] <= 10^5
  • 对于所有的 i != j：intervals[i] != intervals[j]
