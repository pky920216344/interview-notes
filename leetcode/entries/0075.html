荷兰国旗三指针：p0 收 0、p2 收 2、cur 扫描；遇 2 换到尾部后 cur 不动，其余一路前进，一趟原地排好。

思路

  • 维护三段：[0, p0) 全 0、[p0, cur) 全 1、(p2, n-1] 全 2，cur 指向下一个待判的格子。
  • 遇 0：与 p0 交换，p0、cur 同步右移——换进来的是 1（或自身），一定看过。
  • 遇 2：与 p2 交换后 cur 不动——换进来的元素还没看过，下一轮再判；遇 1 直接 cur++。
  • 循环条件 cur <= p2：p2 右边已全部就位，不用再看；一趟完成，原地 O(1)。

1class Solution {2    public void sortColors(int[] nums) {3        // 不变式：[0, p0) 全 0，[p0, cur) 全 1，(p2, n-1] 全 24        int p0 = 0, p2 = nums.length - 1;5        int cur = 0;6        while (cur <= p2) {7            if (nums[cur] == 0) swap(nums, p0++, cur++);     // 0 换到前段，两边都可前进8            else if (nums[cur] == 2) swap(nums, cur, p2--);  // 2 换到后段；换进来的没看过，cur 不动9            else cur++;                                      // 1 留在中段，直接跳过10        }11    }12 13    private void swap(int[] a, int i, int j) {14        int t = a[i];15        a[i] = a[j];16        a[j] = t;17    }18}
题目

给定一个包含红色、白色和蓝色、共 n 个元素的数组 nums ，原地 对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

我们使用整数 0、 1 和 2 分别表示红色、白色和蓝色。

必须在不使用库内置的 sort 函数的情况下解决这个问题。

示例 1：

输入：nums = [2,0,2,1,1,0]

输出：[0,0,1,1,2,2]

解释：

该数组包含两个 0、两个 1 和两个 2。将它们原地排序后，所有 0 排在最前面，接着是所有 1，最后是所有 2。

示例 2：

输入：nums = [2,0,1]

输出：[0,1,2]

解释：

数组中有且仅有一个 0、一个 1 和一个 2，按 0、1、2 的顺序原地排列。

提示：

  • n == nums.length
  • 1 <= n <= 300
  • nums[i] 为 0、1 或 2
