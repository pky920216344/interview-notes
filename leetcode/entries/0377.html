377. 组合总和 Ⅳ

  • 中等
  • 频度 3
  • 动态规划
  • 数组
  • 动态规划
  • 待提交

完全背包求「排列数」：外层金额、内层候选，dp[a] += dp[a−c] 表示「末尾放 c」的所有接法；和 518 求组合数正好循环顺序相反。

思路

  • dp[a] = 凑出金额 a 的排列个数；dp[0] = 1。
  • 外层枚举金额 a，内层枚举候选 c：排列的最后一个数是 c 时，前面任取一种 dp[a−c] 的排法都行，所以 dp[a] += dp[a−c]。
  • 求排列数必须「外层金额、内层候选」（每种金额把所有候选都试一遍）；求组合数（518）则相反。

最优解

时间复杂度 O(target × |nums|)，空间复杂度 O(target)
1class Solution {2    public int combinationSum4(int[] nums, int target) {3        // dp[a]：凑出金额 a 的「排列」个数（顺序不同算不同）4        int[] dp = new int[target + 1];5        dp[0] = 1;   // 凑出 0 只有「什么都不选」一种6        for (int a = 1; a <= target; a++) {7            for (int c : nums) {8                // 枚举排列的最后一个数是 c：前面凑出 a-c 的每种排法都成立9                if (c <= a) dp[a] += dp[a - c];10            }11        }12        return dp[target];13    }14}
题目

给你一个由 不同 整数组成的数组 nums ，和一个目标整数 target 。请你从 nums 中找出并返回总和为 target 的元素组合的个数。

题目数据保证答案符合 32 位整数范围。

示例 1：

输入：nums = [1,2,3], target = 4
输出：7
解释：
所有可能的组合为：
(1, 1, 1, 1)
(1, 1, 2)
(1, 2, 1)
(1, 3)
(2, 1, 1)
(2, 2)
(3, 1)
请注意，顺序不同的序列被视作不同的组合。

示例 2：

输入：nums = [9], target = 3
输出：0

提示：

  • 1 <= nums.length <= 200
  • 1 <= nums[i] <= 1000
  • nums 中的所有元素 互不相同
  • 1 <= target <= 1000
