水塘抽样：一遍扫描，第 k 次遇到 target 就以 1/k 概率把它的索引替换为答案，每个候选等概率。

思路

  • 只遍历一次 nums，用 cnt 计数当前是第几次遇到 target。
  • 第 cnt 次遇到时掷骰子：rnd.nextInt(cnt) == 0 即以 1/cnt 概率替换 ans。
  • 归纳可证每个候选最终被选中的概率都是 1/总次数——新来的以 1/cnt 当选，旧答案以同概率存活。
  • 相比「哈希表存全部索引再随机取」，省掉 O(n) 空间；这是流式数据唯一可行的写法。

图解

最优解

时间复杂度 O(n) 每次 pick，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    private int[] nums;5    private Random rnd = new Random();6 7    public Solution(int[] nums) {8        this.nums = nums;9    }10 11    public int pick(int target) {12        int ans = -1, cnt = 0;   // cnt：到当前为止是第几次遇到 target13        for (int i = 0; i < nums.length; i++) {14            if (nums[i] != target) continue;15            cnt++;16            // 第 cnt 次遇到时以 1/cnt 概率替换答案，等概率性可归纳证明17            if (rnd.nextInt(cnt) == 0) ans = i;18        }19        return ans;20    }21}
题目

给你一个可能含有 重复元素 的整数数组 nums ，请你随机输出给定的目标数字 target 的索引。你可以假设给定的数字一定存在于数组中。

实现 Solution 类：

  • Solution(int[] nums) 用数组 nums 初始化对象。
  • int pick(int target) 从 nums 中选出一个满足 nums[i] == target 的随机索引 i 。如果存在多个有效的索引，则每个索引的返回概率应当相等。

示例：

输入
["Solution", "pick", "pick", "pick"]
[[[1, 2, 3, 3, 3]], [3], [1], [3]]
输出
[null, 4, 0, 2]

解释
Solution solution = new Solution([1, 2, 3, 3, 3]);
solution.pick(3); // 随机返回索引 2, 3 或者 4 之一。每个索引的返回概率应该相等。
solution.pick(1); // 返回 0 。因为只有 nums[0] 等于 1 。
solution.pick(3); // 随机返回索引 2, 3 或者 4 之一。每个索引的返回概率应该相等。

提示：

  • 1 <= nums.length <= 2 * 104
  • -231 <= nums[i] <= 231 - 1
  • target 是 nums 中的一个整数
  • 最多调用 pick 函数 104 次
