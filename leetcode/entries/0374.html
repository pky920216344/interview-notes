374. 猜数字大小

  • 简单
  • 频度 1
  • 二分查找
  • 二分查找
  • 交互
  • 待提交

二分：每次猜区间中点 mid，用 guess 的返回把候选区间砍一半，直到 lo、hi 相遇。

思路

  • 候选区间 [lo, hi] 初始为 [1, n]，pick 必在其中；区间缩到只剩一个数就是答案。
  • mid = lo + (hi - lo) / 2：不能写 (lo + hi) / 2，n 最大 2^31 - 1，两数相加会溢出。
  • guess(mid) 为 -1（太大）或 0（正好）→ 答案在 [lo, mid]，hi = mid；为 1 → lo = mid + 1。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1public class Solution extends GuessGame {2    public int guessNumber(int n) {3        // 候选区间 [lo, hi]，pick 一定在里面4        int lo = 1, hi = n;5        while (lo < hi) {6            int mid = lo + (hi - lo) / 2;   // 不能写 (lo+hi)/2，n 可达 2^31-1 会溢出7            if (guess(mid) <= 0) hi = mid;  // -1 太大、0 正中：答案落在 [lo, mid]8            else lo = mid + 1;              // 1 太小：答案落在 [mid+1, hi]9        }10        return lo;11    }12}
题目

我们正在玩猜数字游戏。猜数字游戏的规则如下：

我会从 1 到 n 随机选择一个数字。 请你猜选出的是哪个数字。（我选的数字在整个游戏中保持不变）。

如果你猜错了，我会告诉你，我选出的数字比你猜测的数字大了还是小了。

你可以通过调用一个预先定义好的接口 int guess(int num) 来获取猜测结果，返回值一共有三种可能的情况：

  • -1：你猜的数字比我选出的数字大 （即 num > pick）。
  • 1：你猜的数字比我选出的数字小 （即 num < pick）。
  • 0：你猜的数字与我选出的数字相等。（即 num == pick）。

返回我选出的数字。

示例 1：

输入：n = 10, pick = 6
输出：6

示例 2：

输入：n = 1, pick = 1
输出：1

示例 3：

输入：n = 2, pick = 1
输出：1

提示：

  • 1 <= n <= 231 - 1
  • 1 <= pick <= n
