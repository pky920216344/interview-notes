367. 有效的完全平方数

  • 简单
  • 频度 1
  • 二分查找
  • 数学
  • 二分查找
  • 待提交

在 [1, num] 上二分找 x：x² 恰好等于 num 即真；乘积用 long 防溢出。

思路

  • 答案空间单调：x² 随 x 递增，所以能二分；找 x*x == num 的整数 x。
  • mid*mid 可达约 2^60，必须用 long，int 相乘会静默溢出。
  • lo > hi 时区间空，说明没有任何整数的平方等于 num。

图解

最优解

时间复杂度 O(log num)，空间复杂度 O(1)
1class Solution {2    public boolean isPerfectSquare(int num) {3        // 在 [1, num] 上二分找 x 使 x*x == num；乘积用 long 防溢出4        long lo = 1, hi = num;5        while (lo <= hi) {6            long mid = (lo + hi) >>> 1;7            long sq = mid * mid;8            if (sq == num) return true;9            if (sq < num) lo = mid + 1;10            else hi = mid - 1;11        }12        return false;13    }14}
题目

给你一个正整数 num 。如果 num 是一个完全平方数，则返回 true ，否则返回 false 。

完全平方数 是一个可以写成某个整数的平方的整数。换句话说，它可以写成某个整数和自身的乘积。

不能使用任何内置的库函数，如  sqrt 。

示例 1：

输入：num = 16
输出：true
解释：返回 true ，因为 4 * 4 = 16 且 4 是一个整数。

示例 2：

输入：num = 14
输出：false
解释：返回 false ，因为 3.742 * 3.742 = 14 但 3.742 不是一个整数。

提示：

  • 1 <= num <= 231 - 1
