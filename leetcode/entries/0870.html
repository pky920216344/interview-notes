870. 优势洗牌

田忌赛马：手牌升序排好，对手从最强开始逐个安排——能赢就出最强的压，赢不了就拿最弱的去送。

思路

  • 把 nums1 升序排序；对手位置按 nums2 值从大到小处理，idx 里存下标避免打乱 nums2。
  • 每个对手位置 j：若手里最强的 nums1[hi] > nums2[j]，用它赢下这场（hi--）。
  • 否则这场注定赢不了：把最弱的 nums1[lo] 送掉（lo++），把强牌留给后面的对手。
  • 对手按从强到弱安排是对的：若连最强都压不住的对手，用什么牌都赢不了，正好消耗弱牌。

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] advantageCount(int[] nums1, int[] nums2) {5        int n = nums1.length;6        int[] ans = new int[n];7        // 田忌赛马：把自己的牌升序排好，对手按从强到弱逐个安排对局8        Arrays.sort(nums1);9        Integer[] idx = new Integer[n];10        for (int i = 0; i < n; i++) idx[i] = i;11        Arrays.sort(idx, (a, b) -> Integer.compare(nums2[b], nums2[a]));12        int lo = 0, hi = n - 1;   // lo 是手里最弱的牌，hi 是最强的13        for (int i = 0; i < n; i++) {14            int j = idx[i];15            if (nums1[hi] > nums2[j]) ans[j] = nums1[hi--];   // 最强的能赢就赢，攒优势16            else ans[j] = nums1[lo++];                        // 赢不了就送最弱的，保住实力17        }18        return ans;19    }20}
题目

给定两个长度相等的数组 nums1 和 nums2，nums1 相对于 nums2 的优势可以用满足 nums1[i] > nums2[i] 的索引 i 的数目来描述。

返回 nums1 的 任意 排列，使其相对于 nums2 的优势最大化。

示例 1：

输入：nums1 = [2,7,11,15], nums2 = [1,10,4,11]
输出：[2,11,7,15]

示例 2：

输入：nums1 = [12,24,8,32], nums2 = [13,25,32,11]
输出：[24,32,8,12]

提示：

  • 1 <= nums1.length <= 105
  • nums2.length == nums1.length
  • 0 <= nums1[i], nums2[i] <= 109
