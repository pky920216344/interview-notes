1358. 包含所有三种字符的子字符串数目

  • 中等
  • 频度 3
  • 滑动窗口
  • 哈希表
  • 字符串
  • 滑动窗口
  • 待提交

滑窗：right 右移到窗口凑齐 a/b/c，就把左端缩到刚好缺一种；此时以 right 结尾、起点 0..left-1 都合法，ans += left。

思路

  • cnt 记窗口内 a/b/c 的个数，right 一路右移。
  • 窗口凑齐三种就持续左缩，直到缺一种为止；缩完的 left 是第一个不合法的起点。
  • 于是以 right 结尾的合法子串恰有 left 个（起点 0..left-1），ans += left。
  • 缩出的字符不会浪费：right 再遇到时计数补回，窗口可再次凑齐。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int numberOfSubstrings(String s) {3        int[] cnt = new int[3];4        int ans = 0, left = 0;5        for (int right = 0; right < s.length(); right++) {6            cnt[s.charAt(right) - 'a']++;7            // 窗口一旦三种齐全，就把左端缩到刚好缺一种字符为止8            while (cnt[0] > 0 && cnt[1] > 0 && cnt[2] > 0) {9                cnt[s.charAt(left) - 'a']--;10                left++;11            }12            // 此时 [left..right] 缺字符，起点 0..left-1 的子串都包含全部三种13            ans += left;14        }15        return ans;16    }17}
题目

给你一个字符串 s ，它只包含三种字符 a, b 和 c 。

请你返回 a，b 和 c 都 至少 出现过一次的子字符串数目。

示例 1：

输入：s = "abcabc"
输出：10
解释：包含 a，b 和 c 各至少一次的子字符串为 "abc", "abca", "abcab", "abcabc", "bca", "bcab", "bcabc", "cab", "cabc" 和 "abc" (相同字符串算多次)。

示例 2：

输入：s = "aaacb"
输出：3
解释：包含 a，b 和 c 各至少一次的子字符串为 "aaacb", "aacb" 和 "acb" 。

示例 3：

输入：s = "abc"
输出：1

提示：

  • 3 <= s.length <= 5 x 104
  • s 只包含字符 'a'，'b' 和 'c' 。
