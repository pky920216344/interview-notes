121. 买卖股票的最佳时机

  • 简单
  • 频度 282
  • 贪心
  • 数组
  • 动态规划
  • 力扣已通过

一次遍历：记住历史最低价 low；今天卖能赚的最多就是「今天价 - low」，取所有天里最大的。

思路

  • low 是到目前为止见过的最低价（最佳买入价），ans 是目前最大利润，初始为 0（不交易）。
  • 每天先假设「今天卖」：利润 prices[i] - low，用来更新 ans；再用 prices[i] 更新 low。
  • 算利润时的 low 来自今天之前的某一天，所以天然满足「先买后卖」。
  • 价格一路下跌时利润始终不超过 0，ans 保持 0，正好对应「不交易」。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxProfit(int[] prices) {3        // low：到目前为止见过的最低价4        int low = prices[0], ans = 0;5        for (int i = 1; i < prices.length; i++) {6            // 今天卖，就在历史最低价那天买7            ans = Math.max(ans, prices[i] - low);8            low = Math.min(low, prices[i]);9        }10        return ans;11    }12}
题目

给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0 。

示例 1：

输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

示例 2：

输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。

提示：

  • 1 <= prices.length <= 105
  • 0 <= prices[i] <= 104
