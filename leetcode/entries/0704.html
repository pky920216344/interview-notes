二分：闭区间 [left, right]，中点比 target 小就丢左半，大就丢右半，区间空了返回 -1。

思路

  • 区间是闭区间 [left, right]，所以循环条件是 left <= right；left > right 说明区间空了，返回 -1。
  • mid = left + (right - left) / 2，比 (left + right) / 2 不会因相加而溢出。
  • nums[mid] == target 直接返回 mid。
  • nums[mid] < target 令 left = mid + 1，否则令 right = mid - 1：mid 已经比较过，必须 ±1 排除掉，不然区间缩不下去，会死循环。

图解

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int search(int[] nums, int target) {3        // 闭区间 [left, right]：target 若存在，一定在里面4        int left = 0, right = nums.length - 1;5        while (left <= right) {6            // 比 (left + right) / 2 不会溢出7            int mid = left + (right - left) / 2;8            if (nums[mid] == target) return mid;9            if (nums[mid] < target) left = mid + 1;10            else right = mid - 1;11        }12        return -1;13    }14}
题目

给定一个 n 个元素有序的（升序）整型数组 nums 和一个目标值 target  ，写一个函数搜索 nums 中的 target，如果 target 存在返回下标，否则返回 -1。

你必须编写一个具有 O(log n) 时间复杂度的算法。


示例 1:

输入: nums = [-1,0,3,5,9,12], target = 9
输出: 4
解释: 9 出现在 nums 中并且下标为 4

示例 2:

输入: nums = [-1,0,3,5,9,12], target = 2
输出: -1
解释: 2 不存在 nums 中因此返回 -1

提示：

  1. 你可以假设 nums 中的所有元素是不重复的。
  2. n 将在 [1, 10000]之间。
  3. nums 的每个元素都将在 [-9999, 9999]之间。
