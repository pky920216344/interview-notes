1493. 删掉一个元素以后全为 1 的最长子数组

滑动窗口：窗口里最多装 1 个 0，答案 = 最大窗口长 − 1（题面要求必须删掉一个元素）。

思路

  • 窗口 [left, right] 里 0 的个数超过 1 就从左端收缩，直到挤出去一个 0。
  • 窗口里那个 0（全是 1 时随便一个 1）删掉后，剩下的就是 窗口长 − 1 个连续的 1。
  • 所以每步 ans = max(ans, right − left)；全 0 数组每个窗口长 1，自然得 0。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int longestSubarray(int[] nums) {3        // 窗口里最多 1 个 0；答案 = 最大窗口长 - 1（必须删一个元素）4        int ans = 0, zero = 0, left = 0;5        for (int right = 0; right < nums.length; right++) {6            if (nums[right] == 0) zero++;7            // 0 超了：左端收缩，直到挤出去一个 08            while (zero > 1) {9                if (nums[left] == 0) zero--;10                left++;11            }12            // 窗口长再减 1：那个 0（或一个 1）要被删掉13            ans = Math.max(ans, right - left);14        }15        return ans;16    }17}
题目

给你一个二进制数组 nums，你需要从中删除一个元素。

请你返回删除操作后，数组中仅包含 1 的 最长非空子数组 的长度。如果不存在这样的 子数组，请返回 0。

示例 1：

输入：nums = [1,1,0,1]
输出：3
解释：删除下标为 2 的元素后，得到 [1,1,1]，其中包含 3 个值为 1 的元素。

示例 2：

输入：nums = [0,1,1,1,0,1,1,0,1]
输出：5
解释：删除下标为 4 的元素后，得到 [0,1,1,1,1,1,0,1]，其中仅包含 1 的最长子数组为 [1,1,1,1,1]。

示例 3：

输入：nums = [1,1,1]
输出：2
解释：你必须删除一个元素。

提示：

  • 1 <= nums.length <= 105
  • nums[i] 的值为 0 或 1。
