777. 在 LR 字符串中交换相邻字符

双指针跳过 X 配对第 k 个 L/R：去掉 X 后序列须相同，L 只能左移、R 只能右移。

思路

  • 移动不改变 L、R 的相对顺序：把两串的 X 都去掉，剩下的 L/R 序列必须逐字符相同。
  • 第 k 个 L：start 里的下标必须 ≥ result 里的（L 只能左移）；第 k 个 R 相反（只能右移）。
  • 双指针同步跳过 X、逐对比较上面两条，任何一条不满足就返回 false。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean canTransform(String start, String result) {3        // L 只会往左挪、R 只会往右挪；去掉 X 后两串必须完全相同4        int n = start.length(), i = 0, j = 0;5        while (true) {6            // 双指针各自跳过 X，对齐到下一个 L 或 R7            while (i < n && start.charAt(i) == 'X') i++;8            while (j < n && result.charAt(j) == 'X') j++;9            // 一边走完，另一边也必须刚好走完10            if (i == n || j == n) return i == n && j == n;11            // 第 k 个非 X 字符配不上，相对顺序已经不同12            if (start.charAt(i) != result.charAt(j)) return false;13            // start 的 L 不能在 result 对应 L 的右边（L 只左移）14            if (start.charAt(i) == 'L' && i < j) return false;15            // start 的 R 不能在 result 对应 R 的左边（R 只右移）16            if (start.charAt(i) == 'R' && i > j) return false;17            i++;18            j++;19        }20    }21}
题目

在一个由 'L' , 'R' 和 'X' 三个字符组成的字符串（例如"RXXLRXRXL"）中进行移动操作。一次移动操作指用一个 "LX" 替换一个 "XL"，或者用一个 "XR" 替换一个 "RX"。现给定起始字符串 start 和结束字符串 result，请编写代码，当且仅当存在一系列移动操作使得 start 可以转换成 result 时， 返回 True。

示例 1：

输入：start = "RXXLRXRXL", result = "XRLXXRRLX"
输出：true
解释：通过以下步骤我们可以将 start 转化为 result：
RXXLRXRXL ->
XRXLRXRXL ->
XRLXRXRXL ->
XRLXXRRXL ->
XRLXXRRLX

示例 2：

输入：start = "X", result = "L"
输出：false

提示：

  • 1 <= start.length <= 104
  • start.length == result.length
  • start 和 result 都只包含 'L', 'R' 或 'X'。
