把 0 视作 -1 求前缀和；哈希表记每个和的最早下标，同和再遇相减就是 0/1 相等的段。

思路

  • 「0 和 1 一样多」等价于：把 0 当 -1 数前缀和，这段的和不变。问题就变成找两个前缀和相同的下标，距离越远越好。
  • 哈希表 first[和] = 最早下标；开局先放 first[0] = -1（空前缀），从下标 0 开始的合法段才对得上。
  • 再次遇到同一个和时 i - first[sum] 就是一段合法子数组；只有最早的下标能让段最长，所以重复出现时表不更新。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int findMaxLength(int[] nums) {5        // 0 当 -1 数前缀和：同一个和出现两次，两处之间的 0 和 1 恰好一样多6        Map<Integer, Integer> first = new HashMap<>();7        first.put(0, -1);   // 空前缀的和是 0，位置记 -1，从头开始的段才对得上8        int sum = 0, ans = 0;9        for (int i = 0; i < nums.length; i++) {10            sum += nums[i] == 1 ? 1 : -1;11            Integer j = first.get(sum);12            if (j == null) {13                first.put(sum, i);               // 这个和头一次见：记下最早的下标14            } else {15                ans = Math.max(ans, i - j);      // 早就见过：中间那段的 0/1 个数相同16            }17        }18        return ans;19    }20}
题目

给定一个二进制数组 nums , 找到含有相同数量的 0 和 1 的最长连续子数组，并返回该子数组的长度。

示例 1：

输入：nums = [0,1]
输出：2
说明：[0, 1] 是具有相同数量 0 和 1 的最长连续子数组。

示例 2：

输入：nums = [0,1,0]
输出：2
说明：[0, 1] (或 [1, 0]) 是具有相同数量 0 和 1 的最长连续子数组。

示例 3：

输入：nums = [0,1,1,1,1,1,0,0,0]
输出：6
解释：[1,1,1,0,0,0] 是具有相同数量 0 和 1 的最长连续子数组。

提示：

  • 1 <= nums.length <= 105
  • nums[i] 不是 0 就是 1
