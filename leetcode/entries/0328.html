328. 奇偶链表

  • 中等
  • 频度 35
  • 链表
  • 双指针
  • 链表
  • 力扣已通过

奇偶各留一条链：odd、even 每轮各跨一步串自己的尾巴，最后把偶链头接回奇链尾。

思路

  • odd 从第 1 个结点出发、even 从第 2 个出发，先用 evenHead 记住偶链头。
  • 每轮两步：odd.next = even.next（奇链跳过偶结点连下下一个），even.next = odd.next（偶链接到新 odd 的后面）；条件是 even != null && even.next != null，偶链先走所以先到头。
  • 循环结束后 odd.next = evenHead：奇链尾接回偶链头，原表头就是新表头。
  • 结点相对顺序自动保持，因为每条链都是按原顺序串的；空链表和单结点直接返回。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public ListNode oddEvenList(ListNode head) {3        // 空链表或单结点：本来就已经「奇偶分开」4        if (head == null || head.next == null) return head;5        ListNode odd = head, even = head.next;6        // evenHead 记住偶链头，最后要接回奇链尾7        ListNode evenHead = even;8        // 奇偶两条链各自串尾：每次各跨一个结点往前跳9        while (even != null && even.next != null) {10            odd.next = even.next;11            odd = odd.next;12            even.next = odd.next;13            even = even.next;14        }15        // 奇链尾接上偶链头16        odd.next = evenHead;17        return head;18    }19}
题目

给定单链表的头节点 head ，将所有索引为奇数的节点和索引为偶数的节点分别分组，保持它们原有的相对顺序，然后把偶数索引节点分组连接到奇数索引节点分组之后，返回重新排序的链表。

第一个节点的索引被认为是 奇数 ， 第二个节点的索引为 偶数 ，以此类推。

请注意，偶数组和奇数组内部的相对顺序应该与输入时保持一致。

你必须在 O(1) 的额外空间复杂度和 O(n) 的时间复杂度下解决这个问题。

示例 1:

输入: head = [1,2,3,4,5]
输出: [1,3,5,2,4]

示例 2:

输入: head = [2,1,3,5,6,4,7]
输出: [2,3,6,7,1,5,4]

提示:

  • n ==  链表中的节点数
  • 0 <= n <= 104
  • -106 <= Node.val <= 106
