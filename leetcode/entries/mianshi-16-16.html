双向扫描定两端：从左往右记前缀最大值，比它小的元素最后出现的位置是 r；从右往左记后缀最小值，比它大的元素最早出现的位置是 l。

思路

  • 一个元素要进待排区，当且仅当前面有比它大的（或后面有比它小的）。
  • 从左往右维护前缀最大值 mx：array[i] < mx 说明 i 错位，r 不断右移到最后一个这样的 i。
  • 从右往左维护后缀最小值 mn：array[i] > mn 说明 i 错位，l 不断左移到最早这样的 i。
  • 排好 [l, r] 恰好整体有序且最短；数组本来有序时两遍都扫不到错位，返回 [-1, -1]。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] subSort(int[] array) {3        int n = array.length, l = -1, r = -1;4        // 从左往右记前缀最大值：比它小的元素前面必有更大的数，最后出现的那个位置就是 r5        int mx = Integer.MIN_VALUE;6        for (int i = 0; i < n; i++) {7            if (array[i] < mx) r = i;8            else mx = array[i];9        }10        // 从右往左记后缀最小值：比它大的元素后面必有更小的数，最早出现的那个位置就是 l11        int mn = Integer.MAX_VALUE;12        for (int i = n - 1; i >= 0; i--) {13            if (array[i] > mn) l = i;14            else mn = array[i];15        }16        return new int[]{l, r};17    }18}
题目

给定一个整数数组，编写一个函数，找出索引m和n，只要将索引区间[m,n]的元素排好序，整个数组就是有序的。注意：n-m尽量最小，也就是说，找出符合条件的最短序列。函数返回值为[m,n]，若不存在这样的m和n（例如整个数组是有序的），请返回[-1,-1]。

示例：

输入： [1,2,4,7,10,11,7,12,6,7,16,18,19]
输出： [3,9]

提示：

  • 0 <= len(array) <= 1000000
