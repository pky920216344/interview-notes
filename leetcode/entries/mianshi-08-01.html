面试题 08.01. 三步问题

递推 f(i) = f(i−1) + f(i−2) + f(i−3)：最后一步跨 1、2 或 3 阶，三类接法相加；三变量滚动，边算边取模。

思路

  • f(i) 是走完 i 阶的走法数；最后一步跨 1、2 或 3 阶，分别接在 f(i−1)、f(i−2)、f(i−3) 种走法后面，相加。
  • 起步：f(1) = 1，f(2) = 2（1+1、2），f(3) = 4（1+1+1、1+2、2+1、3）。
  • 只依赖前三项，用 a、b、c 三个变量滚动，空间 O(1)。
  • 每步求和后立刻 % 1000000007，三个余数相加最大约 3×10^9，用 long 承接再取模，不会溢出。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int waysToStep(int n) {3        if (n <= 2) return n;4        // a=f(i-3)、b=f(i-2)、c=f(i-1)，三个变量滚着往前走5        long a = 1, b = 2, c = 4;6        for (int i = 4; i <= n; i++) {7            long next = (a + b + c) % 1000000007;8            a = b;9            b = c;10            c = next;11        }12        return (int) c;13    }14}
题目

三步问题。有个小孩正在上楼梯，楼梯有 n 阶台阶，小孩一次可以上 1 阶、2 阶或 3 阶。实现一种方法，计算小孩有多少种上楼梯的方式。结果可能很大，你需要对结果模 1000000007。

示例 1：

 输入：n = 3 
 输出：4
 说明：有四种走法

示例 2：

 输入：n = 5
 输出：13

提示:

  1. n 范围在[1, 1000000]之间
