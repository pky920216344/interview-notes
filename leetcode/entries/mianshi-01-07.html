顺时针 90° = 先沿主对角线转置，再每行左右反转；两轮双层循环原地交换，不开新矩阵。

思路

  • 第一步转置：j 从 i + 1 起扫，(i,j) 与 (j,i) 互换，主对角线上的格子不动。
  • 第二步每行左右反转：j 只走半行，(i,j) 与 (i,n-1-j) 互换，首尾对称交换。
  • 例：[[1,2,3],[4,5,6],[7,8,9]] 转置后 [[1,4,7],[2,5,8],[3,6,9]]，每行反转即 [[7,4,1],[8,5,2],[9,6,3]]。

1class Solution {2    public void rotate(int[][] matrix) {3        int n = matrix.length;4        // 第一步：沿主对角线转置，(i,j) 与 (j,i) 成对互换5        for (int i = 0; i < n; i++) {6            for (int j = i + 1; j < n; j++) {7                int t = matrix[i][j];8                matrix[i][j] = matrix[j][i];9                matrix[j][i] = t;10            }11        }12        // 第二步：每行左右反转，(i,j) 与 (i,n-1-j) 成对互换13        for (int i = 0; i < n; i++) {14            for (int j = 0; j < n / 2; j++) {15                int t = matrix[i][j];16                matrix[i][j] = matrix[i][n - 1 - j];17                matrix[i][n - 1 - j] = t;18            }19        }20    }21}
题目

给你一幅由 N × N 矩阵表示的图像，其中每个像素的大小为 4 字节。请你设计一种算法，将图像旋转 90 度。

不占用额外内存空间能否做到？

示例 1：

给定 matrix = 
[
  [1,2,3],
  [4,5,6],
  [7,8,9]
],

原地旋转输入矩阵，使其变为:
[
  [7,4,1],
  [8,5,2],
  [9,6,3]
]

示例 2：

给定 matrix =
[
  [ 5, 1, 9,11],
  [ 2, 4, 8,10],
  [13, 3, 6, 7],
  [15,14,12,16]
], 

原地旋转输入矩阵，使其变为:
[
  [15,13, 2, 5],
  [14, 3, 4, 1],
  [12, 6, 8, 9],
  [16, 7,10,11]
]
