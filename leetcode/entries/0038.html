38. 外观数列

  • 简单
  • 频度 2
  • 模拟
  • 双指针
  • 字符串
  • 待提交

迭代 n−1 轮行程长度编码：每轮用双指针数出连续相同段，压成「段长 + 字符」拼成下一项。

思路

  • 从 "1" 出发，每轮读当前项：i 指向段首，j 一路走到不同字符，段为 [i, j)。
  • 段输出 j - i（长度）+ s[i]（字符），用 StringBuilder 拼接，读完换下一轮。
  • 串里只会出现 1、2、3（同字符最多连 3 个），所以「段长 + 字符」不会产生歧义。

图解

最优解

时间复杂度 O(第 n 项长度)，空间复杂度 O(第 n 项长度)
1class Solution {2    public String countAndSay(int n) {3        String s = "1";                          // 第 1 项4        for (int round = 2; round <= n; round++) {5            StringBuilder sb = new StringBuilder();6            int i = 0;7            while (i < s.length()) {8                int j = i;9                while (j < s.length() && s.charAt(j) == s.charAt(i)) j++;   // 数同字符的连续段10                sb.append(j - i).append(s.charAt(i));                       // 段长 + 字符11                i = j;12            }13            s = sb.toString();14        }15        return s;16    }17}
题目

「外观数列」是一个数位字符串序列，由递归公式定义：

  • countAndSay(1) = "1"
  • countAndSay(n) 是 countAndSay(n-1) 的行程长度编码。

行程长度编码（RLE）是一种字符串压缩方法，其工作原理是通过将每个最大连续相同字符组替换为该组的长度后加上该字符本身。例如，要压缩字符串 "3322251" ，我们将 "33" 用 "23" 替换，将 "222" 用 "32" 替换，将 "5" 用 "15" 替换并将 "1" 用 "11" 替换。因此压缩后字符串变为 "23321511"。

给定一个整数 n ，返回 外观数列 的第 n 个元素。

示例 1：

输入：n = 4

输出："1211"

解释：

countAndSay(1) = "1"

countAndSay(2) = "1" 的行程长度编码 = "11"

countAndSay(3) = "11" 的行程长度编码 = "21"

countAndSay(4) = "21" 的行程长度编码 = "1211"

示例 2：

输入：n = 1

输出："1"

解释：

这是基本情况。

提示：

  • 1 <= n <= 30
