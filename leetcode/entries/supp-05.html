归并排序：递归把数组对半分到只剩一个元素，再两两归并——两边各看队首比大小，小的写回原数组。

思路

  • mergeSort(lo, hi)：从中点切半，递归排好 [lo..mid] 和 [mid+1..hi]，再 merge 归并；lo >= hi（单元素）天然有序，直接返回。
  • merge 前先把两段一起拷进辅助数组 tmp，然后 i、j 分别指向两段队首，轮番比较，把较小者写回 a。
  • 相等时取左段（<=），排序才稳定；一段用完后，另一段剩下的直接整体搬回去。
  • 最坏也是 O(n log n)，代价是要一个 O(n) 辅助数组；手撕时先写 merge 再写递归最不容易错。

1import java.util.*;2 3class Solution {4    public int[] sortArray(int[] nums) {5        mergeSort(nums, 0, nums.length - 1, new int[nums.length]);6        return nums;7    }8 9    // 分：从中点切半，递归排好左右两段再归并10    private void mergeSort(int[] a, int lo, int hi, int[] tmp) {11        if (lo >= hi) return;12        int mid = (lo + hi) >>> 1;13        mergeSort(a, lo, mid, tmp);14        mergeSort(a, mid + 1, hi, tmp);15        merge(a, lo, mid, hi, tmp);16    }17 18    // 合：[lo..mid] 与 [mid+1..hi] 已各自有序19    private void merge(int[] a, int lo, int mid, int hi, int[] tmp) {20        for (int k = lo; k <= hi; k++) tmp[k] = a[k];   // 两段一起拷进辅助数组21        int i = lo, j = mid + 1;22        for (int k = lo; k <= hi; k++) {23            if (i > mid) a[k] = tmp[j++];                // 左段用完，右段整体搬回24            else if (j > hi) a[k] = tmp[i++];            // 右段用完，左段整体搬回25            else if (tmp[i] <= tmp[j]) a[k] = tmp[i++];  // 取小的；相等取左，保证稳定26            else a[k] = tmp[j++];27        }28    }29}
题目

给你一个整数数组 nums，请你将该数组升序排列。

你必须在 不使用任何内置函数 的情况下解决问题，时间复杂度为 O(nlog(n))，并且空间复杂度尽可能小。

示例 1：

输入：nums = [5,2,3,1]
输出：[1,2,3,5]
解释：数组排序后，某些数字的位置没有改变（例如，2 和 3），而其他数字的位置发生了改变（例如，1 和 5）。

示例 2：

输入：nums = [5,1,1,2,0,0]
输出：[0,0,1,1,2,5]
解释：请注意，nums 的值不一定唯一。

提示：

  • 1 <= nums.length <= 5 * 104
  • -5 * 104 <= nums[i] <= 5 * 104
