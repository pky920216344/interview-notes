面试题 08.03. 魔术索引

  • 简单
  • 频度 1
  • 模拟
  • 数组
  • 二分查找
  • 待提交

升序数组跳跃扫描：nums[i] > i 时中间下标都不可能命中，i 直接跳到 nums[i]；否则前进一格。

思路

  • 从 i = 0 起扫：nums[i] == i 就是最小的魔术索引，直接返回；扫完返回 -1。
  • 关键动作：数组升序，所以 nums[i] > i 时，(i, nums[i]) 里的每个下标 j 都有 nums[j] ≥ nums[i] > j，整段跳过，i 直接跳到 nums[i]。
  • nums[i] < i 时没有可跳的余地，i 前进一格（max 同时覆盖两种情况）。
  • 重复值正是这个解法能快的原因：纯递增数组每个下标都错位，只能一路小步走。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int findMagicIndex(int[] nums) {3        int i = 0;4        while (i < nums.length) {5            if (nums[i] == i) return i;6            // 升序：i 与 nums[i] 之间的下标 j 都有 nums[j] ≥ nums[i] > j7            // 不可能是魔术索引，可以整段跳过；nums[i] < i 时只能前进一格8            i = Math.max(i + 1, nums[i]);9        }10        return -1;11    }12}
题目

魔术索引。 在数组A[0...n-1]中，有所谓的魔术索引，满足条件A[i] = i。给定一个有序整数数组，编写一种方法找出魔术索引，若有的话，在数组A中找出一个魔术索引，如果没有，则返回-1。若有多个魔术索引，返回索引值最小的一个。

示例 1：

 输入：nums = [0, 2, 3, 4, 5]
 输出：0
 说明：0下标的元素为0

示例 2：

 输入：nums = [1, 1, 1]
 输出：1

说明：

  1. nums长度在[1, 1000000]之间
  2. 此题为原书中的 Follow-up，即数组中可能包含重复元素的版本
