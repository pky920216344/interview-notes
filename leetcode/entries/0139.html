dp[i] = 前 i 个字符能否拼出：枚举拼接点 j，dp[j] 且 s[j..i) 在字典里。

思路

  • dp[i] 表示前 i 个字符能否由字典拼出，dp[0] = true（空串）。
  • 枚举最后一个词的起点 j：dp[i] = dp[j] && 字典里有 s[j..i)，命中一个就 break。
  • 词放进 HashSet，子串查询 O(1)；按字典最长词限制 j ≥ i - maxLen，枚举量骤减。
  • 答案是 dp[n]；子串生成本身有开销，剪枝后整体近似 O(n²)。

最优解

时间复杂度 O(n²)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public boolean wordBreak(String s, List<String> wordDict) {5        Set<String> dict = new HashSet<>(wordDict);6        // 结尾的词长不会超过字典最长词，记下来剪枝7        int maxLen = 0;8        for (String w : dict) maxLen = Math.max(maxLen, w.length());9        // dp[i]：前 i 个字符能否拼出（dp[0] 是空串）10        boolean[] dp = new boolean[s.length() + 1];11        dp[0] = true;12        for (int i = 1; i <= s.length(); i++) {13            // j 是上一个拼接点，词长 i-j 至多 maxLen14            for (int j = Math.max(0, i - maxLen); j < i; j++) {15                if (dp[j] && dict.contains(s.substring(j, i))) {16                    dp[i] = true;17                    break;18                }19            }20        }21        return dp[s.length()];22    }23}
题目

给你一个字符串 s 和一个字符串列表 wordDict 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 s 则返回 true。

注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

示例 1：

输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。

示例 2：

输入: s = "applepenapple", wordDict = ["apple", "pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。

示例 3：

输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出: false

提示：

  • 1 <= s.length <= 300
  • 1 <= wordDict.length <= 1000
  • 1 <= wordDict[i].length <= 20
  • s 和 wordDict[i] 仅由小写英文字母组成
  • wordDict 中的所有字符串 互不相同
