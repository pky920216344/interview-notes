1614. 括号的最大嵌套深度

  • 简单
  • 频度 2
  • 栈
  • 栈
  • 字符串
  • bracket-sequences
  • 待提交

不用真开栈：深度就是未闭合的 '(' 个数，'(' 加一、')' 减一，扫一遍取最大。

思路

  • 有效括号串里每个 ) 恰好配掉一个 (，当前深度 = 还没闭合的 ( 个数。
  • '(' 时深度加一并刷新最大值，')' 时减一，数字和运算符直接跳过。
  • 全程只需两个计数器，扫完的 ans 就是最大嵌套深度。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxDepth(String s) {3        // 深度 = 当前未闭合的 '(' 个数，扫一遍取最大4        int depth = 0, ans = 0;5        for (int i = 0; i < s.length(); i++) {6            char c = s.charAt(i);7            if (c == '(') {8                depth++;9                ans = Math.max(ans, depth);10            } else if (c == ')') {11                depth--;12            }13        }14        return ans;15    }16}
题目

给定 有效括号字符串 s，返回 s 的 嵌套深度。嵌套深度是嵌套括号的 最大 数量。

示例 1：

输入：s = "(1+(2*3)+((8)/4))+1"

输出：3

解释：数字 8 在嵌套的 3 层括号中。

示例 2：

输入：s = "(1)+((2))+(((3)))"

输出：3

解释：数字 3 在嵌套的 3 层括号中。

示例 3：

输入：s = "()(())((()()))"

输出：3

提示：

  • 1 <= s.length <= 100
  • s 由数字 0-9 和字符 '+'、'-'、'*'、'/'、'('、')' 组成
  • 题目数据保证括号字符串 s 是 有效的括号字符串
