面试题 01.05. 一次编辑

  • 中等
  • 频度 5
  • 双指针
  • 双指针
  • 字符串
  • 待提交

双指针同步扫两个串：失配时等长按替换双跳、长串只跳一格，第二次失配就 false。

思路

  • 长度差超过 1 直接 false；让 s 是短的、t 是长的，只剩两种情形：等长替换、长串插/删一个字符。
  • 同步推进：字符相同双双右移；失配时若还没用过编辑，等长就 i++、j++（替换），否则只 j++（长串跳一格）。
  • 第二次失配立即 false；循环走完就是 true（长串尾部多出的字符不影响）。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean oneEditAway(String first, String second) {3        // 长度差超过 1 必不止一次编辑4        if (Math.abs(first.length() - second.length()) > 1) return false;5        // 让 s 是短的、t 是长的，之后只需处理「长串多一个字符」和「等长替换」6        String s = first.length() <= second.length() ? first : second;7        String t = first.length() <= second.length() ? second : first;8        int i = 0, j = 0;9        boolean edited = false;10        while (i < s.length() && j < t.length()) {11            if (s.charAt(i) == t.charAt(j)) { i++; j++; continue; }12            // 已经用过一次编辑还不匹配：false13            if (edited) return false;14            edited = true;15            // 等长按替换处理，两个指针一起走；长串只跳过一个字符16            if (s.length() == t.length()) i++;17            j++;18        }19        return true;20    }21}
题目

字符串有三种编辑操作:插入一个英文字符、删除一个英文字符或者替换一个英文字符。 给定两个字符串，编写一个函数判定它们是否只需要一次(或者零次)编辑。

示例 1：

输入：
first = "pale"
second = "ple"
输出：True

示例 2：

输入：
first = "pales"
second = "pal"
输出：False
