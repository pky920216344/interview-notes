945. 使数组唯一的最小增量

  • 中等
  • 频度 2

  • 贪心
  • 数组
  • 计数
  • 排序
  • 待提交

排序后扫一遍，维护下一个空位 free：每个数抬到 max(它, free)，free 永远指向下一个可用值。

思路

  • 排序后从小往大安排座位：前面的数占掉的值，后面的重复值只能继续往后排。
  • free 记下一个还没被占的值；x 的落点是 max(x, free)，增量 落点 - x 累加，再令 free = 落点 + 1。
  • 最优性：最终数组也必须递增，第 i 小的最终值至少是 max(前一个 + 1, a[i])，贪心正好取到下界。
  • 总增量可能超出 int（题面只保证答案在 32 位内），中途用 long 累加更稳。

最优解

时间复杂度 O(n log n)，空间复杂度 O(1)（不计排序栈）
1import java.util.*;2 3class Solution {4    public int minIncrementForUnique(int[] nums) {5        Arrays.sort(nums);6        long cost = 0;7        // free：排序扫描中下一个还没被占用的值；每个数只需抬到 max(它, free)8        int free = 0;9        for (int x : nums) {10            int target = Math.max(x, free);   // 撞车或落在别人身后的数，抬到 free11            cost += target - x;12            free = target + 1;13        }14        return (int) cost;15    }16}
题目

给你一个整数数组 nums 。每次 move 操作将会选择任意一个满足 0 <= i < nums.length 的下标 i，并将 nums[i] 递增 1。

返回使 nums 中的每个值都变成唯一的所需要的最少操作次数。

生成的测试用例保证答案在 32 位整数范围内。

示例 1：

输入：nums = [1,2,2]
输出：1
解释：经过一次 move 操作，数组将变为 [1, 2, 3]。

示例 2：

输入：nums = [3,2,1,2,1,7]
输出：6
解释：经过 6 次 move 操作，数组将变为 [3, 4, 1, 2, 5, 7]。
可以看出 5 次或 5 次以下的 move 操作是不能让数组的每个值唯一的。
提示：
  • 1 <= nums.length <= 105
  • 0 <= nums[i] <= 105
