二分答案 x：count(x) = ≤x 中能被 a 或 b 或 c 整除的个数（容斥），单调不减，找最小 count(x) ≥ n。

思路

  • 第 n 个丑数 = 最小的 x 使 count(x) ≥ n（count 只在丑数处 +1，答案本身必是丑数）。
  • count(x) 用容斥：x/a + x/b + x/c − x/lcm(ab) − x/lcm(ac) − x/lcm(bc) + x/lcm(abc)。
  • count 单调不减 → 二分 x，count(mid) ≥ n 收 hi，否则收 lo；范围 [1, 2×10⁹]（题面保证）。
  • lcm 用 long：a*b*c ≤ 10¹⁸ 不会溢出，lcm(x,y) = x/gcd(x,y)*y 先除后乘。

题目

丑数是可以被 a 或 b 或 c 整除的 正整数 。

给你四个整数：n 、a 、b 、c ，请你设计一个算法来找出第 n 个丑数。

示例 1：

输入：n = 3, a = 2, b = 3, c = 5
输出：4
解释：丑数序列为 2, 3, 4, 5, 6, 8, 9, 10... 其中第 3 个是 4。

示例 2：

输入：n = 4, a = 2, b = 3, c = 4
输出：6
解释：丑数序列为 2, 3, 4, 6, 8, 9, 10, 12... 其中第 4 个是 6。

示例 3：

输入：n = 5, a = 2, b = 11, c = 13
输出：10
解释：丑数序列为 2, 4, 6, 8, 10, 11, 12, 13... 其中第 5 个是 10。

提示：

  • 1 <= n, a, b, c <= 109
  • 1 <= a * b * c <= 1018
  • 本题结果在 [1, 2 * 109] 的范围内
