面试题 16.18. 模式匹配

数出 a、b 各出现几次，枚举 a 串长 lenA，由总长方程解出 lenB，再按段校验「同字母同串、a≠b」。

思路

  • 先处理空：空模式只匹配空串；value 为空时两种字母都出现就得都映射成 ""（相同，非法）。
  • 设 a 串长 lenA：由 ca·lenA + cb·lenB = len 解出 lenB（cb=0 时要求余量恰好为 0）。
  • 对每组 (lenA, lenB) 走一遍 pattern 切分：所有 a 段相同、所有 b 段相同才算成立。
  • 两种字母都出现时还要求 a ≠ b；任一组成立即 true，全失败返回 false。

图解

最优解

时间复杂度 O(len²)（len 为 value 长度），空间复杂度 O(len)
1class Solution {2    public boolean patternMatching(String pattern, String value) {3        int ca = 0, cb = 0;4        for (int i = 0; i < pattern.length(); i++) {5            if (pattern.charAt(i) == 'a') ca++;6            else cb++;7        }8        int len = value.length();9        if (ca == 0 && cb == 0) return len == 0;   // 空模式只匹配空串10        if (len == 0) return ca == 0 || cb == 0;   // 空串要两种字母都映射成 ""，相同即非法11        // 枚举 a 串长 lenA；b 串长由总长方程解出（b 不出现时长度为 0）12        for (int lenA = 0; lenA * ca <= len; lenA++) {13            if (ca == 0 && lenA > 0) break;        // 没有 a：a 串长只能是 014            int rest = len - lenA * ca;15            if (cb == 0 ? rest != 0 : rest % cb != 0) continue;16            int lenB = cb == 0 ? 0 : rest / cb;17            if (matches(pattern, value, lenA, lenB)) return true;18        }19        return false;   // 所有 (lenA, lenB) 组合都不成立20    }21 22    /** 按 (lenA, lenB) 把 value 切给 pattern：所有 a 段相同、所有 b 段相同，且 a ≠ b。 */23    private boolean matches(String pattern, String value, int lenA, int lenB) {24        int pos = 0;25        String a = null, b = null;26        for (int i = 0; i < pattern.length(); i++) {27            if (pattern.charAt(i) == 'a') {28                String sub = value.substring(pos, pos + lenA);29                if (a == null) a = sub;30                else if (!a.equals(sub)) return false;31                pos += lenA;32            } else {33                String sub = value.substring(pos, pos + lenB);34                if (b == null) b = sub;35                else if (!b.equals(sub)) return false;36                pos += lenB;37            }38        }39        return a == null || b == null || !a.equals(b);   // 两种字母都出现时不能同串40    }41}
题目

你有两个字符串，即pattern和value。 pattern字符串由字母"a"和"b"组成，用于描述字符串中的模式。例如，字符串"catcatgocatgo"匹配模式"aabab"（其中"cat"是"a"，"go"是"b"），该字符串也匹配像"a"、"ab"和"b"这样的模式。但需注意"a"和"b"不能同时表示相同的字符串。编写一个方法判断value字符串是否匹配pattern字符串。

示例 1：

输入： pattern = "abba", value = "dogcatcatdog"
输出： true

示例 2：

输入： pattern = "abba", value = "dogcatcatfish"
输出： false

示例 3：

输入： pattern = "aaaa", value = "dogcatcatdog"
输出： false

示例 4：

输入： pattern = "abba", value = "dogdogdogdog"
输出： true
解释： "a"="dogdog",b=""，反之也符合规则

提示：

  • 0 <= len(pattern) <= 1000
  • 0 <= len(value) <= 1000
  • 你可以假设pattern只包含字母"a"和"b"，value仅包含小写字母。
