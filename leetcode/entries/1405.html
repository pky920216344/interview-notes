1405. 最长快乐字符串

  • 中等
  • 频度 1
  • 贪心
  • 堆
  • 贪心
  • 字符串
  • 堆（优先队列）
  • 待提交

大顶堆按剩余个数贪心：每次取与结尾不同的最多者连放两个；堆顶会三连就改放一个次大的。

思路

  • 堆里放三种字符的剩余个数，每次取堆顶连放 min(2, 剩余) 个（两个不会三连），再把剩余压回。
  • 堆顶与结尾相同会三连：改放一个次大的垫一下；次大也没有就结束。
  • 能放两个就放两个，最多者优先耗掉；最后放不进去的字符直接丢弃。

时间复杂度 O(a+b+c)，空间复杂度 O(1)（堆里只有 3 个字符）
1import java.util.PriorityQueue;2 3class Solution {4    public String longestDiverseString(int a, int b, int c) {5        // 大顶堆按剩余个数（同数按字母序，取舍才确定）6        PriorityQueue<int[]> heap = new PriorityQueue<>((x, y) -> y[0] != x[0] ? y[0] - x[0] : x[1] - y[1]);7        if (a > 0) heap.add(new int[]{a, 'a'});8        if (b > 0) heap.add(new int[]{b, 'b'});9        if (c > 0) heap.add(new int[]{c, 'c'});10        StringBuilder sb = new StringBuilder();11        while (!heap.isEmpty()) {12            int[] top = heap.poll();13            // 堆顶与结尾相同：再放就三连了，改放一个次大的14            if (sb.length() > 0 && sb.charAt(sb.length() - 1) == top[1]) {15                if (heap.isEmpty()) break;   // 没有别的字符可垫，到此为止16                int[] second = heap.poll();17                sb.append((char) second[1]);18                if (--second[0] > 0) heap.add(second);19                heap.add(top);20            } else {21                // 一次放两个最划算，但剩下不足两个就只能放一个22                int use = Math.min(2, top[0]);23                for (int t = 0; t < use; t++) sb.append((char) top[1]);24                top[0] -= use;25                if (top[0] > 0) heap.add(top);26            }27        }28        return sb.toString();29    }30}
题目

如果字符串中不含有任何 'aaa'，'bbb' 或 'ccc' 这样的字符串作为子串，那么该字符串就是一个「快乐字符串」。

给你三个整数 a，b ，c，请你返回 任意一个 满足下列全部条件的字符串 s：

  • s 是一个尽可能长的快乐字符串。
  • s 中 最多 有a 个字母 'a'、b 个字母 'b'、c 个字母 'c' 。
  • s 中只含有 'a'、'b' 、'c' 三种字母。

如果不存在这样的字符串 s ，请返回一个空字符串 ""。

示例 1：

输入：a = 1, b = 1, c = 7
输出："ccaccbcc"
解释："ccbccacc" 也是一种正确答案。

示例 2：

输入：a = 2, b = 2, c = 1
输出："aabbc"

示例 3：

输入：a = 7, b = 1, c = 0
输出："aabaa"
解释：这是该测试用例的唯一正确答案。

提示：

  • 0 <= a, b, c <= 100
  • a + b + c > 0
