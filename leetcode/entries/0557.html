557. 反转字符串中的单词 III

  • 双指针

逐词处理：双指针定位每个单词 [i, j)，词内首尾双指针交换反转，i 跳过空格继续。

思路

  • 在 char[] 上原地做：外层 i 指向单词开头，内层 j 向右扫到空格或结尾，单词就是 [i, j)。
  • 词内用 l、r 向中间走逐对交换；换完 i = j + 1 跳过空格。
  • 空格本身不参与反转，所以单词顺序和空格位置都不变。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public String reverseWords(String s) {3        char[] a = s.toCharArray();4        int n = a.length, i = 0;5        while (i < n) {6            int j = i;    // 先定位单词 [i, j)：j 停在空格或结尾7            while (j < n && a[j] != ' ') j++;8            for (int l = i, r = j - 1; l < r; l++, r--) {   // 词内首尾交换9                char t = a[l]; a[l] = a[r]; a[r] = t;10            }11            i = j + 1;    // 跳过空格，处理下一个单词12        }13        return new String(a);14    }15}
题目

给定一个字符串 s ，你需要反转字符串中每个单词的字符顺序，同时仍保留空格和单词的初始顺序。

示例 1：

输入：s = "Let's take LeetCode contest"
输出："s'teL ekat edoCteeL tsetnoc"

示例 2:

输入： s = "Mr Ding"
输出："rM gniD"

提示：

  • 1 <= s.length <= 5 * 104
  • s 包含可打印的 ASCII 字符。
  • s 不包含任何开头或结尾空格。
  • s 里 至少 有一个词。
  • s 中的所有单词都用一个空格隔开。
