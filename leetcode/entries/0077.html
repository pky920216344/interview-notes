回溯：从 start 开始逐个选，选一个递归一个，选完撤销；剪枝让 i 最大到 n-need+1，凑不满的分支根本不进。

思路

  • dfs(start, need)：还差 need 个数，只能从 start 往后挑（保证组合内升序、不重复）。
  • need == 0 就把 path 拷贝收进答案；每轮 path.add(i) → 递归 → path.remove(末尾) 回溯。
  • 剪枝：还差 need 个时，i 最大到 n - need + 1（再靠后连剩下的坑都填不满），直接省掉整棵废子树。

题目

给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。

你可以按 任何顺序 返回答案。

示例 1：

输入：n = 4, k = 2
输出：
[
  [2,4],
  [3,4],
  [2,3],
  [1,2],
  [1,3],
  [1,4],
]

示例 2：

输入：n = 1, k = 1
输出：[[1]]

提示：

  • 1 <= n <= 20
  • 1 <= k <= n
