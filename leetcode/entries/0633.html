双指针：a 从 0 起、b 从 √c 起，a²+b² 偏小 a 右移、偏大 b 左移，向中间夹出答案。

思路

  • 只需检查 a ≤ √c 的候选：把 a 从小、b 从大往中间夹，不用枚举所有组合。
  • a²+b² < c 说明 a 太小，a++；> c 说明 b 太大，b--；相等即成功。
  • a²+b² 最大约 2×(2^31)，必须用 long 存，否则溢出变负数误判。
  • b 取 (long) Math.sqrt(c)：浮点平方根对 int 足够准，截断即 ⌊√c⌋。

时间复杂度 O(√c)，空间复杂度 O(1)

题目

给定一个非负整数 c ，你要判断是否存在两个整数 a 和 b，使得 a2 + b2 = c 。

示例 1：

输入：c = 5
输出：true
解释：1 * 1 + 2 * 2 = 5

示例 2：

输入：c = 3
输出：false

提示：

  • 0 <= c <= 231 - 1
