分治：表达式里每个运算符都轮流当「最后算」的，左右两半各自递归出所有结果，再两两组合。

思路

  • 加括号的本质是选「最后算的运算符」：以每个 + - * 为界切成左右两半，各自算出所有可能。
  • 左右结果两两组合，套上当前运算符，就是这一刀下的全部结果。
  • 段里没有运算符（纯数字）时，它自己就是一个结果，递归到底。
  • 结果顺序任意；同一结果可能来自不同括号方案，要保留重复。

最优解

时间复杂度 O(Catalan(n)·n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public List<Integer> diffWaysToCompute(String expression) {5        List<Integer> ans = new ArrayList<>();6        for (int i = 0; i < expression.length(); i++) {7            char op = expression.charAt(i);8            if (op != '+' && op != '-' && op != '*') continue;9            // 每个运算符都试当「最后算」的：左右两半各自算出所有结果10            List<Integer> left = diffWaysToCompute(expression.substring(0, i));11            List<Integer> right = diffWaysToCompute(expression.substring(i + 1));12            // 左右结果两两组合，就是这个运算符留到最后的一切算式13            for (int a : left)14                for (int b : right)15                    ans.add(op == '+' ? a + b : op == '-' ? a - b : a * b);16        }17        // 一段里没有运算符：它就是一个数，自己就是一种结果18        if (ans.isEmpty()) ans.add(Integer.parseInt(expression));19        return ans;20    }21}
题目

给你一个由数字和运算符组成的字符串 expression ，按不同优先级组合数字和运算符，计算并返回所有可能组合的结果。你可以 按任意顺序 返回答案。

生成的测试用例满足其对应输出值符合 32 位整数范围，不同结果的数量不超过 104 。

示例 1：

输入：expression = "2-1-1"
输出：[0,2]
解释：
((2-1)-1) = 0 
(2-(1-1)) = 2

示例 2：

输入：expression = "2*3-4*5"
输出：[-34,-14,-10,-10,10]
解释：
(2*(3-(4*5))) = -34 
((2*3)-(4*5)) = -14 
((2*(3-4))*5) = -10 
(2*((3-4)*5)) = -10 
(((2*3)-4)*5) = 10

提示：

  • 1 <= expression.length <= 20
  • expression 由数字和算符 '+'、'-' 和 '*' 组成。
  • 输入表达式中的所有整数值在范围 [0, 99] 
  • 输入表达式中的所有整数都没有前导 '-' 或 '+' 表示符号。
