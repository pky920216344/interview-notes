1060. 有序数组中的缺失元素

  • 中等
  • 频度 3
  • 二分查找
  • 数组
  • 二分查找
  • 未经力扣验证

miss(i) = nums[i] − nums[0] − i 表示到 i 为止缺了几个数，单调不减；二分锁定它，答案 = nums[lo] + (k − miss(lo))。

思路

  • miss(i) = nums[i] - nums[0] - i：理想无缺失时 nums[i] 应该是 nums[0]+i，差值就是缺失个数，随 i 单调不减。
  • 二分找「miss(i) < k 的最大 i」（上取整取 mid，找右侧边界）：第 k 个缺失的数必落在 nums[i] 右侧的空档里。
  • 答案 = nums[i] + (k - miss(i))；miss(n-1) < k 时同样成立（答案在最后一个元素之后）。
  • 坑：条件是 < k 而不是 ≤ k——miss(i) 恰好等于 k 时，第 k 个缺失值在 nums[i] 左边。

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    /**3     * 1060. 有序数组中的缺失元素（会员题，无力扣模板，这里自定约定）：4     * nums 升序且元素互不相同，返回「从 nums[0] 之后数起的第 k 个缺失整数」。5     * 例如 nums=[4,7,9,10]：缺的是 5,6,8，k=1 得 5，k=3 得 8。6     */7    public int missingElement(int[] nums, int k) {8        int lo = 0, hi = nums.length - 1;9        // miss(i) = nums[i] - nums[0] - i：nums[0] 到 nums[i] 之间缺了几个数，随 i 单调不减10        while (lo < hi) {11            int mid = (lo + hi + 1) >>> 1;12            if (miss(nums, mid) < k) lo = mid;   // 到 mid 为止缺得还不够，第 k 个缺失在更右边13            else hi = mid - 1;14        }15        // 第 k 个缺失的数落在 nums[lo] 右侧：前面已缺 miss(lo) 个，再补 k - miss(lo) 步16        return nums[lo] + (k - miss(nums, lo));17    }18 19    private int miss(int[] nums, int i) {20        return nums[i] - nums[0] - i;21    }22}
