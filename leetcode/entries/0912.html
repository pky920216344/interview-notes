归并排序：从中点切半递归排好两段，再用辅助数组把两段按序合并；最坏也是 O(n log n)。

思路

  • 分：mid = (lo+hi) >>> 1，递归排 [lo,mid]、[mid+1,hi]，lo >= hi 直接返回。
  • 合：左半段拷进 tmp，右半段留在 a 里；i、j 各指向两段开头，每次取较小者放回 a[k]。
  • 相等时取左段（tmp[i] <= a[j]），排序才稳定；一段用完就把另一段整体搬回。
  • 取舍：对比三向快排，归并最坏情况也是 O(n log n) 且稳定，代价是 O(n) 辅助数组（这里只拷左半段）。

1class Solution {2    public int[] sortArray(int[] nums) {3        // 归并排序：最坏也是 O(n log n) 且稳定，代价是 O(n) 辅助数组4        mergeSort(nums, 0, nums.length - 1, new int[nums.length]);5        return nums;6    }7 8    // 分：从中点切半，递归排好左右两段9    private void mergeSort(int[] a, int lo, int hi, int[] tmp) {10        if (lo >= hi) return;11        int mid = (lo + hi) >>> 1;12        mergeSort(a, lo, mid, tmp);13        mergeSort(a, mid + 1, hi, tmp);14        merge(a, lo, mid, hi, tmp);15    }16 17    // 合：a[lo..mid] 与 a[mid+1..hi] 已各自有序，左半段拷进 tmp 后原地归并18    private void merge(int[] a, int lo, int mid, int hi, int[] tmp) {19        for (int k = lo; k <= mid; k++) tmp[k] = a[k];20        int i = lo, j = mid + 1;21        for (int k = lo; k <= hi; k++) {22            if (i > mid) a[k] = a[j++];                 // 左段用完，右段直接搬23            else if (j > hi || tmp[i] <= a[j]) a[k] = tmp[i++];   // 取小的；相等取左，保持稳定24            else a[k] = a[j++];25        }26    }27}
题目

给你一个整数数组 nums，请你将该数组升序排列。

你必须在 不使用任何内置函数 的情况下解决问题，时间复杂度为 O(nlog(n))，并且空间复杂度尽可能小。

示例 1：

输入：nums = [5,2,3,1]
输出：[1,2,3,5]
解释：数组排序后，某些数字的位置没有改变（例如，2 和 3），而其他数字的位置发生了改变（例如，1 和 5）。

示例 2：

输入：nums = [5,1,1,2,0,0]
输出：[0,0,1,1,2,5]
解释：请注意，nums 的值不一定唯一。

提示：

  • 1 <= nums.length <= 5 * 104
  • -5 * 104 <= nums[i] <= 5 * 104
