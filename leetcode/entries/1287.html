1287. 有序数组中出现次数超过25%的元素

  • 简单
  • 频度 2
  • 二分查找
  • 数组
  • 待提交

有序 ⇒ 同值连续成段；出现 > n/4 次的段长 ≥ n/4+1，必盖住 n/4、n/2、3n/4 三个抽查点之一，对候选二分计数验证。

思路

  • 超过 25% 的值在有序数组里是连续一段，长度 ≥ ⌊n/4⌋+1；三个均匀抽查点间隔 ≤ n/4，所以长段必含其一。
  • 只查 arr[n/4] 一个点会漏：大段可能整体落在它右边（如 [1,1,2,3,3,3,4,4]），三个点才保险。
  • 对候选二分找首个/末个出现位置，个数 = 右 − 左 + 1；用 count * 4 > n 判断，避免除法误差。

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int findSpecialInteger(int[] arr) {3        int n = arr.length;4        // 出现超过 n/4 次的值在有序数组里是一整段，必然盖住三个均匀抽查点之一5        for (int p : new int[]{n / 4, n / 2, 3 * n / 4}) {6            int c = arr[p];7            // 二分数 c 的个数，count*4 > n 即严格超过 25%8            if (count(arr, c) * 4 > n) return c;9        }10        return arr[n / 2];   // 题面保证存在，走不到这里11    }12 13    // 二分找 c 的第一个和最后一个下标，个数 = 右 − 左 + 114    private int count(int[] a, int c) {15        int n = a.length, lo = 0, hi = n;16        while (lo < hi) { int m = (lo + hi) >>> 1; if (a[m] < c) lo = m + 1; else hi = m; }17        int first = lo;18        lo = -1;19        hi = n - 1;20        while (lo < hi) { int m = (lo + hi + 1) >>> 1; if (a[m] > c) hi = m - 1; else lo = m; }21        return lo - first + 1;22    }23}
题目

给你一个非递减的 有序 整数数组，已知这个数组中恰好有一个整数，它的出现次数超过数组元素总数的 25%。

请你找到并返回这个整数

示例：

输入：arr = [1,2,2,6,6,6,6,7,10]
输出：6

提示：

  • 1 <= arr.length <= 10^4
  • 0 <= arr[i] <= 10^5
