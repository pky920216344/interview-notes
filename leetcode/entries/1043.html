1043. 分隔数组以得到最大和

  • 中等
  • 频度 1
  • 动态规划
  • 数组
  • 动态规划
  • 待提交

线性 DP：dp[i]=前 i 个的最大和，枚举最后一段长 j≤k，段值=段内最大值×j，接在 dp[i−j] 上。

思路

  • dp[i]：前 i 个元素分段后的最大和，dp[0] = 0。
  • 转移枚举「最后一段」长 j（≤ k 且 ≤ i）：段内最大 best 随 j 左扩只增不减，增量维护。
  • dp[i] = max(dp[i-j] + best * j)：整段所有元素都抬到段内最大值。
  • 答案 dp[n]；每段长不要求恰好 k，≤ k 即可。

最优解

时间复杂度 O(n·k)，空间复杂度 O(n)
1class Solution {2    public int maxSumAfterPartitioning(int[] arr, int k) {3        int n = arr.length;4        int[] dp = new int[n + 1];   // dp[i]：前 i 个元素分段后的最大和，dp[0]=05        for (int i = 1; i <= n; i++) {6            int best = 0;   // 最后一段的最大值，段往左扩只会更大7            for (int j = 1; j <= k && j <= i; j++) {8                best = Math.max(best, arr[i - j]);9                dp[i] = Math.max(dp[i], dp[i - j] + best * j);10            }11        }12        return dp[n];13    }14}
题目

给你一个整数数组 arr，请你将该数组分隔为长度 最多 为 k 的一些（连续）子数组。分隔完成后，每个子数组的中的所有值都会变为该子数组中的最大值。

返回将数组分隔变换后能够得到的元素最大和。本题所用到的测试用例会确保答案是一个 32 位整数。

示例 1：

输入：arr = [1,15,7,9,2,5,10], k = 3
输出：84
解释：数组变为 [15,15,15,9,10,10,10]

示例 2：

输入：arr = [1,4,1,5,7,3,6,1,9,9,3], k = 4
输出：83

示例 3：

输入：arr = [1], k = 1
输出：1

提示：

  • 1 <= arr.length <= 500
  • 0 <= arr[i] <= 109
  • 1 <= k <= arr.length
