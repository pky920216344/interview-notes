80. 删除有序数组中的重复项 II

  • 中等
  • 频度 21
  • 双指针
  • 数组
  • 双指针
  • 力扣已通过

快慢指针：slow 是保留前缀的空位，每个值先和前缀倒数第二个比，不同才写入——天然「最多保留两次」。

思路

  • 前缀 nums[0..slow) 是答案，且已按序排好；fast 只管往前扫。
  • 关键判断：slow < 2 || nums[slow-2] != nums[fast] 才写入。数组有序，同一值必然连续，和「前缀倒数第二个」比一次就够了。
  • 若 nums[slow-2] == nums[fast]：这个值已在前缀里出现两次，跳过。
  • 返回 slow，前缀就是答案本体（力扣按前缀校验）。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int removeDuplicates(int[] nums) {3        // slow 是已保留前缀的下一个空位；每个值最多保留两次4        int slow = 0;5        for (int fast = 0; fast < nums.length; fast++) {6            // 和前缀倒数第二个比：相同再放就是第三次，跳过7            if (slow < 2 || nums[slow - 2] != nums[fast]) {8                nums[slow++] = nums[fast];9            }10        }11        return slow;12    }13}
题目

给你一个有序数组 nums ，请你 原地 删除重复出现的元素，使得出现次数超过两次的元素只出现两次 ，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在 原地 修改输入数组 并在使用 O(1) 额外空间的条件下完成。

说明：

为什么返回数值是整数，但输出的答案是数组呢？

请注意，输入数组是以「引用」方式传递的，这意味着在函数里修改输入数组对于调用者是可见的。

你可以想象内部操作如下:

// nums 是以“引用”方式传递的。也就是说，不对实参做任何拷贝
int len = removeDuplicates(nums);

// 在函数里修改输入数组对于调用者是可见的。
// 根据你的函数返回的长度, 它会打印出数组中 该长度范围内 的所有元素。
for (int i = 0; i < len; i++) {
    print(nums[i]);
}

示例 1：

输入：nums = [1,1,1,2,2,3]
输出：5, nums = [1,1,2,2,3]
解释：函数应返回新长度 length = 5, 并且原数组的前五个元素被修改为 1, 1, 2, 2, 3。 不需要考虑数组中超出新长度后面的元素。

示例 2：

输入：nums = [0,0,1,1,1,1,2,3,3]
输出：7, nums = [0,0,1,1,2,3,3]
解释：函数应返回新长度 length = 7, 并且原数组的前七个元素被修改为 0, 0, 1, 1, 2, 3, 3。不需要考虑数组中超出新长度后面的元素。

提示：

  • 1 <= nums.length <= 3 * 104
  • -104 <= nums[i] <= 104
  • nums 已按升序排列
