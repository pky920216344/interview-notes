哈希表 key→桶 + 计数桶双向链表：inc/dec 把 key 在相邻计数桶之间挪（缺桶就建、空桶就摘），最大/最小计数就是链表两端，全 O(1)。

思路

  • 链表上每个桶装「计数相同」的全部 key，从 head 到 tail 计数严格递增；getMaxKey/getMinKey 取 tail.prev/head.next 桶里的任意 key。
  • inc：key 挪到 count+1 的桶（就是右边相邻的位置，缺就插一个新桶）；新 key 直接进计数 1 的桶。
  • dec：减到 0 连 key 一起删；否则挪到 count−1 的桶（左边相邻，缺就插）。
  • 挪完旧桶可能空掉，顺手从链表摘除——相邻插入/删除都是 O(1)，所以每个操作整体 O(1)。

最优解

时间复杂度 O(1) 每次操作，空间复杂度 O(n)
1import java.util.*;2 3class AllOne {4    // 计数桶按 count 从小到大串成双向链表，每个桶装计数相同的全部 key5    private static class Node {6        int count;7        Set<String> keys = new LinkedHashSet<>();8        Node prev, next;9 10        Node(int count) {11            this.count = count;12        }13    }14 15    private final Node head = new Node(-1);   // head.next：计数最小的桶16    private final Node tail = new Node(-1);   // tail.prev：计数最大的桶17    private final Map<String, Node> map = new HashMap<>();18 19    public AllOne() {20        head.next = tail;21        tail.prev = head;22    }23 24    public void inc(String key) {25        Node cur = map.get(key);26        if (cur == null) {27            Node b = nextBucket(head, 1);              // 新 key：放进（必要时新建）计数 1 的桶28            b.keys.add(key);29            map.put(key, b);30            return;31        }32        Node b = nextBucket(cur, cur.count + 1);       // 挪到右边相邻的计数桶33        b.keys.add(key);34        map.put(key, b);35        removeKey(cur, key);36    }37 38    public void dec(String key) {39        Node cur = map.get(key);40        if (cur.count == 1) {                          // 减到 0：整个 key 删掉41            map.remove(key);42            removeKey(cur, key);43            return;44        }45        Node b = prevBucket(cur, cur.count - 1);       // 挪到左边相邻的计数桶46        b.keys.add(key);47        map.put(key, b);48        removeKey(cur, key);49    }50 51    public String getMaxKey() {52        return tail.prev == head ? "" : tail.prev.keys.iterator().next();53    }54 55    public String getMinKey() {56        return head.next == tail ? "" : head.next.keys.iterator().next();57    }58 59    /** 在 node 右边找计数为 count 的桶，没有就在中间插一个新桶。 */60    private Node nextBucket(Node node, int count) {61        if (node.next.count == count) return node.next;62        Node b = new Node(count);63        insertAfter(node, b);64        return b;65    }66 67    /** 在 node 左边找计数为 count 的桶，没有就在中间插一个新桶。 */68    private Node prevBucket(Node node, int count) {69        if (node.prev.count == count) return node.prev;70        Node b = new Node(count);71        insertAfter(node.prev, b);72        return b;73    }74 75    private void insertAfter(Node a, Node b) {76        b.prev = a;77        b.next = a.next;78        a.next.prev = b;79        a.next = b;80    }81 82    /** 从桶里删 key；桶空了就把它从链表上摘掉。 */83    private void removeKey(Node bucket, String key) {84        bucket.keys.remove(key);85        if (bucket.keys.isEmpty()) {86            bucket.prev.next = bucket.next;87            bucket.next.prev = bucket.prev;88        }89    }90}
题目

请你设计一个用于存储字符串计数的数据结构，并能够返回计数最小和最大的字符串。

实现 AllOne 类：

  • AllOne() 初始化数据结构的对象。
  • inc(String key) 字符串 key 的计数增加 1 。如果数据结构中尚不存在 key ，那么插入计数为 1 的 key 。
  • dec(String key) 字符串 key 的计数减少 1 。如果 key 的计数在减少后为 0 ，那么需要将这个 key 从数据结构中删除。测试用例保证：在减少计数前，key 存在于数据结构中。
  • getMaxKey() 返回任意一个计数最大的字符串。如果没有元素存在，返回一个空字符串 "" 。
  • getMinKey() 返回任意一个计数最小的字符串。如果没有元素存在，返回一个空字符串 "" 。

注意：每个函数都应当满足 O(1) 平均时间复杂度。

示例：

输入
["AllOne", "inc", "inc", "getMaxKey", "getMinKey", "inc", "getMaxKey", "getMinKey"]
[[], ["hello"], ["hello"], [], [], ["leet"], [], []]
输出
[null, null, null, "hello", "hello", null, "hello", "leet"]

解释
AllOne allOne = new AllOne();
allOne.inc("hello");
allOne.inc("hello");
allOne.getMaxKey(); // 返回 "hello"
allOne.getMinKey(); // 返回 "hello"
allOne.inc("leet");
allOne.getMaxKey(); // 返回 "hello"
allOne.getMinKey(); // 返回 "leet"

提示：

  • 1 <= key.length <= 10
  • key 由小写英文字母组成
  • 测试用例保证：在每次调用 dec 时，数据结构中总存在 key
  • 最多调用 inc、dec、getMaxKey 和 getMinKey 方法 5 * 104 次
