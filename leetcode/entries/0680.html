双指针比对，首次失配时「跳过左」或「跳过右」各试一次，其一能纯比对到底就是回文。

思路

  • left、right 向中间走：相等就同时内移；全程无失配说明本身就是回文。
  • 首次失配只有一次删除机会：跳过 left 或 跳过 right，对剩下那段纯比对到底（isPal）。
  • 两个方向有一个成立即可（如 abcaba 删 c）；之后不再有第二次机会，再失配就是 false。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean validPalindrome(String s) {3        int left = 0, right = s.length() - 1;4        while (left < right) {5            if (s.charAt(left) == s.charAt(right)) {6                left++;7                right--;8            } else {9                // 首次失配：只有一次删除机会，跳左、跳右各试一次10                return isPal(s, left + 1, right) || isPal(s, left, right - 1);11            }12        }13        return true;   // 全程没失配，本身就是回文14    }15 16    // 纯比对 [i, j]，不再给第二次机会17    private boolean isPal(String s, int i, int j) {18        while (i < j) {19            if (s.charAt(i) != s.charAt(j)) return false;20            i++;21            j--;22        }23        return true;24    }25}
题目

给你一个字符串 s，最多 可以从中删除一个字符。

请你判断 s 是否能成为回文字符串：如果能，返回 true ；否则，返回 false 。

示例 1：

输入：s = "aba"
输出：true

示例 2：

输入：s = "abca"
输出：true
解释：你可以删除字符 'c' 。

示例 3：

输入：s = "abc"
输出：false

提示：

  • 1 <= s.length <= 105
  • s 由小写英文字母组成
