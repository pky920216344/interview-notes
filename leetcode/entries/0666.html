666. 路径总和 IV

  • 频度 2
  • 深度优先搜索/递归
  • 哈希表
  • 树
  • 深度优先搜索
  • 数组
  • 哈希表
  • 二叉树
  • 未经力扣验证

把每个数拆成（深度, 位置）存哈希；从根 DFS，孩子是 (d+1, 2p−1) 和 (d+1, 2p)，没孩子即叶子，累加各叶的路径和。

思路

  • 题面的数 = 深度×100 + 位置×10 + 值，所以 x/10 就是坐标 key、x%10 是值。
  • (d, p) 的孩子在下一层的 2p−1 和 2p 位置；两个都查不到就是叶子，把当前 sum 结账。
  • 中间结点把 sum 带下去，左右子树的结果相加；树最多 15 个结点，DFS 一遍即可。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int pathSum(int[] nums) {5        // key = 深度*10 + 位置 → 值：题面的数去掉个位就是坐标6        Map<Integer, Integer> val = new HashMap<>();7        for (int x : nums) val.put(x / 10, x % 10);8        return dfs(1, 1, 0, val);9    }10 11    // 从 (d,p) 往下走：sum 是根到这里的和；(d,p) 的孩子是 (d+1, 2p-1) 和 (d+1, 2p)12    private int dfs(int d, int p, int sum, Map<Integer, Integer> val) {13        sum += val.get(d * 10 + p);14        int l = (d + 1) * 10 + 2 * p - 1, r = l + 1;15        // 没有任何孩子就是叶子：一条根到叶的路径在这里结账16        if (!val.containsKey(l) && !val.containsKey(r)) return sum;17        int ans = 0;18        if (val.containsKey(l)) ans += dfs(d + 1, 2 * p - 1, sum, val);19        if (val.containsKey(r)) ans += dfs(d + 1, 2 * p, sum, val);20        return ans;21    }22}
