283. 移动零

  • 简单
  • 频度 68
  • 双指针
  • 数组
  • 双指针
  • 力扣已通过

快慢双指针：fast 找非零数，和 slow 位置交换；slow 左边永远是排好的非零数，0 自然全堆到末尾。

思路

  • [0, slow) 永远是已排好的非零数，保持原相对顺序；fast 从左到右扫。
  • nums[fast] != 0 就和 nums[slow] 交换，slow++：非零区扩一格，换过来的 0 挪到后面。
  • nums[fast] == 0 什么都不做，fast 继续走。
  • 原地交换，没有返回值（void）；修改后的数组就是答案。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public void moveZeroes(int[] nums) {3        // slow：下一个非零数该放的位置，左边全是排好的非零数4        int slow = 0;5        for (int fast = 0; fast < nums.length; fast++) {6            // 遇到非零数就和 slow 位置交换，非零区向右扩一格7            if (nums[fast] != 0) {8                int t = nums[slow];9                nums[slow] = nums[fast];10                nums[fast] = t;11                slow++;12            }13            // 遇到 0 什么都不做，0 被换到后面，自然全堆到末尾14        }15    }16}
题目

给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意 ，必须在不复制数组的情况下原地对数组进行操作。

示例 1:

输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]

示例 2:

输入: nums = [0]
输出: [0]

提示:

  • 1 <= nums.length <= 104
  • -231 <= nums[i] <= 231 - 1
