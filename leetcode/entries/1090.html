1090. 受标签影响的最大值

  • 中等
  • 频度 2
  • 贪心
  • 贪心
  • 数组
  • 哈希表
  • 计数
  • 排序
  • 待提交

贪心：按 value 从大到小挑，凑满 numWanted 件为止；某标签用到 useLimit 次就跳过。

思路

  • 按值降序排下标（值相同的先后不影响答案的和）。
  • 依次挑：标签没用满（used[label] < useLimit）就收下并计数，满了跳过。
  • 挑满 numWanted 件就停；「大值优先 + 标签限额」交换一下顺序只会更差，贪心即最优。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int largestValsFromLabels(int[] values, int[] labels, int numWanted, int useLimit) {5        int n = values.length;6        Integer[] idx = new Integer[n];7        for (int i = 0; i < n; i++) idx[i] = i;8        Arrays.sort(idx, (a, b) -> values[b] - values[a]);   // 值大的先挑9        int[] used = new int[20001];                          // 每个标签已用次数10        int ans = 0, taken = 0;11        for (int i = 0; i < n && taken < numWanted; i++) {12            int j = idx[i];13            if (used[labels[j]] == useLimit) continue;        // 该标签用满，跳过14            used[labels[j]]++;15            ans += values[j];16            taken++;17        }18        return ans;19    }20}
题目

以两个整数数组  values 和 labels 给定 n 个项的值和标签，并且给出两个整数 numWanted 和 useLimit 。

你的任务是从这些项中找到一个值的和 最大 的子集使得：

  • 项的数量 最多 为 numWanted。
  • 相同标签的项的数量 最多 为 useLimit。

返回最大的和。

示例 1：

输入：values = [5,4,3,2,1], labels = [1,1,2,2,3], numWanted = 3, useLimit = 1

输出：9

解释：

选择的子集是第一个、第三个和第五个项，其值之和为 5 + 3 + 1。

示例 2：

输入：values = [5,4,3,2,1], labels = [1,3,3,3,2], numWanted = 3, useLimit = 2

输出：12

解释：

选择的子集是第一个、第二个和第三个项，其值之和为 5 + 4 + 3。

示例 3：

输入：values = [9,8,8,7,6], labels = [0,0,0,1,1], numWanted = 3, useLimit = 1

输出：16

解释：

选择的子集是第一个和第四个项，其值之和为 9 + 7。

提示：

  • n == values.length == labels.length
  • 1 <= n <= 2 * 104
  • 0 <= values[i], labels[i] <= 2 * 104
  • 1 <= numWanted, useLimit <= n
