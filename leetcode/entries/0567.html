567. 字符串的排列

定长滑窗：s2 上维护长度为 s1 的窗口，两个 26 计数数组每滑一格比一次，相等即找到。

思路

  • need 数 s1 的 26 个字母计数，win 数 s2 上长度为 m 的窗口；计数相等 ⇔ 窗口是 s1 的排列。
  • 先数第一个窗口并比较，相等直接返回 true。
  • 每滑一格只改两处：右端字母 win++、左端字母 win--，再 Arrays.equals 比一次。
  • 不用 diff 变量优化也够快：26 格比较是常数，O(26·n)。

最优解

时间复杂度 O(26·n)，空间复杂度 O(26)
1import java.util.*;2 3class Solution {4    public boolean checkInclusion(String s1, String s2) {5        int m = s1.length(), n = s2.length();6        if (m > n) return false;7        int[] need = new int[26], win = new int[26];8        for (int i = 0; i < m; i++) {          // 数 s1 全部字母 + s2 第一个窗口9            need[s1.charAt(i) - 'a']++;10            win[s2.charAt(i) - 'a']++;11        }12        if (Arrays.equals(need, win)) return true;   // 先比第一个窗口13        for (int i = m; i < n; i++) {          // 窗口每次向右滑一格14            win[s2.charAt(i) - 'a']++;         // 右端新字母进窗15            win[s2.charAt(i - m) - 'a']--;     // 左端旧字母出窗16            if (Arrays.equals(need, win)) return true;   // 每滑一格都比一次17        }18        return false;   // 滑完也没有计数一致的窗口19    }20}
题目

给你两个字符串 s1 和 s2 ，写一个函数来判断 s2 是否包含 s1的 排列。如果是，返回 true ；否则，返回 false 。

换句话说，s1 的排列之一是 s2 的 子串 。

示例 1：

输入：s1 = "ab" s2 = "eidbaooo"
输出：true
解释：s2 包含 s1 的排列之一 ("ba").

示例 2：

输入：s1= "ab" s2 = "eidboaoo"
输出：false

提示：

  • 1 <= s1.length, s2.length <= 104
  • s1 和 s2 仅包含小写字母
