168. Excel 表列名称

  • 简单
  • 频度 21
  • 数学
  • 数学
  • 字符串
  • 力扣已通过

无零 26 进制：每位先 n-- 再取余映射 A~Z、整除 26；低位先出，最后整体反转。

思路

  • 列名是「没有 0 的 26 进制」：A=1 … Z=26，直接 % 26 会让 26 变成 0。
  • 每位先 n--：把 1~26 映成 0~25，(char)('A' + n % 26) 取字符，再 n /= 26 处理更高位。
  • 低位先算出来，存在 sb 里是反的，最后 reverse()。

最优解

时间复杂度 O(log n)，空间复杂度 O(log n)
1class Solution {2    public String convertToTitle(int columnNumber) {3        // 26 进制但没有 0：先减 1 把 1~26 映成 0~25，再取余、整除4        StringBuilder sb = new StringBuilder();5        while (columnNumber > 0) {6            columnNumber--;                               // 关键一步：先减 1，Z(26) 才不会算出 07            sb.append((char) ('A' + columnNumber % 26));  // 先拿到低位字符8            columnNumber /= 26;9        }10        return sb.reverse().toString();11    }12}
题目

给你一个整数 columnNumber ，返回它在 Excel 表中相对应的列名称。

例如：

A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28 
...

示例 1：

输入：columnNumber = 1
输出："A"

示例 2：

输入：columnNumber = 28
输出："AB"

示例 3：

输入：columnNumber = 701
输出："ZY"

示例 4：

输入：columnNumber = 2147483647
输出："FXSHRXW"

提示：

  • 1 <= columnNumber <= 231 - 1
