1047. 删除字符串中的所有相邻重复项

  • 简单
  • 频度 21
  • 栈
  • 栈
  • 字符串
  • 力扣已通过

栈：新字符和栈顶相同就一起消掉（弹栈），否则入栈；最后弹栈拼串是反序，反转一次。

思路

  • 从左往右扫：栈顶和当前字符相同 → 这一对相邻重复一起消掉（弹栈）；不同或栈空 → 入栈。
  • 扫完栈里剩下的字符不可能再相邻相同（相同的话早就消了）。
  • 弹栈拼出来是反序，reverse() 一次得到答案。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public String removeDuplicates(String s) {5        Deque<Character> stack = new ArrayDeque<>();6        for (int i = 0; i < s.length(); i++) {7            char c = s.charAt(i);8            // 栈顶和新字符相同：这一对相邻重复一起消掉，弹出栈顶9            if (!stack.isEmpty() && stack.peek() == c) {10                stack.pop();11            } else {12                stack.push(c);13            }14        }15        // 从栈顶往下弹正好是反序，拼完反转一次16        StringBuilder sb = new StringBuilder();17        while (!stack.isEmpty()) sb.append(stack.pop());18        return sb.reverse().toString();19    }20}
题目

给出由小写字母组成的字符串 s，重复项删除操作 会选择两个相邻且相同的字母，并删除它们。

在 s 上反复执行重复项删除操作，直到无法继续删除。

在完成所有重复项删除操作后返回最终的字符串。答案保证唯一。

示例 1：

输入："abbaca"
输出："ca"
解释：
例如，在 "abbaca" 中，我们可以删除 "bb" 由于两字母相邻且相同，这是此时唯一可以执行删除操作的重复项。之后我们得到字符串 "aaca"，其中又只有 "aa" 可以执行重复项删除操作，所以最后的字符串为 "ca"。

示例 2：

输入：s = "azxxzy"
输出："ay"

提示：

  • 1 <= s.length <= 105
  • s 仅由小写英文字母组成。
