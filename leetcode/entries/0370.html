370. 区间加法

  • 中等
  • 频度 1
  • 前缀和/差分
  • 数组
  • 前缀和
  • 未经力扣验证

差分数组：区间 [s,e] 加 inc 只在 s 处 +inc、e+1 处 −inc；最后前缀和一遍还原，m 个区间只要 O(m)。

思路

  • 逐元素模拟是 O(m·n)；差分把「整段加」压成「两端点各改一次」。
  • diff[s] += inc、diff[e+1] -= inc；diff 比 length 多一格，避免 e = length-1 时越界。
  • 还原：sum 从左到右累加 diff[i]，走到哪 res[i] 就是多少——进入区间时被抬起来，离开时落回去。
  • 适用场景：多次区间改、最后一次读全量。

最优解

时间复杂度 O(m + n)，空间复杂度 O(n)
1class Solution {2    public int[] getModifiedArray(int length, int[][] updates) {3        // 差分：区间 [s, e] 加 inc，只在 s 处 +inc、e+1 处 −inc4        int[] diff = new int[length + 1];5        for (int[] u : updates) {6            diff[u[0]] += u[2];7            diff[u[1] + 1] -= u[2];8        }9        // 前缀和还原：走到哪，叠加到哪10        int[] res = new int[length];11        int sum = 0;12        for (int i = 0; i < length; i++) {13            sum += diff[i];14            res[i] = sum;15        }16        return res;17    }18}
