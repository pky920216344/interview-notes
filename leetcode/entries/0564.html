564. 寻找最近的回文数

  • 困难
  • 频度 3
  • 数学
  • 数学
  • 字符串
  • 待提交

只镜像前半部分：候选 = 镜像(half−1)、镜像(half)、镜像(half+1)，再加 99…9 和 10…01 两个边界，取差最小者。

思路

  • 回文由前半决定：把 half 直接镜像得到同侧候选；half±1 的镜像覆盖「进位/借位」后最接近的两种情况。
  • 位数变化的极端（1000 借位、999 进位）正好落在两个边界回文上：10^(len−1)−1 与 10^len+1。
  • 从候选里排除 n 自身，取差值最小者；同差取更小的（题面要求）。
  • 全程 long：n ≤ 10^18 − 1，差值也不会溢出。

时间复杂度 O(len)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public String nearestPalindromic(String n) {5        long num = Long.parseLong(n);6        int len = n.length();7        Set<Long> cands = new HashSet<>();8        // 位数变化时的两个边界回文：99…9（比 n 短一位）与 10…01（比 n 长一位）9        cands.add((long) Math.pow(10, len - 1) - 1);10        cands.add((long) Math.pow(10, len) + 1);11        long half = Long.parseLong(n.substring(0, (len + 1) / 2));12        // 前半部分 ±1 各镜像一次：覆盖「镜像自身」之外最接近的回文13        for (long h = half - 1; h <= half + 1; h++) {14            String s = Long.toString(h);15            if (s.length() != (len + 1) / 2) continue;   // 借位/进位导致位数变化：已被边界候选覆盖16            String rev = new StringBuilder(s.substring(0, len / 2)).reverse().toString();17            cands.add(Long.parseLong(s + rev));18        }19        // 取 ≠ n 且差最小的；同差取小的20        long best = 0;21        boolean first = true;22        for (long c : cands) {23            if (c == num) continue;24            if (first || Math.abs(c - num) < Math.abs(best - num)25                    || (Math.abs(c - num) == Math.abs(best - num) && c < best)) {26                best = c;27                first = false;28            }29        }30        return Long.toString(best);31    }32}
题目

给定一个表示整数的字符串 n ，返回与它最近的回文整数（不包括自身）。如果不止一个，返回较小的那个。

“最近的”定义为两个整数差的绝对值最小。

示例 1:

输入: n = "123"
输出: "121"

示例 2:

输入: n = "1"
输出: "0"
解释: 0 和 2是最近的回文，但我们返回最小的，也就是 0。

提示:

  • 1 <= n.length <= 18
  • n 只由数字组成
  • n 不含前导 0
  • n 代表在 [1, 1018 - 1] 范围内的整数
