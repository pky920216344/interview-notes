1107. 每日新用户统计

  • 中等
  • 频度 1
  • SQL
  • 数据库
  • 未经力扣验证

先 GROUP BY id 取每人最早登录日作注册日，再按注册日计数并夹在 2019 年区间内。

思路

  • 「注册日期」= 每个用户 MIN(login_date)；先按用户聚合出注册日，再按注册日统计人数。
  • 题面不可见（会员题）：本解按社区通行版本实现——只输出有新用户注册的日期（如需补零日期，可用日期序列表 LEFT JOIN）。
  • 区间用 BETWEEN '2019-01-01' AND '2019-12-31' 过滤。
  • ⚠️ 会员题未经力扣验证：列名/输出口径以你实际看到的题面为准。

最优解
