数组栈 + 懒标记：increment 只在最底 min(k, 个数) 个里最深那个下标记一笔增量，弹出时才结算并下传。

思路

  • add[i] 表示「弹出下标 i 的元素时要补上的增量」；increment(k, val) 只写 add[min(k, 个数)-1] 一处，不做逐个加。
  • pop 先结算 stack[top] + add[top]；上面的增量同样盖住下面的元素，所以把 add[top] 下传给 add[top-1] 再清零。
  • 栈满丢弃 push，空栈 pop 返回 -1。

最优解

时间复杂度 三个操作均 O(1)，空间复杂度 O(maxSize)
1class CustomStack {2    private final int[] stack;3    private final int[] add;   // 懒标记：弹出下标 i 的元素时要补上的增量4    private int top = -1;5 6    public CustomStack(int maxSize) {7        stack = new int[maxSize];8        add = new int[maxSize];9    }10 11    public void push(int x) {12        // 满了就丢弃这次 push13        if (top + 1 < stack.length) stack[++top] = x;14    }15 16    public int pop() {17        if (top < 0) return -1;18        int v = stack[top] + add[top];19        if (top > 0) add[top - 1] += add[top];   // 这笔增量同样盖住下面的元素，下传20        add[top] = 0;21        top--;22        return v;23    }24 25    public void increment(int k, int val) {26        // 只影响最底 min(k, 个数) 个：把增量记在它们中最深那个的下标上27        if (top >= 0) add[Math.min(k, top + 1) - 1] += val;28    }29}
题目

请你设计一个支持对其元素进行增量操作的栈。

实现自定义栈类 CustomStack ：

  • CustomStack(int maxSize)：用 maxSize 初始化对象，maxSize 是栈中最多能容纳的元素数量。
  • void push(int x)：如果栈还未增长到 maxSize ，就将 x 添加到栈顶。
  • int pop()：弹出栈顶元素，并返回栈顶的值，或栈为空时返回 -1 。
  • void inc(int k, int val)：栈底的 k 个元素的值都增加 val 。如果栈中元素总数小于 k ，则栈中的所有元素都增加 val 。

示例：

输入：
["CustomStack","push","push","pop","push","push","push","increment","increment","pop","pop","pop","pop"]
[[3],[1],[2],[],[2],[3],[4],[5,100],[2,100],[],[],[],[]]
输出：
[null,null,null,2,null,null,null,null,null,103,202,201,-1]
解释：
CustomStack stk = new CustomStack(3); // 栈是空的 []
stk.push(1);                          // 栈变为 [1]
stk.push(2);                          // 栈变为 [1, 2]
stk.pop();                            // 返回 2 --> 返回栈顶值 2，栈变为 [1]
stk.push(2);                          // 栈变为 [1, 2]
stk.push(3);                          // 栈变为 [1, 2, 3]
stk.push(4);                          // 栈仍然是 [1, 2, 3]，不能添加其他元素使栈大小变为 4
stk.increment(5, 100);                // 栈变为 [101, 102, 103]
stk.increment(2, 100);                // 栈变为 [201, 202, 103]
stk.pop();                            // 返回 103 --> 返回栈顶值 103，栈变为 [201, 202]
stk.pop();                            // 返回 202 --> 返回栈顶值 202，栈变为 [201]
stk.pop();                            // 返回 201 --> 返回栈顶值 201，栈变为 []
stk.pop();                            // 返回 -1 --> 栈为空，返回 -1

提示：

  • 1 <= maxSize, x, k <= 1000
  • 0 <= val <= 100
  • 每种方法 increment，push 以及 pop 分别最多调用 1000 次
