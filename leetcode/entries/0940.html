end[c] 记以字符 c 结尾的子序列数；扫到 c 先加 total+1 个新的，再扣掉上次以 c 结尾的重复部分。

思路

  • end[c]：以字符 c 结尾的不同子序列个数；total：当前不同非空子序列总数。
  • 扫到 c：已有每个子序列（含空串，共 total + 1 个）接上 c 都成新子序列，记 add = total + 1。
  • 但「上次以 c 结尾」的那批上次已经生成过，必须扣 end[c]：total += add − end[c]，再把 end[c] 更新为 add。
  • 结果可能为负先 + MOD 再取模；全程 long 防溢出，只加法不乘法。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(26)
1class Solution {2    public int distinctSubseqII(String s) {3        long[] end = new long[26];   // end[c]：以字符 c 结尾的不同子序列个数4        long total = 0, MOD = 1_000_000_007;5        for (int i = 0; i < s.length(); i++) {6            int c = s.charAt(i) - 'a';7            long add = total + 1;    // 把 c 接到所有已有子序列（含空串）后面8            // 上次以 c 结尾的子序列这次又生成了一遍，扣掉；先 +MOD 防负9            total = (total + add - end[c] + MOD) % MOD;10            end[c] = add;11        }12        return (int) total;13    }14}
题目

给定一个字符串 s，计算 s 的 不同非空子序列 的个数。因为结果可能很大，所以返回答案需要对10^9 + 7 取余 。

字符串的 子序列 是经由原字符串删除一些（也可能不删除）字符但不改变剩余字符相对位置的一个新字符串。

  • 例如，"ace" 是 "abcde" 的一个子序列，但 "aec" 不是。

示例 1：

输入：s = "abc"
输出：7
解释：7 个不同的子序列分别是 "a", "b", "c", "ab", "ac", "bc", 以及 "abc"。

示例 2：

输入：s = "aba"
输出：6
解释：6 个不同的子序列分别是 "a", "b", "ab", "ba", "aa" 以及 "aba"。

示例 3：

输入：s = "aaa"
输出：3
解释：3 个不同的子序列分别是 "a", "aa" 以及 "aaa"。

提示：

  • 1 <= s.length <= 2000
  • s 仅由小写英文字母组成
