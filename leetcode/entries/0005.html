5. 最长回文子串

Manacher：插 # 统一奇偶回文；用最靠右回文 (c, r) 的镜像半径给 p[i] 起步，再往外扩。

思路

  • 预处理：每个字符两侧插 #（aba 变成 #a#b#a#），奇偶长度的回文都变成以单个字符为中心；s[k] 落在 t[2k+1]。
  • p[i]：以 t[i] 为中心的回文半径（不含中心）。回文两端必是 #，所以它在原串里的长度正好是 p[i]，起点是 (i - p[i]) / 2。
  • 记住目前最靠右的回文：中心 c，右端 r = c + p[c]。r 只增不减，所以整体是 O(n)。
  • 若 i < r，i 在回文 c 内部，镜像点是 j = 2c - i。回文对称，所以 p[i] 至少是 min(p[j], r - i)，拿它当起点，不用从 0 比起。
  • 取 r - i 是因为 r 以外还没比较过，镜像半径再大也不能直接信；i >= r 时没有镜像可借，从 0 起步。
  • 起点之外再一圈一圈往外比（lo、hi 同时向外），把 p[i] 扩大；若 i + p[i] > r，就换成新的中心 c = i、r = i + p[i]。
  • 最后取 p 最大的中心 mid：起点 (mid - p[mid]) / 2，长度 p[mid]。并列时取最左边的，力扣接受任意一个最长的。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public String longestPalindrome(String s) {5        int n = s.length();6        // t = #a#b#a#：s[k] 放在 t[2k+1]，其余填 '#'7        char[] t = new char[2 * n + 1];8        Arrays.fill(t, '#');9        for (int k = 0; k < n; k++) t[2 * k + 1] = s.charAt(k);10        int m = t.length;11        // p[i]：以 t[i] 为中心的回文半径，也是原串里这段回文的长度12        int[] p = new int[m];13        // c、r：目前最靠右的回文的中心和右端14        int c = 0, r = 0;15        for (int i = 0; i < m; i++) {16            // i 在 r 内：借镜像点 2c-i 的半径起步，但不能超过 r17            if (i < r) p[i] = Math.min(p[2 * c - i], r - i);18            // 起步之外，再一圈一圈往外硬扩19            int lo = i - p[i] - 1, hi = i + p[i] + 1;20            while (lo >= 0 && hi < m && t[lo] == t[hi]) {21                p[i]++;22                lo--;23                hi++;24            }25            // 右端越过了 r，就换成新的中心26            if (i + p[i] > r) {27                c = i;28                r = i + p[i];29            }30        }31        // 取半径最大的中心 mid，原串起点是 (mid - p[mid]) / 232        int mid = 0;33        for (int i = 1; i < m; i++) if (p[i] > p[mid]) mid = i;34        int start = (mid - p[mid]) / 2;35        return s.substring(start, start + p[mid]);36    }37}
题目

给你一个字符串 s，找到 s 中最长的 回文 子串。

示例 1：

输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。

示例 2：

输入：s = "cbbd"
输出："bb"

提示：

  • 1 <= s.length <= 1000
  • s 仅由数字和英文字母组成
