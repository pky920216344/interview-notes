1590. 使数组和能被 P 整除

  • 哈希表
  • 数组
  • 哈希表
  • 前缀和
  • 待提交

要移除的子数组和 ≡ total (mod p)；前缀和取模存哈希，每个右端点找 (pre−need) mod p 最近出现的位置，取最短。

思路

  • 设移除的子数组和为 S：要 (total − S) ≡ 0 (mod p)，即 S ≡ total (mod p)，记 need = total mod p。
  • 以 i 为移除段右端点时，找 j 使 pre[j] ≡ pre[i] − need (mod p)，移除 (j, i]，长度 i − j。
  • 哈希表 last[r] 存余数 r 最近出现的下标（先查再存，j 才尽量贴近 i）；last[0] = −1 对应空前缀。
  • 总和用 long 累加（1e5 × 1e9 会溢出）；移除整段不合法，答案仍为 n 时输出 −1。

最优解

时间复杂度 O(n)，空间复杂度 O(min(n, p))
1import java.util.*;2 3class Solution {4    public int minSubarray(int[] nums, int p) {5        long total = 0;6        for (int x : nums) total += x;7        int need = (int) (total % p);   // 要移除的子数组和必须 ≡ total (mod p)8        if (need == 0) return 0;9        // last[r]：前缀和 mod p 为 r 的最近下标；j 离 i 越近，移除段越短10        Map<Integer, Integer> last = new HashMap<>();11        last.put(0, -1);12        long pre = 0;13        int ans = nums.length;14        for (int i = 0; i < nums.length; i++) {15            pre = (pre + nums[i]) % p;16            // 移除 (j, i]：需要 pre[j] ≡ pre[i] − need (mod p)，查最近的 j17            int want = (int) ((pre - need + p) % p);18            Integer j = last.get(want);19            if (j != null) ans = Math.min(ans, i - j);20            last.put((int) pre, i);21        }22        return ans < nums.length ? ans : -1;23    }24}
题目

给你一个正整数数组 nums，请你移除 最短 子数组（可以为 空），使得剩余元素的 和 能被 p 整除。 不允许 将整个数组都移除。

请你返回你需要移除的最短子数组的长度，如果无法满足题目要求，返回 -1 。

子数组 定义为原数组中连续的一组元素。

示例 1：

输入：nums = [3,1,4,2], p = 6
输出：1
解释：nums 中元素和为 10，不能被 p 整除。我们可以移除子数组 [4] ，剩余元素的和为 6 。

示例 2：

输入：nums = [6,3,5,2], p = 9
输出：2
解释：我们无法移除任何一个元素使得和被 9 整除，最优方案是移除子数组 [5,2] ，剩余元素为 [6,3]，和为 9 。

示例 3：

输入：nums = [1,2,3], p = 3
输出：0
解释：和恰好为 6 ，已经能被 3 整除了。所以我们不需要移除任何元素。

示例  4：

输入：nums = [1,2,3], p = 7
输出：-1
解释：没有任何方案使得移除子数组后剩余元素的和被 7 整除。

示例 5：

输入：nums = [1000000000,1000000000,1000000000], p = 3
输出：0

提示：

  • 1 <= nums.length <= 105
  • 1 <= nums[i] <= 109
  • 1 <= p <= 109
