1446. 连续字符

  • 简单
  • 频度 1
  • 模拟
  • 字符串
  • 待提交

一遍扫描：当前字符和前一个相同就把当前段延长，否则重置为 1，途中取最大。

思路

  • len 是「以 i 结尾的同字符段长度」：s[i] == s[i-1] 就 len++，否则重置为 1。
  • 字符串至少 1 个字符，ans、len 从 1 起步。
  • 每走一步就 ans = max(ans, len)，不用回头。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxPower(String s) {3        int ans = 1, len = 1;4        // 从第二个字符起：和前一个相同就把当前段延长，否则重新开一段5        for (int i = 1; i < s.length(); i++) {6            if (s.charAt(i) == s.charAt(i - 1)) len++;7            else len = 1;8            ans = Math.max(ans, len);9        }10        return ans;11    }12}
题目

给你一个字符串 s ，字符串的「能量」定义为：只包含一种字符的最长非空子字符串的长度。

请你返回字符串 s 的 能量。

示例 1：

输入：s = "leetcode"
输出：2
解释：子字符串 "ee" 长度为 2 ，只包含字符 'e' 。

示例 2：

输入：s = "abbcccddddeeeeedcba"
输出：5
解释：子字符串 "eeeee" 长度为 5 ，只包含字符 'e' 。

提示：

  • 1 <= s.length <= 500
  • s 只包含小写英文字母。
