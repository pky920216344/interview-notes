讨厌关系连成无向图，「分两组互不讨厌」就是这张图能否二染色；逐连通块 BFS 染色，相邻同色即失败。

思路

  • 把每条 dislikes 建成无向边（两人互相讨厌）；能分两组 ⇔ 图是二分图。
  • color[i]：0 未分组、1 / -1 两组；图可能不连通，每个未染色的人都要当一次起点。
  • BFS：出队 u，邻居未染色就染反色 -color[u] 入队；邻居已染色且同色 → 冲突，返回 false。
  • 染完全部连通块无冲突 → true。

1import java.util.*;2 3class Solution {4    public boolean possibleBipartition(int n, int[][] dislikes) {5        // 互相讨厌的人连边；问题变成：这张图能不能二染色6        List<Integer>[] g = new List[n + 1];7        for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();8        for (int[] d : dislikes) { g[d[0]].add(d[1]); g[d[1]].add(d[0]); }9        int[] color = new int[n + 1];   // 0 未分组，1 / -1 两个组10        // 图可能不连通：每个没染过色的人都要当一次起点11        for (int s = 1; s <= n; s++) {12            if (color[s] != 0) continue;13            Queue<Integer> q = new ArrayDeque<>();14            color[s] = 1;15            q.add(s);16            while (!q.isEmpty()) {17                int u = q.poll();18                for (int v : g[u]) {19                    if (color[v] == color[u]) return false;   // 讨厌的人被分进了同组20                    if (color[v] == 0) { color[v] = -color[u]; q.add(v); }21                }22            }23        }24        return true;25    }26}
题目

给定一组 n 人（编号为 1, 2, ..., n）， 我们想把每个人分进任意大小的两组。每个人都可能不喜欢其他人，那么他们不应该属于同一组。

给定整数 n 和数组 dislikes ，其中 dislikes[i] = [ai, bi] ，表示不允许将编号为 ai 和  bi的人归入同一组。当可以用这种方法将所有人分进两组时，返回 true；否则返回 false。

示例 1：

输入：n = 4, dislikes = [[1,2],[1,3],[2,4]]
输出：true
解释：group1 [1,4], group2 [2,3]

示例 2：

输入：n = 3, dislikes = [[1,2],[1,3],[2,3]]
输出：false

示例 3：

输入：n = 5, dislikes = [[1,2],[2,3],[3,4],[4,5],[1,5]]
输出：false

提示：

  • 1 <= n <= 2000
  • 0 <= dislikes.length <= 104
  • dislikes[i].length == 2
  • 1 <= dislikes[i][j] <= n
  • ai < bi
  • dislikes 中每一组都 不同
