面试题 01.09. 字符串轮转

  • 频度 1
  • 模拟
  • 字符串

轮转不变环形顺序：把 s1 接自己一遍，s2 是它的子串（且长度相等）就是轮转。

思路

  • s1 轮转 i 位的结果，恰好是 s1+s1 里从下标 i 开始、长 len 的那段窗口。
  • 所以「s2 是 s1 的轮转」⟺ 长度相等 且 s2 是 s1+s1 的子串，一次子串查找搞定。
  • 长度不等直接 false；两边都为空视为 true（contains("") 恒真）。
  • 面试追问「只调一次子串检查」时，这个写法正好只调一次 contains。

最优解

时间复杂度 O(n²)（contains 的朴素实现；KMP 可到 O(n)），空间复杂度 O(n)
1class Solution {2    public boolean isFlipedString(String s1, String s2) {3        // s2 是 s1 的轮转 ⟺ 长度相等，且 s2 是 s1+s1 的子串4        if (s1.length() != s2.length()) return false;5        // s1+s1 里每一段长 len 的窗口正好是 s1 的一种轮转6        String doubled = s1 + s1;7        return doubled.contains(s2);8    }9}
题目

字符串轮转。给定两个字符串s1和s2，请编写代码检查s2是否为s1旋转而成（比如，waterbottle是erbottlewat旋转后的字符串）。

示例 1：

 输入：s1 = "waterbottle", s2 = "erbottlewat"
 输出：True

示例 2：

 输入：s1 = "aa", s2 = "aba"
 输出：False

提示：

  1. 字符串长度在[0, 100000]范围内。

说明:

  1. 你能只调用一次检查子串的方法吗？
