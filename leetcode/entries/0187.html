10 字符滑窗：A/C/G/T 各编 2 位滚进 20 位整数，编码当 key 计数，第 2 次出现才收集。

思路

  • 每个字符 2 位：(c >> 1) & 3 对 A/C/G/T 恰好互不相同，10 个字符正好 20 位，一个 int 装下。
  • 滑窗更新 O(1)：code = ((code << 2) | 两位) & mask，比每次截 10 长度子串快一个量级。
  • 用 merge 计数，等于 2 时才收进结果：同一序列只收一次，天然去重。

1import java.util.*;2 3class Solution {4    public List<String> findRepeatedDnaSequences(String s) {5        // A/C/G/T 各编 2 位：(c >> 1) & 3 恰好互不相同，10 个字符正好 20 位6        Map<Integer, Integer> cnt = new HashMap<>();7        List<String> out = new ArrayList<>();8        int mask = (1 << 20) - 1, code = 0;9        for (int i = 0; i < s.length(); i++) {10            // 滑窗：最高 2 位滚出，新字符的 2 位滚进，编码 O(1) 更新11            code = ((code << 2) | ((s.charAt(i) >> 1) & 3)) & mask;12            if (i < 9) continue;   // 凑满第一个 10 长度窗口13            // 第 2 次出现才收集，之后不再收 → 天然去重14            if (cnt.merge(code, 1, Integer::sum) == 2) out.add(s.substring(i - 9, i + 1));15        }16        return out;17    }18}
题目

DNA序列 由一系列核苷酸组成，缩写为 'A', 'C', 'G' 和 'T'.。

  • 例如，"ACGAATTCCG" 是一个 DNA序列 。

在研究 DNA 时，识别 DNA 中的重复序列非常有用。

给定一个表示 DNA序列 的字符串 s ，返回所有在 DNA 分子中出现不止一次的 长度为 10 的序列(子字符串)。你可以按 任意顺序 返回答案。

示例 1：

输入：s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"
输出：["AAAAACCCCC","CCCCCAAAAA"]

示例 2：

输入：s = "AAAAAAAAAAAAA"
输出：["AAAAAAAAAA"]

提示：

  • 0 <= s.length <= 105
  • s[i]=='A'、'C'、'G' or 'T'
