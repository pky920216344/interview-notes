哈希计数 + 按绝对值从小到大配对：每个 x 把自己配给一个 2x；0 只能和 0 配，个数须为偶数。

思路

  • 按绝对值升序处理：最小的 |x| 没有更小的数来当它的前项，只能当前项去 2x 找对象。
  • 每处理一个值就消耗 cnt[2x] 里相应个数；某侧不够配立即 false。
  • 0 是特例：2×0=0，0 只能和 0 配对，cnt[0] 必须是偶数，先单独判掉。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public boolean canReorderDoubled(int[] arr) {5        Map<Integer, Integer> cnt = new HashMap<>();6        for (int x : arr) cnt.merge(x, 1, Integer::sum);7        // 0 只能和 0 配对，个数必须是偶数8        if ((cnt.getOrDefault(0, 0) & 1) == 1) return false;9        // 按绝对值从小到大：小的一半当前项，去翻倍那侧找配对10        List<Integer> keys = new ArrayList<>(cnt.keySet());11        keys.sort(Comparator.comparingInt(Math::abs));12        for (int x : keys) {13            int c = cnt.get(x);14            if (c == 0) continue;   // 已被更小的数配走15            int need = cnt.getOrDefault(2 * x, 0);16            if (need < c) return false;   // 翻倍侧不够配17            cnt.put(2 * x, need - c);18        }19        return true;20    }21}
题目

给定一个长度为偶数的整数数组 arr，只有对 arr 进行重组后可以满足 “对于每个 0 <= i < len(arr) / 2，都有 arr[2 * i + 1] = 2 * arr[2 * i]” 时，返回 true；否则，返回 false。

示例 1：

输入：arr = [3,1,3,6]
输出：false

示例 2：

输入：arr = [2,1,2,6]
输出：false

示例 3：

输入：arr = [4,-2,2,-4]
输出：true
解释：可以用 [-2,-4] 和 [2,4] 这两组组成 [-2,-4,2,4] 或是 [2,4,-2,-4]

提示：

  • 0 <= arr.length <= 3 * 104
  • arr.length 是偶数
  • -105 <= arr[i] <= 105
