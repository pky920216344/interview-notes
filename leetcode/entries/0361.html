361. 轰炸敌人

  • 中等
  • 频度 1
  • 模拟
  • 前缀和/差分
  • 数组
  • 动态规划
  • 矩阵
  • 未经力扣验证

把每行、每列按墙分段缓存敌人数：行段数 rowHits、列段数 colHits[j]，空地的威力就是两者相加。

思路

  • 一格放炸弹能炸的是「所在行段 + 所在列段」的敌人；同一段里的空地答案相同，不必重算。
  • 行：进入新行段（行首或左边是墙）才向右重数一段；列：colHits[j] 在列顶或上邻是墙时才向下重数。
  • 走到 '0' 格就用现成的 rowHits + colHits[j] 更新答案；整张图一遍扫完。

最优解

时间复杂度 O(m·n)，空间复杂度 O(n)
1class Solution {2    public int maxKilledEnemies(char[][] grid) {3        int m = grid.length, n = grid[0].length;4        int rowHits = 0;                    // 当前行、所在墙段内的敌人数5        int[] colHits = new int[n];         // 每列、所在墙段内的敌人数6        int ans = 0;7        for (int i = 0; i < m; i++) {8            for (int j = 0; j < n; j++) {9                // 行首或左边是墙：这一行段没数过，向右数到下一个墙为止10                if (j == 0 || grid[i][j - 1] == 'W') {11                    rowHits = 0;12                    for (int k = j; k < n && grid[i][k] != 'W'; k++) {13                        if (grid[i][k] == 'E') rowHits++;14                    }15                }16                // 顶行或上面是墙：这一列段没数过，向下数到下一个墙为止17                if (i == 0 || grid[i - 1][j] == 'W') {18                    colHits[j] = 0;19                    for (int k = i; k < m && grid[k][j] != 'W'; k++) {20                        if (grid[k][j] == 'E') colHits[j]++;21                    }22                }23                // 炸弹只能放空地：威力 = 行段敌数 + 列段敌数24                if (grid[i][j] == '0') ans = Math.max(ans, rowHits + colHits[j]);25            }26        }27        return ans;28    }29}
