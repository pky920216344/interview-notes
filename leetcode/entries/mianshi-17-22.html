BFS 逐层扩展「一步之差」的词，入队时记父指针；碰到终点就沿父指针回溯出最短序列。

思路

  • 终点不在字典直接返回空；从 beginWord 开始 BFS，每个词把每个位置试 26 个字母生成邻居。
  • 邻居在字典里且没有父指针才入队：第一次到达即最短层，父指针就定死。
  • 父指针表 parent[w] = 上一个词 起点记 null，终点出队即可停止扩展。
  • 回溯：从 endWord 沿父指针走到 beginWord，addFirst 边走边头插，天然反转为起点→终点。

时间复杂度 O(L·26·N)（L 词长，N 字典大小），空间复杂度 O(N·L)
1import java.util.*;2 3class Solution {4    public List<String> findLadders(String beginWord, String endWord, List<String> wordList) {5        Set<String> dict = new HashSet<>(wordList);6        // 终点不在字典里，永远变不出来7        if (!dict.contains(endWord)) return new ArrayList<>();8        // parent[w] = w 的上一个词；beginWord 的前驱记 null9        Map<String, String> parent = new HashMap<>();10        parent.put(beginWord, null);11        Deque<String> q = new ArrayDeque<>();12        q.add(beginWord);13        while (!q.isEmpty()) {14            String cur = q.poll();15            // 终点出队即可回溯，父指针在入队时已记好16            if (cur.equals(endWord)) break;17            // 每个位置试 26 个字母，生成所有「一步之差」的词18            char[] cs = cur.toCharArray();19            for (int i = 0; i < cs.length; i++) {20                char old = cs[i];21                for (char ch = 'a'; ch <= 'z'; ch++) {22                    if (ch == old) continue;23                    cs[i] = ch;24                    String next = new String(cs);25                    // 在字典里且没访问过（没父指针）才入队：保证第一次到达即最短26                    if (dict.contains(next) && !parent.containsKey(next)) {27                        parent.put(next, cur);28                        q.add(next);29                    }30                }31                cs[i] = old;32            }33        }34        if (!parent.containsKey(endWord)) return new ArrayList<>();35        // 从终点沿父指针走回起点，再反转成起点→终点36        LinkedList<String> path = new LinkedList<>();37        for (String w = endWord; w != null; w = parent.get(w)) path.addFirst(w);38        return path;39    }40}
题目

给定字典中的两个词，长度相等。写一个方法，把一个词转换成另一个词， 但是一次只能改变一个字符。每一步得到的新词都必须能在字典中找到。

编写一个程序，返回一个可能的转换序列。如有多个可能的转换序列，你可以返回任何一个。

示例 1：

输入：
beginWord = "hit",
endWord = "cog",
wordList = ["hot","dot","dog","lot","log","cog"]

输出：
["hit","hot","dot","lot","log","cog"]

示例 2：

输入：
beginWord = "hit"
endWord = "cog"
wordList = ["hot","dot","dog","lot","log"]

输出：[]

解释：endWord "cog" 不在字典中，所以不存在符合要求的转换序列。
