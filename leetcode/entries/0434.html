434. 字符串中的单词数

  • 简单
  • 频度 1
  • 模拟
  • 字符串
  • 待提交

扫一遍字符串：每跨过一次「空格 → 非空格」的边界，就是一个新单词，计数即可。

思路

  • 单词是连续非空格段，段数 = 「非空格字符，且前一个是空格（或是开头）」出现的次数。
  • 逐字符扫：s[i] != ' ' 且 i == 0 || s[i-1] == ' ' 时 ans++。
  • 不用切分、不用额外空间；首尾空格、连续空格都被条件自动跳过。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int countSegments(String s) {3        int ans = 0;4        for (int i = 0; i < s.length(); i++) {5            // 非空格，且前一个是空格（或就是开头）：新词开始6            if (s.charAt(i) != ' ' && (i == 0 || s.charAt(i - 1) == ' ')) ans++;7        }8        return ans;9    }10}
题目

统计字符串中的单词个数，这里的单词指的是连续的不是空格的字符。

请注意，你可以假定字符串里不包括任何不可打印的字符。

示例:

输入: "Hello, my name is John"
输出: 5
解释: 这里的单词是指连续的不是空格的字符，所以 "Hello," 算作 1 个单词。
