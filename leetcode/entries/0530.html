中序遍历 BST 得到升序序列，最小差必出现在相邻两值之间；记 prev 一遍扫完。

思路

  • BST 中序遍历天然升序，任意两值的最小差只可能出现在相邻两个被访问的值之间。
  • 维护 prev = 上一个访问的值：每访问一个结点，用 当前值 - prev 更新答案。
  • 首个结点没有前驱，只记 prev 不算差；一遍中序即可，无需额外数组。

最优解

时间复杂度 O(n)，空间复杂度 O(h)
1class Solution {2    private long prev = Long.MIN_VALUE;3    private long ans = Long.MAX_VALUE;4 5    public int getMinimumDifference(TreeNode root) {6        // 复位状态，防止同一实例被多次调用时带上旧值7        prev = Long.MIN_VALUE;8        ans = Long.MAX_VALUE;9        inorder(root);10        return (int) ans;11    }12 13    // 中序遍历得到升序序列，最小差只可能出现在相邻两值之间14    private void inorder(TreeNode node) {15        if (node == null) return;16        inorder(node.left);17        // prev 是中序里上一个访问的值，相邻差在这里产生18        if (prev != Long.MIN_VALUE) ans = Math.min(ans, node.val - prev);19        prev = node.val;20        inorder(node.right);21    }22}
题目

给你一个二叉搜索树的根节点 root ，返回 树中任意两不同节点值之间的最小差值 。

差值是一个正数，其数值等于两值之差的绝对值。

示例 1：

输入：root = [4,2,6,1,3]
输出：1

示例 2：

输入：root = [1,0,48,null,null,12,49]
输出：1

提示：

  • 树中节点的数目范围是 [2, 104]
  • 0 <= Node.val <= 105

注意：本题与 783 https://leetcode.cn/problems/minimum-distance-between-bst-nodes/ 相同
