345. 反转字符串中的元音字母

  • 简单
  • 频度 3
  • 双指针
  • 双指针
  • 字符串
  • 待提交

首尾双指针：l 从左找元音、r 从右找元音，两边都停住就交换，然后各进一格，交错即停。

思路

  • 元音判定用 "aeiouAEIOU".indexOf(c) >= 0，大小写一起覆盖。
  • 内层两个 while 负责跳过辅音；l < r 的保护让两指针交错时立刻停，不会扫过头。
  • 停稳就交换，再 l++、r--；全部元音配对完毕即反转完成。

最优解

时间复杂度 O(n)，空间复杂度 O(n)（toCharArray；双指针本身 O(1)）
1class Solution {2    public String reverseVowels(String s) {3        char[] a = s.toCharArray();4        int l = 0, r = a.length - 1;5        while (l < r) {6            while (l < r && !isVowel(a[l])) l++;7            while (l < r && !isVowel(a[r])) r--;8            // 两边都停在元音上就交换，然后各进一格9            char t = a[l]; a[l] = a[r]; a[r] = t;10            l++;11            r--;12        }13        return new String(a);14    }15 16    private boolean isVowel(char c) {17        // 大小写元音一口气写进一个串，命中就是元音18        return "aeiouAEIOU".indexOf(c) >= 0;19    }20}
题目

给你一个字符串 s ，仅反转字符串中的所有元音字母，并返回结果字符串。

元音字母包括 'a'、'e'、'i'、'o'、'u'，且可能以大小写两种形式出现不止一次。

示例 1：

输入：s = "IceCreAm"

输出："AceCreIm"

解释：

s 中的元音是 ['I', 'e', 'e', 'A']。反转这些元音，s 变为 "AceCreIm".

示例 2：

输入：s = "leetcode"

输出："leotcede"

提示：

  • 1 <= s.length <= 3 * 105
  • s 由 可打印的 ASCII 字符组成
