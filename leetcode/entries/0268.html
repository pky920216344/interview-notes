异或消去：ans 先取 n，再把每个下标 i 和值 nums[i] 依次异或进来；值 v 和下标 v 成对抵消，剩下的就是缺失数。

思路

  • ans 初始为 n，等价于把「下标 n」也放进异或池；随后每步 ans ^= i ^ nums[i]。
  • 异或可交换、x^x=0：数组外的完整下标集 0..n 比数组多一个数，值 v（只要不是缺失数）必与下标 v 成对。
  • 全部成对抵消后，唯一没被配对的就是缺失的数，不用额外数组、不怕求和溢出。

时间复杂度 O(n)，空间复杂度 O(1)

题目

给定一个包含 [0, n] 中 n 个数的数组 nums ，找出 [0, n] 这个范围内没有出现在数组中的那个数。

示例 1：

输入：nums = [3,0,1]

输出：2

解释：n = 3，因为有 3 个数字，所以所有的数字都在范围 [0,3] 内。2 是丢失的数字，因为它没有出现在 nums 中。

示例 2：

输入：nums = [0,1]

输出：2

解释：n = 2，因为有 2 个数字，所以所有的数字都在范围 [0,2] 内。2 是丢失的数字，因为它没有出现在 nums 中。

示例 3：

输入：nums = [9,6,4,2,3,5,7,0,1]

输出：8

解释：n = 9，因为有 9 个数字，所以所有的数字都在范围 [0,9] 内。8 是丢失的数字，因为它没有出现在 nums 中。

提示：

  • n == nums.length
  • 1 <= n <= 104
  • 0 <= nums[i] <= n
  • nums 中的所有数字都 独一无二
