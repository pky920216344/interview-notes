回溯：open < n 才能放 '('，close < open 才能放 ')'，放满 2n 位就记下一个答案。

思路

  • dfs(open, close)：path 是已经放好的括号串，open、close 是其中左、右括号的个数。
  • 左括号没用完（open < n）就可以放 '('；右括号比左括号少（close < open）才可以放 ')'，这样永远不会出现孤立的右括号。
  • 每试一个字符：append、递归、再 deleteCharAt 撤销，回到上一层继续试下一种。
  • path.length() == 2 * n 时，一定恰好 n 对且合法，直接记录。合法串个数是卡特兰数，约 4^n / n^1.5，每个复制 O(n)。

最优解

时间复杂度 O(4^n / √n)，空间复杂度 O(n)（不计输出）
1import java.util.*;2 3class Solution {4    private int n;5    private List<String> ans;6    private final StringBuilder path = new StringBuilder();7 8    public List<String> generateParenthesis(int n) {9        this.n = n;10        ans = new ArrayList<>();11        dfs(0, 0);12        return ans;13    }14 15    // open / close：path 里已有的左括号、右括号个数16    private void dfs(int open, int close) {17        if (path.length() == 2 * n) {18            ans.add(path.toString());19            return;20        }21        // 左括号还没用完，就可以放 '('22        if (open < n) {23            path.append('(');24            dfs(open + 1, close);25            path.deleteCharAt(path.length() - 1);26        }27        // 右括号比左括号少，才可以放 ')'28        if (close < open) {29            path.append(')');30            dfs(open, close + 1);31            path.deleteCharAt(path.length() - 1);32        }33    }34}
题目

数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的 括号组合。

示例 1：

输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]

示例 2：

输入：n = 1
输出：["()"]

提示：

  • 1 <= n <= 8
