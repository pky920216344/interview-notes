补充题23. 检测循环依赖

  • 中等
  • 频度 47
  • 图算法
  • 广度优先搜索
  • 未经力扣验证

拓扑排序 Kahn：依赖边 b→a 建邻接表和入度表，入度 0 的先完成并给后继减 1；最后完成数 < n 就有环。

思路

  • edges[i] = [a, b] 表示 a 依赖 b，建成边 b → a：b 的邻接表挂上 a，a 的入度加 1。
  • 入度 0 的结点没有依赖，先入队；每弹出一个就给后继入度减 1，减到 0 才入队。
  • 环上的结点入度永远减不到 0，进不了队列；队列排空后 done == n 无环，done < n 就有环。
  • 本条目力扣上没有页面：签名自定为 canFinish(int n, int[][] edges)，只做本地验证、不提交。
