带权并查集：父指针挂树，ratio[i] 存「i 除以父结点的商」；同根的查询 x/y = ratio[x]/ratio[y]，不同根或没出现过给 -1。

思路

  • 每个变量一个结点；a/b=v 就把 a 的根挂到 b 的根下，并按 a/b=v 推出根之间的倍数 ratio[ra] = v×ratio[b]/ratio[a]。
  • find 路径压缩时沿途 ratio 累乘，压缩后每个结点直接存「自己 / 根」。
  • 查询 x/y：任一变量没出现过 → -1；两结点不同根（无传导关系）→ -1；同根 → ratio[x]/ratio[y]。

时间复杂度 O((m+q)·α)，空间复杂度 O(m)
1import java.util.*;2 3class Solution {4    // ratio[i]：i 除以父结点的商，即 i = ratio[i] × parent[i]5    private int[] parent;6    private double[] ratio;7 8    public double[] calcEquation(List<List<String>> equations, double[] values, List<List<String>> queries) {9        // 变量编号：字符串 → 下标10        Map<String, Integer> id = new HashMap<>();11        for (List<String> eq : equations) for (String v : eq) id.putIfAbsent(v, id.size());12        int n = id.size();13        parent = new int[n];14        ratio = new double[n];15        for (int i = 0; i < n; i++) { parent[i] = i; ratio[i] = 1.0; }16        for (int i = 0; i < equations.size(); i++) {17            int a = id.get(equations.get(i).get(0)), b = id.get(equations.get(i).get(1));18            // a / b = values[i]：把 a 的根挂到 b 的根下19            union(a, b, values[i]);20        }21        double[] ans = new double[queries.size()];22        for (int i = 0; i < queries.size(); i++) {23            Integer x = id.get(queries.get(i).get(0)), y = id.get(queries.get(i).get(1));24            if (x == null || y == null) { ans[i] = -1.0; continue; }25            int rx = find(x), ry = find(y);26            // 同根：x = ratio[x]×根，y = ratio[y]×根，相除即为答案27            ans[i] = rx == ry ? ratio[x] / ratio[y] : -1.0;28        }29        return ans;30    }31 32    private void union(int a, int b, double v) {33        int ra = find(a), rb = find(b);34        if (ra == rb) return;35        parent[ra] = rb;36        // 由 a/b=v 推出 ra/rb = v×ratio[b]/ratio[a]37        ratio[ra] = v * ratio[b] / ratio[a];38    }39 40    // 路径压缩：沿途 ratio 累乘成「自己 / 根」41    private int find(int x) {42        if (parent[x] == x) return x;43        int root = find(parent[x]);44        ratio[x] *= ratio[parent[x]];45        parent[x] = root;46        return root;47    }48}
题目

给你一个变量对数组 equations 和一个实数值数组 values 作为已知条件，其中 equations[i] = [Ai, Bi] 和 values[i] 共同表示等式 Ai / Bi = values[i] 。每个 Ai 或 Bi 是一个表示单个变量的字符串。

另有一些以数组 queries 表示的问题，其中 queries[j] = [Cj, Dj] 表示第 j 个问题，请你根据已知条件找出 Cj / Dj = ? 的结果作为答案。

返回 所有问题的答案 。如果存在某个无法确定的答案，则用 -1.0 替代这个答案。如果问题中出现了给定的已知条件中没有出现的字符串，也需要用 -1.0 替代这个答案。

注意：输入总是有效的。你可以假设除法运算中不会出现除数为 0 的情况，且不存在任何矛盾的结果。

注意：未在等式列表中出现的变量是未定义的，因此无法确定它们的答案。

示例 1：

输入：equations = [["a","b"],["b","c"]], values = [2.0,3.0], queries = [["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]
输出：[6.00000,0.50000,-1.00000,1.00000,-1.00000]
解释：
条件：a / b = 2.0, b / c = 3.0
问题：a / c = ?, b / a = ?, a / e = ?, a / a = ?, x / x = ?
结果：[6.0, 0.5, -1.0, 1.0, -1.0 ]
注意：x 是未定义的 => -1.0

示例 2：

输入：equations = [["a","b"],["b","c"],["bc","cd"]], values = [1.5,2.5,5.0], queries = [["a","c"],["c","b"],["bc","cd"],["cd","bc"]]
输出：[3.75000,0.40000,5.00000,0.20000]

示例 3：

输入：equations = [["a","b"]], values = [0.5], queries = [["a","b"],["b","a"],["a","c"],["x","y"]]
输出：[0.50000,2.00000,-1.00000,-1.00000]

提示：

  • 1 <= equations.length <= 20
  • equations[i].length == 2
  • 1 <= Ai.length, Bi.length <= 5
  • values.length == equations.length
  • 0.0 < values[i] <= 20.0
  • 1 <= queries.length <= 20
  • queries[i].length == 2
  • 1 <= Cj.length, Dj.length <= 5
  • Ai, Bi, Cj, Dj 由小写英文字母与数字组成
