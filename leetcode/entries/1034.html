DFS 找全 (row,col) 的同色连通块；4 邻出界或异色的格子是边界，收集完统一染色。

思路

  • 从 (row, col) 出发 DFS，只走同色格子，把整个连通块标记出来。
  • 块内格子是边界 ⟺ 某个 4 邻出界或颜色不同；把边界格先收集进列表。
  • 染色必须等 DFS 结束后统一做：边找边染会改掉格子颜色，污染「同色」判断。
  • 目标色与原色相同时跳过染色，原样返回。

1import java.util.*;2 3class Solution {4    private static final int[] DX = {-1, 1, 0, 0}, DY = {0, 0, -1, 1};5    private int c0, m, n;6    private boolean[][] vis;7 8    public int[][] colorBorder(int[][] grid, int row, int col, int color) {9        m = grid.length;10        n = grid[0].length;11        c0 = grid[row][col];12        vis = new boolean[m][n];13        List<int[]> border = new ArrayList<>();14        dfs(grid, row, col, border);15        // 颜色相同就不动；否则把收集好的边界格统一染色（不能边找边染，会污染判断）16        if (c0 != color) {17            for (int[] p : border) grid[p[0]][p[1]] = color;18        }19        return grid;20    }21 22    // 找全 (row,col) 的同色连通块；4 邻出界或异色的格子是边界23    private void dfs(int[][] g, int x, int y, List<int[]> border) {24        vis[x][y] = true;25        boolean edge = false;26        for (int d = 0; d < 4; d++) {27            int nx = x + DX[d], ny = y + DY[d];28            if (nx < 0 || nx >= m || ny < 0 || ny >= n) edge = true;29            else if (g[nx][ny] != c0) edge = true;30            else if (!vis[nx][ny]) dfs(g, nx, ny, border);31        }32        if (edge) border.add(new int[]{x, y});33    }34}
题目

给你一个大小为 m x n 的整数矩阵 grid ，表示一个网格。另给你三个整数 row、col 和 color 。网格中的每个值表示该位置处的网格块的颜色。

如果两个方块在任意 4 个方向上相邻，则称它们 相邻 。

如果两个方块具有相同的颜色且相邻，它们则属于同一个 连通分量 。

连通分量的边界是指连通分量中满足下述条件之一的所有网格块：

  • 在上、下、左、右任意一个方向上与不属于同一连通分量的网格块相邻
  • 在网格的边界上（第一行/列或最后一行/列）

请你使用指定颜色 color 为所有包含网格块 grid[row][col] 的 连通分量的边界 进行着色。

并返回最终的网格 grid 。

示例 1：

输入：grid = [[1,1],[1,2]], row = 0, col = 0, color = 3
输出：[[3,3],[3,2]]

示例 2：

输入：grid = [[1,2,2],[2,3,2]], row = 0, col = 1, color = 3
输出：[[1,3,3],[2,3,3]]

示例 3：

输入：grid = [[1,1,1],[1,1,1],[1,1,1]], row = 1, col = 1, color = 2
输出：[[2,2,2],[2,1,2],[2,2,2]]

提示：

  • m == grid.length
  • n == grid[i].length
  • 1 <= m, n <= 50
  • 1 <= grid[i][j], color <= 1000
  • 0 <= row < m
  • 0 <= col < n
