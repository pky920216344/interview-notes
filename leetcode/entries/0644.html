644. 子数组最大平均数 II

  • 困难
  • 频度 1
  • 二分查找
  • 前缀和/差分
  • 数组
  • 二分查找
  • 前缀和
  • 未经力扣验证

二分均值 mid：把前缀和减去 mid·下标，判定变成「存在 j−i ≥ k 使 b[j] ≥ b[i]」，b[x] = pre[x] − mid·x。

思路

  • 均值越大越难达成 → check 关于 mid 单调，可以二分；范围就是 [min, max]，收敛到 1e-6。
  • 判定转化：均值 ≥ mid ⟺ pre[j] − pre[i] ≥ mid·(j−i) ⟺ b[j] ≥ b[i]，其中 b[x] = pre[x] − mid·x。
  • 只需找 j − i ≥ k 且 b[j] − b[i] ≥ 0：从左往右扫，维护「i ≤ j−k 范围内的最小 b[i]」，b[0]=0 起步。
  • 精度：答案误差 ≤ 二分宽度 1e-6 < 题目要求 1e-5；浮点比较不需要额外容差。

最优解

时间复杂度 O(n log((max−min)/ε))，空间复杂度 O(n)
1class Solution {2    public double findMaxAverage(int[] nums, int k) {3        double lo = Integer.MAX_VALUE, hi = Integer.MIN_VALUE;4        for (int v : nums) { lo = Math.min(lo, v); hi = Math.max(hi, v); }5        // 答案是某个子段均值，必落在 [min, max]；直接二分「均值」本身6        while (hi - lo > 1e-6) {7            double mid = (lo + hi) / 2;8            if (check(nums, k, mid)) lo = mid;   // 存在均值 ≥ mid 的子段 → 答案还能更大9            else hi = mid;10        }11        return lo;12    }13 14    // 是否存在长度 ≥ k 的子段均值 ≥ mid：即存在 j − i ≥ k 使 pre[j] − pre[i] ≥ mid·(j−i)15    private boolean check(int[] nums, int k, double mid) {16        int n = nums.length;17        double[] b = new double[n + 1];   // b[j] = pre[j] − mid·j，均值比较变成纯减法18        for (int j = 0; j < n; j++) b[j + 1] = b[j] + nums[j] - mid;19        double minB = 0;   // i ≤ j−k 范围内见过的最小 b[i]，b[0] = 0 起步20        for (int j = k; j <= n; j++) {21            minB = Math.min(minB, b[j - k]);22            if (b[j] - minB >= 0) return true;   // 这段 [i, j) 均值 ≥ mid23        }24        return false;25    }26}
