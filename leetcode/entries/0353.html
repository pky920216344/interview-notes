353. 贪吃蛇

双端队列存蛇身（队头尾、队尾头）+ 哈希集合判占位；走一步：头入队，没吃到食物就先弹尾，再判撞墙撞身。

思路

  • 蛇身用双端队列：头进队尾、尾从队头出；占位集合让「这格有没有蛇」O(1) 可查。
  • 先判撞墙；没吃到食物就先把尾巴弹出——这样头走进原尾尖的格子不算撞（尾巴这一步正好挪走）。
  • 头的目标格还在占位集合里 → 撞身，游戏结束；吃到食物则尾巴不缩、score+1、食物指针后移。
  • 游戏结束后再调用 move 一律返回 -1。

最优解

时间复杂度 O(1) 每步，空间复杂度 O(蛇长 + 食物数)
1import java.util.*;2 3class SnakeGame {4    private final int width, height;5    private final int[][] food;6    private int foodIdx, score;7    private boolean dead;8    // 双端队列存蛇身格子：队头是尾、队尾是头；格子编码成 r * width + c9    private final Deque<Integer> body = new ArrayDeque<>();10    private final Set<Integer> occupied = new HashSet<>();11 12    public SnakeGame(int width, int height, int[][] food) {13        this.width = width;14        this.height = height;15        this.food = food;16        body.addLast(0);17        occupied.add(0);18    }19 20    public int move(String direction) {21        if (dead) return -1;22        int head = body.peekLast();23        int r = head / width, c = head % width;24        if (direction.equals("U")) r--;25        else if (direction.equals("D")) r++;26        else if (direction.equals("L")) c--;27        else c++;28        // 撞墙：游戏结束29        if (r < 0 || r >= height || c < 0 || c >= width) {30            dead = true;31            return -1;32        }33        int next = r * width + c;34        boolean eat = foodIdx < food.length && food[foodIdx][0] == r && food[foodIdx][1] == c;35        // 不吃就先把尾巴挪走：头才能进「原尾尖」的格子而不算撞身36        if (!eat) occupied.remove(body.pollFirst());37        if (occupied.contains(next)) {38            dead = true;39            return -1;40        }41        body.addLast(next);42        occupied.add(next);43        if (eat) {44            foodIdx++;45            score++;46        }47        return score;48    }49}
