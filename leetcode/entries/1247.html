1247. 交换字符使得字符串相同

  • 中等
  • 频度 1
  • 数学
  • 贪心
  • 数学
  • 字符串

只看两串不同的位置，分 xy、yx 两型计数：同型两两配对一次换一双，各剩一个跨换两次。

思路

  • 相同的位置永远不用动；不同的位置只有两类：xy 型（s1=x,s2=y）和 yx 型。
  • 两个 xy 型一次交换就都归位（yx 同理），共 x/2 + y/2 次。
  • x、y 同为奇数时各剩一个，只能跨着换 2 次，答案加 (x%2)*2。
  • x、y 奇偶不同则总数对不齐，返回 -1。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int minimumSwap(String s1, String s2) {3        // 相同的位置不用管；不同的位置只有 xy 型（s1=x,s2=y）和 yx 型4        int x = 0, y = 0;5        for (int i = 0; i < s1.length(); i++) {6            if (s1.charAt(i) == s2.charAt(i)) continue;7            if (s1.charAt(i) == 'x') x++; else y++;8        }9        // 两种型的个数奇偶必须一致，否则 x、y 总数对不齐，无解10        if ((x & 1) != (y & 1)) return -1;11        // 同型两个一次交换互相成全；各剩一个要跨着换两次12        return x / 2 + y / 2 + (x & 1) * 2;13    }14}
题目

有两个长度相同的字符串 s1 和 s2，且它们其中 只含有 字符 "x" 和 "y"，你需要通过「交换字符」的方式使这两个字符串相同。

每次「交换字符」的时候，你都可以在两个字符串中各选一个字符进行交换。

交换只能发生在两个不同的字符串之间，绝对不能发生在同一个字符串内部。也就是说，我们可以交换 s1[i] 和 s2[j]，但不能交换 s1[i] 和 s1[j]。

最后，请你返回使 s1 和 s2 相同的最小交换次数，如果没有方法能够使得这两个字符串相同，则返回 -1 。

示例 1：

输入：s1 = "xx", s2 = "yy"
输出：1
解释：
交换 s1[0] 和 s2[1]，得到 s1 = "yx"，s2 = "yx"。

示例 2：

输入：s1 = "xy", s2 = "yx"
输出：2
解释：
交换 s1[0] 和 s2[0]，得到 s1 = "yy"，s2 = "xx" 。
交换 s1[0] 和 s2[1]，得到 s1 = "xy"，s2 = "xy" 。
注意，你不能交换 s1[0] 和 s1[1] 使得 s1 变成 "yx"，因为我们只能交换属于两个不同字符串的字符。

示例 3：

输入：s1 = "xx", s2 = "xy"
输出：-1

提示：

  • 1 <= s1.length, s2.length <= 1000
  • s1.length == s2.length
  • s1, s2 只包含 'x' 或 'y'。
