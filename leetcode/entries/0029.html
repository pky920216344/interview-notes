29. 两数相除

  • 中等
  • 频度 13
  • 位运算
  • 位运算
  • 数学
  • 待提交

全部转成负数后用倍增减：每次减掉「除数的 2^k 倍」，商一次加 2^k；不能用乘除取余。

思路

  • 特判：MIN / -1 = +2^31 会溢出，直接返回 MAX_VALUE；除数是 ±1 时商就是被除数本身（或取反），提前返回，防止后面 cnt 翻到 2^31。
  • 统一转负：负数域比正数域多 1，取 abs 反而会溢出；符号用异或记下来，最后再翻回去。
  • 倍增：tmp 从除数开始不停翻倍（cnt 同步翻），翻到再翻一次就大过被除数为止；减掉这一大块，商加 cnt。用 tmp >= dividend - tmp 做减法比较，避免 tmp + tmp 溢出。
  • 商向零截断 = 对绝对值向下取整，天然成立。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int divide(int dividend, int divisor) {3        // 唯一会溢出的商：-2^31 / -1 = +2^31，按题意返回 int 最大值4        if (dividend == Integer.MIN_VALUE && divisor == -1) return Integer.MAX_VALUE;5        // 除数为 ±1：商就是被除数（取反），提前返回防溢出6        if (divisor == 1) return dividend;7        if (divisor == -1) return -dividend;8        // 统一转成负数再算：负数域比正数域大 1，取 abs 反而会溢出9        boolean neg = (dividend < 0) != (divisor < 0);10        if (dividend > 0) dividend = -dividend;11        if (divisor > 0) divisor = -divisor;12        int ans = 0;13        // 倍增：一次减掉「除数的 2^k 倍」，商一次加上 2^k14        while (dividend <= divisor) {15            int tmp = divisor, cnt = 1;16            // 减法比较防溢出：等价于「翻倍后仍不超过被除数」17            while (tmp >= dividend - tmp) {18                tmp += tmp;19                cnt += cnt;20            }21            dividend -= tmp;22            ans += cnt;23        }24        return neg ? -ans : ans;25    }26}
题目

给你两个整数，被除数 dividend 和除数 divisor。将两数相除，要求 不使用 乘法、除法和取余运算。

整数除法应该向零截断，也就是截去（truncate）其小数部分。例如，8.345 将被截断为 8 ，-2.7335 将被截断至 -2 。

返回被除数 dividend 除以除数 divisor 得到的 商 。

注意：假设我们的环境只能存储 32 位 有符号整数，其数值范围是 [−231,  231 − 1] 。本题中，如果商 严格大于 231 − 1 ，则返回 231 − 1 ；如果商 严格小于 -231 ，则返回 -231 。

示例 1:

输入: dividend = 10, divisor = 3
输出: 3
解释: 10/3 = 3.33333.. ，向零截断后得到 3 。

示例 2:

输入: dividend = 7, divisor = -3
输出: -2
解释: 7/-3 = -2.33333.. ，向零截断后得到 -2 。

提示：

  • -231 <= dividend, divisor <= 231 - 1
  • divisor != 0
