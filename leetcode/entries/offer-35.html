剑指 Offer 35. 复杂链表的复制

  • 哈希表
  • 链表

原地三步复制：每个原结点后面插副本串成交错链；副本的 random 指向「原 random 的下一个」；再拆出副本链。

思路

  • 插副本：遍历原链，copy 接在 p 后面（copy.next = p.next; p.next = copy），链长变 2n。
  • 接 random：原结点 p 的 random 的下一个正好是它的副本，所以 p.next.random = p.random.next；random 为空就留着空。
  • 拆链：用尾指针把所有副本串成新链，同时 p.next = copy.next 恢复原链；返回 dummy.next。
  • 不用哈希表：靠「副本就贴在原结点后面」这个位置关系，把 random 的映射变成 next 跳一步。

题目

请实现 copyRandomList 函数，复制一个复杂链表。在复杂链表中，每个节点除了有一个 next 指针指向下一个节点，还有一个 random 指针指向链表中的任意节点或者 null。

示例 1：

输入：head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]

示例 2：

输入：head = [[1,1],[2,1]]
输出：[[1,1],[2,1]]

示例 3：

输入：head = [[3,null],[3,0],[3,null]]
输出：[[3,null],[3,0],[3,null]]

示例 4：

输入：head = []
输出：[]
解释：给定的链表为空（空指针），因此返回 null。

提示：

  • -10000 <= Node.val <= 10000
  • Node.random 为空（null）或指向链表中的节点。
  • 节点数目不超过 1000 。
