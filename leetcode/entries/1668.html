1668. 最大重复子字符串

从 sequence 的每个起点数 word 能连续重复几次（对上一份就跳 m 格接着比），答案取最大连击。

思路

  • word^k 是子串 ⟺ 该起点处 word 连续出现 k 次，所以枚举起点逐个数连击就够。
  • 每对上一份就把位置右移 m = word.length 格再比，startsWith(word, i + k*m) 一行完成比对。
  • 先用 i + (k+1)*m <= n 保证下一份不越界，再比对；连击断掉就换下一个起点。

图解

最优解

时间复杂度 O(n²)，空间复杂度 O(1)
1class Solution {2    public int maxRepeating(String sequence, String word) {3        int m = word.length(), n = sequence.length(), ans = 0;4        // 枚举每个起点：word^k 能匹配，起点一定是 word 的一次出现5        for (int i = 0; i + m <= n; i++) {6            int k = 0;7            // 每匹配上一份 word 就往后跳 m 格接着数8            while (i + (k + 1) * m <= n && sequence.startsWith(word, i + k * m)) k++;9            ans = Math.max(ans, k);10        }11        return ans;12    }13}
题目

给你一个字符串 sequence ，如果字符串 word 连续重复 k 次形成的字符串是 sequence 的一个子字符串，那么单词 word 的 重复值为 k。单词 word 的 最大重复值 是单词 word 在 sequence 中最大的重复值。如果 word 不是 sequence 的子串，那么重复值 k 为 0 。

给你一个字符串 sequence 和 word ，请你返回 最大重复值 k 。

示例 1：

输入：sequence = "ababc", word = "ab"
输出：2
解释："abab" 是 "ababc" 的子字符串。

示例 2：

输入：sequence = "ababc", word = "ba"
输出：1
解释："ba" 是 "ababc" 的子字符串，但 "baba" 不是 "ababc" 的子字符串。

示例 3：

输入：sequence = "ababc", word = "ac"
输出：0
解释："ac" 不是 "ababc" 的子字符串。

提示：

  • 1 <= sequence.length <= 100
  • 1 <= word.length <= 100
  • sequence 和 word 都只包含小写英文字母。
