BFS 逐层处理（队列每轮恰好装着一层），先按从上往下的顺序收集，最后整体反转一次。

思路

  • 和普通层序遍历一样：根入队；每轮先记 size = queue.size()（此刻队列恰好是这一层），弹 size 个、孩子排到队尾。
  • 每层列表照常 ans.add(level)（从上往下）；结束时 Collections.reverse(ans) 一次性反转，最底层就排到了最前。
  • 根为空直接返回空列表。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public List<List<Integer>> levelOrderBottom(TreeNode root) {5        if (root == null) return new ArrayList<>();6        List<List<Integer>> ans = new ArrayList<>();7        Queue<TreeNode> queue = new ArrayDeque<>();8        queue.add(root);9        while (!queue.isEmpty()) {10            // 此刻队列里恰好是同一层的全部结点11            int size = queue.size();12            List<Integer> level = new ArrayList<>();13            for (int i = 0; i < size; i++) {14                TreeNode node = queue.poll();15                level.add(node.val);16                // 孩子排到队尾，属于下一层17                if (node.left != null) queue.add(node.left);18                if (node.right != null) queue.add(node.right);19            }20            ans.add(level);   // 照常从上往下收集21        }22        Collections.reverse(ans);   // 整体反转：最底层排到最前23        return ans;24    }25}
题目

给你二叉树的根节点 root ，返回其节点值 自底向上的层序遍历 。 （即按从叶子节点所在层到根节点所在的层，逐层从左向右遍历）

示例 1：

输入：root = [3,9,20,null,null,15,7]
输出：[[15,7],[9,20],[3]]

示例 2：

输入：root = [1]
输出：[[1]]

示例 3：

输入：root = []
输出：[]

提示：

  • 树中节点数目在范围 [0, 2000] 内
  • -1000 <= Node.val <= 1000
