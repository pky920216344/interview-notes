剑指 Offer 45. 破解闯关密码

  • 中等
  • 频度 20
  • 贪心
  • 贪心
  • 字符串
  • 排序
  • 力扣已通过

把每个数当字符串，按「x+y 与 y+x 谁小」升序排序，再顺序拼接。

思路

  • 排序规则：比较 x+y 和 y+x 两个拼接串，小的排前面。比如 3 和 30：303 < 330，所以 30 排在 3 前面。
  • 该比较是全序（可传递），交换论证可证按它排好后整体拼接最小。
  • 全是 0 时按本题说明保留前导 0（如 00），不用去掉。
  • 结果要用 String 返回，可能非常长。

题目

闯关游戏需要破解一组密码，闯关组给出的有关密码的线索是：

  • 一个拥有密码所有元素的非负整数数组 password
  • 密码是 password 中所有元素拼接后得到的最小的一个数

请编写一个程序返回这个密码。

示例 1：

输入：password = [15, 8, 7]
输出："1578"

示例 2：

输入：password = [0, 3, 30, 34, 5, 9]
输出："03033459"

提示：

  • 0 < password.length <= 100

说明:

  • 输出结果可能非常大，所以你需要返回一个字符串而不是整数
  • 拼接起来的数字可能会有前导 0，最后结果不需要去掉前导 0
