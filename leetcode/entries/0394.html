双栈：遇 '[' 把重复次数和外层串压栈并清空 cur；遇 ']' 弹出，拼成「弹的串 + cur 重复 k 次」。

思路

  • cur 是「正在收集的当前层串」，num 边读边 num*10+d（数字可能多位）。
  • 遇 [：num、cur 分别压数字栈、字符串栈，再清空，专心收括号里的内容。
  • 遇 ]：弹出上层的串 prev 和次数 k，prev 接上 k 份 cur，结果作为新的 cur。
  • 普通字母直接 cur.append(c)；扫完 cur 就是答案，嵌套靠栈自动处理。

时间复杂度 O(输出长度)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public String decodeString(String s) {5        // 数字栈存重复次数，字符串栈存 '[' 外面的串6        Deque<Integer> numStack = new ArrayDeque<>();7        Deque<StringBuilder> strStack = new ArrayDeque<>();8        StringBuilder cur = new StringBuilder();9        int num = 0;10        for (int i = 0; i < s.length(); i++) {11            char c = s.charAt(i);12            if (c >= '0' && c <= '9') {13                num = num * 10 + (c - '0');   // 数字可能不止一位14            } else if (c == '[') {15                // 压下「次数」和「外面的串」，cur 清空专收括号里的16                numStack.push(num);17                strStack.push(cur);18                num = 0;19                cur = new StringBuilder();20            } else if (c == ']') {21                // 弹出，拼成「弹的串 + 当前串重复 k 次」22                StringBuilder prev = strStack.pop();23                int k = numStack.pop();24                while (k-- > 0) prev.append(cur);25                cur = prev;26            } else {27                cur.append(c);                // 普通字母直接接在 cur 后面28            }29        }30        return cur.toString();31    }32}
题目

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: k[encoded_string]，表示其中方括号内部的 encoded_string 正好重复 k 次。注意 k 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 k ，例如不会出现像 3a 或 2[4] 的输入。

测试用例保证输出的长度不会超过 105。

示例 1：

输入：s = "3[a]2[bc]"
输出："aaabcbc"

示例 2：

输入：s = "3[a2[c]]"
输出："accaccacc"

示例 3：

输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"

示例 4：

输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"

提示：

  • 1 <= s.length <= 30
  • s 由小写英文字母、数字和方括号 '[]' 组成
  • s 保证是一个 有效 的输入。
  • s 中所有整数的取值范围为 [1, 300]
