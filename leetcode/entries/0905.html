905. 按奇偶排序数组

  • 数组
  • 双指针
  • 排序

首尾双指针原地分区：左找奇数、右找偶数，交换后两边各进一格；与剑指 Offer 21 同一套路。

思路

  • 只要求「偶数在前、奇数在后」不要求稳定，所以交换分区即可，一遍扫完。
  • nums[l] 是偶数 → l++；nums[r] 是奇数 → r--；左奇右偶才交换。
  • 循环条件 l < r：两指针相遇时分区完成，[0, l) 全偶、(r, n-1] 全奇。
  • 相同思路的题：剑指 Offer 21（奇数在前）。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] sortArrayByParity(int[] nums) {3        // 左指针找偶数该待的位置，右指针找奇数；相对顺序不要求4        int l = 0, r = nums.length - 1;5        while (l < r) {6            if (nums[l] % 2 == 0) l++;           // 左边已是偶数，不用管7            else if (nums[r] % 2 == 1) r--;      // 右边已是奇数，不用管8            else {                               // 左奇右偶：交换，两边同时收窄9                int t = nums[l];10                nums[l] = nums[r];11                nums[r] = t;12                l++;13                r--;14            }15        }16        return nums;17    }18}
题目

给你一个整数数组 nums，将 nums 中的的所有偶数元素移动到数组的前面，后跟所有奇数元素。

返回满足此条件的 任一数组 作为答案。

示例 1：

输入：nums = [3,1,2,4]
输出：[2,4,3,1]
解释：[4,2,3,1]、[2,4,1,3] 和 [4,2,1,3] 也会被视作正确答案。

示例 2：

输入：nums = [0]
输出：[0]

提示：

  • 1 <= nums.length <= 5000
  • 0 <= nums[i] <= 5000
