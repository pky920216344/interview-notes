DFS 先右后左并带上深度：每层第一个到达的结点就是该层最右边的，直接记进答案。

思路

  • dfs(node, depth) 先走右孩子、再走左孩子，这样每层第一个到达的结点，一定是这层最右边的。
  • ans.size() 是「已经记过的层数」：depth == ans.size() 说明这层还没人记，就加入 ans；否则直接跳过。
  • 右子树比左子树浅时，左边更深的结点没人挡着，也会被记下，不用特殊处理。

1import java.util.*;2 3class Solution {4    public List<Integer> rightSideView(TreeNode root) {5        List<Integer> ans = new ArrayList<>();6        dfs(root, 0, ans);7        return ans;8    }9 10    // 先右后左：每层第一个到达的，就是这层最右边的11    private void dfs(TreeNode node, int depth, List<Integer> ans) {12        if (node == null) return;13        // ans.size() 是已记过的层数；相等说明这层还没记14        if (depth == ans.size()) ans.add(node.val);15        dfs(node.right, depth + 1, ans);16        dfs(node.left, depth + 1, ans);17    }18}
