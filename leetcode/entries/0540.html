540. 有序数组中的单一元素

  • 中等
  • 频度 15
  • 二分查找
  • 数组
  • 二分查找
  • 待提交

二分：把 mid 退到偶数位看 (mid, mid+1) 是否成对——成对说明单一元素在右半，断了就在 mid 及其左。

思路

  • 单一元素把数组分两段：左边配对从偶数位开始 (0,1)(2,3)…，右边错位成 (奇, 偶)——用这个二分。
  • 先把 mid 退到偶数下标（mid 为奇数就 -1），统一比较 nums[mid] == nums[mid^1]（mid^1：偶数 +1、奇数 -1）。
  • 相等 → (mid, mid+1) 是完整对，答案在 mid+2 之后：lo = mid + 2；不等 → 答案 ≤ mid：hi = mid。
  • lo == hi 时就是答案；单一元素是唯一让「偶数位配对」断掉的位置。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int singleNonDuplicate(int[] nums) {3        // 单一元素左侧：偶数位与右邻成对；右侧：配对错位成（奇数, 偶数）4        int lo = 0, hi = nums.length - 1;5        while (lo < hi) {6            int mid = (lo + hi) >>> 1;7            if (mid % 2 == 1) mid--;      // 把 mid 退到偶数下标，统一成「看 (mid, mid+1)」8            if (nums[mid] == nums[mid ^ 1]) {9                lo = mid + 2;             // 这对完整：单一元素在右半10            } else {11                hi = mid;                 // 这对断了：单一元素在 mid 及其左边12            }13        }14        return nums[lo];15    }16}
题目

给你一个仅由整数组成的有序数组，其中每个元素都会出现两次，唯有一个数只会出现一次。

请你找出并返回只出现一次的那个数。

你设计的解决方案必须满足 O(log n) 时间复杂度和 O(1) 空间复杂度。

示例 1:

输入: nums = [1,1,2,3,3,4,4,8,8]
输出: 2

示例 2:

输入: nums =  [3,3,7,7,10,11,11]
输出: 10

提示:

  • 1 <= nums.length <= 105
  • 0 <= nums[i] <= 105
