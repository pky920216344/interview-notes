222. 完全二叉树的节点个数

  • 频度 18

  • 数学

  • 树
  • 二分查找

  • 力扣已通过

完全树只比高：左右子树沿最左链量高，同高则左子树是满树（2^lh 个含根），只递归另一边，O(log²n)。

思路

  • 普通遍历是 O(n)；完全树的妙处：比一下左、右子树的高（各沿最左链数层数）就能判断哪边是满树。
  • lh == rh：右子树的最左链也够到了最底层，说明最底层已铺满左子树 → 左子树是满树，2^lh - 1 个加根正好 2^lh 个，只需递归右子树。
  • lh != rh：右边够不到底 → 右子树是满树，2^rh 个（含根），只需递归左子树。
  • 每层只递归一边、每次量高 O(log n)，总共 O(log²n)；1 << h 就是 2^h。

图解

最优解

时间复杂度 O(log²n)，空间复杂度 O(log n)（递归栈）
1class Solution {2    public int countNodes(TreeNode root) {3        if (root == null) return 0;4        // 高 = 沿最左链数的层数：左、右子树各量一次，只差 O(log n)5        int lh = height(root.left), rh = height(root.right);6        if (lh == rh) {7            // 两边同高：左子树是满树，2^lh - 1 个加根正好 2^lh，右子树递归8            return (1 << lh) + countNodes(root.right);9        }10        // 左比右高：右子树是满树，2^rh - 1 个加根正好 2^rh，左子树递归11        return (1 << rh) + countNodes(root.left);12    }13 14    // 沿最左链一路数到底，数出的层数就是子树的高15    private int height(TreeNode p) {16        int h = 0;17        for (; p != null; p = p.left) h++;18        return h;19    }20}
题目

给你一棵 完全二叉树 的根节点 root ，求出该树的节点个数。

完全二叉树 的定义如下：在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 h 层（从第 0 层开始），则该层包含 1~ 2h 个节点。

示例 1：

输入：root = [1,2,3,4,5,6]
输出：6

示例 2：

输入：root = []
输出：0

示例 3：

输入：root = [1]
输出：1

提示：

  • 树中节点的数目范围是[0, 5 * 104]
  • 0 <= Node.val <= 5 * 104
  • 题目数据保证输入的树是 完全二叉树

进阶：遍历树来统计节点是一种时间复杂度为 O(n) 的简单解决方案。你可以设计一个更快的算法吗？
