301. 删除无效的括号

BFS 逐层删一个括号：HashSet 去重，哪一层先出现合法串就全收下并停，删除数最少。

思路

  • 把「删 0 个、删 1 个、删 2 个……」的串按层铺开（每层只比上一层多删一个括号，字母永远不动）：第一层出现合法串时，删除数就是最小值，本层全部合法串都是答案。
  • valid 用括号计数：任何前缀里 ) 不得多于 (，扫完要配平；字母不影响计数。
  • HashSet 去重是关键：删不同位置常得到同一个串，不去重会指数爆炸；碰到合法只停在本层，本层扫完即止。

1import java.util.*;2 3class Solution {4    public List<String> removeInvalidParentheses(String s) {5        List<String> ans = new ArrayList<>();6        // seen：出现过的串记下来，同一串不再重复展开7        Set<String> seen = new HashSet<>();8        Queue<String> queue = new ArrayDeque<>();9        seen.add(s);10        queue.add(s);11        boolean found = false;12        while (!queue.isEmpty()) {13            int size = queue.size();14            while (size-- > 0) {15                String cur = queue.poll();16                if (valid(cur)) { ans.add(cur); found = true; continue; }17                // 本层已找到答案：再删只会更多，不再往下展开18                if (found) continue;19                for (int k = 0; k < cur.length(); k++) {20                    if (cur.charAt(k) != '(' && cur.charAt(k) != ')') continue;   // 字母永远保留21                    String next = cur.substring(0, k) + cur.substring(k + 1);22                    if (seen.add(next)) queue.add(next);23                }24            }25            // 本层处理完就停：先碰到合法串的这一层就是最少删除数26            if (found) break;27        }28        return ans;29    }30 31    // 括号计数：任何前缀里 ) 不能多于 (，扫完要正好配平32    private boolean valid(String t) {33        int bal = 0;34        for (int i = 0; i < t.length(); i++) {35            char c = t.charAt(i);36            if (c == '(') bal++;37            else if (c == ')' && --bal < 0) return false;38        }39        return bal == 0;40    }41}
题目

给你一个由若干括号和字母组成的字符串 s ，删除最小数量的无效括号，使得输入的字符串有效。

返回所有可能的结果。答案可以按 任意顺序 返回。

示例 1：

输入：s = "()())()"
输出：["(())()","()()()"]

示例 2：

输入：s = "(a)())()"
输出：["(a())()","(a)()()"]

示例 3：

输入：s = ")("
输出：[""]

提示：

  • 1 <= s.length <= 25
  • s 由小写英文字母以及括号 '(' 和 ')' 组成
  • s 中至多含 20 个括号
