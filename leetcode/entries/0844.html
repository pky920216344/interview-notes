逆序双指针：从右往左给每个退格记一笔账，跳过被删字符后逐位比较两边保留的字符。

思路

  • 退格删的是左边的字符，从右往左看才知道每个字符删没删，不用真的重建。
  • skip：向左遇 # 欠账 +1；遇普通字符先抵账，账清了才停在这里。
  • 每轮两边各自 skip 后比较当前字符，不同立即 false。
  • 只有一边还有剩余（skip 后仍 ≥ 0）也是 false；两边同时走完才 true。

时间复杂度 O(m+n)，空间复杂度 O(1)
1class Solution {2    public boolean backspaceCompare(String s, String t) {3        int i = s.length() - 1, j = t.length() - 1;4        // 从右往左：各自跳过被退格删掉的字符，再比较剩下的5        while (i >= 0 || j >= 0) {6            i = skip(s, i);7            j = skip(t, j);8            // 两边同时走完才算相等；只有一边还有剩余就是不等9            if (i >= 0 && j >= 0) {10                if (s.charAt(i) != t.charAt(j)) return false;11            } else if (i >= 0 || j >= 0) {12                return false;13            }14            i--;15            j--;16        }17        return true;18    }19 20    // 返回从 i 往左第一个没被退格删掉的字符下标；没有则 -121    private int skip(String s, int i) {22        int back = 0;23        while (i >= 0) {24            if (s.charAt(i) == '#') back++;25            else if (back > 0) back--;26            else break;27            i--;28        }29        return i;30    }31}
题目

给定 s 和 t 两个字符串，当它们分别被输入到空白的文本编辑器后，如果两者相等，返回 true 。# 代表退格字符。

注意：如果对空文本输入退格字符，文本继续为空。

示例 1：

输入：s = "ab#c", t = "ad#c"
输出：true
解释：s 和 t 都会变成 "ac"。

示例 2：

输入：s = "ab##", t = "c#d#"
输出：true
解释：s 和 t 都会变成 ""。

示例 3：

输入：s = "a#c", t = "b"
输出：false
解释：s 会变成 "c"，但 t 仍然是 "b"。

提示：

  • 1 <= s.length, t.length <= 200
  • s 和 t 只含有小写字母以及字符 '#'
