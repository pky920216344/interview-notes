306. 累加数

  • 中等
  • 频度 15
  • 模拟
  • 字符串
  • 回溯
  • 待提交

回溯枚举前两个数：第一刀 i、第二刀 j 定下 a、b，后面每段用字符串加法逐一验证，对不上就换切法。

思路

  • 累加序列由前两个数完全决定：枚举 a = num[0,i)、b = num[i,j)（i < n-1 保证还有第 3 个数），之后只能逐段验证。
  • 验证：sum = a+b 必须与下一段逐字符相等；对上就 a←b、b←sum 滚动前进，直到串尾。
  • 前导 0 规则：只有 "0" 本身可以以 0 开头，长度 > 1 的段首字符不能是 '0'。
  • 数字可达 19 位以上，long 会溢出，用字符串加法（从个位往高位加）最稳。

最优解

时间复杂度 O(n³)（n ≤ 35，很小），空间复杂度 O(n)
1class Solution {2    public boolean isAdditiveNumber(String num) {3        int n = num.length();4        // 枚举第一个数的结尾 i 和第二个数的结尾 j，后面只能被验证5        for (int i = 1; i < n - 1; i++) {6            for (int j = i + 1; j < n; j++) {7                if (check(num, i, j)) return true;8            }9        }10        return false;   // 试遍所有切法都不是11    }12 13    // 前两个数是 num[0,i) 和 num[i,j)，验证后面是否一路累加到结尾14    private boolean check(String num, int i, int j) {15        String a = num.substring(0, i), b = num.substring(i, j);16        // 除 0 以外不能以 0 开头17        if ((a.length() > 1 && a.charAt(0) == '0') || (b.length() > 1 && b.charAt(0) == '0')) return false;18        while (j < num.length()) {19            String sum = add(a, b);20            // 下一段必须严格等于 sum（长度都对不上就直接失败）21            if (j + sum.length() > num.length() || !num.startsWith(sum, j)) {22                return false;23            }24            j += sum.length();25            a = b;26            b = sum;27        }28        return true;29    }30 31    // 字符串加法：从个位往高位加，数字再大也不怕32    private String add(String a, String b) {33        StringBuilder sb = new StringBuilder();34        int i = a.length() - 1, j = b.length() - 1, carry = 0;35        while (i >= 0 || j >= 0 || carry > 0) {36            int s = carry + (i >= 0 ? a.charAt(i--) - '0' : 0) + (j >= 0 ? b.charAt(j--) - '0' : 0);37            sb.append((char) ('0' + s % 10));38            carry = s / 10;39        }40        return sb.reverse().toString();41    }42}
题目

累加数 是一个字符串，组成它的数字可以形成累加序列。

一个有效的 累加序列 必须 至少 包含 3 个数。除了最开始的两个数以外，序列中的每个后续数字必须是它之前两个数字之和。

给你一个只包含数字 '0'-'9' 的字符串，编写一个算法来判断给定输入是否是 累加数 。如果是，返回 true ；否则，返回 false 。

说明：累加序列里的数，除数字 0 之外，不会 以 0 开头，所以不会出现 1, 2, 03 或者 1, 02, 3 的情况。

示例 1：

输入："112358"
输出：true 
解释：累加序列为: 1, 1, 2, 3, 5, 8 。1 + 1 = 2, 1 + 2 = 3, 2 + 3 = 5, 3 + 5 = 8

示例 2：

输入："199100199"
输出：true 
解释：累加序列为: 1, 99, 100, 199。1 + 99 = 100, 99 + 100 = 199

提示：

  • 1 <= num.length <= 35
  • num 仅由数字（0 - 9）组成
