剑指 Offer 03. 寻找文件副本

  • 简单
  • 频度 21
  • 哈希表
  • 数组
  • 哈希表
  • 排序
  • 力扣已通过

原地交换归位：值 v 应该待在下标 v；把 v 换回家，发现家里已经是 v 就是重复，O(n) 不用额外空间。

思路

  • 值域恰好是 0 ~ n-1，值和下标一一对应：每个换过去的 v 都永久归位，总共最多换 n 次，均摊 O(n)。
  • documents[i] != i 时：设 v = documents[i]；若 documents[v] == v，v 同时出现在两处，直接返回 v。
  • 否则交换 documents[i] 和 documents[v]，把 v 送回家，循环继续直到 i 处装着 i。
  • 会修改输入数组（原地解法）；题面只要求返回任一副本，不限制修改。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int findRepeatDocument(int[] documents) {3        // 值都在 0 ~ n-1：把值 v 归位到下标 v，家里已经有 v 的就是副本4        for (int i = 0; i < documents.length; i++) {5            while (documents[i] != i) {6                int v = documents[i];7                if (documents[v] == v) return v;   // v 的位置已经是 v：v 就是副本8                documents[i] = documents[v];       // v 家里的旧值换到 i 来9                documents[v] = v;                  // v 回家10            }11        }12        return -1;   // 题面保证有副本，走不到这里13    }14}
题目

设备中存有 n 个文件，文件 id 记于数组 documents。若文件 id 相同，则定义为该文件存在副本。请返回任一存在副本的文件 id。

示例 1：

输入：documents = [2, 5, 3, 0, 5, 0]
输出：0 或 5

提示：

  • 0 ≤ documents[i] ≤ n-1
  • 2 <= n <= 100000
