升序数组里缺席一个学号，二分找第一个 records[i] > i 的下标；找不到就说明缺的是 n。

思路

  • 正常点名里 records[i] == i；缺席点之后整体前移，records[i] > i。第一个错位处的下标就是缺席学号。
  • 二分：records[mid] == mid 说明前半完整，lo = mid + 1；否则错位已发生，hi = mid - 1。
  • 循环结束时 lo 停在第一个错位处；一路相等时 lo 走到 n，即缺的是最后一个学号。

图解

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int takeAttendance(int[] records) {3        // 升序且只缺一个学号：第一个 records[i] > i 的下标 i 就是缺席者4        int lo = 0, hi = records.length - 1;5        while (lo <= hi) {6            int mid = (lo + hi) >>> 1;7            if (records[mid] == mid) lo = mid + 1;   // 前半完整，缺席在右半8            else hi = mid - 1;                       // 这里已错位，缺席在左半（含 mid）9        }10        return lo;11    }12}
题目

某班级 n 位同学的学号为 0 ~ n-1。点名结果记录于升序数组 records。假定仅有一位同学缺席，请返回他的学号。

示例 1：

输入：records = [0,1,2,3,5]
输出：4

示例 2：

输入：records = [0, 1, 2, 3, 4, 5, 6, 8]
输出：7

提示：

1 <= records.length <= 10000
