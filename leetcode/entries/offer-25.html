剑指 Offer 25. 训练计划 IV

  • 双指针
  • 递归
  • 链表
  • 待提交

迭代 + 哨兵：dummy 后面长出结果链，每次比较两链表头，小的接上并后移；一边空了把另一边整段接上。

思路

  • dummy 哨兵免去「结果头结点」的特判，tail 始终指向结果链的最后一个结点。
  • 循环里谁的值小谁接到 tail.next，对应指针后移，tail 跟进一位。
  • 一边为空就退出循环，tail.next 接上没走完的那一段——它本身有序，不用再比较。

最优解

时间复杂度 O(m + n)，空间复杂度 O(1)
1class Solution {2    public ListNode trainningPlan(ListNode l1, ListNode l2) {3        // 哨兵结点当结果链的起点，免得单独处理头结点4        ListNode dummy = new ListNode(), tail = dummy;5        while (l1 != null && l2 != null) {6            // 谁的值小谁接到 tail 后面，对应指针后移一位7            if (l1.val <= l2.val) {8                tail.next = l1;9                l1 = l1.next;10            } else {11                tail.next = l2;12                l2 = l2.next;13            }14            tail = tail.next;15        }16        // 一边走空了，另一边剩下的整段直接接上（本身有序）17        tail.next = l1 != null ? l1 : l2;18        return dummy.next;19    }20}
题目

给定两个以 有序链表 形式记录的训练计划 l1、l2，分别记录了两套核心肌群训练项目编号，请合并这两个训练计划，按训练项目编号 升序 记录于链表并返回。

注意：新链表是通过拼接给定的两个链表的所有节点组成的。

示例 1：

输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]

示例 2：

输入：l1 = [], l2 = []
输出：[]

示例 3：

输入：l1 = [], l2 = [0]
输出：[0]

提示：

0 <= 链表长度 <= 1000
