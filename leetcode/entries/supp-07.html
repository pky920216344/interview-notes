补充题7. 木头切割问题

  • 中等
  • 频度 7
  • 动态规划
  • 未经力扣验证

完全背包：dp[j] = 长 j 的木条最高卖价；枚举第一段长 l，price[l−1] + dp[j−l] 取最大。

思路

  • 「可以重复切同一种长度」就是完全背包：物品是段（重 = 长，价 = 售价），背包容量是 n。
  • dp[j] 从小到大递推；每步枚举第一段长 l：dp[j] = max(price[l−1] + dp[j−l])。
  • l = j 就是「整根不切」，所以不用单独处理整根的情况。
  • 只求最优值；若要还原切法，另记每步选的 l 往回走。

1/*2 * codetop 补充题7 木头切割问题（力扣无对应页面，不提交）：3 * 一根长度为 n 的木条，price[i] 是长度为 i+1 的木段的售价（0 ≤ i < price.length）；4 * 把木条切成若干段卖出，求最大总收益，也可以整根不切。5 * 每种长度可以切出多段（完全背包：物品是「一段木头」，重量是长度，价值是售价）。6 */7class Solution {8    public int maxRevenue(int n, int[] price) {9        // dp[j]：长 j 的木条能卖的最高价10        int[] dp = new int[n + 1];11        for (int j = 1; j <= n; j++)12            // 枚举切下的第一段长 l：卖 price[l-1]，剩下 j−l 按最优方案切13            for (int l = 1; l <= j; l++)14                dp[j] = Math.max(dp[j], price[l - 1] + dp[j - l]);15        return dp[n];16    }17}
