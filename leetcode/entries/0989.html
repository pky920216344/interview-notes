989. 数组形式的整数加法

  • 简单
  • 频度 2
  • 模拟
  • 数组
  • 数学
  • 待提交

把 k 整个当「进位」从末位逐位加：本位 = (数位 + k) % 10，k 再 /10 带走高位；num 用完 k 还有剩就继续写。

思路

  • 不把 num 转成数（会溢出），而是把 k 当作流动的进位：k += num[i] 后 k % 10 就是本位。
  • k /= 10 自然把进位留在 k 里；num 扫完后 k > 0 就继续循环，把剩余位逐个 ans.add(k % 10)。
  • 结果是低位在前，最后 Collections.reverse 翻转回来。

最优解

时间复杂度 O(max(n, log k))，空间复杂度 O(1)（不计返回数组）
1import java.util.*;2 3class Solution {4    public List<Integer> addToArrayForm(int[] num, int k) {5        List<Integer> ans = new ArrayList<>();6        // 从末位起逐位加 k：k 暂存「剩余要加的数 + 进位」，本位 = k % 107        for (int i = num.length - 1; i >= 0 || k > 0; i--) {8            if (i >= 0) k += num[i];9            ans.add(k % 10);10            k /= 10;11        }12        Collections.reverse(ans);   // 低位到高位加的，最后翻转回来13        return ans;14    }15}
题目

整数的 数组形式  num 是按照从左到右的顺序表示其数字的数组。

  • 例如，对于 num = 1321 ，数组形式是 [1,3,2,1] 。

给定 num ，整数的 数组形式 ，和整数 k ，返回 整数 num + k 的 数组形式 。

示例 1：

输入：num = [1,2,0,0], k = 34
输出：[1,2,3,4]
解释：1200 + 34 = 1234

示例 2：

输入：num = [2,7,4], k = 181
输出：[4,5,5]
解释：274 + 181 = 455

示例 3：

输入：num = [2,1,5], k = 806
输出：[1,0,2,1]
解释：215 + 806 = 1021

提示：

  • 1 <= num.length <= 104
  • 0 <= num[i] <= 9
  • num 不包含任何前导零，除了零本身
  • 1 <= k <= 104
