559. N 叉树的最大深度

  • 频度 8
  • 深度优先搜索/递归
  • 树
  • 深度优先搜索
  • 广度优先搜索
  • 待提交

递归：结点深度 = 各孩子深度的最大值 + 1；空树 0，叶子自然得到 1。

思路

  • 整棵树的深度由「最深的那条根到叶路径」决定，所以每个结点先递归算完所有孩子的深度。
  • 取孩子深度的最大值再加 1 就是本结点深度；空树返回 0，叶子（无孩子）自然得 1。
  • 递归按后序汇总：孩子算完才轮到父亲，深度一层层向上传，根的返回值即答案。

题目

给定一个 N 叉树，找到其最大深度。

最大深度是指从根节点到最远叶子节点的最长路径上的节点总数。

N 叉树输入按层序遍历序列化表示，每组子节点由空值分隔（请参见示例）。

 

示例 1：

输入：root = [1,null,3,2,4,null,5,6]
输出：3

示例 2：

输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：5

提示：

  • 树的深度不会超过 1000 。
  • 树的节点数目位于 [0, 104] 之间。
