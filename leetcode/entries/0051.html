  • 数组
  • 回溯

逐行回溯：每行选一列放皇后，用三个 boolean 集合 O(1) 判列、主对角线、副对角线冲突，放不下就回溯换列。

思路

  • 按行放：每行必有一个皇后且不冲突，所以只需给每行选列，行号即递归深度。
  • 三个集合：cols[col] 占列；主对角线 row-col+n（同线差为定值）；副对角线 row+col（同线和为定值）。
  • 进入前占位、递归返回后撤销（回溯）；被占的列/线直接 continue。
  • 放满 n 行就把 queens[row] 渲染成棋盘收进答案。

1import java.util.*;2 3class Solution {4    public List<List<String>> solveNQueens(int n) {5        List<List<String>> ans = new ArrayList<>();6        int[] queens = new int[n];   // queens[row]：这一行的皇后放在哪一列7        dfs(0, n, queens, new boolean[n], new boolean[2 * n], new boolean[2 * n], ans);8        return ans;9    }10 11    // 逐行放：cols 管列冲突，d1 管主对角线（row-col+n），d2 管副对角线（row+col）12    private void dfs(int row, int n, int[] queens, boolean[] cols, boolean[] d1, boolean[] d2, List<List<String>> ans) {13        if (row == n) {14            List<String> board = new ArrayList<>();15            for (int r = 0; r < n; r++) {16                char[] line = new char[n];17                Arrays.fill(line, '.');18                line[queens[r]] = 'Q';19                board.add(new String(line));20            }21            ans.add(board);22            return;23        }24        for (int col = 0; col < n; col++) {25            int a = row - col + n, b = row + col;26            if (cols[col] || d1[a] || d2[b]) continue;   // 列或对角线被占：这格不能放27            cols[col] = d1[a] = d2[b] = true;28            queens[row] = col;29            dfs(row + 1, n, queens, cols, d1, d2, ans);30            cols[col] = d1[a] = d2[b] = false;   // 回溯：撤掉占位再试下一列31        }32    }33}
题目

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

n 皇后问题 研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 n ，返回所有不同的 n 皇后问题 的解决方案。

每一种解法包含一个不同的 n 皇后问题 的棋子放置方案，该方案中 'Q' 和 '.' 分别代表了皇后和空位。

示例 1：

输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如上图所示，4 皇后问题存在两个不同的解法。

示例 2：

输入：n = 1
输出：[["Q"]]

提示：

  • 1 <= n <= 9
