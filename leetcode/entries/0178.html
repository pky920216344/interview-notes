178. 分数排名

  • 中等
  • 频度 1
  • SQL
  • 数据库
  • 待提交

同分同名次且并列后名次紧接 → 就是 DENSE_RANK()，按 score 降序开窗。

思路

  • 题面排名规则逐条对应：同分同名次 + 并列后连续不空缺 ⟹ DENSE_RANK()（RANK 会空缺、ROW_NUMBER 会拆并列）。
  • rank 是 MySQL 保留字，作别名时用反引号包住即可（写成反引号 + rank + 反引号）。
  • 开窗函数作用于全表行，外层再按 score 降序排一次保证输出顺序。
  • 老版本 MySQL 的替代写法：(SELECT COUNT(DISTINCT b.score) FROM Scores b WHERE b.score >= a.score) AS rank（相关子查询）。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1-- 178（codetop 0178）分数排名（MySQL）2-- 题意：Scores(id, score)。排名规则：分数从高到低；同分同名次；并列后名次紧接不空缺（即 DENSE_RANK）。3-- 输出列名 rank（保留字需反引号或大小写别名），按 score 降序。4SELECT score,5       DENSE_RANK() OVER (ORDER BY score DESC) AS `rank`6FROM Scores7ORDER BY score DESC;
题目

表: Scores

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| score       | decimal |
+-------------+---------+
id 是该表的主键（有不同值的列）。
该表的每一行都包含了一场比赛的分数。Score 是一个有两位小数点的浮点值。

编写一个解决方案来查询分数的排名。排名按以下规则计算:

  • 分数应按从高到低排列。
  • 如果两个分数相等，那么两个分数的排名应该相同。
  • 在排名相同的分数后，排名数应该是下一个连续的整数。换句话说，排名之间不应该有空缺的数字。

按 score 降序返回结果表。

查询结果格式如下所示。

示例 1:

输入: 
Scores 表:
+----+-------+
| id | score |
+----+-------+
| 1  | 3.50  |
| 2  | 3.65  |
| 3  | 4.00  |
| 4  | 3.85  |
| 5  | 4.00  |
| 6  | 3.65  |
+----+-------+
输出: 
+-------+------+
| score | rank |
+-------+------+
| 4.00  | 1    |
| 4.00  | 1    |
| 3.85  | 2    |
| 3.65  | 3    |
| 3.65  | 3    |
| 3.50  | 4    |
+-------+------+
