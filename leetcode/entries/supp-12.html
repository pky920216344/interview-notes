补充题12. 二叉树的下一个节点

  • 中等
  • 频度 7
  • 模拟
  • 未经力扣验证

有右子树，后继是右子树最左结点；没有，就沿 parent 上行，第一次不是「右孩子」时停下的父结点就是后继。

思路

  • 中序顺序是「左 → 根 → 右」：有右子树时，后继在右子树里，一路向左走到底。
  • 没有右子树时，自己和自己的祖先链里，后继是第一个把自己当左孩子的祖先的父结点。
  • 实现：while (cur.parent != null && cur.parent.right == cur) cur = cur.parent;，返回 cur.parent。
  • 一路爬到根都停不下来（整棵树里它是最后一个结点），返回 null。
