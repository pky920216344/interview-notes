剑指 Offer 47. 珠宝的最高价值

网格 DP：走到每格的最大价值 = 本格价值 + max(上方, 左边)；逐行算，用一行滚动数组存上一行。

思路

  • dp[j] 滚动表示「走到当前行第 j 列」的最大价值；更新前它是上一行的值（上方来路）。
  • 从左到右扫：dp[j-1] 已是本行的值（左边来路），取 max(dp[j], dp[j-1]) + frame[i][j] 写回。
  • 第一列没有左边来路，直接继承上方；答案是右下角的 dp[n-1]。

图解

最优解

时间复杂度 O(mn)，空间复杂度 O(n)
1class Solution {2    public int jewelleryValue(int[][] frame) {3        int m = frame.length, n = frame[0].length;4        // dp[j]：走到「当前行」第 j 列时能拿到的最大价值（滚动掉行这一维）5        int[] dp = new int[n];6        for (int i = 0; i < m; i++) {7            for (int j = 0; j < n; j++) {8                // 更新前的 dp[j] 是上方来路，已更新的 dp[j-1] 是左边来路9                int best = Math.max(dp[j], j > 0 ? dp[j - 1] : 0);10                dp[j] = best + frame[i][j];11            }12        }13        return dp[n - 1];14    }15}
题目

现有一个记作二维矩阵 frame 的珠宝架，其中 frame[i][j] 为该位置珠宝的价值。拿取珠宝的规则为：

  • 只能从架子的左上角开始拿珠宝
  • 每次可以移动到右侧或下侧的相邻位置
  • 到达珠宝架子的右下角时，停止拿取

注意：珠宝的价值都是大于 0 的。除非这个架子上没有任何珠宝，比如 frame = [[0]]。

示例 1：

输入：frame = [[1,3,1],[1,5,1],[4,2,1]]
输出：12
解释：路径 1→3→5→2→1 可以拿到最高价值的珠宝

提示：

  • 0 < frame.length <= 200
  • 0 < frame[0].length <= 200
