226. 翻转二叉树

  • 频度 68

  • 树
  • 深度优先搜索
  • 广度优先搜索
  • 二叉树
  • 力扣已通过

递归交换每个结点的左右孩子：tmp 存住左孩子再互相赋值，然后进两棵子树继续翻，返回根。

思路

  • root == null 返回 null；否则 tmp 先存住 root.left，三行把左右孩子换过来。
  • 交换后对新的 root.left、root.right 各递归一次，每个结点都轮到一次交换。
  • 原地翻转，最后返回根结点本身；空树直接返回。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(h)
1class Solution {2    public TreeNode invertTree(TreeNode root) {3        if (root == null) return null;4        // tmp 存住左孩子，交换左右两棵子树5        TreeNode tmp = root.left;6        root.left = root.right;7        root.right = tmp;8        // 再进新的左右子树继续翻9        invertTree(root.left);10        invertTree(root.right);11        return root;12    }13}
题目

给你一棵二叉树的根节点 root ，翻转这棵二叉树，并返回其根节点。

示例 1：

输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]

示例 2：

输入：root = [2,1,3]
输出：[2,3,1]

示例 3：

输入：root = []
输出：[]

提示：

  • 树中节点数目范围在 [0, 100] 内
  • -100 <= Node.val <= 100
