260. 只出现一次的数字 III

  • 中等
  • 频度 20
  • 位运算
  • 位运算
  • 数组
  • 力扣已通过

全体异或得 x^y，取 lowbit 把数组按这一位分成两组，两组各自再异或一次就剩下那两个数。

思路

  • 第一遍全体异或：出现两次的互相抵消，结果就是 x ^ y（x、y 是两个只出现一次的数，必不为 0）。
  • low = xor & (-xor) 取出最低的 1 位：x 和 y 在这一位上必定一个 0 一个 1。
  • 第二遍按 (x & low) 是否为 0 把数组分成两组各自异或：成对的数低位相同，必然落进同一组继续抵消，两组分别剩下 x 和 y。
  • 返回顺序任意，本题不挑顺序。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] singleNumber(int[] nums) {3        // 全部异或到一起：成对的抵消，只剩 x ^ y4        int xor = 0;5        for (int x : nums) xor ^= x;6        // lowbit：x 和 y 不同的最低位，它俩在这位上必然一个 0 一个 17        int low = xor & (-xor);8        // 按这位分成两组各自异或：组内成对的抵消，两组各剩一个9        int[] ans = new int[2];10        for (int x : nums) ans[(x & low) != 0 ? 1 : 0] ^= x;11        return ans;12    }13}
题目

给你一个整数数组 nums，其中恰好有两个元素只出现一次，其余所有元素均出现两次。 找出只出现一次的那两个元素。你可以按 任意顺序 返回答案。

你必须设计并实现线性时间复杂度的算法且仅使用常量额外空间来解决此问题。

示例 1：

输入：nums = [1,2,1,3,2,5]
输出：[3,5]
解释：[5, 3] 也是有效的答案。

示例 2：

输入：nums = [-1,0]
输出：[-1,0]

示例 3：

输入：nums = [0,1]
输出：[1,0]

提示：

  • 2 <= nums.length <= 3 * 104
  • -231 <= nums[i] <= 231 - 1
  • 除两个只出现一次的整数外，nums 中的其他数字都出现两次
