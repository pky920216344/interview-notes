763. 划分字母区间

先记每个字母最后出现的下标；扫描时 end = max(end, last[c]) 把段撑到最远，i 追上 end 就切一段。

思路

  • 预扫一遍记 last[c]；段 [start, end] 的含义：段内每个字母都不会再出现在段外。
  • 扫描时 end = max(end, last[c]) 只增不减——重复读到旧字母时 max 保住已撑到的边界（直接赋值会回退）。
  • i == end 说明段闭合成形，切下 i - start + 1，start = i + 1 开新段。

最优解

时间复杂度 O(n)，空间复杂度 O(1)（26 大小的数组；不计返回值）
1import java.util.*;2 3class Solution {4    public List<Integer> partitionLabels(String s) {5        // last[c]：字母 c 最后一次出现的下标6        int[] last = new int[26];7        for (int i = 0; i < s.length(); i++) last[s.charAt(i) - 'a'] = i;8        List<Integer> ans = new ArrayList<>();9        // 当前段的边界：段内每个字母都必须在段内最后出现10        int start = 0, end = 0;11        for (int i = 0; i < s.length(); i++) {12            end = Math.max(end, last[s.charAt(i) - 'a']);13            // i 追上 end：段里字母都不会再出现，切一段14            if (i == end) {15                ans.add(i - start + 1);16                start = i + 1;17            }18        }19        return ans;20    }21}
题目

给你一个字符串 s 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 "ababcc" 能够被分为 ["abab", "cc"]，但类似 ["aba", "bcc"] 或 ["ab", "ab", "cc"] 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 s 。

返回一个表示每个字符串片段的长度的列表。

示例 1： 
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。

示例 2：

输入：s = "eccbbbbdec"
输出：[10]

提示：

  • 1 <= s.length <= 500
  • s 仅由小写英文字母组成
