排序 + DP：从小到大算 dp[a] = 1 + Σ 因子对的 dp 乘积（左右相同计 1 组、不同计 2 组），全部累加取模。

思路

  • 根值 a 的树：左右孩子都是数组里更小的值且乘积等于 a，所以先排序，dp 只依赖更小的值。
  • 转移：dp[i] += dp[l] × dp[r]（arr[l] × arr[r] == arr[i]）；左右因子相同计 1 组、不同则左右交换计 2 组，所以只枚举左 ≤ 右再乘 2。
  • 每个值至少有单结点这 1 棵；答案 = 所有 dp[i] 累加对 10⁹+7 取模。

时间复杂度 O(n²)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int numFactoredBinaryTrees(int[] arr) {5        Arrays.sort(arr);6        int n = arr.length;7        final long MOD = 1_000_000_007;8        long[] dp = new long[n];                      // dp[i]：以 arr[i] 为根的因子二叉树数9        Map<Integer, Integer> idx = new HashMap<>();  // 值 → 排序后的下标10        long ans = 0;11        for (int i = 0; i < n; i++) {12            dp[i] = 1;                                // 单结点树13            for (int l = 0; l < i; l++) {14                if (arr[i] % arr[l] != 0) continue;15                Integer r = idx.get(arr[i] / arr[l]);16                // 只枚举左因子 ≤ 右因子：相同算 1 组，不同左右交换算 2 组17                if (r == null || arr[r] < arr[l]) continue;18                dp[i] = (dp[i] + dp[l] * dp[r] * (l == r ? 1 : 2)) % MOD;19            }20            idx.put(arr[i], i);21            ans = (ans + dp[i]) % MOD;22        }23        return (int) ans;24    }25}
题目

给出一个含有不重复整数元素的数组 arr ，每个整数 arr[i] 均大于 1。

用这些整数来构建二叉树，每个整数可以使用任意次数。其中：每个非叶结点的值应等于它的两个子结点的值的乘积。

满足条件的二叉树一共有多少个？答案可能很大，返回 对 109 + 7 取余 的结果。

示例 1:

输入: arr = [2, 4]
输出: 3
解释: 可以得到这些二叉树: [2], [4], [4, 2, 2]

示例 2:

输入: arr = [2, 4, 5, 10]
输出: 7
解释: 可以得到这些二叉树: [2], [4], [5], [10], [4, 2, 2], [10, 2, 5], [10, 5, 2].

提示：

  • 1 <= arr.length <= 1000
  • 2 <= arr[i] <= 109
  • arr 中的所有值 互不相同
