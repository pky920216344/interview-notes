1570. 两个稀疏向量的点积

构造时只存非零 <下标,值> 升序表；点积用双指针按下标归并，相等才相乘。

思路

  • 稀疏向量只存非零：List<int[]>{下标, 值}，天然按下标升序。
  • dotProduct 双指针：两表下标相等 → 相乘累加、双双前进；谁的下标小谁前进（不可能匹配）。
  • 关键点：两表下标都升序，双指针一遍合并即可；点积只花与非零个数成正比的时间。

最优解

时间复杂度 构造 O(n)，点积 O(min(nz₁, nz₂))，空间复杂度 O(nz)
1import java.util.*;2 3class SparseVector {4    // 只存非零元素：<下标, 值>，按下标升序，dotProduct 用双指针合并5    private final List<int[]> pairs = new ArrayList<>();6 7    public SparseVector(int[] nums) {8        for (int i = 0; i < nums.length; i++) {9            if (nums[i] != 0) pairs.add(new int[]{i, nums[i]});   // 稀疏就只记非零10        }11    }12 13    // Return the dot product of two sparse vectors14    public int dotProduct(SparseVector vec) {15        int ans = 0;16        int i = 0, j = 0;17        while (i < pairs.size() && j < vec.pairs.size()) {18            if (pairs.get(i)[0] == vec.pairs.get(j)[0]) {   // 下标相同：这一对相乘累加19                ans += pairs.get(i)[1] * vec.pairs.get(j)[1];20                i++;21                j++;22            } else if (pairs.get(i)[0] < vec.pairs.get(j)[0]) {23                i++;   // 下标小的不可能再匹配，前进24            } else {25                j++;26            }27        }28        return ans;29    }30}
