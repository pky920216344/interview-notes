建 26 字母的 rank 表；整体有序等价于每对相邻词有序，第一个不同字符的 rank 分胜负，前缀相同则短的小。

思路

  • rank[c] 存外星字母表中 c 的序号，两个字符比大小就是查表相减。
  • 整体有序 ⟺ 每一对相邻词都有序，所以只比较相邻词，发现一对违序就返回 false。
  • 逐字符比到第一个不同处分胜负；前缀完全相同时短词排前面（app < apple）。

时间复杂度 O(总字符数)，空间复杂度 O(1)
1class Solution {2    public boolean isAlienSorted(String[] words, String order) {3        int[] rank = new int[26];4        for (int i = 0; i < 26; i++) rank[order.charAt(i) - 'a'] = i;5        // 相邻两词都有序，整体就有序6        for (int i = 1; i < words.length; i++) {7            if (cmp(words[i - 1], words[i], rank) > 0) return false;8        }9        return true;10    }11 12    // 外星语字典序比较：a < b 返回负数13    private int cmp(String a, String b, int[] rank) {14        int n = Math.min(a.length(), b.length());15        for (int i = 0; i < n; i++) {16            if (a.charAt(i) != b.charAt(i)) {17                return rank[a.charAt(i) - 'a'] - rank[b.charAt(i) - 'a'];18            }19        }20        return a.length() - b.length();   // 前缀相同：短的小21    }22}
题目

某种外星语也使用英文小写字母，但可能顺序 order 不同。字母表的顺序（order）是一些小写字母的排列。

给定一组用外星语书写的单词 words，以及其字母表的顺序 order，只有当给定的单词在这种外星语中按字典序排列时，返回 true；否则，返回 false。

示例 1：

输入：words = ["hello","leetcode"], order = "hlabcdefgijkmnopqrstuvwxyz"
输出：true
解释：在该语言的字母表中，'h' 位于 'l' 之前，所以单词序列是按字典序排列的。

示例 2：

输入：words = ["word","world","row"], order = "worldabcefghijkmnpqstuvxyz"
输出：false
解释：在该语言的字母表中，'d' 位于 'l' 之后，那么 words[0] > words[1]，因此单词序列不是按字典序排列的。

示例 3：

输入：words = ["apple","app"], order = "abcdefghijklmnopqrstuvwxyz"
输出：false
解释：当前三个字符 "app" 匹配时，第二个字符串相对短一些，然后根据词典编纂规则 "apple" > "app"，因为 'l' > '∅'，其中 '∅' 是空白字符，定义为比任何其他字符都小（更多信息）。

提示：

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 20
  • order.length == 26
  • 在 words[i] 和 order 中的所有字符都是英文小写字母。
