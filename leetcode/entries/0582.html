582. 杀掉进程

建「父进程 → 子进程列表」邻接表，从 kill 号开始 BFS/DFS，进队的每个进程连同整棵子树一起被杀。

思路

  • 扫一遍 ppid 建邻接表：children[ppid[i]] 收下 pid[i]；父进程号 0 表示顶层。
  • 从 kill 出发 BFS（或 DFS）：每弹出一个进程就记入名单，再把它的直接孩子入队。
  • 队列空时名单恰好是 kill 及其全部后代；题目对输出顺序不限。

1import java.util.*;2 3class Solution {4    public List<Integer> killProcess(List<Integer> pid, List<Integer> ppid, int kill) {5        // 邻接表：父进程号 → 直接子进程列表；ppid 里出现 0 表示它的父进程已不在列表里6        Map<Integer, List<Integer>> children = new HashMap<>();7        for (int i = 0; i < pid.size(); i++) {8            children.computeIfAbsent(ppid.get(i), k -> new ArrayList<>()).add(pid.get(i));9        }10        // 从 kill 出发 BFS：进队的每个进程连同它的整棵子树一起被杀11        List<Integer> out = new ArrayList<>();12        Deque<Integer> queue = new ArrayDeque<>();13        queue.add(kill);14        while (!queue.isEmpty()) {15            int cur = queue.poll();16            out.add(cur);17            List<Integer> cs = children.get(cur);18            if (cs != null) for (int ch : cs) queue.add(ch);19        }20        return out;21    }22}
