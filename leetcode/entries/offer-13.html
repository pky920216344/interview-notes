从 (0,0) 出发 DFS/BFS 连通计数：只能右/下走，数位和(行)+数位和(列) ≤ cnt 的格子才可进。

思路

  • 起点固定 (0,0)，只能向右或向下走；格子 (i,j) 可进当且仅当 digitSum(i) + digitSum(j) ≤ cnt。
  • 从起点做一次 DFS/BFS 连通计数（vis 防重入），数出的就是答案。
  • 关键：数位和达标的格子不一定可达——可能被一整排高数位和的格子挡住（如 cnt=1 时 (10,0) 进不去），所以不能直接数合格格子的个数。
  • 数位和可以预处理或现算，x ≤ 100 直接逐位除 10 即可。

时间复杂度 O(m·n)，空间复杂度 O(m·n)
1class Solution {2    public int wardrobeFinishing(int m, int n, int cnt) {3        boolean[][] vis = new boolean[m][n];4        return dfs(0, 0, m, n, cnt, vis);5    }6 7    // 只能向右或向下走：返回从 (i,j) 出发能整理到的格子数8    private int dfs(int i, int j, int m, int n, int cnt, boolean[][] vis) {9        if (i == m || j == n || vis[i][j] || digitSum(i) + digitSum(j) > cnt) return 0;10        vis[i][j] = true;11        return 1 + dfs(i + 1, j, m, n, cnt, vis) + dfs(i, j + 1, m, n, cnt, vis);12    }13 14    private int digitSum(int x) {15        int s = 0;16        for (; x > 0; x /= 10) s += x % 10;17        return s;18    }19}
题目

家居整理师将待整理衣橱划分为 m x n 的二维矩阵 grid，其中 grid[i][j] 代表一个需要整理的格子。整理师自 grid[0][0] 开始 逐行逐列 地整理每个格子。

整理规则为：在整理过程中，可以选择 向右移动一格 或 向下移动一格，但不能移动到衣柜之外。同时，不需要整理 digit(i) + digit(j) > cnt 的格子，其中 digit(x) 表示数字 x 的各数位之和。

请返回整理师 总共需要整理多少个格子。

示例 1：

输入：m = 4, n = 7, cnt = 5
输出：18

提示：

  • 1 <= n, m <= 100
  • 0 <= cnt <= 20
