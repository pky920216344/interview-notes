228. 汇总区间

  • 中等
  • 频度 1
  • 模拟
  • 数组
  • 待提交

一趟扫描：从每个「断点」出发，只要相邻差 1 就把区间向右延伸，断开时收段输出，单值段不加箭头。

思路

  • 每段从起点 start 开始：nums[i+1] == nums[i] + 1 就延伸，否则本段结束。
  • 收段时 start == nums[i] 说明只有一个数，输出 "a"；否则输出 "a->b"。
  • 输入升序且无重复，段与段天然按序产生；空数组返回空列表。

最优解

时间复杂度 O(n)，空间复杂度 O(1)（不计输出）
1import java.util.*;2 3class Solution {4    public List<String> summaryRanges(int[] nums) {5        List<String> ans = new ArrayList<>();6        for (int i = 0; i < nums.length; i++) {7            int start = nums[i];   // 本段起点8            // 相邻差 1 就连续：一路延伸到断开为止9            while (i + 1 < nums.length && nums[i + 1] == nums[i] + 1) i++;10            if (start == nums[i]) ans.add(String.valueOf(start));11            else ans.add(start + "->" + nums[i]);12        }13        return ans;14    }15}
题目

给定一个  无重复元素 的 有序 整数数组 nums 。

区间 [a,b] 是从 a 到 b（包含）的所有整数的集合。

返回 恰好覆盖数组中所有数字 的 最小有序 区间范围列表 。也就是说，nums 的每个元素都恰好被某个区间范围所覆盖，并且不存在属于某个区间但不属于 nums 的数字 x 。

列表中的每个区间范围 [a,b] 应该按如下格式输出：

  • "a->b" ，如果 a != b
  • "a" ，如果 a == b

示例 1：

输入：nums = [0,1,2,4,5,7]
输出：["0->2","4->5","7"]
解释：区间范围是：
[0,2] --> "0->2"
[4,5] --> "4->5"
[7,7] --> "7"

示例 2：

输入：nums = [0,2,3,4,6,8,9]
输出：["0","2->4","6","8->9"]
解释：区间范围是：
[0,0] --> "0"
[2,4] --> "2->4"
[6,6] --> "6"
[8,9] --> "8->9"

提示：

  • 0 <= nums.length <= 20
  • -231 <= nums[i] <= 231 - 1
  • nums 中的所有值都 互不相同
  • nums 按升序排列
