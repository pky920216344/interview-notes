边扫边数：每个数和之前出现过的同值数各成一个好数对，ans 加上该值已出现次数再计数加一。

思路

  • 扫到 x 时，前面每个同值的数都能和它组成好数对，所以 ans += cnt[x]，然后 cnt[x]++。
  • 一次遍历就出结果，不需要回头数；等价于对每个值算 C(出现次数, 2)。
  • 值域 1~100，直接开长度 101 的数组当计数表，比哈希表更快。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int numIdenticalPairs(int[] nums) {3        int[] cnt = new int[101];4        int ans = 0;5        // 每遇到一个数，它和之前出现过的同值数各组成一个好数对6        for (int x : nums) {7            ans += cnt[x];8            cnt[x]++;9        }10        return ans;11    }12}
题目

给你一个整数数组 nums 。

如果一组数字 (i,j) 满足 nums[i] == nums[j] 且 i < j ，就可以认为这是一组 好数对 。

返回好数对的数目。

示例 1：

输入：nums = [1,2,3,1,1,3]
输出：4
解释：有 4 组好数对，分别是 (0,3), (0,4), (3,4), (2,5) ，下标从 0 开始

示例 2：

输入：nums = [1,1,1,1]
输出：6
解释：数组中的每组数字都是好数对

示例 3：

输入：nums = [1,2,3]
输出：0

提示：

  • 1 <= nums.length <= 100
  • 1 <= nums[i] <= 100
