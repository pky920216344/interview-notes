319. 灯泡开关

  • 数学

灯 i 被拨的次数 = i 的约数个数；约数成对出现，只有完全平方数被拨奇数次而亮着，答案 = ⌊√n⌋。

思路

  • 灯 i 在第 d 轮被拨当且仅当 d 整除 i，所以被拨次数 = i 的约数个数。
  • 约数成对 (d, i/d)：非平方数被拨偶数次回到灭；平方数的 d = i/d 只算一次，被拨奇数次，最后亮着。
  • 答案就是 ≤ n 的完全平方数个数 = ⌊√n⌋；n 到 1e9 也不能模拟，必须用这个结论。

最优解

时间复杂度 O(√n)（也可 O(1) 用 Math.sqrt 再校正），空间复杂度 O(1)

题目

初始时有 n 个灯泡处于关闭状态。第一轮，你将会打开所有灯泡。接下来的第二轮，你将会每两个灯泡关闭第二个。

第三轮，你每三个灯泡就切换第三个灯泡的开关（即，打开变关闭，关闭变打开）。第 i 轮，你每 i 个灯泡就切换第 i 个灯泡的开关。直到第 n 轮，你只需要切换最后一个灯泡的开关。

找出并返回 n 轮后有多少个亮着的灯泡。

示例 1：

输入：n =3
输出：1 
解释：
初始时, 灯泡状态 [关闭, 关闭, 关闭].
第一轮后, 灯泡状态 [开启, 开启, 开启].
第二轮后, 灯泡状态 [开启, 关闭, 开启].
第三轮后, 灯泡状态 [开启, 关闭, 关闭]. 

你应该返回 1，因为只有一个灯泡还亮着。

示例 2：

输入：n = 0
输出：0

示例 3：

输入：n = 1
输出：1

提示：

  • 0 <= n <= 109
