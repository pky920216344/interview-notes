剑指 Offer 38. 套餐内商品的排列顺序

排序 + 回溯：逐层选一个没用过的字符拼下去，同层里相同的字符只允许从左往右依次选，天然去重。

思路

  • 先 Arrays.sort：相同字符相邻，去重条件才有统一写法；结果也顺带按字典序产出。
  • 回溯模板：used[i] 标记字符是否在路径里，进递归前置 true、回来置 false，path 拼满就收一个排列。
  • 去重关键：cs[i] == cs[i-1] && !used[i-1] 就跳过——前一个相同字符刚被回溯（不在路径里），说明这一层已经用同样字符开过头，再选必出重复排列。
  • !used[i-1] 是「同层」的判据：若前一个相同字符在路径里（used[i-1] 为 true），那是纵向的重复使用，必须放行。

1import java.util.*;2 3class Solution {4    public String[] goodsOrder(String goods) {5        char[] cs = goods.toCharArray();6        Arrays.sort(cs);   // 排序让相同字符相邻，同层去重才有依据7        List<String> ans = new ArrayList<>();8        dfs(cs, new boolean[cs.length], new StringBuilder(), ans);9        return ans.toArray(new String[0]);10    }11 12    // used[i]：cs[i] 是否已在当前路径里13    private void dfs(char[] cs, boolean[] used, StringBuilder path, List<String> ans) {14        if (path.length() == cs.length) {15            ans.add(path.toString());16            return;17        }18        for (int i = 0; i < cs.length; i++) {19            // 同层去重：cs[i] 与前一个相同且前一个还没被选，说明这一层刚试过它，跳过20            if (used[i] || (i > 0 && cs[i] == cs[i - 1] && !used[i - 1])) continue;21            used[i] = true;22            path.append(cs[i]);23            dfs(cs, used, path, ans);24            path.deleteCharAt(path.length() - 1);25            used[i] = false;26        }27    }28}
题目

某店铺将用于组成套餐的商品记作字符串 goods，其中 goods[i] 表示对应商品。请返回该套餐内所含商品的 全部排列方式 。

返回结果 无顺序要求，但不能含有重复的元素。

示例 1：

输入：goods = "agew"
输出：["aegw","aewg","agew","agwe","aweg","awge","eagw","eawg","egaw","egwa","ewag","ewga","gaew","gawe","geaw","gewa","gwae","gwea","waeg","wage","weag","wega","wgae","wgea"]

提示：

  • 1 <= goods.length <= 8
