977. 有序数组的平方

  • 简单
  • 频度 16
  • 双指针
  • 数组
  • 双指针
  • 排序
  • 待提交

首尾双指针比绝对值（平方），大的从结果数组尾部往前放，一遍 O(n)。

思路

  • 有序数组平方后最大值只会出现在两端：l、r 从两头往中间走。
  • 比 sqL 和 sqR，大的写进 ans[pos] 并 pos--（从尾往前填），对应指针再收缩一步。
  • 相等时走 else 分支即可；负数端的平方同样可能是最大值，别只盯右端。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)（不计结果数组）
1class Solution {2    public int[] sortedSquares(int[] nums) {3        int n = nums.length;4        int[] ans = new int[n];5        // 两端的绝对值最大：双指针从两头往中间比，大的从结果尾部往前放6        int l = 0, r = n - 1, pos = n - 1;7        while (l <= r) {8            int sqL = nums[l] * nums[l], sqR = nums[r] * nums[r];9            if (sqL > sqR) { ans[pos] = sqL; l++; }   // 左边的平方更大10            else { ans[pos] = sqR; r--; }             // 右边的更大或相等11            pos--;                                     // 从尾往前填12        }13        return ans;14    }15}
题目

给你一个按 非递减顺序 排序的整数数组 nums，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。

示例 1：

输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后，数组变为 [16,1,0,9,100]
排序后，数组变为 [0,1,9,16,100]

示例 2：

输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]

提示：

  • 1 <= nums.length <= 104
  • -104 <= nums[i] <= 104
  • nums 已按 非递减顺序 排序
