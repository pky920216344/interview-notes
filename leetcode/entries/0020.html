20. 有效的括号

  • 简单
  • 频度 301
  • 栈
  • 栈
  • 字符串
  • bracket-sequences
  • 力扣已通过

栈：遇到左括号就压入它期待的右括号；遇到右括号必须等于栈顶，否则无效；扫完栈要是空的。

思路

  • 用数组 stack 加计数 top 模拟栈，栈里存「期待出现的右括号」：读到 ( 压 )，[ 压 ]，{ 压 }。
  • 读到右括号：栈空，或者不等于栈顶 stack[top - 1]，直接返回 false；相等就 top-- 弹出。
  • 扫完后必须 top == 0，否则还有左括号没闭合（比如 ((），别忘了这一步。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public boolean isValid(String s) {3        // 数组当栈用，top 是栈里的元素个数4        char[] stack = new char[s.length()];5        int top = 0;6        for (int i = 0; i < s.length(); i++) {7            char c = s.charAt(i);8            // 左括号：压入它期待的右括号9            if (c == '(') stack[top++] = ')';10            else if (c == '[') stack[top++] = ']';11            else if (c == '{') stack[top++] = '}';12            else {13                // 右括号：栈空，或和栈顶对不上，都无效14                if (top == 0 || stack[top - 1] != c) return false;15                top--;16            }17        }18        // 栈里还剩没闭合的左括号，也无效19        return top == 0;20    }21}
题目

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

  1. 左括号必须用相同类型的右括号闭合。
  2. 左括号必须以正确的顺序闭合。
  3. 每个右括号都有一个对应的相同类型的左括号。

示例 1：

输入：s = "()"

输出：true

示例 2：

输入：s = "()[]{}"

输出：true

示例 3：

输入：s = "(]"

输出：false

示例 4：

输入：s = "([])"

输出：true

示例 5：

输入：s = "([)]"

输出：false

提示：

  • 1 <= s.length <= 104
  • s 仅由括号 '()[]{}' 组成
