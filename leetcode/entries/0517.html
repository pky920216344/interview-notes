  • 贪心
  • 数组
  • 待提交

先判总和能均分；答案 = max(最大的单台净送出量 d，最大的前缀缺口 |flow|)——前者受「每台每步只送 1 件」限制，后者受「每步跨分界线只过 1 件」限制。

思路

  • 总和不能均分直接 −1；否则目标 avg = sum/n。
  • 一遍扫：d = v − avg 是这台的净送出量；flow 累加 d，|flow| 是「左半边还缺多少件」= 必须跨过分界线的件数。
  • 两个下界：一件衣服要送出 d 件的那台每步只能送 1 件 → 至少 max(d) 步；每个分界线每步只能净过 1 件 → 至少 max|flow| 步。
  • 答案 = 两个下界的较大者，且该步数可以构造达到，故为最少步数。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int findMinMoves(int[] machines) {3        int n = machines.length, sum = 0;4        for (int v : machines) sum += v;5        if (sum % n != 0) return -1;   // 总数分不匀，无解6        int avg = sum / n, ans = 0, flow = 0;7        for (int v : machines) {8            int d = v - avg;      // 这台的净送出量（负数是净收进）9            flow += d;            // 左边前缀累计的净流出：这么多件必须跨过分界线10            // d 步数下界：一台每步最多送出 1 件，要送 d 件就得 d 步11            // |flow| 步数下界：每步跨过分界线的最多 1 件12            ans = Math.max(ans, Math.max(d, Math.abs(flow)));13        }14        return ans;15    }16}
题目

假设有 n台超级洗衣机放在同一排上。开始的时候，每台洗衣机内可能有一定量的衣服，也可能是空的。

在每一步操作中，你可以选择任意 m (1 <= m <= n) 台洗衣机，与此同时将每台洗衣机的一件衣服送到相邻的一台洗衣机。

给定一个整数数组 machines 代表从左至右每台洗衣机中的衣物数量，请给出能让所有洗衣机中剩下的衣物的数量相等的 最少的操作步数 。如果不能使每台洗衣机中衣物的数量相等，则返回 -1 。

示例 1：

输入：machines = [1,0,5]
输出：3
解释：
第一步:    1     0 <-- 5    =>    1     1     4
第二步:    1 <-- 1 <-- 4    =>    2     1     3    
第三步:    2     1 <-- 3    =>    2     2     2

示例 2：

输入：machines = [0,3,0]
输出：2
解释：
第一步:    0 <-- 3     0    =>    1     2     0    
第二步:    1     2 --> 0    =>    1     1     1

示例 3：

输入：machines = [0,2,0]
输出：-1
解释：
不可能让所有三个洗衣机同时剩下相同数量的衣物。

提示：

  • n == machines.length
  • 1 <= n <= 104
  • 0 <= machines[i] <= 105
