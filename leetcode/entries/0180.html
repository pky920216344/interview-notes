180. 连续出现的数字

  • 中等
  • 频度 2
  • SQL
  • 数据库
  • 待提交

同表自连接两次，id 相邻（+1、+2）且三个 num 全相等即是连续三次，DISTINCT 去重输出。

思路

  • 「连续」依赖 id 是自增主键：l2.id = l1.id + 1、l3.id = l1.id + 2 把相邻三行绑在一起。
  • 三行 num 两两相等（l1=l2 AND l2=l3）就是连续三次；DISTINCT 防止更长的连续段重复输出。
  • 若表没有自增 id（SQL Server 变体），标准替代是 ROW_NUMBER() OVER (ORDER BY id) − ROW_NUMBER() OVER (PARTITION BY num ORDER BY id) 分组——同一数字的连续段该差值不变。

最优解

时间复杂度 O(n)，空间复杂度 O(n)

题目

表：Logs

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| num         | varchar |
+-------------+---------+
在 SQL 中，id 是该表的主键。
id 是一个自增列。

找出所有至少连续出现三次的数字。

返回的结果表中的数据可以按 任意顺序 排列。
