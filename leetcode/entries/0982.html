982. 按位与为零的三元组

两两枚举记 g[m] = a&b==m 的对数；SOS 求 f[x] = 值⊆x 的个数；答案 = Σ g[m]·f[~m]。

思路

  • 枚举前两数：g[a & b]++，n ≤ 1000 时 10⁶ 次循环，远快于三重循环的 10⁹。
  • f[x] = Σ_{c ⊆ x} cnt[c] 用 SOS 逐位累加：f[x] += f[x ^ (1 << b)]，两重循环 16·2¹⁶。
  • 三数 AND 为 0 ⟺ 第三个数 c ⊆ ~m（m = a & b）→ 答案 = Σ g[m] · f[~m & 0xFFFF]。
  • 三元组最多 1000³ = 10⁹，int 装得下，但乘积先按 long 累加更稳。

最优解

时间复杂度 O(n² + 16·2^16)，空间复杂度 O(2^16)
1class Solution {2    public int countTriplets(int[] nums) {3        int[] cnt = new int[1 << 16];4        for (int x : nums) cnt[x]++;5        // g[m]：a & b == m 的有序对 (a, b) 个数；n ≤ 1000，直接两两枚举6        int[] g = new int[1 << 16];7        for (int a : nums) for (int b : nums) g[a & b]++;8        // f[x] = Σ_{c ⊆ x} cnt[c]：子集和（SOS），逐位累加9        long[] f = new long[1 << 16];10        for (int x = 0; x < (1 << 16); x++) f[x] = cnt[x];11        for (int b = 0; b < 16; b++)12            for (int x = 0; x < (1 << 16); x++)13                if ((x & (1 << b)) != 0) f[x] += f[x ^ (1 << b)];14        // 第三个数 c 要与 m = a & b 无公共位，即 c ⊆ ~m：按 g[m] 配 f[~m] 求和15        long ans = 0;16        for (int m = 0; m < (1 << 16); m++) ans += g[m] * f[(~m) & 0xFFFF];17        return (int) ans;18    }19}
题目

给你一个整数数组 nums ，返回其中 按位与三元组 的数目。

按位与三元组 是由下标 (i, j, k) 组成的三元组，并满足下述全部条件：

  • 0 <= i < nums.length
  • 0 <= j < nums.length
  • 0 <= k < nums.length
  • nums[i] & nums[j] & nums[k] == 0 ，其中 & 表示按位与运算符。
 

示例 1：

输入：nums = [2,1,3]
输出：12
解释：可以选出如下 i, j, k 三元组：
(i=0, j=0, k=1) : 2 & 2 & 1
(i=0, j=1, k=0) : 2 & 1 & 2
(i=0, j=1, k=1) : 2 & 1 & 1
(i=0, j=1, k=2) : 2 & 1 & 3
(i=0, j=2, k=1) : 2 & 3 & 1
(i=1, j=0, k=0) : 1 & 2 & 2
(i=1, j=0, k=1) : 1 & 2 & 1
(i=1, j=0, k=2) : 1 & 2 & 3
(i=1, j=1, k=0) : 1 & 1 & 2
(i=1, j=2, k=0) : 1 & 3 & 2
(i=2, j=0, k=1) : 3 & 2 & 1
(i=2, j=1, k=0) : 3 & 1 & 2

示例 2：

输入：nums = [0,0,0]
输出：27

提示：

  • 1 <= nums.length <= 1000
  • 0 <= nums[i] < 216
