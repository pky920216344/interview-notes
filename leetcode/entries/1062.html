1062. 最长重复子串的长度

  • 未经力扣验证

答案二分：有长为 len 的重复子串就必有更短的重复子串；对每个 len 用哈希集合判所有子串是否出现两次。

思路

  • 单调性：存在长 len 的重复子串，它的前缀就是长 len-1 的重复子串 ⇒ 对长度二分。
  • hasRepeat(len)：把每个长 len 子串放进 HashSet，add 返回 false 就是第二次出现。
  • 两次出现允许重叠（起点不同即可）；重复子串至多长 n-1，所以 hi 从 n-1 起。

时间复杂度 O(n^2·log n)，空间复杂度 O(n^2)
1import java.util.*;2 3class Solution {4    public int longestRepeatingSubstring(String s) {5        int n = s.length();6        // 有长为 len 的重复子串，就必有更短的重复子串：答案对长度单调，直接二分7        int lo = 1, hi = n - 1, ans = 0;8        while (lo <= hi) {9            int mid = (lo + hi) >>> 1;10            if (hasRepeat(s, mid)) {11                ans = mid;12                lo = mid + 1;13            } else {14                hi = mid - 1;15            }16        }17        return ans;18    }19 20    // 长 len 的所有起点子串放进哈希集合，add 返回 false 说明第二次出现21    private boolean hasRepeat(String s, int len) {22        Set<String> seen = new HashSet<>();23        for (int i = 0; i + len <= s.length(); i++) {24            if (!seen.add(s.substring(i, i + len))) return true;25        }26        return false;27    }28}
