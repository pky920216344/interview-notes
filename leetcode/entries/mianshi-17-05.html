字母 +1、数字 −1 求前缀和；哈希记每个前缀和的最早下标，同和两下标之间就是平衡段，取最长。

思路

  • 把每个元素分类：纯数字串记 -1，否则记 +1，「字母数 == 数字数」等价于区间和为 0，即两端前缀和相等。
  • 哈希表 first 记每个前缀和最早出现的下标（0 在开头置 -1）；再次遇到同和时 [j+1, i] 就是一个平衡段。
  • 用「最早下标」配对，得到的区间一定最长也最左；只有严格更长才更新，天然满足并列取最左的要求。

1import java.util.*;2 3class Solution {4    public String[] findLongestSubarray(String[] array) {5        // 字母记 +1、数字记 -1：两个相等的前缀和之间，字母数 == 数字数6        Map<Integer, Integer> first = new HashMap<>();   // 前缀和 -> 最早出现下标7        first.put(0, -1);8        int sum = 0, bestLen = 0, bestL = 0;9        for (int i = 0; i < array.length; i++) {10            sum += isNum(array[i]) ? -1 : 1;11            Integer j = first.get(sum);                  // 最早的同前缀和下标12            if (j == null) first.put(sum, i);13            else if (i - j > bestLen) { bestLen = i - j; bestL = j + 1; }14        }15        return Arrays.copyOfRange(array, bestL, bestL + bestLen);16    }17 18    // 元素是非空的纯数字串就当数字，其余都当字母19    private boolean isNum(String s) {20        if (s.isEmpty()) return false;21        for (int i = 0; i < s.length(); i++) if (!Character.isDigit(s.charAt(i))) return false;22        return true;23    }24}
题目

给定一个放有字母和数字的数组，找到最长的子数组，且包含的字母和数字的个数相同。

返回该子数组，若存在多个最长子数组，返回左端点下标值最小的子数组。若不存在这样的数组，返回一个空数组。

示例 1：

输入：["A","1","B","C","D","2","3","4","E","5","F","G","6","7","H","I","J","K","L","M"]

输出：["A","1","B","C","D","2","3","4","E","5","F","G","6","7"]

示例 2：

输入：["A","A"]

输出：[]

提示：

  • array.length <= 100000
