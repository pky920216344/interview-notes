135. 分发糖果

  • 困难
  • 频度 45
  • 贪心
  • 贪心
  • 数组
  • 力扣已通过

两次遍历：左→右满足「比左邻大就多一颗」，右→左满足「比右邻大就至少多一颗」，逐位取 max。

思路

  • 约束只有相邻比较，拆成两个单向规则分别满足：先左→右扫，升坡在前一位基础上 +1，否则发 1 颗。
  • 再右→左扫：ratings[i] > ratings[i+1] 的位置取 max(c[i], c[i+1]+1)——取 max 才不会破坏左→右已满足的约束。
  • 相邻评分相等时没有任何约束，双方都是 1 颗即可。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int candy(int[] ratings) {3        // 两个方向的相邻约束分开满足，再逐位取更严的那个4        int n = ratings.length;5        int[] c = new int[n];6        c[0] = 1;7        for (int i = 1; i < n; i++) {8            // 左→右：比左边大就在左边基础上 +1，否则重新发 1 颗9            c[i] = ratings[i] > ratings[i - 1] ? c[i - 1] + 1 : 1;10        }11        int sum = c[n - 1];12        for (int i = n - 2; i >= 0; i--) {13            // 右→左：比右边大就至少多一颗，取 max 兼顾左边的约束14            if (ratings[i] > ratings[i + 1]) c[i] = Math.max(c[i], c[i + 1] + 1);15            sum += c[i];16        }17        return sum;18    }19}
题目

n 个孩子站成一排。

给你一个整数数组 ratings 表示每个孩子的评分。

你需要按照以下要求，给这些孩子分发糖果：

  • 每个孩子 至少 分配到 1 个糖果。
  • 相邻两个孩子中，评分 更高 的那个会获得更多的糖果。

请你给每个孩子分发糖果，计算并返回需要准备的 最少 糖果数目。

示例 1：

输入：ratings = [1,0,2]
输出：5
解释：你可以分别给第一个、第二个、第三个孩子分发 2、1、2 颗糖果。

示例 2：

输入：ratings = [1,2,2]
输出：4
解释：你可以分别给第一个、第二个、第三个孩子分发 1、2、1 颗糖果。
     第三个孩子只得到 1 颗糖果，这满足题面中的两个条件。

提示：

  • 1 <= n == ratings.length <= 5 * 104
  • 0 <= ratings[i] <= 5 * 104
