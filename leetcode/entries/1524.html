1524. 和为奇数的子数组数目

前缀和只记奇偶：子数组 (l, r] 为奇和 ⟺ 两端前缀奇偶不同，边扫边数配对数。

思路

  • 空前缀算「偶」，cnt[0] 从 1 起——它让从下标 0 开头的子数组也能被配上。
  • 读到 x 后前缀奇偶 par 翻转与否由 x 的奇偶决定；以当前点为右端点的奇和子数组个数 = cnt[par 异或 1]。
  • 每步累加后取模，ans 用 long 防溢出（裸计数可达 5×10⁹）。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int numOfSubarrays(int[] arr) {3        final int MOD = 1_000_000_007;4        // cnt[0/1]：左边前缀和为偶/奇的个数，空前缀算偶，所以 cnt[0] 从 1 起5        int[] cnt = {1, 0};6        long ans = 0;7        int par = 0;   // 当前前缀和的奇偶8        for (int x : arr) {9            par ^= x & 1;10            // 子数组 (l, r] 和为奇 ⟺ 两端前缀奇偶不同，配上奇偶相反的左端点11            ans = (ans + cnt[par ^ 1]) % MOD;12            cnt[par]++;13        }14        return (int) ans;15    }16}
题目

给你一个整数数组 arr 。请你返回和为 奇数 的子数组数目。

由于答案可能会很大，请你将结果对 10^9 + 7 取余后返回。

示例 1：

输入：arr = [1,3,5]
输出：4
解释：所有的子数组为 [[1],[1,3],[1,3,5],[3],[3,5],[5]] 。
所有子数组的和为 [1,4,9,3,8,5].
奇数和包括 [1,9,3,5] ，所以答案为 4 。

示例 2 ：

输入：arr = [2,4,6]
输出：0
解释：所有子数组为 [[2],[2,4],[2,4,6],[4],[4,6],[6]] 。
所有子数组和为 [2,6,12,4,10,6] 。
所有子数组和都是偶数，所以答案为 0 。

示例 3：

输入：arr = [1,2,3,4,5,6,7]
输出：16

示例 4：

输入：arr = [100,100,99,99]
输出：4

示例 5：

输入：arr = [7]
输出：1

提示：

  • 1 <= arr.length <= 10^5
  • 1 <= arr[i] <= 100
