92. 反转链表 II

  • 中等
  • 频度 271
  • 链表
  • 链表
  • 力扣已通过

哨兵 + 头插法：先找到区间前一个结点 pre，再把区间里的结点依次摘下来插到 pre 后面，一次遍历。

思路

  • 哨兵 dummy 接在表头前，left = 1（要换表头）时 pre 也存在，不用特判。
  • pre 走到区间前一个结点；cur = pre.next 是区间第一个结点，循环里它不动，最后沉到区间末尾。
  • 循环 right - left 次，每次把 cur 后面的结点 next 摘下来，头插到 pre 后面：cur.next = next.next、next.next = pre.next、pre.next = next。
  • next.next = pre.next 不能写成 next.next = cur：第一轮碰巧相等，第二轮起就错了。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public ListNode reverseBetween(ListNode head, int left, int right) {3        // 哨兵：left 为 1 时，区间前也有结点4        ListNode dummy = new ListNode(0, head);5        ListNode pre = dummy;6        // pre 走到区间前一个结点7        for (int i = 1; i < left; i++) pre = pre.next;8        // cur 是区间第一个结点，反转后沉到末尾9        ListNode cur = pre.next;10        for (int i = left; i < right; i++) {11            // 摘下 cur 后面的结点，头插到 pre 后面12            ListNode next = cur.next;13            cur.next = next.next;14            next.next = pre.next;15            pre.next = next;16        }17        return dummy.next;18    }19}
题目
给你单链表的头指针 head 和两个整数 left 和 right ，其中 left <= right 。请你反转从位置 left 到位置 right 的链表节点，返回 反转后的链表 。

示例 1：

输入：head = [1,2,3,4,5], left = 2, right = 4
输出：[1,4,3,2,5]

示例 2：

输入：head = [5], left = 1, right = 1
输出：[5]

提示：

  • 链表中节点数目为 n
  • 1 <= n <= 500
  • -500 <= Node.val <= 500
  • 1 <= left <= right <= n
