归并排序时顺手统计：合并两段时右段先出队，左段剩下的都更大，一口气加 mid-i+1 个逆序对。

思路

  • 逆序对只在「合并两个有序段」时跨段产生：右段出一个元素，左段 [i..mid] 就都比它大，一次加 mid-i+1 个。
  • 递归分别统计左右段内部的逆序对，再加合并时跨段的个数。
  • 相等（a[i] <= a[j]）不算逆序对，此时左段先出队。
  • temp 辅助数组只开一次复用。

时间复杂度 O(n log n)，空间复杂度 O(n)
1class Solution {2    public int reversePairs(int[] record) {3        // temp 只开一次，归并时复用4        int[] temp = new int[record.length];5        return (int) mergeSort(record, temp, 0, record.length - 1);6    }7 8    /** 把 a[l..r] 排好序，返回这段区间里的逆序对个数。 */9    private long mergeSort(int[] a, int[] temp, int l, int r) {10        if (l >= r) return 0;11        int mid = (l + r) >>> 1;12        // 左、右两半内部的逆序对先各自统计13        long cnt = mergeSort(a, temp, l, mid) + mergeSort(a, temp, mid + 1, r);14        int i = l, j = mid + 1, k = l;15        while (i <= mid && j <= r) {16            if (a[i] <= a[j]) temp[k++] = a[i++];17            else {18                // 右边先出队：a[i..mid] 全都比 a[j] 大，一口气记 mid-i+1 个19                cnt += mid - i + 1;20                temp[k++] = a[j++];21            }22        }23        while (i <= mid) temp[k++] = a[i++];24        while (j <= r) temp[k++] = a[j++];25        System.arraycopy(temp, l, a, l, r - l + 1);26        return cnt;27    }28}
题目

在股票交易中，如果前一天的股价高于后一天的股价，则可以认为存在一个「交易逆序对」。请设计一个程序，输入一段时间内的股票交易记录 record，返回其中存在的「交易逆序对」总数。

示例 1：

输入：record = [9, 7, 5, 4, 6]
输出：8
解释：交易中的逆序对为 (9, 7), (9, 5), (9, 4), (9, 6), (7, 5), (7, 4), (7, 6), (5, 4)。

提示：

0 <= record.length <= 50000
