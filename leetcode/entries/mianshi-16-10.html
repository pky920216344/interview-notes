面试题 16.10. 生存人数

  • 中等
  • 频度 1
  • 前缀和/差分
  • 数组
  • 计数
  • 待提交

差分数组：出生年 +1、死亡次年 −1，前缀和从 1900 扫到 2000，取最大且并列取最小年份。

思路

  • 人生存区间是 [birth, death] 闭区间：题面明确「生于 1908、死于 1909 计入两年」，死亡当年还算活着。
  • 差分只在出生年 +1、死亡次年 −1；前缀和扫一遍，每格就是该年活着的人数。
  • 死亡在 2000 年以后的 −1 落在扫描窗口外，不减也不影响结果（2000 年后没有出生，人数只会变少）。
  • 更新答案用严格大于 cur > best：并列时自然保留最早的年份。

图解

最优解

时间复杂度 O(n + 101)，空间复杂度 O(101)
1class Solution {2    public int maxAliveYear(int[] birth, int[] death) {3        // 差分：出生年 +1；死亡当年人还在（题面：任意时期存活即计入），-1 放到死亡次年4        int[] delta = new int[102];   // 下标 0..101 对应年份 1900..20015        for (int i = 0; i < birth.length; i++) {6            delta[birth[i] - 1900]++;7            if (death[i] < 2000) delta[death[i] + 1 - 1900]--;   // 2000 之后扫不到，减不减一样8        }9        int cur = 0, best = 0, ans = 1900;10        for (int y = 1900; y <= 2000; y++) {11            cur += delta[y - 1900];12            if (cur > best) {           // 严格大于：并列时保留最早（最小）的年份13                best = cur;14                ans = y;15            }16        }17        return ans;18    }19}
题目

给定 N 个人的出生年份和死亡年份，第 i 个人的出生年份为 birth[i]，死亡年份为 death[i]，实现一个方法以计算生存人数最多的年份。

你可以假设所有人都出生于 1900 年至 2000 年（含 1900 和 2000 ）之间。如果一个人在某一年的任意时期处于生存状态，那么他应该被纳入那一年的统计中。例如，生于 1908 年、死于 1909 年的人应当被列入 1908 年和 1909 年的计数。

如果有多个年份生存人数相同且均为最大值，输出其中最小的年份。

示例：

输入：
birth = [1900, 1901, 1950]
death = [1948, 1951, 2000]
输出： 1901

提示：

  • 0 < birth.length == death.length <= 10000
  • birth[i] <= death[i]
