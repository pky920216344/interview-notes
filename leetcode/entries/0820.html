把每个词反转后排序：互为后缀的词反转后互为前缀、必相邻，扫一遍只给「没被后一个词前缀覆盖」的词付词长+1。

思路

  • 关键转化：me 是 time 的后缀 ⇔ 反转后 em 是 emit 的前缀；排序把前缀关系变成相邻关系。
  • 排序后扫一遍：若 rev[i+1] 以 rev[i] 开头，rev[i] 被 rev[i+1] 捎带（原词藏在它的 # 前），跳过不计。
  • 没被覆盖的词各付 词长 + 1（结尾必须有 #）；重复词排序后相邻，同样只付一次。

最优解

时间复杂度 O(n·L log n)（L 为词长），空间复杂度 O(n·L)
1import java.util.Arrays;2 3class Solution {4    public int minimumLengthEncoding(String[] words) {5        int n = words.length;6        // 反转每个词：原来互为后缀的词，反转后变成互为前缀7        String[] rev = new String[n];8        for (int i = 0; i < n; i++) rev[i] = new StringBuilder(words[i]).reverse().toString();9        Arrays.sort(rev);10        int total = 0;11        for (int i = 0; i < n; i++) {12            // 排在后面的词若以当前词开头，当前词就是它的后缀，被免费捎带13            if (i + 1 < n && rev[i + 1].startsWith(rev[i])) continue;14            total += rev[i].length() + 1;   // 词长 + 结尾的 '#'15        }16        return total;17    }18}
题目

单词数组 words 的 有效编码 由任意助记字符串 s 和下标数组 indices 组成，且满足：

  • words.length == indices.length
  • 助记字符串 s 以 '#' 字符结尾
  • 对于每个下标 indices[i] ，s 的一个从 indices[i] 开始、到下一个 '#' 字符结束（但不包括 '#'）的 子字符串 恰好与 words[i] 相等

给你一个单词数组 words ，返回成功对 words 进行编码的最小助记字符串 s 的长度 。

示例 1：

输入：words = ["time", "me", "bell"]
输出：10
解释：一组有效编码为 s = "time#bell#" 和 indices = [0, 2, 5] 。
words[0] = "time" ，s 开始于 indices[0] = 0 到下一个 '#' 结束的子字符串，如加粗部分所示 "time#bell#"
words[1] = "me" ，s 开始于 indices[1] = 2 到下一个 '#' 结束的子字符串，如加粗部分所示 "time#bell#"
words[2] = "bell" ，s 开始于 indices[2] = 5 到下一个 '#' 结束的子字符串，如加粗部分所示 "time#bell#"

示例 2：

输入：words = ["t"]
输出：2
解释：一组有效编码为 s = "t#" 和 indices = [0] 。

提示：

  • 1 <= words.length <= 2000
  • 1 <= words[i].length <= 7
  • words[i] 仅由小写字母组成
