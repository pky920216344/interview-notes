有序数组取中点当根：左右两半结点数最多差 1，递归建出的 BST 自动高度最小。

思路

  • 要高度最小，就要左右子树的结点数尽量均衡：取中点当根，左半建左子树、右半建右子树。
  • (lo + hi) >>> 1 取中点偏左，子数组规模最多差 1；递归到 lo > hi 返回 null。
  • 有序数组天然满足「左 < 根 < 右」，不用再判断 BST 性质。
  • 建出的树高正好是下界 ceil(log2(n+1))，即最小高度。

最优解

时间复杂度 O(n)，空间复杂度 O(log n)（递归栈）
1class Solution {2    public TreeNode sortedArrayToBST(int[] nums) {3        return build(nums, 0, nums.length - 1);4    }5 6    // 把有序段 nums[lo..hi] 建成最矮 BST，返回根7    private TreeNode build(int[] nums, int lo, int hi) {8        if (lo > hi) return null;9        int mid = (lo + hi) >>> 1;   // 中点当根：左右两半结点数最多差 110        TreeNode root = new TreeNode(nums[mid]);11        root.left = build(nums, lo, mid - 1);12        root.right = build(nums, mid + 1, hi);13        return root;14    }15}
题目

给定一个有序整数数组，元素各不相同且按升序排列，编写一个算法，创建一棵高度最小的二叉搜索树。

示例： 
给定有序数组: [-10,-3,0,5,9],

一个可能的答案是：[0,-3,9,-10,null,5]，它可以表示下面这个高度平衡二叉搜索树：

          0 
         / \ 
       -3   9 
       /   / 
     -10  5
