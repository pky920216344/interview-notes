371. 两整数之和

  • 简单
  • 频度 1
  • 位运算
  • 位运算
  • 数学
  • 待提交

位运算加法：异或结果当无进位和，与再左移一位当进位，反复相加直到进位为 0。

思路

  • 二进制加法拆成两步：a ^ b 是按位求和但丢掉进位；(a & b) << 1 恰好是进位，两边同为 1 的位向左进一位。
  • 把这两个结果再当成两个加数重复上面的步骤，直到进位为 0，此时的无进位和就是答案。
  • Java 的 int 移位自动回绕，补码负数同样成立，进位不断左移迟早变 0，循环必然终止。

1class Solution {2    public int getSum(int a, int b) {3        // a 当「无进位和」，b 当「进位」；进位为 0 时 a 就是答案4        while (b != 0) {5            int carry = (a & b) << 1;   // 两边都是 1 的位，向左进一位6            a = a ^ b;                  // 异或：不带进位的和7            b = carry;8        }9        return a;10    }11}
题目

给你两个整数 a 和 b ，不使用 运算符 + 和 - ​​​​​​​，计算并返回两整数之和。

示例 1：

输入：a = 1, b = 2
输出：3

示例 2：

输入：a = 2, b = 3
输出：5

提示：

  • -1000 <= a, b <= 1000
