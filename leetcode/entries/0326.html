326. 3 的幂

不断除以 3：能一路整除到 1 的才是 3 的幂，负数和 0 直接排除。

思路

  • n ≤ 0 直接 false；1 是 3⁰，要返回 true。
  • 只要 n % 3 == 0 就 n /= 3，把因子 3 全部除掉。
  • 除完后剩 1 才是 3 的幂；像 45 → 15 → 5 这样剩下别的数就不是。

题目

给定一个整数，写一个函数来判断它是否是 3 的幂次方。如果是，返回 true ；否则，返回 false 。

整数 n 是 3 的幂次方需满足：存在整数 x 使得 n == 3x

示例 1：

输入：n = 27
输出：true

示例 2：

输入：n = 0
输出：false

示例 3：

输入：n = 9
输出：true

示例 4：

输入：n = 45
输出：false

提示：

  • -231 <= n <= 231 - 1
