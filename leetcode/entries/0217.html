217. 存在重复元素

  • 简单
  • 频度 4
  • 哈希表
  • 数组
  • 哈希表
  • 排序
  • 待提交

哈希集合边放边查：每个数字放入前先看在不在集合里，在就是重复，一遍扫完。

思路

  • HashSet.add(x) 的返回值就是「x 原来不在集合里」——返回 false 即撞见重复，直接 return true。
  • 扫完都没撞上，说明所有元素互不相同，返回 false。
  • 先 contains 再 add 是两次查询，add 的返回值一次搞定。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public boolean containsDuplicate(int[] nums) {5        Set<Integer> seen = new HashSet<>();6        for (int x : nums) {7            // add 返回 false 说明 x 已经在集合里：撞见重复8            if (!seen.add(x)) return true;9        }10        return false;11    }12}
题目
给你一个整数数组 nums 。如果任一值在数组中出现 至少两次 ，返回 true ；如果数组中每个元素互不相同，返回 false 。

示例 1：

输入：nums = [1,2,3,1]

输出：true

解释：

元素 1 在下标 0 和 3 出现。

示例 2：

输入：nums = [1,2,3,4]

输出：false

解释：

所有元素都不同。

示例 3：

输入：nums = [1,1,1,3,3,4,3,2,4,2]

输出：true

提示：

  • 1 <= nums.length <= 105
  • -109 <= nums[i] <= 109
