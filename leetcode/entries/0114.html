前序原地展开：每个结点把左子树最右结点接上自己的右子树，再把左子树整体搬到右边，沿右链前进。

思路

  • 前序 = 根 → 左子树全部 → 右子树全部：左子树的最右结点恰好排在右子树所有结点之前。
  • 对每个 curr：找到左子树最右结点 last，last.right = curr.right 接上原右子树，再 curr.right = curr.left、curr.left = null。
  • curr 沿右链前进即可——右边永远挂着还没处理的部分，不用栈，O(1) 空间。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public void flatten(TreeNode root) {3        // 沿右链走：把每个结点的左子树搬到右子树前面4        TreeNode curr = root;5        while (curr != null) {6            if (curr.left != null) {7                // 左子树的最右结点：前序里它排在本层右子树全部结点之前8                TreeNode last = curr.left;9                while (last.right != null) last = last.right;10                // 原右子树接到它后面，左子树整体搬到右边11                last.right = curr.right;12                curr.right = curr.left;13                curr.left = null;14            }15            // 左边已空，往右走一步就是前序的下一个16            curr = curr.right;17        }18    }19}
题目

给你二叉树的根结点 root ，请你将它展开为一个单链表：

  • 展开后的单链表应该同样使用 TreeNode ，其中 right 子指针指向链表中下一个结点，而左子指针始终为 null 。
  • 展开后的单链表应该与二叉树 先序遍历 顺序相同。

示例 1：

输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]

示例 2：

输入：root = []
输出：[]

示例 3：

输入：root = [0]
输出：[0]

提示：

  • 树中结点数在范围 [0, 2000] 内
  • -100 <= Node.val <= 100
