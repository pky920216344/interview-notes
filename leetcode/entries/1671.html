1671. 得到山形数组的最少删除次数

山形 = 一个峰：从左扫最长严格递增 up、从右扫最长严格递减 down，答案 = n − max(up[i]+down[i]−1)。

思路

  • 保留的山形数组由「峰」决定：以 i 为峰时最多保留 up[i] + down[i] − 1 个（峰被两侧各算一次，减 1）。
  • up[i]：以 i 结尾的最长严格递增；down[i]：以 i 开头的最长严格递减——把数组反转后就是同一遍 LIS。
  • LIS 用贪心 tails + 二分做到 O(n log n)；两侧各扫一遍。
  • 峰两侧都必须非空（up[i] ≥ 2 且 down[i] ≥ 2），否则不是山形；答案 = n − 最长山形。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1class Solution {2    public int minimumMountainRemovals(int[] nums) {3        int n = nums.length;4        int[] up = lis(nums);5        int[] rev = new int[n];6        for (int i = 0; i < n; i++) rev[i] = nums[n - 1 - i];7        int[] down = lis(rev);8        int best = 0;9        for (int i = 0; i < n; i++) {10            int l = up[i], r = down[n - 1 - i];11            // 峰两侧都至少要有一个元素，才称得上山形12            if (l >= 2 && r >= 2) best = Math.max(best, l + r - 1);13        }14        return n - best;15    }16 17    // ends[i]：以 a[i] 结尾的最长严格递增子序列长度（贪心 tails + 二分）18    private int[] lis(int[] a) {19        int[] tails = new int[a.length];20        int[] ends = new int[a.length];21        int len = 0;22        for (int i = 0; i < a.length; i++) {23            int lo = 0, hi = len;24            while (lo < hi) {25                int mid = (lo + hi) >>> 1;26                if (tails[mid] < a[i]) lo = mid + 1; else hi = mid;27            }28            ends[i] = lo + 1;29            tails[lo] = a[i];30            if (lo == len) len++;31        }32        return ends;33    }34}
题目

我们定义 arr 是 山形数组 当且仅当它满足：

  • arr.length >= 3
  • 存在某个下标 i （从 0 开始） 满足 0 < i < arr.length - 1 且：
    • arr[0] < arr[1] < ... < arr[i - 1] < arr[i]
    • arr[i] > arr[i + 1] > ... > arr[arr.length - 1]

给你整数数组 nums​ ，请你返回将 nums 变成 山形状数组 的​ 最少 删除次数。

示例 1：

输入：nums = [1,3,1]
输出：0
解释：数组本身就是山形数组，所以我们不需要删除任何元素。

示例 2：

输入：nums = [2,1,1,5,6,2,3,1]
输出：3
解释：一种方法是将下标为 0，1 和 5 的元素删除，剩余元素为 [1,5,6,3,1] ，是山形数组。

提示：

  • 3 <= nums.length <= 1000
  • 1 <= nums[i] <= 109
  • 题目保证 nums 删除一些元素后一定能得到山形数组。
