727. 最小窗口子序列

  • 困难
  • 频度 2
  • 双指针
  • 贪心
  • 字符串
  • 动态规划
  • 滑动窗口
  • 未经力扣验证

右端贪心扫 s 跟住 t，t 匹配完就从终点回缩找最晚起点，得到该终点的最短窗口；记录最优后从起点+1 重新起配。

思路

  • j 是 t 里下一个要匹配的下标：s[i]==t[j] 才 j++——贪心保证第一次凑满的位置是最早的终点。
  • 凑满后从终点往回走，p 从 t 尾往前双边同时回退：每段 t 字符都尽量靠右对上 → 找到结束在这点的最短窗口。
  • 记录后从窗口起点重新起配（i = start, j = 0，循环再 i++）：更短的窗口只会结束在更右边。
  • 整个过程每个字符只被少数几遍扫描；没有任何合法窗口时返回 ""。

时间复杂度 O(n·m) 最坏，通常近似 O(n)，空间复杂度 O(1)
1class Solution {2    public String minWindow(String s, String t) {3        int n = s.length(), m = t.length();4        int bestL = -1, bestLen = n + 1;5        int i = 0, j = 0;   // i 扫 s；j 是 t 里下一个要匹配的下标6        while (i < n) {7            if (s.charAt(i) == t.charAt(j)) {8                j++;9                if (j == m) {              // t 在 i 处匹配完：回缩找最晚（最短）的起点10                    int end = i;11                    int p = m - 1;12                    while (p >= 0) {       // 从 t 尾往前贪心回配，起点尽量靠右13                        if (s.charAt(i) == t.charAt(p)) p--;14                        i--;15                    }16                    int start = i + 1;17                    if (end - start + 1 < bestLen) { bestLen = end - start + 1; bestL = start; }18                    i = start;             // 从窗口起点重新起配（循环末尾 i++ 落到 start+1）19                    j = 0;20                }21            }22            i++;23        }24        return bestL < 0 ? "" : s.substring(bestL, bestL + bestLen);25    }26}
