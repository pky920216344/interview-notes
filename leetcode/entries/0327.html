前缀和转成「数 pre[j]−pre[i] 落在 [lower,upper] 的对数」，归并排序合并前用两指针窗口对每个左半值数右半。

思路

  • 区间和 S(i,j) = pre[j+1] − pre[i]；问题变成：前缀和数组里数下标对 (i<j) 使差落在 [lower, upper]。
  • 归并排序：递归数完两半内部，合并前两半各自有序——左半值增大时，右半的合法窗口 [pre[i]+lower, pre[i]+upper] 只会右移，双指针 O(n) 数完跨半区的对。
  • 前缀和必须用 long：nums[i] 可达 ±2³¹，相加会溢出 int；答案由题面保证在 int 内。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1class Solution {2    private long[] tmp;3    private long lower, upper;4 5    public int countRangeSum(int[] nums, int lower, int upper) {6        int n = nums.length;7        // 区间和 S(i,j) = pre[j+1] − pre[i]：问题变成数「前缀和数组里 pre[j]−pre[i] 落在区间内」的对数8        long[] pre = new long[n + 1];9        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + nums[i];10        this.lower = lower;11        this.upper = upper;12        tmp = new long[n + 1];13        return (int) sort(pre, 0, n);14    }15 16    // 对 pre[lo..hi] 归并排序，返回其中下标对 (i<j) 满足 pre[j]−pre[i] ∈ [lower, upper] 的个数17    private long sort(long[] a, int lo, int hi) {18        if (lo >= hi) return 0;19        int mid = (lo + hi) >>> 1;20        long cnt = sort(a, lo, mid) + sort(a, mid + 1, hi);21        // 两半各自有序：左半值增大时，右半的合法窗口 [p, q) 只会整体右移22        int p = mid + 1, q = mid + 1;23        for (int i = lo; i <= mid; i++) {24            while (p <= hi && a[p] - a[i] < lower) p++;25            while (q <= hi && a[q] - a[i] <= upper) q++;26            cnt += q - p;27        }28        // 标准归并：借助 tmp 合并两半29        int i = lo, j = mid + 1, w = lo;30        System.arraycopy(a, lo, tmp, lo, hi - lo + 1);31        while (i <= mid && j <= hi) a[w++] = tmp[i] <= tmp[j] ? tmp[i++] : tmp[j++];32        while (i <= mid) a[w++] = tmp[i++];33        while (j <= hi) a[w++] = tmp[j++];34        return cnt;35    }36}
题目

给你一个整数数组 nums 以及两个整数 lower 和 upper 。求数组中，值位于范围 [lower, upper] （包含 lower 和 upper）之内的 区间和的个数 。

区间和 S(i, j) 表示在 nums 中，位置从 i 到 j 的元素之和，包含 i 和 j (i ≤ j)。

示例 1： 
输入：nums = [-2,5,-1], lower = -2, upper = 2
输出：3
解释：存在三个区间：[0,0]、[2,2] 和 [0,2] ，对应的区间和分别是：-2 、-1 、2 。

示例 2：

输入：nums = [0], lower = 0, upper = 0
输出：1

提示：

  • 1 <= nums.length <= 105
  • -231 <= nums[i] <= 231 - 1
  • -105 <= lower <= upper <= 105
  • 题目数据保证答案是一个 32 位 的整数
