754. 到达终点数字

  • 中等
  • 频度 2
  • 数学
  • 数学
  • 二分查找
  • 待提交

数学：一直往右走 1,2,3,… 直到 sum 首次 ≥ |target| 且 sum − |target| 是偶数；差是奇数就再走一步，答案就是步数 k。

思路

  • 到 -target 和到 target 的最少步数相同，先取 |target|。
  • 一直往右走 1+2+…+k，首个 sum ≥ t 且 sum − t 为偶数的 k 即答案：翻转某一步的方向只让总和减少偶数，所以差必须是偶数才收得了。
  • 差 = 2d 时把第 d 步反向即可精确落在 t（d ≤ k 恒成立）；差是奇数就再走一步，每多走一步差奇偶性翻转，最多再走两步。
  • sum 会到 10^9 量级，用 long 防溢出。

最优解

时间复杂度 O(√|target|)，空间复杂度 O(1)
1class Solution {2    public int reachNumber(int target) {3        // 左右对称，只看 |target|4        long t = Math.abs((long) target);5        long sum = 0;   // 一直往右走 k 步能到的位置：1+2+…+k6        int k = 0;7        // sum 不够 target，或者超出的部分是奇数（没法靠翻转一步抵消），就再多走一步8        while (sum < t || (sum - t) % 2 != 0) {9            k++;10            sum += k;11        }12        return k;13    }14}
题目

在一根无限长的数轴上，你站在0的位置。终点在target的位置。

你可以做一些数量的移动 numMoves :

  • 每次你可以选择向左或向右移动。
  • 第 i 次移动（从  i == 1 开始，到 i == numMoves ），在选择的方向上走 i 步。

给定整数 target ，返回 到达目标所需的 最小 移动次数(即最小 numMoves ) 。

示例 1:

输入: target = 2
输出: 3
解释:
第一次移动，从 0 到 1 。
第二次移动，从 1 到 -1 。
第三次移动，从 -1 到 2 。

示例 2:

输入: target = 3
输出: 2
解释:
第一次移动，从 0 到 1 。
第二次移动，从 1 到 3 。

提示:

  • -109 <= target <= 109
  • target != 0
