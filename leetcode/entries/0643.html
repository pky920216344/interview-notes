643. 子数组最大平均数 I

  • 简单
  • 频度 1
  • 滑动窗口
  • 数组
  • 滑动窗口
  • 待提交

定长滑窗滚动和：先算首个窗口的和，之后每步「进一个、出一个」，最后除以 k。

思路

  • 平均数最大 ⟺ 窗口和最大，长度固定为 k，只需维护窗口和。
  • 先累加前 k 个得 sum；此后每右移一格：sum += nums[i] - nums[i-k]，避免重复求和。
  • 用 long 存和防溢出（10^5 × 10^4 = 10^9 虽在 int 内，留余量更稳），答案 (double) best / k。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public double findMaxAverage(int[] nums, int k) {3        long sum = 0;4        for (int i = 0; i < k; i++) sum += nums[i];   // 先算第一个窗口的和5        long best = sum;6        for (int i = k; i < nums.length; i++) {7            sum += nums[i] - nums[i - k];   // 右边进一格、左边出一格，O(1) 滚动更新8            best = Math.max(best, sum);9        }10        return (double) best / k;11    }12}
题目

给你一个由 n 个元素组成的整数数组 nums 和一个整数 k 。

请你找出平均数最大且 长度为 k 的连续子数组，并输出该最大平均数。

任何误差小于 10-5 的答案都将被视为正确答案。

示例 1：

输入：nums = [1,12,-5,-6,50,3], k = 4
输出：12.75
解释：最大平均数 (12-5-6+50)/4 = 51/4 = 12.75

示例 2：

输入：nums = [5], k = 1
输出：5.00000

提示：

  • n == nums.length
  • 1 <= k <= n <= 105
  • -104 <= nums[i] <= 104
