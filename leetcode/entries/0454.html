分两组：A+B 的所有和先哈希计数，再对每个 C+D 的和 s 查 -s 出现几次，累加出全部组合数。

思路

  • 四个数分两组两两求和：A+B 的和最多 n² 种，先 O(n²) 全部数进哈希表 cnt。
  • 对 C+D 的每个和 s，答案加上 cnt[-s]——四数之和为 0 当且仅当表里有 -s。
  • 同一个和出现多次要累加次数（merge），表里没有就用 getOrDefault 兜 0，别让缺键中断。
  • 不需要考虑下标去重：(i,j,k,l) 只要四数和为 0 就是一个合法元组，直接累加即可。

最优解

时间复杂度 O(n²)，空间复杂度 O(n²)
1import java.util.*;2 3class Solution {4    public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {5        // 先把 A+B 的每种和出现多少次数进哈希表6        Map<Integer, Integer> cnt = new HashMap<>();7        for (int a : nums1) {8            for (int b : nums2) {9                cnt.merge(a + b, 1, Integer::sum);10            }11        }12        int ans = 0;13        // C+D 每得到一个和 s，就凑出 cnt 中 -s 那么多组答案14        for (int c : nums3) {15            for (int d : nums4) {16                ans += cnt.getOrDefault(-(c + d), 0);17            }18        }19        return ans;20    }21}
题目

给你四个整数数组 nums1、nums2、nums3 和 nums4 ，数组长度都是 n ，请你计算有多少个元组 (i, j, k, l) 能满足：

  • 0 <= i, j, k, l < n
  • nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0

示例 1：

输入：nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
输出：2
解释：
两个元组如下：
1. (0, 0, 0, 1) -> nums1[0] + nums2[0] + nums3[0] + nums4[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> nums1[1] + nums2[1] + nums3[0] + nums4[0] = 2 + (-1) + (-1) + 0 = 0

示例 2：

输入：nums1 = [0], nums2 = [0], nums3 = [0], nums4 = [0]
输出：1

  提示：

  • n == nums1.length
  • n == nums2.length
  • n == nums3.length
  • n == nums4.length
  • 1 <= n <= 200
  • -228 <= nums1[i], nums2[i], nums3[i], nums4[i] <= 228
