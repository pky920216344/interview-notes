单调栈：新数更小就弹栈顶换成它，但弹出前必须确认「剩下的数还够凑满 k 个」；栈满后小的照样能弹。

思路

  • 栈里维护「目前最优的开头」，遇到更小的 nums[i] 就把更大的栈顶弹掉，答案字典序更小。
  • 弹出条件 top + n - i >= k：弹掉后栈里剩 top 个，加上还未读的 n-i 个仍能凑满 k，才允许弹。
  • 栈满 k 个后不再入栈，但遇到更小的数仍可先弹再补；最后栈里正好是答案。

最优解

时间复杂度 O(n)，空间复杂度 O(k)
1class Solution {2    public int[] mostCompetitive(int[] nums, int k) {3        int n = nums.length;4        int[] stack = new int[k];   // 数组当栈，最后正好就是答案5        int top = -1;6        for (int i = 0; i < n; i++) {7            // 栈顶比当前大就弹它换当前；前提是弹掉后剩下的数仍够凑满 k 个8            while (top >= 0 && stack[top] > nums[i] && top + n - i >= k) top--;9            if (top < k - 1) stack[++top] = nums[i];10        }11        return stack;12    }13}
题目

给你一个整数数组 nums 和一个正整数 k ，返回长度为 k 且最具 竞争力 的 nums 子序列。

数组的子序列是从数组中删除一些元素（可能不删除元素）得到的序列。

在子序列 a 和子序列 b 第一个不相同的位置上，如果 a 中的数字小于 b 中对应的数字，那么我们称子序列 a 比子序列 b（相同长度下）更具 竞争力 。 例如，[1,3,4] 比 [1,3,5] 更具竞争力，在第一个不相同的位置，也就是最后一个位置上， 4 小于 5 。

示例 1：

输入：nums = [3,5,2,6], k = 2
输出：[2,6]
解释：在所有可能的子序列集合 {[3,5], [3,2], [3,6], [5,2], [5,6], [2,6]} 中，[2,6] 最具竞争力。

示例 2：

输入：nums = [2,4,3,3,5,4,9,6], k = 4
输出：[2,3,3,4]

提示：

  • 1 <= nums.length <= 105
  • 0 <= nums[i] <= 109
  • 1 <= k <= nums.length
