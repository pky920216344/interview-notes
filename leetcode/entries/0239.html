239. 滑动窗口最大值

  • 频度 159

  • 单调栈
  • 队列
  • 数组
  • 滑动窗口
  • 单调队列
  • 堆（优先队列）
  • range-minimum-maximum-query
  • 力扣已通过

单调递减双端队列存下标：新数先弹掉不比它大的队尾，滑出窗口的队头也弹掉，队头就是窗口最大值。

思路

  • 队列里存下标，对应的值从队头到队尾递减，所以队头永远是当前窗口的最大值。
  • 新数 nums[i] 进队前，把队尾所有不比它大的下标弹掉：它们又旧又小，不可能再当最大值。
  • 弹完把 i 放到队尾；若队头下标 <= i - k，说明已滑出窗口，弹掉（每步最多滑出一个，用 if 就够）。
  • i >= k - 1 时窗口满了，nums[队头] 就是 ans[i - k + 1]。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(k)
1import java.util.*;2 3class Solution {4    public int[] maxSlidingWindow(int[] nums, int k) {5        int n = nums.length;6        int[] ans = new int[n - k + 1];7        // 存下标，值从队头到队尾递减，8        // 所以队头就是窗口最大值9        Deque<Integer> dq = new ArrayDeque<>();10        for (int i = 0; i < n; i++) {11            // 队尾不比新数大，以后不可能再是最大值12            while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) {13                dq.pollLast();14            }15            dq.offerLast(i);16            // 队头滑出了窗口 [i - k + 1, i]17            if (dq.peekFirst() <= i - k) dq.pollFirst();18            // 窗口满了才有答案19            if (i >= k - 1) ans[i - k + 1] = nums[dq.peekFirst()];20        }21        return ans;22    }23}
题目

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

返回 滑动窗口中的最大值 。

示例 1：

输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7

示例 2：

输入：nums = [1], k = 1
输出：[1]

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104
  • 1 <= k <= nums.length
