689. 三个无重叠子数组的最大和

预扫 left/right 记每侧最优 k 窗口起点，再枚举中间窗口，三段总和取最大。

思路

  • W[i] 是以 i 开头的长度 k 窗口和；left[i] 记 W[0..i] 最大者的起点，right[i] 记 W[i..] 的，各扫一遍。
  • 枚举中间窗口 mid：总和 = W[left[mid-k]] + W[mid] + W[right[mid+k]]，取最大。
  • 并列都取最靠前下标（left、right 并列取早，mid 只在严格更大时更新），答案自动是字典序最小。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] maxSumOfThreeSubarrays(int[] nums, int k) {5        int n = nums.length;6        // W[i]：以 i 开头的长度 k 窗口的和，滑动一遍算出7        long[] W = new long[n - k + 1];8        long sum = 0;9        for (int i = 0; i < n; i++) {10            sum += nums[i];11            if (i >= k) sum -= nums[i - k];12            if (i >= k - 1) W[i - k + 1] = sum;13        }14        // left[i]：W[0..i] 里和最大的窗口起点；right[i]：W[i..] 里的，都取最靠前15        int m = W.length;16        int[] left = new int[m], right = new int[m];17        left[0] = 0;18        for (int i = 1; i < m; i++) left[i] = W[i] > W[left[i - 1]] ? i : left[i - 1];19        right[m - 1] = m - 1;20        for (int i = m - 2; i >= 0; i--) right[i] = W[i] >= W[right[i + 1]] ? i : right[i + 1];21        // 枚举中间窗口：左取 left[mid-k]、右取 right[mid+k]，总和最大即答案22        int[] ans = new int[3];23        long best = -1;24        for (int mid = k; mid <= n - 2 * k; mid++) {25            long total = W[left[mid - k]] + W[mid] + W[right[mid + k]];26            if (total > best) {27                best = total;28                ans[0] = left[mid - k];29                ans[1] = mid;30                ans[2] = right[mid + k];31            }32        }33        return ans;34    }35}
题目

给你一个整数数组 nums 和一个整数 k ，找出三个长度为 k 、互不重叠、且全部数字和最大的子数组，并返回这三个子数组。

以下标的数组形式返回结果，数组中的每一项分别指示每个子数组的起始位置（下标从 0 开始）。如果有多个结果，返回字典序最小的一个。

示例 1：

输入：nums = [1,2,1,2,6,7,5,1], k = 2
输出：[0,3,5]
解释：子数组 [1, 2], [2, 6], [7, 5] 对应的起始下标为 [0, 3, 5]。
也可以取 [2, 1], 但是结果 [1, 3, 5] 在字典序上更大。

示例 2：

输入：nums = [1,2,1,2,1,2,1,2,1], k = 2
输出：[0,2,4]

提示：

  • 1 <= nums.length <= 2 * 104
  • 1 <= nums[i] < 216
  • 1 <= k <= floor(nums.length / 3)
