滑窗 + last[]：读到窗口内已有的字符，left 直接跳到它上次出现位置的下一位。

思路

  • 窗口 [left, right] 保证无重复；last[c] 记 c 上次出现位置 + 1，0 表示没出现过。
  • 读到 c：left = max(left, last[c])，一步跳过重复；必须取 max——旧位置可能在窗口左边界外（如 abba 的第二个 a），直接赋值会让 left 回退。
  • 每扫一格用 right - left + 1 更新最长长度。

最优解

时间复杂度 O(n)，空间复杂度 O(1)（last 是 128 格常数）
1class Solution {2    public int dismantlingAction(String arr) {3        int[] last = new int[128];   // last[c]：字符 c 上次出现位置 + 1，0 表示没出现过4        int ans = 0, left = 0;5        for (int right = 0; right < arr.length(); right++) {6            char c = arr.charAt(right);7            left = Math.max(left, last[c]);   // 重复就跳到上次出现位置的下一位8            last[c] = right + 1;9            ans = Math.max(ans, right - left + 1);10        }11        return ans;12    }13}
题目

某套连招动作记作序列 arr，其中 arr[i] 为第 i 个招式的名字。请返回 arr 中最多可以出连续不重复的多少个招式。

示例 1：

输入：arr = "dbascDdad"
输出：6
解释：因为连续且最长的招式序列是 "dbascD" 或 "bascDd"，所以其长度为 6。

示例 2：

输入：arr = "KKK"
输出：1
解释：因为无重复字符的最长子串是 "K"，所以其长度为 1。

示例 3：

输入：arr = "pwwkew"
输出：3
解释：因为连续且最长的招式序列是 "wke"，所以其长度为 3。     
请注意区分 子串 与 子序列 的概念：你的答案必须是 连续招式 的长度，也就是 子串。而 "pwke" 是一个非连续的 子序列，不是 子串。

提示：

  • 0 <= arr.length <= 40000
  • arr 由英文字母、数字、符号和空格组成。

注意：本题与主站 3 题相同：https://leetcode.cn/problems/longest-substring-without-repeating-characters/
