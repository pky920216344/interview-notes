1650. 二叉树的最近公共祖先 III

  • 中等
  • 频度 1
  • 双指针
  • 树
  • 哈希表
  • 双指针
  • 二叉树
  • lowest-common-ancestor
  • binary-lifting
  • 未经力扣验证

两个指针从 p、q 同时沿 parent 上爬，谁先到根就跳到对方起点接着走；两人路程等长，必在 LCA 相遇。

思路

  • 只有父指针、没有根：最笨的办法是各爬到根记两条链再求交（O(h) 空间）；双指针爬坡把空间降到 O(1)。
  • 关键动作：a = a.parent == null ? q : a.parent——到根就换到对方的起点再爬一遍。
  • 为什么必相遇：a 走的路程 = p 到根 + q 到 LCA；b 走的路程 = q 到根 + p 到 LCA。两段路程相等，且都在 LCA 处「用完」自己的第一段，所以同时踏进 LCA。
  • p 是 q 的祖先（或反过来）时同样成立：先到根的换道补齐路程差，相遇点就是较浅的那个结点。
