438. 找到字符串中所有字母异位词

定长滑窗计数：先装满第一个窗口，之后右进左出各一个字符，26 格计数和 p 相等就是异位词。

思路

  • need[c] 是 p 的字母计数，win[c] 是当前窗口的计数；异位词 ⇔ 两个计数表完全相等。
  • 先把 s[0..m-1] 装进窗口判一次；之后每步 win[s[r]]++、win[s[r-m]]--，增量维护。
  • 每步用 Arrays.equals(win, need) 比较，相等就把起点 r - m + 1 收进答案。
  • s 比 p 短时窗口装不满（计数总和就对不上），不用单独写分支。

时间复杂度 O(26n)，空间复杂度 O(26)
1import java.util.*;2 3class Solution {4    public List<Integer> findAnagrams(String s, String p) {5        List<Integer> ans = new ArrayList<>();6        int m = p.length(), n = s.length();7        int[] need = new int[26], win = new int[26];8        for (int i = 0; i < m; i++) need[p.charAt(i) - 'a']++;9        // 先装满第一个窗口；s 比 p 短时窗口装不满，计数和永远对不上，自然没有命中10        for (int i = 0; i < m && i < n; i++) win[s.charAt(i) - 'a']++;11        if (Arrays.equals(win, need)) ans.add(0);12        // 之后每步右端进一个、左端出一个，计数表和 need 相等就是异位词13        for (int r = m; r < n; r++) {14            win[s.charAt(r) - 'a']++;          // 右端进窗15            win[s.charAt(r - m) - 'a']--;      // 左端出窗16            if (Arrays.equals(win, need)) ans.add(r - m + 1);17        }18        return ans;19    }20}
题目

给定两个字符串 s 和 p，找到 s中所有 p的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

示例 1:

输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

 示例 2:

输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。

提示:

  • 1 <= s.length, p.length <= 3 * 104
  • s 和 p 仅包含小写字母
