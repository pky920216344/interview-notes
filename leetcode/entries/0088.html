88. 合并两个有序数组

  • 简单
  • 频度 305
  • 双指针
  • 数组
  • 双指针
  • 排序
  • 力扣已通过

三指针从后往前放：每次把两个数组末尾较大的那个，放到 nums1 的最后一个空位。

思路

  • i、j 指向 nums1、nums2 有效部分的末尾，k = m + n - 1 指向 nums1 要写入的位置。
  • 必须从后往前放：nums1 末尾是空位，写 k 不会盖掉没比较的数；从前往后放会盖掉。
  • 比较 nums1[i] 和 nums2[j]，大的放进 nums1[k]，对应指针和 k 一起左移；i < 0 时只能取 nums2。
  • 循环条件是 j >= 0：nums2 放完就结束，nums1 剩下的前缀本来就在原位。

最优解

时间复杂度 O(m + n)，空间复杂度 O(1)
1class Solution {2    public void merge(int[] nums1, int m, int[] nums2, int n) {3        // 从后往前放：末尾的空位不会盖掉没比较的数4        int i = m - 1, j = n - 1, k = m + n - 1;5        // nums2 放完即可，nums1 剩下的已就位6        while (j >= 0) {7            // i < 0：nums1 用完，只能取 nums28            if (i >= 0 && nums1[i] > nums2[j]) {9                nums1[k--] = nums1[i--];10            } else {11                nums1[k--] = nums2[j--];12            }13        }14    }15}
题目

给你两个按 非递减顺序 排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n ，分别表示 nums1 和 nums2 中的元素数目。

请你 合并 nums2 到 nums1 中，使合并后的数组同样按 非递减顺序 排列。

注意：最终，合并后数组不应由函数返回，而是存储在数组 nums1 中。为了应对这种情况，nums1 的初始长度为 m + n，其中前 m 个元素表示应合并的元素，后 n 个元素为 0 ，应忽略。nums2 的长度为 n 。

示例 1：

输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
解释：需要合并 [1,2,3] 和 [2,5,6] 。
合并结果是 [1,2,2,3,5,6] ，其中斜体加粗标注的为 nums1 中的元素。

示例 2：

输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
解释：需要合并 [1] 和 [] 。
合并结果是 [1] 。

示例 3：

输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
解释：需要合并的数组是 [] 和 [1] 。
合并结果是 [1] 。
注意，因为 m = 0 ，所以 nums1 中没有元素。nums1 中仅存的 0 仅仅是为了确保合并结果可以顺利存放到 nums1 中。

提示：

  • nums1.length == m + n
  • nums2.length == n
  • 0 <= m, n <= 200
  • 1 <= m + n <= 200
  • -109 <= nums1[i], nums2[j] <= 109
