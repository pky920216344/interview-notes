排序后从大到小，按虚拟索引 (2i+1) % (n|1) 摆放：大数落奇数位、小数落偶数位，相等中位数被隔开。

思路

  • 要 nums[0] < nums[1] > nums[2] < …：奇数位该放大数、偶数位该放小数，各自从大到小摆，峰谷才会「外扩」。
  • 直接按顺序穿插会在相等中位数处翻车（相邻两个一样大）。虚拟索引映射把相等的数隔到同奇偶、间隔 2 的位置上。
  • 映射顺序：位 1,3,5,… 先被大数占满，再回绕到 0,2,4,… 放小数；(n|1) 把 n 强行变奇数，回绕才对齐。
  • 排序即可拿到中位数分界，不必写 O(n) 的快速选择；本题保证输入必有解。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public void wiggleSort(int[] nums) {5        int[] s = nums.clone();6        Arrays.sort(s);7        int n = nums.length;8        // 虚拟索引：把 s 从大到小依次放到 (2*i+1) % (n|1) 号位置——9        // 大于中位数的落在奇数位、小于的落在偶数位；相等的中位数被映射隔开，不会撞在一起10        for (int i = 0; i < n; i++) {11            nums[(2 * i + 1) % (n | 1)] = s[n - 1 - i];12        }13    }14}
题目

给你一个整数数组 nums，将它重新排列成 nums[0] < nums[1] > nums[2] < nums[3]... 的顺序。

你可以假设所有输入数组都可以得到满足题目要求的结果。

示例 1：

输入：nums = [1,5,1,1,6,4]
输出：[1,6,1,5,1,4]
解释：[1,4,1,5,1,6] 同样是符合题目要求的结果，可以被判题程序接受。

示例 2：

输入：nums = [1,3,2,2,3,1]
输出：[2,3,1,3,1,2]

提示：

  • 1 <= nums.length <= 5 * 104
  • 0 <= nums[i] <= 5000
  • 题目数据保证，对于给定的输入 nums ，总能产生满足题目要求的结果
