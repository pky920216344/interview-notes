739. 每日温度

  • 中等
  • 频度 64
  • 单调栈
  • 栈
  • 数组
  • 单调栈
  • 力扣已通过

单调递减栈存「还没等到更暖天」的下标；今天更暖就连续弹栈结算，答案 = i - 栈顶下标。

思路

  • 栈里放下标，从栈底到栈顶温度严格递减：这些天都还没等到答案。
  • 第 i 天更暖时，一路弹栈结算 ans[j] = i - j，弹到栈顶温度不比今天低为止；相等不算更暖。
  • 温度只有更低或相等才入栈，所以栈内温度天然单调递减，ans 初始全 0。
  • 每个下标只入栈、出栈各一次，均摊 O(n)。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int[] dailyTemperatures(int[] temperatures) {3        int n = temperatures.length;4        int[] ans = new int[n];5        // 栈里放「还没等到更暖天」的下标，对应温度从栈底到栈顶递减6        int[] stack = new int[n];7        int top = -1;8        for (int i = 0; i < n; i++) {9            int t = temperatures[i];10            // 今天更暖：栈顶那些天等的答案就是 i - 它的下标11            while (top >= 0 && t > temperatures[stack[top]]) {12                int j = stack[top--];13                ans[j] = i - j;14            }15            stack[++top] = i;16        }17        // 还留在栈里的天等不到更暖天，ans 保持初始的 018        return ans;19    }20}
题目

给定一个整数数组 temperatures ，表示每天的温度，返回一个数组 answer ，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。

示例 1:

输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,1,4,2,1,1,0,0]

示例 2:

输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]

示例 3:

输入: temperatures = [30,60,90]
输出: [1,1,0]

提示：

  • 1 <= temperatures.length <= 105
  • 30 <= temperatures[i] <= 100
