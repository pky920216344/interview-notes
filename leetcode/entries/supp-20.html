补充题20. 立方根

  • 中等
  • 频度 8
  • 数学
  • 未经力扣验证

牛顿迭代解 r³ = a：r ← (2r + a/r²)/3，正初值恒收敛；负数先取绝对值再补符号，最后四舍五入到 1 位小数。

思路

  • 解方程 r³ = a：牛顿迭代 r ← r − f(r)/f′(r) = (2r + a/r²)/3；从正初值 max(1, a) 出发对任意 a > 0 都收敛。
  • 负输入先取 a = |x| 迭代，收敛后再补负号，避免在负半轴讨论凹凸性。
  • 收敛判据：相邻两步之差小于 1e-12 × max(1, |r|)（相对误差），最多 200 次兜底。
  • 题面要求保留 1 位小数：Math.round(r × 10) / 10.0 四舍五入后返回（如 27 → 3.0、-23 → -2.8）。

最优解

时间复杂度 O(迭代次数)（几十步内收敛），空间复杂度 O(1)
1class Solution {2    // 求立方根，结果保留 1 位小数（题面精度）；负数先取绝对值再补符号3    public double cbrt(double x) {4        double a = Math.abs(x);5        // 牛顿迭代解 r³ = a：正初值迭代恒收敛6        double r = Math.max(1.0, a);7        for (int i = 0; i < 200; i++) {8            double next = (2 * r + a / (r * r)) / 3;9            // 相邻两步差已小于相对阈值：认为收敛10            if (Math.abs(next - r) < 1e-12 * Math.max(1.0, Math.abs(next))) break;11            r = next;12        }13        // 保留 1 位小数：四舍五入到 0.114        double ans = Math.round(r * 10) / 10.0;15        return x < 0 ? -ans : ans;16    }17}
