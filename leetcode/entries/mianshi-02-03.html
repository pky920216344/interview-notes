面试题 02.03. 删除中间节点

  • 频度 1
  • 链表
  • 链表
  • 待提交

拿不到前驱，就把待删结点伪装成后继：拷贝后继的值，再让 next 越过后继。

思路

  • 单向链表删结点通常要前驱，但这里只有 node 本身，于是换个思路：不删它，把它变成后继。
  • node.val = node.next.val：值被后继覆盖。
  • node.next = node.next.next：跳过后继，链表等效于少了原结点。

最优解

时间复杂度 O(1)，空间复杂度 O(1)
1class Solution {2    // 只拿到待删结点、拿不到前驱：把它自己变成后继，再让 next 越过后继3    public void deleteNode(ListNode node) {4        node.val = node.next.val;5        node.next = node.next.next;6    }7}
题目

若链表中的某个节点，既不是链表头节点，也不是链表尾节点，则称其为该链表的「中间节点」。

假定已知链表的某一个中间节点，请实现一种算法，将该节点从链表中删除。

例如，传入节点 c（位于单向链表 a->b->c->d->e->f 中），将其删除后，剩余链表为 a->b->d->e->f

示例：

输入：节点 5 （位于单向链表 4->5->1->9 中）
输出：不返回任何数据，从链表中删除传入的节点 5，使链表变为 4->1->9
