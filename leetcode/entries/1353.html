1353. 最多可以参加的会议数目

  • 中等
  • 频度 5
  • 贪心
  • 堆
  • 贪心
  • 数组
  • 排序
  • 堆（优先队列）
  • 待提交

按开始日排序后逐天推进；已开始会议的结束日入小根堆，先弹掉过期的，再贪心参加结束最早的堆顶。

思路

  • 贪心：每天在「已开始且未过期」的会议里参加结束最早的，把更晚结束的留给后面的日子。
  • 会议按开始日排序，day 逐天推进；堆空且下一场会议还没开始时，day 直接跳到那个开始日。
  • 每天三步：把堆顶结束日 < day 的过期会议弹出 → 把今天开始的会议结束日入堆 → 弹出堆顶参加，ans++。
  • 堆里始终是「今天还能参加」的会议；结束日越早越紧迫，所以堆顶就是当天该参加的那场。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int maxEvents(int[][] events) {5        Arrays.sort(events, (a, b) -> a[0] - b[0]);   // 会议按开始日从早到晚6        // 小根堆存「已开始会议」的结束日，堆顶是最先结束的7        PriorityQueue<Integer> heap = new PriorityQueue<>();8        int ans = 0, i = 0, n = events.length, day = 1;9        while (i < n || !heap.isEmpty()) {10            if (heap.isEmpty() && events[i][0] > day) day = events[i][0];   // 空档直接跳到下一场会议开始11            while (i < n && events[i][0] <= day) heap.add(events[i++][1]);12            while (!heap.isEmpty() && heap.peek() < day) heap.poll();   // 今天之前就结束的已过期13            if (!heap.isEmpty()) { heap.poll(); ans++; }   // 今天参加结束最早的那场14            day++;15        }16        return ans;17    }18}
题目

给你一个数组 events，其中 events[i] = [startDayi, endDayi] ，表示会议 i 开始于 startDayi ，结束于 endDayi 。

你可以在满足 startDayi <= d <= endDayi 中的任意一天 d 参加会议 i 。在任意一天 d 中只能参加一场会议。

请你返回你可以参加的 最大 会议数目。

示例 1：

输入：events = [[1,2],[2,3],[3,4]]
输出：3
解释：你可以参加所有的三个会议。
安排会议的一种方案如上图。
第 1 天参加第一个会议。
第 2 天参加第二个会议。
第 3 天参加第三个会议。

示例 2：

输入：events= [[1,2],[2,3],[3,4],[1,2]]
输出：4

提示：​​​​​​

  • 1 <= events.length <= 105
  • events[i].length == 2
  • 1 <= startDayi <= endDayi <= 105
