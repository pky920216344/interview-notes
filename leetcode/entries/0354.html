排序成「宽升序、同宽高降序」，问题变成对高度做严格 LIS（二分 O(n log n)），同宽的假递增被降序挡掉。

思路

  • 宽升序排序后，「宽严格递增」只需看高度；同宽时高降序，保证同一宽度内的高不会被串成递增（同宽不能互套）。
  • 对高度序列做严格 LIS：tails[k] 是长度 k+1 的子序列的最小结尾，tails 始终递增。
  • 每个高二分找第一个 ≥ h 的位置：找到就覆盖（长度不涨），lo == size 说明 h 比结尾都大，追加并 size++。
  • 等于 tails 结尾的值走覆盖分支，天然实现「严格递增」。

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int maxEnvelopes(int[][] envelopes) {5        // 宽升序、同宽高降序：同宽里只有最高的那个能代表这组宽度6        Arrays.sort(envelopes, (a, b) -> a[0] != b[0] ? a[0] - b[0] : b[1] - a[1]);7        // 对高做严格 LIS：tails[k] = 长度 k+1 的递增子序列的最小结尾8        int[] tails = new int[envelopes.length];9        int size = 0;10        for (int[] e : envelopes) {11            int h = e[1], lo = 0, hi = size;12            // 二分找第一个 >= h 的位置：等值也停在这里13            while (lo < hi) {14                int mid = (lo + hi) >>> 1;15                if (tails[mid] < h) lo = mid + 1; else hi = mid;16            }17            tails[lo] = h;18            if (lo == size) size++;19        }20        return size;21    }22}
题目

给你一个二维整数数组 envelopes ，其中 envelopes[i] = [wi, hi] ，表示第 i 个信封的宽度和高度。

当另一个信封的宽度和高度都比这个信封大的时候，这个信封就可以放进另一个信封里，如同俄罗斯套娃一样。

请计算 最多能有多少个 信封能组成一组“俄罗斯套娃”信封（即可以把一个信封放到另一个信封里面）。

注意：不允许旋转信封。

 

示例 1：

输入：envelopes = [[5,4],[6,4],[6,7],[2,3]]
输出：3
解释：最多信封的个数为 3, 组合为: [2,3] => [5,4] => [6,7]。

示例 2：

输入：envelopes = [[1,1],[1,1],[1,1]]
输出：1

提示：

  • 1 <= envelopes.length <= 105
  • envelopes[i].length == 2
  • 1 <= wi, hi <= 105
