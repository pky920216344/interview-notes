990. 等式方程的可满足性

等号有传递性，用并查集：先把所有 == 合并成一个集合，再逐条查 != 的两端是否已被连成同根。

思路

  • 两遍扫：第一遍把每条 a==b 做 union；第二遍查每条 a!=b，若两端 find 相同则矛盾返回 false。
  • 顺序不能反：必须先合并完所有 == 再查 !=，否则传递性还没生效就误判。
  • 并查集只开 26 个字母，find 带路径压缩，复杂度近似常数。
  • a!=a 这类自反矛盾也会被第二遍抓到（同根）。

最优解

时间复杂度 O(n·α(26)) ≈ O(n)，空间复杂度 O(26)
1import java.util.*;2 3class Solution {4    int[] p = new int[26];5 6    public boolean equationsPossible(String[] equations) {7        // 每个字母自己是一个集合8        for (int i = 0; i < 26; i++) p[i] = i;9        // 第一遍：所有 == 都并起来（== 具有传递性）10        for (String e : equations) if (e.charAt(1) == '=') union(e.charAt(0) - 'a', e.charAt(3) - 'a');11        // 第二遍：每条 != 的两端必须不在同一集合12        for (String e : equations) {13            if (e.charAt(1) == '!') {14                int a = find(e.charAt(0) - 'a'), b = find(e.charAt(3) - 'a');15                if (a == b) return false;16            }17        }18        return true;19    }20 21    void union(int a, int b) {22        p[find(a)] = find(b);23    }24 25    int find(int x) {26        // 路径压缩：沿途结点直接挂到根上27        if (p[x] != x) p[x] = find(p[x]);28        return p[x];29    }30}
题目

给定一个由表示变量之间关系的字符串方程组成的数组，每个字符串方程 equations[i] 的长度为 4，并采用两种不同的形式之一："a==b" 或 "a!=b"。在这里，a 和 b 是小写字母（不一定不同），表示单字母变量名。

只有当可以将整数分配给变量名，以便满足所有给定的方程时才返回 true，否则返回 false。 

示例 1：

输入：["a==b","b!=a"]
输出：false
解释：如果我们指定，a = 1 且 b = 1，那么可以满足第一个方程，但无法满足第二个方程。没有办法分配变量同时满足这两个方程。

示例 2：

输入：["b==a","a==b"]
输出：true
解释：我们可以指定 a = 1 且 b = 1 以满足满足这两个方程。

示例 3：

输入：["a==b","b==c","a==c"]
输出：true

示例 4：

输入：["a==b","b!=c","c==a"]
输出：false

示例 5：

输入：["c==c","b==d","x!=z"]
输出：true

提示：

  1. 1 <= equations.length <= 500
  2. equations[i].length == 4
  3. equations[i][0] 和 equations[i][3] 是小写字母
  4. equations[i][1] 要么是 '='，要么是 '!'
  5. equations[i][2] 是 '='
