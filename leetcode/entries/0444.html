444. 序列重建

  • 中等
  • 频度 1
  • 模拟
  • 图
  • 拓扑排序
  • 数组
  • directed-acyclic-graph
  • 未经力扣验证

org 唯一 ⟺ 每个 seq 都是 org 的子序列，且 org 的 n−1 个相邻对都被某条 seq 原样相邻覆盖。

思路

  • 用 pos[v] 记值在 org 里的下标；seq 里相邻两值的位置必须严格递增，否则它根本不是 org 的子序列。
  • 相邻两值位置恰好差 1：这对顺序被「锁死」，标记 covered。
  • n−1 个相邻对全被锁死 ⟹ 约束链 org[0]<org[1]<…<org[n−1] 成立，拓扑序唯一；再查每个值都在 seqs 里出现过（n=1 时只靠这一条）。

时间复杂度 O(所有 seq 总长 + n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public boolean sequenceReconstruction(int[] org, List<List<Integer>> seqs) {5        int n = org.length;6        int[] pos = new int[n + 1];   // pos[v]：值 v 在 org 中的下标（org 是 1..n 的排列）7        for (int i = 0; i < n; i++) pos[org[i]] = i;8        boolean[] covered = new boolean[Math.max(n - 1, 1)];   // 相邻对 (org[i], org[i+1]) 是否被覆盖9        Set<Integer> seen = new HashSet<>();10        for (List<Integer> seq : seqs) {11            int prev = 0;   // 0 不是合法值，当哨兵12            for (int v : seq) {13                // 值越界，或在本 seq 里位置倒退/重复：它不是 org 的子序列14                if (v < 1 || v > n || (prev != 0 && pos[v] <= pos[prev])) return false;15                seen.add(v);16                // 相邻两值正好是 org 的一对相邻元素：这一对顺序被锁定了17                if (prev != 0 && pos[v] == pos[prev] + 1) covered[pos[prev]] = true;18                prev = v;19            }20        }21        // 每个值都得在 seqs 里出现过（n=1 时没有相邻对可依靠）22        if (seen.size() < n) return false;23        // n−1 个相邻对全被锁定 ⟹ 顺序唯一24        for (int i = 0; i + 1 < n; i++) {25            if (!covered[i]) return false;26        }27        return true;28    }29}
