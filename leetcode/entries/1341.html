1341. 电影评分

  • 中等
  • 频度 1
  • SQL
  • 数据库
  • 待提交

两段查询各自「按月过滤 → GROUP BY 聚合 → 排序取第一」，UNION ALL 拼成单列 results。

思路

  • 用户段不限月份（官方示例解释把 1 月的评分也算进「评论电影数量」），电影段才限 February 2020——这是本题最大的坑。
  • 月份过滤用半开区间 created_at >= '2020-02-01' AND < '2020-03-01'——比 DATE_FORMAT 稳（能用上索引）。
  • 用户段：COUNT(*) 降序、名字典序升序，LIMIT 1；电影段：AVG(rating) 降序、同规则。
  • UNION ALL 拼接：两个查询各自内部排序后只取 1 行，UNION ALL 保证两行都保留（UNION 会去重，两行不同时无差，但语义上 ALL 更对）。
  • 带括号分段 + 各自 LIMIT 是「每组取第一」类题的固定套路；MySQL 里子查询带 ORDER BY/LIMIT 必须有括号。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1-- 1341（codetop 1341）电影评分（MySQL）2-- 题意：Movies(movie_id, title)、Users(user_id, name)、MovieRating(movie_id, user_id, rating, created_at)。3-- 两段结果合并成单列 results：4--   ① 评论电影数量最多的用户名（不限时间，并列取字典序小）；5--   ② 2020 年 2 月平均分最高的电影名（并列取字典序小）。6-- 用户段不限月份是本题最大的坑（官方示例解释里 1 月的评分也计入 Daniel 的 3 部）。7-- 用 UNION ALL 拼两段各自 ORDER BY + LIMIT 1 的查询。8(SELECT u.name AS results9FROM MovieRating mr10JOIN Users u ON u.user_id = mr.user_id11GROUP BY mr.user_id, u.name12ORDER BY COUNT(*) DESC, u.name ASC13LIMIT 1)14UNION ALL15(SELECT m.title AS results16FROM MovieRating mr17JOIN Movies m ON m.movie_id = mr.movie_id18WHERE mr.created_at >= '2020-02-01'19  AND mr.created_at < '2020-03-01'20GROUP BY mr.movie_id, m.title21ORDER BY AVG(mr.rating) DESC, m.title ASC22LIMIT 1);
题目

表：Movies

+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| movie_id      | int     |
| title         | varchar |
+---------------+---------+
movie_id 是这个表的主键(具有唯一值的列)。
title 是电影的名字。
每部电影都有一个唯一的 title。

表：Users

+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| user_id       | int     |
| name          | varchar |
+---------------+---------+
user_id 是表的主键(具有唯一值的列)。
'name' 列具有唯一值。

表：MovieRating

+---------------+---------+
| Column Name   | Type    |
+---------------+---------+
| movie_id      | int     |
| user_id       | int     |
| rating        | int     |
| created_at    | date    |
+---------------+---------+
(movie_id, user_id) 是这个表的主键(具有唯一值的列的组合)。
这个表包含用户在其评论中对电影的评分 rating 。
created_at 是用户的点评日期。

请你编写一个解决方案：

  • 查找评论电影数量最多的用户名。如果出现平局，返回字典序较小的用户名。
  • 查找在 February 2020 平均评分最高 的电影名称。如果出现平局，返回字典序较小的电影名称。

字典序 ，即按字母在字典中出现顺序对字符串排序，字典序较小则意味着排序靠前。

返回结果格式如下例所示。

示例 1：

输入：
Movies 表：
+-------------+--------------+

+-------------+--------------+
| 1           | Avengers     |

MovieRating 表：
+-------------+--------------+--------------+-------------+

| 1           | 1            | 3            | 2020-01-12  |
| 1           | 2            | 4            | 2020-02-11  |
| 1           | 3            | 2            | 2020-02-12  |

输出：
Result 表：
+--------------+

+--------------+

+--------------+
解释：
Daniel 和 Monica 都点评了 3 部电影（"Avengers", "Frozen 2" 和 "Joker"） 但是 Daniel 字典序比较小。
Frozen 2 和 Joker 在 2 月的评分都是 3.5，但是 Frozen 2 的字典序比较小。
