516. 最长回文子序列

  • 中等
  • 频度 37
  • 动态规划
  • 字符串
  • 动态规划
  • 力扣已通过

区间 DP：dp[i][j] 是 s[i..j] 的最长回文子序列长度，两端相等就内部 +2，不相等就丢一头取大；i 倒序保证依赖先算好。

思路

  • dp[i][j]：区间 s[i..j] 的答案。s[i] == s[j] 时 dp[i][j] = dp[i+1][j-1] + 2（这对端子一定同时在回文里）；否则 max(dp[i+1][j], dp[i][j-1])。
  • dp[i+1][j-1] 在 j == i+1 时是空区间，数组默认 0 正好当空串用，不用特判。
  • i 必须倒序（从 n-1 往 0），这样算 dp[i][j] 时第 i+1 行已经就绪；对角线 dp[i][i] = 1 是边界。
  • 答案是 dp[0][n-1]；想压空间可用一维滚动，但二维更好背。

图解

最优解

时间复杂度 O(n²)，空间复杂度 O(n²)（可压到 O(n)）
1class Solution {2    public int longestPalindromeSubseq(String s) {3        // dp[i][j]：s[i..j] 里最长回文子序列的长度4        int n = s.length();5        int[][] dp = new int[n][n];6        // i 从右往左：算 dp[i][j] 时 dp[i+1][...] 必须已经算好7        for (int i = n - 1; i >= 0; i--) {8            dp[i][i] = 1;                             // 单个字符自己就是回文9            for (int j = i + 1; j < n; j++) {10                if (s.charAt(i) == s.charAt(j)) {11                    dp[i][j] = dp[i + 1][j - 1] + 2;  // 两端配成一对，加上中间部分12                } else {13                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);   // 两端配不上，丢掉一头14                }15            }16        }17        return dp[0][n - 1];18    }19}
题目

给你一个字符串 s ，找出其中最长的回文子序列，并返回该序列的长度。

子序列定义为：不改变剩余字符顺序的情况下，删除某些字符或者不删除任何字符形成的一个序列。

示例 1：

输入：s = "bbbab"
输出：4
解释：一个可能的最长回文子序列为 "bbbb" 。

示例 2：

输入：s = "cbbd"
输出：2
解释：一个可能的最长回文子序列为 "bb" 。

提示：

  • 1 <= s.length <= 1000
  • s 仅由小写英文字母组成
