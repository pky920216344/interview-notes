518. 零钱兑换 II

  • 动态规划

组合数完全背包：外层枚举硬币、内层枚举金额，dp[a] += dp[a-c]；dp[0]=1 起步，dp[amount] 即答案。

思路

  • dp[a] = 用已引入的面额凑出 a 的组合数；dp[0] = 1（什么都不选也是一种）。
  • 每引入一枚面额 c，从 a = c 到 amount 做 dp[a] += dp[a - c]：相当于在 a-c 的每种方案后面再放一枚 c。
  • 循环顺序就是答案的语义：外层硬币、内层金额 → 组合数（1,2 和 2,1 算一种）；反过来外层金额、内层硬币 → 排列数（如 377 题）。
  • 内层正序遍历是因为每种面额无限用（完全背包）；dp[amount] 就是答案。

图解

最优解

时间复杂度 O(amount × coins)，空间复杂度 O(amount)
1class Solution {2    public int change(int amount, int[] coins) {3        // dp[a]：用已引入的硬币凑出金额 a 的组合数4        int[] dp = new int[amount + 1];5        dp[0] = 1;   // 凑 0 元只有「什么都不选」一种6        for (int c : coins) {            // 外层硬币：{1,2} 和 {2,1} 只算一种（组合数）7            for (int a = c; a <= amount; a++) {8                dp[a] += dp[a - c];      // 在 a-c 的每种方案后面放一枚 c9            }10        }11        return dp[amount];12    }13}
题目

给你一个整数数组 coins 表示不同面额的硬币，另给一个整数 amount 表示总金额。

请你计算并返回可以凑成总金额的硬币组合数。如果任何硬币组合都无法凑出总金额，返回 0 。

假设每一种面额的硬币有无限个。 

题目数据 保证 最终 结果符合 32 位 带符号整数。

示例 1：

输入：amount = 5, coins = [1, 2, 5]
输出：4
解释：有四种方式可以凑成总金额：
5=5
5=2+2+1
5=2+1+1+1
5=1+1+1+1+1

示例 2：

输入：amount = 3, coins = [2]
输出：0
解释：只用面额 2 的硬币不能凑成总金额 3 。

示例 3：

输入：amount = 10, coins = [10] 
输出：1

提示：

  • 1 <= coins.length <= 300
  • 1 <= coins[i] <= 5000
  • coins 中的所有值 互不相同
  • 0 <= amount <= 5000
