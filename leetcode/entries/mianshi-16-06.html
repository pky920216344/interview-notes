面试题 16.06. 最小差

两数组各自排序后双指针夹逼：谁指的数小谁右移，途中不断用 |a[i]-b[j]| 刷新最小差。

思路

  • 排序后从两头各放一个指针：a[i] < b[j] 说明 a[i] 配后面的 b 只会更远，i 右移；反之 j 右移。
  • 每比较一对就用 |a[i]-b[j]| 刷新 best；碰到相等直接返回 0，不可能更小。
  • 一方走完就停：剩下的配对只会更远，best 已经是答案。
  • 关键坑：a[i] - b[j] 要先转 long 再取绝对值，两个 int 极值相减会溢出。

最优解

时间复杂度 O(m log m + n log n)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int smallestDifference(int[] a, int[] b) {5        Arrays.sort(a);6        Arrays.sort(b);7        long best = Long.MAX_VALUE;   // 差最大能到 2^32，int 装不下8        int i = 0, j = 0;9        while (i < a.length && j < b.length) {10            // 相减必须先转 long：两个极值相减会溢出11            long d = (long) a[i] - b[j];12            best = Math.min(best, d < 0 ? -d : d);13            if (d == 0) return 0;         // 有相等的数，差为 0 到顶了14            if (d < 0) i++;               // a 小，右移 a 去逼近15            else j++;                     // a 大，右移 b 去逼近16        }17        return (int) best;18    }19}
题目

给定两个整数数组a和b，计算具有最小差绝对值的一对数值（每个数组中取一个值），并返回该对数值的差

示例：

输入：{1, 3, 15, 11, 2}, {23, 127, 235, 19, 8}
输出：3，即数值对(11, 8)

提示：

  • 1 <= a.length, b.length <= 100000
  • -2147483648 <= a[i], b[i] <= 2147483647
  • 正确结果在区间 [0, 2147483647] 内
