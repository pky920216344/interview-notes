空间换时间：每个单词拆出全部「后缀#前缀」组合存哈希表（后建覆盖=自动取大下标），查询 O(1)。

思路

  • 词长 ≤ 7：一个词的后缀 ≤ 8 种 × 前缀 ≤ 8 种 ≤ 64 个键；1e4 个词也就几十万条，内存扛得住。
  • 键 = 后缀 + '#' + 前缀（# 防止前后缀拼在一起有歧义）；按下标顺序写入，同键后来覆盖 → 值天然是最大下标。
  • 查询时拼出 suff + '#' + pref 直接查表，查不到返回 −1。

图解

最优解

时间复杂度 建表 O(Σw²)，查询 O(1)，空间复杂度 O(Σw²)
1import java.util.*;2 3class WordFilter {4    // 键 = 后缀 + '#' + 前缀 → 最大下标；下标按序写入，同键后来者覆盖，天然取大5    private final Map<String, Integer> map = new HashMap<>();6 7    public WordFilter(String[] words) {8        for (int i = 0; i < words.length; i++) {9            String w = words[i];10            for (int s = 0; s <= w.length(); s++) {         // 后缀：从空串到整词11                for (int p = 0; p <= w.length(); p++) {     // 前缀：从空串到整词12                    map.put(w.substring(s) + '#' + w.substring(0, p), i);13                }14            }15        }16    }17 18    public int f(String pref, String suff) {19        return map.getOrDefault(suff + '#' + pref, -1);20    }21}22 23/**24 * Your WordFilter object will be instantiated and called as such:25 * WordFilter obj = new WordFilter(words);26 * int param_1 = obj.f(pref,suff);27 */
题目

设计一个包含一些单词的特殊词典，并能够通过前缀和后缀来检索单词。

实现 WordFilter 类：

  • WordFilter(string[] words) 使用词典中的单词 words 初始化对象。
  • f(string pref, string suff) 返回词典中具有前缀 pref 和后缀 suff 的单词的下标。如果存在不止一个满足要求的下标，返回其中 最大的下标 。如果不存在这样的单词，返回 -1 。

示例：

输入
["WordFilter", "f"]
[[["apple"]], ["a", "e"]]
输出
[null, 0]
解释
WordFilter wordFilter = new WordFilter(["apple"]);
wordFilter.f("a", "e"); // 返回 0 ，因为下标为 0 的单词：前缀 prefix = "a" 且 后缀 suffix = "e" 。
 

提示：

  • 1 <= words.length <= 104
  • 1 <= words[i].length <= 7
  • 1 <= pref.length, suff.length <= 7
  • words[i]、pref 和 suff 仅由小写英文字母组成
  • 最多对函数 f 执行 104 次调用
