快速排序：随机选基准，三向切分成「小于 / 等于 / 大于」三段，等于的一段已就位，只递归左右两段。

思路

  • 随机选基准 pivot，有序数组也不会退化成 O(n^2)；三向切分让大量重复元素也不拖慢。
  • i 从左往右扫：[lo, lt) 小于，[lt, i) 等于，[i, gt] 还没看，(gt, hi] 大于。
  • a[i] < pivot：与 lt 处交换，lt、i 右移；a[i] > pivot：与 gt 处交换，gt 左移，i 不动，换来的数还没看；相等：i 右移。
  • i 越过 gt 后，等于 pivot 的一段已就位，只递归 [lo, lt - 1] 和 [gt + 1, hi]。

时间复杂度 平均 O(n log n)，空间复杂度 O(log n)
1import java.util.*;2 3class Solution {4    private final Random rnd = new Random();5 6    public int[] sortArray(int[] nums) {7        sort(nums, 0, nums.length - 1);8        return nums;9    }10 11    private void sort(int[] a, int lo, int hi) {12        if (lo >= hi) return;13        // 随机选基准，有序数组也不会退化14        int pivot = a[lo + rnd.nextInt(hi - lo + 1)];15        // 三向切分，i 从左往右扫：16        // [lo, lt) 小于，[lt, i) 等于，(gt, hi] 大于17        int lt = lo, i = lo, gt = hi;18        while (i <= gt) {19            if (a[i] < pivot) swap(a, lt++, i++);20            else if (a[i] > pivot) swap(a, i, gt--);21            else i++;22        }23        // 等于基准的一段已就位，只递归左右两段24        sort(a, lo, lt - 1);25        sort(a, gt + 1, hi);26    }27 28    private void swap(int[] a, int i, int j) {29        int t = a[i];30        a[i] = a[j];31        a[j] = t;32    }33}
题目

给你一个整数数组 nums，请你将该数组升序排列。

你必须在 不使用任何内置函数 的情况下解决问题，时间复杂度为 O(nlog(n))，并且空间复杂度尽可能小。

示例 1：

输入：nums = [5,2,3,1]
输出：[1,2,3,5]
解释：数组排序后，某些数字的位置没有改变（例如，2 和 3），而其他数字的位置发生了改变（例如，1 和 5）。

示例 2：

输入：nums = [5,1,1,2,0,0]
输出：[0,0,1,1,2,5]
解释：请注意，nums 的值不一定唯一。

提示：

  • 1 <= nums.length <= 5 * 104
  • -5 * 104 <= nums[i] <= 5 * 104
