面试题 02.04. 分割链表

用两个哑结点把链表拆成「小于 x」和「其余」两条链，各自尾插保持相对顺序，最后上链尾接下链头。

思路

  • 一次遍历：p.val < x 尾插进 small，否则尾插进 big，哑结点免去判头。
  • 拼接前必须 big.next = null：big 尾结点的 next 还是原链的旧指向，可能指回 small 里的结点成环。
  • small.next = bigHead.next 完成拼接，返回 smallHead.next。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public ListNode partition(ListNode head, int x) {3        // 两条链分别收拢：小于 x 的进 small，其余进 big，各自保持相对顺序4        ListNode smallHead = new ListNode(), bigHead = new ListNode();5        ListNode small = smallHead, big = bigHead;6        for (ListNode p = head; p != null; p = p.next) {7            if (p.val < x) {8                small.next = p;9                small = p;10            } else {11                big.next = p;12                big = p;13            }14        }15        // 关键：先断掉 big 的旧尾巴，否则它可能还指着 small 里的结点成环16        big.next = null;17        small.next = bigHead.next;18        return smallHead.next;19    }20}
题目

给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有 小于 x 的节点都出现在 大于或等于 x 的节点之前。

你不需要 保留 每个分区中各节点的初始相对位置。

示例 1：

输入：head = [1,4,3,2,5,2], x = 3
输出：[1,2,2,4,3,5]

示例 2：

输入：head = [2,1], x = 2
输出：[1,2]

提示：

  • 链表中节点的数目在范围 [0, 200] 内
  • -100 <= Node.val <= 100
  • -200 <= x <= 200
