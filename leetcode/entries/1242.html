线程池并发抓取：同步去重集合 seen 保证每个 URL 只被一个线程抓，pending 计数归零触发 CountDownLatch 收工。

思路

  • 共享状态就两个：seen（并发安全的去重集合）与 pending（原子计数）；seen.add 成功的线程负责抓这个 URL，天然做到每个 URL 恰好被抓一次。
  • hostname 过滤在入队前做：和 startUrl 域名不同的链接直接丢。
  • pending 记「还没跑完的任务数」：子任务先加一再提交，父任务在 finally 里减一，减到 0 说明全部收工，CountDownLatch 放行主线程。
  • 收工后返回 seen 里收集到的全部本站 URL。

1import java.util.*;2import java.util.concurrent.*;3import java.util.concurrent.atomic.*;4 5/**6 * HtmlParser 由力扣提供（接口）：getUrls(url) 返回该页面上的所有链接；本地验证时定义在 Check.java 里。7 */8class Solution {9    public List<String> crawl(String startUrl, HtmlParser htmlParser) {10        String host = hostname(startUrl);11        Set<String> seen = ConcurrentHashMap.newKeySet();   // 已抓的 URL：全线程共享去重12        seen.add(startUrl);13        AtomicInteger pending = new AtomicInteger(1);       // 还没跑完的抓取任务数14        CountDownLatch allDone = new CountDownLatch(1);15        ExecutorService pool = Executors.newFixedThreadPool(8);16 17        class Task implements Runnable {18            final String url;19 20            Task(String url) { this.url = url; }21 22            public void run() {23                try {24                    for (String next : htmlParser.getUrls(url)) {25                        // 同 hostname 才要；seen.add 成功 = 第一个见到的线程负责抓它26                        if (hostname(next).equals(host) && seen.add(next)) {27                            pending.incrementAndGet();28                            pool.execute(new Task(next));29                        }30                    }31                } finally {32                    if (pending.decrementAndGet() == 0) allDone.countDown();   // 最后一个任务收工33                }34            }35        }36 37        pool.execute(new Task(startUrl));38        try {39            allDone.await();        // 等全部抓取任务结束40        } catch (InterruptedException e) {41            Thread.currentThread().interrupt();42        }43        pool.shutdownNow();44        return new ArrayList<>(seen);45    }46 47    // hostname：scheme:// 之后到第一个 '/' 之前48    private String hostname(String url) {49        int start = url.indexOf("://") + 3;50        int end = url.indexOf('/', start);51        return end < 0 ? url.substring(start) : url.substring(start, end);52    }53}
