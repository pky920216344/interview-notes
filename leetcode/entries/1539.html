1539. 第 k 个缺失的正整数

  • 简单
  • 频度 4
  • 二分查找
  • 数组
  • 二分查找
  • 待提交

位置 i 前面缺 arr[i]-(i+1) 个数，缺口数随 i 单调不减；二分找第一个缺口 ≥ k 的位置 lo，答案就是 lo+k。

思路

  • 缺口数 arr[i] - (i+1)：把 i+1 个「本应出现的数」和实际值一比就得出，严格升序保证它单调不减。
  • 二分 [lo, hi) 找第一个缺口 ≥ k 的下标；缺口 ≥ k 时 hi = mid（mid 可能是答案），否则 lo = mid + 1。
  • 答案 = lo + k：前 lo 个数都在数组里，再加上 k 个缺失；缺口全 < k 时 lo = n，同样得 n + k。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int findKthPositive(int[] arr, int k) {3        // arr[i] 前面缺 arr[i]-(i+1) 个正整数；二分找第一个缺口 >= k 的位置4        int lo = 0, hi = arr.length;5        while (lo < hi) {6            int mid = (lo + hi) >>> 1;7            if (arr[mid] - (mid + 1) >= k) hi = mid;8            else lo = mid + 1;9        }10        // 答案 = lo + k：lo 个在数组里 + k 个缺失，缺口不足 k 时 lo=n 也成立11        return lo + k;12    }13}
题目

给你一个 严格升序排列 的正整数数组 arr 和一个整数 k 。

请你找到这个数组里第 k 个缺失的正整数。

示例 1：

输入：arr = [2,3,4,7,11], k = 5
输出：9
解释：缺失的正整数包括 [1,5,6,8,9,10,12,13,...] 。第 5 个缺失的正整数为 9 。

示例 2：

输入：arr = [1,2,3,4], k = 2
输出：6
解释：缺失的正整数包括 [5,6,7,...] 。第 2 个缺失的正整数为 6 。

提示：

  • 1 <= arr.length <= 1000
  • 1 <= arr[i] <= 1000
  • 1 <= k <= 1000
  • 对于所有 1 <= i < j <= arr.length 的 i 和 j 满足 arr[i] < arr[j]
