719. 找出第 K 小的数对距离

排序后二分「第 k 小的距离值 d」：双指针 O(n) 数距离 ≤ d 的对数，对数随 d 单调不减，按个数收缩边界。

思路

  • 答案是某个距离值：在 [0, 最大值−最小值] 上二分这个值，而不是二分下标。
  • count(d)：排序后对每个右端 r，l 停在第一个 nums[r]−nums[l] ≤ d 的位置，cnt += r−l；d 越大对数越多，单调可二分。
  • count(mid) ≥ k 说明第 k 小 ≤ mid，收缩 hi；否则抬 lo。收敛时 lo 就是答案。

时间复杂度 O(n log n + n log W)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int smallestDistancePair(int[] nums, int k) {5        Arrays.sort(nums);6        // 二分「第 k 小的距离值」d：距离 ≤ d 的对数随 d 单调不减7        int lo = 0, hi = nums[nums.length - 1] - nums[0];8        while (lo < hi) {9            int mid = (lo + hi) >>> 1;10            if (count(nums, mid) >= k) hi = mid;   // 够 k 对：答案可能是 mid 或更小11            else lo = mid + 1;                     // 不足 k 对：mid 太小12        }13        return lo;14    }15 16    // 排序后双指针：对每个右端 r，数它左边距离 ≤ d 的对数17    private int count(int[] nums, int d) {18        int cnt = 0, l = 0;19        for (int r = 0; r < nums.length; r++) {20            while (nums[r] - nums[l] > d) l++;21            cnt += r - l;22        }23        return cnt;24    }25}
题目

数对 (a,b) 由整数 a 和 b 组成，其数对距离定义为 a 和 b 的绝对差值。

给你一个整数数组 nums 和一个整数 k ，数对由 nums[i] 和 nums[j] 组成且满足 0 <= i < j < nums.length 。返回 所有数对距离中 第 k 小的数对距离。

示例 1：

输入：nums = [1,3,1], k = 1
输出：0
解释：数对和对应的距离如下：
(1,3) -> 2
(1,1) -> 0
(3,1) -> 2
距离第 1 小的数对是 (1,1) ，距离为 0 。

示例 2：

输入：nums = [1,1,1], k = 2
输出：0

示例 3：

输入：nums = [1,6,1], k = 3
输出：5

提示：

  • n == nums.length
  • 2 <= n <= 104
  • 0 <= nums[i] <= 106
  • 1 <= k <= n * (n - 1) / 2
