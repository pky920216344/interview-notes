1556. 千位分隔数

  • 简单
  • 频度 13
  • 模拟
  • 字符串
  • 待提交

从右往左每次取一位，每凑满 3 位补一个点，最后把StringBuilder整体反转。

思路

  • do-while 让 n=0 也取一次，所以 0 会输出 "0" 而不是空串。
  • 补点条件 ++cnt % 3 == 0 && n > 0：凑满 3 位且左边还有数字才补，避免开头多点。
  • sb 里低位在前，最后 reverse() 一次成型。

时间复杂度 O(log n)，空间复杂度 O(log n)
1class Solution {2    public String thousandSeparator(int n) {3        // 从右往左每次取一位，每凑满 3 位补一个点；n=0 也进循环，输出 "0"4        StringBuilder sb = new StringBuilder();5        int cnt = 0;6        do {7            sb.append(n % 10);8            n /= 10;9            // 凑满 3 位且左边还有数字，才补分隔点10            if (++cnt % 3 == 0 && n > 0) sb.append('.');11        } while (n > 0);12        // 低位在前，整个反转才是正常读法13        return sb.reverse().toString();14    }15}
题目

给你一个整数 n，请你每隔三位添加点（即 "." 符号）作为千位分隔符，并将结果以字符串格式返回。

示例 1：

输入：n = 987
输出："987"

示例 2：

输入：n = 1234
输出："1.234"

示例 3：

输入：n = 123456789
输出："123.456.789"

示例 4：

输入：n = 0
输出："0"

提示：

  • 0 <= n < 2^31
