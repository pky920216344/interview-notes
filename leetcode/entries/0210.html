BFS 拓扑排序：建图 b→a 统计入度，入度 0 的课依次入队、出队时给邻居减入度；学不满 n 门就是有环。

思路

  • prerequisites[i] = [a, b] 表示先修 b 才能学 a：连边 b→a，a 入度加一。
  • 所有入度 0 的课先入队；出队一门就写进 order，并把它指向的课入度减一，减到 0 的进队——队列天然保证先修课先出队。
  • 结束时 order 装满 n 门就有解；装不满说明剩下的课互为先修（有环），返回空数组。

最优解

时间复杂度 O(V+E)，空间复杂度 O(V+E)
1import java.util.*;2 3class Solution {4    public int[] findOrder(int numCourses, int[][] prerequisites) {5        List<List<Integer>> g = new ArrayList<>();6        for (int i = 0; i < numCourses; i++) g.add(new ArrayList<>());7        int[] indeg = new int[numCourses];8        // b 是 a 的先修课：连边 b -> a，a 的入度加一9        for (int[] p : prerequisites) {10            g.get(p[1]).add(p[0]);11            indeg[p[0]]++;12        }13        // 入度为 0 的课没有先修课，先入队14        Queue<Integer> q = new ArrayDeque<>();15        for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.add(i);16        int[] order = new int[numCourses];17        int k = 0;18        while (!q.isEmpty()) {19            int c = q.poll();20            order[k++] = c;21            // 学完 c：指向它的课入度减一，减到 0 就能学了22            for (int next : g.get(c)) {23                if (--indeg[next] == 0) q.add(next);24            }25        }26        // 有环就修不完，输出的课数不够，返回空数组27        return k == numCourses ? order : new int[0];28    }29}
题目

现在你总共有 numCourses 门课需要选，记为 0 到 numCourses - 1。给你一个数组 prerequisites ，其中 prerequisites[i] = [ai, bi] ，表示在选修课程 ai 前 必须 先选修 bi 。

  • 例如，想要学习课程 0 ，你需要先完成课程 1 ，我们用一个匹配来表示：[0,1] 。

返回你为了学完所有课程所安排的学习顺序。可能会有多个正确的顺序，你只要返回 任意一种 就可以了。如果不可能完成所有课程，返回 一个空数组 。

示例 1：

输入：numCourses = 2, prerequisites = [[1,0]]
输出：[0,1]
解释：总共有 2 门课程。要学习课程 1，你需要先完成课程 0。因此，正确的课程顺序为 [0,1] 。

示例 2：

输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
输出：[0,2,1,3]
解释：总共有 4 门课程。要学习课程 3，你应该先完成课程 1 和课程 2。并且课程 1 和课程 2 都应该排在课程 0 之后。
因此，一个正确的课程顺序是 [0,1,2,3] 。另一个正确的排序是 [0,2,1,3] 。

示例 3：

输入：numCourses = 1, prerequisites = []
输出：[0]
提示：
  • 1 <= numCourses <= 2000
  • 0 <= prerequisites.length <= numCourses * (numCourses - 1)
  • prerequisites[i].length == 2
  • 0 <= ai, bi < numCourses
  • ai != bi
  • 所有[ai, bi] 互不相同
