414. 第三大的数

  • 简单
  • 频度 4
  • 模拟
  • 数组
  • 排序
  • 待提交

一次扫描维护前三大的不同值 f>s>t；重复值直接跳过，扫完 t 还是空就说明不足三个，返回最大。

思路

  • 三个变量 f > s > t 当「前三名榜」；新值先查是否榜上已有，重复不占名次。
  • 新值更大就整体下移插入：x > f 时 t=s, s=f, f=x，x > s 时同理。
  • 用 long 的 Long.MIN_VALUE 当空位哨兵：int 最小值本身也是合法数据，若用 int 存哨兵会把它误判成「没值」。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int thirdMax(int[] nums) {3        // f > s > t 是当前三个最大的不同值；long 哨兵避开 int 最小值的坑4        long f = Long.MIN_VALUE, s = Long.MIN_VALUE, t = Long.MIN_VALUE;5        for (int x : nums) {6            if (x == f || x == s || x == t) continue;    // 榜上已有：重复值不占名次7            if (x > f) { t = s; s = f; f = x; }8            else if (x > s) { t = s; s = x; }9            else if (x > t) t = x;10        }11        // t 还是哨兵说明不同值不足三个，返回最大12        return t == Long.MIN_VALUE ? (int) f : (int) t;13    }14}
题目

给定一个整数数组 nums。

返回此数组中 第三大的数 。如果不存在，则返回数组中 最大 的数。

示例 1：

输入：[3, 2, 1]
输出：1
解释：第三大的数是 1 。

示例 2：

输入：[1, 2]
输出：2
解释：第三大的数不存在, 所以返回最大的数 2 。

示例 3：

输入：[2, 2, 3, 1]
输出：1
解释：注意，要求返回第三大的数，是指在所有不同数字中排第三大的数。
此例中存在两个值为 2 的数，它们都排第二。在所有不同数字中排第三大的数为 1 。

提示：

  • 1 <= nums.length <= 104
  • -231 <= nums[i] <= 231 - 1
