一次后序 DFS：每棵子树返回（最深叶深度, 这些叶子的 LCA）；两边同深就在本结点汇合，否则沿更深一侧原样上传。

思路

  • 空子树报告 (0, null)；叶子报告 (1, 自己)。
  • 左右深度相等 → 最深叶分居两侧，本结点就是它们的 LCA，报告 (深+1, 本结点)。
  • 不相等 → 答案完全在更深一侧，把那一侧的 LCA 原样上传；根的报告就是答案，唯一最深叶时自然得到它自己。

时间复杂度 O(n)，空间复杂度 O(树高)
1class Solution {2    // 一次后序 DFS 的报告：子树最深叶子的深度 + 这些叶子在子树里的 LCA3    static class Res {4        int depth;5        TreeNode lca;6 7        Res(int depth, TreeNode lca) {8            this.depth = depth;9            this.lca = lca;10        }11    }12 13    public TreeNode lcaDeepestLeaves(TreeNode root) {14        return dfs(root).lca;15    }16 17    private Res dfs(TreeNode node) {18        if (node == null) return new Res(0, null);19        Res l = dfs(node.left), r = dfs(node.right);20        // 两边最深叶同层：它们在本结点汇合，本结点就是 LCA21        if (l.depth == r.depth) return new Res(l.depth + 1, node);22        // 否则答案在更深一侧，原样上传23        return l.depth > r.depth ? new Res(l.depth + 1, l.lca) : new Res(r.depth + 1, r.lca);24    }25}
题目

给你一个有根节点 root 的二叉树，返回它 最深的叶节点的最近公共祖先 。

回想一下：

  • 叶节点 是二叉树中没有子节点的节点
  • 树的根节点的 深度 为 0，如果某一节点的深度为 d，那它的子节点的深度就是 d+1
  • 如果我们假定 A 是一组节点 S 的 最近公共祖先，S 中的每个节点都在以 A 为根节点的子树中，且 A 的深度达到此条件下可能的最大值。

示例 1：

输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2,7,4]
解释：我们返回值为 2 的节点，在图中用黄色标记。
在图中用蓝色标记的是树的最深的节点。
注意，节点 6、0 和 8 也是叶节点，但是它们的深度是 2 ，而节点 7 和 4 的深度是 3 。

示例 2：

输入：root = [1]
输出：[1]
解释：根节点是树中最深的节点，它是它本身的最近公共祖先。

示例 3：

输入：root = [0,1,3,null,2]
输出：[2]
解释：树中最深的叶节点是 2 ，最近公共祖先是它自己。

提示：

  • 树中的节点数将在 [1, 1000] 的范围内。
  • 0 <= Node.val <= 1000
  • 每个节点的值都是 独一无二 的。
