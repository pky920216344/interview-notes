83. 删除排序链表中的重复元素

  • 简单
  • 频度 69
  • 链表
  • 链表
  • 力扣已通过

排序链表重复必相邻：cur 一路向右，下一个值相等就跳过 cur.next，不等才前进。

思路

  • 链表已排序：重复的值一定相邻，cur 只需要跟 cur.next 比。
  • 相等：cur.next = cur.next.next 跳过重复结点；cur 原地不动——后面可能还有一串重复。
  • 不等：cur = cur.next 前进一位。
  • 头结点永远保留，最后直接返回 head。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public ListNode deleteDuplicates(ListNode head) {3        // 空链表没有重复可言4        if (head == null) return null;5        ListNode cur = head;6        // 已排序：重复值必相邻，只跟下一个比7        while (cur.next != null) {8            if (cur.next.val == cur.val) {9                // 相等就跳过下一个，cur 原地不动10                cur.next = cur.next.next;11            } else {12                // 不等才前进13                cur = cur.next;14            }15        }16        // 头结点永远保留17        return head;18    }19}
题目

给定一个已排序的链表的头 head ， 删除所有重复的元素，使每个元素只出现一次 。返回 已排序的链表 。

示例 1：

输入：head = [1,1,2]
输出：[1,2]

示例 2：

输入：head = [1,1,2,3,3]
输出：[1,2,3]

提示：

  • 链表中节点数目在范围 [0, 300] 内
  • -100 <= Node.val <= 100
  • 题目数据保证链表已经按升序 排列
