面试题 16.03. 交点

  • 困难
  • 频度 2
  • 数学
  • 几何
  • 数学
  • 待提交

叉积判平行：不平行就用参数 t、u 判交点是否都落在线段内；共线则投影取重叠区间的最小 X 端点。

思路

  • 把线段写成 起点 + t·方向。r×s ≠ 0（叉积）时两直线交于一点：t = q×s/(r×s)、u = q×r/(r×s)，t、u 都在 [0,1] 才是线段交点。
  • 整数坐标全程用叉积/点积的整数比较（in01 用交叉相乘判 [0,1]），避免浮点误差；只在最后一步转 double。
  • 共线（r×s = 0 且 q×r = 0）：两段投影到段 1 的参数轴，重叠区间 [lo, hi] 非空才有交；沿段 1 方向 X 单调，rx > 0 取 lo 端、否则取 hi 端，正好是「X 最小、再 Y 最小」。
  • 线段退化成点时单独判「点是否在另一段上」。

lo : hi;29        return pt(x1 + (double) rx * pick / rr, y1 + (double) ry * pick / rr);30    }31 32    // t = num/den（den ≠ 0）是否落在 [0, 1]，用整数比较避免浮点误差33    private boolean in01(long num, long den) {34        if (den < 0) { num = -num; den = -den; }35        return num >= 0 && num <= den;36    }37 38    // 点 (px,py) 是否在线段 (起点 qx,qy，方向 dx,dy) 上：共线且投影在段内39    private boolean onSeg(long qx, long qy, long dx, long dy, long px, long py) {40        long ex = px - qx, ey = py - qy;41        return ex * dy - ey * dx == 0 && ex * dx + ey * dy >= 0 && ex * dx + ey * dy <= dx * dx + dy * dy;42    }43 44    private double[] pt(double x, double y) {45        return new double[]{x, y};46    }47}
题目

给定两条线段（表示为起点start = {X1, Y1}和终点end = {X2, Y2}），如果它们有交点，请计算其交点，没有交点则返回空值。

要求浮点型误差不超过10^-6。若有多个交点（线段重叠）则返回 X 值最小的点，X 坐标相同则返回 Y 值最小的点。

示例 1：

输入：
line1 = {0, 0}, {1, 0}
line2 = {1, 1}, {0, -1}
输出： {0.5, 0}

示例 2：

输入：
line1 = {0, 0}, {3, 3}
line2 = {1, 1}, {2, 2}
输出： {1, 1}

示例 3：

输入：
line1 = {0, 0}, {1, 1}
line2 = {1, 0}, {2, 1}
输出： {}，两条线段没有交点

提示：

  • 坐标绝对值不会超过 2^7
  • 输入的坐标均是有效的二维坐标
