按公差计数的 DP：dp[i][d] = 以 nums[i] 结尾、公差 d 的「弱等差序列」(≥2 项) 个数；每对 (j,i) 让 dp[j][d] 条全部延伸成答案，对 [j,i] 自己存进 dp[i][d] 等后续延伸。

思路

  • d = (long) nums[i] − nums[j]：数值取满 int 时相减会溢出，必须用 long。
  • 扫描所有对 (j, i)：ans += dp[j][d]（每条以 j 结尾的等差序列接上 i 就多一个 ≥3 项的答案）；dp[i][d] += dp[j][d] + 1，+1 是新出现的对 [j,i]，它只有 2 项，先记账等后面延伸。
  • 计数会很大，哈希值和 ans 都用 long，最后按题意收进 int。

时间复杂度 O(n²)，空间复杂度 O(n²)
1import java.util.*;2 3class Solution {4    public int numberOfArithmeticSlices(int[] nums) {5        int n = nums.length;6        long ans = 0;7        // dp[i]：以 nums[i] 结尾的「弱等差序列」（≥2 项）按公差计数的个数，可能很大用 long8        List<HashMap<Long, Long>> dp = new ArrayList<>();9        for (int i = 0; i < n; i++) dp.add(new HashMap<>());10        for (int i = 1; i < n; i++) {11            for (int j = 0; j < i; j++) {12                // 数值取满 int 范围时相减会溢出，必须用 long13                long d = (long) nums[i] - nums[j];14                long c = dp.get(j).getOrDefault(d, 0L);15                ans += c;   // 以 j 结尾的每条等差序列接上 nums[i]，都多出一个 ≥3 项的答案16                // +1 是新出现的对 [j,i]：它只有 2 项，先存着等后面延伸17                dp.get(i).merge(d, c + 1, Long::sum);18            }19        }20        return (int) ans;21    }22}
题目

给你一个整数数组 nums ，返回 nums 中所有 等差子序列 的数目。

如果一个序列中 至少有三个元素 ，并且任意两个相邻元素之差相同，则称该序列为等差序列。

  • 例如，[1, 3, 5, 7, 9]、[7, 7, 7, 7] 和 [3, -1, -5, -9] 都是等差序列。
  • 再例如，[1, 1, 2, 5, 7] 不是等差序列。

数组中的子序列是从数组中删除一些元素（也可能不删除）得到的一个序列。

  • 例如，[2,5,10] 是 [1,2,1,2,4,1,5,10] 的一个子序列。

题目数据保证答案是一个 32-bit 整数。

示例 1：

输入：nums = [2,4,6,8,10]
输出：7
解释：所有的等差子序列为：
[2,4,6]
[4,6,8]
[6,8,10]
[2,4,6,8]
[4,6,8,10]
[2,4,6,8,10]
[2,6,10]

示例 2：

输入：nums = [7,7,7,7,7]
输出：16
解释：数组中的任意子序列都是等差子序列。

提示：

  • 1  <= nums.length <= 1000
  • -231 <= nums[i] <= 231 - 1
