420. 强密码检验器

贪心三分支：太短用 max(缺类型数, 6−n) 个插入；长度合规用 max(缺类型数, Σ⌊段长/3⌋) 次替换；超长先删 n−20 个（删除按段长 %3 分桶优先抵替换），再加 max(缺类型数, 剩余替换数)。

思路

  • 先数缺的类型 missing，再把串切成连续同字符段：长度 L 的段要 ⌊L/3⌋ 次替换才能打断（换掉一个就断开一处）。
  • n < 6：插入补长度，插入进段里还能拆段、补类型 → max(missing, 6−n)。
  • 6 ≤ n ≤ 20：替换一箭双雕（打断段 + 补类型）→ max(missing, Σ⌊L/3⌋)。
  • n > 20：删 n−20 个是硬性的，让删除去抵替换：%3==0 的段删 1 个省 1 次，%3==1 的删 2 个省 1 次，剩下的每删 3 个省 1 次（删到段剩 2 为止）；答案 = 删除数 + max(missing, 剩余替换数)。

题目

满足以下条件的密码被认为是强密码：

  • 由至少 6 个，至多 20 个字符组成。
  • 包含至少 一个小写 字母，至少 一个大写 字母，和至少 一个数字 。
  • 不包含连续三个重复字符 (比如 "Baaabb0" 是弱密码, 但是 "Baaba0" 是强密码)。

给你一个字符串 password ，返回 将 password 修改到满足强密码条件需要的最少修改步数。如果 password 已经是强密码，则返回 0 。

在一步修改操作中，你可以：

  • 插入一个字符到 password ，
  • 从 password 中删除一个字符，或
  • 用另一个字符来替换 password 中的某个字符。

示例 1：

输入：password = "a"
输出：5

示例 2：

输入：password = "aA1"
输出：3

示例 3：

输入：password = "1337C0d3"
输出：0

提示：

  • 1 <= password.length <= 50
  • password 由字母、数字、点 '.' 或者感叹号 '!' 组成
