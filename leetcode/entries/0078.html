78. 子集

  • 中等
  • 频度 108
  • 分治
  • 位运算
  • 数组
  • 回溯
  • 力扣已通过

迭代翻倍：从 [空集] 出发，每来一个数就把现有每个子集复制一份加上它，n 个数正好得到 2^n 个。

思路

  • ans 初始只有一个空集；遍历 nums，每个数都让子集总数翻倍。
  • 翻倍方式：先记下 size = ans.size()，把前 size 个每个复制一份、加上 x、追加到尾部。
  • 旧子集不含 x、新子集带上 x，正好一分为二，不重不漏。
  • 只遍历 i < size（旧的那些）；新追加的不再复制，否则死循环。

最优解

时间复杂度 O(n × 2^n)，空间复杂度 O(2^n)（不计输出）
1import java.util.*;2 3class Solution {4    public List<List<Integer>> subsets(int[] nums) {5        List<List<Integer>> ans = new ArrayList<>();6        ans.add(new ArrayList<>());            // 从空集出发7        for (int x : nums) {8            // 每来一个数：把现有每个子集复制一份、加上 x9            int size = ans.size();10            for (int i = 0; i < size; i++) {11                List<Integer> t = new ArrayList<>(ans.get(i));12                t.add(x);13                ans.add(t);14            }15        }16        return ans;17    }18}
题目

给你一个整数数组 nums ，数组中的元素 互不相同 。返回该数组所有可能的子集（幂集）。

解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。

示例 1：

输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

示例 2：

输入：nums = [0]
输出：[[],[0]]

提示：

  • 1 <= nums.length <= 10
  • -10 <= nums[i] <= 10
  • nums 中的所有元素 互不相同
