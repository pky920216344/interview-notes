回溯：每串先压成 26 位字符集掩码（串内有重复记 -1 永不选），逐串选/不选，掩码与已选 mask 无交集才能拼，取总长最大。

思路

  • 预处理：每串算出 26 位掩码；串内出现重复字符就记 -1，它永远不可能入选，直接跳过。
  • dfs(i, mask)：mask 是已选字符集。每个串两条分支——不选；掩码与 mask 无交集时选（mask | masks[i]）。
  • 长度由 lens[i] 在「选」分支里累加；n ≤ 16，最多 2^16 条路径，不用记忆化也很快。

最优解

时间复杂度 O(2^n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    private int[] masks;    // 每个串的 26 位字符集掩码；含重复字符的串记 -1（永远不能选）5    private int[] lens;6    private int n;7 8    public int maxLength(List<String> arr) {9        n = arr.size();10        masks = new int[n];11        lens = new int[n];12        for (int i = 0; i < n; i++) {13            String s = arr.get(i);14            int m = 0;15            boolean dup = false;16            for (int k = 0; k < s.length(); k++) {17                int b = 1 << (s.charAt(k) - 'a');18                if ((m & b) != 0) { dup = true; break; }19                m |= b;20            }21            masks[i] = dup ? -1 : m;22            lens[i] = s.length();23        }24        return dfs(0, 0);25    }26 27    // 已选字符集为 mask，从前 i 个串里继续挑；返回还能再凑出的最大长度28    private int dfs(int i, int mask) {29        if (i == n) return 0;30        int best = dfs(i + 1, mask);                        // 不选第 i 个31        if (masks[i] >= 0 && (masks[i] & mask) == 0) {      // 字符集不相交才能选32            int take = lens[i] + dfs(i + 1, mask | masks[i]);33            if (take > best) best = take;34        }35        return best;36    }37}
题目

给定一个字符串数组 arr，字符串 s 是将 arr 的含有 不同字母 的 子序列 字符串 连接 所得的字符串。

请返回所有可行解 s 中最长长度。

子序列 是一种可以从另一个数组派生而来的数组，通过删除某些元素或不删除元素而不改变其余元素的顺序。

示例 1：

输入：arr = ["un","iq","ue"]
输出：4
解释：所有可能的串联组合是：
- ""
- "un"
- "iq"
- "ue"
- "uniq" ("un" + "iq")
- "ique" ("iq" + "ue")
最大长度为 4。

示例 2：

输入：arr = ["cha","r","act","ers"]
输出：6
解释：可能的解答有 "chaers" 和 "acters"。

示例 3：

输入：arr = ["abcdefghijklmnopqrstuvwxyz"]
输出：26

提示：

  • 1 <= arr.length <= 16
  • 1 <= arr[i].length <= 26
  • arr[i] 中只含有小写英文字母
