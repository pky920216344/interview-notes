536. 从字符串生成二叉树

递归下降解析：读一个整数当结点，跟一对括号就递归读左子树，再跟一对就读右子树。

思路

  • 语法只有三种成分：整数（可带负号）、(、)；一个全局下标 i 一路向右吃字符。
  • parse()：先读整数建结点；若下一个字符是 (，吃掉后递归得左子树，再吃 )；若还有 (，同样方式得右子树。
  • 递归入口遇到 ) 或串结束说明是空子树——这也顺带处理了空串输入。
  • 数字要按多位读：while 里累加 v = v*10 + digit，负号单独记。

时间复杂度 O(n)，空间复杂度 O(h)
1class Solution {2    private String s;3    private int i;   // 解析进度：当前读到的字符下标4 5    public TreeNode str2tree(String s) {6        this.s = s;7        i = 0;8        return parse();   // 空串返回 null9    }10 11    // 递归下降：读一个结点 = 读整数 + 可选的 "(左子树)" + 可选的 "(右子树)"12    private TreeNode parse() {13        if (i == s.length() || s.charAt(i) == ')') return null;14        boolean neg = false;15        if (s.charAt(i) == '-') {16            neg = true;17            i++;18        }19        int v = 0;20        while (i < s.length() && Character.isDigit(s.charAt(i))) {21            v = v * 10 + (s.charAt(i) - '0');22            i++;23        }24        TreeNode node = new TreeNode(neg ? -v : v);25        if (i < s.length() && s.charAt(i) == '(') {26            i++;                  // 吃掉 '('，递归读左子树27            node.left = parse();28            i++;                  // 吃掉配对的 ')'29            if (i < s.length() && s.charAt(i) == '(') {30                i++;31                node.right = parse();32                i++;33            }34        }35        return node;36    }37}
