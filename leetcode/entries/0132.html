132. 分割回文串 II

  • 困难
  • 频度 5
  • 动态规划
  • 字符串
  • 动态规划
  • 待提交

先 O(n²) 预处理回文表 pal[i][j]（两端相等 + 内层回文），再 DP：cut[i] = 前 i+1 个字符的最少切割数，按「最后一段」枚举转移。

思路

  • 回文表：pal[i][j] = (s[i]==s[j]) && (长度 < 2 或 pal[i+1][j-1])；i 倒着扫，算长区间时内层已就绪。
  • cut[i]：整段 s[0..i] 是回文 → 0；否则初值 i（每个字符间都切），再枚举最后一段起点 j：pal[j][i] 成立时 cut[i] = min(cut[i], cut[j-1]+1)。
  • 答案 cut[n-1]；两个 DP 共用一个内层下标，写的时候先表后切，别混两层循环方向。

图解

最优解

时间复杂度 O(n²)，空间复杂度 O(n²)
1class Solution {2    public int minCut(String s) {3        int n = s.length();4        // pal[i][j]：s[i..j] 是否回文；i 倒着扫才能用到内层小区间5        boolean[][] pal = new boolean[n][n];6        for (int i = n - 1; i >= 0; i--)7            for (int j = i; j < n; j++)8                pal[i][j] = s.charAt(i) == s.charAt(j) && (j - i < 2 || pal[i + 1][j - 1]);9        // cut[i]：前 i+1 个字符最少切几刀10        int[] cut = new int[n];11        for (int i = 0; i < n; i++) {12            if (pal[0][i]) { cut[i] = 0; continue; }13            cut[i] = i;   // 最坏：每个字符之间都切一刀14            for (int j = 1; j <= i; j++)15                // 最后一段取 s[j..i] 且是回文，前面的代价看 cut[j-1]16                if (pal[j][i]) cut[i] = Math.min(cut[i], cut[j - 1] + 1);17        }18        return cut[n - 1];19    }20}
题目

给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是回文串。

返回符合要求的 最少分割次数 。

示例 1：

输入：s = "aab"
输出：1
解释：只需一次分割就可将 s 分割成 ["aa","b"] 这样两个回文子串。

示例 2：

输入：s = "a"
输出：0

示例 3：

输入：s = "ab"
输出：1

提示：

  • 1 <= s.length <= 2000
  • s 仅由小写英文字母组成
