475. 供暖器

  • 简单
  • 频度 3
  • 二分查找
  • 数组
  • 双指针
  • 二分查找
  • 排序
  • 待提交

排序 + 二分：每个房子在供暖器里二分找「第一个 ≥ 它」的位置，取左右两个供暖器里较近的距离，答案 = 所有房子距离的最大值。

思路

  • 两组坐标都排序；排序后每个房子只需看左右各一个供暖器，不必扫全部。
  • 二分找第一个 ≥ h 的供暖器下标 lo：heaters[lo] 是右侧最近，heaters[lo-1] 是左侧最近，取距离较小者。
  • 一侧不存在（lo 在两端）时用 Integer.MAX_VALUE 兜底，最后答案取所有房子需求的最大半径。

图解

最优解

时间复杂度 O(n log n + m log m)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int findRadius(int[] houses, int[] heaters) {5        Arrays.sort(houses);6        Arrays.sort(heaters);7        int ans = 0;8        for (int h : houses) {9            // 二分找第一个位置 ≥ h 的供暖器，下标记为 lo10            int lo = 0, hi = heaters.length;   // 循环不变量：答案在 [lo, hi) 里11            while (lo < hi) {12                int mid = (lo + hi) >>> 1;13                if (heaters[mid] < h) lo = mid + 1;14                else hi = mid;15            }16            // 只需看左右各一个供暖器：lo 是右侧最近，lo-1 是左侧最近17            int dr = lo < heaters.length ? heaters[lo] - h : Integer.MAX_VALUE;18            int dl = lo > 0 ? h - heaters[lo - 1] : Integer.MAX_VALUE;19            // 这个房子需要的半径取左右较近者；整体半径取所有房子里的最大值20            ans = Math.max(ans, Math.min(dl, dr));21        }22        return ans;23    }24}
题目

冬季已经来临。 你的任务是设计一个有固定加热半径的供暖器向所有房屋供暖。

在加热器的加热半径范围内的每个房屋都可以获得供暖。

现在，给出位于一条水平线上的房屋 houses 和供暖器 heaters 的位置，请你找出并返回可以覆盖所有房屋的最小加热半径。

注意：所有供暖器 heaters 都遵循你的半径标准，加热的半径也一样。

示例 1:

输入: houses = [1,2,3], heaters = [2]
输出: 1
解释: 仅在位置 2 上有一个供暖器。如果我们将加热半径设为 1，那么所有房屋就都能得到供暖。

示例 2:

输入: houses = [1,2,3,4], heaters = [1,4]
输出: 1
解释: 在位置 1, 4 上有两个供暖器。我们需要将加热半径设为 1，这样所有房屋就都能得到供暖。

示例 3：

输入：houses = [1,5], heaters = [2]
输出：3

提示：

  • 1 <= houses.length, heaters.length <= 3 * 104
  • 1 <= houses[i], heaters[i] <= 109
