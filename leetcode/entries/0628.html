628. 三个数的最大乘积

  • 简单
  • 频度 13
  • 模拟
  • 数组
  • 数学
  • 排序
  • 待提交

线性扫一遍，只留五个数：最大的三个和最小的两个；答案是 max(三最大乘积, 两最小×最大)。

思路

  • 全是正数时答案是三个最大的；有负数时「两个最小的负数 × 最大的数」可能反超（负负得正）。
  • 维护 max1 ≥ max2 ≥ max3 和 min1 ≤ min2：每个 x 挤进前三名时，后面的名次依次往后挪一位。
  • 最后取 max(max1*max2*max3, min1*min2*max1)，一遍扫完，不用排序。

时间复杂度 O(n)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int maximumProduct(int[] nums) {5        // max1 ≥ max2 ≥ max3 是最大的三个数；min1 ≤ min2 是最小的两个6        int max1 = Integer.MIN_VALUE, max2 = Integer.MIN_VALUE, max3 = Integer.MIN_VALUE;7        int min1 = Integer.MAX_VALUE, min2 = Integer.MAX_VALUE;8        for (int x : nums) {9            // x 挤进前三名时，后面的依次往后挪一位10            if (x >= max1) { max3 = max2; max2 = max1; max1 = x; }11            else if (x >= max2) { max3 = max2; max2 = x; }12            else if (x > max3) max3 = x;13            // x 挤进最小的两个时同理14            if (x <= min1) { min2 = min1; min1 = x; }15            else if (x < min2) min2 = x;16        }17        // 两最小负数相乘得正，再乘最大数，可能反超三最大18        return Math.max(max1 * max2 * max3, min1 * min2 * max1);19    }20}
题目

给你一个整型数组 nums。

在数组中找出由三个数组成的 最大 乘积，并返回这个 最大 乘积。

示例 1：

输入：nums = [1,2,-3]
输出：-6
解释：只有三个数字 1、2 和 -3，因此最大乘积是 1 * 2 * -3 = -6。

示例 2：

输入：nums = [1,2,3,4]
输出：24
解释：最大的乘积来自三个最大的数字：2 * 3 * 4 = 24。

示例 3：

输入：nums = [-1,-2,-3]
输出：-6
解释：只有三个数字 -1、-2 和 -3，因此最大乘积是 (-1) * (-2) * (-3) = -6。

提示：

  • 3 <= nums.length <= 104
  • -1000 <= nums[i] <= 1000
