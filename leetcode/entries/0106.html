106. 从中序与后序遍历序列构造二叉树

后序最后一个是根：哈希表存中序下标定位切分；从后往前取根时先建右子树再建左子树，p 才对得上。

思路

  • 后序的末尾是根；哈希表 pos 存「中序值 → 下标」，一次建好、O(1) 定位，免去每次线性扫。
  • 根在中序的位置 mid：[lo, mid−1] 是左子树、[mid+1, hi] 是右子树，递归切分。
  • 用全局下标 p 从后往前吃后序：先建右子树再建左子树，p 才正好按「根→右→左」的倒序推进（和 105 题的前序版本正好左右相反）。
  • 递归深度 O(h)，最坏一条链 O(n)；值互不相同是哈希定位的前提。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    // pos：值 -> 中序下标；p：后序下一个根（从后往前）5    private Map<Integer, Integer> pos = new HashMap<>();6    private int p;7 8    public TreeNode buildTree(int[] inorder, int[] postorder) {9        // 每次调用先复位，防上一次调用的残留10        p = postorder.length - 1;11        pos.clear();12        for (int i = 0; i < inorder.length; i++) pos.put(inorder[i], i);13        return build(inorder, postorder, 0, inorder.length - 1);14    }15 16    // 中序区间 [lo, hi] 建树：后序末尾是根17    private TreeNode build(int[] inorder, int[] postorder, int lo, int hi) {18        if (lo > hi) return null;19        TreeNode root = new TreeNode(postorder[p--]);20        int mid = pos.get(root.val);21        // 从后往前取根，必须先右后左，p 才能正好对上22        root.right = build(inorder, postorder, mid + 1, hi);23        root.left = build(inorder, postorder, lo, mid - 1);24        return root;25    }26}
题目

给定两个整数数组 inorder 和 postorder ，其中 inorder 是二叉树的中序遍历， postorder 是同一棵树的后序遍历，请你构造并返回这颗 二叉树 。

示例 1:

输入：inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
输出：[3,9,20,null,null,15,7]

示例 2:

输入：inorder = [-1], postorder = [-1]
输出：[-1]

提示:

  • 1 <= inorder.length <= 3000
  • postorder.length == inorder.length
  • -3000 <= inorder[i], postorder[i] <= 3000
  • inorder 和 postorder 都由 不同 的值组成
  • postorder 中每一个值都在 inorder 中
  • inorder 保证是树的中序遍历
  • postorder 保证是树的后序遍历
