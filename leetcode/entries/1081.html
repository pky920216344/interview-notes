1081. 不同字符的最小子序列

单调栈贪心：栈里存「还没定死」的字符；新字符更小且栈顶后面还有剩，就弹掉栈顶（以后能补回来）。

思路

  • left[c] 先数好每种字符还剩几个没读；in[c] 记录是否已在栈里，在栈里的直接跳过。
  • 读到 c：只要栈顶比 c 大且 left[栈顶] > 0（后面还有，弹掉以后能补回来），就弹栈顶。
  • 两个条件缺一不可：栈顶更大但后面没有了，弹掉就再也回不来，只能保留（这是最容易漏的分支）。
  • 栈底到栈顶就是字典序最小、每种字符恰一次的子序列。

最优解

时间复杂度 O(n)，空间复杂度 O(26)
1class Solution {2    public String smallestSubsequence(String s) {3        int[] left = new int[26];    // 每种字符还剩几个没读4        boolean[] in = new boolean[26];5        for (int i = 0; i < s.length(); i++) left[s.charAt(i) - 'a']++;6        StringBuilder sb = new StringBuilder();   // 当栈用，栈顶是最后一个字符7        for (int i = 0; i < s.length(); i++) {8            char c = s.charAt(i);9            left[c - 'a']--;10            if (in[c - 'a']) continue;   // 已在栈里：再放一个也不会更小11            // 栈顶比 c 大且后面还有：弹掉，以后还能补回来12            while (sb.length() > 0 && sb.charAt(sb.length() - 1) > c13                    && left[sb.charAt(sb.length() - 1) - 'a'] > 0) {14                in[sb.charAt(sb.length() - 1) - 'a'] = false;15                sb.deleteCharAt(sb.length() - 1);16            }17            sb.append(c);18            in[c - 'a'] = true;19        }20        return sb.toString();21    }22}
题目

返回 s 字典序最小的子序列，该子序列包含 s 的所有不同字符，且只包含一次。

示例 1：

输入：s = "bcabc"
输出："abc"

示例 2：

输入：s = "cbacdcbc"
输出："acdb"

提示：

  • 1 <= s.length <= 1000
  • s 由小写英文字母组成

注意：该题与 316 https://leetcode.cn/problems/remove-duplicate-letters/ 相同
