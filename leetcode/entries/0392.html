双指针：i 指着 s 里下一个要找的字符，扫 t，对上就 i++；扫完 i 走满 s 就是子序列。

思路

  • i 是 s 中待匹配的下标，j 一路扫 t，每个 t[j] 只看一眼。
  • t[j] == s[i] 就 i++：贪心取最早的匹配不会错，后面只会更宽裕。
  • 扫完看 i == s.length()；s 为空时天然成立，t 扫完 i 没走满就是 false。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean isSubsequence(String s, String t) {3        int i = 0;4        // 扫 t：当前字符对上 s 的下一位就 i++，对不上就跳过5        for (int j = 0; j < t.length() && i < s.length(); j++) {6            if (t.charAt(j) == s.charAt(i)) i++;7        }8        // i 走到头 = s 的每个字符都在 t 里按顺序找到了9        return i == s.length();10    }11}
题目

给定字符串 s 和 t ，判断 s 是否为 t 的子序列。

字符串的一个子序列是原始字符串删除一些（也可以不删除）字符而不改变剩余字符相对位置形成的新字符串。（例如，"ace"是"abcde"的一个子序列，而"aec"不是）。

进阶：

如果有大量输入的 S，称作 S1, S2, ... , Sk 其中 k >= 10亿，你需要依次检查它们是否为 T 的子序列。在这种情况下，你会怎样改变代码？

  • 0 <= t.length <= 10^4
  • 两个字符串都只由小写字符组成。
