普通队列管进出，另挂一个单调递减双端队列，队头永远等于当前队列里的最大值。

思路

  • max 保持单调递减：add 时把队尾所有比新值小的挤掉再入队——被挤的没出队新值就先进来了，最大轮不到它们。
  • get_max：直接看 max 队头，空队返回 -1。
  • remove：普通队列出队得到 v；若 v 恰好等于 max 队头，max 队头同步弹出（其他值不在 max 里，不用管）。
  • 挤掉相等的吗？不：用严格小于才挤，相等要留着，否则先出的最大值会被误删。

1import java.util.*;2 3class Checkout {4    private final Deque<Integer> q = new ArrayDeque<>();     // 普通队列：保证先进先出5    private final Deque<Integer> max = new ArrayDeque<>();   // 单调递减：队头永远是当前最大6 7    public Checkout() {8    }9 10    public int get_max() {11        return max.isEmpty() ? -1 : max.peekFirst();12    }13 14    public void add(int value) {15        q.addLast(value);16        // 队尾比 value 小的全部挤掉：它们没出队 value 就先进来了，最大轮不到它们17        while (!max.isEmpty() && max.peekLast() < value) max.pollLast();18        max.addLast(value);19    }20 21    public int remove() {22        if (q.isEmpty()) return -1;23        int v = q.pollFirst();24        // 出队的恰好是当前最大：单调队列的队头同步弹出25        if (max.peekFirst() == v) max.pollFirst();26        return v;27    }28}
题目

请设计一个自助结账系统，该系统需要通过一个队列来模拟顾客通过购物车的结算过程，需要实现的功能有：

  • get_max()：获取结算商品中的最高价格，如果队列为空，则返回 -1
  • add(value)：将价格为 value 的商品加入待结算商品队列的尾部
  • remove()：移除第一个待结算的商品价格，如果队列为空，则返回 -1

注意，为保证该系统运转高效性，以上函数的均摊时间复杂度均为 O(1)

示例 1：

输入: 
["Checkout","add","add","get_max","remove","get_max"]
[[],[4],[7],[],[],[]]

输出: [null,null,null,7,4,7]

示例 2：

输入: 
["Checkout","remove","get_max"]
[[],[],[]]

输出: [null,-1,-1]

提示：

  • 1 <= get_max, add, remove 的总操作数 <= 10000
  • 1 <= value <= 10^5
