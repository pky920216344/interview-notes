205. 同构字符串

双向哈希一遍扫：记录每个字符「上次出现的位置 + 1」，同一位置两边字符的上次位置必须相等。

思路

  • 同构 = 存在字符间的一一对应：s[i] 换成对应字符要恰好得到 t，两个方向都不能一对多。
  • ls[a]、lt[b] 分别记 s、t 字符上次出现的位置 + 1（0 表示没出现过）。
  • 每位比较 ls[a] == lt[b]：相等说明两边字符的出现节奏一致；不等立即 false。
  • 位置相同即隐含双向一致：a 第二次出现在 b 第二次出现的同一位，既保证 a→b 稳定，也保证没有别的字符映射到 b。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean isIsomorphic(String s, String t) {3        // last[c]：字符 c 最后一次出现的位置 + 1，0 表示还没出现过4        int[] ls = new int[128], lt = new int[128];5        for (int i = 0; i < s.length(); i++) {6            char a = s.charAt(i), b = t.charAt(i);7            // 同一位置上，两边字符的「上次出现位置」必须一致，否则映射断了8            if (ls[a] != lt[b]) return false;9            ls[a] = i + 1;10            lt[b] = i + 1;11        }12        return true;13    }14}
题目

给定两个字符串 s 和 t ，判断它们是否是同构的。

如果 s 中的字符可以按某种映射关系替换得到 t ，那么这两个字符串是同构的。

每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

示例 1：

输入：s = "egg", t = "add"

输出：true

解释：

字符串 s 和 t 可以通过以下方式变得相同：

  • 将 'e' 映射为 'a'。
  • 将 'g' 映射为 'd'。

示例 2：

输入：s = "f11", t = "b23"

输出：false

解释：

字符串 s 和 t 无法变得相同，因为 '1' 需要同时映射到 '2' 和 '3'。

示例 3：

输入：s = "paper", t = "title"

输出：true

提示：

  • 1 <= s.length <= 5 * 104
  • t.length == s.length
  • s 和 t 由任意有效的 ASCII 字符组成
