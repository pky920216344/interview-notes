120. 三角形最小路径和

  • 中等
  • 频度 35
  • 动态规划
  • 数组
  • 动态规划
  • 力扣已通过

自底向上：dp 就用最后一行，从倒数第二行起每格取「下面两个邻居中小的」加上自己，滚到顶 dp[0] 即答案。

思路

  • 定义 dp[j] = 从下一行第 j 格走到底的最小路径和，先直接装最后一行。
  • 从倒数第二行往上：dp[j] = min(dp[j], dp[j+1]) + triangle[i][j]，本行第 j 格只能汇入下一行的 j 或 j+1。
  • 自底向上不用回溯、不用判边界（dp 比 j+1 恒在范围内），滚到顶后 dp[0] 就是答案。
  • 值有负数，自顶向下贪心挑较小孩子会错（局部小 ≠ 全局小），必须把每个位置的答案都用 DP 算出来。

最优解

时间复杂度 O(n²)，空间复杂度 O(n)
1import java.util.List;2 3class Solution {4    public int minimumTotal(List<List<Integer>> triangle) {5        int n = triangle.size();6        // dp[j]：从下一行第 j 格走到底的最小和，先装最后一行7        int[] dp = new int[triangle.get(n - 1).size()];8        for (int j = 0; j < dp.length; j++) dp[j] = triangle.get(n - 1).get(j);9        // 自底向上：本行 j 汇入下一行的 j 或 j + 1，选小的10        for (int i = n - 2; i >= 0; i--) {11            List<Integer> row = triangle.get(i);12            for (int j = 0; j <= i; j++) {13                dp[j] = Math.min(dp[j], dp[j + 1]) + row.get(j);14            }15        }16        // 顶点即整条路径的最小和17        return dp[0];18    }19}
题目

给定一个三角形 triangle ，找出自顶向下的最小路径和。

每一步只能移动到下一行中相邻的结点上。相邻的结点 在这里指的是 下标 与 上一层结点下标 相同或者等于 上一层结点下标 + 1 的两个结点。也就是说，如果正位于当前行的下标 i ，那么下一步可以移动到下一行的下标 i 或 i + 1 。

示例 1：

输入：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
输出：11
解释：如下面简图所示：
   2
  3 4
 6 5 7
4 1 8 3
自顶向下的最小路径和为 11（即，2 + 3 + 5 + 1 = 11）。

示例 2：

输入：triangle = [[-10]]
输出：-10

提示：

  • 1 <= triangle.length <= 200
  • triangle[0].length == 1
  • triangle[i].length == triangle[i - 1].length + 1
  • -104 <= triangle[i][j] <= 104

进阶：
