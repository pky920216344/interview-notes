只存前序遍历的值；反序列化时带着上下界递归，值越界就说明它属于别的子树，还给上层。

思路

  • BST 前序 = 「根 + 左子树 + 右子树」，且左子树值全小于根、右子树全大于根——所以不用存 null 占位，中序由大小关系唯一推出。
  • 反序列化 de(lo, hi)：读队头的值 v，若 v 超出 [lo, hi] 就返回 null（不消耗这个值）；否则建结点，左子树范围 [lo, v]、右子树 [v, hi]。
  • 越界「还给上层」是关键：1 的右边界是 3，读到 8 时拒绝，8 一路回到根的右子树才被收下。
  • 比「前序 + null 标记」的通用法省一半字符；范围用 long 防溢出。

题目

序列化是将数据结构或对象转换为一系列位的过程，以便它可以存储在文件或内存缓冲区中，或通过网络连接链路传输，以便稍后在同一个或另一个计算机环境中重建。

设计一个算法来序列化和反序列化 二叉搜索树 。 对序列化/反序列化算法的工作方式没有限制。 您只需确保二叉搜索树可以序列化为字符串，并且可以将该字符串反序列化为最初的二叉搜索树。

编码的字符串应尽可能紧凑。

示例 1：

输入：root = [2,1,3]
输出：[2,1,3]

示例 2：

输入：root = []
输出：[]
