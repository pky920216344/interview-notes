688. 骑士在棋盘上的概率

  • 频度 2
  • 动态规划
  • 动态规划
  • 待提交

逐层概率 DP：每个「马」位把概率均分给 8 个落点，出界的份额直接丢弃；答案 = 走完 k 步后全棋盘概率之和。

思路

  • cur[r][c] = 走当前步数后停在这格且从未出界的概率；初始只有起点是 1。
  • 每一步：把每格概率除以 8 加到 8 个「马」位上；落点出界的那份直接丢弃（这正是损失的概率）。
  • 滚动两个 n×n 数组即可；走完 k 步后把全棋盘概率加起来就是答案。
  • 概率只做加法和除法，double 足够；判定题给 1e-6 容差。

时间复杂度 O(k·n²)，空间复杂度 O(n²)
1class Solution {2    public double knightProbability(int n, int k, int row, int column) {3        double[][] cur = new double[n][n];          // cur[r][c]：走当前步数后停在这格的概率4        cur[row][column] = 1;5        int[][] dirs = {{1, 2}, {2, 1}, {-1, 2}, {-2, 1}, {1, -2}, {2, -1}, {-1, -2}, {-2, -1}};6        for (int step = 0; step < k; step++) {7            double[][] next = new double[n][n];8            for (int r = 0; r < n; r++) {9                for (int c = 0; c < n; c++) {10                    if (cur[r][c] == 0) continue;11                    for (int[] d : dirs) {12                        int nr = r + d[0], nc = c + d[1];13                        if (nr < 0 || nr >= n || nc < 0 || nc >= n) continue;   // 出界的份额直接丢弃14                        next[nr][nc] += cur[r][c] / 8;   // 每个马位均分 1/8 的概率15                    }16                }17            }18            cur = next;19        }20        double ans = 0;                             // 还在棋盘上 = 所有格概率之和21        for (int r = 0; r < n; r++) for (int c = 0; c < n; c++) ans += cur[r][c];22        return ans;23    }24}
题目

在一个 n x n 的国际象棋棋盘上，一个骑士从单元格 (row, column) 开始，并尝试进行 k 次移动。行和列是 从 0 开始 的，所以左上单元格是 (0,0) ，右下单元格是 (n - 1, n - 1) 。

象棋骑士有8种可能的走法，如下图所示。每次移动在基本方向上是两个单元格，然后在正交方向上是一个单元格。

每次骑士要移动时，它都会随机从8种可能的移动中选择一种(即使棋子会离开棋盘)，然后移动到那里。

骑士继续移动，直到它走了 k 步或离开了棋盘。

返回 骑士在棋盘停止移动后仍留在棋盘上的概率 。

示例 1：

输入: n = 3, k = 2, row = 0, column = 0
输出: 0.0625
解释: 有两步(到(1,2)，(2,1))可以让骑士留在棋盘上。
在每一个位置上，也有两种移动可以让骑士留在棋盘上。
骑士留在棋盘上的总概率是0.0625。

示例 2：

输入: n = 1, k = 0, row = 0, column = 0
输出: 1.00000

提示:

  • 1 <= n <= 25
  • 0 <= k <= 100
  • 0 <= row, column <= n - 1
