318. 最大单词长度乘积

  • 中等
  • 频度 3
  • 位运算
  • 哈希表
  • 位运算
  • 数组
  • 字符串
  • 待提交

每个词压成 26 位字母掩码；掩码相同的词只留最长的；两掩码按位与为 0（无公共字母）时用长度乘积更新答案。

思路

  • 每个词算一个 26 位掩码：出现过的字母对应位记 1；有无公共字母就是一次按位与。
  • 哈希表 掩码 → 最长词长 去重：字母组合相同的词，只有最长的还值得配对。
  • 去重后的候选两两试配：(mask1 & mask2) == 0 就用长度乘积更新答案；都不行返回 0。

1import java.util.*;2 3class Solution {4    public int maxProduct(String[] words) {5        // 掩码 -> 见过该字母组合的单词里最长的长度6        Map<Integer, Integer> best = new HashMap<>();7        for (String w : words) {8            int mask = 0;9            for (int i = 0; i < w.length(); i++) mask |= 1 << (w.charAt(i) - 'a');10            Integer old = best.get(mask);11            if (old == null || old < w.length()) best.put(mask, w.length());12        }13        // 候选两两试配：两掩码按位与为 0（没有公共字母）才能配14        List<int[]> cand = new ArrayList<>();15        for (Map.Entry<Integer, Integer> e : best.entrySet()) {16            cand.add(new int[]{e.getKey(), e.getValue()});17        }18        int ans = 0;19        for (int i = 0; i < cand.size(); i++) {20            for (int j = i + 1; j < cand.size(); j++) {21                if ((cand.get(i)[0] & cand.get(j)[0]) == 0) {22                    ans = Math.max(ans, cand.get(i)[1] * cand.get(j)[1]);23                }24            }25        }26        return ans;27    }28}
题目

给你一个字符串数组 words ，找出并返回 length(words[i]) * length(words[j]) 的最大值，并且这两个单词不含有公共字母。如果不存在这样的两个单词，返回 0 。

示例 1：

输入：words = ["abcw","baz","foo","bar","xtfn","abcdef"]
输出：16 
解释：这两个单词为"abcw", "xtfn"。

示例 2：

输入：words = ["a","ab","abc","d","cd","bcd","abcd"]
输出：4 
解释：这两个单词为 "ab", "cd"。

示例 3：

输入：words = ["a","aa","aaa","aaaa"]
输出：0 
解释：不存在这样的两个单词。

提示：

  • 2 <= words.length <= 1000
  • 1 <= words[i].length <= 1000
  • words[i] 仅包含小写字母
