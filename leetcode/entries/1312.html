1312. 让字符串成为回文串的最少插入次数

  • 动态规划
  • 字符串
  • 动态规划
  • 待提交

区间 DP：dp[i][j] 是把 s[i..j] 补成回文的最少插入数；两端相等取里面那段，不等就补一端取较小者 +1。

思路

  • dp[i][j]：把 s[i..j] 补成回文的最少插入数；长度 1 恒为 0。
  • s[i] == s[j]：两端天然配对，dp[i][j] = dp[i+1][j-1]（区间长 2 时取到 0，默认值正合适）。
  • 不等：在左端补 s[j] 或在右端补 s[i]，dp[i][j] = min(dp[i+1][j], dp[i][j-1]) + 1。
  • i 必须倒着扫、j 正着扫，保证算 dp[i][j] 时下边一行和左边一格已就绪；答案 dp[0][n-1]。
  • 等价视角：答案 = n − 最长回文子序列长度（回文子序列之外的字符都得配对补上）。

最优解

时间复杂度 O(n²)，空间复杂度 O(n²)
1class Solution {2    public int minInsertions(String s) {3        int n = s.length();4        // dp[i][j]：把 s[i..j] 补成回文的最少插入数5        int[][] dp = new int[n][n];6        // i 倒着扫：算 dp[i][j] 时 dp[i+1][*] 必须已经填好7        for (int i = n - 2; i >= 0; i--) {8            for (int j = i + 1; j < n; j++) {9                // 两端相等：不用补，答案就是里面那段10                if (s.charAt(i) == s.charAt(j)) dp[i][j] = dp[i + 1][j - 1];11                // 不等：在左端或右端补一个字符，取较小者再 +112                else dp[i][j] = Math.min(dp[i + 1][j], dp[i][j - 1]) + 1;13            }14        }15        return dp[0][n - 1];16    }17}
题目

给你一个字符串 s ，每一次操作你都可以在字符串的任意位置插入任意字符。

请你返回让 s 成为回文串的 最少操作次数 。

「回文串」是正读和反读都相同的字符串。

示例 1：

输入：s = "zzazz"
输出：0
解释：字符串 "zzazz" 已经是回文串了，所以不需要做任何插入操作。

示例 2：

输入：s = "mbadm"
输出：2
解释：字符串可变为 "mbdadbm" 或者 "mdbabdm" 。

示例 3：

输入：s = "leetcode"
输出：5
解释：插入 5 个字符后字符串变为 "leetcodocteel" 。

提示：

  • 1 <= s.length <= 500
  • s 中所有字符都是小写字母。
