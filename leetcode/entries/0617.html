617. 合并二叉树

双递归同位合并：两边都有值就相加留在 root1 上，一边为空就把另一边整棵接上。

思路

  • 两边都非空：root1.val += root2.val，再递归合并左右孩子；合并就地改在 root1 上。
  • 有一边为空：直接返回另一边，剩下的子树原样接上，不用逐个复制。
  • 递归到空就停，所以只访问两树重叠的部分，代价是 O(min(m, n))。

图解

最优解

时间复杂度 O(min(m, n))，空间复杂度 O(min(m, n))
1class Solution {2    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {3        // 有一边走到空：另一边剩下的整棵直接接上4        if (root1 == null) return root2;5        if (root2 == null) return root1;6        // 同位都有值：相加留在 root1 上，再递归合并左右7        root1.val += root2.val;8        root1.left = mergeTrees(root1.left, root2.left);9        root1.right = mergeTrees(root1.right, root2.right);10        return root1;   // 同位相加、空位接管都完成了11    }12}
题目

给你两棵二叉树： root1 和 root2 。

想象一下，当你将其中一棵覆盖到另一棵之上时，两棵树上的一些节点将会重叠（而另一些不会）。你需要将这两棵树合并成一棵新二叉树。合并的规则是：如果两个节点重叠，那么将这两个节点的值相加作为合并后节点的新值；否则，不为 null 的节点将直接作为新二叉树的节点。

返回合并后的二叉树。

注意: 合并过程必须从两个树的根节点开始。

示例 1：

输入：root1 = [1,3,2,5], root2 = [2,1,3,null,4,null,7]
输出：[3,4,5,5,4,null,7]

示例 2：

输入：root1 = [1], root2 = [1,2]
输出：[2,2]

提示：

  • 两棵树中的节点数目在范围 [0, 2000] 内
  • -104 <= Node.val <= 104
