BFS 逐层走：队列里只放还没展开的结点，弹一个收一个值、孩子排到队尾；出队顺序天然就是从左到右的层序。

思路

  • 空树直接返回空数组；否则根结点先入队。
  • 循环弹队头：值收进结果，左右孩子排到队尾——队列里永远是「还没展开的结点」。
  • 出队顺序自动按层、从左到右推进，不需要记录层号；收完把列表转成 int[] 返回。

最优解

时间复杂度 O(n)，空间复杂度 O(n)（队列宽度上限是一层结点数）
1import java.util.*;2 3class Solution {4    public int[] decorateRecord(TreeNode root) {5        if (root == null) return new int[0];6        List<Integer> vals = new ArrayList<>();7        Queue<TreeNode> q = new ArrayDeque<>();8        q.add(root);9        // 队列里只放还没展开的结点：弹一个、收一个值、孩子排到队尾10        while (!q.isEmpty()) {11            TreeNode node = q.poll();12            vals.add(node.val);13            if (node.left != null) q.add(node.left);14            if (node.right != null) q.add(node.right);15        }16        // 收集完再转数组，循环里不用预知结点总数17        int[] ans = new int[vals.size()];18        for (int i = 0; i < ans.length; i++) ans[i] = vals.get(i);19        return ans;20    }21}
题目

一棵圣诞树记作根节点为 root 的二叉树，节点值为该位置装饰彩灯的颜色编号。请按照从 左 到 右 的顺序返回每一层彩灯编号。

示例 1：

输入：root = [8,17,21,18,null,null,6]
输出：[8,17,21,18,6]

提示：

  1. 节点总数 <= 1000
