859. 亲密字符串

  • 简单
  • 频度 2
  • 模拟
  • 哈希表
  • 字符串
  • 待提交

长度相等才谈交换；两串完全相等时要存在重复字符，否则必须恰好 2 处不同且交叉相等。

思路

  • 长度不等直接 false；完全相等时交换必须「换了个寂寞」——存在重复字符才换得回来。
  • 有差异时数不同的位置：恰好 2 处且 s[i]=goal[j]、s[j]=goal[i] 才能一次交换修好。
  • 只有 1 处不同或 ≥3 处都返回 false：1 处时交换必然制造新的不同（用 j >= 0 短路防止越界）。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean buddyStrings(String s, String goal) {3        if (s.length() != goal.length()) return false;4        if (s.equals(goal)) {5            // 完全相等：必须能交换两个相同的字符，也就是要存在重复字符6            int[] seen = new int[26];7            for (int i = 0; i < s.length(); i++)8                if (seen[s.charAt(i) - 'a']++ > 0) return true;9            return false;   // 每个字符都独一无二，怎么换都会变样10        }11        // 不相等：找不同的位置，必须恰好 2 处且交叉相等12        int i = -1, j = -1;13        for (int k = 0; k < s.length(); k++) {14            if (s.charAt(k) != goal.charAt(k)) {15                if (i < 0) i = k;16                else if (j < 0) j = k;17                else return false;   // 第 3 处不同：一次交换救不回18            }19        }20        // j 还没赋值说明只有 1 处不同：换哪都多出一个差异，false21        return j >= 0 && s.charAt(i) == goal.charAt(j) && s.charAt(j) == goal.charAt(i);22    }23}
题目

给你两个字符串 s 和 goal ，只要我们可以通过交换 s 中的两个字母得到与 goal 相等的结果，就返回 true ；否则返回 false 。

交换字母的定义是：取两个下标 i 和 j （下标从 0 开始）且满足 i != j ，接着交换 s[i] 和 s[j] 处的字符。

  • 例如，在 "abcd" 中交换下标 0 和下标 2 的元素可以生成 "cbad" 。

示例 1：

输入：s = "ab", goal = "ba"
输出：true
解释：你可以交换 s[0] = 'a' 和 s[1] = 'b' 生成 "ba"，此时 s 和 goal 相等。

示例 2：

输入：s = "ab", goal = "ab"
输出：false
解释：你只能交换 s[0] = 'a' 和 s[1] = 'b' 生成 "ba"，此时 s 和 goal 不相等。

示例 3：

输入：s = "aa", goal = "aa"
输出：true
解释：你可以交换 s[0] = 'a' 和 s[1] = 'a' 生成 "aa"，此时 s 和 goal 相等。

提示：

  • 1 <= s.length, goal.length <= 2 * 104
  • s 和 goal 由小写英文字母组成
