每 2k 个字符算一段，段内前 k 个反转、后 k 个原样；剩不足 k 时剩多少反转多少。

思路

  • for (i = 0; i < n; i += 2k) 定位每段开头，一次只关心 [i, min(i+k, n)-1]。
  • 反转区间用首尾双指针原地交换；min(i+k, n)-1 自动处理「不足 k 剩多少反多少」。
  • 段内 [i+k, i+2k) 的部分完全不碰，自然保持原样。

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public String reverseStr(String s, int k) {3        char[] a = s.toCharArray();4        int n = a.length;5        // 每 2k 个一段，段内前 k 个反转（不足 k 就剩多少反多少）6        for (int i = 0; i < n; i += 2 * k) {7            reverse(a, i, Math.min(i + k, n) - 1);8        }9        return new String(a);10    }11 12    private void reverse(char[] a, int l, int r) {13        while (l < r) {14            char t = a[l];15            a[l] = a[r];16            a[r] = t;17            l++;18            r--;19        }20    }21}
题目

给定一个字符串 s 和一个整数 k，从字符串开头算起，每计数至 2k 个字符，就反转这 2k 字符中的前 k 个字符，再重新计数。

  • 如果剩余字符少于 k 个，则将剩余字符全部反转。
  • 如果剩余字符小于 2k 但大于或等于 k 个，则反转前 k 个字符，其余字符保持原样。

示例 1：

输入：s = "abcdefg", k = 2
输出："bacdfeg"

示例 2：

输入：s = "abcd", k = 2
输出："bacd"

提示：

  • 1 <= s.length <= 104
  • s 仅由小写英文组成
  • 1 <= k <= 104
