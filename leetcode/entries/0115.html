115. 不同的子序列

  • 困难
  • 频度 21
  • 动态规划
  • 字符串
  • 动态规划
  • 力扣已通过

DP：dp[j] 是 s 前 i 个字符匹配 t 前 j 个的方案数；字符相等时 dp[j] += dp[j-1]，一维数组倒序滚动。

思路

  • 二维递推：dp[i][j] = dp[i-1][j]（不用 s[i]）+ (s[i]==t[j] ? dp[i-1][j-1] : 0)（用 s[i] 匹配）；边界 dp[i][0] = 1。
  • 压成一行后必须倒序扫 j：这样 dp[j-1] 还是上一行的旧值；正序会先把 dp[j-1] 更新成本轮的，污染加法。
  • 内部用 long 累加防溢出，返回时转 int——题面保证答案在 32 位范围内。
  • t 比 s 长时答案自然是 0：dp[j] 只会从更小的 j-1 传上来，凑不够。

图解

最优解

时间复杂度 O(mn)，空间复杂度 O(n)
1class Solution {2    public int numDistinct(String s, String t) {3        int m = s.length(), n = t.length();4        // dp[j]：s 前 i 个字符里匹配 t 前 j 个的方案数，逐行覆盖滚动5        long[] dp = new long[n + 1];6        dp[0] = 1;                                   // 匹配空 t：什么都不选，1 种7        for (int i = 1; i <= m; i++) {8            char c = s.charAt(i - 1);9            // 倒序扫：dp[j-1] 还是上一行的旧值，正序会被本轮污染10            for (int j = n; j >= 1; j--) {11                if (c == t.charAt(j - 1)) dp[j] += dp[j - 1];12            }13        }14        return (int) dp[n];                          // 题面保证结果在 int 范围内15    }16}
题目

给你两个字符串 s和 t ，统计并返回在 s 的 子序列 中 t 出现的个数。

测试用例保证结果在 32 位有符号整数范围内。

示例 1：

输入：s = "rabbbit", t = "rabbit"
输出：3
解释：
如下所示, 有 3 种可以从 s 中得到 "rabbit" 的方案。
rabbbit
rabbbit
rabbbit

示例 2：

输入：s = "babgbag", t = "bag"
输出：5
解释：
如下所示, 有 5 种可以从 s 中得到 "bag" 的方案。 
babgbag
babgbag
babgbag
babgbag
babgbag

提示：

  • 1 <= s.length, t.length <= 1000
  • s 和 t 由英文字母组成
