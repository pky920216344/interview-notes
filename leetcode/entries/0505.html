还是「滚到撞墙」的停点图，但边权=滚过的格数长短不一，用 Dijkstra（小顶堆）求到终点的最短滚动距离。

思路

  • 与 490 同款滚动：从停点沿一个方向 while 滚到撞墙，滚过的格数 len 就是这条边的权。
  • 距离按「格数」算而不是「滚动次数」，各边不等长，普通 BFS 会错，要用 Dijkstra。
  • dist 表记每个停点的最短距离；堆顶弹出时若 d > dist[r][c] 是过期条目，跳过。
  • 弹出终点即可返回 dist；堆空没到终点返回 -1（终点可能只是路过格，不是停点）。

时间复杂度 O(m × n × max(m, n) × log(m × n))，空间复杂度 O(m × n)
1import java.util.*;2 3class Solution {4    public int shortestDistance(int[][] maze, int[] start, int[] destination) {5        int m = maze.length, n = maze[0].length;6        int[][] dist = new int[m][n];7        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);8        dist[start[0]][start[1]] = 0;9        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);10        pq.add(new int[]{0, start[0], start[1]});11        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};12        while (!pq.isEmpty()) {13            int[] top = pq.poll();14            int d = top[0], r = top[1], c = top[2];15            if (d > dist[r][c]) continue;   // 堆里的过期条目，跳过16            if (r == destination[0] && c == destination[1]) return d;17            for (int[] dir : dirs) {18                int nr = r, nc = c, len = 0;19                while (open(maze, nr + dir[0], nc + dir[1])) {20                    nr += dir[0];21                    nc += dir[1];22                    len++;23                }24                // 这条边的权 = 滚过的格数；Dijkstra 松弛到每个停点25                if (d + len < dist[nr][nc]) {26                    dist[nr][nc] = d + len;27                    pq.add(new int[]{d + len, nr, nc});28                }29            }30        }31        return -1;32    }33 34    // (r, c) 在界内且是空格，球就能滚过去35    private boolean open(int[][] maze, int r, int c) {36        return r >= 0 && r < maze.length && c >= 0 && c < maze[0].length && maze[r][c] == 0;37    }38}
