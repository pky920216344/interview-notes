724. 寻找数组的中心下标

  • 简单
  • 频度 3
  • 前缀和/差分
  • 数组
  • 前缀和
  • 待提交

先算总和，再扫一遍只维护左侧和 left；left == total − left − nums[i] 时 i 就是中心下标。

思路

  • 右侧和不必单独维护：right = total − left − nums[i]，一个变量搞定。
  • 从左往右扫，命中立刻 return i，天然就是最靠左的中心下标。
  • 扫完没命中返回 −1；长度为 1 时 left = 0、right = 0，下标 0 就是答案。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int pivotIndex(int[] nums) {3        int total = 0;4        for (int x : nums) total += x;5        // left 是 i 左侧的和；右侧和不用另算：total − left − nums[i]6        int left = 0;7        for (int i = 0; i < nums.length; i++) {8            if (left == total - left - nums[i]) return i;9            left += nums[i];10        }11        return -1;12    }13}
题目

给你一个整数数组 nums ，请计算数组的 中心下标 。

数组 中心下标是数组的一个下标，其左侧所有元素相加的和等于右侧所有元素相加的和。

如果中心下标位于数组最左端，那么左侧数之和视为 0 ，因为在下标的左侧不存在元素。这一点对于中心下标位于数组最右端同样适用。

如果数组有多个中心下标，应该返回 最靠近左边 的那一个。如果数组不存在中心下标，返回 -1 。

示例 1：

输入：nums = [1, 7, 3, 6, 5, 6]
输出：3
解释：
中心下标是 3 。
左侧数之和 sum = nums[0] + nums[1] + nums[2] = 1 + 7 + 3 = 11 ，
右侧数之和 sum = nums[4] + nums[5] = 5 + 6 = 11 ，二者相等。

示例 2：

输入：nums = [1, 2, 3]
输出：-1
解释：
数组中不存在满足此条件的中心下标。

示例 3：

输入：nums = [2, 1, -1]
输出：0
解释：
中心下标是 0 。
左侧数之和 sum = 0 ，（下标 0 左侧不存在元素），
右侧数之和 sum = nums[1] + nums[2] = 1 + -1 = 0 。

提示：

  • 1 <= nums.length <= 104
  • -1000 <= nums[i] <= 1000
