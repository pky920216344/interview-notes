845. 数组中的最长山脉

两遍扫描出 up/down：up[i] 是以 i 结尾的上坡步数，down[i] 是从 i 开始的下坡步数；每个「山顶」长度 = up+down+1。

思路

  • up[i] = up[i-1] + 1（当 arr[i] > arr[i-1]，否则 0），左→右一遍。
  • down[i] = down[i+1] + 1（当 arr[i] > arr[i+1]，否则 0），右→左一遍。
  • 山顶要两边都有坡：up[i] > 0 && down[i] > 0 才是山，长度 up[i] + down[i] + 1。
  • 相等不算坡：arr[i] == arr[i-1] 时 up[i] 归零，平台会打断山脉。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int longestMountain(int[] arr) {3        int n = arr.length;4        int[] up = new int[n], down = new int[n];5        // up[i]：以 i 结尾的连续上坡步数；down[i]：从 i 开始的连续下坡步数6        for (int i = 1; i < n; i++) if (arr[i] > arr[i - 1]) up[i] = up[i - 1] + 1;7        for (int i = n - 2; i >= 0; i--) if (arr[i] > arr[i + 1]) down[i] = down[i + 1] + 1;8        int ans = 0;9        // 山顶：既有上坡进来又有下坡出去，长度 = 上坡 + 山顶 + 下坡10        for (int i = 1; i < n - 1; i++)11            if (up[i] > 0 && down[i] > 0) ans = Math.max(ans, up[i] + down[i] + 1);12        return ans;13    }14}
题目

把符合下列属性的数组 arr 称为 山脉数组 ：

  • arr.length >= 3
  • 存在下标 i（0 < i < arr.length - 1），满足
    • arr[0] < arr[1] < ... < arr[i - 1] < arr[i]
    • arr[i] > arr[i + 1] > ... > arr[arr.length - 1]

给出一个整数数组 arr，返回最长山脉子数组的长度。如果不存在山脉子数组，返回 0 。

示例 1：

输入：arr = [2,1,4,7,3,2,5]
输出：5
解释：最长的山脉子数组是 [1,4,7,3,2]，长度为 5。

示例 2：

输入：arr = [2,2,2]
输出：0
解释：不存在山脉子数组。

提示：

  • 1 <= arr.length <= 104
  • 0 <= arr[i] <= 104
