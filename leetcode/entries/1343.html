1343. 大小为 K 且平均值大于等于阈值的子数组数目

  • 中等
  • 频度 2
  • 滑动窗口
  • 数组
  • 滑动窗口
  • 待提交

定长滑窗：「平均值 ≥ threshold」换成「窗口和 ≥ threshold×k」的整数判断；每步滑入右边一个、滑出左边一个。

思路

  • 平均值判断换成 sum ≥ (long)threshold×k，避免除法；乘积用 long 防溢出。
  • 先把前 k 个加进 sum；窗口凑满后每步判一次，判完立刻减掉最左元素，为下一个窗口做准备。
  • 定长窗口不用左右指针来回动，只有「进一个、出一个」，一遍扫完。

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int numOfSubarrays(int[] arr, int k, int threshold) {3        // 平均值 ≥ threshold ⟺ 窗口和 ≥ threshold×k，全部用 long 防止相乘溢出4        long limit = (long) threshold * k;5        long sum = 0;6        int ans = 0;7        for (int i = 0; i < arr.length; i++) {8            sum += arr[i];9            if (i < k - 1) continue;   // 窗口还没凑满 k 个10            // [i-k+1, i] 是一个完整窗口：判定完就把最左边的元素移出窗口11            if (sum >= limit) ans++;12            sum -= arr[i - k + 1];13        }14        return ans;15    }16}
题目

给你一个整数数组 arr 和两个整数 k 和 threshold 。

请你返回长度为 k 且平均值大于等于 threshold 的子数组数目。

示例 1：

输入：arr = [2,2,2,2,5,5,5,8], k = 3, threshold = 4
输出：3
解释：子数组 [2,5,5],[5,5,5] 和 [5,5,8] 的平均值分别为 4，5 和 6 。其他长度为 3 的子数组的平均值都小于 4 （threshold 的值)。

示例 2：

输入：arr = [11,13,17,23,29,31,7,5,2,3], k = 3, threshold = 5
输出：6
解释：前 6 个长度为 3 的子数组平均值都大于 5 。注意平均值不是整数。

提示：

  • 1 <= arr.length <= 105
  • 1 <= arr[i] <= 104
  • 1 <= k <= arr.length
  • 0 <= threshold <= 104
