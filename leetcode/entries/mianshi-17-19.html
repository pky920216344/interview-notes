面试题 17.19. 消失的两个数字

  • 困难
  • 频度 3

  • 位运算
  • 数组
  • 哈希表
  • 待提交

全集 1..n 与数组互相异或得到 x^y；取最低位的 1 把全集和数组各分两组，两组各自再异或出 x、y。

思路

  • 全集 1..n 异或一遍再异或数组：现身的数两两抵消，剩下两个缺失数的异或 x^y（x≠y，非零）。
  • x^y 的最低位 1 那一位上，x、y 必定一个 0 一个 1——这是把它俩分开的唯一依据。
  • 全集和数组都按「这一位是否为 1」分两组各自异或：每组里现身的抵消，剩下一个缺失数。
  • 两组结果排序后输出（题面说任意顺序都行，固定排序好对拍）。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] missingTwo(int[] nums) {3        int n = nums.length + 2;               // 全集是 1..n，缺了两个4        int xy = 0;5        for (int i = 1; i <= n; i++) xy ^= i;  // 全集异或一遍6        for (int x : nums) xy ^= x;            // 再异或数组：现身的全部抵消，剩下 x^y7        int low = xy & -xy;                    // x^y 的最低位 1：x、y 在这一位必定不同8        int a = 0, b = 0;9        for (int i = 1; i <= n; i++) {         // 全集和数组都按这一位分成两组10            if ((i & low) != 0) a ^= i;11            else b ^= i;12        }13        for (int x : nums) {14            if ((x & low) != 0) a ^= x;15            else b ^= x;16        }17        // 每组里现身的数又全部抵消，各剩一个缺失的数18        return new int[]{Math.min(a, b), Math.max(a, b)};19    }20}
题目

给定一个数组，包含从 1 到 N 所有的整数，但其中缺了两个数字。你能在 O(N) 时间内只用 O(1) 的空间找到它们吗？

以任意顺序返回这两个数字均可。

示例 1：

输入：[1]
输出：[2,3]

示例 2：

输入：[2,3]
输出：[1,4]

提示：

  • nums.length <= 30000
