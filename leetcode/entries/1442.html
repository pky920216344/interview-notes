a==b ⟺ [i..k] 整段异或为 0 ⟺ P[i]==P[k+1]；哈希记每个前缀值的 (次数, 下标和)，ans += 次数×k − 下标和。

思路

  • 前缀异或 P[i] = arr[0..i-1] 的异或和；a == b 两段异或相消，等价于 P[i] == P[k+1]。
  • 一旦相等，j 可取 [i+1, k] 里任何位置，这对 (i, k) 贡献 k - i 个三元组。
  • 从左往右扫 k：先查表里 P[k+1] 的 (次数 c, 下标和 s)，ans += c*k - s（即 Σ(k−i)）；再把 P[k] 入表供后续当 i 用。
  • 顺序不能反：P[k] 自己不能当本次的 i（要求 i < j ≤ k）。

1import java.util.*;2 3class Solution {4    public int countTriplets(int[] arr) {5        // cnt[v]：前缀异或值 v 出现过的次数；sum[v]：出现 v 的那些前缀下标之和6        Map<Integer, Integer> cnt = new HashMap<>(), sum = new HashMap<>();7        int ans = 0, pre = 0;   // pre = P[k]，前 k 个元素的异或和8        for (int k = 0; k < arr.length; k++) {9            int v = pre ^ arr[k];   // v = P[k+1]；P[i]==P[k+1] 说明 [i..k] 整段异或为 010            Integer c = cnt.get(v);11            if (c != null) ans += c * k - sum.get(v);   // 每个这样的 i 贡献 k-i 个可取的 j12            cnt.merge(pre, 1, Integer::sum);   // P[k] 入表，成为后续步骤的 i 候选13            sum.merge(pre, k, Integer::sum);14            pre = v;15        }16        return ans;17    }18}
题目

给你一个整数数组 arr 。

现需要从数组中取三个下标 i、j 和 k ，其中 (0 <= i < j <= k < arr.length) 。

a 和 b 定义如下：

  • a = arr[i] ^ arr[i + 1] ^ ... ^ arr[j - 1]
  • b = arr[j] ^ arr[j + 1] ^ ... ^ arr[k]

注意：^ 表示 按位异或 操作。

请返回能够令 a == b 成立的三元组 (i, j , k) 的数目。

示例 1：

输入：arr = [2,3,1,6,7]
输出：4
解释：满足题意的三元组分别是 (0,1,2), (0,2,2), (2,3,4) 以及 (2,4,4)

示例 2：

输入：arr = [1,1,1,1,1]
输出：10

示例 3：

输入：arr = [2,3]
输出：0

示例 4：

输入：arr = [1,3,5,7,9]
输出：3

示例 5：

输入：arr = [7,11,12,9,5,2,7,17,22]
输出：8

提示：

  • 1 <= arr.length <= 300
  • 1 <= arr[i] <= 10^8
