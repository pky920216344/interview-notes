786. 第 K 个最小的质数分数

  • 困难
  • 频度 6
  • 堆
  • 数组
  • 双指针
  • 二分查找
  • 排序
  • 堆（优先队列）
  • 待提交

把 n(n−1)/2 个分数看成分母从大到小的 n−1 条有序链，小根堆做多路归并，弹 k−1 次后堆顶就是答案。

思路

  • 固定分子 i 时，分母越大分数越小：把每行看成一条降序链，行头 (i, n−1) 是行内最小，先把 n−1 个行头入堆。
  • 堆按分数比较：a/b < c/d 用交叉相乘 a·d < c·b 判，避免浮点误差（值 ≤ 3e4，乘积不溢出）。
  • 弹出堆顶 (i, j) 后，压入同一行的下一个 (i, j−1)（j−1 > i 才压）；弹出 k−1 次后，堆顶就是第 k 小。
  • 分数两两不等（1 和互异质数之比），堆顶序列唯一，答案确定。

时间复杂度 O(n + k log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] kthSmallestPrimeFraction(int[] arr, int k) {5        int n = arr.length;6        // 小根堆放分子下标对 (i, j)，i < j，按分数 arr[i]/arr[j] 比较（交叉相乘防精度误差）7        PriorityQueue<int[]> pq = new PriorityQueue<>(8            (a, b) -> Long.compare((long) arr[a[0]] * arr[b[1]], (long) arr[a[1]] * arr[b[0]]));9        // 每个分子行的最小分数在分母最大处：先把每行的行头入堆10        for (int i = 0; i + 1 < n; i++) pq.offer(new int[]{i, n - 1});11        while (--k > 0) {12            int[] t = pq.poll();13            // 同一行里，分母减小分数变大：弹出 (i, j) 就压入行内的下一个 (i, j-1)14            if (t[1] - 1 > t[0]) pq.offer(new int[]{t[0], t[1] - 1});15        }16        return new int[]{arr[pq.peek()[0]], arr[pq.peek()[1]]};17    }18}
题目

给你一个按递增顺序排序的数组 arr 和一个整数 k 。数组 arr 由 1 和若干 质数 组成，且其中所有整数互不相同。

对于每对满足 0 <= i < j < arr.length 的 i 和 j ，可以得到分数 arr[i] / arr[j] 。

那么第 k 个最小的分数是多少呢?  以长度为 2 的整数数组返回你的答案, 这里 answer[0] == arr[i] 且 answer[1] == arr[j] 。

 

示例 1：

输入：arr = [1,2,3,5], k = 3
输出：[2,5]
解释：已构造好的分数,排序后如下所示: 
1/5, 1/3, 2/5, 1/2, 3/5, 2/3
很明显第三个最小的分数是 2/5

示例 2：

输入：arr = [1,7], k = 1
输出：[1,7]

提示：

  • 2 <= arr.length <= 1000
  • 1 <= arr[i] <= 3 * 104
  • arr[0] == 1
  • arr[i] 是一个 质数 ，i > 0
  • arr 中的所有数字 互不相同 ，且按 严格递增 排序
  • 1 <= k <= arr.length * (arr.length - 1) / 2
