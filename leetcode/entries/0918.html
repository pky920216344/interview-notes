一趟扫描同时跑最大 Kadane 和最小 Kadane：答案 = max(普通最大和, 总和 − 最小子数组和)，全负要特判。

思路

  • 环形最大子数组只有两种形态：不跨缝（普通 Kadane 的 bestMax），或跨缝（把中间一段最小子数组挖掉）。
  • 跨缝的最大和 = total - bestMin；最小子数组用同款 Kadane 顺带求出：curMin = min(curMin + v, v)。
  • 全负特判：此时 bestMin == total，环形公式会算出空环的 0；bestMax < 0 就直接返回 bestMax。
  • 单元素数组也成立：total - bestMin = 0 不会盖过 bestMax 本身。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxSubarraySumCircular(int[] nums) {3        // 一趟扫描同时跑最大 Kadane 和最小 Kadane，顺带累加总和4        int total = 0, curMax = 0, bestMax = Integer.MIN_VALUE;5        int curMin = 0, bestMin = Integer.MAX_VALUE;6        for (int v : nums) {7            curMax = Math.max(curMax + v, v);8            bestMax = Math.max(bestMax, curMax);9            curMin = Math.min(curMin + v, v);10            bestMin = Math.min(bestMin, curMin);11            total += v;12        }13        // 全负时 bestMin == total，环形公式会算出空环的 0，直接返回普通最大14        if (bestMax < 0) return bestMax;15        // 跨缝的最大子数组 = 总和 - 挖掉的中间最小子数组16        return Math.max(bestMax, total - bestMin);17    }18}
题目

给定一个长度为 n 的环形整数数组 nums ，返回 nums 的非空 子数组 的最大可能和 。

环形数组 意味着数组的末端将会与开头相连呈环状。形式上， nums[i] 的下一个元素是 nums[(i + 1) % n] ， nums[i] 的前一个元素是 nums[(i - 1 + n) % n] 。

子数组 最多只能包含固定缓冲区 nums 中的每个元素一次。形式上，对于子数组 nums[i], nums[i + 1], ..., nums[j] ，不存在 i <= k1, k2 <= j 其中 k1 % n == k2 % n 。

示例 1：

输入：nums = [1,-2,3,-2]
输出：3
解释：从子数组 [3] 得到最大和 3

示例 2：

输入：nums = [5,-3,5]
输出：10
解释：从子数组 [5,5] 得到最大和 5 + 5 = 10

示例 3：

输入：nums = [3,-2,2,-3]
输出：3
解释：从子数组 [3] 和 [3,-2,2] 都可以得到最大和 3

提示：

  • n == nums.length
  • 1 <= n <= 3 * 104
  • -3 * 104 <= nums[i] <= 3 * 104​​​​​​​
