678. 有效的括号字符串

不真的给 '*' 定角色：维护「未配对左括号数」的可行区间 [lo, hi]，逐字符更新，最后看 0 在不在区间里。

思路

  • (：两端 +1；)：两端 -1；*：左端 -1（当右括号）、右端 +1（当左括号），区间被撑开。
  • hi < 0 立即 false：右括号多到把 * 全当左括号都填不平。
  • lo < 0 时重置回 0 而不是 false：说明某个 * 不必当右括号（改成空串即可），下限不该为负。
  • 结尾 lo == 0 才有效：即使全按最省的分法也剩不下未配对的左括号。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public boolean checkValidString(String s) {3        // [lo, hi]：扫到现在，未配对左括号数的最小 / 最大可能值4        int lo = 0, hi = 0;5        for (char c : s.toCharArray()) {6            if (c == '(') { lo++; hi++; }7            else if (c == ')') { lo--; hi--; }8            else { lo--; hi++; }           // '*' 当右括号最坏、当左括号最好9            if (hi < 0) return false;      // 连 '*' 都当左括号也填不平右括号10            if (lo < 0) lo = 0;            // lo 为负说明某个 '*' 改当空串就好，兜回 011        }12        return lo == 0;                    // 最省的分法下也没剩左括号，才配得平13    }14}
题目

给你一个只包含三种字符的字符串，支持的字符类型分别是 '('、')' 和 '*'。请你检验这个字符串是否为有效字符串，如果是 有效 字符串返回 true 。

有效 字符串符合如下规则：

  • 任何左括号 '(' 必须有相应的右括号 ')'。
  • 任何右括号 ')' 必须有相应的左括号 '(' 。
  • 左括号 '(' 必须在对应的右括号之前 ')'。
  • '*' 可以被视为单个右括号 ')' ，或单个左括号 '(' ，或一个空字符串 ""。

示例 1：

输入：s = "()"
输出：true

示例 2：

输入：s = "(*)"
输出：true

示例 3：

输入：s = "(*))"
输出：true

提示：

  • 1 <= s.length <= 100
  • s[i] 为 '('、')' 或 '*'
