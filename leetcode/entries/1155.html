1155. 掷骰子等于目标和的方法数

  • 中等
  • 频度 3
  • 动态规划
  • 动态规划
  • 待提交

分组背包：dp[j] = 已掷骰子凑出和 j 的方式数；每掷一枚骰子，dp[j] = Σ dp[j−d]（d=1..k），倒序扫防同枚重复用。

思路

  • 一维滚动：dp[j] 是「目前掷过的骰子」凑出和 j 的方式数，初始 dp[0] = 1。
  • 每掷一枚骰子：dp[j] = Σ dp[j-d]（d=1..k），含义是「这枚掷出 d，之前凑出 j-d」。
  • 必须倒序扫 j：保证读到的 dp[j-d] 还是上一枚骰子的值，不会被本轮覆盖。
  • 中间和用 long 累加再 % 1_000_000_007；target < n 或 > n·k 时自然得 0。

最优解

时间复杂度 O(n·target·k)，空间复杂度 O(target)
1class Solution {2    public int numRollsToTarget(int n, int k, int target) {3        final int MOD = 1_000_000_007;4        // dp[j]：已掷的骰子凑出和 j 的方式数；dp[0]=1 表示一枚都没掷、和为 05        int[] dp = new int[target + 1];6        dp[0] = 1;7        for (int i = 1; i <= n; i++) {8            // 倒序扫：dp[j-d] 还是上一枚骰子的值，不会被本轮覆盖9            for (int j = target; j >= 0; j--) {10                long sum = 0;11                for (int d = 1; d <= k && d <= j; d++) sum += dp[j - d];12                dp[j] = (int) (sum % MOD);13            }14        }15        return dp[target];16    }17}
题目

这里有 n 个一样的骰子，每个骰子上都有 k 个面，分别标号为 1 到 k 。

给定三个整数 n、k 和 target，请返回投掷骰子的所有可能得到的结果（共有 kn 种方式），使得骰子面朝上的数字总和等于 target。

由于答案可能很大，你需要对 109 + 7 取模。

示例 1：

输入：n = 1, k = 6, target = 3
输出：1
解释：你掷了一个有 6 个面的骰子。
得到总和为 3 的结果的方式只有一种。

示例 2：

输入：n = 2, k = 6, target = 7
输出：6
解释：你掷了两个骰子，每个骰子有 6 个面。
有 6 种方式得到总和为 7 的结果: 1+6, 2+5, 3+4, 4+3, 5+2, 6+1。

示例 3：

输入：n = 30, k = 30, target = 500
输出：222616187
解释：返回的结果必须对 109 + 7 取模。

提示：

  • 1 <= n, k <= 30
  • 1 <= target <= 1000
