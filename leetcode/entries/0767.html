计数：最大次数超过 (n+1)/2 直接返回空串；否则按次数从多到少先填偶数位 0,2,4…，再回头填奇数位。

思路

  • 先数 26 个字母的出现次数；max > (n+1)/2 时无论怎么排都有两个相邻，返回空串。
  • 字母按次数从多到少排（同次数按字母序），依次填偶数位 0,2,4…，填满后跳回 idx=1 续填奇数位。
  • 同一字母的相邻槽位实际下标差 2，天然不同；次数最多的字母排在最前、只占偶数位——这正是次数不能超 (n+1)/2 的原因。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public String reorganizeString(String s) {5        int n = s.length();6        int[] cnt = new int[26];7        for (int i = 0; i < n; i++) cnt[s.charAt(i) - 'a']++;8        // 次数超过一半必然出现相邻同字母，直接摆不出来9        int max = 0;10        for (int v : cnt) max = Math.max(max, v);11        if (max > (n + 1) / 2) return "";12        // 按次数从多到少排字母（次数相同按字母序），多的先占位13        Integer[] order = new Integer[26];14        for (int c = 0; c < 26; c++) order[c] = c;15        Arrays.sort(order, (a, b) -> cnt[a] != cnt[b] ? cnt[b] - cnt[a] : a - b);16        // 依次填偶数位 0,2,4…，填满再回头填奇数位 1,3,5…17        char[] res = new char[n];18        int idx = 0;19        for (int c : order) {20            for (int k = 0; k < cnt[c]; k++) {21                res[idx] = (char) ('a' + c);22                idx += 2;23                if (idx >= n) idx = 1;24            }25        }26        return new String(res);27    }28}
题目

给定一个字符串 s ，检查是否能重新排布其中的字母，使得任意两个相邻字符不相同。

返回 s 的任意可能的重新排列。若不可行，返回空字符串 "" 。

示例 1:

输入: s = "aab"
输出: "aba"

示例 2:

输入: s = "aaab"
输出: ""

提示:

  • 1 <= s.length <= 500
  • s 只包含小写字母
