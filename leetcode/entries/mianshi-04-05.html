  • 待提交

递归传开区间 (lo, hi)：每个结点必须严格落在祖先们共同收紧的界内，越界即假。

思路

  • 只查「孩子 < 父」不够：非法结构可能藏在孙子层（例题里 4 是根的右孩子但小于根）。
  • 递归携带 (lo, hi)：进左子树把上界收紧为 node.val，进右子树把下界收紧为 node.val；val ≤ lo 或 val ≥ hi 直接 false。
  • BST 定义是严格大于/小于，相等也非法（[2,2,2] 是 false）。
  • 界用 long：结点值可能是 Integer.MIN_VALUE / MAX_VALUE，用 int 当界会先把它们误判非法。
  • 短路：check(左) && check(右)，左边一假右边不再进。

时间复杂度 O(n)，空间复杂度 O(h)
1class Solution {2    public boolean isValidBST(TreeNode root) {3        // 每个结点都必须落在开区间 (lo, hi) 里；4        // 用 long 当界，免得 ±21 亿的结点值被 int 界误判5        return check(root, Long.MIN_VALUE, Long.MAX_VALUE);6    }7 8    // 子树里所有值都要严格落在 (lo, hi) 内9    private boolean check(TreeNode node, long lo, long hi) {10        if (node == null) return true;11        if (node.val <= lo || node.val >= hi) return false;12        // 左子树的上界收紧为 node.val；右子树的下界收紧为 node.val13        return check(node.left, lo, node.val) && check(node.right, node.val, hi);14    }15}
题目

实现一个函数，检查一棵二叉树是否为二叉搜索树。

示例 1： 
输入：
    2
   / \
  1   3
输出：true
示例 2： 
输入：
    5
   / \
  1   4
     / \
    3   6
输出：false
解释：输入为: [5,1,4,null,null,3,6]。
     根节点的值为 5 ，但是其右子节点值为 4 。
