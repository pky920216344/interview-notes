1139. 最大的以 1 为边界的正方形

  • 中等
  • 频度 2
  • 动态规划
  • 数组
  • 动态规划
  • 矩阵
  • 待提交

预处理每格「向左、向上连续 1 的长度」；枚举右下角，边长从 min(左,上) 往下试，只验顶边和左边够不够长。

思路

  • left[i][j]、up[i][j]：该格向左、向上连续 1 的长度，一次扫描递推出来。
  • 以 (i,j) 为右下角、边长 s：底边、右边自动满足（left、up ≥ s 才进循环），只需再验顶边 left[i-s+1][j] ≥ s 和左边 up[i][j-s+1] ≥ s。
  • 边长从大到小试，成立就更新答案；最多试到 min(m,n) 种，总面积答案 = 最大边长²。

最优解

时间复杂度 O(m·n·min(m,n))，空间复杂度 O(m·n)
1class Solution {2    public int largest1BorderedSquare(int[][] grid) {3        int m = grid.length, n = grid[0].length;4        // left/up 多留一行一列：每格向左、向上连续 1 的长度（含自己）5        int[][] left = new int[m + 1][n + 1], up = new int[m + 1][n + 1];6        for (int i = 0; i < m; i++) {7            for (int j = 0; j < n; j++) {8                if (grid[i][j] == 1) {9                    left[i + 1][j + 1] = left[i + 1][j] + 1;10                    up[i + 1][j + 1] = up[i][j + 1] + 1;11                }12            }13        }14        int ans = 0;15        for (int i = 0; i < m; i++) {16            for (int j = 0; j < n; j++) {17                // 以 (i,j) 为右下角：边长从 min(向左, 向上) 往下试，成功就停18                for (int s = Math.min(left[i + 1][j + 1], up[i + 1][j + 1]); s > ans; s--) {19                    // 顶边、左边也要够长20                    if (left[i - s + 2][j + 1] >= s && up[i + 1][j - s + 2] >= s) {21                        ans = s;22                        break;23                    }24                }25            }26        }27        return ans * ans;28    }29}
题目

给你一个由若干 0 和 1 组成的二维网格 grid，请你找出边界全部由 1 组成的最大 正方形 子网格，并返回该子网格中的元素数量。如果不存在，则返回 0。

示例 1：

输入：grid = [[1,1,1],[1,0,1],[1,1,1]]
输出：9

示例 2：

输入：grid = [[1,1,0,0]]
输出：1

提示：

  • 1 <= grid.length <= 100
  • 1 <= grid[0].length <= 100
  • grid[i][j] 为 0 或 1
