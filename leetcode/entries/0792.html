26 个桶按「下一个要匹配的字符」给词排队；s 从左到右扫，每读一个字符就推进对应桶里所有词的指针。

思路

  • 初始把每个词按首字母入桶；桶里存「词下标 + 已匹配长度」。
  • s 每读一个字符 c：取出桶 c 里全部词，各推进一格；没匹配完的按新字符重新入桶。
  • 推进到词尾的计数 +1；每个词只被 s 的每个字符摸一次，不逐词扫 s。

最优解

时间复杂度 O(s + Σ|words|)，空间复杂度 O(Σ|words|)
1import java.util.*;2 3class Solution {4    public int numMatchingSubseq(String s, String[] words) {5        // waiting[c]：下一个要匹配的字符是 c 的词，排成一队6        List<int[]>[] waiting = new List[26];7        for (int i = 0; i < 26; i++) waiting[i] = new ArrayList<>();8        for (int i = 0; i < words.length; i++) waiting[words[i].charAt(0) - 'a'].add(new int[]{i, 0});9        int ans = 0;10        for (int p = 0; p < s.length(); p++) {11            List<int[]> cur = waiting[s.charAt(p) - 'a'];12            waiting[s.charAt(p) - 'a'] = new ArrayList<>();13            for (int[] w : cur) {14                int next = w[1] + 1;15                if (next == words[w[0]].length()) ans++;  // 整个词都匹配上了16                else waiting[words[w[0]].charAt(next) - 'a'].add(new int[]{w[0], next});17            }18        }19        return ans;20    }21}
题目

给定字符串 s 和字符串数组 words, 返回  words[i] 中是s的子序列的单词个数 。

字符串的 子序列 是从原始字符串中生成的新字符串，可以从中删去一些字符(可以是none)，而不改变其余字符的相对顺序。

  • 例如， “ace” 是 “abcde” 的子序列。

示例 1:

输入: s = "abcde", words = ["a","bb","acd","ace"]
输出: 3
解释: 有三个是 s 的子序列的单词: "a", "acd", "ace"。

Example 2:

输入: s = "dsahjpjauf", words = ["ahjpjau","ja","ahbwzgqnuk","tnmlanowax"]
输出: 2

提示:

  • 1 <= s.length <= 5 * 104
  • 1 <= words.length <= 5000
  • 1 <= words[i].length <= 50
  • words[i]和 s 都只由小写字母组成。
