286. 墙与门

  • 中等
  • 频度 1
  • 广度优先搜索
  • 广度优先搜索
  • 数组
  • 矩阵
  • 未经力扣验证

多源 BFS：所有门一起入队当第 0 层，一圈圈向外扩散；空房第一次被碰到时的层数就是答案。

思路

  • 求「每个空房到最近门」反过来做：从全部门同时出发 BFS，距离逐层 +1。
  • 空房只在还是 INF 时入队：第一次到达一定来自最近的门，之后不再更新。
  • 墙 -1 既当起点也不穿越；被墙围死的空房保持 INF。

1import java.util.*;2 3class Solution {4    private static final int INF = 2147483647;5 6    public void wallsAndGates(int[][] rooms) {7        int m = rooms.length, n = rooms[0].length;8        Queue<int[]> queue = new ArrayDeque<>();9        // 所有门（值为 0）一起入队，当 BFS 的第 0 层10        for (int i = 0; i < m; i++)11            for (int j = 0; j < n; j++)12                if (rooms[i][j] == 0) queue.add(new int[]{i, j});13        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};14        while (!queue.isEmpty()) {15            int[] cur = queue.poll();16            for (int[] d : dirs) {17                int r = cur[0] + d[0], c = cur[1] + d[1];18                // 只填还是 INF 的空房：先碰到它的一定来自最近的门19                if (r >= 0 && r < m && c >= 0 && c < n && rooms[r][c] == INF) {20                    rooms[r][c] = rooms[cur[0]][cur[1]] + 1;21                    queue.add(new int[]{r, c});22                }23            }24        }25    }26}
