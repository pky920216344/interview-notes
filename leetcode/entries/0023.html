23. 合并 K 个升序链表

分治：把 k 条链表对半拆开，递归合并左右两半，再用「合并两个有序链表」把两条合成一条。

思路

  • merge(lo, hi) 返回 lists[lo..hi] 合并后的链表：lo == hi 直接返回；否则从 mid 对半拆，递归合并左右两半。
  • 左右两半各得一条有序链表后，用 mergeTwo 合成一条：就是「合并两个有序链表」，哨兵 + 谁小接谁，最后接上剩下的。
  • 每层递归合计只处理 N 个结点（N 是结点总数），共 log k 层，所以时间 O(N log k)；递归栈深 O(log k)。
  • 边界：lists 为空数组直接返回 null；空链表（null）照常参与合并。

最优解

时间复杂度 O(N log k)，空间复杂度 O(log k)
1class Solution {2    public ListNode mergeKLists(ListNode[] lists) {3        if (lists.length == 0) return null;4        return merge(lists, 0, lists.length - 1);5    }6 7    // 合并 lists[lo..hi]：对半拆开，各自合并成一条，再把两条合并8    private ListNode merge(ListNode[] lists, int lo, int hi) {9        if (lo == hi) return lists[lo];10        int mid = lo + (hi - lo) / 2;11        ListNode left = merge(lists, lo, mid);12        ListNode right = merge(lists, mid + 1, hi);13        return mergeTwo(left, right);14    }15 16    // 合并两个升序链表：哨兵 + 谁小接谁17    private ListNode mergeTwo(ListNode a, ListNode b) {18        ListNode dummy = new ListNode(), tail = dummy;19        while (a != null && b != null) {20            if (a.val <= b.val) {21                tail.next = a;22                a = a.next;23            } else {24                tail.next = b;25                b = b.next;26            }27            tail = tail.next;28        }29        // 剩下的那一条整段接上30        tail.next = a != null ? a : b;31        return dummy.next;32    }33}
题目

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

示例 1：

输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6

示例 2：

输入：lists = []
输出：[]

示例 3：

输入：lists = [[]]
输出：[]

提示：

  • k == lists.length
  • 0 <= k <= 10^4
  • 0 <= lists[i].length <= 500
  • -10^4 <= lists[i][j] <= 10^4
  • lists[i] 按 升序 排列
  • lists[i].length 的总和不超过 10^4
