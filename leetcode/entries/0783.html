中序遍历 BST 得到升序序列，最小差值只会出现在相邻两个值之间；边遍历边用一个 prev 记上一个值。

思路

  • BST 中序 = 升序序列，任意两值的最小差必是序列里相邻两值之差，不用两两比。
  • 递归中序：左 → 结点 → 右；访问结点时 ans = min(ans, val - prev)，然后 prev = val。
  • prev 用 -1 当哨兵（值域非负），第一次访问只记 prev 不算差。

1class Solution {2    private int prev = -1;               // 中序序列里的上一个值；-1 表示还没访问过任何结点3    private int ans = Integer.MAX_VALUE;4 5    public int minDiffInBST(TreeNode root) {6        prev = -1;                       // 每次调用重置状态（判题机可能复用同一个对象）7        ans = Integer.MAX_VALUE;8        inorder(root);9        return ans;10    }11 12    // 中序遍历 BST 得到升序序列，最小差值只会出现在相邻两个值之间13    private void inorder(TreeNode node) {14        if (node == null) return;15        inorder(node.left);16        if (prev >= 0) ans = Math.min(ans, node.val - prev);17        prev = node.val;18        inorder(node.right);19    }20}
题目

给你一个二叉搜索树的根节点 root ，返回 树中任意两不同节点值之间的最小差值 。

差值是一个正数，其数值等于两值之差的绝对值。

示例 1：

输入：root = [4,2,6,1,3]
输出：1

示例 2：

输入：root = [1,0,48,null,null,12,49]
输出：1

提示：

  • 树中节点的数目范围是 [2, 100]
  • 0 <= Node.val <= 105

注意：本题与 530：https://leetcode.cn/problems/minimum-absolute-difference-in-bst/ 相同
