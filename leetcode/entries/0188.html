188. 买卖股票的最佳时机 IV

  • 频度 17
  • 动态规划
  • 贪心
  • 数组
  • 动态规划
  • 待提交

状态机 DP：buy[j] = 持有第 j 笔的最大收益，sell[j] = 完成 j 笔的最大收益；每天先更新 buy 再更新 sell，O(nk)。

思路

  • 第 123 题（k=2）的推广：buy[j] = max(buy[j], sell[j-1] - p)（接着持有或今天买第 j 笔），sell[j] = max(sell[j], buy[j] + p)（捂着或今天卖第 j 笔）。
  • buy 初始 -∞（没买过就不能卖），用 Integer.MIN_VALUE / 2 防加法溢出；sell 初始 0（同日买卖不亏，天然合法）。
  • k ≥ n/2 时直接贪心：n 天最多只有 n/2 笔完整交易，再多也用不上；把每段上涨差价全加起来，避免 O(nk) 的白费（也是防 MLE）。

最优解

时间复杂度 O(nk)，空间复杂度 O(k)
1import java.util.*;2 3class Solution {4    public int maxProfit(int k, int[] prices) {5        int n = prices.length;6        // 交易次数超过 n/2 就等于不限次数：只要今天比昨天贵，差价全部赚走7        if (k >= n / 2) {8            int ans = 0;9            for (int i = 1; i < n; i++) ans += Math.max(0, prices[i] - prices[i - 1]);10            return ans;11        }12        // buy[j]：正持有第 j 笔（买了没卖）的最大收益；sell[j]：已完成 j 笔的最大收益13        int[] buy = new int[k + 1], sell = new int[k + 1];14        Arrays.fill(buy, Integer.MIN_VALUE / 2);   // 没买过：负无穷，减半防止加价格时溢出15        for (int p : prices) {16            for (int j = 1; j <= k; j++) {17                buy[j] = Math.max(buy[j], sell[j - 1] - p);   // 继续持有，或今天新买第 j 笔18                sell[j] = Math.max(sell[j], buy[j] + p);      // 继续捂着，或今天卖出第 j 笔19            }20        }21        return sell[k];22    }23}
题目

给你一个整数数组 prices 和一个整数 k ，其中 prices[i] 是某支给定的股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 k 笔交易。也就是说，你最多可以买 k 次，卖 k 次。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

示例 1：

输入：k = 2, prices = [2,4,1]
输出：2
解释：在第 1 天 (股票价格 = 2) 的时候买入，在第 2 天 (股票价格 = 4) 的时候卖出，这笔交易所能获得利润 = 4-2 = 2 。

示例 2：

输入：k = 2, prices = [3,2,6,5,0,3]
输出：7
解释：在第 2 天 (股票价格 = 2) 的时候买入，在第 3 天 (股票价格 = 6) 的时候卖出, 这笔交易所能获得利润 = 6-2 = 4 。
     随后，在第 5 天 (股票价格 = 0) 的时候买入，在第 6 天 (股票价格 = 3) 的时候卖出, 这笔交易所能获得利润 = 3-0 = 3 。

提示：

  • 1 <= k <= 100
  • 1 <= prices.length <= 1000
  • 0 <= prices[i] <= 1000
