313. 超级丑数

多指针 DP：每个质数一个指针，指着「下一个要乘的丑数」；每轮取最小候选入表，撞车的指针一起前进防重复。

思路

  • dp 顺序生成超级丑数；ptr[j] 记质数 primes[j] 该乘 dp 里的第几个，候选 = primes[j] × dp[ptr[j]]。
  • 每轮扫一遍候选取最小入 dp，再把所有等于最小值的指针一起前移——否则 6 = 2×3 = 3×2 会进表两次。
  • 候选用 long 存：dp 最大到 2^31 附近时，primes[j] × dp[ptr] 会先溢出 int。

最优解

时间复杂度 O(n × m)，空间复杂度 O(n + m)
1class Solution {2    public int nthSuperUglyNumber(int n, int[] primes) {3        int m = primes.length;4        int[] dp = new int[n];       // dp[i]：第 i+1 个超级丑数，dp[0] = 15        int[] ptr = new int[m];      // 每个质数下一步乘 dp 的第几个6        long[] cand = new long[m];   // 每个质数的候选值，用 long 防乘法溢出7        for (int j = 0; j < m; j++) cand[j] = primes[j];8        dp[0] = 1;                   // 1 不含质因数，也算超级丑数9        for (int i = 1; i < n; i++) {10            long min = Long.MAX_VALUE;11            for (int j = 0; j < m; j++) min = Math.min(min, cand[j]);12            dp[i] = (int) min;13            // 所有撞上同一个最小值的指针一起前进，同一个数才不会生成两次14            for (int j = 0; j < m; j++) {15                if (cand[j] == min) {16                    ptr[j]++;17                    cand[j] = (long) primes[j] * dp[ptr[j]];18                }19            }20        }21        return dp[n - 1];22    }23}
题目

超级丑数 是一个正整数，并满足其所有质因数都出现在质数数组 primes 中。

给你一个整数 n 和一个整数数组 primes ，返回第 n 个 超级丑数 。

题目数据保证第 n 个 超级丑数 在 32-bit 带符号整数范围内。

示例 1：

输入：n = 12, primes = [2,7,13,19]
输出：32 
解释：给定长度为 4 的质数数组 primes = [2,7,13,19]，前 12 个超级丑数序列为：[1,2,4,7,8,13,14,16,19,26,28,32] 。

示例 2：

输入：n = 1, primes = [2,3,5]
输出：1
解释：1 不含质因数，因此它的所有质因数都在质数数组 primes = [2,3,5] 中。
 

提示：

  • 1 <= n <= 105
  • 1 <= primes.length <= 100
  • 2 <= primes[i] <= 1000
  • 题目数据 保证 primes[i] 是一个质数
  • primes 中的所有值都 互不相同 ，且按 递增顺序 排列
