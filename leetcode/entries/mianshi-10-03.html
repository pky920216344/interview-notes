面试题 10.03. 搜索旋转数组

旋转 + 重复的二分：拿 mid 和右端比定哪半有序，相等就丢右端；命中不返回，缩到左端才返回。

思路

  • arr[mid] > arr[right]：旋转点在右半，[left, mid] 有序；< 则 [mid, right] 有序；== 分不清，right--（右端必不是 target）。
  • 有序的那半按值域决定去留；因为要最小下标，arr[left] == target 时直接返回（更小的都已排除）。
  • 命中 arr[mid] 先不返回：right = mid 把它留在窗口里继续向左收缩，缩到左端命中才停。

最优解

时间复杂度 O(log n)，大量重复时退化 O(n)，空间复杂度 O(1)
1class Solution {2    public int search(int[] arr, int target) {3        int left = 0, right = arr.length - 1;4        while (left <= right) {5            // 左端就是 target：更小的下标都已排除，它就是最小下标6            if (arr[left] == target) return left;7            int mid = left + (right - left) / 2;8            if (arr[mid] == target) {9                // 命中先不返回：更小的下标可能还在左边，右端缩到 mid 继续找10                right = mid;11            } else if (arr[mid] > arr[right]) {12                // 右半跨着旋转点，左半 [left, mid] 才有序13                if (arr[left] <= target && target < arr[mid]) right = mid - 1;14                else left = mid + 1;15            } else if (arr[mid] < arr[right]) {16                // 右半 [mid, right] 有序17                if (arr[mid] < target && target <= arr[right]) left = mid + 1;18                else right = mid - 1;19            } else {20                // arr[mid] == arr[right]：分不清哪半有序，右端必不是 target，丢掉21                right--;22            }23        }24        return -1;25    }26}
题目

搜索旋转数组。给定一个排序后的数组，包含n个整数，但这个数组已被旋转过很多次了，次数不详。请编写代码找出数组中的某个元素，假设数组元素原先是按升序排列的。若有多个相同元素，返回索引值最小的一个。

示例 1：

 输入：arr = [15, 16, 19, 20, 25, 1, 3, 4, 5, 7, 10, 14], target = 5
 输出：8（元素5在该数组中的索引）

示例 2：

 输入：arr = [15, 16, 19, 20, 25, 1, 3, 4, 5, 7, 10, 14], target = 11
 输出：-1 （没有找到）

提示:

  1. arr 长度范围在[1, 1000000]之间
