922. 按奇偶排序数组 II

  • 数组

  • 待提交

原地双指针：i 扫偶数位找放错的奇数，j 扫奇数位找放错的偶数，找到就交换，两边同时归位。

思路

  • 偶数位（下标 0,2,4…）该放偶数，奇数位该放奇数；奇数和偶数各占一半。
  • i 沿偶数位走：nums[i] 是偶数就跳过；是奇数就让 j 沿奇数位找那个放错的偶数，交换。
  • 交换一次修好两个位置，所以 j 不会越界、每个位置只被扫过一次。
  • 结果不唯一，题目允许任意合法排列。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int[] sortArrayByParityII(int[] nums) {3        // i 扫偶数位找放错的奇数，j 扫奇数位找放错的偶数；奇偶各占一半，j 不会越界4        int i = 0, j = 1;5        for (; i < nums.length; i += 2) {6            if (nums[i] % 2 == 0) continue;   // 偶数位放对了，不用管7            while (nums[j] % 2 == 1) j += 2;  // 奇数位上必有放错的偶数等着换8            int t = nums[i]; nums[i] = nums[j]; nums[j] = t;9        }10        return nums;11    }12}
题目

给定一个非负整数数组 nums，  nums 中一半整数是 奇数 ，一半整数是 偶数 。

对数组进行排序，以便当 nums[i] 为奇数时，i 也是 奇数 ；当 nums[i] 为偶数时， i 也是 偶数 。

你可以返回 任何满足上述条件的数组作为答案 。

示例 1：

输入：nums = [4,2,5,7]
输出：[4,5,2,7]
解释：[4,7,2,5]，[2,5,4,7]，[2,7,4,5] 也会被接受。

示例 2：

输入：nums = [2,3]
输出：[2,3]

提示：

  • 2 <= nums.length <= 2 * 104
  • nums.length 是偶数
  • nums 中一半是偶数
  • 0 <= nums[i] <= 1000
