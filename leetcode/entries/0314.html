314. 二叉树的垂直遍历

  • 中等
  • 频度 3
  • 深度优先搜索/递归
  • 树
  • 深度优先搜索
  • 广度优先搜索
  • 哈希表
  • 二叉树
  • 排序
  • 未经力扣验证

DFS 给每个结点记 (列, 行, 先序序号)：左孩子列减一、右孩子列加一；排序后按列分组输出。

思路

  • 根是第 0 列第 0 行，走一步行加一，向左列减一、向右列加一。
  • 三个键排序：列升序 → 行升序 → 先序序号升序；先序在前的正是更靠左的，所以同行同列自然「从左到右」。
  • 排序后同列必连续，扫一遍切组，每组按序收集值。
  • 空树直接返回空列表。

1import java.util.*;2 3class Solution {4    public List<List<Integer>> verticalOrder(TreeNode root) {5        List<int[]> nodes = new ArrayList<>();   // {col, row, val, 先序序号}6        dfs(root, 0, 0, new int[1], nodes);7        // 列小的在前；同列上层的在前；同行同列先序在前的在前（即从左到右）8        nodes.sort((a, b) -> {9            if (a[0] != b[0]) return a[0] - b[0];10            if (a[1] != b[1]) return a[1] - b[1];11            return a[3] - b[3];12        });13        List<List<Integer>> out = new ArrayList<>();14        for (int i = 0; i < nodes.size(); i++) {15            if (i == 0 || nodes.get(i)[0] != nodes.get(i - 1)[0]) out.add(new ArrayList<>());16            out.get(out.size() - 1).add(nodes.get(i)[2]);17        }18        return out;19    }20 21    // 先序 DFS：左孩子列减一，右孩子列加一，行（深度）加一22    private void dfs(TreeNode node, int col, int row, int[] seq, List<int[]> nodes) {23        if (node == null) return;24        nodes.add(new int[]{col, row, node.val, seq[0]++});25        dfs(node.left, col - 1, row + 1, seq, nodes);26        dfs(node.right, col + 1, row + 1, seq, nodes);27    }28}
