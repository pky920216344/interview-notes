阶乘进制：k−1 逐位除以「剩余位数的阶乘」，商决定当前位取候选里第几个数，余数继续往下。

思路

  • 以某数开头的排列每组有 (n−1)! 个：k−1 除以它，商 = 跳过几组 = 当前位在候选里的下标。
  • k %= (n−1)! 后继续确定下一位（组数变成 (n−2)!…），候选取走一个就少一个。
  • k 先减 1 转成 0 起始；n ≤ 9，阶乘表用 int 就够。

时间复杂度 O(n^2)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public String getPermutation(int n, int k) {5        // fact[i] = i!：第 i 位后面还有 i 个位置，每组排列有 i! 个6        int[] fact = new int[n];7        fact[0] = 1;8        for (int i = 1; i < n; i++) fact[i] = fact[i - 1] * i;9        // 候选数字 1..n，用有序表：取走一个后剩下的仍有序10        List<Integer> cand = new ArrayList<>();11        for (int i = 1; i <= n; i++) cand.add(i);12        k--;   // 题目从 1 数起，转成 0 起始的序号13        StringBuilder sb = new StringBuilder();14        // 逐位确定：第一位看 k 落在哪个「以某数开头的组」里15        for (int i = n - 1; i >= 0; i--) {16            int idx = k / fact[i];      // 当前位应取候选里第 idx 个（0 起始）17            sb.append(cand.remove(idx));18            k %= fact[i];               // 组内还剩多少，继续确定下一位19        }20        return sb.toString();21    }22}
题目

给出集合 [1,2,3,...,n]，其所有元素共有 n! 种排列。

按大小顺序列出所有排列情况，并一一标记，当 n = 3 时, 所有排列如下：

  1. "123"
  2. "132"
  3. "213"
  4. "231"
  5. "312"
  6. "321"

给定 n 和 k，返回第 k 个排列。

示例 1：

输入：n = 3, k = 3
输出："213"

示例 2：

输入：n = 4, k = 9
输出："2314"

示例 3：

输入：n = 3, k = 1
输出："123"

提示：

  • 1 <= n <= 9
  • 1 <= k <= n!
