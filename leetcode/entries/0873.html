873. 最长的斐波那契子序列的长度

dp[j][k]=以 arr[j]、arr[k] 结尾的长度：哈希找 need=arr[k]−arr[j]，dp[j][k]=dp[i][j]+1，最后 +2。

思路

  • 固定结尾两个数 (j, k)，前一个数被唯一确定：need = arr[k] − arr[j]，哈希表 O(1) 定位。
  • need 必须严格小于 arr[j]（否则不递增），找到就 dp[j][k] = dp[need 的下标][j] + 1。
  • dp 初值 0 表示「开头一对」；答案是最大 dp + 2，一个都接不上就返回 0。
  • 严格递增保证值→下标一一对应，也保证了转移只用已算过的 dp[i][j]。

最优解

时间复杂度 O(n²)，空间复杂度 O(n²)
1import java.util.*;2 3class Solution {4    public int lenLongestFibSubseq(int[] arr) {5        int n = arr.length;6        // pos[v]：值 v 的下标；严格递增所以一一对应7        Map<Integer, Integer> pos = new HashMap<>();8        for (int i = 0; i < n; i++) pos.put(arr[i], i);9        // dp[j][k]：以 arr[j]、arr[k] 结尾的斐波那契式子序列，比「开头两个数」多接了几步10        int[][] dp = new int[n][n];11        int ans = 0;12        for (int k = 0; k < n; k++)13            for (int j = 0; j < k; j++) {14                int need = arr[k] - arr[j];   // 想接在 (j,k) 前面的那个数15                // 必须比 arr[j] 小才落在 j 左边，数列才严格递增16                if (need < arr[j] && pos.containsKey(need))17                    dp[j][k] = dp[pos.get(need)][j] + 1;18                ans = Math.max(ans, dp[j][k]);19            }20        // dp 里存的是「多接的步数」，最长还要加上开头两个数；接不上任何步就返回 021        return ans > 0 ? ans + 2 : 0;22    }23}
题目

如果序列 x1, x2, ..., xn 满足下列条件，就说它是 斐波那契式 的：

  • n >= 3
  • 对于所有 i + 2 <= n，都有 xi + xi+1 == xi+2

给定一个 严格递增 的正整数数组形成序列 arr ，找到 arr 中最长的斐波那契式的子序列的长度。如果不存在，返回  0 。

子序列 是通过从另一个序列 arr 中删除任意数量的元素（包括删除 0 个元素）得到的，同时不改变剩余元素顺序。例如，[3, 5, 8] 是 [3, 4, 5, 6, 7, 8] 的子序列。

示例 1：

输入: arr =[1,2,3,4,5,6,7,8]
输出: 5
解释: 最长的斐波那契式子序列为 [1,2,3,5,8] 。

示例 2：

输入: arr =[1,3,7,11,12,14,18]
输出: 3
解释: 最长的斐波那契式子序列有 [1,11,12]、[3,11,14] 以及 [7,11,18] 。

提示：

  • 3 <= arr.length <= 1000

  • 1 <= arr[i] < arr[i + 1] <= 109
