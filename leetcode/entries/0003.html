3. 无重复字符的最长子串

滑动窗口：右指针一路向右扫；读到窗口里已有的字符，左指针就直接跳到它上次出现位置的后一位。

思路

  • 窗口 [left, right] 表示「当前没有重复字符的子串」，right 从左到右扫一遍。
  • 数组 last[c] 记着字符 c 上次出现的位置 + 1，0 表示没出现过。
  • 读到 c：left = max(left, last[c])，一步跳过重复位置。必须取 max：旧位置可能早就在窗口左边，直接赋值会让 left 回退（比如 abba）。
  • 每扫一格，用 right - left + 1 更新最长长度。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int lengthOfLongestSubstring(String s) {3        // last[c]：字符 c 上次出现的位置 + 1，0 表示没出现过4        int[] last = new int[128];5        int ans = 0;6        // 窗口 [left, right] 里保证没有重复字符7        int left = 0;8        for (int right = 0; right < s.length(); right++) {9            char c = s.charAt(right);10            // c 若在窗口内出现过，left 跳到它上次位置的下一位，11            // 否则 left 不动12            left = Math.max(left, last[c]);13            last[c] = right + 1;14            ans = Math.max(ans, right - left + 1);15        }16        return ans;17    }18}
题目

给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串的长度。

示例 1:

输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

示例 2:

输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。

示例 3:

输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。

提示：

  • 0 <= s.length <= 105
  • s 由英文字母、数字、符号和空格组成
