面试题 02.02. 返回倒数第 k 个节点

双指针拉开定距：fast 先走 k 步，再与 slow 同速前进，fast 到 null 时 slow 正停在倒数第 k 个。

思路

  • fast 先走 k 步，从此比 slow 恒领先 k 个结点。
  • 然后两个指针同速前进，间距 k 保持不变。
  • fast 走到 null 时，链表尾部还剩 k 个结点，slow 就停在倒数第 k 个。
  • 只扫一遍链表，不用先数一遍长度。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int kthToLast(ListNode head, int k) {3        // fast 先走 k 步，从此和 slow 恒差 k 个结点4        ListNode fast = head, slow = head;5        for (int i = 0; i < k; i++) fast = fast.next;6        // 再同速前进：fast 到 null 时，尾部剩下的 k 个里 slow 正在第一个7        while (fast != null) {8            fast = fast.next;9            slow = slow.next;10        }11        return slow.val;12    }13}
题目

实现一种算法，找出单向链表中倒数第 k 个节点。返回该节点的值。

注意：本题相对原题稍作改动

示例：

输入： 1->2->3->4->5 和 k = 2
输出： 4

说明：

给定的 k 保证是有效的。
