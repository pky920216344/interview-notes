1477. 找两个和为目标值且不重叠的子数组

  • 动态规划
  • 滑动窗口
  • 待提交

左右各做一次正数滑窗，记下「前缀内/后缀内最短 target 子数组」，再枚举切分点把两段最短拼起来。

思路

  • 元素全为正 → 和为 target 的窗口具有单调性，滑窗 sum > target 就左缩，sum == target 记长度。
  • 左扫一遍得 bestLeft[i]（[0..i] 内最短），右扫一遍得 bestRight[i]（[i..n−1] 内最短），各自带前缀/后缀最小值。
  • 枚举切分点 i：两个子数组不重叠 ⟺ 一个在 [0..i]、另一个在 [i+1..n−1]，答案 = min(bestLeft[i] + bestRight[i+1])。
  • 任一侧凑不出（值为 ∞）就跳过；整体凑不出返回 −1。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public int minSumOfLengths(int[] arr, int target) {3        int n = arr.length, INF = Integer.MAX_VALUE / 2;4        int[] bestLeft = new int[n], bestRight = new int[n];5        // 左→右滑窗：bestLeft[i] = [0..i] 里和为 target 的最短子数组长度6        for (int r = 0, l = 0, sum = 0, best = INF; r < n; r++) {7            sum += arr[r];8            while (sum > target) sum -= arr[l++];9            if (sum == target) best = Math.min(best, r - l + 1);   // 以 r 结尾的窗口10            bestLeft[r] = best;11        }12        // 右→左滑窗：bestRight[i] = [i..n−1] 里和为 target 的最短子数组长度13        for (int l = n - 1, r = n - 1, sum = 0, best = INF; l >= 0; l--) {14            sum += arr[l];15            while (sum > target) sum -= arr[r--];16            if (sum == target) best = Math.min(best, r - l + 1);   // 以 l 开头的窗口17            bestRight[l] = best;18        }19        // 在 i 和 i+1 之间切一刀：左边取最短 + 右边取最短20        int ans = INF;21        for (int i = 0; i + 1 < n; i++) ans = Math.min(ans, bestLeft[i] + bestRight[i + 1]);22        return ans >= INF ? -1 : ans;23    }24}
题目

给你一个整数数组 arr 和一个整数值 target 。

请你在 arr 中找 两个互不重叠的子数组 且它们的和都等于 target 。可能会有多种方案，请你返回满足要求的两个子数组长度和的 最小值 。

请返回满足要求的最小长度和，如果无法找到这样的两个子数组，请返回 -1 。

示例 1：

输入：arr = [3,2,2,4,3], target = 3
输出：2
解释：只有两个子数组和为 3 （[3] 和 [3]）。它们的长度和为 2 。

示例 2：

输入：arr = [7,3,4,7], target = 7
输出：2
解释：尽管我们有 3 个互不重叠的子数组和为 7 （[7], [3,4] 和 [7]），但我们会选择第一个和第三个子数组，因为它们的长度和 2 是最小值。

示例 3：

输入：arr = [4,3,2,6,2,3,4], target = 6
输出：-1
解释：我们只有一个和为 6 的子数组。

示例 4：

输入：arr = [5,5,4,4,5], target = 3
输出：-1
解释：我们无法找到和为 3 的子数组。

示例 5：

输入：arr = [3,1,1,1,5,1,2,1], target = 3
输出：3
解释：注意子数组 [1,2] 和 [2,1] 不能成为一个方案因为它们重叠了。

提示：

  • 1 <= arr.length <= 10^5
  • 1 <= arr[i] <= 1000
  • 1 <= target <= 10^8
