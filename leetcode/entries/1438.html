1438. 绝对差不超过限制的最长连续子数组

  • 待提交

滑动窗口 + 两个单调队列：max 队头管窗口最大、min 队头管窗口最小；差超限就左缩，总体 O(n)。

思路

  • 两个队列都存下标：maxQ 从队头到队尾值递减、minQ 递增，队头即窗口最大/最小。
  • 新数入队前，把队尾不再可能当最值的下标弹掉（比它差的都没用了）。
  • 窗口内 最大 − 最小 > limit 就 left++，队头下标滑出窗口随即弹出；收缩完窗口必然合法。
  • 每个下标最多进出队列各一次，均摊 O(1)，总体 O(n)。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int longestSubarray(int[] nums, int limit) {5        // 两个单调队列存下标：maxQ 队头是窗口最大，minQ 队头是窗口最小6        Deque<Integer> maxQ = new ArrayDeque<>();7        Deque<Integer> minQ = new ArrayDeque<>();8        int left = 0, ans = 0;9        for (int right = 0; right < nums.length; right++) {10            // 队尾比新数差的下标弹掉：它们不可能再当窗口最值11            while (!maxQ.isEmpty() && nums[maxQ.peekLast()] <= nums[right]) maxQ.pollLast();12            while (!minQ.isEmpty() && nums[minQ.peekLast()] >= nums[right]) minQ.pollLast();13            maxQ.offerLast(right);14            minQ.offerLast(right);15            // 窗口内最大 - 最小超限：左端收缩直到重新合法16            while (nums[maxQ.peekFirst()] - nums[minQ.peekFirst()] > limit) {17                left++;18                // 队头下标滑出窗口就弹出19                if (maxQ.peekFirst() < left) maxQ.pollFirst();20                if (minQ.peekFirst() < left) minQ.pollFirst();21            }22            ans = Math.max(ans, right - left + 1);23        }24        return ans;25    }26}
题目

给你一个整数数组 nums 和一个整数 limit。

请你返回 最长非空子数组 的长度，要求该 子数组 中 任意两个元素 之间的差的 绝对值 都 小于或等于 limit。

示例 1：

输入： nums = [8,2,4,7], limit = 4

输出： 2

解释：

检查所有子数组，计算每个子数组中任意两个元素之间的最大绝对差：
[8] 的最大绝对差为 |8-8| = 0 <= 4。
[8,2] 的最大绝对差为 |8-2| = 6 > 4。
[8,2,4] 的最大绝对差为 |8-2| = 6 > 4。
[8,2,4,7] 的最大绝对差为 |8-2| = 6 > 4。
[2] 的最大绝对差为 |2-2| = 0 <= 4。
[2,4] 的最大绝对差为 |4-2| = 2 <= 4。
[2,4,7] 的最大绝对差为 |7-2| = 5 > 4。注意，元素对 (2, 7) 并不相邻，但仍然需要进行比较。
[4] 的最大绝对差为 |4-4| = 0 <= 4。
[4,7] 的最大绝对差为 |7-4| = 3 <= 4。
[7] 的最大绝对差为 |7-7| = 0 <= 4。
因此，最长子数组的长度为 2。

示例 2：

输入： nums = [10,1,2,4,7,2], limit = 5

输出： 4

解释：

子数组 [2,4,7,2] 满足条件，因为其中任意两个元素之间的绝对差都不超过 5，最大绝对差为 |7-2| = 5。

该子数组无法向左扩展，因为 [1,2,4,7,2] 包含元素对 (1, 7)，其绝对差为 |7-1| = 6 > 5。因此，最长子数组的长度为 4。

示例 3：

输入： nums = [4,2,2,2,4,4,2,2], limit = 0

输出： 3

解释：

由于 limit = 0，子数组中任意两个元素都必须相等，因此只有由相同元素连续组成的子数组才满足条件。

满足条件的最长子数组为 [2,2,2]，长度为 3。

提示：

  • 1 <= nums.length <= 105
  • 1 <= nums[i] <= 109
  • 0 <= limit <= 109
