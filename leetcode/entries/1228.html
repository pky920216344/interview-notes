1228. 等差数列中缺失的数字

  • 简单
  • 频度 1
  • 数学
  • 数组
  • 数学
  • 未经力扣验证

排序后公差 d = (末−首)/n（完整数列 n+1 项）；扫相邻差，唯一的「差 ≠ d」处缺口就是 arr[i−1]+d。

思路

  • 缺了一项的等差数列：完整有 n+1 项，首尾都还在，所以 d = (arr[n−1] − arr[0]) / n，正好整除。
  • 只有一处相邻差是 2d，其余都是 d；扫到 arr[i] − arr[i−1] ≠ d，缺失值 = arr[i−1] + d。
  • 公差为 0（全相同）时算不出缺口，缺的就是 arr[0] 本身。

1import java.util.*;2 3class Solution {4    public int missingNumber(int[] arr) {5        int n = arr.length;6        Arrays.sort(arr);7        // 完整等差数列有 n+1 项，首尾都在：公差 = (末 − 首) / n8        int d = (arr[n - 1] - arr[0]) / n;9        if (d == 0) return arr[0];   // 公差为 0：全相同的数列，缺的还是它10        for (int i = 1; i < n; i++) {11            // 唯一一个「相邻差 = 2d」的位置，缺的就是 arr[i-1] + d12            if (arr[i] - arr[i - 1] != d) return arr[i - 1] + d;13        }14        return arr[0];   // 题目保证缺失项不在首尾，到这里说明 d = 0 的退化情形15    }16}
