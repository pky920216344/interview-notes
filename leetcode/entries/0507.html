507. 完美数

因子成对出现 (i, num/i)，只枚举 i 到 √num，两个一起入账；因子和等于本身即是完美数。

思路

  • 和 sum 从 1 起步（因子 1 先记上，num 本身不算）。
  • i 从 2 试到 √num：整除就把 i 和 num/i 都加上。
  • i == num/i（平方根）只加一次；num == 1 时因子和是 0，特判返回 false。

最优解

时间复杂度 O(√num)，空间复杂度 O(1)
1class Solution {2    public boolean checkPerfectNumber(int num) {3        // 1 的「除自身外的因子和」是 0，不是完美数4        if (num == 1) return false;5        int sum = 1;                     // 因子 1 先记上（num 本身不算）6        // 因子成对出现 (i, num/i)，枚举到 √num 就够了7        for (int i = 2; i * i <= num; i++) {8            if (num % i != 0) continue;9            sum += i;                    // 小因子10            if (i != num / i) sum += num / i;   // 大因子；平方根只记一次11        }12        return sum == num;13    }14}
题目

对于一个 正整数，如果它和除了它自身以外的所有 正因子 之和相等，我们称它为 「完美数」。

给定一个 整数 n， 如果是完美数，返回 true；否则返回 false。

示例 1：

输入：num = 28
输出：true
解释：28 = 1 + 2 + 4 + 7 + 14
1, 2, 4, 7, 和 14 是 28 的所有正因子。

示例 2：

输入：num = 7
输出：false

提示：

  • 1 <= num <= 108
