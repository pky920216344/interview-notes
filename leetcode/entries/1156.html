1156. 单字符重复子串的最大长度

按字母收集连续段；单段可借一个同字母接到段尾，相邻两段中间只隔一个字符就能并成一段，都受「该字母总个数」封顶。

思路

  • 一遍切出每个字母的连续段（起点 + 长度），cnt[c] 记每个字母总个数。
  • 单段候选 min(段长+1, 总个数)：别处还有同字母就能借一个来（交换到段端）。
  • 相邻两段候选 min(左段+右段+1, 总个数)：中间恰好隔一个字符才接得上（先判 b 起点 == a 末尾+1，隔两个以上直接跳过）。
  • 借来的第 1 个来自「总个数比这两段多」；总个数刚好等于两段之和时，交换段端字符也能并出 左+右 长，公式同样覆盖。

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int maxRepOpt1(String text) {5        int n = text.length();6        int[] cnt = new int[26];7        for (int i = 0; i < n; i++) cnt[text.charAt(i) - 'a']++;8        // 每个字母的连续段：int[]{起点, 长度}9        List<int[]>[] segs = new List[26];10        for (int c = 0; c < 26; c++) segs[c] = new ArrayList<>();11        for (int i = 0; i < n; ) {12            int j = i;13            while (j < n && text.charAt(j) == text.charAt(i)) j++;14            segs[text.charAt(i) - 'a'].add(new int[]{i, j - i});15            i = j;16        }17        int ans = 0;18        for (int c = 0; c < 26; c++) {19            int total = cnt[c];20            List<int[]> ss = segs[c];21            // 单段：别处还有同字母时，可借一个接到段尾22            for (int k = 0; k < ss.size(); k++)23                ans = Math.max(ans, Math.min(ss.get(k)[1] + 1, total));24            // 相邻两段中间只隔一个字符：交换后能并成一段25            for (int k = 0; k + 1 < ss.size(); k++) {26                int[] a = ss.get(k), b = ss.get(k + 1);27                if (a[0] + a[1] + 1 != b[0]) continue;28                ans = Math.max(ans, Math.min(a[1] + b[1] + 1, total));29            }30        }31        return ans;32    }33}
题目

如果字符串中的所有字符都相同，那么这个字符串是单字符重复的字符串。

给你一个字符串 text，你只能交换其中两个字符一次或者什么都不做，然后得到一些单字符重复的子串。返回其中最长的子串的长度。

示例 1：

输入：text = "ababa"
输出：3

示例 2：

输入：text = "aaabaaa"
输出：6

示例 3：

输入：text = "aaabbaaa"
输出：4

示例 4：

输入：text = "aaaaa"
输出：5

示例 5：

输入：text = "abcdef"
输出：1

提示：

  • 1 <= text.length <= 20000
  • text 仅由小写英文字母组成。
