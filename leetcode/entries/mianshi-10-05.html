还是二分，只是 mid 落在空串上时，向两边线性挪到最近的非空串当支点再比；区间全空直接判不存在。

思路

  • 正常二分：words[mid] 与 s 用 compareTo 比较，偏小去右半、偏大去左半。
  • words[mid] 是空串时，从 mid−1 向左、mid+1 向右挪到最近的非空串当支点（两边之间全是空串，不影响有序性）。
  • 两边都挪出界说明 [lo, hi] 全是空串，s 非空不可能命中，直接结束返回 −1。

最优解

时间复杂度 O(n) 最坏（空串极多时），平均 O(log n)，空间复杂度 O(1)
1class Solution {2    public int findString(String[] words, String s) {3        int lo = 0, hi = words.length - 1;4        int ans = -1;5        while (ans < 0 && lo <= hi) {6            int mid = (lo + hi) >>> 1;7            if (words[mid].isEmpty()) {8                // 支点落在空串上：向两边挪到最近的非空串9                int l = mid - 1, r = mid + 1;10                while (lo <= l && words[l].isEmpty()) l--;11                while (r <= hi && words[r].isEmpty()) r++;12                if (l < lo && r > hi) break;   // 区间里全是空串，s 不可能在里面13                mid = l >= lo ? l : r;         // 拿一个非空支点继续比14            }15            int cmp = words[mid].compareTo(s);16            if (cmp == 0) ans = mid;           // 命中17            else if (cmp < 0) lo = mid + 1;    // 支点偏小，去右半18            else hi = mid - 1;                 // 支点偏大，去左半19        }20        return ans;21    }22}
题目

稀疏数组搜索。有个排好序的字符串数组，其中散布着一些空字符串，编写一种方法，找出给定字符串的位置。

示例 1：

 输入：words = ["at", "", "", "", "ball", "", "", "car", "", "","dad", "", ""], s = "ta"
 输出：-1
 说明：不存在返回-1。

示例 2：

 输入：words = ["at", "", "", "", "ball", "", "", "car", "", "","dad", "", ""], s = "ball"
 输出：4

提示:

  1. words的长度在[1, 1000000]之间
