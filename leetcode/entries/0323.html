323. 无向图中连通分量的数目

  • 中等
  • 频度 1
  • 并查集
  • 深度优先搜索
  • 广度优先搜索
  • 并查集
  • 图
  • 未经力扣验证

并查集：起点人人自成一份，每条边把两个不同的根合并，合并一次分量数减一。

思路

  • pa[i] 初始指向自己，cnt = n；find 找根时路径减半压缩，越用越快。
  • 每条边 (u,v)：两端根不同说明本就分属两个分量，pa[a] = b 合并、cnt--；同根则跳过（这条边是环内冗余边）。
  • 答案就是剩下的 cnt。

最优解

时间复杂度 O(n + m·α(n))，空间复杂度 O(n)
1class Solution {2    private int[] pa;3 4    public int countComponents(int n, int[][] edges) {5        pa = new int[n];6        for (int i = 0; i < n; i++) pa[i] = i;7        int cnt = n;   // 初始人人自成一个分量8        for (int[] e : edges) {9            // 两端根不同 → 本来不连通，合并后分量数减一；同根说明已有路，跳过10            int a = find(e[0]), b = find(e[1]);11            if (a != b) {12                pa[a] = b;13                cnt--;14            }15        }16        return cnt;17    }18 19    // 找根，顺路路径减半压缩，越压越扁20    private int find(int x) {21        while (pa[x] != x) {22            pa[x] = pa[pa[x]];23            x = pa[x];24        }25        return x;26    }27}
