数组当完全二叉树：先建大顶堆，再每轮把堆顶换到堆尾并缩小堆，下滤新堆顶，尾部从右到左依次放好最大值。

思路

  • 下标 i 的孩子是 2i+1、2i+2，不用真的建树。
  • 建堆：叶子天然是堆，从最后一个非叶结点 n/2 - 1 往前逐个下滤，整体 O(n)。
  • 下滤：和较大的那个孩子比，比它小就交换、继续往下；升序所以用大顶堆。
  • 排序：堆顶是剩余部分最大值，与堆尾交换后堆缩小一格，再对下标 0 下滤；重复 n-1 轮。

最优解

时间复杂度 O(n log n)，空间复杂度 O(1)
1class Solution {2    public int[] sortArray(int[] nums) {3        int n = nums.length;4        // 自底向上建大顶堆：从最后一个非叶结点往前逐个下滤5        for (int i = n / 2 - 1; i >= 0; i--) siftDown(nums, i, n);6        // 每轮把堆顶（剩余部分的最大值）换到堆尾，堆缩小一格，再下滤新堆顶7        for (int end = n - 1; end > 0; end--) {8            int tmp = nums[0];9            nums[0] = nums[end];10            nums[end] = tmp;11            siftDown(nums, 0, end);12        }13        return nums;14    }15 16    // 堆大小为 size 时，把 a[pos] 下滤到正确位置：和较大的孩子比，小了就换下去17    private void siftDown(int[] a, int pos, int size) {18        while (true) {19            int child = pos * 2 + 1;20            if (child >= size) return;            // 没有孩子，已经到位21            if (child + 1 < size && a[child + 1] > a[child]) child++;   // 挑较大的孩子22            if (a[pos] >= a[child]) return;       // 不比孩子小，堆性质成立23            int tmp = a[pos];24            a[pos] = a[child];25            a[child] = tmp;26            pos = child;27        }28    }29}
题目

给你一个整数数组 nums，请你将该数组升序排列。

你必须在 不使用任何内置函数 的情况下解决问题，时间复杂度为 O(nlog(n))，并且空间复杂度尽可能小。

示例 1：

输入：nums = [5,2,3,1]
输出：[1,2,3,5]
解释：数组排序后，某些数字的位置没有改变（例如，2 和 3），而其他数字的位置发生了改变（例如，1 和 5）。

示例 2：

输入：nums = [5,1,1,2,0,0]
输出：[0,0,1,1,2,5]
解释：请注意，nums 的值不一定唯一。

提示：

  • 1 <= nums.length <= 5 * 104
  • -5 * 104 <= nums[i] <= 5 * 104
