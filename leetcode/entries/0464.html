博弈搜索 + 位掩码记忆化：状态就是「用掉哪些数」的 bitmask，当前行动方存在一步让对方必败就赢。

思路

  • 两个预判先挡住：total ≤ 0 直接赢；1..n 全加起来 < total 则谁都到不了，返回 false。
  • 状态 (mask, remaining) 里 remaining 由 mask 唯一决定（用掉的数决定已凑的和），所以 memo 只用 mask 当键。
  • 转移：当前方任选一个没用过的数 i；若 i ≥ remaining 直接赢，否则看对方从新局面出发是否必败，有一条这样的路就赢。
  • n ≤ 20，2^20 个状态各算一遍，暴力穷举靠记忆化才跑得动。

最优解

时间复杂度 O(2^n · n)，空间复杂度 O(2^n)
1class Solution {2    private int n;3    private int[] memo;   // 0 没算过，1 当前行动方必胜，-1 必败4 5    public boolean canIWin(int maxChoosableInteger, int desiredTotal) {6        // 全部数加起来都够不到：谁都赢不了，先手算输7        if ((long) maxChoosableInteger * (maxChoosableInteger + 1) / 2 < desiredTotal) return false;8        n = maxChoosableInteger;9        memo = new int[1 << n];10        return dfs(0, desiredTotal);11    }12 13    // remaining：还差多少分到 desiredTotal；返回当前行动方是否必胜。14    // 用掉的数由 mask 决定，剩余和也随之确定，所以 memo 只用 mask 做键15    private boolean dfs(int mask, int remaining) {16        if (memo[mask] != 0) return memo[mask] > 0;17        for (int i = 0; i < n; i++) {18            if ((mask & (1 << i)) == 0 && ((i + 1 >= remaining) || !dfs(mask | (1 << i), remaining - (i + 1)))) {19                memo[mask] = 1;20                return true;21            }22        }23        memo[mask] = -1;24        return false;25    }26}
题目

在 "100 game" 这个游戏中，两名玩家轮流选择从 1 到 10 的任意整数，累计整数和，先使得累计整数和 达到或超过  100 的玩家，即为胜者。

如果我们将游戏规则改为 “玩家 不能 重复使用整数” 呢？

例如，两个玩家可以轮流从公共整数池中抽取从 1 到 15 的整数（不放回），直到累计整数和 >= 100。

给定两个整数 maxChoosableInteger （整数池中可选择的最大数）和 desiredTotal（累计和），若先出手的玩家能稳赢则返回 true ，否则返回 false 。假设两位玩家游戏时都表现 最佳 。

示例 1：

输入：maxChoosableInteger = 10, desiredTotal = 11
输出：false
解释：
无论第一个玩家选择哪个整数，他都会失败。
第一个玩家可以选择从 1 到 10 的整数。
如果第一个玩家选择 1，那么第二个玩家只能选择从 2 到 10 的整数。
第二个玩家可以通过选择整数 10（那么累积和为 11 >= desiredTotal），从而取得胜利.
同样地，第一个玩家选择任意其他整数，第二个玩家都会赢。

示例 2:

输入：maxChoosableInteger = 10, desiredTotal = 0
输出：true

示例 3:

输入：maxChoosableInteger = 10, desiredTotal = 1
输出：true

提示:

  • 1 <= maxChoosableInteger <= 20
  • 0 <= desiredTotal <= 300
