713. 乘积小于 K 的子数组

滑动窗口：乘积一旦 ≥ k 就左缩；以 right 结尾的合法子数组恰好 right-left+1 个。

思路

  • 元素全 ≥ 1，乘积随窗口扩大单调不减，滑窗可行；right 每右移一格先乘进去。
  • prod ≥ k 就 prod /= nums[left++] 左缩到重新小于 k（含缩成空窗，k=0 时全程空窗）。
  • 以 right 结尾、合法的子数组左端点可以是 [left..right] 里任何一个，所以一次加 right-left+1。
  • prod 每轮结束都 < k ≤ 10^6，再乘一个 ≤ 1000 也不会爆 long。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int numSubarrayProductLessThanK(int[] nums, int k) {3        long prod = 1;   // 及时左缩保证 prod < k*1000，long 绝不会溢出4        int ans = 0, left = 0;5        for (int right = 0; right < nums.length; right++) {6            prod *= nums[right];7            while (prod >= k && left <= right) prod /= nums[left++];   // 太大就左缩8            ans += right - left + 1;   // 以 right 结尾的合法子数组有 right-left+1 个9        }10        return ans;11    }12}
题目

给定一个整数数组 nums 和一个整数 k。

请你返回 子数组 内所有元素的 乘积严格小于 k 的连续子数组的数目。

示例 1：

输入：nums = [10,5,2,6], k = 100
输出：8
解释：8 个乘积小于 100 的子数组分别为：[10]、[5]、[2]、[6]、[10,5]、[5,2]、[2,6]、[5,2,6]。
需要注意的是 [10,5,2] 并不是乘积小于 100 的子数组。

示例 2：

输入：nums = [1,2,3], k = 0
输出：0

提示: 

  • 1 <= nums.length <= 3 * 104
  • 1 <= nums[i] <= 1000
  • 0 <= k <= 106
