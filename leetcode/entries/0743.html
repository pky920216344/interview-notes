朴素 Dijkstra：每轮把「未定里 dist 最小」的节点定成最终最短路，再用它松弛；答案是 dist 最大值。

思路

  • 全源里只用到单源，且边权非负 → Dijkstra；n ≤ 100 用邻接矩阵 + 朴素选最小，最好写。
  • 初始 dist[k] = 0 其余 ∞；每轮选未定中 dist 最小的节点 u，标定后用它松弛所有出边。
  • 选出的 u 的 dist 已不可能再变小（其它路径都要经过已定节点，只会更长），这就是贪心正确性。
  • 答案 = 所有 dist 的最大值；若有 ∞ 说明有节点收不到信号，返回 −1。

最优解

时间复杂度 O(n^2 + E)，空间复杂度 O(n^2)
1import java.util.*;2 3class Solution {4    public int networkDelayTime(int[][] times, int n, int k) {5        final int INF = Integer.MAX_VALUE / 2;6        // 邻接矩阵：g[u][v] = u→v 的时延；n ≤ 100，矩阵最省事7        int[][] g = new int[n + 1][n + 1];8        for (int[] row : g) Arrays.fill(row, INF);9        for (int[] e : times) g[e[0]][e[1]] = Math.min(g[e[0]][e[1]], e[2]);10        // 朴素 Dijkstra：每轮把「未定里 dist 最小」的节点定为最终最短路11        int[] dist = new int[n + 1];12        Arrays.fill(dist, INF);13        dist[k] = 0;14        boolean[] done = new boolean[n + 1];15        for (int round = 0; round < n; round++) {16            int u = 0;17            for (int v = 1; v <= n; v++) {18                if (!done[v] && (u == 0 || dist[v] < dist[u])) u = v;19            }20            // 剩下的都不可达，提前结束21            if (u == 0 || dist[u] == INF) break;22            done[u] = true;23            // 用刚定的 u 松弛其它节点；INF 不会溢出（dist 和权重都很小）24            for (int v = 1; v <= n; v++) {25                if (dist[u] + g[u][v] < dist[v]) dist[v] = dist[u] + g[u][v];26            }27        }28        // 答案 = 最晚收到信号的时间；有节点收不到就是 -129        int ans = 0;30        for (int v = 1; v <= n; v++) ans = Math.max(ans, dist[v]);31        return ans >= INF ? -1 : ans;32    }33}
题目

有 n 个网络节点，标记为 1 到 n。

给你一个列表 times，表示信号经过 有向 边的传递时间。 times[i] = (ui, vi, wi)，其中 ui 是源节点，vi 是目标节点， wi 是一个信号从源节点传递到目标节点的时间。

现在，从某个节点 K 发出一个信号。需要多久才能使所有节点都收到信号？如果不能使所有节点收到信号，返回 -1 。

示例 1：

输入：times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
输出：2

示例 2：

输入：times = [[1,2,1]], n = 2, k = 1
输出：1

示例 3：

输入：times = [[1,2,1]], n = 2, k = 2
输出：-1

提示：

  • 1 <= k <= n <= 100
  • 1 <= times.length <= 6000
  • times[i].length == 3
  • 1 <= ui, vi <= n
  • ui != vi
  • 0 <= wi <= 100
  • 所有 (ui, vi) 对都 互不相同（即，不含重复边）
