153. 寻找旋转排序数组中的最小值

  • 中等
  • 频度 59
  • 二分查找
  • 数组
  • 二分查找
  • 力扣已通过

二分：拿 nums[mid] 和 nums[hi] 比；mid 更大说明最小值在右半，mid 更小说明 mid 自己可能是答案，hi 收到 mid。

思路

  • 旋转数组 = 两段升序拼接，最小值是第二段的开头；[lo, hi] 里永远留着答案。
  • nums[mid] > nums[hi]：断点（最小值）一定在 mid 右边，lo = mid + 1。
  • nums[mid] < nums[hi]：mid 到 hi 这段有序，最小值在 [lo, mid]；mid 可能就是答案，所以 hi = mid 而不是 mid-1。
  • 元素互不相同保证比较无歧义；lo == hi 时区间只剩 1 格，即最小值。

图解

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int findMin(int[] nums) {3        int lo = 0, hi = nums.length - 1;4        // [lo, hi] 里永远留着最小值；元素互不相同，比较不会歧义5        while (lo < hi) {6            int mid = lo + (hi - lo) / 2;7            if (nums[mid] > nums[hi]) {8                // mid 比右端大：断点在 mid 右边，最小值在 (mid, hi]9                lo = mid + 1;10            } else {11                // mid 比右端小：mid 右侧有序，最小值在 [lo, mid]，mid 自己可能是答案12                hi = mid;13            }14        }15        return nums[lo];16    }17}
题目
已知一个长度为 n 的数组，预先按照升序排列，经由 1 到 n 次 旋转 后，得到输入数组。例如，原数组 nums = [0,1,2,4,5,6,7] 在变化后可能得到：
  • 若旋转 4 次，则可以得到 [4,5,6,7,0,1,2]
  • 若旋转 7 次，则可以得到 [0,1,2,4,5,6,7]

注意，数组 [a[0], a[1], a[2], ..., a[n-1]] 旋转一次 的结果为数组 [a[n-1], a[0], a[1], a[2], ..., a[n-2]] 。

给你一个元素值 互不相同 的数组 nums ，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 最小元素 。

你必须设计一个时间复杂度为 O(log n) 的算法解决此问题。

示例 1：

输入：nums = [3,4,5,1,2]
输出：1
解释：原数组为 [1,2,3,4,5] ，旋转 3 次得到输入数组。

示例 2：

输入：nums = [4,5,6,7,0,1,2]
输出：0
解释：原数组为 [0,1,2,4,5,6,7] ，旋转 4 次得到输入数组。

示例 3：

输入：nums = [11,13,15,17]
输出：11
解释：原数组为 [11,13,15,17] ，旋转 4 次得到输入数组。

提示：

  • n == nums.length
  • 1 <= n <= 5000
  • -5000 <= nums[i] <= 5000
  • nums 中的所有整数 互不相同
  • nums 原来是一个升序排序的数组，并进行了 1 至 n 次旋转
