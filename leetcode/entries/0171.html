26 进制且 A=1：从左往右读，每读一位就把已累积的值 ×26 再加这一位的值。

思路

  • 和十进制「逐位读数」完全同构：AB = (1×26 + 2)，读 C 就是 (1×26+2)×26 + 3。
  • 每位加的是 c - 'A' + 1（A 是 1 不是 0），这是和普通 26 进制唯一的差别。
  • 7 位列名最大到 FXSHRXW = 2147483647，恰好不溢出 int。

题目

给你一个字符串 columnTitle ，表示 Excel 表格中的列名称。返回 该列名称对应的列序号 。

例如：

A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28 
...

示例 1:

输入: columnTitle = "A"
输出: 1

示例 2:

输入: columnTitle = "AB"
输出: 28

示例 3:

输入: columnTitle = "ZY"
输出: 701

提示：

  • 1 <= columnTitle.length <= 7
  • columnTitle 仅由大写英文组成
  • columnTitle 在范围 ["A", "FXSHRXW"] 内
