补充题14. 阿拉伯数字转中文数字

  • 中等
  • 频度 24
  • 模拟
  • 未经力扣验证

按「亿 / 万 / 个」三节转换：节内从千位往低位拼，中间的零合并成一个，节首「一十」省略「一」。

思路

  • 拆三节：亿 = n/1e8、万 = n/1e4 % 1e4、个 = n%1e4，各自是 0..9999 的数；整节为零就跳过。
  • 节内从千到个：非零位拼「数字 + 单位」；前面跳过的零位合并成一个「零」垫在下一组前。
  • 补零两个时机：节内有跳过的零位；跨节时中间隔了零节或本节不满千（如 1000001 → 一百万零一）。
  • 「一十」只在整串最开头省成「十」（10→十、110000→十一万）；零后面要念全（1000010→一百万零一十）。

最优解

时间复杂度 O(1)（最多 10 位），空间复杂度 O(1)
1class Solution {2    private static final String[] D = {"", "一", "二", "三", "四", "五", "六", "七", "八", "九"};3    private static final String[] U = {"", "十", "百", "千"};   // 个、十、百、千的单位4 5    // 0 ≤ n ≤ int 上限：按「亿/万/个」三节转换，输出小写中文6    public String convert(int n) {7        if (n == 0) return "零";8        int[] secs = {n / 100_000_000, n / 10_000 % 10_000, n % 10_000};9        String[] units = {"亿", "万", ""};10        StringBuilder sb = new StringBuilder();11        boolean emitted = false, pendingZero = false;12        for (int k = 0; k < 3; k++) {13            if (secs[k] == 0) {   // 整节为零先跳过，但它隔出了中间的零14                if (emitted) pendingZero = true;15                continue;16            }17            // 补零：中间隔了零节，或本节不满一千18            if (emitted && (pendingZero || secs[k] < 1000)) sb.append('零');19            appendSection(sb, secs[k], !emitted);20            sb.append(units[k]);21            emitted = true;22            pendingZero = false;23        }24        return sb.toString();25    }26 27    // 一节（1..9999）从千位往个位拼，中间的零合并成一个28    // omitShi：本节是整串开头时，节首「一十」省略成「十」29    private void appendSection(StringBuilder sb, int x, boolean omitShi) {30        int[] d = {x % 10, x / 10 % 10, x / 100 % 10, x / 1000};   // 个、十、百、千31        boolean emitted = false, pendingZero = false;32        for (int i = 3; i >= 0; i--) {33            if (d[i] == 0) {34                if (emitted) pendingZero = true;   // 后面还有数字才真的要补零35                continue;36            }37            if (pendingZero) sb.append('零');38            if (omitShi && i == 1 && d[i] == 1 && !emitted) sb.append('十');39            else sb.append(D[d[i]]).append(U[i]);40            emitted = true;41            pendingZero = false;42        }43    }44}
