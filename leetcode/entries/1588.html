1588. 所有奇数长度子数组的和

  • 数学

贡献法：arr[i] 被 (i+1)×(n−i) 个子数组包含，其中奇数长度占一半向上取整，答案 = Σ 贡献×值。

思路

  • 不枚举子数组，改算每个 arr[i] 的贡献：子数组含 arr[i] ⟺ 左端 ≤ i 且右端 ≥ i。
  • 左端有 i+1 种、右端有 n-i 种，共 (i+1)*(n-i) 个子数组包含它。
  • 长度为奇数（左长+右长为偶数）的恰好占一半，向上取整：((i+1)*(n-i)+1)/2。
  • 答案 = Σ 奇数长度个数 × arr[i]，一遍扫完。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int sumOddLengthSubarrays(int[] arr) {3        int n = arr.length, ans = 0;4        // arr[i] 出现在多少个奇数长度子数组里：左端 i+1 种 × 右端 n-i 种，奇长度占一半（向上取整）5        for (int i = 0; i < n; i++) {6            ans += ((i + 1) * (n - i) + 1) / 2 * arr[i];7        }8        return ans;9    }10}
题目

给你一个正整数数组 arr ，请你计算所有可能的奇数长度子数组的和。

子数组 定义为原数组中的一个连续子序列。

请你返回 arr 中 所有奇数长度子数组的和 。

示例 1：

输入：arr = [1,4,2,5,3]
输出：58
解释：所有奇数长度子数组和它们的和为：
[1] = 1
[4] = 4
[2] = 2
[5] = 5
[3] = 3
[1,4,2] = 7
[4,2,5] = 11
[2,5,3] = 10
[1,4,2,5,3] = 15
我们将所有值求和得到 1 + 4 + 2 + 5 + 3 + 7 + 11 + 10 + 15 = 58

示例 2：

输入：arr = [1,2]
输出：3
解释：总共只有 2 个长度为奇数的子数组，[1] 和 [2]。它们的和为 3 。

示例 3：

输入：arr = [10,11,12]
输出：66

提示：

  • 1 <= arr.length <= 100
  • 1 <= arr[i] <= 1000
