字典树：add 沿前缀建结点、词尾打标记；search 逐层走，遇到 '.' 就把这一层所有分支都递归试一遍。

思路

  • add：从根逐字符下走，缺结点就建，最后一个结点标 word = true。
  • search：逐字符下走；普通字符沿对应分支走，走空了就是 false。
  • . 是通配：把当前结点的全部 26 个分支递归试一遍，任一命中即 true。
  • 走完整个 word 还不算完：必须停在打了 word 标记的结点上（搜 b.. 不能靠 bad 的前缀 ba 蒙混）。

最优解

时间复杂度 add O(L)，search 最坏 O(26^L·L)，空间复杂度 O(总字符数)
1import java.util.*;2 3class WordDictionary {4    // 26 叉字典树：共享前缀只存一份，'.' 逐分支递归5    private static class Node {6        Node[] next = new Node[26];7        boolean word;   // 走到这里是否构成一个完整的词8    }9 10    private Node root = new Node();11 12    public WordDictionary() {13    }14 15    public void addWord(String word) {16        Node cur = root;17        for (int i = 0; i < word.length(); i++) {18            int c = word.charAt(i) - 'a';19            if (cur.next[c] == null) cur.next[c] = new Node();20            cur = cur.next[c];21        }22        cur.word = true;23    }24 25    public boolean search(String word) {26        return match(root, word, 0);27    }28 29    // 从第 depth 位开始匹配 word 剩下的部分30    private boolean match(Node node, String word, int depth) {31        if (node == null) return false;32        if (depth == word.length()) return node.word;33        char c = word.charAt(depth);34        if (c == '.') {35            for (Node next : node.next) {   // 通配：26 个分支全试36                if (match(next, word, depth + 1)) return true;37            }38            return false;39        }40        return match(node.next[c - 'a'], word, depth + 1);41    }42}
题目

请你设计一个数据结构，支持 添加新单词 和 查找字符串是否与任何先前添加的字符串匹配 。

实现词典类 WordDictionary ：

  • WordDictionary() 初始化词典对象
  • void addWord(word) 将 word 添加到数据结构中，之后可以对它进行匹配
  • bool search(word) 如果数据结构中存在字符串与 word 匹配，则返回 true ；否则，返回  false 。word 中可能包含一些 '.' ，每个 . 都可以表示任何一个字母。

示例：

输入：
["WordDictionary","addWord","addWord","addWord","search","search","search","search"]
[[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]]
输出：
[null,null,null,null,false,true,true,true]

解释：
WordDictionary wordDictionary = new WordDictionary();
wordDictionary.addWord("bad");
wordDictionary.addWord("dad");
wordDictionary.addWord("mad");
wordDictionary.search("pad"); // 返回 False
wordDictionary.search("bad"); // 返回 True
wordDictionary.search(".ad"); // 返回 True
wordDictionary.search("b.."); // 返回 True

提示：

  • 1 <= word.length <= 25
  • addWord 中的 word 由小写英文字母组成
  • search 中的 word 由 '.' 或小写英文字母组成
  • 最多调用 104 次 addWord 和 search
