185. 部门工资前三高的所有员工

  • 困难
  • 频度 1
  • SQL
  • 数据库
  • 待提交

DENSE_RANK 按（部门内、工资降序）给出「不同工资」的名次，并列同薪同名次不占位，外层取 rk ≤ 3。

思路

  • 「前三高的不同工资」用 DENSE_RANK() OVER (PARTITION BY departmentId ORDER BY salary DESC)：并列同薪同名次，后面的名次不空跳——这正是「按工资值排名」的语义。
  • 若用 ROW_NUMBER 会把并列员工挤掉（每行一个名次），用 RANK 会跳号（并列后从 4 开始），都会错删/多留，DENSE_RANK 才对。
  • 窗口函数算完包一层再 WHERE rk <= 3——窗口函数不能直接写在 WHERE 里。
  • JOIN Department 只为取部门名。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1-- 185（codetop 0185）部门工资前三高的所有员工（MySQL）2-- 题意：Employee(id, name, salary, departmentId)、Department(id, name)。3-- 找每个部门「不同工资排名前三」的全部员工（并列同工资都算同一排名），输出 部门名、员工名、工资。4-- DENSE_RANK 按「不同工资」排名：并列不占位，第三名之后不再要。5SELECT d.name AS Department,6       e.name AS Employee,7       e.salary AS Salary8FROM (9    SELECT name,10           salary,11           departmentId,12           DENSE_RANK() OVER (PARTITION BY departmentId ORDER BY salary DESC) AS rk13    FROM Employee14) e15JOIN Department d ON d.id = e.departmentId16WHERE e.rk <= 3;
题目

表: Employee

+--------------+---------+
| Column Name  | Type    |
+--------------+---------+
| id           | int     |
| name         | varchar |
| salary       | int     |
| departmentId | int     |
+--------------+---------+
id 是该表的主键列(具有唯一值的列)。
departmentId 是 Department 表中 ID 的外键（reference 列）。
该表的每一行都表示员工的ID、姓名和工资。它还包含了他们部门的ID。

表: Department

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| name        | varchar |
+-------------+---------+
id 是该表的主键列(具有唯一值的列)。
该表的每一行表示部门ID和部门名。

公司的主管们感兴趣的是公司每个部门中谁赚的钱最多。一个部门的 高收入者 是指一个员工的工资在该部门的 不同 工资中 排名前三 。

编写解决方案，找出每个部门中 收入高的员工 。
