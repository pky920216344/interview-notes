659. 分割数组为连续子序列

  • 待提交

贪心：能接在以 x-1 结尾的链尾就接；否则看 x+1、x+2 是否都有货，有就开新链 [x,x+1,x+2]，否则 false。

思路

  • 两个哈希：count[x] 是 x 还剩几个没进链，end[x] 是以 x 结尾的链有几条。
  • 遍历 x：先看 end[x-1] > 0，接上去（短链能延长就尽量延长）；否则要 count[x+1]、count[x+2] 都 > 0 才能开新链——新链必须立刻凑够 3 个。
  • 消耗掉的 x+1、x+2 要从 count 里扣掉，轮到它们时 count == 0 直接跳过。

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public boolean isPossible(int[] nums) {5        // count[x]：x 还剩几个没进链；end[x]：以 x 结尾的链有几条6        Map<Integer, Integer> count = new HashMap<>();7        Map<Integer, Integer> end = new HashMap<>();8        for (int x : nums) count.merge(x, 1, Integer::sum);9        for (int x : nums) {10            if (count.get(x) == 0) continue;   // 已被前面的链消耗掉11            if (end.getOrDefault(x - 1, 0) > 0) {12                // 优先接在以 x-1 结尾的链后面：短链能延长就尽量延长13                end.merge(x - 1, -1, Integer::sum);14                end.merge(x, 1, Integer::sum);15            } else if (count.getOrDefault(x + 1, 0) > 0 && count.getOrDefault(x + 2, 0) > 0) {16                // 开新链必须凑够 x、x+1、x+2 三个，否则它永远长不到 317                count.merge(x + 1, -1, Integer::sum);18                count.merge(x + 2, -1, Integer::sum);19                end.merge(x + 2, 1, Integer::sum);20            } else {21                return false;22            }23            count.merge(x, -1, Integer::sum);24        }25        return true;26    }27}
题目

给你一个按 非递减顺序 排列的整数数组 nums 。

请你判断是否能在将 nums 分割成 一个或多个子序列 的同时满足下述 两个 条件：

  • 每个子序列都是一个 连续递增序列（即，每个整数 恰好 比前一个整数大 1 ）。
  • 所有子序列的长度 至少 为 3。

如果可以分割 nums 并满足上述条件，则返回 true ；否则，返回 false 。

示例 1：

输入：nums = [1,2,3,3,4,5]
输出：true
解释：nums 可以分割成以下子序列：
[1,2,3,3,4,5] --> 1, 2, 3
[1,2,3,3,4,5] --> 3, 4, 5

示例 2：

输入：nums = [1,2,3,3,4,4,5,5]
输出：true
解释：nums 可以分割成以下子序列：
[1,2,3,3,4,4,5,5] --> 1, 2, 3, 4, 5
[1,2,3,3,4,4,5,5] --> 3, 4, 5

示例 3：

输入：nums = [1,2,3,4,4,5]
输出：false
解释：无法将 nums 分割成长度至少为 3 的连续递增子序列。

提示：

  • 1 <= nums.length <= 104
  • -1000 <= nums[i] <= 1000
  • nums 按非递减顺序排列
