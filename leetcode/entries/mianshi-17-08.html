面试题 17.08. 马戏团人塔

按（身高升序、同身高体重降序）排序，问题变成体重序列上的最长严格递增子序列，二分做到 O(n log n)。

思路

  • 能叠起来 = 身高、体重都严格递增。先按身高升序排，同身高让体重大的在前——同身高的人体重必然递减，永远选不出一串。
  • 排完后只需在体重序列上求最长严格递增子序列（LIS）。
  • tails[k] 维护「长度 k+1 的递增子序列的最小结尾」：每个体重二分找第一个 ≥ w 的位置，接不上尾巴就替换（为后面留更小的余地），能接上就长度 +1。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int bestSeqAtIndex(int[] height, int[] weight) {5        int n = height.length;6        Integer[] order = new Integer[n];7        for (int i = 0; i < n; i++) order[i] = i;8        // 身高升序；同身高体重大的在前：同身高的人永远叠不到一起9        Arrays.sort(order, (a, b) ->10                height[a] != height[b] ? height[a] - height[b] : weight[b] - weight[a]);11        // 在体重序列上求最长严格递增子序列：tails[k] = 长度 k+1 的最小结尾12        int[] tails = new int[n];13        int len = 0;14        for (int id : order) {15            int w = weight[id], lo = 0, hi = len;16            while (lo < hi) {17                int mid = (lo + hi) >>> 1;18                if (tails[mid] < w) lo = mid + 1;19                else hi = mid;20            }21            tails[lo] = w;   // 接不上尾巴时 lo == len，这一步就是追加22            if (lo == len) len++;23        }24        return len;25    }26}
题目

有个马戏团正在设计叠罗汉的表演节目，一个人要站在另一人的肩膀上。出于实际和美观的考虑，在上面的人要比下面的人矮一点且轻一点。已知马戏团每个人的身高和体重，请编写代码计算叠罗汉最多能叠几个人。

示例：

输入：height = [65,70,56,75,60,68] weight = [100,150,90,190,95,110]
输出：6
解释：从上往下数，叠罗汉最多能叠 6 层：(56,90), (60,95), (65,100), (68,110), (70,150), (75,190)

提示：

  • height.length == weight.length <= 10000
