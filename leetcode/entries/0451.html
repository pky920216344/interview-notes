计数 + 频次桶：bucket[f] 收下频次为 f 的字符（按 ASCII 序），最后从高频桶往低频桶倒出来拼串。

思路

  • cnt[c] 统计频次；桶数组下标就是频次，bucket[f] 每个字符重复 f 遍收进去。
  • 按 ASCII 序遍历字符装桶，同频字符天然有序——答案不唯一时这就是一份合法输出。
  • 最后 f 从 s.length() 往下扫，桶非空就追加进 sb，频次高的自动排在前面。
  • 频次最大也就 n，桶数组开 n + 1 就够。

最优解

时间复杂度 O(n + C)，空间复杂度 O(n)
1class Solution {2    public String frequencySort(String s) {3        int[] cnt = new int[128];4        for (char c : s.toCharArray()) cnt[c]++;5        // 桶的下标就是频次：bucket[f] 按 ASCII 顺序收下频次为 f 的字符6        StringBuilder[] bucket = new StringBuilder[s.length() + 1];7        for (int i = 0; i < 128; i++) {8            int f = cnt[i];9            if (f == 0) continue;10            if (bucket[f] == null) bucket[f] = new StringBuilder();11            for (int k = 0; k < f; k++) bucket[f].append((char) i);12        }13        // 从高频往低频把桶倒出来，拼成结果14        StringBuilder sb = new StringBuilder();15        for (int f = s.length(); f >= 1; f--) {16            if (bucket[f] != null) sb.append(bucket[f]);17        }18        return sb.toString();19    }20}
题目

给定一个字符串 s ，根据字符出现的 频率 对其进行 降序排序 。一个字符出现的 频率 是它出现在字符串中的次数。

返回 已排序的字符串 。如果有多个答案，返回其中任何一个。

示例 1:

输入: s = "tree"
输出: "eert"
解释: 'e'出现两次，'r'和't'都只出现一次。
因此'e'必须出现在'r'和't'之前。此外，"eetr"也是一个有效的答案。

示例 2:

输入: s = "cccaaa"
输出: "cccaaa"
解释: 'c'和'a'都出现三次。此外，"aaaccc"也是有效的答案。
注意"cacaca"是不正确的，因为相同的字母必须放在一起。

示例 3:

输入: s = "Aabb"
输出: "bbAa"
解释: 此外，"bbaA"也是一个有效的答案，但"Aabb"是不正确的。
注意'A'和'a'被认为是两种不同的字符。

提示:

  • 1 <= s.length <= 5 * 105
  • s 由大小写英文字母和数字组成
