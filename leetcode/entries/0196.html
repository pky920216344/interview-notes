196. 删除重复的电子邮箱

  • 简单
  • 频度 1
  • SQL
  • 数据库
  • 待提交

自连接把「同邮箱且 id 更大」的行配出来直接 DELETE，保住每组最小 id。

思路

  • DELETE p1 FROM Person p1 JOIN Person p2：p1 是被删方，条件 同邮箱 AND p1.id > p2.id——每组只留 id 最小者。
  • MySQL 的 DELETE 必须用 DELETE 别名 FROM 表 别名 JOIN… 语法（不能直接 DELETE FROM Person WHERE … IN 子查询引用同表，会报「不能在 FROM 里重新指定目标表」）。
  • 想用窗口函数版本：先 SELECT id FROM (SELECT id, ROW_NUMBER() OVER (PARTITION BY email ORDER BY id) rn FROM Person) t WHERE rn > 1 再 DELETE IN——同样需要包一层派生表绕过同表限制。
  • 保留「最小 id」由 p1.id > p2.id 的方向保证；等号去掉（自己和自己相等时跳过）。

最优解

时间复杂度 O(n²)（索引可优化到近似 O(n)），空间复杂度 O(1)

题目

表: Person

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| email       | varchar |
+-------------+---------+
id 是该表的主键列(具有唯一值的列)。
该表的每一行包含一封电子邮件。电子邮件将不包含大写字母。

编写解决方案 删除 所有重复的电子邮件，只保留一个具有最小 id 的唯一电子邮件。

（对于 SQL 用户，请注意你应该编写一个 DELETE 语句而不是 SELECT 语句。）

（对于 Pandas 用户，请注意你应该直接修改 Person 表。）

运行脚本后，显示的答案是 Person 表。驱动程序将首先编译并运行您的代码片段，然后再显示 Person 表。Person 表的最终顺序 无关紧要 。

返回结果格式如下示例所示。

示例 1:

输入: 
Person 表:
+----+------------------+
| id | email            |
+----+------------------+
| 1  | john@example.com |
| 2  | bob@example.com  |
| 3  | john@example.com |
+----+------------------+
输出: 
+----+------------------+
| id | email            |
+----+------------------+
| 1  | john@example.com |
| 2  | bob@example.com  |
+----+------------------+
解释: john@example.com重复两次。我们保留最小的Id = 1。
