1115. 交替打印 FooBar

  • 中等
  • 频度 4
  • 并发
  • 多线程
  • 待提交

两个信号量当「通行证」：初始 fooGate=1、barGate=0；谁打印完就把票递给对方，n 轮严格交替。

思路

  • fooGate 初始 1 张票、barGate 初始 0 张：天然保证 foo 先打、bar 后打。
  • foo()：acquire fooGate → printFoo.run() → release barGate；bar() 对称地反过来。
  • 票在两人手里转一圈正好一轮 foobar；没有票的线程在 acquire 上阻塞，不会忙等。
  • 两张票永不同时为 1，也就不可能出现 foofoo 或 barbar。

题目

给你一个类：

class FooBar {
  public void foo() {
    for (int i = 0; i < n; i++) {
      print("foo");
    }
  }

  public void bar() {
    for (int i = 0; i < n; i++) {
      print("bar");
    }
  }
}

两个不同的线程将会共用一个 FooBar 实例：

  • 线程 A 将会调用 foo() 方法，而
  • 线程 B 将会调用 bar() 方法

请设计修改程序，以确保 "foobar" 被输出 n 次。

示例 1：

输入：n = 1
输出："foobar"
解释：这里有两个线程被异步启动。其中一个调用 foo() 方法, 另一个调用 bar() 方法，"foobar" 将被输出一次。

示例 2：

输入：n = 2
输出："foobarfoobar"
解释："foobar" 将被输出两次。

提示：

  • 1 <= n <= 1000
