三次反转：先反转前 target 个，再反转其余，最后整体反转，前 target 个就到了末尾。

思路

  • 要把 ab|cdef 变成 cdef|ab，把两段各自反转再整体反转：ab cdef → ba fedc → cdefab。
  • 每次反转用双指针从两头向中间交换，原地完成，不用额外数组。
  • 记忆口诀：局部反转、整体反转。

最优解

时间复杂度 O(n)，空间复杂度 O(1)（不计输出）
1class Solution {2    public String dynamicPassword(String password, int target) {3        char[] a = password.toCharArray();4        // 三次反转：前 target 个、其余部分、整体，O(1) 额外空间5        reverse(a, 0, target - 1);6        reverse(a, target, a.length - 1);7        reverse(a, 0, a.length - 1);8        return new String(a);9    }10 11    private void reverse(char[] a, int i, int j) {12        while (i < j) {13            char t = a[i];14            a[i++] = a[j];15            a[j--] = t;16        }17    }18}
题目

某公司门禁密码使用动态口令技术。初始密码为字符串 password，密码更新均遵循以下步骤：

  • 设定一个正整数目标值 target
  • 将 password 前 target 个字符按原顺序移动至字符串末尾

请返回更新后的密码字符串。

示例 1：

输入: password = "s3cur1tyC0d3", target = 4
输出: "r1tyC0d3s3cu"

示例 2：

输入: password = "lrloseumgh", target = 6
输出: "umghlrlose"

提示：

  • 1 <= target < password.length <= 10000
