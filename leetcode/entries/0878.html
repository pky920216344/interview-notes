878. 第 N 个神奇数字

二分答案 x：[1,x] 里神奇数个数 = x/a + x/b − x/lcm（容斥），找最小的「个数 ≥ n」的 x。

思路

  • 个数随 x 单调不减 → 可以二分 x；上界 n × min(a,b) 必然够 n 个。
  • count(x) = ⌊x/a⌋ + ⌊x/b⌋ − ⌊x/lcm(a,b)⌋：公倍数被前两项数了两次，减回一次。
  • lcm = a / gcd(a,b) × b 要用 long：a、b ≤ 4×10⁴ 时 lcm 可达 1.6×10⁹，超 int。
  • count(mid) ≥ n → 答案 ≤ mid（hi = mid）；否则 lo = mid + 1。收敛处对 10⁹+7 取模。

最优解

时间复杂度 O(log(n·min(a,b)))，空间复杂度 O(1)
1class Solution {2    public int nthMagicalNumber(int n, int a, int b) {3        long lcm = (long) a / gcd(a, b) * b;4        // [1, x] 里神奇数的个数 = x/a + x/b - x/lcm（容斥：公倍数被加了两次）5        long lo = 1, hi = (long) Math.min(a, b) * n;   // 第 n 个不会超过 n*min(a,b)6        while (lo < hi) {7            long mid = lo + (hi - lo) / 2;8            if (mid / a + mid / b - mid / lcm >= n) hi = mid;   // 够 n 个：答案 ≤ mid9            else lo = mid + 1;                                   // 不够：答案更大10        }11        return (int) (lo % 1_000_000_007);12    }13 14    private long gcd(long a, long b) { return b == 0 ? a : gcd(b, a % b); }15}
题目

一个正整数如果能被 a 或 b 整除，那么它是神奇的。

给定三个整数 n , a , b ，返回第 n 个神奇的数字。因为答案可能很大，所以返回答案 对 109 + 7 取模 后的值。

示例 1：

输入：n = 1, a = 2, b = 3
输出：2

示例 2：

输入：n = 4, a = 2, b = 3
输出：6

提示：

  • 1 <= n <= 109
  • 2 <= a, b <= 4 * 104
