不真的旋转：递推 F(k) = F(k−1) + sum − n·nums[n−k]，一遍扫完取最大值。

思路

  • 先算 F(0) = Σ i·nums[i] 和 sum = Σ nums[i]。
  • 从 F(k−1) 转到 F(k)：整组数右旋一位，每个数的系数都 +1（合计 +sum），只有转到队尾的那个 nums[n−k] 系数从 n−1 归 0（减掉 (n−1)·nums[n−k]，合起来即 −n·nums[n−k]）。
  • 递推 k = 1..n−1，途中用 ans 记最大值；中间值可能超出 int，用 long 存。

最优解

时间复杂度 O(n)，空间复杂度 O(1)
1class Solution {2    public int maxRotateFunction(int[] nums) {3        int n = nums.length;4        long sum = 0, f = 0;                      // f 即 F(0) = Σ i·nums[i]5        for (int i = 0; i < n; i++) {6            sum += nums[i];7            f += (long) i * nums[i];8        }9        long ans = f;10        // 旋转一次：其余数的系数都 +1（共 +sum），只有转到队尾的 nums[n-k] 从 n-1 归 011        for (int k = 1; k < n; k++) {12            f += sum - (long) n * nums[n - k];13            ans = Math.max(ans, f);14        }15        return (int) ans;16    }17}
题目

给定一个长度为 n 的整数数组 nums 。

假设 arrk 是数组 nums 顺时针旋转 k 个位置后的数组，我们定义 nums 的 旋转函数  F 为：

  • F(k) = 0 * arrk[0] + 1 * arrk[1] + ... + (n - 1) * arrk[n - 1]

返回 F(0), F(1), ..., F(n-1)中的最大值 。

生成的测试用例让答案符合 32 位 整数。

示例 1:

输入: nums = [4,3,2,6]
输出: 26
解释:
F(0) = (0 * 4) + (1 * 3) + (2 * 2) + (3 * 6) = 0 + 3 + 4 + 18 = 25
F(1) = (0 * 6) + (1 * 4) + (2 * 3) + (3 * 2) = 0 + 4 + 6 + 6 = 16
F(2) = (0 * 2) + (1 * 6) + (2 * 4) + (3 * 3) = 0 + 6 + 8 + 9 = 23
F(3) = (0 * 3) + (1 * 2) + (2 * 6) + (3 * 4) = 0 + 2 + 12 + 12 = 26
所以 F(0), F(1), F(2), F(3) 中的最大值是 F(3) = 26 。

示例 2:

输入: nums = [100]
输出: 0

提示:

  • n == nums.length
  • 1 <= n <= 105
  • -100 <= nums[i] <= 100
