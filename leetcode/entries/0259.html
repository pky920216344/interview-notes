259. 较小的三数之和

  • 中等
  • 频度 2
  • 双指针
  • 数组
  • 双指针
  • 二分查找
  • 排序
  • 未经力扣验证

排序后固定最小位 i，双指针扫后半段：三数和一旦小于 target，hi 及以左全部配得上，一次加上 hi−lo 对。

思路

  • 排序后枚举第一位 i，问题变成「后半段里有多少对 (lo, hi) 使 nums[i]+nums[lo]+nums[hi] < target」。
  • lo 从 i+1 起、hi 从末尾起：和太小就把 hi 以左的全部收进答案（ans += hi − lo），lo 右移；和太大就 hi 左移。
  • 数的是下标三元组，重复值不必去重——同值的不同下标本来就是不同的三元组。
  • 正确性：固定 i、lo 后，hi 从大到小第一个满足的位置左侧全都满足，用一次减法批量计数，避免逐对枚举。

最优解

时间复杂度 O(n^2)，空间复杂度 O(1)（不计排序栈）
1import java.util.*;2 3class Solution {4    public int threeSumSmaller(int[] nums, int target) {5        Arrays.sort(nums);6        int n = nums.length, ans = 0;7        for (int i = 0; i < n - 2; i++) {8            int lo = i + 1, hi = n - 1;9            while (lo < hi) {10                // 以 i、lo 为前两位，hi 及以左的都能配上：一次加上 hi - lo 对11                if (nums[i] + nums[lo] + nums[hi] < target) {12                    ans += hi - lo;13                    lo++;14                } else {15                    hi--;16                }17            }18        }19        return ans;20    }21}
