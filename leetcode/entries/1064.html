1064. 不动点

  • 简单
  • 频度 1
  • 二分查找
  • 数组
  • 二分查找
  • 未经力扣验证

arr 严格递增 ⇒ arr[i]−i 非递减；二分找第一个 arr[i]−i ≥ 0 的位置，再看它是否恰好为 0。

思路

  • 判定「arr[i] == i」等价于「arr[i] − i == 0」，而 arr 严格递增让 arr[i] − i 非递减 → 可以二分。
  • arr[mid] − mid ≥ 0：mid 可能是答案，hi = mid 往左收；否则 lo = mid + 1。
  • 结束时 lo == hi：arr[lo] == lo 就命中，否则无不动点返回 −1。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int fixedPoint(int[] arr) {3        // arr 严格递增 ⇒ f(i) = arr[i] − i 非递减：二分找第一个 f ≥ 0 的位置4        int lo = 0, hi = arr.length - 1;5        while (lo < hi) {6            int mid = lo + (hi - lo) / 2;7            if (arr[mid] - mid >= 0) hi = mid;   // mid 可能就是答案，往左半收8            else lo = mid + 1;9        }10        return arr[lo] == lo ? lo : -1;11    }12}
