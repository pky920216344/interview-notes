774. 最小化去加油站的最大距离

  • 困难
  • 频度 1
  • 二分查找
  • 数组
  • 二分查找
  • 未经力扣验证

二分答案「最大段距 d」：长 g 的段拆成 ceil(g/d) 小段、要补 ceil(g/d)−1 个新站；总补站数 ≤ k 的最小 d 即答案。

思路

  • 单调性：允许的段距 d 越大，要补的新站越少 → 对 d 二分，可行就往下压。
  • 判定一遍扫段：长 g 的段补 ceil(g/d)−1 个站，累加与 k 比较。
  • 浮点二分固定轮数夹到 1e-6 精度；答案必是某个 g/j，不会卡在非法精度上。

时间复杂度 O(n log(maxGap/1e-6))，空间复杂度 O(1)
1class Solution {2    public double minmaxGasDist(int[] stations, int k) {3        int n = stations.length;4        if (n <= 1) return 0;5        double lo = 0, hi = 0;6        for (int i = 1; i < n; i++) hi = Math.max(hi, stations[i] - stations[i - 1]);7        if (hi == 0) return 0;8        // 二分「最大段距」：d 越小要补的新站越多，可行域单调9        for (int it = 0; it < 100; it++) {10            double mid = (lo + hi) / 2;11            if (feasible(stations, k, mid)) hi = mid;12            else lo = mid;13        }14        return hi;15    }16 17    // 段长 g 拆成 ceil(g/d) 小段，要补 ceil(g/d)−1 个新站；总补站数 ≤ k 即可行18    private boolean feasible(int[] stations, int k, double d) {19        long need = 0;20        for (int i = 1; i < stations.length; i++)21            need += (long) Math.ceil((stations[i] - stations[i - 1]) / d) - 1;22        return need <= k;23    }24}
