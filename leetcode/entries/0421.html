421. 数组中两个数的最大异或值

逐位贪心：从高位往低位试，把 ans 这一位补成 1；看前缀集合里有没有两个前缀能异或出 want=ans|1<<bit。

思路

  • 高位定生死：从第 30 位往下试，mask 每轮多铺一位，x & mask 只留已尝试的高位前缀。
  • 想让这一位是 1：目标前缀 want = ans | (1 << bit)；集合里存在 p 使 p ^ want 也在集合，就说明有两个原数的前缀异或出了 want。
  • 试得成就 ans = want 把这一位固定下来；试不成就保持，继续往低位走。
  • 全程只用前缀集合判断，不需要知道具体是哪两个数、也不用字典树。

1import java.util.*;2 3class Solution {4    public int findMaximumXOR(int[] nums) {5        int ans = 0, mask = 0;6        // 从最高位往低位试：这一位能不能是 1，试出来就固定下来7        for (int bit = 30; bit >= 0; bit--) {8            mask |= 1 << bit;                     // 掩码扩一位，只留已尝试的高位9            Set<Integer> set = new HashSet<>();10            for (int x : nums) set.add(x & mask); // 收集所有数的高位前缀11            int want = ans | (1 << bit);          // 期望前缀：ans 的这一位再补成 112            for (int p : set) {13                // 有前缀 p 和 p^want 都在集合里，就说明能异或出 want14                if (set.contains(p ^ want)) {15                    ans = want;16                    break;17                }18            }19        }20        return ans;21    }22}
题目

给你一个整数数组 nums ，返回 nums[i] XOR nums[j] 的最大运算结果，其中 0 ≤ i ≤ j < n 。

示例 1：

输入：nums = [3,10,5,25,2,8]
输出：28
解释：最大运算结果是 5 XOR 25 = 28.

示例 2：

输入：nums = [14,70,53,83,49,91,36,80,92,51,66,70]
输出：127

提示：

  • 1 <= nums.length <= 2 * 105
  • 0 <= nums[i] <= 231 - 1
