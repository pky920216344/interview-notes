570. 至少有5名直接下属的经理

  • 中等
  • 频度 1
  • SQL
  • 数据库
  • 待提交

关联子查询按 managerId = e.id 数直接下属，COUNT ≥ 5 的员工本人就是经理。

思路

  • 「直接下属」= managerId 指向自己的人；对每个候选 e 用关联子查询计数。
  • 输出的是经理的 name（不是下属的名字，也不是 id）。
  • 另一种写法：GROUP BY managerId HAVING COUNT(*) >= 5 再 JOIN 回取名字——两步但同义。
  • NULL 的 managerId 不会误算（NULL 不等任何 id，顶层老板没有下属时不会被选中）。

最优解

时间复杂度 O(n²)（managerId 建索引后近似 O(n)），空间复杂度 O(1)

题目

表: Employee

+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| name        | varchar |
| department  | varchar |
| managerId   | int     |

id 是此表的主键（具有唯一值的列）。
该表的每一行表示雇员的名字、他们的部门和他们的经理的id。
如果managerId为空，则该员工没有经理。
没有员工会成为自己的管理者。

编写一个解决方案，找出至少有五个直接下属的经理。
