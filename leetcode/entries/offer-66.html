剑指 Offer 66. 按规则计算统计结果

  • 中等
  • 频度 3
  • 前缀和/差分
  • 数组
  • 前缀和
  • 待提交

不用除法：第一遍从左往右把「左边乘积」放进 b，第二遍从右往左把「右边乘积」乘进去。

思路

  • 第一遍：b[i] = left（左边全体乘积），随后 left *= a[i]；b[0] 左边没数，是空乘积 1。
  • 第二遍：b[i] *= right，随后 right *= a[i]；两遍合起来 b[i] = 左缀 × 右缀。
  • 有 0 也能算（除法方案会除零失效）；全程只有乘法。

最优解

时间复杂度 O(n)，空间复杂度 O(1)（输出数组不计）
1class Solution {2    public int[] statisticalResult(int[] arrayA) {3        int n = arrayA.length;4        int[] b = new int[n];5        // 第一遍从左往右：b[i] 先放「i 左边所有数的乘积」（b[0] 左边没有数，放 1）6        int left = 1;7        for (int i = 0; i < n; i++) {8            b[i] = left;9            left *= arrayA[i];   // left 变成「到 i 为止（含）」的左缀乘积10        }11        // 第二遍从右往左：再把「i 右边所有数的乘积」乘进去12        int right = 1;13        for (int i = n - 1; i >= 0; i--) {14            b[i] *= right;15            right *= arrayA[i];16        }17        return b;18    }19}
题目

为了深入了解这些生物群体的生态特征，你们进行了大量的实地观察和数据采集。数组 arrayA 记录了各个生物群体数量数据，其中 arrayA[i] 表示第 i 个生物群体的数量。请返回一个数组 arrayB，该数组为基于数组 arrayA 中的数据计算得出的结果，其中 arrayB[i] 表示将第 i 个生物群体的数量从总体中排除后的其他数量的乘积。

示例 1：

输入：arrayA = [2, 4, 6, 8, 10]
输出：[1920, 960, 640, 480, 384]

提示：

  • 所有元素乘积之和不会溢出 32 位整数
  • arrayA.length <= 100000
