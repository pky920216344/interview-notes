917. 仅仅反转字母

  • 简单
  • 频度 1
  • 双指针
  • 双指针
  • 字符串
  • 待提交

首尾双指针向中间走：一侧不是字母就跳过，两侧都是字母才交换。

思路

  • 把字符串转成 char[]，指针 i 从头、j 从尾向中间收。
  • a[i] 不是字母：i++ 跳过；a[j] 不是字母：j-- 跳过——符号永远留在原位。
  • 两侧都是字母才交换，交换后 i++、j--；i ≥ j 时结束。

最优解

时间复杂度 O(n)，空间复杂度 O(n)（char 数组；Java 里 String 不可变）
1class Solution {2    public String reverseOnlyLetters(String s) {3        char[] a = s.toCharArray();4        // 首尾双指针：两侧都是字母才交换，符号原地不动5        int i = 0, j = a.length - 1;6        while (i < j) {7            if (!isLetter(a[i])) i++;          // 左侧不是字母，右移跳过8            else if (!isLetter(a[j])) j--;     // 右侧不是字母，左移跳过9            else { char t = a[i]; a[i++] = a[j]; a[j--] = t; }10        }11        return new String(a);12    }13 14    private boolean isLetter(char c) {15        return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z');16    }17}
题目

给你一个字符串 s ，根据下述规则反转字符串：

  • 所有非英文字母保留在原有位置。
  • 所有英文字母（小写或大写）位置反转。

返回反转后的 s 。

示例 1：

输入：s = "ab-cd"
输出："dc-ba"

示例 2：

输入：s = "a-bC-dEf-ghIj"
输出："j-Ih-gfE-dCba"

示例 3：

输入：s = "Test1ng-Leet=code-Q!"
输出："Qedo1ct-eeLg=ntse-T!"

提示

  • 1 <= s.length <= 100
  • s 仅由 ASCII 值在范围 [33, 122] 的字符组成
  • s 不含 '\"' 或 '\\'
