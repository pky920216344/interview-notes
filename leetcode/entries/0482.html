482. 密钥格式化

  • 简单
  • 频度 2
  • 模拟
  • 字符串
  • 待提交

从右往左收字符：丢掉连字符、小写转大写，每凑满 k 个就在组尾补一个连字符，最后整体反转。

思路

  • 第一组「可以不足 k」这个规则从左算很别扭，从右往左看就变成「每 k 个一组」，天然对齐。
  • 指针从右往左扫：连字符直接跳过；普通字符转大写追加，++len % k == 0 时补一个 -。
  • 收完后最左边可能多出一个 -（最左组恰好凑满时），去掉它，再把整个 sb 反转。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1class Solution {2    public String licenseKeyFormatting(String s, int k) {3        StringBuilder sb = new StringBuilder();4        int len = 0;                                   // 从右往左数：当前组已经收了几个字符5        for (int i = s.length() - 1; i >= 0; i--) {6            char c = s.charAt(i);7            if (c == '-') continue;                    // 旧连字符全部丢弃8            sb.append(Character.toUpperCase(c));9            if (++len % k == 0) sb.append('-');        // 每凑满 k 个字符就在组尾补一个连字符10        }11        if (sb.length() > 0 && sb.charAt(sb.length() - 1) == '-') sb.setLength(sb.length() - 1);12        return sb.reverse().toString();                // 从右往左攒的，整体反转才是答案13    }14}
题目

给定一个许可密钥字符串 s，仅由字母、数字字符和破折号组成。字符串由 n 个破折号分成 n + 1 组。你也会得到一个整数 k 。

我们想要重新格式化字符串 s，使每一组包含 k 个字符，除了第一组，它可以比 k 短，但仍然必须包含至少一个字符。此外，两组之间必须插入破折号，并且应该将所有小写字母转换为大写字母。

返回 重新格式化的许可密钥 。

示例 1：

输入：S = "5F3Z-2e-9-w", k = 4
输出："5F3Z-2E9W"
解释：字符串 S 被分成了两个部分，每部分 4 个字符；
     注意，两个额外的破折号需要删掉。

示例 2：

输入：S = "2-5g-3-J", k = 2
输出："2-5G-3J"
解释：字符串 S 被分成了 3 个部分，按照前面的规则描述，第一部分的字符可以少于给定的数量，其余部分皆为 2 个字符。

提示:

  • 1 <= s.length <= 105
  • s 只包含字母、数字和破折号 '-'.
  • 1 <= k <= 104
