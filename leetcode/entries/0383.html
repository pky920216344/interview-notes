magazine 建成 26 格字符库存，ransomNote 逐字符消耗；库存被扣成负数就是不够，返回 false。

思路

  • 先扫 magazine：stock[c] 记每种字符有几个，这就是全部库存。
  • 再扫 ransomNote：每用一个字符就 stock[c]--，像从仓库提货。
  • 关键在判断方式：不重新比数量，而是看库存有没有被扣成负数——扣成负数说明这种字符透支了，立即 false。

图解

最优解

时间复杂度 O(n + m)，空间复杂度 O(1)
1class Solution {2    public boolean canConstruct(String ransomNote, String magazine) {3        int[] stock = new int[26];                       // magazine 的字符库存4        for (int i = 0; i < magazine.length(); i++) stock[magazine.charAt(i) - 'a']++;5        for (int i = 0; i < ransomNote.length(); i++) {6            int c = ransomNote.charAt(i) - 'a';7            stock[c]--;                                  // 用一个字符就消耗一个库存8            if (stock[c] < 0) return false;              // 扣成负数：这种字符不够用9        }10        return true;11    }12}
题目

给你两个字符串：ransomNote 和 magazine ，判断 ransomNote 能不能由 magazine 里面的字符构成。

如果可以，返回 true ；否则返回 false 。

magazine 中的每个字符只能在 ransomNote 中使用一次。

示例 1：

输入：ransomNote = "a", magazine = "b"
输出：false

示例 2：

输入：ransomNote = "aa", magazine = "ab"
输出：false

示例 3：

输入：ransomNote = "aa", magazine = "aab"
输出：true

提示：

  • 1 <= ransomNote.length, magazine.length <= 105
  • ransomNote 和 magazine 由小写英文字母组成
