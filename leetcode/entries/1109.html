1109. 航班预订统计

  • 中等
  • 频度 7
  • 前缀和/差分
  • 数组
  • 前缀和
  • 待提交

差分数组：每条预订只在起点 +seats、终点后一格 −seats，最后前缀和一遍还原每个航班的座位数。

思路

  • 区间整体加一个数不必逐格加：d[l-1] += seats、d[r] -= seats（题目 1 起始，转成 0 起始下标）。
  • 全部记完后做前缀和：累计到哪一班，那个值就是该班的座位总数。
  • 撤销记在 d[r]：r = n 时要写 d[n]，所以差分数组开 n+1 长。

最优解

时间复杂度 O(n + m)，空间复杂度 O(n)
1class Solution {2    public int[] corpFlightBookings(int[][] bookings, int n) {3        // 差分：区间 [l, r] 整段加 seats ⇒ 起点记账、终点后一格撤销4        int[] d = new int[n + 1];5        for (int[] b : bookings) {6            d[b[0] - 1] += b[2];7            d[b[1]] -= b[2];8        }9        int[] ans = new int[n];10        int run = 0;11        for (int i = 0; i < n; i++) {12            // 前缀和还原：跑到哪一班，累计值就是该班的座位总数13            run += d[i];14            ans[i] = run;15        }16        return ans;17    }18}
题目

这里有 n 个航班，它们分别从 1 到 n 进行编号。

有一份航班预订表 bookings ，表中第 i 条预订记录 bookings[i] = [firsti, lasti, seatsi] 意味着在从 firsti 到 lasti （包含 firsti 和 lasti ）的 每个航班 上预订了 seatsi 个座位。

请你返回一个长度为 n 的数组 answer，里面的元素是每个航班预定的座位总数。

示例 1：

输入：bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5
输出：[10,55,45,25,25]
解释：
航班编号        1   2   3   4   5
预订记录 1 ：   10  10
预订记录 2 ：       20  20
预订记录 3 ：       25  25  25  25
总座位数：      10  55  45  25  25
因此，answer = [10,55,45,25,25]

示例 2：

输入：bookings = [[1,2,10],[2,2,15]], n = 2
输出：[10,25]
解释：
航班编号        1   2
预订记录 1 ：   10  10
预订记录 2 ：       15
总座位数：      10  25
因此，answer = [10,25]

提示：

  • 1 <= n <= 2 * 104
  • 1 <= bookings.length <= 2 * 104
  • bookings[i].length == 3
  • 1 <= firsti <= lasti <= n
  • 1 <= seatsi <= 104
