950. 按递增顺序显示卡牌

队列模拟翻开顺序：牌升序排队，队列装下标，每张牌放到队首下标、再把下一个下标押到队尾。

思路

  • 翻开的位置序列与牌值无关：直接翻开、垫底、再翻开……由 n 唯一决定。
  • 把下标 0..n-1 放进队列，按发牌规则弹出的顺序就是「落位顺序」。
  • 牌升序遍历：ans[q.poll()] = card，再把队首下标押回队尾，对应「翻一张、垫一张」。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public int[] deckRevealedIncreasing(int[] deck) {5        Arrays.sort(deck);6        int n = deck.length;7        // 队列装下标：弹出的顺序就是「翻开顺序」8        Deque<Integer> q = new ArrayDeque<>();9        for (int i = 0; i < n; i++) q.add(i);10        int[] ans = new int[n];11        for (int card : deck) {12            // 最小的牌放进队头下标（它第一个被翻开）13            ans[q.poll()] = card;14            // 下一个下标押到队尾，模拟「翻一张、垫一张」15            if (!q.isEmpty()) q.add(q.poll());16        }17        return ans;18    }19}
题目

牌组中的每张卡牌都对应有一个唯一的整数。你可以按你想要的顺序对这套卡片进行排序。

最初，这些卡牌在牌组里是正面朝下的（即，未显示状态）。

现在，重复执行以下步骤，直到显示所有卡牌为止：

  1. 从牌组顶部抽一张牌，显示它，然后将其从牌组中移出。
  2. 如果牌组中仍有牌，则将下一张处于牌组顶部的牌放在牌组的底部。
  3. 如果仍有未显示的牌，那么返回步骤 1。否则，停止行动。

返回能以递增顺序显示卡牌的牌组顺序。

答案中的第一张牌被认为处于牌堆顶部。

示例：

输入：[17,13,11,2,3,5,7]
输出：[2,13,3,11,5,17,7]
解释：
我们得到的牌组顺序为 [17,13,11,2,3,5,7]（这个顺序不重要），然后将其重新排序。
重新排序后，牌组以 [2,13,3,11,5,17,7] 开始，其中 2 位于牌组的顶部。
我们显示 2，然后将 13 移到底部。牌组现在是 [3,11,5,17,7,13]。
我们显示 3，并将 11 移到底部。牌组现在是 [5,17,7,13,11]。
我们显示 5，然后将 17 移到底部。牌组现在是 [7,13,11,17]。
我们显示 7，并将 13 移到底部。牌组现在是 [11,17,13]。
我们显示 11，然后将 17 移到底部。牌组现在是 [13,17]。
我们展示 13，然后将 17 移到底部。牌组现在是 [17]。
我们显示 17。
由于所有卡片都是按递增顺序排列显示的，所以答案是正确的。

提示：

  1. 1 <= A.length <= 1000
  2. 1 <= A[i] <= 10^6
  3. 对于所有的 i != j，A[i] != A[j]
