43. 字符串相乘

  • 中等
  • 频度 134
  • 模拟
  • 数学
  • 字符串
  • 模拟
  • 力扣已通过

模拟竖式：第 i 位乘第 j 位累加到结果数组第 i+j+1 位，扫完从右往左统一进位，最后去前导零。

思路

  • 结果最多 m + n 位，开这么长的数组 a；num1[i] × num2[j] 累加到 a[i+j+1]（竖式的个位对齐）。
  • 两层循环先只累加不进位：每格最多几万，int 装得下。
  • 从右往左 a[k-1] += a[k] / 10; a[k] %= 10; 统一进位。
  • 去前导零时至少留一位，全零乘积输出 "0"。

图解

最优解

时间复杂度 O(mn)，空间复杂度 O(m+n)
1class Solution {2    public String multiply(String num1, String num2) {3        int m = num1.length(), n = num2.length();4        // 乘积最多 m + n 位；第 i 位 × 第 j 位累加到第 i + j + 1 位5        int[] a = new int[m + n];6        for (int i = m - 1; i >= 0; i--) {7            int x = num1.charAt(i) - '0';8            for (int j = n - 1; j >= 0; j--) {9                a[i + j + 1] += x * (num2.charAt(j) - '0');10            }11        }12        // 从右往左统一进位（每格最多几万，int 装得下）13        for (int k = m + n - 1; k > 0; k--) {14            a[k - 1] += a[k] / 10;15            a[k] %= 10;16        }17        // 去前导零，至少留一位18        int start = 0;19        while (start < a.length - 1 && a[start] == 0) start++;20        StringBuilder sb = new StringBuilder();21        for (int k = start; k < a.length; k++) sb.append(a[k]);22        return sb.toString();23    }24}
题目

给定两个以字符串形式表示的非负整数 num1 和 num2，返回 num1 和 num2 的乘积，它们的乘积也表示为字符串形式。

注意：不能使用任何内置的 BigInteger 库或直接将输入转换为整数。

示例 1:

输入: num1 = "2", num2 = "3"
输出: "6"

示例 2:

输入: num1 = "123", num2 = "456"
输出: "56088"

提示：

  • 1 <= num1.length, num2.length <= 200
  • num1 和 num2 只能由数字组成。
  • num1 和 num2 都不包含任何前导零，除了数字0本身。
