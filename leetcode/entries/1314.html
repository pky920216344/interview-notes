二维前缀和：s 多一圈 0，每个答案就是「以 (i,j) 为中心、夹到边界内的方块」做四角容斥，一次相减出结果。

思路

  • 先算二维前缀和 s[i][j] = 左上矩形 (0,0)~(i-1,j-1) 的和；外圈补 0，转移就是 上 + 左 − 左上 + 自己。
  • 每个格子 (i,j) 的方块是 (i±k, j±k)，四条边先 max/min 夹到矩阵边界内。
  • 方块和 = s[r2][c2] − s[r1][c2] − s[r2][c1] + s[r1][c1]（大矩形减上减左，左上被减两次加回来）。

最优解

时间复杂度 O(mn)，空间复杂度 O(mn)
1class Solution {2    public int[][] matrixBlockSum(int[][] mat, int k) {3        int m = mat.length, n = mat[0].length;4        // s[i][j] = 左上角 (0,0)~(i-1,j-1) 矩形的和，多一圈 0 免掉边界判断5        int[][] s = new int[m + 1][n + 1];6        for (int i = 1; i <= m; i++)7            for (int j = 1; j <= n; j++)8                s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + mat[i - 1][j - 1];9        int[][] ans = new int[m][n];10        for (int i = 0; i < m; i++)11            for (int j = 0; j < n; j++) {12                // 以 (i,j) 为中心的方块，四条边先夹到矩阵边界内13                int r1 = Math.max(0, i - k), r2 = Math.min(m, i + k + 1);14                int c1 = Math.max(0, j - k), c2 = Math.min(n, j + k + 1);15                ans[i][j] = s[r2][c2] - s[r1][c2] - s[r2][c1] + s[r1][c1];16            }17        return ans;18    }19}
题目

给你一个 m x n 的矩阵 mat 和一个整数 k ，请你返回一个矩阵 answer ，其中每个 answer[i][j] 是所有满足下述条件的元素 mat[r][c] 的和： 

  • i - k <= r <= i + k,
  • j - k <= c <= j + k 且
  • (r, c) 在矩阵内。

示例 1：

输入：mat = [[1,2,3],[4,5,6],[7,8,9]], k = 1
输出：[[12,21,16],[27,45,33],[24,39,28]]

示例 2：

输入：mat = [[1,2,3],[4,5,6],[7,8,9]], k = 2
输出：[[45,45,45],[45,45,45],[45,45,45]]

提示：

  • m == mat.length
  • n == mat[i].length
  • 1 <= m, n, k <= 100
  • 1 <= mat[i][j] <= 100
