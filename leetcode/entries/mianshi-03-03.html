List<栈> 管理多摞：push 进最后一摞、满了开新摞；pop/popAt 弹空一摞就整摞删除，下标前移。

思路

  • push：容量 ≤0 直接忽略；最后一摞没满就压入，满了新开一摞。
  • pop 等价于 popAt(最后一摞的下标)；popAt(index) 越界或该摞空返回 −1。
  • 关键：某摞弹空后整摞从列表删除，popAt 的下标永远对着删除后的当前列表。

1import java.util.ArrayDeque;2import java.util.ArrayList;3import java.util.Deque;4import java.util.List;5 6class StackOfPlates {7    private final int cap;8    // stacks.get(i) 是第 i 摞；摞空了立刻从列表删掉，后面的下标整体前移9    private final List<Deque<Integer>> stacks = new ArrayList<>();10 11    public StackOfPlates(int cap) {12        this.cap = cap;13    }14 15    public void push(int val) {16        if (cap <= 0) return;   // 容量为 0 什么也放不下17        // 最后一摞满了就新开一摞18        if (stacks.isEmpty() || stacks.get(stacks.size() - 1).size() == cap) {19            stacks.add(new ArrayDeque<>());20        }21        stacks.get(stacks.size() - 1).push(val);22    }23 24    public int pop() {25        return popAt(stacks.size() - 1);26    }27 28    public int popAt(int index) {29        if (index < 0 || index >= stacks.size()) return -1;30        Deque<Integer> s = stacks.get(index);31        if (s.isEmpty()) return -1;32        int val = s.pop();33        // 空摞删掉：popAt 的下标永远对着删除后的当前列表34        if (s.isEmpty()) stacks.remove(index);35        return val;36    }37}
题目

堆盘子。设想有一堆盘子，堆太高可能会倒下来。因此，在现实生活中，盘子堆到一定高度时，我们就会另外堆一堆盘子。请实现数据结构SetOfStacks，模拟这种行为。SetOfStacks应该由多个栈组成，并且在前一个栈填满时新建一个栈。此外，SetOfStacks.push()和SetOfStacks.pop()应该与普通栈的操作方法相同（也就是说，pop()返回的值，应该跟只有一个栈时的情况一样）。 进阶：实现一个popAt(int index)方法，根据指定的子栈，执行pop操作。

当某个栈为空时，应当删除该栈。当栈中没有元素或不存在该栈时，pop，popAt 应返回 -1.

示例 1：

 输入：
["StackOfPlates", "push", "push", "popAt", "pop", "pop"]
[[1], [1], [2], [1], [], []]
 输出：
[null, null, null, 2, 1, -1]

示例 2：

 输入：
["StackOfPlates", "push", "push", "push", "popAt", "popAt", "popAt"]
[[2], [1], [2], [3], [0], [0], [0]]
 输出：
[null, null, null, null, 2, 1, 3]
