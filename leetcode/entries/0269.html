相邻单词第一对不同字符给出「前 < 后」的偏序边；同前缀时长词在前是矛盾；拓扑排序输出字母序，有环返回空串。

思路

  • 只看相邻两个单词：第一对不同字符 u vs v 给出边 u→v；后面的单词推不出更多约束。
  • 特判：短词排在长词后面却是其前缀（abc 后跟 ab）直接返回 ""；相同前缀部分不建边。
  • Kahn 拓扑排序：入度 0 的字母入队，弹一个写进答案、把后继入度减一；26×26 布尔矩阵存边，同一对字母只记一次。
  • 输出的字母数少于出现过的字母数 ⇒ 有环 ⇒ 返回 ""。合法答案不唯一，本题判题接受任意拓扑序。

时间复杂度 O(C)（C 为全部字符数，拓扑排序内层是 26），空间复杂度 O(1)（26×26 定长矩阵）
1import java.util.ArrayDeque;2import java.util.Queue;3 4class Solution {5    public String alienOrder(String[] words) {6        boolean[] seen = new boolean[26];           // 出现过的字母都是结点7        boolean[][] before = new boolean[26][26];   // before[a][b]：a 必须排在 b 前面8        for (String w : words) {9            for (int i = 0; i < w.length(); i++) seen[w.charAt(i) - 'a'] = true;10        }11        // 相邻两词第一对不同字符给出一条偏序边；同前缀时长词在前是矛盾12        for (int i = 1; i < words.length; i++) {13            String a = words[i - 1], b = words[i];14            int j = 0, len = Math.min(a.length(), b.length());15            while (j < len && a.charAt(j) == b.charAt(j)) j++;16            if (j == len) {17                if (a.length() > b.length()) return "";   // 短词在后却是长词前缀：矛盾18                continue;                                 // 前缀相同部分推不出边19            }20            int u = a.charAt(j) - 'a', v = b.charAt(j) - 'a';21            if (!before[u][v]) { before[u][v] = true; }   // 同一对字母只记一条边22        }23        // 拓扑排序（Kahn）：入度 0 的字母入队，按 a..z 固定顺序拿，输出可复现24        int[] indeg = new int[26];25        for (int u = 0; u < 26; u++) {26            for (int v = 0; v < 26; v++) {27                if (before[u][v]) indeg[v]++;28            }29        }30        Queue<Integer> q = new ArrayDeque<>();31        for (int c = 0; c < 26; c++) {32            if (seen[c] && indeg[c] == 0) q.add(c);33        }34        StringBuilder sb = new StringBuilder();35        int total = 0;36        for (int c = 0; c < 26; c++) if (seen[c]) total++;37        while (!q.isEmpty()) {38            int u = q.poll();39            sb.append((char) ('a' + u));40            for (int v = 0; v < 26; v++) {41                if (!before[u][v] || --indeg[v] != 0) continue;42                q.add(v);43            }44        }45        return sb.length() == total ? sb.toString() : "";   // 字母没出完 = 有环，字典矛盾46    }47}
