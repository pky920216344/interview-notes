哈希表存「路径 → 值」，键存在就等于已创建；create 校验「路径未被占 + 父路径已存在」。

思路

  • 不必真建树：Map<路径, 值> 的键集合就是「已存在的全部路径」，get 就是 getOrDefault(path, -1)。
  • createPath 两道拦路：路径已存在 → false；父路径不存在 → false。父路径取 lastIndexOf('/') 的前缀，根的直接子路径（截到开头）父路径视为存在。
  • 两关都过才 put 并返回 true。

最优解

时间复杂度 每次 O(L)（L 为路径长度），空间复杂度 O(已创建路径总长)
1import java.util.*;2 3class FileSystem {4    // 路径 → 值；存在即表示该路径已创建5    private final Map<String, Integer> vals = new HashMap<>();6 7    public FileSystem() {8    }9 10    // 两个拦路条件：路径已存在、父路径不存在（根的直接子路径父路径视为存在）11    public boolean createPath(String path, int value) {12        if (vals.containsKey(path)) return false;13        int cut = path.lastIndexOf('/');14        if (cut > 0 && !vals.containsKey(path.substring(0, cut))) return false;15        vals.put(path, value);16        return true;17    }18 19    public int get(String path) {20        return vals.getOrDefault(path, -1);21    }22}23 24/**25 * Your FileSystem object will be instantiated and called as such:26 * FileSystem obj = new FileSystem();27 * boolean param_1 = obj.createPath(path, value);28 * int param_2 = obj.get(path);29 */
