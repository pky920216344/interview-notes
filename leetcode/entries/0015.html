15. 三数之和

  • 中等
  • 频度 498
  • 双指针
  • 数组
  • 双指针
  • 排序
  • 力扣已通过

排序后固定第一个数，另两个数用左右双指针往中间夹；第一个数、l、r 三处都要跳过重复值。

思路

  • 先排序：相同的数挨在一起才好去重，双指针也才有方向可循。
  • 外层固定 nums[i]，l = i + 1、r = n - 1 往中间夹：和 < 0 就 l++，和 > 0 就 r--。
  • 和为 0 就收下，然后 l++、r-- 一起走一步，继续找下一组。
  • 去重共三处：nums[i] 和上一个相同就整轮跳过；收下后 l、r 各自越过和刚用过的值相同的数。

最优解

时间复杂度 O(n²)，空间复杂度 O(1)（不计排序）
1import java.util.*;2 3class Solution {4    public List<List<Integer>> threeSum(int[] nums) {5        List<List<Integer>> ans = new ArrayList<>();6        // 排序后相同的数挨在一起，才能去重7        Arrays.sort(nums);8        int n = nums.length;9        for (int i = 0; i < n - 2; i++) {10            // 第一个数和上一轮相同，会重复11            if (i > 0 && nums[i] == nums[i - 1]) continue;12            int l = i + 1, r = n - 1;13            while (l < r) {14                int sum = nums[i] + nums[l] + nums[r];15                // 和太小让 l 右移，和太大让 r 左移16                if (sum < 0) {17                    l++;18                } else if (sum > 0) {19                    r--;20                } else {21                    ans.add(Arrays.asList(nums[i], nums[l], nums[r]));22                    l++;23                    r--;24                    // 和刚收下的值相同，会重复25                    while (l < r && nums[l] == nums[l - 1]) l++;26                    while (l < r && nums[r] == nums[r + 1]) r--;27                }28            }29        }30        return ans;31    }32}
题目

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

示例 1：

输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。

示例 2：

输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0 。

示例 3：

输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0 。

提示：

  • 3 <= nums.length <= 3000
  • -105 <= nums[i] <= 105
