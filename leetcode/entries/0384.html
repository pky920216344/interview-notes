Fisher-Yates：i 从 n−1 往前，每个 i 与 [0, i] 里随机挑的 j 原地交换；reset 靠一份初始底版。

思路

  • 存两份：origin 底版 + cur 工作数组；reset() 从底版再拷一份返回，shuffle() 直接在 cur 上原地交换。
  • shuffle()：for i = n−1 … 1，j = rnd.nextInt(i + 1)，交换 cur[i] 与 cur[j]——每个位置恰好被定一次，共 n−1 次交换。
  • 关键是范围含 i 自己（nextInt(i + 1)、j 可以等于 i）：写成 j ∈ [0, i−1] 漏掉自己，[1,2,3,4] 的恒等排列概率会直接变 0，排列不再等可能。

时间复杂度 O(n) 每次 shuffle，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    private final int[] origin;   // 初始数组，reset 用的底版5    private int[] cur;            // 当前数组，shuffle 在它上面原地交换6    private final Random rnd = new Random();7 8    public Solution(int[] nums) {9        origin = Arrays.copyOf(nums, nums.length);10        cur = Arrays.copyOf(nums, nums.length);11    }12 13    public int[] reset() {14        // 回到初始状态：从底版再拷一份，别把底版本身交出去15        cur = Arrays.copyOf(origin, origin.length);16        return cur;17    }18 19    public int[] shuffle() {20        // Fisher-Yates：从后往前，i 与 [0, i] 里随机挑的 j 交换21        for (int i = cur.length - 1; i > 0; i--) {22            int j = rnd.nextInt(i + 1);23            int t = cur[i]; cur[i] = cur[j]; cur[j] = t;24        }25        return cur;   // cur 就是打乱后的数组26    }27}
题目

给你一个整数数组 nums ，设计算法来打乱一个没有重复元素的数组。打乱后，数组的所有排列应该是 等可能 的。

实现 Solution class:

  • Solution(int[] nums) 使用整数数组 nums 初始化对象
  • int[] reset() 重设数组到它的初始状态并返回
  • int[] shuffle() 返回数组随机打乱后的结果

示例 1：

输入
["Solution", "shuffle", "reset", "shuffle"]
[[[1, 2, 3]], [], [], []]
输出
[null, [3, 1, 2], [1, 2, 3], [1, 3, 2]]

解释
Solution solution = new Solution([1, 2, 3]);
solution.shuffle();    // 打乱数组 [1,2,3] 并返回结果。任何 [1,2,3]的排列返回的概率应该相同。例如，返回 [3, 1, 2]
solution.reset();      // 重设数组到它的初始状态 [1, 2, 3] 。返回 [1, 2, 3]
solution.shuffle();    // 随机返回数组 [1, 2, 3] 打乱后的结果。例如，返回 [1, 3, 2]

提示：

  • 1 <= nums.length <= 50
  • -106 <= nums[i] <= 106
  • nums 中的所有元素都是 唯一的
  • 最多可以调用 104 次 reset 和 shuffle
