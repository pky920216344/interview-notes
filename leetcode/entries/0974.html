974. 和可被 K 整除的子数组

前缀和对 k 取余 + 哈希计数：余数相同的前缀之间夹的和必被 k 整除，边扫边数。

思路

  • 和 560 同套路：子数组和 = 两前缀和之差；这里只问「差能否被 k 整除」，即两个前缀除以 k 的余数相同。
  • 负数取模在 Java 里会得负数，统一 (x % k + k) % k 修正到 [0, k)，余数才能当表键比较。
  • 扫到每位：先 ans += cnt[prefix]，再把当前余数计数 +1（先查后存）；余 0 先记 1 次，覆盖从头开始的子数组。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(min(n, k))
1import java.util.*;2 3class Solution {4    public int subarraysDivByK(int[] nums, int k) {5        // cnt：前缀和除以 k 的余数 → 出现次数；空前缀 0 先记 1 次6        Map<Integer, Integer> cnt = new HashMap<>();7        cnt.put(0, 1);8        int prefix = 0, ans = 0;9        for (int cur : nums) {10            // 负数取模在 Java 里是负的，+k 再模一次修正到 [0, k)11            prefix = ((prefix + cur) % k + k) % k;12            // 两个前缀余数相同，中间夹的和就能被 k 整除13            ans += cnt.getOrDefault(prefix, 0);14            cnt.merge(prefix, 1, Integer::sum);15        }16        return ans;17    }18}
题目

给定一个整数数组 nums 和一个整数 k ，返回其中元素之和可被 k 整除的非空 子数组 的数目。

子数组 是数组中 连续 的部分。

示例 1：

输入：nums = [4,5,0,-2,-3,1], k = 5
输出：7
解释：
有 7 个子数组满足其元素之和可被 k = 5 整除：
[4, 5, 0, -2, -3, 1], [5], [5, 0], [5, 0, -2, -3], [0], [0, -2, -3], [-2, -3]

示例 2:

输入: nums = [5], k = 9
输出: 0

提示:

  • 1 <= nums.length <= 3 * 104
  • -104 <= nums[i] <= 104
  • 2 <= k <= 104
