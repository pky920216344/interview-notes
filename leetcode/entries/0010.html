DP：dp[i][j] 表示 s 前 i 个与 p 前 j 个能否整体匹配；普通字符抄左上，x* 看「配零个」或「再吃一个」。

思路

  • dp[i][j]：s 前 i 个、p 前 j 个能否整体匹配；dp[0][0]=true，第 0 行沿 x* 传 dp[0][j-2]。
  • p[j] 是普通字符或 .：配得上 s[i] 就 dp[i][j] = dp[i-1][j-1]。
  • p[j] 是 *：dp[i][j] = dp[i][j-2]（x\* 配零个），或 x 配得上 s[i] 时 dp[i-1][j]（x\* 再多吃一个）。

最优解

时间复杂度 O(mn)，空间复杂度 O(mn)
1class Solution {2    public boolean isMatch(String s, String p) {3        int m = s.length(), n = p.length();4        // dp[i][j]：s 前 i 个字符与 p 前 j 个字符能否整体匹配5        boolean[][] dp = new boolean[m + 1][n + 1];6        dp[0][0] = true;7        // 空串能被 x*y*… 匹配：每个 x* 都取零个8        for (int j = 2; j <= n; j++) {9            if (p.charAt(j - 1) == '*') dp[0][j] = dp[0][j - 2];10        }11        for (int i = 1; i <= m; i++) {12            for (int j = 1; j <= n; j++) {13                if (p.charAt(j - 1) == '*') {14                    // x* 配零个：跳过 x*；或 x 配得上 s[i]：x* 再多吃一个字符15                    dp[i][j] = dp[i][j - 2] || (charMatch(s, p, i, j) && dp[i - 1][j]);16                } else if (charMatch(s, p, i, j)) {17                    // 普通字符或 '.' 配对成功：看双方各少一个的前缀18                    dp[i][j] = dp[i - 1][j - 1];19                }20            }21        }22        return dp[m][n];23    }24 25    // p 的第 j 个模式字符能否匹配 s 的第 i 个字符；j 处是 '*' 时看它前面的 x26    private boolean charMatch(String s, String p, int i, int j) {27        char pc = p.charAt(j - 1);28        if (pc == '*') pc = p.charAt(j - 2);29        return pc == '.' || pc == s.charAt(i - 1);30    }31}
题目

给你一个字符串 s 和一个字符规律 p，请你来实现一个支持 '.' 和 '*' 的正则表达式匹配。

  • '.' 匹配任意单个字符
  • '*' 匹配零个或多个前面的那一个元素

返回一个布尔值，表示匹配是否覆盖整个输入字符串（而非部分）。

 

示例 1：

输入：s = "aa", p = "a"
输出：false
解释："a" 无法匹配 "aa" 整个字符串。

示例 2:

输入：s = "aa", p = "a*"
输出：true
解释：因为 '*' 代表可以匹配零个或多个前面的那一个元素, 在这里前面的元素就是 'a'。因此，字符串 "aa" 可被视为 'a' 重复了一次。

示例 3：

输入：s = "ab", p = ".*"
输出：true
解释：".*" 表示可匹配零个或多个（'*'）任意字符（'.'）。

提示：

  • 1 <= s.length <= 20
  • 1 <= p.length <= 20
  • s 只包含从 a-z 的小写字母。
  • p 只包含从 a-z 的小写字母，以及字符 . 和 *。
  • 保证每次出现字符 * 时，前面都匹配到有效的字符
