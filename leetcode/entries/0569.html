569. 员工薪水中位数

  • 困难
  • 频度 1
  • SQL
  • 数据库
  • 未经力扣验证

ROW_NUMBER 排序 + COUNT 总数，奇数取正中一位、偶数取中间两位求平均（两个中位下标用 IN 一次框住）。

思路

  • 中位数下标通式：(cnt+1)/2 与 (cnt+2)/2——奇数时两者相等（同一位），偶数时是中间两位；WHERE rn IN (两值) 一次框住。
  • 偶数个时外层 AVG(salary) 天然求两中位数的平均；奇数个时 AVG 只作用一行，结果不变。
  • 窗口函数算完包一层再过滤（窗口结果不能直接进 WHERE）。
  • ⚠️ 会员题未经力扣验证：题面不可见，是否要求舍入、列名口径以你实际看到的题面为准。

最优解

时间复杂度 O(n log n)，空间复杂度 O(n)
