1171. 从链表中删去总和值为零的连续节点

前缀和做哈希键：当前缀和重复出现，说明中间一整段和为 0，直接把前一个结点接到当前结点后面。

思路

  • 哨兵 dummy 也算进前缀和（seen[0] = dummy）：两个结点前缀和相同 ⟺ 它们之间那段和为 0。
  • seen 记「每个前缀和现在挂在哪个结点上」；扫到重复的和，就把老结点 e 直连 cur.next，整段删除。
  • 删除的结点要同步从 seen 里清掉（沿链走一遍、按各自前缀和移除），否则残留记录会指到已删除的结点。
  • 删完继续用同一个 sum 往后扫：删掉的段和为 0，不影响后面的前缀和。

图解

最优解

时间复杂度 O(n)，空间复杂度 O(n)
1import java.util.*;2 3class Solution {4    public ListNode removeZeroSumSublists(ListNode head) {5        ListNode dummy = new ListNode(0);6        dummy.next = head;7        // seen：前缀和 -> 现在带着这个前缀和的结点；存活结点的前缀和互不相同8        Map<Integer, ListNode> seen = new HashMap<>();9        seen.put(0, dummy);10        int sum = 0;11        for (ListNode cur = head; cur != null; cur = cur.next) {12            sum += cur.val;13            ListNode e = seen.get(sum);14            if (e == null) {                 // 第一次见这个前缀和：cur 保留15                seen.put(sum, cur);16            } else {                         // e 之后到 cur 这段和为 0：整段删除17                int s = sum;                 // e 的前缀和也是 sum18                for (ListNode n = e.next; n != cur; n = n.next) {19                    s += n.val;              // s 走到 n 的前缀和20                    seen.remove(s);          // 被删结点的记录一并清掉21                }22                e.next = cur.next;           // e 直接连到 cur 后面，中间全跳过23            }24        }25        return dummy.next;26    }27}
题目

给你一个链表的头节点 head，请你编写代码，反复删去链表中由 总和 值为 0 的连续节点组成的序列，直到不存在这样的序列为止。

删除完毕后，请你返回最终结果链表的头节点。

你可以返回任何满足题目要求的答案。

（注意，下面示例中的所有序列，都是对 ListNode 对象序列化的表示。）

示例 1：

输入：head = [1,2,-3,3,1]
输出：[3,1]
提示：答案 [1,2,1] 也是正确的。

示例 2：

输入：head = [1,2,3,-3,4]
输出：[1,2,4]

示例 3：

输入：head = [1,2,3,-3,-2]
输出：[1]

提示：

  • 给你的链表中可能有 1 到 1000 个节点。
  • 对于链表中的每个节点，节点的值：-1000 <= node.val <= 1000.
