按右端升序排序后贪心：数对左端严格大于当前链尾就接上，接不上跳过。

思路

  • 按右端升序排序后「能接就接」是最优的：右端越小的数对，给后面留的空间越多。
  • end 记当前链尾；p[0] > end 才能接（严格大于），接上后 end = p[1]。
  • 本质是「最多不相交区间选择」，一个排序加一次扫描。

图解

最优解

时间复杂度 O(n log n)，空间复杂度 O(1)
1import java.util.*;2 3class Solution {4    public int findLongestChain(int[][] pairs) {5        // 按右端升序：右端越小，留给后面数对的空间越多6        Arrays.sort(pairs, (a, b) -> a[1] - b[1]);7        int ans = 0, end = Integer.MIN_VALUE;8        for (int[] p : pairs) {9            // 左端严格大于链尾才能接上，接不上就跳过10            if (p[0] > end) {11                ans++;12                end = p[1];13            }14        }15        return ans;16    }17}
题目

给你一个由 n 个数对组成的数对数组 pairs ，其中 pairs[i] = [lefti, righti] 且 lefti < righti 。

现在，我们定义一种 跟随 关系，当且仅当 b < c 时，数对 p2 = [c, d] 才可以跟在 p1 = [a, b] 后面。我们用这种形式来构造 数对链 。

找出并返回能够形成的 最长数对链的长度 。

你不需要用到所有的数对，你可以以任何顺序选择其中的一些数对来构造。

示例 1：

输入：pairs = [[1,2], [2,3], [3,4]]
输出：2
解释：最长的数对链是 [1,2] -> [3,4] 。

示例 2：

输入：pairs = [[1,2],[7,8],[4,5]]
输出：3
解释：最长的数对链是 [1,2] -> [4,5] -> [7,8] 。

提示：

  • n == pairs.length
  • 1 <= n <= 1000
  • -1000 <= lefti < righti <= 1000
