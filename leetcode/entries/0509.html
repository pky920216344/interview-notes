斐波那契只要前两项：a、b 两个变量滚动前进，算 n 步后 a 正好是 F(n)，数组都不用开。

思路

  • 循环不变量：进第 i 轮时 a=F(i)、b=F(i+1)；next=a+b 后 a←b、b←next，窗口右移一格。
  • 滚 n 步后 a=F(n)，直接返回 a；n=0 时不进循环，a=0 天然正确。
  • n ≤ 30 不会溢出 int，所以不用 long。

题目

斐波那契数 （通常用 F(n) 表示）形成的序列称为 斐波那契数列 。该数列由 0 和 1 开始，后面的每一项数字都是前面两项数字的和。也就是：

F(0) = 0，F(1) = 1
F(n) = F(n - 1) + F(n - 2)，其中 n > 1

给定 n ，请计算 F(n) 。

示例 1：

输入：n = 2
输出：1
解释：F(2) = F(1) + F(0) = 1 + 0 = 1

示例 2：

输入：n = 3
输出：2
解释：F(3) = F(2) + F(1) = 1 + 1 = 2

示例 3：

输入：n = 4
输出：3
解释：F(4) = F(3) + F(2) = 2 + 1 = 3

提示：

  • 0 <= n <= 30
