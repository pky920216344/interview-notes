剑指 Offer 53 - I. 统计目标成绩的出现次数

  • 简单
  • 频度 19
  • 二分查找
  • 数组
  • 二分查找
  • 力扣已通过

两次二分：第一个 ≥ target 的下标，减第一个 ≥ target+1 的下标，差就是出现次数。

思路

  • 只写一个 lowerBound(scores, x)：返回第一个 ≥ x 的下标，没有就是 scores.length。
  • 左边界 = lowerBound(target)；「右边界后一位」= lowerBound(target + 1)，即第一个 > target 的下标。
  • 两者相减即出现次数；target 不存在时两边界相等，差自然是 0。
  • 循环不变量：边界只可能在 [lo, hi) 里；scores[mid] ≥ x 时 hi = mid，否则 lo = mid + 1，lo == hi 时收敛。

最优解

时间复杂度 O(log n)，空间复杂度 O(1)
1class Solution {2    public int countTarget(int[] scores, int target) {3        // 左边界 = 第一个 ≥ target 的下标；右边界再往右一位 = 第一个 ≥ target+1 的下标4        return lowerBound(scores, target + 1) - lowerBound(scores, target);5    }6 7    // 第一个 ≥ x 的下标；都不满足就是 scores.length。搜索区间 [lo, hi) 左闭右开8    private int lowerBound(int[] scores, int x) {9        int lo = 0, hi = scores.length;10        while (lo < hi) {11            int mid = (lo + hi) >>> 1;12            if (scores[mid] >= x) hi = mid;   // mid 满足，边界在 [lo, mid] 里13            else lo = mid + 1;                // mid 不够大，边界在右侧14        }15        return lo;16    }17}
题目

某班级考试成绩按非严格递增顺序记录于整数数组 scores，请返回目标成绩 target 的出现次数。

示例 1：

输入: scores = [2, 2, 3, 4, 4, 4, 5, 6, 6, 8], target = 4
输出: 3

示例 2：

输入: scores = [1, 2, 3, 5, 7, 9], target = 6
输出: 0

提示：

  • 0 <= scores.length <= 105
  • -109 <= scores[i] <= 109
  • scores 是一个非递减数组
  • -109 <= target <= 109
